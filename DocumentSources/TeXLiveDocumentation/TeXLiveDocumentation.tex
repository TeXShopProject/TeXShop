\section{\TeX\ Live Documentation}

\TeX\ Live comes with documentation for almost every package. The latest versions are online:

\begin{itemize}
\item The documentation of any package, found by its name:
\url{https://texdoc.org}. To open the copy installed on your Mac, choose
\textbf{Help $\rightarrow$ Show Help for Package...} in TeXShop.

\item Every package, with its description, documentation and current version, on
CTAN, the Comprehensive \TeX\ Archive Network: \url{https://ctan.org}.

\item The \TeX\ Live guide, in several languages:
\url{https://tug.org/texlive/doc.html}.
\end{itemize}

Here are a few samples to show the variety of what's available:

\begin{itemize}

\item A book on \LaTeX, \emph{The Not So Short Introduction to \LaTeX}, by Tobias Oetiker et~al.:
\url{https://ctan.org/pkg/lshort-english}

\item \LaTeX\ package recommendations for common tasks: \url{https://ctan.org/pkg/latex-doc-ptr}

\item The documentation for Beamer, a \LaTeX\ class to create presentations:
\url{https://ctan.org/pkg/beamer}

\end{itemize}

\section{Getting Started with \LaTeX}

Some online links for learning \LaTeX:

\begin{itemize}
\item \url{https://tug.org/begin.html} - introductory material for those
new to \TeX.

\item \url{https://learnlatex.org} - online \LaTeX\ lessons, with
interactive examples.

\item \url{https://tug.org/FontCatalogue} - available fonts, including
\LaTeX\ usage.

\end{itemize}


\section{\TeX\ and TUG}

A few more general online links:

\begin{itemize}
	
\item \url{https://tug.org} - \TeX\ Users Group site. Please join or
donate if you like!

\item \url{https://tug.org/whatis.html} - a short history of \TeX.

\item \url{https://tug.org/TUGboat} - all issues of \textsl{TUGboat},
the main journal about \TeX.

\item \url{https://tug.org/texlive} - \TeX\ Live home page.

\item \url{https://ctan.org} - the Comprehensive \TeX\ Archive Network
(CTAN), with extensive information about all packages.

\end{itemize}
