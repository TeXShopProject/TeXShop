\section{Documentation de \TeX\ Live}

\TeX\ Live contient la documentation de presque tous les packages. Les versions les plus récentes sont en ligne :

\begin{itemize}
\item La documentation de n'importe quel package, trouvée par son nom :
\url{https://texdoc.org}. Pour ouvrir la copie installée sur votre Mac, choisissez
\textbf{Aide $\rightarrow$ Afficher l'aide pour le package...} dans TeXShop.

\item Tous les packages, avec leur description, leur documentation et leur version actuelle, sur
le CTAN, le Comprehensive \TeX\ Archive Network : \url{https://ctan.org}.

\item Le guide de \TeX\ Live, en plusieurs langues :
\url{https://tug.org/texlive/doc.html}.
\end{itemize}

Voici quelques exemples qui montrent la variété des informations disponibles :

\begin{itemize}

\item Un livre sur \LaTeX, \emph{The Not So Short Introduction to \LaTeX}, de Tobias Oetiker, Hubert Partl, Irene Hyna et Elisabeth Schlegl, en français :
\url{https://ctan.org/pkg/lshort-french}

\item Recommandations des packages \LaTeX\ pour les tâches courantes : \url{https://ctan.org/pkg/latex-doc-ptr}

\item La documentation pour Beamer, une classe \LaTeX\ pour créer des présentations :
\url{https://ctan.org/pkg/beamer}

\end{itemize}
