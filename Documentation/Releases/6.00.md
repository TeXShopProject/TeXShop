# TeXShop 6.00

<!-- release-status: draft -->

TeXShop 6.00 follows TeXShop 5.59. It adds a new Find panel, LaTeX-aware spell checking, pinned link previews, a new Settings window and a status bar, and fixes many problems.

## Main changes

- **Advanced Find panel:** a new Find panel with regular expressions lists every match, does multiple replacement, and finds and replaces in all files with the same root file.
- **LaTeX-aware spell checking:** check the spelling of the text alone, skipping TeX commands and mathematics.
- **Pinned link previews:** pin a link preview with the Option key.
- **Settings window:** a new Settings window with a sidebar and a search field.
- **Status bar:** the lines, characters and words are shown under the source.

## Advanced Find panel

- A new find and replace panel with regular expressions, the Advanced Find panel. Find All lists every match, and Highlight All marks them in the text.
- Multiple Replace applies saved sets of find and replace pairs at once.
- Find and replace in all files with the same root file: a new window, opened from the Find submenu of the Edit menu, lists each match in the root file and in the TeX files that name it as TEX root, shows each replacement before and after, and replaces them all at once, saving a copy of the files first. Suggested by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#45](https://github.com/TeXShopProject/TeXShop/issues/45)).
- A cheat sheet shows how to write regular expressions, and Find also works in the console, the log and the Experiment windows.

## LaTeX-aware spell checking

- Check the spelling of the text alone, skipping TeX commands, comments, mathematics and arguments that are not prose. The spelling panel and the choice of dictionaries are easier to use as well, and a spelling error found in a long document is now shown ([#32](https://github.com/TeXShopProject/TeXShop/issues/32), [#38](https://github.com/TeXShopProject/TeXShop/issues/38)). Suggested and reported by [Ralph Martin](https://github.com/ralphrmartin) and [Herb Schulz](https://github.com/herbs), and contributed by [Ralph Martin](https://github.com/ralphrmartin), also in [PR #40](https://github.com/TeXShopProject/TeXShop/pull/40), [PR #51](https://github.com/TeXShopProject/TeXShop/pull/51) and [PR #57](https://github.com/TeXShopProject/TeXShop/pull/57).

## Preview

- Link previews are easier to read and show the page number at the lower right, which Settings can turn off; pin one with the Option key, and turn previews on or off with the Control key. Suggested and reported by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#7](https://github.com/TeXShopProject/TeXShop/issues/7), [#10](https://github.com/TeXShopProject/TeXShop/issues/10), [#12](https://github.com/TeXShopProject/TeXShop/issues/12), [#14](https://github.com/TeXShopProject/TeXShop/issues/14), [#17](https://github.com/TeXShopProject/TeXShop/issues/17), [#30](https://github.com/TeXShopProject/TeXShop/issues/30), [#35](https://github.com/TeXShopProject/TeXShop/issues/35)).
- In a split Preview window, show a link’s target in the other part or switch the two parts; after unsplitting, the part you were using stays, and the pages usually stay in place on the screen when MultiPage display is first split into a top and a bottom part. In a window that is not split, Switch Views changes between two views, each with its own magnification, display format and pinned link popup. Suggested by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#14](https://github.com/TeXShopProject/TeXShop/issues/14), [#25](https://github.com/TeXShopProject/TeXShop/issues/25), [#31](https://github.com/TeXShopProject/TeXShop/issues/31), [#52](https://github.com/TeXShopProject/TeXShop/issues/52), [#60](https://github.com/TeXShopProject/TeXShop/issues/60), [#66](https://github.com/TeXShopProject/TeXShop/issues/66)). The single window opens with the divider where it was last, suggested by [Felix Finster](https://github.com/felix-finster) ([#26](https://github.com/TeXShopProject/TeXShop/issues/26)).
- Annotate with an annotation toolbar under the toolbar of the Preview window (Preview › Show Annotation Toolbar). Its tools work on the document of that window, also in the window that shows the source and the Preview. Suggested by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#49](https://github.com/TeXShopProject/TeXShop/issues/49)).
- Zoom to Content Width and Fit to Content Width, scrolling that does not turn pages and a magnifying glass at any magnification are added, and the outline in the drawer stays as it was after typesetting. Suggested and reported by [Uwe Schmock](https://github.com/Uwe-Schmock) and [svb-bit](https://github.com/svb-bit) ([#9](https://github.com/TeXShopProject/TeXShop/issues/9), [#19](https://github.com/TeXShopProject/TeXShop/issues/19), [#33](https://github.com/TeXShopProject/TeXShop/issues/33)). When another application such as latexmk rewrites the PDF, the preview is updated at the same place. Press Return in the drawer to go to the entry chosen with the keyboard, suggested by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#61](https://github.com/TeXShopProject/TeXShop/issues/61)).
- The preview toolbar has the icons of Apple’s Preview, tool tips and page layout menus; click the word next to its magnification field to open the Magnification menu. Suggested by Bruno Voisin and [Uwe Schmock](https://github.com/Uwe-Schmock) ([#28](https://github.com/TeXShopProject/TeXShop/issues/28), [#34](https://github.com/TeXShopProject/TeXShop/issues/34), [#54](https://github.com/TeXShopProject/TeXShop/issues/54)).
- Print from the Preview as Apple’s Preview does: with Auto Rotate and Scale to Fit in the print panel, each page is turned and made to fit the paper. Suggested by Bruno Voisin.

## Editing

- Command-0 shows the document’s console. Suggested by [Nicolas Martignoni](https://github.com/martignoni) ([#2](https://github.com/TeXShopProject/TeXShop/issues/2)).
- Click or drag over the line numbers to select whole lines.
- The Edit menu has Character Type Conversion, Unicode Normalization, and Swap with Clipboard, which replaces the selection with the clipboard text and places the selection on the clipboard.
- Copy with Style in the Edit menu makes a copy of the source as rich text with its syntax coloring; TeXShop 4.08 to 5.00 made a copy in rich text, without the syntax colors. Copy still makes a copy in plain text.
- The Macro Editor has a new design, and macros and key bindings can insert the clipboard text.
- Key bindings with the new Paste box checked apply to text you paste, as well as to typing.
- Fullwidth letters, digits and symbols can be shown in their own color; to show them like other text, turn off Highlight Fullwidth Letters and Symbols in Settings → Editor.
- The encoding of a source file is detected automatically.
- Experiment typesets with the document’s pictures and references, and its source looks like the document’s source. Suggested and reported by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#8](https://github.com/TeXShopProject/TeXShop/issues/8), [#20](https://github.com/TeXShopProject/TeXShop/issues/20)).
- Complete the reference names that the document defines, and BibDesk citations, with a new item in the Edit menu. Settings → Keyboard shows the Option and Control mark keys, and Experiment uses the same completion key as the source window.
- The Tags menu is always up to date, and Character Info shows details of a character.

## Settings window

- Settings has a sidebar with ten categories: General, Documents and Saving, Editor, Keyboard, Spell Checking, Themes, Typesetting, Console, Preview, and Updates. Search Settings finds a setting.
- Detect Paths… sets the TeX and Ghostscript installations automatically.
- The index program and MetaPost can be set.
- Change the shortcut of any menu command and the key bindings in Settings → Keyboard; Duplicate and Close All, which macOS adds to the File menu, can also be changed. Reported by [Herb Schulz](https://github.com/herbs) ([#46](https://github.com/TeXShopProject/TeXShop/issues/46)).
- Settings → Updates can include betas. The keyboard shortcut of Quit works while the message that TeXShop is up to date is shown. Suggested by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#68](https://github.com/TeXShopProject/TeXShop/issues/68)).
- Autosave and Versions can be turned off, the first page can be shown alone as a cover, @ can count as part of command names, expl3 and index highlighting can be on at opening, the markers for invisible characters can be chosen, the left and right arrow keys can always turn pages, the Preview can keep its magnification, display format and split in full screen, the Advanced Find panel can be kept on top, and window opacity can also be typed as a number.
- In Settings → Preview and Settings → Editor, the settings for how a document opens are put together in one group, When a Document Opens.
- General links to Comment Lines and Hidden Settings.

## App icon and appearance

- A new app icon, and the Dock icon while TeXShop is running can be one of the earlier designs. Suggested by [LaTeX fetishist](https://github.com/LaTeX-fetishist) and [Nicolas Martignoni](https://github.com/martignoni) ([#3](https://github.com/TeXShopProject/TeXShop/issues/3)).
- On macOS 26 and later, TeXShop has the Liquid Glass appearance.
- The digits of line numbers line up, and the Matrix and LaTeX panels are easier to read in Dark Mode.
- Comments and other colors of the bundled themes are easier to read.
- Settings → Themes lists the themes: add, duplicate, rename, delete, restore, export and import them there.

## Changes in behavior from earlier versions

- **Spell checking:** LaTeX-aware spell checking is on by default. The legacy method is in Settings → Spell Checking.
- **Find:** the Advanced Find panel is used by default. The earlier panel can be chosen in Settings → Editor → Find Panel.
- **Syntax highlighting:** the switch is no longer in Settings; to open documents without syntax highlighting, use the hidden setting listed in Comment Lines and Hidden Settings. The Source menu items are now Syntax Highlighting and Highlight expl3 Code.
- **Index highlighting:** the Color Index item of the source toolbar is now Highlight Index Entries in the Source menu.
- **Settings profiles:** settings profiles are replaced by engine profiles in Settings → Typesetting. Choose a profile to set up typesetting for that TeX engine in one step.
- **Themes:** colors are saved as soon as they change, and the themes to edit are chosen in their list.
- **Typesetting settings:** Default Command is now Typeset New Documents With, and Command to use is now Engine File.
- **Arrow keys in the preview:** in single-page and two-page layouts, the Up and Down Arrow keys scroll within the page instead of turning it. Suggested by [svb-bit](https://github.com/svb-bit) ([#9](https://github.com/TeXShopProject/TeXShop/issues/9)).
- **Menu shortcuts set in macOS:** shortcuts for TeXShop made in macOS System Settings may need to be set again in Settings → Keyboard.
- **Macro shortcuts:** macro shortcuts are set in the list of the Macro Editor.
- **Marks:** the mark commands are in Edit → Marks.
- **Command completion:** the Command Completion submenu of the Source menu is now one item, Add to Command Completion List.
- **Open Style File:** it has moved from the Help menu to the File menu.
- **Demo movies:** the two movies in the Help menu are removed. Reported by [Herb Schulz](https://github.com/herbs) ([#43](https://github.com/TeXShopProject/TeXShop/issues/43)).
- **Fullscreen (Old Method):** this item of the Window menu is removed. Use Window → Enter Full Screen instead.
- **Smooth text and line art:** this setting is removed.
- **Save PostScript File and -dALLOWPSTRANSPARENCY:** these settings are removed.
- **Obsolete settings:** settings that had no effect are removed.
- **Themes from earlier color settings:** this button in Settings → Themes and the macro Colored source are removed.
- **Clipboard conversion of ¥ and `\`:** these two items of the Edit menu are removed. When Encoding for new documents in Settings is UTF-8, ¥ and `\` in text you paste stay the same, also with otf conversion; with a Japanese encoding, its own conversion is used as before. With UTF-8, ¥ is replaced with a backslash when you type or paste it while Key Bindings are on for the document: when you install TeXShop for the first time, Key Bindings already give a backslash for ¥ and have its Paste box checked; earlier users can set the output of ¥ to a single backslash and check its Paste box.
- **`\UTF` commands:** `\UTF` commands of the otf package are turned back into characters when a file is opened.
- **Line endings:** opening a file with Windows or other line endings tells you that they were changed to LF.
- **Statistics:** Edit › Statistics… opens Text Statistics in the status bar.

## Fixes: typesetting and the console

- **Critical fix:** Stop now ends TeX; before, TeX kept running.
- Fix problems with the console and typesetting: console output can be copied while TeX runs, broken characters in console output and logs are shown correctly, Command-1 returns to the file typeset with `% !TEX root`, stopping no longer hangs when a typesetting tool cannot start, TeXShop tells you when the root file cannot be found, and the tools for pictures, MetaPost and texloganalyser work when the TeX or Ghostscript folder has a space in its path.
- Typesetting is stopped when its document is closed or when you quit TeXShop, and it no longer starts when the save before it fails, when you cancel that save, or when you stop it during that save.

## Fixes: preview

- Fix the position and display of the preview: it no longer moves after reloading or turning pages on macOS 26 and 27, when it is split or its divider is dragged, when the window changes width, or when it is reopened during typesetting; parts of the linked page no longer show around a link preview; pages take the theme’s color again; a split Preview window no longer shows a light band in Dark Mode; and a PDF with a password shows its pages in both parts of a split Preview window. Reported by [svb-bit](https://github.com/svb-bit), [Uwe Schmock](https://github.com/Uwe-Schmock) and [ethanphil4-a11y](https://github.com/ethanphil4-a11y) ([#5](https://github.com/TeXShopProject/TeXShop/issues/5), [#9](https://github.com/TeXShopProject/TeXShop/issues/9), [#21](https://github.com/TeXShopProject/TeXShop/issues/21), [#23](https://github.com/TeXShopProject/TeXShop/issues/23), [#24](https://github.com/TeXShopProject/TeXShop/issues/24), [#39](https://github.com/TeXShopProject/TeXShop/issues/39), [#53](https://github.com/TeXShopProject/TeXShop/issues/53), [#55](https://github.com/TeXShopProject/TeXShop/issues/55)).
- SyncTeX goes to the place clicked, a crash while the preview reloads is fixed, and Space scrolls correctly through large pages.
- On macOS 26 and later, the toolbar of the Preview window works while the magnifying glass is the tool, and link popups no longer appear over the toolbar. Reported by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#44](https://github.com/TeXShopProject/TeXShop/issues/44)).
- On macOS 27, Page Up and Page Down work again in single-page and two-page layouts. They turn the page when the whole page is shown in the window; otherwise they scroll by a screen, and at the end of the page go on to the next or previous page, as the Preview app does on macOS 15 and 26.
- Clicking an entry of the outline in the drawer goes to its page again after the Preview window is closed and opened again, and after a new document is typeset for the first time. Reported by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#59](https://github.com/TeXShopProject/TeXShop/issues/59)).

## Fixes: opening and saving documents

- The cursor no longer jumps in files synced by OneDrive, Google Drive and similar services, document windows open again in Romanian, and TeXShop notices changes saved by other editors. Reported by [Steuard](https://github.com/Steuard) and [Tom](https://github.com/yo3iti) ([#29](https://github.com/TeXShopProject/TeXShop/issues/29), [#42](https://github.com/TeXShopProject/TeXShop/issues/42)), with a contribution from [Daisuke Nishihama](https://github.com/ddd3h) in [PR #1](https://github.com/TeXShopProject/TeXShop/pull/1).
- Fix reading and saving in several encodings: UTF-8 with a byte order mark, UTF-16, GB 2312, the backslash and the tilde in Japanese encodings, the encoding menu in the Save dialog, Automatic UTF-8-Mac to UTF-8 Conversion and conversion to otf package `\UTF` / `\CID` work correctly, and Make Default Editor works for `.tex` files.
- With Show Full Path in Window Title on in the toolbar, the title of the source window no longer goes back to the file name after an autosave.

## Fixes: editing and other

- Fix the coloring and display of the source: a line break in a comment and an unclosed argument no longer upset the colors, a form feed no longer hides the rest of the document, and a `% !TEX spellcheck` line no longer changes the language of other documents. Long documents are faster to show and edit. Reported in part by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#16](https://github.com/TeXShopProject/TeXShop/issues/16)).
- Splitting the source in the single window divides it evenly, the Home URL of the HTML window works, and a crash in the Matrix panel is fixed.
- On macOS 26 and later, the end of the toolbar no longer jumps back and forth at some window width.
- On macOS 26, the default set at the bottom of the sheet that changes the toolbar no longer grows and shows twice when clicked. Reported by [Uwe Schmock](https://github.com/Uwe-Schmock) ([#48](https://github.com/TeXShopProject/TeXShop/issues/48)).
- When a file of TeXShop in ~/Library/TeXShop, such as the macros, the LaTeX panel or the themes, is missing or damaged, TeXShop replaces it with its own copy without an error message; the damaged file is kept in a folder of ~/Library/TeXShop.
- In fonts without a fixed width, a tab in the source is no longer about twice the Tab Size set in Settings.
- Fix the highlight of brackets: it no longer ends too early when you type one after another, it stays when you scroll, resize the window or change themes, and brackets typed with a Japanese input method get the highlight only once confirmed.
- Undo now works after you insert a mark or remove one, and by default, Windows or other line endings in text you paste are changed to LF.
- Fix a crash when a setting or file that TeXShop reads is missing or damaged, such as a font that was removed or a damaged macros file, or when you sync from a page without SyncTeX information. The Previous Page and Next Page buttons of an image window turn its pages.
- Fix text that was cut off or drawn over other text, buttons and menus that did not work, and texts left in English, in some languages.

- Update the bundled zlib to 1.4 and the SyncTeX parser to 1.21.
