# TeXShop 5.59

This is the first TeXShop release maintained by Yusuke Terada, following Richard Koch's handover of the project. It builds on TeXShop 5.58 Golden Gate.

## Changes

- Keep the PDF zoom indicator in sync with trackpad gestures and preserve manual zoom when reloading a PDF.
- Correct initial PDF positioning and preview overlay coordinates.
- Add a PDF appearance menu with System, Light, and Dark choices.
- Fix toolbar item sizing and localized Preferences layouts and fonts.
- Create HTML preview views at runtime to avoid document-window loading failures on older macOS versions.
- Enable macOS filename suggestions for untitled documents on macOS 27.
- Fix a syntax-highlighting range error that could cause a crash.
- Align invisible-character markers with the text baseline.
- Restore the preview after a failed compilation produces an invalid PDF and a subsequent compilation succeeds.
- Work around a PDFKit/Metal rendering crash on macOS 27.
- Introduce a new app icon and update Sparkle to 2.10.1, using TeXShopProject's update feed and signing key.

## Installation

Download `TeXShop-5.59.zip`, extract it, and copy TeXShop.app to Applications. A separate TeX distribution, such as MacTeX, is required for typesetting.

The application is built for Apple Silicon and Intel with a minimum deployment target of macOS 14.6.

Users of Richard Koch's earlier releases should install this release manually. This release uses a new update feed and signing key for subsequent TeXShopProject updates.
