Spell Checking in TeXShop

Settings > Source > TeX-aware spell checking selects this mode, enabled by default in TeXShop 5.60. Turn it off to use the legacy exclusion options below the checkbox. Your previous options are retained. The new rules apply to TeX source files; other file types keep their previous behavior. This setting does not turn on Check Spelling While Typing. Use Edit TeX exclusion rules… to customize what is skipped.

The new rules apply to unsaved TeX documents and files with the extensions tex, ltx, latex, dtx, ins, sty, cls, clo, bbx, cbx, lbx. Mixed-source formats such as Sweave (Rnw), and other extensions including ctx, retain the legacy behavior.

TeXShop's spell checking knows about TeX. It skips comments, maths, commands, and the arguments of commands such as \label, \ref, \cite and \usepackage, and checks the rest of your text. It uses the standard Spelling and Grammar panel, so it works the way spell checking works in other Mac programs.

Checking a document

  • Choose Edit > Spelling and Grammar > Show Spelling and Grammar (⌘:) to open the panel. It goes to the first misspelled word after the cursor.
  • Press Find Next in the panel, or choose Check Document Now (⌘;), to move to the next one. The word is selected in your document, and the window scrolls so that its line is in the middle.
  • In the panel, Change replaces the word with the chosen suggestion (or with what you type in the panel's word field), Ignore ignores the word in this document, and Learn adds it to the dictionary for the current language.
  • With Check Spelling While Typing turned on, misspelled words are underlined as you type, but not in the parts of the source that are skipped.

Macros you define yourself (\newcommand, \def …) are read from the document, and an argument that the definition only passes on to \ref, to maths or the like is skipped too.

Text marked as another language with \foreignlanguage, \selectlanguage, \begin{otherlanguage} and the like is checked in that language, but is not underlined while you type.

Enter the replacement in the separate Replacement for Change All field, then click Change All or press Return. Selecting a different system suggestion with a click or the Up/Down keys fills this field. When there is only one suggestion, it is entered in this field as soon as the word is shown. To copy an already selected suggestion again, first select a different one, then select the desired suggestion; if there is no other suggestion, type it or use Find Next again. If a suggestion is not copied, enter the replacement manually. The replacement applies throughout the reviewed document, excluding skipped text, and can be undone in one step. After changing the document or selection, use Find Next again before replacing.

The original behaviour

Hold the Option key when you choose Show Spelling and Grammar or Check Document Now, or when you click Find Next, to use the system's own search, which does not skip any markup.

Forgetting learned words

Edit > Spelling and Grammar > Forget Learned Words… lists the words in the document in front that you have learned for the current language. Select one or several (Shift-click or Command-click) and click Forget Selected to remove them from the dictionary. Only learned words that occur in the document are listed.

Changing what is skipped

Edit > Spelling and Grammar > Edit Spelling Exclusions… opens the file ~/Library/TeXShop/SpellCheck/SpellingExclusions.txt in a text editor. It lists what is skipped, one rule per line, and explains its own format at the top. Changes take effect the next time you spell check; no restart is needed. For example, to skip the argument of a command you have defined, add a line such as

skip-args  1  mycommand

and to skip the inside of an environment:

skip-body  proof

If you delete the file, TeXShop puts back a fresh copy of the default the next time it starts. To stop skipping anything, replace its contents with comments only.
