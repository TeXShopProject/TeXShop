Macros

O menu Macros, e o item Macros da barra de ferramentas, contêm comandos que inserem código LaTeX no código-fonte ou executam scripts AppleScript. Algumas das macros que acompanham o TeXShop:

  • Set Typesetting Program…, Set Encoding… e Set Root File… escrevem as linhas % !TEX que escolhem o motor de composição, a codificação e o arquivo principal de um documento. Escolha o motor ou a codificação na lista que Set Typesetting Program… ou Set Encoding… mostra, ou o arquivo principal no diálogo que Set Root File… abre; a linha é escrita corretamente no início do código-fonte.
  • Insert Begin/End transforma a palavra no ponto de inserção ou a palavra selecionada, como theorem, em um par \begin{theorem} … \end{theorem}, com o ponto de inserção entre eles.
  • Submenus como Headings, Mathematics, Lists, Tables e Figures inserem código LaTeX comum.

O editor de macros

Escolha Macros › Abrir editor de macros... para ver como cada macro está definida, alterá-la ou acrescentar macros suas. A lista à esquerda é o menu Macros: arraste os itens para reorganizá-los e use a barra abaixo da lista para acrescentar itens, submenus e separadores. O texto de uma macro é inserido no código-fonte. Nesse texto, fichas arredondadas representam o texto selecionado, o texto da área de transferência e o lugar do ponto de inserção; escolha-as no menu Inserir, abaixo do texto.

Para dar um atalho de teclado a uma macro, selecione-a na lista, clique no atalho dela (ou clique duas vezes nele) e pressione as teclas. Um atalho usa a tecla Command ou Control, ou é uma tecla de função. Se um comando de menu ou outra macro já o usa, o editor de macros avisa.

As macros ficam guardadas em ~/Library/TeXShop/Macros/Macros_Latex.plist. Para passar macros a outras pessoas, selecione-as no editor de macros e escolha Macros › Salvar seleção em um arquivo...; para acrescentar macros de um arquivo assim, escolha Macros › Adicionar macros de um arquivo....

O capítulo Ajuda para macros explica as macros em detalhe, incluindo as macros AppleScript.
