Ajustes ocultos

A janela Ajustes tem os ajustes de que a maioria das pessoas precisa. Os menos comuns são ajustes ocultos: não têm nenhum controle na janela Ajustes e são alterados com um comando no Terminal. A referência “Linhas de Comentário e Ajustes Ocultos” lista todos os ajustes ocultos com o respectivo comando, agrupados por assunto. Abra-a com Ajuda › Linhas de Comentário e Ajustes Ocultos (em inglês) ou com “Abrir o manual Linhas de Comentário e Ajustes Ocultos…” em Ajustes › Geral › Avançado.

Alterar um ajuste oculto

  1. Encerre o TeXShop.
  2. Abra o Terminal (em /Applications/Utilities), digite o comando e pressione Return.
  3. Abra o TeXShop de novo.

Cada comando tem a forma defaults write TeXShop nome valor. Para voltar ao valor padrão, use defaults delete TeXShop nome.

Exemplos

defaults write TeXShop OtherTrashExtensions -array 'nav' 'snm'
Arquivo › Limpar arquivos auxiliares remove também os arquivos com essas extensões. Indique as extensões sem o ponto. Consulte Remover arquivos AUX.
defaults write TeXShop ConTeXtTags YES
O menu Etiquetas lista os comandos de seção do ConTeXt, como \title e \subject, em vez dos do LaTeX.
defaults write TeXShop RedConsoleAfterError YES
O texto digitado no console para responder a um erro do TeX, e toda a saída posterior dessa execução, aparece em vermelho.
defaults write TeXShop RefreshTime 2
Enquanto “Sempre monitorar alterações no PDF feitas por outros apps” estiver ativado em Ajustes › Pré-visualização, o TeXShop verifica a cada 2 segundos se um PDF mudou. O padrão é 1 segundo e o mínimo, 0,5.

Os ajustes que estão na janela Ajustes não se repetem entre os ajustes ocultos. Por exemplo, ir para a marca seguinte ou anterior de Editar › Marcas com Option ou Control e a tecla de ativação da conclusão é ativado e desativado com “Ir para a marca seguinte ou anterior com Option ou Control e a tecla de ativação” em Ajustes › Teclado. Para encontrar um ajuste desses, use “Buscar ajustes”; consulte Alterar os ajustes e Buscar ajustes.
