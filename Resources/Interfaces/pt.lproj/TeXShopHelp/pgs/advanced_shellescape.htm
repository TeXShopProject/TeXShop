Proteção contra shell escape

Durante a composição, o TeX pode executar outros programas. Por padrão, o TeX Live permite apenas uma lista curta de programas confiáveis, por exemplo para converter gráficos EPS em PDF. Os pacotes que precisam executar outros programas pedem a opção -shell-escape (também escrita --shell-escape).

Com essa opção, um documento pode executar qualquer comando, por exemplo um que apague todos os arquivos da sua pasta pessoal. Use-a apenas para documentos em que você confia, e não para arquivos que recebe de outras pessoas.

Acrescentar a opção

  • No comando LaTeX ou plain TeX de Ajustes › Composição › PDF direto, para todos os documentos compostos com PDF direto.
  • Em um arquivo de motor, para todos os documentos compostos com esse motor; consulte Adicionar motores de composição.
  • Para um documento composto com um dos motores latexmk, como o pdflatexmk, com a linha % !TEX parameter = -shell-escape no início do código-fonte.

Um motor já tem a opção: o sepdflatexmk, que vem com o TeXShop e está na pasta Engines desde o início, sempre compõe com --shell-escape. Escolhê-lo na barra de ferramentas da janela do código-fonte ou com uma linha % !TEX program = sepdflatexmk basta; por isso, use-o apenas para documentos em que você confia.

Confirmar shell escape

Ajustes › Composição › PDF direto › “Confirmar shell escape”, desativado por padrão, protege os comandos do grupo PDF direto. Quando ele está ativado e o comando plain TeX ou LaTeX desse grupo contém -shell-escape ou --shell-escape, o TeXShop pergunta antes de compor um documento pela primeira vez depois que ele é aberto:

  • OK compõe com a opção.
  • “Omitir shell escape” compõe sem ela.
  • Cancelar não compõe.

Depois que você escolhe OK ou “Omitir shell escape”, a resposta vale para esse documento até que ele seja fechado; assim, você pode compor os seus próprios documentos com a opção e os documentos de outras pessoas sem ela. Os arquivos de motor não são verificados, mesmo que contenham -shell-escape; por isso, o sepdflatexmk compõe com a opção sem perguntar.
