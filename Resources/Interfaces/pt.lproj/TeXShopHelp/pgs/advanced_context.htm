ConTeXt e MetaPost

ConTeXt

O ConTeXt é um pacote de macros de Hans Hagen, uma alternativa ao LaTeX com comandos próprios e grande ênfase no design tipográfico. O TeX Live inclui o ConTeXt, e o ConTeXt Garden distribui uma versão, atualizada com frequência, que se instala na sua pasta pessoal.

Os motores para o ConTeXt estão em ~/Library/TeXShop/Engines/Inactive/ConTeXt, junto com o guia Setting-Up-ConTeXt.pdf e documentos de exemplo:

MotorCompõe com
ConTeXt.engineo ConTeXt do TeX Live que roda sobre o LuaTeX
ConTeXt-TL.engineo ConTeXt do TeX Live que roda sobre o luametatex
ConTeXt-CG.enginea versão do ConTeXt Garden na sua pasta pessoal

Mova o motor de que precisar para ~/Library/TeXShop/Engines e coloque linhas mágicas no início do arquivo principal do documento, por exemplo:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Para o ConTeXt-CG, digite a pasta dos programas da instalação do ConTeXt Garden no campo “Segundos motores TeX” de Ajustes › Composição › Caminhos e acrescente a linha % !TEX useAlternatePath, que faz o TeXShop passar essa pasta ao motor em vez da do TeX Live.

Para a sincronização entre o código-fonte e a pré-visualização, acrescente \setupsynctex[state=start,method=min] à configuração do documento; a linha % !TEX useConTeXtSyncParser faz o TeXShop usar o código de sincronização do próprio ConTeXt. O capítulo sobre o ConTeXt em Ajuda › Manual do TeXShop (em inglês) descreve em detalhe a instalação da versão do ConTeXt Garden e cada motor.

Para listar no menu Etiquetas comandos de seção do ConTeXt como \title e \subject, ative o ajuste oculto ConTeXtTags; consulte Ajustes ocultos.

MetaPost

O MetaPost, de John Hobby, desenha ilustrações a partir de uma descrição em uma linguagem de programação derivada do METAFONT de Knuth. O seu manual faz parte do TeX Live: escolha Ajuda › Exibir ajuda para o pacote... e digite metapost.

Compor › MetaPost (⇧⌘M), ou MetaPost no menu local ao lado do botão Compor, executa o MetaPost no arquivo que tem o nome do documento ativo e a extensão .mp: no próprio documento, se ele for um arquivo .mp, e, caso contrário, no arquivo .mp ao lado dele, como o que o pacote mfpic grava para um documento .tex. Ele executa o comando de Ajustes › Composição › Ferramentas relacionadas › MetaPost, mpost por padrão. Os perfis do motor definem esse campo: pmpost para pLaTeX + dvipdfmx e upmpost para upLaTeX + dvipdfmx, que compõem texto em japonês nos rótulos, e mpost para os outros perfis. O LuaLaTeX não consegue incluir figuras cujos rótulos o pmpost ou o upmpost compuseram em japonês; com o LuaLaTeX, desenhe essas figuras no documento com o pacote luamplib.

Para salvar um arquivo novo como arquivo MetaPost, escolha o tipo mp no menu Formato do diálogo Salvar.

O motor nv-metapost, de Nicola Vitacolonna, facilita o trabalho com o MetaPost e mostra as figuras de um arquivo na janela de pré-visualização. Ele está em ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; o arquivo README.rtf e a pasta examples, um nível acima, em MetaPostEngines-1.4.7, explicam como instalá-lo e usá-lo e trazem arquivos de exemplo. Por exemplo, um arquivo que começa com

% !TEX program = nv-metapost
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

é composto com o nv-metapost quando esse motor estiver na pasta Engines.

Os desenhos do MetaPost também podem ser escritos dentro de um documento LaTeX, com o pacote luamplib para o LuaLaTeX, ou com pacotes como o mfpic, que gravam os desenhos em um arquivo .mp que o MetaPost processa entre duas composições.
