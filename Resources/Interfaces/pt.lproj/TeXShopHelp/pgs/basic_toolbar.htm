Barra de ferramentas e AppleScript

Alterar a barra de ferramentas

A janela do código-fonte, a janela de pré-visualização e a janela que mostra os dois têm cada uma a sua própria barra de ferramentas. Para alterar uma delas, ative a janela e escolha Janela › Personalizar barra de ferramentas..., ou clique na barra de ferramentas com a tecla Control pressionada e escolha ali Personalizar Barra de Ferramentas…. Arraste itens para a barra de ferramentas ou para fora dela, ou arraste o conjunto padrão para a barra de ferramentas para recomeçar. Janela › Ocultar Barra de Ferramentas oculta a barra de ferramentas da janela ativa.

Itens da janela do código-fonte

Compor, com o menu Programa ao lado, compõe o documento com o programa ali escolhido; há também botões para programas individuais, como BibTeX e Gerar índice. Modelos e Macros inserem texto (consulte Modelos e documentos-modelo e Macros). Marcas e Rótulos rolam o código-fonte até uma seção ou um rótulo. Associações de teclas ativa ou desativa as associações de teclas para o documento, e Dividir Janela divide a janela (clique com a tecla Option pressionada para dividi-la lado a lado).

Caminho completo mostra o caminho completo do arquivo no título da janela em vez de apenas o nome; clique de novo para mostrar o nome. A escolha é mantida para as janelas abertas depois.

Itens da janela de pré-visualização

A janela de pré-visualização tem, entre outros, Página anterior e Página seguinte, Ir para a página, Voltar/Avançar, Ampliação, Modo do Mouse, Buscar, Gaveta, Marcas de sincronismo, Dividir Janela e Aparência, que mostra as páginas claras ou escuras. Clique na palavra ao lado do campo de ampliação para abrir o menu Ampliação.

“Layout da página” escolhe Uma única página, Página dupla, Várias páginas ou Várias páginas duplas para o documento. “Modo de página dupla” escolhe, para o documento enquanto ele está aberto, se duas páginas correm da esquerda para a direita ou da direita para a esquerda e se a primeira página é mostrada sozinha como capa; “Restaurar ajustes do documento”, nesse menu, volta aos Ajustes e às linhas de comentário mágico do documento. Zoom para o conteúdo e Zoom para a largura do conteúdo alteram a ampliação uma única vez para que a parte composta da página, sem as margens brancas, caiba na janela ou na largura dela. Consulte A janela de pré-visualização.

Página › Mostrar Barra de Ferramentas de Anotações mostra uma segunda barra de ferramentas abaixo da barra de ferramentas, com as ferramentas para acrescentar notas, destaques e formas ao PDF. Clique no botão de fechar na extremidade direita dela, ou escolha Página › Ocultar Barra de Ferramentas de Anotações, para removê-la. As anotações são descritas no Manual do TeXShop (Ajuda › Manual do TeXShop (em inglês)).

AppleScript

O TeXShop pode ser controlado com AppleScript: os scripts podem compor documentos, executar o BibTeX e o MakeIndex e trabalhar com o texto do código-fonte. As macros AppleScript do menu Macros executam scripts desse tipo; consulte Macros AppleScript. Os comandos que o TeXShop entende são explicados em Ajuda › Documentos antigos › Notas sobre o Applescript no TeXShop (em inglês) e listados no dicionário de scripts do TeXShop, que o Editor de Scripts abre com Arquivo › Abrir Dicionário.
