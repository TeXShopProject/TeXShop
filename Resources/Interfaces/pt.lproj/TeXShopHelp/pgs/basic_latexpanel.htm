Painel LaTeX

Janela › Painel LaTeX... abre um painel de código LaTeX: símbolos matemáticos, letras gregas, funções, caracteres acentuados e internacionais, ambientes e comandos de tipo de letra. Clique no código-fonte onde o código deve entrar e depois clique em um botão do painel. O código do botão é inserido no ponto de inserção. O painel permanece na frente das janelas de código-fonte enquanto você trabalha.

Os botões estão organizados em páginas. Escolha uma página com os botões no topo de cada parte do painel: Matemática, Grego, Símbolos, Funções e Internacional, e Ambientes, Tipo e Personalizado.

Se houver texto selecionado quando você clicar em um botão de tipo de letra ou de ambiente, o texto selecionado vai para dentro do código inserido, como em \textbf{texto selecionado}.

Alguns símbolos precisam do pacote amssymb. Acrescente esta linha ao preâmbulo de um documento que os usa:

\usepackage{amssymb}

Personalizar o painel

O código que cada botão insere fica guardado em ~/Library/TeXShop/LatexPanel/completion.plist. Abra esse arquivo no TeXShop para alterá-lo; os comentários no início dele explicam como ele é organizado. Os nomes dos botões padrão não podem ser alterados, mas o código que eles inserem pode. Nesse código:

  • #SEL# representa o texto selecionado;
  • #INS# marca para onde vai o ponto de inserção depois que o código é inserido;
  • #PASTE# representa o texto da área de transferência.

A página Personalizado tem espaço para até dezesseis botões seus. Cada um é definido na lista Customized do arquivo por duas cadeias de caracteres, o nome do botão e o código que ele insere:

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Salve o arquivo em UTF-8 e depois encerre e reabra o TeXShop para ver as alterações no painel. Se o arquivo estiver faltando ou danificado, o TeXShop o substitui pela sua própria cópia. Consulte Modificar o Painel LaTeX e Arquivos em ~/Library/TeXShop.
