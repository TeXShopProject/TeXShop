Entender as macros padrão

A melhor maneira de entender as macros padrão é examiná-las no editor de macros (Macros › Abrir editor de macros...): selecione uma macro na lista, e o seu conteúdo aparece ao lado.

Por exemplo, suponha que você queira um ambiente theorem. Digite a palavra theorem, selecione-a e escolha Macros › Insert Begin/End. A palavra é substituída por

\begin{theorem}

\end{theorem}

e o ponto de inserção é colocado na linha entre as duas.

Insert Begin/End é uma macro AppleScript (consulte Macros AppleScript). Uma macro de texto que faz o mesmo quando uma palavra está selecionada é assim:

\begin{#SEL#}
#INS#
\end{#SEL#}

Marcadores de posição nas macros de texto

O texto de uma macro de texto é inserido no código-fonte com estas substituições:

#SEL#
é substituído pelo texto que estava selecionado quando a macro foi escolhida, ou por nada se nenhum texto estava selecionado.
#INS#
marca para onde vai o ponto de inserção. Sem ele, o ponto de inserção é colocado no fim do texto inserido.
#PASTE#
é substituído pelo texto da área de transferência, ou por nada se a área de transferência não contém texto.
•
é uma marca, para a qual Editar › Marcas pode ir.

No editor de macros, esses marcadores de posição aparecem como etiquetas arredondadas; Definir novas macros explica como inseri-los. Com esse conhecimento, as macros padrão são fáceis de entender e de alterar.
