Definir macros AppleScript

O AppleScript é uma linguagem própria. O AppleScript Language Guide da Apple, no site da Apple para desenvolvedores, a descreve por completo.

Caminhos e o nome do documento

Antes de executar uma macro AppleScript, o TeXShop substitui os textos a seguir pelo caminho de um arquivo do documento ativo, entre aspas duplas:

#FILEPATH#
o arquivo de código-fonte
#TEXPATH#
o arquivo .tex
#NAMEPATH#
o arquivo de código-fonte sem a extensão
#FOLDERPATH#
a pasta que contém o código-fonte, terminando com uma barra
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
os arquivos .pdf, .dvi, .ps, .log e .aux
#INDPATH#, #BBLPATH#, #HTMLPATH#
os arquivos .ind, .bbl e .html

Por exemplo, se #FILEPATH# dá /Users/name/Projects/Fourier/Fourier.tex, #FOLDERPATH# dá /Users/name/Projects/Fourier/. Se o documento nunca foi salvo, #FILEPATH# é um texto vazio.

#DOCUMENTNAME# é substituído pelo nome do documento como o título da janela do código-fonte o mostra: com a extensão, ou sem ela se a extensão estiver oculta. Um script o usa para se dirigir ao documento que o chamou:

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

Comandos do TeXShop

Um AppleScript pode fazer o seu trabalho de duas maneiras: pode executar comandos de shell, como descrito em Scripts com comandos de shell, ou pode chamar os comandos do próprio TeXShop, como descrito em Scripts com os comandos de composição do TeXShop. Entre outros, o TeXShop entende estes comandos:

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

Os seis primeiros comandos compõem sem interrupção, sem parar nos erros. Os seis seguintes também compõem, mas param em um erro para que você possa responder no console. Um comando de composição retorna imediatamente, antes de a composição terminar. taskdone retorna NO enquanto a composição ainda está em andamento e YES quando ela termina. refreshpdf e refreshtext fazem as janelas de PDF e de texto mostrarem a versão mais recente dos seus arquivos. goto line seleciona uma linha no código-fonte:

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
