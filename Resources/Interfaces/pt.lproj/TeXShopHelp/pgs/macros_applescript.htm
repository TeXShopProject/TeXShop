Macros AppleScript

Uma macro cujo conteúdo começa com

--AppleScript

ou

--AppleScript direct

é executada como um AppleScript quando é escolhida; maiúsculas e minúsculas não importam. Por exemplo, Macros › Applescript › View pdf with Preview abre o PDF do documento ativo no Pré-Visualização, depois que o PDF tiver sido composto. O seu conteúdo é

--AppleScript direct

tell application "Preview"
  activate
  open POSIX file #PDFPATH#
end tell

Antes de o script ser executado, o TeXShop substitui #PDFPATH# pelo caminho do PDF; Definir macros AppleScript lista todos esses textos. “View pdf with Adobe Acrobat Reader DC”, no mesmo submenu, faz o mesmo com o Adobe Acrobat.

--AppleScript direct e --AppleScript

Um script que começa com --AppleScript direct é executado pelo próprio TeXShop. Enquanto ele é executado, o TeXShop não responde a mais nada; por isso, o script não pode pedir ao TeXShop algo que possa exigir a sua intervenção. Por exemplo, ele não pode pedir ao TeXShop que execute o LaTeX: se o arquivo tivesse um erro, o console ficaria esperando a sua resposta, que o TeXShop não poderia receber.

Um script que começa com --AppleScript é executado pelo ScriptRunner, um pequeno programa dentro do TeXShop. Esse script pode pedir ao TeXShop coisas que possam exigir a sua intervenção, porque o ScriptRunner espera enquanto o TeXShop continua ativo.

Assim, --AppleScript direct é adequado para macros simples, enquanto --AppleScript é necessário para scripts que compõem ou trabalham de outro modo com o TeXShop.
