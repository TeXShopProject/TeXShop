BibTeX

O BibTeX monta a bibliografia de um documento LaTeX a partir de uma base de dados de referências, um arquivo com a extensão .bib. O documento cita as entradas pelas suas chaves, e o BibTeX lista apenas as entradas citadas.

Uma base de dados mybibliography.bib contém entradas como

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

e o documento as cita e indica o estilo e a base de dados:

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

Executar o BibTeX

  1. Componha o documento. As citações aparecem como [?], e falta a bibliografia.
  2. Escolha Compor › BibTeX (⇧⌘B), ou escolha BibTeX no menu local ao lado do botão Compor e clique em Compor.
  3. Componha mais duas vezes: a primeira execução acrescenta a bibliografia, a segunda preenche as citações.

Compor com o latexmk, por exemplo com o motor pdflatexmk ou com um perfil configurado “Com latexmk”, executa o BibTeX e as passagens adicionais automaticamente.

Para criar uma nova base de dados no TeXShop, escolha o tipo bib no menu Formato do diálogo Salvar, para que o arquivo receba a extensão .bib. Uma base de dados também pode ficar na sua árvore TeX pessoal, onde todos os documentos a encontram; consulte Adicionar arquivos pessoais ao TeX Live.

Escolher o programa

Compor › BibTeX executa o comando de Ajustes › Composição › Ferramentas relacionadas › Motor BibTeX, bibtex por padrão. Digite ali outro programa com as opções de que ele precisar, por exemplo biber para documentos que usam o pacote biblatex. Os perfis do motor definem esse campo: pbibtex para pLaTeX + dvipdfmx, upbibtex para upLaTeX + dvipdfmx e LuaLaTeX (japonês), e bibtex para os outros perfis.

Para escolher o programa de um documento, coloque uma linha como esta em uma das suas vinte primeiras linhas:

% !BIB program = biber

A linha tem prioridade sobre o ajuste. A forma % !BIB TS-program = é lida da mesma maneira.
