Reorganizar o menu Macros

Abra o editor de macros (Macros › Abrir editor de macros...). A lista à esquerda mostra o menu Macros como uma estrutura de tópicos, como a visualização em lista de uma janela do Finder. Para mover um item, arraste-o para outro lugar; arraste-o para a esquerda ou para a direita para colocá-lo em outro nível, dentro ou fora de um submenu.

Para renomear um item, selecione-o e pressione Return, ou clique mais uma vez no seu nome após um instante, como no Finder. Digite o novo nome e pressione Return; Escape mantém o nome anterior.
