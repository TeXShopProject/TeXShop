Adicionar arquivos pessoais ao TeX Live

Arquivos de estilo, classes, bases de dados bibliográficas e outros arquivos que não fazem parte do TeX Live vão para a sua árvore TeX pessoal, a pasta texmf dentro da pasta Library da sua pasta pessoal: ~/Library/texmf. Todos os programas do TeX Live encontram os arquivos ali, e eles têm prioridade sobre os arquivos de mesmo nome do próprio TeX Live. Não é preciso registrar nada depois de acrescentar um arquivo; a próxima composição o encontra.

A pasta Library fica oculta no Finder. Para abri-la, escolha Ir › Ir para Pasta… no Finder e digite ~/Library. Crie ali a pasta texmf se ela ainda não existir.

Antes de acrescentar um pacote

A maioria dos pacotes do CTAN já faz parte do TeX Live, e o MacTeX instala todos eles. Para ver se o TeX já tem um arquivo, escolha Arquivo › Abrir arquivo de estilo no TeXShop e digite o nome dele, como hyperref.sty; o TeXShop abre o arquivo que o TeX usaria. Acrescente um pacote à sua árvore pessoal apenas quando o TeX Live não o tiver, ou quando você precisar de uma versão própria. Como a sua cópia tem prioridade, remova-a quando o TeX Live estiver em dia; caso contrário, você continua usando a versão antiga.

Onde os arquivos ficam

As pastas dentro de texmf seguem a mesma estrutura do TeX Live. Crie as pastas de que precisar:

PastaConteúdo
tex/latex/pacotes e classes LaTeX (.sty, .cls), cada pacote em uma pasta própria
tex/plain/arquivos para o plain TeX
tex/generic/arquivos que funcionam com qualquer formato
bibtex/bib/bases de dados bibliográficas (.bib)
bibtex/bst/estilos bibliográficos (.bst)
doc/documentação dos pacotes que você acrescentou; Ajuda › Exibir ajuda para o pacote... a encontra ali

Por exemplo, um pacote com as suas próprias macros e a sua base de dados bibliográfica ficariam guardados como

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

Então \usepackage{mymacros} e \bibliography{mybibliography} funcionam em todos os documentos, onde quer que estejam salvos.

Verificar a pasta

Para ver qual pasta o seu TeX usa como árvore pessoal, digite no Terminal

kpsewhich -var-value TEXMFHOME

Em um Mac, ela é ~/Library/texmf, a menos que a instalação tenha sido configurada de outra forma. Para ver qual cópia de um arquivo o TeX vai ler, digite por exemplo kpsewhich mymacros.sty.

Não acrescente arquivos às pastas do próprio TeX Live; consulte Mais sobre o TeX Live.
