Remover arquivos AUX

Quando o LaTeX compõe Galois.tex, ele grava arquivos auxiliares como Galois.aux, Galois.toc e Galois.log, que a execução seguinte lê para as referências cruzadas, o sumário e coisas semelhantes. Se a composição for interrompida no meio, por exemplo depois de um erro, esses arquivos podem ficar danificados, e a execução seguinte informa erros que não estão no código-fonte, muitas vezes logo antes de \begin{document}. Mover os arquivos auxiliares para o Lixo e compor de novo resolve isso.

Mover os arquivos para o Lixo

  • Arquivo › Limpar arquivos auxiliares (⌃⌘A), ou o botão “Limpar arquivos auxiliares” no console, move os arquivos auxiliares do documento para o Lixo.
  • Compor › Limpar auxiliares & Compor (⌥⌘T) faz isso e depois compõe. No menu Compor, o item aparece no lugar de Compor enquanto você mantém pressionada a tecla Option.

Os arquivos movidos para o Lixo são os que estão na pasta do código-fonte, têm o nome dele e uma destas extensões:

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

Os arquivos que o SyncTeX deixa com (busy) no fim do nome quando a composição é interrompida também vão para o Lixo. O arquivo .bbl do BibTeX é mantido.

Em um projeto cujos arquivos de capítulo indicam um arquivo principal com % !TEX root, são movidos os arquivos do arquivo principal, também quando o comando é dado em um arquivo de capítulo.

Variações

  • Mantenha pressionada a tecla Shift ao escolher “Limpar arquivos auxiliares” ou ao clicar no botão para mover também o arquivo PDF do documento para o Lixo. Normalmente o PDF antigo é mantido, para que a janela de pré-visualização tenha algo a mostrar quando a composição falha.
  • Mantenha pressionada a tecla Option ao escolher “Limpar arquivos auxiliares” ou ao clicar no botão para limpar um projeto inteiro: todo arquivo com uma das extensões acima na pasta do arquivo principal e em todas as pastas abaixo dela vai para o Lixo, qualquer que seja o seu nome. Isso também remove os arquivos .aux que \include grava para os capítulos em subpastas.

Dois ajustes ocultos alteram o comportamento. Para acrescentar extensões à lista, por exemplo dvi, digite no Terminal

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

e, para voltar à lista padrão,

defaults write TeXShop OtherTrashExtensions -array

Para que o comportamento com Option seja o comportamento padrão de “Limpar arquivos auxiliares”:

defaults write TeXShop AggressiveTrashAUX YES
