Definir o arquivo principal de um projeto

Documentos grandes costumam ser divididos em vários arquivos: um arquivo principal com o preâmbulo, que inclui um arquivo para cada capítulo. Por exemplo, um arquivo principal Main.tex poderia ser assim:

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

Quando você edita two.tex, o TeXShop deve compor Main.tex, e não o capítulo, que não tem preâmbulo. Para indicar isso, coloque esta linha em uma das vinte primeiras linhas de cada arquivo de capítulo:

% !TEX root = ../Main.tex

O próprio arquivo principal não precisa dessa linha. O nome do arquivo principal pode ser indicado

  • só pelo nome, Main.tex, quando ele está na mesma pasta que o arquivo de capítulo;
  • em relação à pasta do arquivo de capítulo, ../Main.tex ou ../../Main.tex;
  • pelo caminho completo, /Users/me/Book/Main.tex, que precisa ser alterado quando o projeto muda de lugar.

A macro Set Root File… do menu Macros insere a linha: ela pede o arquivo principal e oferece uma linha relativa ou absoluta, substituindo uma linha root anterior.

O que a linha root faz

  • Compor em um arquivo de capítulo compõe o arquivo principal, e a janela de pré-visualização do arquivo principal mostra o documento inteiro. Uma linha % !TEX program ou outras linhas mágicas para a composição devem ficar no arquivo principal.
  • Editar › Ir para o erro abre o arquivo que contém um erro, se ele não estiver aberto, e vai para a linha.
  • A sincronização a partir da janela de pré-visualização abre o arquivo de capítulo que contém o ponto clicado; consulte Sincronizar código-fonte e pré-visualização.
  • Limpar arquivos auxiliares remove os arquivos auxiliares do arquivo principal; consulte Remover arquivos AUX.
  • Janela › Código-fonte ⇔ Pré-visualização (⌘1) em um arquivo de capítulo traz para a frente a janela de pré-visualização do arquivo principal. Usá-lo de novo na janela de pré-visualização volta à janela do código-fonte de onde você veio, ou ao arquivo principal se você não veio de uma janela do código-fonte.

Abrir um arquivo de capítulo

Quando um arquivo de capítulo com uma linha root é aberto, o TeXShop também abre o arquivo principal e a sua janela de pré-visualização. Dois itens de Ajustes › Geral › Arquivo principal do projeto controlam isso: “Abrir o arquivo principal ao abrir um documento” ativa ou desativa esse comportamento, e “Minimizar a janela do arquivo principal” envia a janela do código-fonte do arquivo principal para o Dock, já que ela raramente é editada enquanto você trabalha em um capítulo.

Buscar e substituir no projeto inteiro

Para buscar em todos os arquivos de um projeto de uma só vez, escolha Editar › Buscar › Buscar nas Fontes TeX com a Mesma TEX root… em um dos seus arquivos de capítulo, ou Buscar nas Fontes TeX com Este Arquivo como TEX root… no arquivo principal. A busca abrange o arquivo principal e os arquivos .tex da sua pasta e das subpastas que o indicam em uma linha root nas suas 20 primeiras linhas. Consulte Buscar nas fontes TeX e Buscar e substituir.

Arquivos principais indicados em arquivos .texshop

Um arquivo com a extensão .texshop ao lado de um arquivo de capítulo, como two.texshop para two.tex, também pode indicar o arquivo principal, e o TeXShop ainda o lê. Nenhum comando de menu cria esses arquivos; use uma linha % !TEX root, que acompanha o código-fonte.
