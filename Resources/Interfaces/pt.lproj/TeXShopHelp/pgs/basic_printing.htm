Imprimir

Para imprimir o documento composto, escolha Arquivo › Imprimir... (⌘P) na janela de pré-visualização ou na janela do código-fonte. Em um projeto com arquivo principal, é impresso o documento principal composto.

O diálogo de impressão tem uma seção TeXShop com as mesmas opções do Pré-Visualização da Apple. Com “Girar Automaticamente”, cada página é girada para se ajustar ao papel, de modo que uma página em formato paisagem é impressa de lado em papel retrato. Com “Ajustar Para”, cada página é redimensionada para caber no papel; escolha “Ajustar Tamanho:” em vez disso para imprimir com uma porcentagem fixa. As duas opções vêm ativadas, e as escolhas da última impressão são mantidas para o documento enquanto ele está aberto. A orientação do papel segue a primeira página.

Para imprimir o texto do código-fonte, escolha Arquivo › Imprimir código-fonte.... Arquivo › Configurar Página... escolhe o tamanho do papel.
