Criar e usar formatos de TeX

Um arquivo de formato (extensão .fmt) é um retrato do TeX depois de ter lido um conjunto de macros. O próprio LaTeX é um formato: o TeX o carrega em um instante, em vez de ler os códigos-fonte do LaTeX toda vez. Você pode criar um formato próprio a partir de um preâmbulo longo, para que a composição comece mais depressa, ou usar um formato fornecido por um projeto ou por uma organização.

Um formato só funciona com o motor e com a versão do TeX Live que o criaram. Um formato criado com o pdfLaTeX do TeX Live 2026 não pode ser usado pelo XeLaTeX nem por outro ano do TeX Live; crie-o de novo depois de instalar um novo TeX Live.

Criar um formato

Coloque em um arquivo as linhas que o formato deve conter, terminando com \dump. Por exemplo, uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

No Terminal, vá para a pasta desse arquivo e digite

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Isso carrega o formato LaTeX, lê uo.tex e grava uo.fmt. Um documento composto com esse formato omite as linhas que estão no formato e começa com \begin{document}.

Usar um formato no TeXShop

  1. Mova uo.fmt para a pasta ~/Library/texmf/web2c, criando as pastas se necessário, para que o TeX o encontre a partir de qualquer pasta.
  2. No Finder, abra ~/Library/TeXShop/Engines (TeXShop › Abrir pasta ~/Library/TeXShop), duplique um motor como XeLaTeX.engine e renomeie a cópia, por exemplo Oregon.engine. O nome aparece no TeXShop e não precisa coincidir com o do formato.
  3. Abra a cópia no TeXShop e altere a última linha para que o motor fique assim: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Os documentos abertos depois disso listam Oregon no menu local ao lado do botão Compor. Para usar o formato em um documento independentemente do que estiver escolhido ali, acrescente esta linha no início do código-fonte:

% !TEX program = Oregon

Para torná-lo o padrão, escolha “Arquivo de motor” em Ajustes › Composição › Motor › “Compor documentos novos com” e Oregon no menu “Arquivo de motor”. Consulte Adicionar motores de composição.

Para um formato plain TeX, use pdftex em vez de pdflatex no motor. Para um formato a ser usado via DVI, o motor também precisa converter o arquivo DVI em PDF, por exemplo com dvipdfmx "${1:r}.dvi" em um script zsh, porque o TeXShop mostra o arquivo PDF com o nome do código-fonte.
