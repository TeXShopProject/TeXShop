Scripts com comandos de shell

Esta página usa a macro Run pdfLaTeX with Shell Escape de Claus Gerhardt, em Macros › Claus Gerhardt Macros, para mostrar como um AppleScript chama um script de shell. O script de shell em si é simples: ele acrescenta as pastas dos programas do TeX ao caminho de busca e executa o pdflatex com --shell-escape. Os seus próprios scripts provavelmente farão mais, por exemplo executar vários programas em sequência; é aí que estas técnicas se tornam úteis.

O script de shell

O script de shell é ~/Library/TeXShop/bin/pdflatexc. Ele não depende do TeXShop: se a sua pasta estiver no seu caminho de busca, digitar pdflatexc myfile.tex no Terminal o executa. Ei-lo:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

O AppleScript

A macro que chama esse script de shell é mais interessante:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Depois dos comentários, as sete primeiras linhas são uma receita de Claus Gerhardt para salvar o arquivo de código-fonte e encontrar o nome do seu documento, que é colocado em frontName. O trabalho é feito pelo script compilado setname.scpt em ~/Library/TeXShop/Scripts: essas linhas encontram o caminho ~/Library/TeXShop/Scripts/setname.scpt, carregam o script e o chamam com #NAMEPATH# e #TEXPATH#.

Muitas vezes, o mesmo pode ser feito de modo mais simples com

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

A receita tem duas vantagens. Ela funciona também quando o documento da frente não é o que deve receber os comandos seguintes, por exemplo um arquivo de log como /Users/name/Examples/myfile.log. E, se o arquivo nunca foi salvo, a receita retorna um erro, enquanto o comando save deixaria o script esperando atrás de um diálogo de salvamento.

As seis linhas seguintes definem as variáveis dirName e baseName. Se o arquivo de código-fonte for /Users/name/My Papers/Stuff/myfile.tex, dirName é '/Users/name/My Papers/Stuff', entre aspas para o shell por causa do espaço no nome de uma pasta, e baseName é myfile.tex. O nome do arquivo é posto entre aspas da mesma forma quando é passado ao script de shell, de modo que ambos podem conter espaços.

As três linhas seguintes chamam o script de shell. O resultado é o mesmo que digitar cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' no Terminal. As três últimas linhas atualizam a janela de pré-visualização.

Várias dessas linhas são complicadas, mas podem ser copiadas sem alterações para novos scripts.

Executar comandos de shell a partir do AppleScript

O AppleScript executa um comando de shell na forma

do shell script "cmd input"

Para montar um comando a partir de partes, escreva-o na forma equivalente

do shell script "cmd " & "input"

Repare no espaço depois de cmd. O “e” comercial junta dois textos:

"cmd " & "input" = "cmd input"

Um shell iniciado pelo AppleScript começa na pasta raiz. O comando

do shell script "cd " & dirName

muda para a pasta em dirName, que já está entre aspas; por isso, não são necessárias outras aspas.

Cada do shell script inicia um novo shell, de modo que um comando posterior não estaria nessa pasta. Para executar outros comandos na mesma pasta, junte-os com ponto e vírgula em um único comando, como no Terminal:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

O script acima faz isso com cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc e input2 = baseName. As linhas

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

são apenas uma forma prática de pôr essa sequência em uma única variável.
