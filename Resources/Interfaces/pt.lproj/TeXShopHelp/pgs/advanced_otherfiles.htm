Abrir outros arquivos com o TeXShop

O TeXShop abre qualquer arquivo de texto; assim, você pode ler os arquivos de log, os arquivos aux e outros arquivos do TeX que ficam ao lado dos seus documentos. Ele também abre arquivos PDF e imagens.

Arquivos tratados como código-fonte TeX

Os arquivos com as extensões a seguir, e os arquivos sem extensão, são código-fonte TeX para o TeXShop: eles aparecem com destaque de sintaxe e podem ser compostos.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

Outros arquivos de texto, como os arquivos .log, .aux, .bst, .engine ou .txt, abrem como texto simples, sem destaque de sintaxe.

Para que o TeXShop trate arquivos com outra extensão como código-fonte TeX, acrescente a extensão com um ajuste oculto no Terminal; por exemplo, para arquivos do ConTeXt com a extensão mkiv:

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

Arquivos PDF e imagens

Os arquivos PDF e as imagens com as extensões .png, .jpg, .jpeg, .tif, .tiff e .eps abrem em uma janela própria. Os arquivos DVI e PostScript (.dvi, .ps) são convertidos em PDF e mostrados.

Salvar com outra extensão

Um arquivo mantém a sua extensão quando o TeXShop o salva. Um documento novo é salvo como arquivo .tex, a menos que você escolha outro tipo no menu Formato do diálogo Salvar, como sty, bib ou mp.

O TeXShop salva um arquivo na codificação com que ele foi aberto. Ele foi feito para o TeX e arquivos relacionados; um arquivo em um formato incomum pode mudar se for salvo depois de editado no TeXShop. Consulte Codificações.
