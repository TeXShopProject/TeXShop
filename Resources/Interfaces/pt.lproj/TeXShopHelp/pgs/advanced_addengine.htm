Adicionar motores de composição

Além do plain TeX e do LaTeX, o TeXShop compõe com motores: pequenos scripts de shell com a extensão .engine na pasta ~/Library/TeXShop/Engines. Um motor pode executar um único programa ou uma cadeia de programas, por exemplo o LuaLaTeX, depois o Biber e depois o LuaLaTeX mais duas vezes. O TeXShop vem com motores como LuaLaTeX, XeLaTeX e pdflatexmk; a subpasta Inactive guarda muitos outros.

Escolher um motor

O menu local ao lado do botão Compor, na barra de ferramentas da janela do código-fonte, lista os motores. Escolha um e clique em Compor ou pressione ⌘T. A escolha vale apenas para esse documento.

Para compor os documentos novos com um motor, escolha “Arquivo de motor” em Ajustes › Composição › Motor › “Compor documentos novos com” e escolha o motor no menu “Arquivo de motor”, logo abaixo. “Editar a lista de motores…” abre a pasta Engines no Finder; o menu “Arquivo de motor” acompanha a pasta à medida que você acrescenta, remove ou renomeia arquivos. Se o arquivo de motor escolhido não estiver mais na pasta, o menu o mostra como não encontrado e os documentos são compostos com o LaTeX.

Para vincular um documento a um motor, coloque uma linha como esta em uma das suas vinte primeiras linhas:

% !TEX program = XeLaTeX

O nome é o nome do arquivo de motor sem .engine; tex e latex compõem o plain TeX e o LaTeX via DVI, e pdftex e pdflatex os compõem com PDF direto. A linha tem prioridade sobre a barra de ferramentas, sobre os ajustes e sobre “Compor com motor alternativo”. A forma % !TEX TS-program = é lida da mesma maneira. Escreva a linha exatamente como mostrado, com um espaço de cada lado do sinal de igual; a macro Program do menu Macros insere a linha para você, com uma lista de nomes de motores para escolher. Em um projeto com arquivo principal, só o arquivo principal precisa da linha.

Compor › Compor com motor alternativo (⌃⌥⌘T) compõe uma vez com o motor de Ajustes › Composição › Motor › Motor alternativo, pdflatexmk por padrão, sem alterar a barra de ferramentas. No menu Compor, o item aparece no lugar de Compor enquanto você mantém pressionadas as teclas Control e Option. Ele é adequado para documentos que normalmente são compostos em uma passagem rápida e, de vez em quando, por completo, com o latexmk.

Escrever um motor

A maneira mais fácil de criar um motor é duplicar um dos motores da pasta Engines no Finder, renomear a cópia e abri-la no TeXShop para editá-la. Um arquivo de motor precisa ter a extensão .engine e permissão de execução, que uma cópia duplicada mantém. Os documentos abertos depois disso listam o novo motor na barra de ferramentas. Este é o XeLaTeX.engine:

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

A primeira linha indica o shell ou a linguagem do script; zsh, bash, tcsh, Perl e outros funcionam, desde que o script esteja escrito nessa linguagem. O TeXShop executa o motor na pasta do arquivo de código-fonte e lhe passa três valores:

$1
O nome do arquivo de código-fonte com a extensão, sem a pasta, como main.tex. Um script que muda para outra pasta precisa guardar antes o caminho completo, por exemplo como "$PWD/$1". Em um projeto, este é o arquivo principal.
$2
O resto de uma linha % !TEX parameter = … perto do início do código-fonte (do arquivo principal), com várias opções separadas por espaços, por exemplo % !TEX parameter = -shell-escape. Sem essa linha, é um único espaço.
$3
A pasta do campo “Motores TeX” de Ajustes › Composição › Caminhos, ou a pasta de “Segundos motores TeX” quando o documento contém a linha % !TEX useAlternatePath.

Quando o motor termina, o TeXShop abre na janela de pré-visualização o arquivo PDF com o nome do código-fonte e a extensão .pdf, se houver um, e rola até o lugar mostrado antes da composição. Um script que produz outra saída pode dizer o que mostrar com as linhas a seguir, escritas em qualquer lugar do motor dentro de um comentário da sua linguagem:

LinhaEfeito
!TEX-noPreviewnenhuma janela de pré-visualização, mesmo que outras linhas abaixo estejam presentes
!TEX-pdfPreviewmostrar o arquivo PDF
!TEX-htmlPreviewmostrar na janela HTML o arquivo HTML de mesmo nome
!TEX-bothPreviewmostrar o arquivo PDF e o arquivo HTML
!TEX-noConsolenão mostrar o console

Por exemplo, um motor que executa o LuaLaTeX, o Biber e o LuaLaTeX mais duas vezes poderia ser assim, em zsh, onde ${1:r} é o nome sem a extensão:

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

A pasta Inactive

A subpasta Engines/Inactive contém motores para fluxos de trabalho especiais, muitas vezes com documentação e exemplos, por exemplo para latexmk, ConTeXt, Sage, PreTeXt, pythontex e Typst. Para usar um deles, mova-o da sua pasta para a própria pasta Engines. Quando o TeXShop é atualizado, a pasta Inactive é substituída pela versão atual, enquanto os arquivos que estão diretamente na pasta Engines nunca são tocados; assim, os motores que você editou são mantidos.

Para saber mais sobre os motores, consulte o capítulo “Engines and latexmk” em Ajuda › Manual do TeXShop (em inglês).
