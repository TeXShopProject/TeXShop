Macros AppleScript padrão

O TeXShop vem com uma coleção de macros AppleScript de Will Robertson, Claus Gerhardt e outros autores. Algumas delas executam uma série de comandos de composição em sequência. Copiando-as e alterando-as, você pode criar scripts para o seu próprio trabalho. Esta página descreve algumas delas, com os nomes que têm no menu Macros.

Column macros, Insert reference, Open quickly…

Estas macros são de Will Robertson. No submenu Column macros, New tabular e New array inserem um ambiente tabular ou array com os números de linhas e colunas que você indicar, e Add column e Delete column alteram as linhas que você selecionar. Insert reference procura comandos \label{…} no arquivo atual e permite escolher um rótulo em uma lista; ela insere o rótulo dentro de \ref{…}, um comando que você pode alterar no script. Se houver texto selecionado, só são listados os rótulos que o contêm. Open quickly… lista os arquivos .tex, .sty e .pdf da pasta do arquivo de código-fonte atual e abre os que você escolher.

Paste Spreadsheet Cells

Esta macro, de Alan Munn, cola células de uma planilha no seu código-fonte LaTeX como uma tabela. Selecione um intervalo de células no Excel ou em outro app de planilhas e copie-as. Depois, escolha Macros › Paste Spreadsheet Cells e escolha um estilo de tabela:

cells
converte o texto copiado apenas em células de tabela do LaTeX.
booktabs
toma a primeira linha como cabeçalho e coloca \toprule, \midrule e \bottomrule em um ambiente tabular.
simple
coloca um ambiente tabular simples em volta das células.
longtable
toma a primeira linha como cabeçalho, acrescenta as linhas de cabeçalho de uma longtable e coloca as células em um ambiente longtable.

A macro substitui o conteúdo da área de transferência pelo texto LaTeX. Para colar as mesmas células em outro estilo, copie-as de novo na planilha antes.

Applescript › Save Copy with Unix Line Endings, Save Copy with Windows Line Endings, Save Copy with Classic Mac Line Endings

Os arquivos de texto terminam as linhas de maneiras diferentes: o macOS e o Unix com um avanço de linha, o Windows com um retorno de carro seguido de um avanço de linha, e os arquivos muito antigos de Macintosh só com um retorno de carro. O TeXShop lê os três. Se o editor de outra pessoa não conseguir, use estas macros. Para um arquivo de código-fonte MyFile.tex, Save Copy with Unix Line Endings grava uma cópia do arquivo salvo chamada MyFile_Unix.tex com avanços de linha; Save Copy with Windows Line Endings grava MyFile_Windows.tex e Save Copy with Classic Mac Line Endings grava MyFile_Mac.tex. As macros usam o programa flip, de Craig Stuart Sapp, em ~/Library/TeXShop/bin.

Applescript › Run LaTeX, BibTeX, Then LaTeX Twice

Um documento com bibliografia precisa de várias execuções: o LaTeX grava o arquivo .aux, o BibTeX o usa para gravar os arquivos .bbl e .blg, o LaTeX é executado de novo para acrescentar a bibliografia e mais uma vez para atualizar as referências a ela. Esta macro as executa uma após a outra. Scripts com os comandos de composição do TeXShop explica como ela funciona.

Claus Gerhardt Macros

A maioria das macros deste submenu chama scripts de shell em ~/Library/TeXShop/bin, como pdflatexc, que executa o pdfLaTeX, e bibtexc, que executa o BibTeX. Cada macro cujo nome começa com Run executa os programas indicados no nome, nessa ordem, e Open PDF abre o PDF do documento. Run LaTeX, dvips and ps2pdf também precisa do Ghostscript. Elas trabalham com um arquivo salvo. Scripts com comandos de shell explica Run pdfLaTeX with Shell Escape como exemplo.

Make HTML with TeX4ht

O TeX4ht converte um documento LaTeX em uma página web: uma página HTML e arquivos de imagem. Make HTML with TeX4ht executa o htlatex no documento e abre o arquivo HTML resultante no Safari. O pacote tex4ht não precisa ser carregado no documento; o htlatex o carrega. Make HTML with TeX4ht, Remaking Images executa o htlatex com a opção -r, que gera as imagens de novo mesmo quando elas já existem.

Extract Pages from PDF…

Extract Pages from PDF… cria arquivos PDF que contêm páginas selecionadas do PDF do documento. Primeiro, ele pergunta quantos arquivos criar e, depois, as páginas de cada arquivo, como 5:8 para as páginas 5 a 8 ou 3:4,6,8:12. Se o documento se chama MyFile, os arquivos são salvos como MyFile-1.pdf, MyFile-2.pdf e assim por diante.

MetaPost

Run pdfLaTeX, MakeIndex, MetaPost, Then pdfLaTeX abre os arquivos de log no caminho. Consulte ConTeXt e MetaPost sobre o MetaPost.
