Macros AppleScript padrão

O TeXShop vem com uma coleção de macros AppleScript de Will Robertson, Claus Gerhardt e outros autores. Algumas delas executam uma série de comandos de composição em sequência. Copiando-as e alterando-as, você pode criar scripts para o seu próprio trabalho. Esta página descreve algumas delas, com os nomes que têm no menu Macros.

Column macros, Insert reference, Open quickly…

Estas macros são de Will Robertson. No submenu Column macros, New tabular e New array inserem um ambiente tabular ou array com os números de linhas e colunas que você indicar, e Add column e Delete column alteram as linhas que você selecionar. Insert reference procura comandos \label{…} no arquivo atual e permite escolher um rótulo em uma lista; ela insere o rótulo dentro de \ref{…}, um comando que você pode alterar no script. Se houver texto selecionado, só são listados os rótulos que o contêm. Open quickly… lista os arquivos .tex, .sty e .pdf da pasta do arquivo de código-fonte atual e abre os que você escolher.

Paste Spreadsheet Cells

Esta macro, de Alan Munn, cola células de uma planilha no seu código-fonte LaTeX como uma tabela. Selecione um intervalo de células no Excel ou em outro aplicativo de planilhas e copie-as. Depois, escolha Macros › Paste Spreadsheet Cells e escolha um estilo de tabela:

cells
converte o texto copiado apenas em células de tabela do LaTeX.
booktabs
toma a primeira linha como cabeçalho e coloca \toprule, \midrule e \bottomrule em um ambiente tabular.
simple
coloca um ambiente tabular simples em volta das células.
longtable
toma a primeira linha como cabeçalho, acrescenta as linhas de cabeçalho de uma longtable e coloca as células em um ambiente longtable.

A macro substitui o conteúdo da área de transferência pelo texto LaTeX. Para colar as mesmas células em outro estilo, copie-as de novo na planilha antes.

Applescript › Convert to MAC, Convert to Unix, Convert to Windows

Os arquivos de texto terminam as linhas de maneiras diferentes: o macOS e o Unix com um avanço de linha, o Windows com um retorno de carro seguido de um avanço de linha, e os arquivos muito antigos de Macintosh só com um retorno de carro. O TeXShop lê os três. Se o editor de outra pessoa não conseguir, use estas macros. Para um arquivo de código-fonte MyFile.tex, Convert to Unix grava uma cópia do arquivo salvo chamada MyFile_Unix.tex com avanços de linha; Convert to Windows grava MyFile_Windows.tex e Convert to MAC grava MyFile_Mac.tex. As macros usam o programa flip, de Craig Stuart Sapp, em ~/Library/TeXShop/bin.

Applescript › Bibliography

Um documento com bibliografia precisa de várias execuções: o LaTeX grava o arquivo .aux, o BibTeX o usa para gravar os arquivos .bbl e .blg, o LaTeX é executado de novo para acrescentar a bibliografia e mais uma vez para atualizar as referências a ela. A macro Bibliography executa LaTeX, BibTeX, LaTeX e LaTeX, um após o outro. Scripts com os comandos de composição do TeXShop explica como ela funciona.

Claus Gerhardt Macros

A maioria das macros deste submenu chama scripts de shell com o mesmo nome em ~/Library/TeXShop/bin; bibtexcpl, mpostcpl e latex-makeindex-mpost chamam vários deles em sequência, e openpdf abre o PDF do documento. Elas trabalham com um arquivo salvo. Scripts com comandos de shell explica pdflatexc como exemplo.

htlatexc, htlatexr

O TeX4ht converte um documento LaTeX em uma página web: uma página HTML e arquivos de imagem. htlatexc executa o htlatex no documento e abre o arquivo HTML resultante no Safari. O pacote tex4ht não precisa ser carregado no documento; o htlatex o carrega. htlatexr executa o htlatex com a opção -r, que gera as imagens de novo mesmo quando elas já existem.

pdfselectc

pdfselectc cria arquivos PDF que contêm páginas selecionadas do PDF do documento. Primeiro, ele pergunta quantos arquivos criar e, depois, as páginas de cada arquivo, como 5:8 para as páginas 5 a 8 ou 3:4,6,8:12. Se o documento se chama MyFile, os arquivos são salvos como MyFile-1.pdf, MyFile-2.pdf e assim por diante.

mpostc, mpostcpl, latex-makeindex-mpost

mpostc executa o MetaPost e depois o pdfLaTeX; mpostcpl executa o pdfLaTeX, o MetaPost e de novo o pdfLaTeX. latex-makeindex-mpost executa o pdfLaTeX, o MakeIndex, o MetaPost e de novo o pdfLaTeX, abrindo os arquivos de log no caminho. Consulte ConTeXt e MetaPost sobre o MetaPost.
