Scripts com os comandos de composição do TeXShop

Um documento com bibliografia precisa de uma sequência de composições: o LaTeX grava o arquivo .aux, o BibTeX o usa para gravar os arquivos .bbl e .blg, o LaTeX é executado de novo para acrescentar a bibliografia ao documento e mais uma vez para atualizar as referências a ela. Os seus projetos podem precisar de sequências semelhantes, e uma macro AppleScript pode executá-las para você.

A macro Macros › Applescript › Run LaTeX, BibTeX, Then LaTeX Twice, que vem com o TeXShop, mostra como. Este é o seu conteúdo:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

A primeira linha faz desta uma macro AppleScript executada pelo ScriptRunner, para que ela possa pedir ao TeXShop que componha (consulte Macros AppleScript). As linhas seguintes verificam #FILEPATH#, o caminho completo do arquivo de código-fonte. Ele é um texto vazio quando o documento ainda não foi salvo; nesse caso, o script pede que você o salve e para.

Em seguida, o script se refere ao documento por #DOCUMENTNAME#. O próprio TeXShop salva o documento quando um comando de composição começa; por isso, o script não precisa salvá-lo.

Os comandos restantes executam latexinteractive, bibtex, latex e latex. Um comando de composição retorna ao script imediatamente, antes de a composição terminar; por isso, depois de cada comando, um laço repeat espera até que taskdone informe que o trabalho terminou. A linha delay 2 faz o script pausar entre as verificações, em vez de perguntar sem parar e deixar o computador lento. Os comandos estão listados em Definir macros AppleScript.
