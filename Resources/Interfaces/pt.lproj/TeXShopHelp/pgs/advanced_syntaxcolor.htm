Destaque de sintaxe

A janela do código-fonte mostra o TeX em cores: os comentários, os comandos, as notas de rodapé, os marcadores $ e & e os parênteses ( ), { } e [ ] têm cada um a sua cor. Fonte › Destaque de sintaxe ativa ou desativa o destaque para o documento ativo. Os documentos abrem com ele ativado; para abri-los com ele desativado, use o ajuste oculto

defaults write TeXShop SyntaxColoringEnabled NO

O que é destacado

  • Os comandos são uma barra invertida seguida de letras. Ajustes › Editor › Destaque de sintaxe › “@ faz parte dos comandos” conta também @ como letra, como nos comandos internos dos pacotes.
  • O texto de \footnote, \footcite e \autocite, e dos comandos que começam com \cite ou \Cite, como \citep e \citeauthor, aparece na cor “Nota de rodapé”. O ajuste oculto defaults write TeXShop SyntaxColorFootnote NO colore apenas o comando.
  • Fonte › Destacar as entradas do índice mostra os argumentos de \index e \esindex na cor Índice. Ajustes › Editor › Destaque de sintaxe › “Destacar as entradas do índice por padrão” o ativa quando os documentos são abertos.
  • Fonte › Destacar o código expl3 colore também as funções, as variáveis e as outras partes do código expl3, a camada de programação do LaTeX, para quem escreve pacotes. “Destacar o código expl3 por padrão”, no mesmo grupo, o ativa quando os documentos são abertos.
  • “Destacar letras e símbolos de largura total”, no mesmo grupo, mostra nas cores “Largura total” as letras, os dígitos e os símbolos de largura total, que facilmente se confundem com caracteres ASCII em texto japonês.

“Destacar as entradas do índice” e “Destacar o código expl3” se aplicam ao documento ativo; cada janela do código-fonte tem a sua própria escolha. Os arquivos que não são código-fonte TeX, como os arquivos de log, não são destacados; consulte Abrir outros arquivos com o TeXShop para ver a lista de extensões e como acrescentar uma.

Alterar as cores

As cores pertencem ao tema. Escolha-as em Ajustes › Temas:

  • o grupo “Destaque de sintaxe” tem Comentário, Comando, Nota de rodapé, Marcador e Índice;
  • o grupo Parênteses tem as cores de ( ), { } e [ ];
  • o grupo expl3 tem function, __function, key, variable, __variable, argument e msg;
  • o grupo Destaques tem, entre outras, as cores “Largura total”;
  • o grupo “Sintaxe XML” tem as cores para os arquivos HTML e XML.

Cada tema tem as suas próprias cores; assim, o “Tema modo claro” e o “Tema modo escuro” podem ser diferentes.
