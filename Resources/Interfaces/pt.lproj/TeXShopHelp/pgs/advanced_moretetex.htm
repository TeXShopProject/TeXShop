Mais sobre o TeX Live

Onde o TeX Live é instalado

O MacTeX instala o TeX Live em /usr/local/texlive/2026, e o BasicTeX em /usr/local/texlive/2026basic. O TeX Live é lançado uma vez por ano, e cada ano é instalado em uma pasta própria, como 2027, de modo que vários anos podem ficar lado a lado no Mac. Para remover um deles, arraste a sua pasta para o Lixo.

A pasta /usr/local fica oculta no Finder. Para ver o que há dentro dela, escolha Ir › Ir para Pasta… no Finder e digite o caminho.

Como o TeXShop encontra o TeX

O TeXShop executa o TeX a partir da pasta indicada no campo “Motores TeX” de Ajustes › Composição › Caminhos. O padrão é /Library/TeX/texbin, um link que os instaladores do MacTeX e do BasicTeX apontam para os programas do TeX Live recém-instalado. Quando um novo ano do TeX Live é instalado, o link passa a apontar para ele, e o TeXShop usa o novo TeX sem nenhuma alteração nos ajustes.

Para usar outra instalação, digite a pasta dos seus programas em “Motores TeX”, por exemplo /usr/local/texlive/2026/bin/universal-darwin, ou clique em “Detectar caminhos…” para escolher entre as instalações que o TeXShop encontrar; consulte Convivência com outras distribuições de TeX.

Deixe o TeX Live como está

As pastas do TeX Live pertencem ao sistema, e uma atualização ou um novo ano do TeX Live as substitui. Não acrescente nem altere arquivos nelas. Em vez disso, coloque os seus próprios arquivos de estilo, classes e bibliografias na sua árvore pessoal, onde o TeX os encontra primeiro e onde as atualizações não mexem; consulte Adicionar arquivos pessoais ao TeX Live.

Documentação

O TeX Live contém documentação para quase todos os pacotes. Ajuda › Exibir ajuda para o pacote... abre a documentação de um pacote pelo seu nome, por exemplo hyperref ou tikz. Ajuda › Documentação do TeX Live indica onde encontrar on-line o guia do TeX Live e outras documentações.
