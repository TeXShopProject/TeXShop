Usar um editor externo

Você pode escrever em outro editor e usar o TeXShop para compor e mostrar o PDF.

Abrir só a pré-visualização

Arquivo › Abrir só para ver... pede um arquivo de código-fonte e abre apenas a sua janela de pré-visualização. Se o arquivo ainda não tiver sido composto, ou se o PDF for mais antigo que o código-fonte, o TeXShop o compõe primeiro. Edite o código-fonte no seu editor; para compor, salve-o lá e clique em Compor na janela de pré-visualização ou pressione ⌘T. Nesse modo, o TeXShop nunca abre nem altera o arquivo de código-fonte. Se a barra de ferramentas da janela de pré-visualização não tiver um botão Compor, use Janela › Personalizar barra de ferramentas... para acrescentar um.

Se você sempre trabalha assim, ative Ajustes › Geral › Ao iniciar › “Usar editor externo”. Arquivo › Abrir... e Abrir recente passam então a abrir os arquivos de código-fonte só para pré-visualização, e Arquivo › Abrir só para ver... se torna Abrir para editar..., que abre um arquivo de código-fonte no editor do próprio TeXShop quando você precisar. Os outros arquivos, como os arquivos PDF, de imagem e de log, abrem como antes.

Manter a pré-visualização atualizada

Quando o PDF é reescrito por outro programa, por exemplo pelo seu editor ou pelo latexmk no Terminal, o TeXShop o recarrega quando você volta ao TeXShop ou à janela de pré-visualização, mantendo a página e a ampliação. Com Ajustes › Pré-visualização › Atualização › “Sempre monitorar alterações no PDF feitas por outros apps” ativado, ele recarrega o PDF assim que este muda, mesmo com o TeXShop em segundo plano, por exemplo quando a pré-visualização está ao lado do seu editor. Uma pré-visualização com anotações que não foram salvas não é recarregada, para que as anotações não se percam.

O TeXShop também monitora os arquivos de código-fonte abertos no seu próprio editor. Quando outro editor altera um desses arquivos, o TeXShop o recarrega, a menos que a cópia no TeXShop tenha alterações não salvas.

Sincronizar com o editor

Clicar com Command na janela de pré-visualização pode levar você à linha no seu editor, e o botão “Vá para o erro” do console pode abrir ali a linha de um erro. Isso requer “Usar editor externo”, um ajuste oculto e um programa de linha de comando do editor:

  • Para o TextMate, cujo comando mate está em /usr/local/bin: defaults write TeXShop TextMateSync YES.
  • Para qualquer outro editor: defaults write TeXShop OtherEditorSync YES e um script executável /usr/local/bin/othereditor que recebe o número da linha como $1 e o caminho completo do arquivo como $2. Para o BBEdit, ele é assim: 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

Para o sentido inverso, de uma linha no editor para a janela de pré-visualização, o editor chama o TeXShop por AppleScript com os comandos sync_preview_line, sync_preview_index e sync_preview_name. O capítulo “Using an External Editor” de Ajuda › Manual do TeXShop (em inglês) traz um script completo.

A pasta ~/Library/TeXShop/ExternalEditorScripts contém suporte pronto com documentação: AppleScripts que compõem e pré-visualizam no TeXShop um documento do BBEdit e um plug-in para o Vim.

Comandos AppleScript para editores

Um editor pode chamar estes comandos AppleScript de um documento do TeXShop:

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Compõem ou executam o plain TeX, o LaTeX, o BibTeX, o MakeIndex ou o MetaPost. A chamada retorna imediatamente, sem esperar o fim da composição; a pré-visualização é atualizada quando ela termina.
taskdone
Retorna NO enquanto a composição está em andamento e YES quando ela termina.
refreshpdf
Recarrega o PDF e traz a janela de pré-visualização para a frente.
refreshpdfbackground
Recarrega o PDF sem trazer o TeXShop para a frente, quando a janela de pré-visualização já está aberta.
refreshtext
Lê de novo do disco o arquivo de código-fonte.
open_for_externaleditor
Abre um arquivo de código-fonte como Arquivo › Abrir só para ver... o faz.

Quando o editor compõe por meio do TeXShop, “Sempre monitorar alterações no PDF feitas por outros apps” não é necessário. Consulte também Scripts com os comandos de composição do TeXShop.
