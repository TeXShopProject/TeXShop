Modo alternativo de composição

O TeXShop normalmente compõe com o método PDF direto: o pdfLaTeX ou o pdfTeX grava diretamente o arquivo PDF. O método alternativo, Via DVI, executa o LaTeX ou o TeX para gerar um arquivo DVI, converte-o em PostScript com o dvips e converte o PostScript em PDF com o Ghostscript. O script simpdftex do TeX Live realiza essas etapas.

O Via DVI é necessário para documentos que inserem código PostScript na saída, por exemplo com o pacote pstricks. As imagens EPS não precisam dele: o TeX Live as converte em PDF ao compor com PDF direto.

Escolher o método

Compor › Via DVI e Compor › PDF direto mudam o método do documento ativo; os outros documentos abertos mantêm o seu. Ajustes › Composição › “Método de composição” define o método com que os documentos começam. Sua terceira opção, “Script pessoal”, executa em vez disso os comandos do grupo Script pessoal. Os comandos do Via DVI, um para plain TeX e outro para LaTeX, estão no grupo Via DVI de Ajustes › Composição. O perfil do motor LaTeX + dvips + Ghostscript, em “Outro” no menu “Perfil do motor”, prepara a composição Via DVI.

Escolher o método no documento

Uma linha entre as 20 primeiras linhas do código-fonte define o programa e o método desse documento, quaisquer que sejam os ajustes:

LinhaCompõe com
% !TEX program = pdflatexLaTeX, PDF direto
% !TEX program = latexLaTeX, Via DVI
% !TEX program = pdftexplain TeX, PDF direto
% !TEX program = texplain TeX, Via DVI
% !TEX program = personallatexLaTeX, Script pessoal
% !TEX program = personaltexplain TeX, Script pessoal

Opções do Via DVI

Por padrão, o Ghostscript ignora a transparência do PostScript. Para mantê-la, acrescente --distilleropts "-dALLOWPSTRANSPARENCY" ao final do comando no grupo Via DVI. Para manter o arquivo PostScript intermediário, acrescente --keep-psfile. O Ghostscript é executado a partir da pasta indicada em Ajustes › Composição › Caminhos › Ghostscript.
