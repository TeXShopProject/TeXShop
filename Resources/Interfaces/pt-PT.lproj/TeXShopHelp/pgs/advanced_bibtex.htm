BibTeX

O BibTeX constrói a bibliografia de um documento LaTeX a partir de uma base de dados de referências, um ficheiro com a extensão .bib. O documento cita as entradas pelas suas chaves, e o BibTeX enumera apenas as entradas citadas.

Uma base de dados mybibliography.bib contém entradas como

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

e o documento cita-as e indica o estilo e a base de dados:

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

Executar o BibTeX

  1. Componha o documento. As citações aparecem como [?] e a bibliografia está em falta.
  2. Escolha Compor › BibTeX (⇧⌘B), ou escolha BibTeX no menu pop-up ao lado do botão «Compor» e prima «Compor».
  3. Componha mais duas vezes: a primeira execução adiciona a bibliografia, a segunda preenche as citações.

A composição com o latexmk, por exemplo com o motor pdflatexmk ou com um perfil configurado «Com latexmk», executa por si o BibTeX e as passagens adicionais.

Para criar uma nova base de dados no TeXShop, escolha o tipo bib no menu «Formato do ficheiro» da caixa de diálogo Guardar, para que o ficheiro receba a extensão .bib. Uma base de dados também pode ficar na sua árvore TeX pessoal, onde todos os documentos a encontram; consulte Adicionar ficheiros pessoais ao TeX Live.

Escolher o programa

Compor › BibTeX executa o comando indicado em Definições › Composição › «Ferramentas relacionadas» › «Motor BibTeX», por predefinição bibtex. Introduza aí outro programa com as opções de que precise, por exemplo biber para documentos que usam o pacote biblatex. Os perfis do motor definem este campo: pbibtex para pLaTeX + dvipdfmx, upbibtex para upLaTeX + dvipdfmx e LuaLaTeX (japonês), e bibtex para os outros perfis.

Para escolher o programa para um documento, coloque uma linha como esta numa das suas primeiras vinte linhas:

% !BIB program = biber

A linha tem prioridade sobre a definição. A forma % !BIB TS-program = é lida da mesma maneira.
