Verificar a ortografia

O TeXShop verifica a ortografia com o corretor ortográfico e os dicionários do macOS. A verificação ortográfica adaptada ao LaTeX está ativada desde o início: verifica o texto e ignora os comandos do TeX, a matemática, os comentários e os argumentos de comandos como \label, \ref, \cite e \usepackage, bem como os argumentos que não são texto corrido, como chaves, cores e unidades, dos pacotes mais comuns. Os comandos que o documento define com \newcommand, \def e semelhantes são lidos, pelo que um argumento que uma definição passa a \ref ou para a matemática também é ignorado. O texto assinalado como sendo de outro idioma, por exemplo com \foreignlanguage, é verificado nesse idioma, mas não é sublinhado enquanto escreve.

Verificar um documento

As palavras com erros são sublinhadas enquanto escreve, desde que Edição › Ortografia e gramática › Corrigir ortografia ao escrever esteja ativado. Para percorrer o documento palavra a palavra, escolha Edição › Ortografia e gramática › Mostrar ortografia e gramática (⌘:): o painel mostra a primeira palavra com erro a seguir ao ponto de inserção. Clique em «Procurar seguinte» no painel, ou escolha «Corrigir documento agora» (⌘;), para ir para a seguinte. Mantenha premida a tecla Opção ao fazê-lo para usar a procura do macOS, que não ignora nenhuma marcação.

Para substituir uma palavra em todo o lado, escreva a substituição no campo «Substituição para Alterar tudo» do painel, ou selecione uma sugestão, e clique em «Alterar tudo»; um «Desfazer» anula a alteração. Depois de editar o documento ou de selecionar outro texto, clique novamente em «Procurar seguinte» antes de alterar uma palavra. Se tiver editado o campo «Substituição para Alterar tudo» e quiser uma sugestão que estava selecionada, selecione primeiro outra sugestão e depois essa; quando só há uma sugestão, escreva-a. «Esquecer palavras aprendidas…», no submenu «Ortografia e gramática», enumera as palavras do documento que foram aprendidas para o idioma atual e remove do dicionário as que selecionar. «Corrigir ortografia automaticamente», no mesmo submenu, altera as palavras enquanto escreve; está desativado de início, o que convém ao TeX, onde também alteraria comandos.

Definições › Ortografia

No grupo «Ortografia», «Verificar a ortografia ao escrever» define se as palavras com erros são sublinhadas num documento quando este é aberto, «Corrigir a ortografia» define se «Corrigir ortografia automaticamente» está ativado num documento quando este é aberto, e «Dicionário» é descrito mais abaixo. O grupo «Método» escolhe como o código-fonte TeX é verificado:

«Usar verificação adaptada ao LaTeX (recomendado)»
O método descrito acima. «Editar exclusões de LaTeX…», no fim da respetiva linha, abre as regras que indicam o que é ignorado.
«Método anterior»
O macOS verifica tudo, exceto o que as três opções por baixo deixam de fora: «Ignorar comandos LaTeX», «Ignorar os parâmetros selecionados», que ignora os parâmetros de alguns comandos com palavras especiais, como \usepackage, e «Ignorar comentários». Estas opções só funcionam enquanto o destaque de sintaxe está ativado, e «Corrigir documento agora» não as respeita.

O método adaptado ao LaTeX verifica os documentos que ainda não foram guardados e os ficheiros com as extensões tex, ltx, latex, dtx, ins, sty, cls, clo, bbx, cbx e lbx. Os outros ficheiros, como os ficheiros Sweave, são sempre verificados com o método anterior.

Regras de exclusão

As regras da verificação ortográfica adaptada ao LaTeX estão no ficheiro ~/Library/TeXShop/SpellCheck/SpellingExclusions.txt. Abra-o com «Editar exclusões de LaTeX…» nas Definições ou com Edição › Ortografia e gramática › Editar exclusões de ortografia…; o ficheiro abre-se no TeXShop, e o seu início explica o formato. Por exemplo, estas linhas ignoram o primeiro argumento de um comando \mycommand e o conteúdo do ambiente proof:

skip-args  1  mycommand
skip-body  proof

As alterações produzem efeito na verificação ortográfica seguinte. Se o ficheiro for apagado, o TeXShop cria uma nova cópia do ficheiro predefinido no arranque seguinte. Para não ignorar nada, deixe nele apenas linhas de comentário.

Dicionários

«Dicionário», em Definições › Ortografia, escolhe o dicionário dos documentos. Uma nova escolha aplica-se também aos documentos abertos, exceto àqueles cujo dicionário foi escolhido com uma linha % !TEX spellcheck ou no painel «Ortografia e gramática». O menu mostra cada idioma com o seu próprio nome, como Deutsch ou Français, e o respetivo código, como de ou fr_CA, como dica. «Deteção automática do idioma» deixa o macOS escolher o idioma a partir do texto.

Para usar outro dicionário num documento, escolha-o no menu pop-up na parte inferior do painel «Ortografia e gramática» enquanto esse documento está à frente. Cada documento aberto mantém o seu próprio dicionário, e o painel muda quando muda de documento. A escolha não é mantida quando o documento é fechado.

Para dar a um documento o seu dicionário sempre que é aberto, coloque uma linha como esta entre as suas 20 primeiras linhas:

% !TEX spellcheck = de-DE

O valor é um código de idioma, como nas dicas do menu «Dicionário»: fr para francês, ou fr_CA para o francês do Canadá; também pode ser escrito com hífen, como fr-CA. A linha é lida quando o documento é aberto, por isso, depois de a acrescentar, guarde, feche e volte a abrir o documento. Num documento com ficheiros de capítulo, coloque a linha em cada ficheiro.

Consulte Pesquisar definições para encontrar definições na janela Definições.
