Adicionar motores de composição

Além do plain TeX e do LaTeX, o TeXShop compõe com motores: pequenos scripts da shell com a extensão .engine na pasta ~/Library/TeXShop/Engines. Um motor pode executar um único programa ou uma cadeia de programas, por exemplo o LuaLaTeX, depois o Biber e depois mais duas vezes o LuaLaTeX. O TeXShop inclui motores como LuaLaTeX, XeLaTeX e pdflatexmk; a subpasta Inactive contém muitos mais.

Escolher um motor

O menu pop-up ao lado do botão «Compor» na barra de ferramentas da janela do código-fonte enumera os motores. Escolha um e prima «Compor» ou ⌘T. A escolha aplica-se apenas a esse documento.

Para compor os novos documentos com um motor, escolha «Ficheiro de motor» em Definições › Composição › Motor › «Compor documentos novos com» e escolha o motor no menu «Ficheiro de motor» por baixo. «Editar a lista de motores…» abre a pasta Engines no Finder; o menu «Ficheiro de motor» acompanha a pasta à medida que adiciona, remove ou muda o nome de ficheiros. Se o ficheiro de motor escolhido já não estiver na pasta, o menu indica que não foi encontrado e os documentos são compostos com LaTeX.

Para associar um documento a um motor, coloque uma linha como esta numa das suas primeiras vinte linhas:

% !TEX program = XeLaTeX

O nome é o nome do ficheiro de motor sem .engine; tex e latex compõem plain TeX e LaTeX via DVI, e pdftex e pdflatex compõem-nos em PDF direto. A linha tem prioridade sobre a barra de ferramentas, sobre as definições e sobre «Compor com motor alternativo». A forma % !TEX TS-program = é lida da mesma maneira. Escreva a linha exatamente como mostrado, com um espaço de cada lado do sinal de igual; a macro Program do menu Macros insere a linha por si, com uma lista de nomes de motores à escolha. Num projeto com um ficheiro principal, só o ficheiro principal precisa da linha.

Compor › Compor com motor alternativo (⌃⌥⌘T) compõe uma vez com o motor indicado em Definições › Composição › Motor › «Motor alternativo», por predefinição pdflatexmk, sem alterar a barra de ferramentas. No menu Compor, o item aparece em vez de Compor enquanto mantém premidas as teclas Controlo e Opção. É adequado para documentos que normalmente são compostos numa passagem rápida e ocasionalmente por completo, com o latexmk.

Escrever um motor

A forma mais fácil de criar um motor é duplicar um da pasta Engines no Finder, mudar o nome da cópia e abri-la no TeXShop para a editar. Um ficheiro de motor tem de ter a extensão .engine e permissão de execução, que uma cópia duplicada mantém. Os documentos abertos depois disso mostram o novo motor na barra de ferramentas. Eis o XeLaTeX.engine:

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

A primeira linha indica a shell ou a linguagem do script; zsh, bash, tcsh, Perl e outras funcionam, desde que o script esteja escrito nessa linguagem. O TeXShop executa o motor na pasta do ficheiro de código-fonte e passa-lhe três valores:

$1
O nome do ficheiro de código-fonte com a extensão, sem a pasta, como main.tex. Um script que mude para outra pasta tem de guardar primeiro o caminho completo, por exemplo como "$PWD/$1". Num projeto, é o ficheiro principal.
$2
O resto de uma linha % !TEX parameter = … perto do início do código-fonte (do ficheiro principal), com várias opções separadas por espaços, por exemplo % !TEX parameter = -shell-escape. Sem essa linha, é um único espaço.
$3
A pasta indicada no campo «Motores TeX» de Definições › Composição › Caminhos, ou a pasta indicada em «Segundos motores TeX» quando o documento contém a linha % !TEX useAlternatePath.

Quando o motor termina, o TeXShop abre na janela de pré-visualização o ficheiro PDF com o nome do código-fonte e a extensão .pdf, se existir, e desloca-se para o local mostrado antes da composição. Um script que produza outro resultado pode indicar o que mostrar com as linhas seguintes, escritas em qualquer parte do motor dentro de um comentário da sua linguagem:

LinhaEfeito
!TEX-noPreviewnenhuma janela de pré-visualização, mesmo que estejam presentes outras linhas abaixo
!TEX-pdfPreviewmostrar o ficheiro PDF
!TEX-htmlPreviewmostrar o ficheiro HTML com o mesmo nome na janela HTML
!TEX-bothPreviewmostrar o ficheiro PDF e o ficheiro HTML
!TEX-noConsolenão mostrar a consola

Por exemplo, um motor que execute o LuaLaTeX, o Biber e mais duas vezes o LuaLaTeX poderia ser assim, em zsh, onde ${1:r} é o nome sem a extensão:

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

A pasta Inactive

A subpasta Engines/Inactive contém motores para fluxos de trabalho especiais, muitas vezes com documentação e exemplos, por exemplo para latexmk, ConTeXt, Sage, PreTeXt, pythontex e Typst. Para usar um, mova-o da respetiva pasta para a própria pasta Engines. Quando o TeXShop é atualizado, a pasta Inactive é substituída pela versão atual, enquanto os ficheiros que estão diretamente na pasta Engines nunca são alterados, pelo que os motores que editou são mantidos.

Para saber mais sobre os motores, consulte o capítulo «Engines and latexmk» em Ajuda › Manual do TeXShop (em inglês).
