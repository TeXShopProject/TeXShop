Imprimir

Para imprimir o documento composto, escolha Ficheiro › Imprimir... (⌘P) na janela de pré-visualização ou na janela do código-fonte. Num projeto com um ficheiro principal, é impresso o documento principal composto.

O diálogo de impressão tem uma secção TeXShop com as mesmas opções que a Pré-visualização da Apple. Com «Rodar automaticamente», cada página é rodada para se adequar ao papel, pelo que uma página em formato horizontal é impressa de lado em papel vertical. Com «Ajustar escala», cada página é redimensionada para caber no papel; escolha antes «Escala» para imprimir com uma percentagem fixa. Ambas estão ativadas de início, e as escolhas da última impressão são mantidas para o documento enquanto está aberto. A orientação do papel segue a primeira página.

Para imprimir o texto do código-fonte, escolha Ficheiro › Imprimir o código.... Ficheiro › Configurar página... escolhe o tamanho do papel.
