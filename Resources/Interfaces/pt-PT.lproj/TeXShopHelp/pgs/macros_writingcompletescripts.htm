Escrever scripts com os comandos de composição do TeXShop

Um documento com bibliografia precisa de uma sequência de execuções de composição: o LaTeX escreve o ficheiro .aux, o BibTeX usa-o para escrever os ficheiros .bbl e .blg, o LaTeX é executado de novo para adicionar a bibliografia ao documento e mais uma vez para atualizar as referências a ela. Os seus projetos podem precisar de sequências semelhantes, e uma macro AppleScript pode executá-las por si.

A macro Macros › Applescript › Bibliography, fornecida com o TeXShop, mostra como. Este é o seu conteúdo:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

A primeira linha faz desta uma macro AppleScript executada pelo ScriptRunner, pelo que pode pedir ao TeXShop que componha (consulte Macros AppleScript). As linhas seguintes verificam #FILEPATH#, o caminho completo do ficheiro de código-fonte. É uma cadeia vazia quando o documento ainda não foi guardado; nesse caso, o script pede-lhe que o guarde e termina.

Em seguida, o script refere-se ao documento através de #DOCUMENTNAME#. O próprio TeXShop guarda o documento quando um comando de composição começa, pelo que o script não precisa de o guardar.

Os restantes comandos executam latexinteractive, bibtex, latex e latex. Um comando de composição regressa de imediato ao script, antes de a composição terminar, por isso, depois de cada comando, um ciclo repeat espera até que taskdone indique que o trabalho está concluído. A linha delay 2 faz o script pausar entre as verificações, em vez de perguntar continuamente e tornar o computador mais lento. Os comandos estão enumerados em Definir macros AppleScript.
