Modo de composição alternativo

Normalmente, o TeXShop compõe com o método «PDF direto»: o pdfLaTeX ou o pdfTeX escreve diretamente o ficheiro PDF. O método alternativo, «Via DVI», executa o LaTeX ou o TeX para criar um ficheiro DVI, converte-o em PostScript com o dvips e converte o PostScript em PDF com o Ghostscript. O script simpdftex do TeX Live executa estes passos.

«Via DVI» é necessário para documentos que colocam código PostScript no resultado, por exemplo com o pacote pstricks. As imagens EPS não precisam dele: o TeX Live converte-as em PDF durante a composição com «PDF direto».

Escolher o método

Compor › Via DVI e Compor › PDF direto mudam o método do documento ativo; os outros documentos abertos mantêm o seu. Definições › Composição › «Método de composição» define o método com que os documentos começam. A terceira opção, «Script pessoal», executa em vez disso os comandos do grupo «Script pessoal». Os comandos de «Via DVI», um para o plain TeX e outro para o LaTeX, estão no grupo «Via DVI» de Definições › Composição. O perfil do motor LaTeX + dvips + Ghostscript, em «Outro» no menu «Perfil do motor», prepara a composição «Via DVI».

Escolher o método no documento

Uma linha entre as 20 primeiras linhas do código-fonte define o programa e o método desse documento, independentemente das definições:

LinhaCompõe com
% !TEX program = pdflatexLaTeX, PDF direto
% !TEX program = latexLaTeX, Via DVI
% !TEX program = pdftexplain TeX, PDF direto
% !TEX program = texplain TeX, Via DVI
% !TEX program = personallatexLaTeX, Script pessoal
% !TEX program = personaltexplain TeX, Script pessoal

Opções de Via DVI

Por predefinição, o Ghostscript ignora a transparência do PostScript. Para a manter, acrescente --distilleropts "-dALLOWPSTRANSPARENCY" no fim do comando do grupo «Via DVI». Para manter o ficheiro PostScript intermédio, acrescente --keep-psfile. O Ghostscript é executado a partir da pasta indicada em Definições › Composição › Caminhos › Ghostscript.
