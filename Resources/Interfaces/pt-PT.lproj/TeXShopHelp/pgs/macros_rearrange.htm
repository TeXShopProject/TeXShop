Reorganizar o menu Macros

Abra o editor de macros (Macros › Abrir editor de macros…). A lista à esquerda mostra o menu Macros como uma estrutura hierárquica, à semelhança da vista de lista de uma janela do Finder. Para mover um item, arraste-o para outro local; arraste-o para a esquerda ou para a direita para o colocar noutro nível, dentro ou fora de um submenu.

Para mudar o nome de um item, selecione-o e prima Return, ou clique de novo no nome passado um momento, como no Finder. Escreva o novo nome e prima Return; Escape mantém o nome anterior.
