Painel Matrix

Janela › Painel Matrix... abre um painel que escreve matrizes e tabelas por si. Preencha as entradas na sua tabela, escolha o aspeto do resultado e insira-o no código-fonte, no ponto de inserção.

Criar uma matriz ou uma tabela

  1. Introduza o tamanho em «Linhas» e «Colunas», até 999 cada.
  2. Em «Ambiente», escolha matrix para uma matriz numa fórmula (um ambiente array) ou tabular para uma tabela de texto. Com tabular, «Dentro de um ambiente table» coloca a tabela num flutuante table com legenda e rótulo.
  3. Para uma matriz, escolha os delimitadores esquerdo e direito. O ponto deixa esse lado sem delimitador, e o último botão usa o delimitador escrito no campo ao lado.
  4. Os dois botões com imagens de uma matriz acrescentam uma moldura à volta das entradas e linhas entre elas.
  5. Preencha as entradas. «Limpar tudo» esvazia-as todas; «Matriz identidade» e «Matriz nula» preenchem-nas com uma matriz identidade ou com zeros.
  6. Clique em «Inserir» ou prima ⌘Return.

Trabalhar na tabela

A tabela funciona como uma folha de cálculo. Clique numa célula para a escolher, arraste ou clique com Shift premido para escolher várias, e escreva para substituir o valor; faça duplo clique, prima F2 ou prima Controlo + U para o editar. Return desce, Tab avança para a direita e as teclas de seta movem-se em qualquer direção; Delete esvazia as células escolhidas. «Copiar» e «Colar» trocam células com aplicações de folha de cálculo. Arraste o número de uma linha para mover a linha. «Desfazer» e «Refazer» atuam sobre a tabela enquanto o painel está ativo.

Quando a matriz é reduzida, as células fora dela mantêm os seus valores, mostrados a cinzento, e voltam quando a matriz é de novo aumentada. Aumente o painel para ver mais da tabela.

Personalizar o código inserido

O código que o painel escreve à volta das entradas é guardado em ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist: o início e o fim dos ambientes, os delimitadores, os separadores entre entradas e entre linhas, as linhas de uma moldura ou grelha, e a letra c que define o alinhamento de cada coluna. Por exemplo, mude c para r para alinhar as colunas à direita. Mantenha o número e a ordem dos textos no ficheiro e reinicie o TeXShop depois de o alterar. Consulte Ficheiros em ~/Library/TeXShop.
