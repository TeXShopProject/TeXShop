Remover ficheiros AUX

Quando o LaTeX compõe Galois.tex, escreve ficheiros auxiliares como Galois.aux, Galois.toc e Galois.log, que a execução seguinte lê para as referências cruzadas, o índice geral e outros elementos semelhantes. Se a composição for interrompida a meio, por exemplo depois de um erro, estes ficheiros podem ficar danificados, e a execução seguinte comunica erros que não estão no código-fonte, muitas vezes logo antes de \begin{document}. Mover os ficheiros auxiliares para o Lixo e compor de novo resolve o problema.

Mover os ficheiros para o Lixo

  • Ficheiro › Apagar ficheiros auxiliares (⌃⌘A), ou o botão «Apagar ficheiros aux.» da consola, move para o Lixo os ficheiros auxiliares do documento.
  • Compor › Apagar aux. e compor (⌥⌘T) faz isto e depois compõe. No menu Compor, o item aparece em vez de Compor enquanto mantém premida a tecla Opção.

Os ficheiros movidos para o Lixo são os que estão na pasta do código-fonte, têm o seu nome e uma destas extensões:

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

Os ficheiros que o SyncTeX deixa com (busy) no fim do nome quando a composição é interrompida também são movidos para o Lixo. O ficheiro .bbl do BibTeX é mantido.

Num projeto cujos ficheiros de capítulo indicam um ficheiro principal com % !TEX root, são movidos para o Lixo os ficheiros do ficheiro principal, também quando o comando é dado num ficheiro de capítulo.

Variantes

  • Mantenha premida a tecla Shift ao escolher «Apagar ficheiros auxiliares» ou ao clicar no botão para mover também para o Lixo o ficheiro PDF do documento. Normalmente o PDF antigo é mantido, para que a janela de pré-visualização tenha algo para mostrar quando a composição falha.
  • Mantenha premida a tecla Opção ao escolher «Apagar ficheiros auxiliares» ou ao clicar no botão para limpar um projeto inteiro: todos os ficheiros com uma das extensões acima na pasta do ficheiro principal e em todas as pastas abaixo dela são movidos para o Lixo, seja qual for o nome. Isto remove também os ficheiros .aux que \include escreve para os capítulos em subpastas.

Duas definições ocultas alteram este comportamento. Para adicionar extensões à lista, por exemplo dvi, escreva no Terminal

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

e, para voltar à lista padrão,

defaults write TeXShop OtherTrashExtensions -array

Para tornar o comportamento com Opção o comportamento padrão de «Apagar ficheiros auxiliares»:

defaults write TeXShop AggressiveTrashAUX YES
