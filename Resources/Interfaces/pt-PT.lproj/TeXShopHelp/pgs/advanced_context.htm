ConTeXt e MetaPost

ConTeXt

O ConTeXt é um pacote de macros de Hans Hagen, uma alternativa ao LaTeX com comandos próprios e uma forte ênfase no design tipográfico. O TeX Live inclui o ConTeXt, e o ConTeXt Garden distribui uma versão, atualizada com frequência, que se instala na sua pasta pessoal.

Os motores para o ConTeXt estão em ~/Library/TeXShop/Engines/Inactive/ConTeXt, juntamente com o guia Setting-Up-ConTeXt.pdf e documentos de exemplo:

MotorCompõe com
ConTeXt.engineo ConTeXt do TeX Live que funciona sobre o LuaTeX
ConTeXt-TL.engineo ConTeXt do TeX Live que funciona sobre o luametatex
ConTeXt-CG.enginea versão do ConTeXt Garden na sua pasta pessoal

Mova o motor de que precisa para ~/Library/TeXShop/Engines e coloque linhas especiais no início do ficheiro principal do documento, por exemplo:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Para o ConTeXt-CG, introduza a pasta dos programas da instalação do ConTeXt Garden no campo «Segundos motores TeX» de Definições › Composição › Caminhos e adicione a linha % !TEX useAlternatePath, que faz o TeXShop passar essa pasta ao motor em vez da do TeX Live.

Para a sincronização entre o código-fonte e a pré-visualização, adicione \setupsynctex[state=start,method=min] à configuração do documento; a linha % !TEX useConTeXtSyncParser faz o TeXShop usar o código de sincronização do próprio ConTeXt. O capítulo sobre o ConTeXt em Ajuda › Manual do TeXShop (em inglês) descreve em pormenor a instalação da versão do ConTeXt Garden e cada motor.

Para enumerar no menu Etiquetas os comandos de secção do ConTeXt, como \title e \subject, ative a definição oculta ConTeXtTags; consulte Definições ocultas.

MetaPost

O MetaPost, de John Hobby, desenha ilustrações a partir de uma descrição numa linguagem de programação derivada do METAFONT de Knuth. O seu manual faz parte do TeX Live: escolha Ajuda › Mostrar ajuda do pacote… e escreva metapost.

Compor › MetaPost (⇧⌘M), ou MetaPost no menu pop-up ao lado do botão «Compor», executa o MetaPost sobre o ficheiro com o nome do documento ativo e a extensão .mp: sobre o próprio documento, se for um ficheiro .mp, e caso contrário sobre o ficheiro .mp ao lado dele, como o que o pacote mfpic escreve para um documento .tex. Executa o comando indicado em Definições › Composição › «Ferramentas relacionadas» › MetaPost, por predefinição mpost. Os perfis do motor definem este campo: pmpost para pLaTeX + dvipdfmx e upmpost para upLaTeX + dvipdfmx, que compõem texto japonês nas legendas, e mpost para os outros perfis. O LuaLaTeX não consegue incluir figuras cujas legendas o pmpost ou o upmpost tenham composto em japonês; com o LuaLaTeX, desenhe essas figuras no documento com o pacote luamplib.

Para guardar um ficheiro novo como ficheiro MetaPost, escolha o tipo mp no menu «Formato do ficheiro» da caixa de diálogo Guardar.

Os motores nv-metapost e nv-metafun, de Nicola Vitacolonna, facilitam o trabalho com o MetaPost e o MetaFun e mostram as figuras de um ficheiro na janela de pré-visualização. Estão em ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; o ficheiro README.pdf e a pasta examples, um nível acima, em MetaPostEngines-1.4.7, explicam como instalá-los e usá-los e fornecem ficheiros de exemplo. Por exemplo, um ficheiro que comece por

% !TEX program = nv-metafun
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

é composto com o nv-metafun depois de esse motor estar na pasta Engines.

Os desenhos MetaPost também podem ser escritos dentro de um documento LaTeX, com o pacote luamplib para o LuaLaTeX, ou com pacotes como o mfpic, que escrevem os desenhos num ficheiro .mp que o MetaPost processa entre duas composições.
