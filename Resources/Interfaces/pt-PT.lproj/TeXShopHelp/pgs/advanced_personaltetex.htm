Adicionar ficheiros pessoais ao TeX Live

Os ficheiros de estilo, as classes, as bases de dados bibliográficas e outros ficheiros que não fazem parte do TeX Live vão para a sua árvore TeX pessoal, a pasta texmf na pasta Biblioteca da sua pasta pessoal: ~/Library/texmf. Todos os programas do TeX Live encontram aí os ficheiros, e estes têm prioridade sobre os ficheiros com o mesmo nome do próprio TeX Live. Não é preciso registar nada depois de adicionar um ficheiro; a composição seguinte encontra-o.

A pasta Biblioteca está oculta no Finder. Para a abrir, escolha Ir › Ir para a pasta… no Finder e escreva ~/Library. Crie aí a pasta texmf se ainda não existir.

Antes de adicionar um pacote

A maioria dos pacotes do CTAN já faz parte do TeX Live, e o MacTeX instala-os todos. Para ver se o TeX já tem um ficheiro, escolha Ficheiro › Abrir ficheiro de estilo… no TeXShop e escreva o nome, como hyperref.sty; o TeXShop abre o ficheiro que o TeX usaria. Adicione um pacote à sua árvore pessoal apenas quando o TeX Live não o tiver, ou quando precisar de uma versão própria. Como a sua cópia tem prioridade, remova-a quando o TeX Live estiver atualizado, caso contrário continuará a usar a versão antiga.

Onde colocar os ficheiros

As pastas dentro de texmf seguem a mesma estrutura do TeX Live. Crie as pastas de que precisar:

PastaConteúdo
tex/latex/pacotes e classes LaTeX (.sty, .cls), cada pacote numa pasta própria
tex/plain/ficheiros para plain TeX
tex/generic/ficheiros que funcionam com qualquer formato
bibtex/bib/bases de dados bibliográficas (.bib)
bibtex/bst/estilos bibliográficos (.bst)
doc/documentação dos pacotes que adicionou; Ajuda › Mostrar ajuda do pacote… encontra-a aí

Por exemplo, um pacote com as suas próprias macros e a sua base de dados bibliográfica seriam guardados como

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

Assim, \usepackage{mymacros} e \bibliography{mybibliography} funcionam em todos os documentos, onde quer que estejam guardados.

Verificar a pasta

Para ver que pasta o seu TeX usa como árvore pessoal, escreva no Terminal

kpsewhich -var-value TEXMFHOME

Num Mac, é ~/Library/texmf, a menos que a instalação tenha sido configurada de outra forma. Para ver que cópia de um ficheiro o TeX vai ler, escreva, por exemplo, kpsewhich mymacros.sty.

Não adicione ficheiros às pastas do próprio TeX Live; consulte Mais sobre o TeX Live.
