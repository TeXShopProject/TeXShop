Criar e usar formatos TeX

Um ficheiro de formato (extensão .fmt) é um instantâneo do TeX depois de ter lido um conjunto de macros. O próprio LaTeX é um formato: o TeX carrega-o num instante em vez de ler sempre o código-fonte do LaTeX. Pode criar um formato próprio a partir de um preâmbulo longo, para que a composição comece mais depressa, ou usar um formato fornecido por um projeto ou por uma organização.

Um formato só funciona com o motor e a versão do TeX Live que o criaram. Um formato criado com o pdfLaTeX do TeX Live 2026 não pode ser usado pelo XeLaTeX nem por outro ano do TeX Live; crie-o de novo depois de instalar um novo TeX Live.

Criar um formato

Coloque num ficheiro as linhas que o formato deve conter, terminando com \dump. Por exemplo, uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

No Terminal, mude para a pasta deste ficheiro e escreva

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Isto carrega o formato LaTeX, lê uo.tex e escreve uo.fmt. Um documento composto com este formato omite as linhas que estão no formato e começa com \begin{document}.

Usar um formato no TeXShop

  1. Mova uo.fmt para a pasta ~/Library/texmf/web2c, criando as pastas se for necessário, para que o TeX o encontre a partir de qualquer pasta.
  2. No Finder, abra ~/Library/TeXShop/Engines (TeXShop › Abrir ~/Library/TeXShop), duplique um motor como XeLaTeX.engine e mude o nome da cópia, por exemplo para Oregon.engine. O nome aparece no TeXShop e não tem de coincidir com o do formato.
  3. Abra a cópia no TeXShop e altere a última linha para que o motor fique assim: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Os documentos abertos depois disso mostram Oregon no menu pop-up ao lado do botão «Compor». Para usar o formato num documento, seja qual for a escolha nesse menu, adicione esta linha no início do código-fonte:

% !TEX program = Oregon

Para o tornar a predefinição, escolha «Ficheiro de motor» em Definições › Composição › Motor › «Compor documentos novos com» e Oregon no menu «Ficheiro de motor». Consulte Adicionar motores de composição.

Para um formato plain TeX, use pdftex em vez de pdflatex no motor. Para um formato a usar via DVI, o motor tem também de converter o ficheiro DVI em PDF, por exemplo com dvipdfmx "${1:r}.dvi" num script zsh, porque o TeXShop mostra o ficheiro PDF com o nome do código-fonte.
