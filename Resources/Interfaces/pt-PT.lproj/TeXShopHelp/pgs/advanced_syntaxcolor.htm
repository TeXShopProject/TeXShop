Destaque de sintaxe

A janela do código-fonte mostra o TeX a cores: os comentários, os comandos, as notas de rodapé, os marcadores $ e & e os parênteses ( ), { } e [ ] têm cada um a sua cor. Código-fonte › Destaque de sintaxe ativa ou desativa o destaque no documento ativo. Os documentos abrem com o destaque ativo; para os abrir com o destaque desativado, use a definição oculta

defaults write TeXShop SyntaxColoringEnabled NO

O que é destacado

  • Os comandos são uma barra invertida seguida de letras. Definições › Editor › «Destaque de sintaxe» › «@ nos comandos» conta também @ como letra, como nos comandos internos dos pacotes.
  • O texto de \footnote, \footcite e \autocite, e dos comandos que começam por \cite ou \Cite, como \citep e \citeauthor, é mostrado com a cor «Nota de rodapé». A definição oculta defaults write TeXShop SyntaxColorFootnote NO colore apenas o comando.
  • Código-fonte › Destacar as entradas do índice mostra os argumentos de \index e \esindex com a cor «Índice». Definições › Editor › «Destaque de sintaxe» › «Destacar as entradas do índice por predefinição» ativa-o quando os documentos abrem.
  • Código-fonte › Destacar o código expl3 colore também as funções, as variáveis e outras partes do código expl3, a camada de programação do LaTeX, para quem escreve pacotes. «Destacar o código expl3 por predefinição», no mesmo grupo, ativa-o quando os documentos abrem.
  • «Destacar letras e símbolos de largura total», no mesmo grupo, mostra com as cores «Largura total» as letras, os dígitos e os símbolos de largura total, que se confundem facilmente com caracteres ASCII em texto japonês.

«Destacar as entradas do índice» e «Destacar o código expl3» aplicam-se ao documento ativo; cada janela do código-fonte tem a sua própria escolha. Os ficheiros que não são código-fonte TeX, como os ficheiros de registo, não são destacados; consulte Abrir outros ficheiros com o TeXShop para ver a lista de extensões e saber como adicionar uma.

Alterar as cores

As cores pertencem ao tema. Escolha-as em Definições › Temas:

  • o grupo «Destaque de sintaxe» tem «Comentário», «Comando», «Nota de rodapé», «Marcador» e «Índice»;
  • o grupo «Parênteses» tem as cores de ( ), { } e [ ];
  • o grupo expl3 tem function, __function, key, variable, __variable, argument e msg;
  • o grupo «Destaques» tem, entre outras, as cores «Largura total»;
  • o grupo «Sintaxe XML» tem as cores para ficheiros HTML e XML.

Cada tema tem as suas próprias cores, pelo que o «Tema do modo claro» e o «Tema do modo escuro» podem ser diferentes.
