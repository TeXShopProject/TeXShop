Instalar o TeX Live

O TeXShop precisa de uma distribuição TeX. A distribuição padrão é o TeX Live, que os grupos de utilizadores de TeX produzem todos os anos para macOS, Windows, Linux e outros sistemas. No Mac, instala-se com o MacTeX, um pacote de instalação feito pelo TeX Users Group (TUG):

https://tug.org/mactex/

A página oferece dois pacotes. Faça duplo clique no pacote que descarregou e siga o instalador; quando este terminar, o TeX está pronto a usar.

MacTeX
O TeX Live completo, com cerca de 7 GB, com o Ghostscript, e o TeXShop e outras aplicações em /Applications/TeX. Quase todos os exemplos de um livro sobre TeX ou LaTeX funcionam sem acrescentar nada. Escolha este pacote para trabalho a sério.
BasicTeX
Uma pequena parte do TeX Live, com cerca de 140 MB, suficiente para experimentar o TeX e compor muitos documentos LaTeX. Não instala o TeXShop; consulte Instalar o TeXShop.

Onde é instalado o TeX Live

O MacTeX instala o TeX Live em /usr/local/texlive/2026 e o BasicTeX em /usr/local/texlive/2026basic. Os dois podem ser instalados lado a lado. Todos os anos, por volta de abril, sai um novo TeX Live, numa pasta com o nome do ano. Para remover uma instalação, arraste a respetiva pasta para o Lixo.

O instalador cria também /Library/TeX/texbin, que conduz aos programas do TeX Live em uso e passa para o novo TeX Live quando este é instalado. O TeXShop executa o TeX a partir daí (Definições › Composição › Caminhos › Motores TeX), pelo que não é preciso alterar nada a cada novo ano. «Detetar caminhos…», no mesmo grupo, procura as instalações do TeX e do Ghostscript no Mac e permite escolher uma delas.

Entre as versões anuais, os pacotes do TeX Live recebem atualizações. O MacTeX instala o TeX Live Utility em /Applications/TeX para as instalar.

Outras distribuições TeX

O TeXShop também funciona com o TeX instalado pelo MacPorts ou pelo Homebrew, ou com o MiKTeX. Os programas destas distribuições estão noutras pastas: use «Detetar caminhos…» ou escreva a pasta em Definições › Composição › Caminhos › Motores TeX. Consulte Coexistir com outras distribuições TeX.
