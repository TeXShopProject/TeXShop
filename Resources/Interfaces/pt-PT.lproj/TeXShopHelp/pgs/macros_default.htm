Compreender as macros predefinidas

A melhor forma de compreender as macros predefinidas é observá-las no editor de macros (Macros › Abrir editor de macros…): selecione uma macro na lista e o seu conteúdo aparece ao lado.

Por exemplo, suponha que quer um ambiente theorem. Escreva a palavra theorem, selecione-a e escolha Macros › Insert Begin/End. A palavra é substituída por

\begin{theorem}

\end{theorem}

e o ponto de inserção é colocado na linha intermédia.

Insert Begin/End é uma macro AppleScript (consulte Macros AppleScript). Uma macro de texto que faz o mesmo quando uma palavra está selecionada é:

\begin{#SEL#}
#INS#
\end{#SEL#}

Marcadores de posição nas macros de texto

O texto de uma macro de texto é inserido no código-fonte com estas substituições:

#SEL#
é substituído pelo texto que estava selecionado quando a macro foi escolhida, ou por nada se não havia texto selecionado.
#INS#
indica o local para onde vai o ponto de inserção. Sem ele, o ponto de inserção é colocado no fim do texto inserido.
#PASTE#
é substituído pelo texto da área de transferência, ou por nada se a área de transferência não contiver texto.
•
é uma marca, para a qual Edição › Marcas permite ir.

No editor de macros, estes marcadores de posição aparecem como fichas arredondadas; Definir novas macros explica como inseri-los. Com estes conhecimentos, as macros predefinidas são fáceis de compreender e de alterar.
