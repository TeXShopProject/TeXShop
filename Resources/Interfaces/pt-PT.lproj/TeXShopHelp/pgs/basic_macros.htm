Macros

O menu Macros, e o item «Macros» da barra de ferramentas, contêm comandos que inserem código LaTeX no código-fonte ou executam scripts AppleScript. Algumas das macros fornecidas com o TeXShop:

  • Program, Encoding e Root escrevem as linhas % !TEX que escolhem o motor de composição, a codificação e o ficheiro principal de um documento. Escolha o motor ou a codificação na lista que Program ou Encoding mostra, ou o ficheiro principal no diálogo que Root abre; a linha é escrita corretamente no início do código-fonte.
  • Insert Begin/End transforma a palavra no ponto de inserção, ou a palavra selecionada, como theorem, num par \begin{theorem} … \end{theorem}, com o ponto de inserção entre eles.
  • Submenus como Headings, Mathematics, Lists, Tables e Figures inserem código LaTeX comum.

O editor de macros

Escolha Macros › Abrir editor de macros... para ver como cada macro está definida, alterá-la ou acrescentar macros suas. A lista à esquerda é o menu Macros: arraste itens para os reorganizar e use a barra por baixo da lista para acrescentar itens, submenus e separadores. O texto de uma macro é inserido no código-fonte. Neste texto, fichas arredondadas representam o texto selecionado, o texto da área de transferência e o local do ponto de inserção; escolha-as no menu «Inserir», por baixo do texto.

Para dar um atalho de teclado a uma macro, selecione-a na lista, clique no respetivo atalho (ou faça duplo clique nele) e prima as teclas. Um atalho usa a tecla Comando ou Controlo, ou é uma tecla de função. Se um comando de menu ou outra macro já o usar, o editor de macros indica-o.

As macros são guardadas em ~/Library/TeXShop/Macros/Macros_Latex.plist. Para dar macros a outras pessoas, selecione-as no editor de macros e escolha Macros › Guardar seleção num ficheiro...; para acrescentar macros de um ficheiro destes, escolha Macros › Adicionar macros de um ficheiro....

O capítulo Ajuda das macros explica as macros em pormenor, incluindo as macros AppleScript (consulte Macros AppleScript).
