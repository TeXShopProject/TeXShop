Usar um editor externo

Pode escrever noutro editor e usar o TeXShop para compor e mostrar o PDF.

Abrir apenas a pré-visualização

Ficheiro › Abrir para pré-visualizar… pede um ficheiro de código-fonte e abre apenas a respetiva janela de pré-visualização. Se o ficheiro ainda não tiver sido composto, ou se o PDF for mais antigo do que o código-fonte, o TeXShop compõe-no primeiro. Edite o código-fonte no seu editor; para compor, guarde-o aí e prima «Compor» na janela de pré-visualização ou prima ⌘T. Neste modo, o TeXShop nunca abre nem altera o ficheiro de código-fonte. Se a barra de ferramentas da janela de pré-visualização não tiver o botão «Compor», adicione-o com Janela › Personalizar barra de ferramentas….

Se trabalhar sempre desta forma, ative Definições › Geral › «Ao iniciar» › «Configurar para editor externo». Ficheiro › Abrir… e «Abrir documento recente» passam então a abrir os ficheiros de código-fonte apenas para pré-visualização, e Ficheiro › Abrir para pré-visualizar… passa a «Abrir para editar…», que abre um ficheiro de código-fonte no editor do próprio TeXShop quando precisar. Os outros ficheiros, como PDF, imagens e ficheiros de registo, abrem como antes.

Manter a pré-visualização atualizada

Quando o PDF é reescrito por outro programa, por exemplo pelo seu editor ou pelo latexmk no Terminal, o TeXShop recarrega-o quando volta ao TeXShop ou à janela de pré-visualização, mantendo a página e a ampliação. Com Definições › Pré-visualização › Atualização › «Vigiar sempre as alterações ao PDF feitas por outras apps» ativo, recarrega o PDF assim que este muda, mesmo com o TeXShop em segundo plano, por exemplo quando a pré-visualização está ao lado do seu editor. Uma pré-visualização com anotações por guardar não é recarregada, para que as anotações não se percam.

O TeXShop vigia também os ficheiros de código-fonte abertos no seu próprio editor. Quando outro editor altera um desses ficheiros, o TeXShop recarrega-o, a menos que a cópia no TeXShop tenha alterações por guardar.

Sincronizar com o editor

Um clique com a tecla Comando premida na janela de pré-visualização pode levá-lo à linha no seu editor, e «Mostrar erro» na consola pode abrir aí a linha de um erro. Isto requer «Configurar para editor externo», uma definição oculta e um programa de linha de comandos do editor:

  • Para o TextMate, cujo comando mate está em /usr/local/bin: defaults write TeXShop TextMateSync YES.
  • Para qualquer outro editor: defaults write TeXShop OtherEditorSync YES e um script executável /usr/local/bin/othereditor que recebe o número da linha como $1 e o caminho completo do ficheiro como $2. Para o BBEdit, é assim: 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

Para o sentido inverso, de uma linha no editor para a janela de pré-visualização, o editor chama o TeXShop através do AppleScript com os comandos sync_preview_line, sync_preview_index e sync_preview_name. O capítulo «Using an External Editor» de Ajuda › Manual do TeXShop (em inglês) contém um script completo.

A pasta ~/Library/TeXShop/ExternalEditorScripts contém suporte pronto a usar, com documentação: AppleScripts que compõem e pré-visualizam no TeXShop um documento do BBEdit e um plug-in para o Vim.

Comandos AppleScript para editores

Um editor pode chamar estes comandos AppleScript de um documento do TeXShop:

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Compor, ou executar plain TeX, LaTeX, BibTeX, MakeIndex ou MetaPost. A chamada regressa de imediato, sem esperar pelo fim da composição; a pré-visualização é atualizada quando a composição termina.
taskdone
Devolve NO enquanto a composição está em curso e YES quando terminou.
refreshpdf
Recarrega o PDF e traz a janela de pré-visualização para a frente.
refreshpdfbackground
Recarrega o PDF sem trazer o TeXShop para a frente, quando a janela de pré-visualização já está aberta.
refreshtext
Lê de novo o ficheiro de código-fonte a partir do disco.
open_for_externaleditor
Abre um ficheiro de código-fonte como Ficheiro › Abrir para pré-visualizar….

Quando o editor compõe através do TeXShop, «Vigiar sempre as alterações ao PDF feitas por outras apps» não é necessário. Consulte também Escrever scripts com os comandos de composição do TeXShop.
