Escrever scripts com comandos da shell

Esta página usa a macro Run pdfLaTeX with Shell Escape de Claus Gerhardt, em Macros › Claus Gerhardt Macros, para mostrar como um AppleScript chama um script da shell. O script da shell em si é simples: adiciona as pastas dos programas TeX ao caminho de pesquisa e executa o pdflatex com --shell-escape. Os seus próprios scripts farão provavelmente mais, por exemplo executar vários programas em sequência; é nesse caso que estas técnicas se tornam úteis.

O script da shell

O script da shell é ~/Library/TeXShop/bin/pdflatexc. Não depende do TeXShop: se a sua pasta estiver no seu caminho de pesquisa, escrever pdflatexc myfile.tex no Terminal executa-o. Ei-lo:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

O AppleScript

A macro que chama este script da shell é mais interessante:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Depois dos comentários, as sete primeiras linhas são uma receita de Claus Gerhardt para guardar o ficheiro de código-fonte e encontrar o nome do seu documento, que é colocado em frontName. O trabalho é feito pelo script compilado setname.scpt em ~/Library/TeXShop/Scripts: estas linhas encontram o caminho ~/Library/TeXShop/Scripts/setname.scpt, carregam o script e chamam-no com #NAMEPATH# e #TEXPATH#.

Muitas vezes, o mesmo pode fazer-se de forma mais simples com

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

A receita tem duas vantagens. Funciona também quando o documento da frente não é aquele que deve receber os comandos seguintes, por exemplo um ficheiro de registo como /Users/name/Examples/myfile.log. E, se o ficheiro nunca tiver sido guardado, a receita devolve um erro, enquanto o comando save deixaria o script à espera atrás de uma caixa de diálogo de gravação.

As seis linhas seguintes definem as variáveis dirName e baseName. Se o ficheiro de código-fonte for /Users/name/My Papers/Stuff/myfile.tex, dirName é '/Users/name/My Papers/Stuff', entre aspas para a shell por causa do espaço num nome de pasta, e baseName é myfile.tex. O nome do ficheiro é colocado entre aspas da mesma forma quando é passado ao script da shell, pelo que ambos podem conter espaços.

As três linhas seguintes chamam o script da shell. O resultado é o mesmo que escrever cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' no Terminal. As três últimas linhas atualizam a janela de pré-visualização.

Várias destas linhas são complicadas, mas podem ser copiadas sem alterações para novos scripts.

Executar comandos da shell a partir do AppleScript

O AppleScript executa um comando da shell na forma

do shell script "cmd input"

Para construir um comando a partir de partes, escreva-o na forma equivalente

do shell script "cmd " & "input"

Repare no espaço depois de cmd. O E comercial junta duas cadeias:

"cmd " & "input" = "cmd input"

Uma shell iniciada pelo AppleScript começa na pasta raiz. O comando

do shell script "cd " & dirName

muda para a pasta indicada em dirName, que já está entre aspas, pelo que não são necessárias mais aspas.

Cada do shell script inicia uma nova shell, pelo que um comando posterior não estaria nessa pasta. Para executar mais comandos na mesma pasta, junte-os com pontos e vírgulas num único comando, como no Terminal:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

O script acima faz isto com cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc e input2 = baseName. As linhas

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

são simplesmente uma forma prática de colocar esta sequência numa única variável.
