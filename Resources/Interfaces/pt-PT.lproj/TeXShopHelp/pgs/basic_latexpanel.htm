Painel LaTeX

Janela › Painel LaTeX... abre um painel de código LaTeX: símbolos matemáticos, letras gregas, funções, caracteres acentuados e internacionais, ambientes e comandos de tipo de letra. Clique no código-fonte onde o código deve ficar e depois clique num botão do painel. O respetivo código é inserido no ponto de inserção. O painel fica à frente das janelas do código-fonte enquanto trabalha.

Os botões estão organizados em páginas. Escolha uma página com os botões no topo de cada parte do painel: «Matemática», «Grego», «Símbolos», «Funções» e «Internacional», e «Ambientes», «Tipo» e «Personalizado».

Se houver texto selecionado quando clica num botão de tipo de letra ou de ambiente, o texto selecionado fica dentro do código inserido, como em \textbf{texto selecionado}.

Alguns símbolos precisam do pacote amssymb. Acrescente esta linha ao preâmbulo de um documento que os use:

\usepackage{amssymb}

Personalizar o painel

O código que cada botão insere é guardado em ~/Library/TeXShop/LatexPanel/completion.plist. Abra este ficheiro no TeXShop para o alterar; os comentários no seu início explicam como está organizado. Os nomes dos botões padrão não podem ser alterados, mas o código que inserem pode. Neste código:

  • #SEL# representa o texto selecionado;
  • #INS# assinala onde fica o ponto de inserção depois de o código ser inserido;
  • #PASTE# representa o texto da área de transferência.

A página «Personalizado» tem espaço para até dezasseis botões seus. Cada um é definido na lista Customized do ficheiro por dois textos, o nome do botão e o código que insere:

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Guarde o ficheiro em UTF-8 e depois saia do TeXShop e volte a abri-lo para ver as alterações no painel. Se o ficheiro faltar ou estiver danificado, o TeXShop substitui-o pela sua própria cópia. Consulte Modificar o Painel LaTeX e Ficheiros em ~/Library/TeXShop.
