Templates and Stationery

Templates

The Templates menu in the toolbar of the source window inserts a template at the insertion point, indented like the current line. TeXShop comes with these templates:

  • LatexTemplate, XeLaTeX Template, LatexSpanishTemplate and BeamerTemplate: the start of a LaTeX article, a XeLaTeX document, a LaTeX article in Spanish and a Beamer presentation;
  • TexTemplate: the \end that closes a plain TeX document;
  • GraphicsTemplate: the code to include a graphic;
  • TeX4ht-Header and TeX4ht-Interactive: code for documents converted to HTML with TeX4ht;
  • More: a submenu with preambles, document classes such as article, letter and memoir, floating figures and tables, and mathematical layouts such as align and matrices.

The templates are ordinary files in ~/Library/TeXShop/Templates; choose TeXShop › Open ~/Library/TeXShop to get there. To make your own template, for example the preamble you use for every article, save a file with the extension .tex in this folder, or duplicate a template and change it. Subfolders become submenus. Templates you add, rename or remove show in the menu of windows opened afterward.

Updates of TeXShop do not change this folder, so your templates are kept. To get the original templates back, move the Templates folder out of ~/Library/TeXShop, for example to the Desktop, and restart TeXShop: it creates the folder again with its own templates.

Stationery

File › New from Stationery… starts a new document from a complete sample: choose one in the list, which shows a description of each, and click Create; Space shows the selected stationery in Quick Look. The new document is untitled; save it where you like. TeXShop comes with stationery for an AMS article, a Beamer presentation, a letter, a PreTeXt document, a project with a root file and a chapter, and a XeLaTeX document.

The stationery is kept in ~/Library/TeXShop/Stationery. “Show in Finder” in the panel opens this folder. To add the document in front as stationery, click + in the panel and give it a name and a description; − moves the selected stationery to the Trash, and clicking the description of the selected stationery lets you change it. You can also put the file there yourself, for example Report.tex, together with a file Report.comment holding one sentence that describes it.
