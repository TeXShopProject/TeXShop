MakeIndex

MakeIndex sorts the index entries of a LaTeX document and writes the index. To add an index to a document:

  1. Put \usepackage{makeidx} and \makeindex in the preamble.
  2. Put \printindex where the index should appear, often just before \end{document}.
  3. Mark the entries in the text: 
    There are many animals in the world\index{animal}.
Examples include bears\index{animal!bear}
and tigers\index{animal!tiger}.

To create the index, typeset the document, then choose Typeset › MakeIndex (⇧⌘I), or choose MakeIndex in the pop-up menu beside the Typeset button and press Typeset, and then typeset again. Typesetting with latexmk runs MakeIndex by itself.

MakeIndex runs the program in Settings › Typesetting › Related Tools › Index Program, followed by the name of the idx file. The default is makeindex. Fill in another program, such as mendex or upmendex for Japanese documents, with any options it needs, for instance upmendex -s mystyle.ist. The engine profiles set this field: makeindex for the Western profiles, mendex for pLaTeX + dvipdfmx, and upmendex for upLaTeX + dvipdfmx and LuaLaTeX (Japanese).

Source › Highlight Index Entries shows the arguments of \index in the Index color of the theme; see Syntax Highlighting.
