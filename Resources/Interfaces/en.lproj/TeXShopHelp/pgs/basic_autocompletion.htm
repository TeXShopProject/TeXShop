Greg Landweber has added key bindings to the TeXShop editor. Typing a double quote will produce a pair of double quotes with the cursor positioned between them. Typing the ^ symbol will produce ^{ } with the cursor positioned between the brackets. Etc. Thirty-nine such bindings are currently available.

Key Bindings can be turned off or on with an item in the Settings window. The default is off.

Key Bindings can also be turned on or off on a file by file basis by the Key Bindings item in the Source menu. This facility is provided because Key Bindings reconfigures keys on the keyboard; turn if off if you need keys to input their standard characters.

Key Bindings are user configurable. Open Settings and select Keyboard. The Key Bindings section lists each input character with its output string, under "Input Character" and "Output String". Double-click a cell to edit it in place; press + below the list to add a key binding and − to delete the selected ones, and drag rows to change their order. An input character is a single character. Changes are saved at once and take effect immediately; Edit › Undo reverts them.

In an output string, #SEL# (the selected text), #INS# (where the insertion point goes), #PASTE# (the text on the clipboard), • (a mark), line breaks and tabs are shown as small labels. Add them with "Insert" below the list, or type them: Option-Return enters a line break and Option-Tab a tab. The ? button lists them all. The list is stored in ~/Library/TeXShop/Keyboard/autocompletion.plist, in the same form as before.
