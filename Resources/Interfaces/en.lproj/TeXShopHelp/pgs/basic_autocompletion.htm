Key Bindings

Key bindings make a typed character insert other text. With the list that comes with TeXShop, typing ^ gives ^{} with the insertion point between the braces, typing " gives the TeX quotes ``'' around the insertion point, and typing ä gives \"a. A key binding can also put the selected text inside: select a word and type ^ to get ^{word}. The list has 45 key bindings.

Key bindings are off at first. Turn on “Use key bindings (default for new documents)” in Settings › Keyboard to have them on in every document you open. Source › Key Bindings turns them on or off for the document in front, for example to type a character that has a key binding as itself. The KeyBindings item, which can be added to the toolbar, does the same.

The Key Binding List

The Key Bindings group of Settings › Keyboard lists the key bindings, with each Input Character and its Output String. Double-click a cell to edit it; click + below the list to add a key binding and − to delete the selected ones, and drag rows to change their order. An input character is a single character. Changes are saved at once and act in open documents too; Edit › Undo takes them back.

In an output string, special items are shown as small labels: the selected text, the place of the insertion point, the text on the clipboard, a mark (•) for Edit › Marks, a line break and a tab. Add them with Insert below the list, or type them: #SEL#, #INS#, #PASTE# and •, Option-Return for a line break and Option-Tab for a tab. The ? button lists them all.

A check in the Paste column applies the key binding also to text you paste into the source or drop on it: each occurrence of the input character is replaced by the output string. As with typing, this happens only while key bindings are on for the document. A key binding whose output string contains the selection, the insertion point, the clipboard or a mark cannot be checked.

The yen sign

On a Japanese keyboard, the key for the backslash may type a yen sign (¥). In the list that comes with TeXShop, ¥ gives a single backslash and its Paste box is checked. So when the encoding for new documents is UTF-8, turning on key bindings is enough to have ¥ typed or pasted into the source become \. If your list comes from an earlier version of TeXShop, set the output string of ¥ to a single backslash and check its Paste box yourself.

The list is stored in ~/Library/TeXShop/Keyboard/autocompletion.plist; see Modifying Key Bindings.
