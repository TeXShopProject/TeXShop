Preliminaries

TeXShop macros and the Macro Editor are by Mitsuhiro Shishikura; the default LaTeX macros were created by Mitsuhiro Shishikura and Hirokazu Ogawa.

Macros are listed in the Macros menu and in the Macros pop-up menu of the source window toolbar. There are two kinds. Text macros insert text into the source, like the buttons of the LaTeX Panel. AppleScript macros run an AppleScript; see AppleScript Macros.

Where macros are kept

The macros are stored in

~/Library/TeXShop/Macros/Macros_Latex.plist

and the Macros menu shows them for every typesetting engine. A separate set can be kept for the built-in engines plain TeX, BibTeX, MakeIndex and MetaPost: when one of these is chosen for the document, the Macro Editor saves its macros in a file of its own, such as Macros_Tex.plist, and leaves Macros_Latex.plist unchanged.

The macro files are ordinary text files, but they are best changed with the Macro Editor: choose Macros › Open Macro Editor…. Defining New Macros explains how to add, delete and name macros and how to give them shortcuts.

If the Macros folder is missing

If the Macros folder is missing when TeXShop starts, TeXShop creates it again with the default macros. If Macros_Latex.plist is damaged, TeXShop replaces it with its own copy when it starts, without a message, and keeps the damaged file in ~/Library/TeXShop/Backups. To start over with the default macros, quit TeXShop, move the Macros folder to the desktop and start TeXShop again; the moved folder keeps your old macros.

Sharing macros

While the Macro Editor is open, the Macros menu has two more commands. “Save selection to file...” saves the selected macros in a file of their own, which you can give to others. “Add macros from file...” adds the macros of such a file to your list; then arrange them in the Macro Editor as you like.
