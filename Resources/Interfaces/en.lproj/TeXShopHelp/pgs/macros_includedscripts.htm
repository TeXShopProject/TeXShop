Default AppleScript Macros

TeXShop comes with a collection of AppleScript macros by Will Robertson, Claus Gerhardt and others. Some of them run a series of typesetting commands in sequence. By copying and changing them, you can build scripts for your own work. This page describes some of them, under their names in the Macros menu.

Column macros, Insert reference, Open quickly…

These macros are by Will Robertson. In the Column macros submenu, New tabular and New array insert a tabular or array environment with the numbers of rows and columns you enter, and Add column and Delete column change the rows you select. Insert reference searches the current file for \label{…} commands and lets you choose a label from a list; it inserts the label wrapped in \ref{…}, a command you can change in the script. If text is selected, only the labels that contain it are listed. Open quickly… lists the .tex, .sty and .pdf files in the folder of the current source file and opens the ones you choose.

Paste Spreadsheet Cells

This macro, by Alan Munn, pastes cells from a spreadsheet into your LaTeX source as a table. Select a range of cells in Excel or another spreadsheet application and copy them. Then choose Macros › Paste Spreadsheet Cells and choose a table style:

cells
converts the copied text to LaTeX table cells only.
booktabs
takes the first line as a header and places \toprule, \midrule and \bottomrule in a tabular environment.
simple
puts a simple tabular environment around the cells.
longtable
takes the first line as a header, adds the header lines of a longtable and puts the cells in a longtable environment.

The macro replaces the contents of the clipboard with the LaTeX text. To paste the same cells in another style, copy them again in the spreadsheet first.

Applescript › Save Copy with Unix Line Endings, Save Copy with Windows Line Endings, Save Copy with Classic Mac Line Endings

Text files end their lines in different ways: macOS and Unix with a line feed, Windows with a carriage return followed by a line feed, and very old Macintosh files with a carriage return alone. TeXShop reads all three. If someone else's editor cannot, use these macros. For a source file MyFile.tex, Save Copy with Unix Line Endings writes a copy of the saved file named MyFile_Unix.tex with line feeds; Save Copy with Windows Line Endings writes MyFile_Windows.tex and Save Copy with Classic Mac Line Endings writes MyFile_Mac.tex. The macros use the program flip by Craig Stuart Sapp in ~/Library/TeXShop/bin.

Applescript › Run LaTeX, BibTeX, Then LaTeX Twice

A document with a bibliography needs several runs: LaTeX writes the .aux file, BibTeX uses it to write the .bbl and .blg files, LaTeX runs again to add the bibliography, and once more to update the references to it. This macro runs them one after another. Writing Scripts with TeXShop Typesetting Commands explains how it works.

Claus Gerhardt Macros

Most macros of this submenu call shell scripts in ~/Library/TeXShop/bin, such as pdflatexc, which runs pdfLaTeX, and bibtexc, which runs BibTeX. Each macro whose name begins with Run runs the programs it names, in that order, and Open PDF opens the PDF of the document. Run LaTeX, dvips and ps2pdf also needs Ghostscript. They work on a saved file. Writing Scripts with Shell Commands explains Run pdfLaTeX with Shell Escape as an example.

Make HTML with TeX4ht

TeX4ht converts a LaTeX document into a web page: an HTML page and image files. Make HTML with TeX4ht runs htlatex on the document and opens the resulting HTML file in Safari. The package tex4ht does not need to be loaded in the document; htlatex loads it. Make HTML with TeX4ht, Remaking Images runs htlatex with the option -r, which makes the images again even when they already exist.

Extract Pages from PDF…

Extract Pages from PDF… makes PDF files that contain selected pages of the document's PDF. It first asks how many files to make, then for the pages of each file, such as 5:8 for pages 5 to 8 or 3:4,6,8:12. If the document is named MyFile, the files are saved as MyFile-1.pdf, MyFile-2.pdf and so on.

MetaPost

Run pdfLaTeX, MakeIndex, MetaPost, Then pdfLaTeX opens the log files on the way. See ConTeXt and MetaPost for MetaPost.
