Alternate Typesetting Mode

TeXShop normally typesets with the Direct PDF method: pdfLaTeX or pdfTeX writes the PDF file directly. The alternate method, Via DVI, runs LaTeX or TeX to make a DVI file, converts it to PostScript with dvips, and converts the PostScript to PDF with Ghostscript. The script simpdftex of TeX Live does these steps.

Via DVI is needed for documents that put PostScript code into the output, for example with the pstricks package. EPS pictures do not need it: TeX Live converts them to PDF while typesetting with Direct PDF.

Choosing the method

Typeset › Via DVI and Typeset › Direct PDF switch the method of the active document; other open documents keep theirs. Settings › Typesetting › Typesetting Method sets the method that documents start with. Its third choice, Personal Script, runs the commands of the Personal Script group instead. The commands of Via DVI, one for plain TeX and one for LaTeX, are in the Via DVI group of Settings › Typesetting. The engine profile LaTeX + dvips + Ghostscript, under Other in the Engine Profile menu, sets up typesetting Via DVI.

Choosing the method in the document

A line among the first 20 lines of the source sets the program and the method for that document, whatever the settings are:

LineTypesets with
% !TEX program = pdflatexLaTeX, Direct PDF
% !TEX program = latexLaTeX, Via DVI
% !TEX program = pdftexplain TeX, Direct PDF
% !TEX program = texplain TeX, Via DVI
% !TEX program = personallatexLaTeX, Personal Script
% !TEX program = personaltexplain TeX, Personal Script

Options for Via DVI

Ghostscript ignores PostScript transparency by default. To keep it, add --distilleropts "-dALLOWPSTRANSPARENCY" at the end of the command in the Via DVI group. To keep the intermediate PostScript file, add --keep-psfile. Ghostscript is run from the folder in Settings › Typesetting › Paths › Ghostscript.
