Windows and Tabs

TeXShop windows can be gathered as tabs of one window, as in other macOS apps. In Settings › General, Open New Windows as Tabs chooses when this happens: Never, Automatically, which follows the tab setting of macOS, or Always.

With Always and separate source and Preview windows, the source of each document you open becomes a tab of the source window and its preview a tab of the Preview window; consoles and logs are gathered in the same way. Selecting a tab of one window brings the matching tab of the other forward when you typeset or sync. If source and Preview are shown in one window (Source and Preview in Settings › General set to Use One Window), each tab holds one whole document. Window › Use One Window and Window › Use Separate Windows change the active document between the two ways.

A window that shows source and Preview together, with or without tabs, works well in full screen: the console then floats over it while you typeset.

Opening a project in tabs

For a book whose chapters are separate files, the root file can ask TeXShop to open the chapters as tabs of its window. Put this line in the first 20 lines of the root file:

% !TEX useTabs

When the root file opens, the files named by its \include commands open as tabs. Short names for the tabs can follow on the same line, in parentheses and separated by commas; a blank between two commas keeps the name of that file:

% !TEX useTabs (Intro, Groups, , Fields)

To give the files of \input commands tabs as well, use this hidden setting in Terminal:

defaults write TeXShop TabsAlsoForInputFiles YES

To choose the files yourself, put a useTabsWithFiles line in the first 20 lines of the root file and add a tabbedFile line for each tab, all in its first 50 lines. A name for the tab can follow in parentheses:

% !TEX useTabsWithFiles
% !TEX tabbedFile{chapter1/Introduction.tex} (Introduction)
% !TEX tabbedFile{Galois.log}
% !TEX tabbedFile{~/Graphics/diagram.pdf}

A path is relative to the folder of the root file, starts at your home folder with ~, or is a full path. Always write the extension, even when the Finder hides it: these tabs can also show logs, PDF files and graphics. Each file opens as it would if you opened it yourself, so a source file may bring its preview along.

See Help › Comment Lines and Hidden Settings for the other magic comment lines.
