BibTeX

BibTeX builds the bibliography of a LaTeX document from a database of references, a file with the extension .bib. The document cites entries by their keys, and BibTeX lists only the entries cited.

A database mybibliography.bib contains entries like

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

and the document cites them and names the style and the database:

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

Running BibTeX

  1. Typeset the document. Citations appear as [?], and the bibliography is missing.
  2. Choose Typeset › BibTeX (⇧⌘B), or choose BibTeX in the pop-up menu beside the Typeset button and press Typeset.
  3. Typeset twice more: the first run adds the bibliography, the second fills in the citations.

Typesetting with latexmk, for instance with the pdflatexmk engine or a profile set up “With latexmk”, runs BibTeX and the extra passes by itself.

To make a new database in TeXShop, choose the bib type in the File Type menu of the Save dialog, so that the file gets the extension .bib. A database can also live in your personal TeX tree, where every document finds it; see Adding Personal Files to TeX Live.

Choosing the program

Typeset › BibTeX runs the command in Settings › Typesetting › Related Tools › BibTeX Engine, bibtex by default. Enter another program there with any options it needs, for instance biber for documents that use the biblatex package. The engine profiles set this field: pbibtex for pLaTeX + dvipdfmx, upbibtex for upLaTeX + dvipdfmx and LuaLaTeX (Japanese), and bibtex for the other profiles.

To choose the program for one document, put a line like this in one of its first twenty lines:

% !BIB program = biber

The line takes precedence over the setting. The form % !BIB TS-program = is read the same way.
