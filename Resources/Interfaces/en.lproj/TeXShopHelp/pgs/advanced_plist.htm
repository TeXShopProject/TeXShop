Files in ~/Library/TeXShop

TeXShop keeps the files you can customize in the folder ~/Library/TeXShop, which it creates the first time it runs. TeXShop › Open ~/Library/TeXShop opens the folder in the Finder. To take your customizations to another Mac, copy this folder there.

What the folder contains

Most of these files are edited in TeXShop itself, and there is no need to open them:

The menu shortcuts in KeyEquivalents.plist become the defaults of the shortcut list in Settings › Keyboard; shortcuts changed in Settings take precedence. See Redefining Keyboard Menu Shortcuts.

Editing a file by hand

Files with the extension .plist are XML text. They can be opened and edited in TeXShop, in another text editor or in Xcode. Several of them begin with comments that explain their format. Keep them in UTF-8, the encoding they are written in. Edit the colors of themes in Settings › Themes rather than in their files.

If a file you edited stops working, move it out of the folder, or move its folder to the desktop, and restart TeXShop: it creates the file again with its original contents.

Missing or damaged files

When one of the files that TeXShop needs, such as the macros, the key bindings, the texts of the LaTeX Panel and the Matrix Panel, the menu shortcuts, the command completion list, the spelling exclusions or the standard themes, is missing, or is found damaged when TeXShop starts, TeXShop puts its own copy in its place without an error message. A damaged file is moved to the folder ~/Library/TeXShop/Backups, in a folder named after the date and time, so that you can recover your changes from it.

Files you may delete on purpose, such as templates, stationery, engines and your own themes, are not restored.
