Find in TeX Sources

A document split into a root file and chapter files can be searched, and replaced in, in all its files at once. With one of its files in front, choose Edit › Find › Find in TeX Sources with the Same TEX root…; when the root file itself is in front, the item is Find in TeX Sources with This File as TEX root…. The same item is in the menu of Find All in the Advanced Find Panel, and Apply to TeX Sources with the Same TEX root… in the menu of Replace All in the Multiple Replace window opens the window with the set chosen there. The items are dimmed for an untitled document and for a file whose name does not end in .tex.

Which files are searched

The window searches the root file and the .tex files in its folder and the folders below it that name it in a % !TEX root line among their first 20 lines; see Setting a Project Root File. The line under the modes says which root file is searched, and its ? button repeats this rule. Files named in \input or \include are not followed, and a root file named in a .texshop file is not used. Symbolic links to files, folders reached through symbolic links or aliases, and the folder TeXShop Backups are left out.

The list on the left shows the files; turn off a file or a folder there to leave it out. If some files or folders could not be read, the button Files not read at the bottom lists them with the reason.

Finding and replacing

The find and replace fields and the options are those of the Advanced Find Panel. Choose a mode:

  • Find lists every match with its line number.
  • Replace shows each line before and after the replacement. Every match has a check box; a match turned off is not replaced.
  • Multiple Replace applies a set of the Multiple Replace window and lists the groups of changed lines, each with one check box. Edit… opens the set in that window.

Click a row to show the match in its document; double-click it to bring that window to the front. The list follows your changes, and the ↻ button (⌘R) collects the files again. The stop button, the Escape key or ⌘. stops a long search.

A document that is open is searched as it is on the screen, with its unsaved changes; a file that is not open is read in the encoding TeXShop would open it in. Some files can only be searched, not replaced in, for example a file that cannot be written or that its encoding cannot save back unchanged. They are marked ⊘, and the mark gives the reason.

Replace All

Replace All asks before it replaces. If a file has changed in the meantime, nothing is replaced and the list is made again. With Save backups on, each file to be changed is first copied into the folder TeXShop Backups, in a folder named after the date and time, next to the root file.

Files that are not open are then written directly, in their own encoding and with their line endings and permissions; this cannot be undone. Open documents are changed on the screen and are not saved, and one Undo in a document takes back its replacements. Stopping Replace All leaves the files already done replaced and the others unchanged. Afterwards the files are searched again, and the line at the bottom says how many matches were replaced. If some files could not be changed, a sheet lists them with the reason, and Show in Finder opens the folder of the backup.

Do not run Replace All while another application keeps writing these files.
