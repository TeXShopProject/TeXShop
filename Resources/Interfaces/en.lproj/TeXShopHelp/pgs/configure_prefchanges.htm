Engine Profile in Typesetting sets the typesetting commands for one kind of TeX engine, the BibTeX engine, the index program, MetaPost and otf package support; the Japanese profiles also set UTF-8 as the encoding for new documents, the dictionary and UTF-8-MAC conversion. Other settings stay as they are. Choosing a profile asks for confirmation; Use latexmk runs BibTeX, the index and further passes as needed. The menu shows Custom as soon as any setting of the profile is changed. Escape cancels. Detect Paths in the same category sets the paths to TeX and Ghostscript. To keep an original theme, duplicate it before editing. Creating a theme asks for a name; replacing an existing theme requires confirmation. Theme changes reach open documents after saving succeeds. If saving fails, the last saved colors are restored.

Auto Save and Versions takes effect after restarting TeXShop. Switching between the standard Find Panel and Find Bar updates the source, console and log views of open documents immediately. Switching to or from OgreKit takes effect after restarting TeXShop.

Users should consider changing a small number of default settings provided by TeXShop. Some of these changes depend on characteristics of individual displays and cannot be set until you use the program.

By default, TeXShop opens source and preview windows in the spot they last appeared. This only makes sense when you deal with one document at a time. It is usually better to open source and preview windows in a predetermined optimal position. To make that happen, typeset a simple document. Then arrange the position and size of the source and preview windows. Side by side is best if your screen is large enough. Open TeXShop Settings. In the "General" category, select "All Windows Start At Fixed Position" and click "Set With Current Position." Make the same change in the "Preview" category.

A later addition to TeXShop makes this easier. Instead of opening TeXShop Settings, activate the source window and then choose ``Save Source Position'' in the Source Menu. Then activate the preview window and select ``Save Preview Position'' in the Preview Menu.

If you have a portable connected to a large monitor, the above commands will configure for display on the large monitor. It is possible to also configure for trips when the portable is used by itself without the monitor. This configuration can be done with the large monitor attached, or without. Arrange the source and preview windows as desired on the portable screen. Activate the source window and select the menu item ``Save Source Position for Portable'' in the Source Menu, Then activate the preview window and select ``Save Preview Position for Portable'' in the preview window.
