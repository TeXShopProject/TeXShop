Recommended Changes to Settings

TeXShop works with its default settings, but a few of them depend on your TeX installation, your screen and your habits. They are worth checking first. Choose TeXShop › Settings… to open the Settings window; Using Settings and Search Settings explains how to find a setting.

Choose an engine profile

Settings › Typesetting › Engine Profile sets up typesetting in one step. Choose the profile of the engine you use; the less common ones are under Other. A sheet lists the values the profile sets and marks those that change. Turn off any value you want to keep, then click OK; Cancel changes nothing.

Choose “With latexmk” to have latexmk run BibTeX, the index program and further passes as needed; otherwise each typesetting runs the engine once. A profile sets the typesetting method and its typesetting commands, the kpsewhich command, the BibTeX engine, the index program, MetaPost and “Convert to otf Package \UTF / \CID”. The Japanese profiles also set UTF-8 as the encoding for new documents, the spelling dictionary and conversion of UTF-8-MAC. Every other setting stays as it is. When you change one of these settings later, the menu shows Custom; choose the profile again to go back to its values.

The paths to TeX and Ghostscript are set apart, with “Detect Paths…” in the Paths group of the same category. When TeXShop starts for the first time, it asks for the paths and then for an engine profile.

Typesetting commands

The commands that a profile sets are in the Direct PDF and Via DVI groups of Settings › Typesetting, each with a plain TeX and a LaTeX command, and “Typesetting Method” chooses which group is used. Typeset › Direct PDF and Typeset › Via DVI switch the method for the active document only. The default commands already contain -file-line-error, which lets TeXShop take you to the line of an error, and -synctex=1, which makes synchronization between source and preview work, so most people never edit them. If a document needs -shell-escape, see Shell Escape Protection first.

Choose the find interface

Settings › Editor › Find interface chooses the window or bar that Find opens. “Advanced Find Panel (recommended)” finds with regular expressions, lists all matches and replaces several pairs of strings at once; see Find and Replace. The Apple Find Panel and the Apple Find Bar are the standard find of macOS, and “OgreKit Find Panel (Legacy)” remains available. A new choice takes effect at once, except a switch to or from the OgreKit Find Panel, which takes effect after restarting TeXShop. Turn on “Keep the Advanced Find panel on top” if the panel should stay in front of the document windows.

Keep autosave on

“Enable Autosave and Versions” in Settings › Documents and Saving is on by default, and keeping it on is recommended. macOS then saves your documents while you work, and File › Revert To › Browse All Versions brings back earlier versions. If you turn it off, the file changes only when you save it; “Keep the previous file as “name~” when saving” then keeps the previous version beside it. A change of this setting takes effect after restarting TeXShop.

Fix the window positions

By default each window opens where it was when it was last closed. If you usually work on one document at a time, it is better to open the windows at a fixed place. Typeset a short document and arrange its source and Preview windows, side by side if the screen is wide enough. Then, in Settings › General › Window Positions, choose “All windows start at fixed position” for Source and for Preview and click “Set with current position” on each row. The Console and HTML rows work the same way.

The menu commands Source › Save Source Position and Preview › Save Preview Position do the same from the windows themselves. If you use a portable Mac with a large display, arrange the windows for the built-in screen and choose Source › Save Source Position for Portable and Preview › Save Preview Position for Portable as well; TeXShop then uses those positions when the large display is not connected.

Fonts and colors

The font of the source window is set in Settings › Editor › Document Font, and the font of the console in Settings › Console. Settings › Themes chooses and edits the color themes of the source, Preview and console windows; see Syntax Highlighting.
