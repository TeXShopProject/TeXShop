Installing TeX Live

TeXShop needs a TeX distribution. The standard one is TeX Live, which TeX user groups produce every year for macOS, Windows, Linux and other systems. On the Mac it is installed with MacTeX, an installer package made by the TeX Users Group (TUG):

https://tug.org/mactex/

The page offers two packages. Double-click the one you downloaded and follow the installer; when it ends, TeX is ready to use.

MacTeX
The complete TeX Live, with Ghostscript, and TeXShop and other applications in /Applications/TeX. Almost any example from a book about TeX or LaTeX works without adding anything. Choose this package for real work.
BasicTeX
A small part of TeX Live, enough to try TeX and to typeset many LaTeX documents. It does not install TeXShop; see Installing TeXShop.

Where TeX Live is installed

MacTeX installs TeX Live in /usr/local/texlive/2026, and BasicTeX in /usr/local/texlive/2026basic. The two can be installed side by side. A new TeX Live comes out every year, around April, in a folder named after its year. To remove an installation, drag its folder to the Trash.

The installer also makes /Library/TeX/texbin, which leads to the programs of the TeX Live in use and follows a new TeX Live when it is installed. TeXShop runs TeX from there (Settings › Typesetting › Paths › TeX Engines), so nothing has to be changed for a new year. Detect Paths… in the same group looks for the TeX and Ghostscript installations on the Mac and lets you choose one.

Between the yearly releases, the packages of TeX Live receive updates. MacTeX installs TeX Live Utility in /Applications/TeX to install them.

Other TeX distributions

TeXShop also works with TeX installed by MacPorts or Homebrew, or with MiKTeX. Their programs are in other folders: use Detect Paths…, or type the folder in Settings › Typesetting › Paths › TeX Engines. See Coexisting with Other TeX Distributions.
