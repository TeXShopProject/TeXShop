Colored Text

The xcolor package colors text in the typeset document. Load it in the preamble:

\usepackage{xcolor}

Then \color{blue} switches to blue until the end of the current group or environment, and \textcolor{red}{This is very important!} colors just its argument. To define colors of your own, use for instance

\definecolor{mycolor}{rgb}{0.2, 0.7, 0.8}

The option dvipsnames adds a list of named colors, such as BrickRed and ForestGreen:

\usepackage[dvipsnames]{xcolor}

The documentation of xcolor, opened with Help › Show Help for Package…, lists all colors and options.

The color of the pages in the Preview window

Colored text can be hard to read on a white page. The pages in the Preview window can be given another color in Settings › Themes: in the Windows group, the color under “Light Pages” in the Preview row fills the pages while they are shown light. Each theme has its own color, so the Light Mode Theme and the Dark Mode Theme can use different colors.

The color is only for viewing: it is not printed, and it does not appear when part of a page is copied. Pages shown dark with the Appearance item in the toolbar of the Preview window are not filled with this color. The color of the text itself is set by the document, with xcolor as above.
