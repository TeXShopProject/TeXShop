Making and Using TeX Formats

A format file (extension .fmt) is a snapshot of TeX after it has read a set of macros. LaTeX itself is a format: TeX loads it in a moment instead of reading the LaTeX sources every time. You can make a format of your own from a long preamble, so that typesetting starts faster, or use a format that a project or an organization provides.

A format works only with the engine and the TeX Live version that made it. A format made with pdfLaTeX of TeX Live 2026 cannot be used by XeLaTeX or by another year of TeX Live; make it again after installing a new TeX Live.

Making a format

Put the lines that the format should contain in a file, ending with \dump. For example, uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

In Terminal, change to the folder of this file and type

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

This loads the LaTeX format, reads uo.tex and writes uo.fmt. A document typeset with this format leaves out the lines that are in the format and starts with \begin{document}.

Using a format in TeXShop

  1. Move uo.fmt to the folder ~/Library/texmf/web2c, creating the folders if necessary, so that TeX finds it from any folder.
  2. In the Finder, open ~/Library/TeXShop/Engines (TeXShop › Open ~/Library/TeXShop), duplicate an engine such as XeLaTeX.engine, and rename the copy, for instance Oregon.engine. The name appears in TeXShop and need not match the format.
  3. Open the copy in TeXShop and change its last line so that the engine reads: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Documents opened afterwards list Oregon in the pop-up menu beside the Typeset button. To use the format for one document whatever is chosen there, add this line at the top of the source:

% !TEX program = Oregon

To make it the default, choose “Engine File” in Settings › Typesetting › Engine › Typeset New Documents With, and Oregon in the Engine File menu. See Adding Typesetting Engines.

For a plain TeX format, use pdftex instead of pdflatex in the engine. For a format to be used Via DVI, the engine must also convert the DVI file to PDF, for instance with dvipdfmx "${1:r}.dvi" in a zsh script, because TeXShop shows the PDF file with the name of the source.
