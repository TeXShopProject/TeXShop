AppleScript Macros

A macro whose contents begin with

--AppleScript

or

--AppleScript direct

runs as an AppleScript when it is chosen; the case of the letters does not matter. For example, Macros › Applescript › View pdf with Preview opens the PDF of the active document in Preview, once the PDF has been typeset. Its contents are

--AppleScript direct

tell application "Preview"
  activate
  open POSIX file #PDFPATH#
end tell

Before the script runs, TeXShop replaces #PDFPATH# with the path of the PDF; Defining AppleScript Macros lists all such strings. “View pdf with Adobe Acrobat Reader DC” in the same submenu does the same with Adobe Acrobat.

--AppleScript direct and --AppleScript

A script beginning with --AppleScript direct is run by TeXShop itself. While it runs, TeXShop does not respond to anything else, so the script cannot ask TeXShop to do something that might need your input. For example, it cannot ask TeXShop to run LaTeX: if the file had an error, the console would wait for your input, which TeXShop could not receive.

A script beginning with --AppleScript is run by ScriptRunner, a small program inside TeXShop. Such a script can ask TeXShop to do things that might need your input, because ScriptRunner waits while TeXShop stays active.

So --AppleScript direct suits simple macros, while --AppleScript is needed for scripts that typeset or otherwise work with TeXShop.
