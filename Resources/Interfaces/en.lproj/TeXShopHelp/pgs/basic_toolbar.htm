Toolbar and AppleScript

Changing the toolbar

The source window, the Preview window and the window that shows both have toolbars of their own. To change one, make the window active and choose Window › Customize Toolbar…, or Control-click the toolbar and choose Customize Toolbar… there. Drag items into the toolbar or out of it, or drag the default set to the toolbar to start again. Window › Hide Toolbar hides the toolbar of the active window.

Items of the source window

Typeset, with the Program menu beside it, typesets the document with the program chosen there; there are also buttons for single programs such as BibTeX and Make Index. Templates and Macros insert text (see Templates and Stationery and Macros). Tags and Labels scroll the source to a section or a label. KeyBindings turns key bindings on or off for the document, and Split Source divides the window (Option-click to divide it side by side).

FullPath shows the full path of the file in the title of the window instead of its name alone; click it again to show the name. The choice is kept for windows opened later.

Items of the Preview window

The Preview window has, among others, Previous Page and Next Page, Go to page, Back/Forward, Magnification, Mouse Mode, Search PDF, Drawer, Sync Marks, Split Preview and Appearance, which shows the pages light or dark. Click the word next to the magnification field to open the Magnification menu.

Page Layout chooses Single Page, Two Pages, Continuous or Continuous Two Pages for the document. Two-Page Arrangement chooses, for the document while it is open, whether two pages run left to right or right to left and whether the first page is shown alone as a cover; Restore Document Settings in this menu returns to Settings and the magic comment lines of the document. Zoom to Content and Zoom to Content Width change the magnification once so that the typeset part of the page, without its white margins, fits the window or its width. See The Preview Window.

Preview › Show Annotation Toolbar shows a second toolbar below the toolbar, with the tools for adding notes, highlights and shapes to the PDF. Click the close button at its right end, or choose Preview › Hide Annotation Toolbar, to remove it. Annotations are described in the TeXShop Manual (Help › TeXShop Manual).

AppleScript

TeXShop can be controlled with AppleScript: scripts can typeset documents, run BibTeX and MakeIndex, and work with the text of the source. AppleScript macros in the Macros menu run such scripts; see AppleScript Macros. The commands TeXShop understands are explained in Help › Older Documents › Notes on Applescript in TeXShop, and listed in the scripting dictionary of TeXShop, which Script Editor opens with File › Open Dictionary.
