Preliminaries

TeXShop is a macOS application for writing documents in TeX and LaTeX. You write the source in an editor window, typeset it with a click or ⌘T, and read the result in a Preview window beside it. A Command-click in either window shows the matching place in the other.

TeXShop does not contain TeX. It runs the programs of a TeX distribution, normally TeX Live, which the MacTeX installer puts on the Mac; see Installing TeX Live. TeXShop requires macOS 14.6 or later.

As installed, TeXShop typesets LaTeX documents with pdfLaTeX, which writes a PDF file directly, and the Preview window shows that file. It is an ordinary PDF file that can be sent to others and read on any computer. To typeset with another engine, such as LuaLaTeX, choose an engine profile in Settings or name the engine at the top of the document; see Typesetting Documents.

What this help contains

Basic Help
Installing TeX Live and TeXShop, typesetting, the Preview window, editing, finding and replacing, spell checking, key bindings and command completion, the panels, macros, printing and Settings.
Advanced Help
Typesetting engines, projects with a root file, BibTeX and MakeIndex, encodings, external editors, syntax highlighting and other topics.

How do I configure TeXShop?
Recommended settings, new items for ~/Library/TeXShop, hidden settings, key bindings and keyboard shortcuts.

The Help menu opens further documents. The TeXShop Manual describes every feature in detail. First Steps with TeXShop is a short introduction for new users. About This Release tells what to do after an update, if anything, and Changes lists what each version changed. Comment Lines and Hidden Settings lists the magic comment lines, such as % !TEX program =, and the settings that the Settings window does not show.

The TeXShop web site is texshop.app.
