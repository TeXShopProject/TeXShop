Obtaining New Library Items

TeXShop keeps the files you can change, such as templates, macros, engines, key bindings, the LaTeX Panel file and themes, in ~/Library/TeXShop, the TeXShop folder of the Library folder in your home folder. TeXShop › Open ~/Library/TeXShop opens it in the Finder. When TeXShop runs for the first time, it creates this folder with default contents.

What a new version changes

A new version of TeXShop leaves most of ~/Library/TeXShop alone, so your changes are kept. A few places hold TeXShop's own support files or optional items, and a new version brings them up to date:

  • the folders bin, Documents, ExternalEditorScripts and Scripts;
  • Engines/Inactive and HTML/Inactive, which hold engines and HTML files you can move into use;
  • HTML/Help.html, the page shown by Help › HTML Commands;
  • the folder New, which is replaced as a whole.

In these places every file that comes with TeXShop is replaced by its new version, so changes you made to such a file are lost; new files are added, and files you added under other names stay as they are. To keep your own version of one of these files, save it under another name.

The engines in use, in the Engines folder itself, are not changed. Only when the folder was last updated by a version of TeXShop older than 6.00 does TeXShop add html.engine to Engines, once, and only if no file of that name is there. In the Macros folder, a few macros that came with TeXShop and were never edited, such as the one that opens the TeXShop web site, are updated to their current text; edited macros and your own macros stay as they are. Everything else keeps your changes.

TeXShop records its version in a hidden file .Version in ~/Library/TeXShop/New and updates the folder only when it is newer than the version recorded there. So ~/Library/TeXShop is not rewritten each time TeXShop starts, and an older version of TeXShop can be run without changing it.

The New folder

The folder New contains items that you may want to add yourself, for instance new templates. Move such an item to the right folder, such as Templates, and edit it as you like. Help › About This Release says when there is something to pick up.

Missing and damaged files

When a file that TeXShop needs, such as the macros, the LaTeX Panel file, the key bindings, KeyEquivalents.plist or a theme, is missing or damaged, TeXShop replaces it with its own copy when it starts, without a message. The damaged file is kept in ~/Library/TeXShop/Backups, so you can recover your changes from it.

Getting the default contents of a folder

To get the latest default contents of a folder, for instance Templates, quit TeXShop, move that folder out of ~/Library/TeXShop (to the desktop, say) and start TeXShop again. It creates the folder with its default contents. Then copy back from the moved folder whatever you want to keep.
