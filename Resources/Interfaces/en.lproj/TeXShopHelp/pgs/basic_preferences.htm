Changing Settings

Choose TeXShop › Settings… (⌘,) to change how TeXShop works. The sidebar of Settings lists ten categories: General, Documents and Saving, Editor, Keyboard, Spell Checking, Themes, Typesetting, Console, Preview and Updates. Each category starts with a short overview and arranges its settings in named groups. Back and Forward, or ⌘[ and ⌘], return to the categories you visited while Settings is open.

Settings decide how documents start; menu commands change only the active document while it is open. For example, Source › Show Line Numbers shows or hides the line numbers of the active window, while Line Numbers in Settings › Editor decides whether documents open with line numbers. Settings of this kind are collected in the group When a Document Opens at the top of the Editor and Preview categories.

Changes are saved as you make them; a text field takes its value when you press Return or leave the field. Enable Autosave and Versions, and switching to or from the OgreKit Find Panel, take effect after TeXShop restarts.

Search Settings

Type in Search Settings at the top of the sidebar to find a setting, an option or a menu command. Each result shows the name of the item and its category. Words separated by spaces must all describe the same item, and the name of a category narrows the search. Case, Latin accents, fullwidth characters and the difference between hiragana and katakana are ignored. Select a result to go to the setting, which is highlighted; Back then returns to where you were. Clearing the search keeps the category on screen. A menu command opens Keyboard with the command in its list, where its shortcut can be changed.

General

Startup chooses whether TeXShop opens an empty document when it starts without a file (Open Empty Document). Configure for External Editor is for writing the source in another editor: TeXShop then shows only the preview of a source file; see Using an External Editor.

Windows chooses whether the source and the preview of a document open in separate windows or in one window, on which side of that window the source is (“Source position in the combined window”), and whether new windows open as tabs (see Windows and Tabs). Window Positions chooses where the source, Preview, console and HTML windows open; “Set with current position” uses the place and size of the window that is open now. Project Root File opens the root file of a project when one of its chapter files is opened; see Setting a Project Root File.

Dock Icon While Running chooses the icon TeXShop shows in the Dock: the current one or one of the earlier designs. Advanced has the button “Open the Comment Lines and Hidden Settings Manual…”, which opens the document that lists magic comment lines and the settings not shown in this window; see Hidden Settings.

Documents and Saving

Encoding for new documents is Unicode (UTF-8), the right choice for almost everyone. When a file without an encoding line is opened, TeXShop detects its encoding; a line % !TEX encoding = … at the top of a file, written for you by Macros › Encoding, fixes the encoding of that file. Show Encoding in Save Dialog adds an encoding menu to the Save dialog. See Encodings.

Enable Autosave and Versions turns on the macOS feature that saves your edits while you work and keeps earlier versions. “Keep the previous file as “name~” when saving” keeps a backup of the file as it was before each save: for paper.tex, the file paper~.tex. Automatically convert UTF-8-MAC to UTF-8 combines characters stored in separate parts, such as か (U+304B) followed by the combining voiced sound mark (U+3099), into single characters, here が (U+304C), when saving.

Editor

Document Font sets the font of all source windows; a monospaced font keeps columns of source lined up. In the same Display group, Line Number Size makes the line numbers small or large, and “Tags Menu in Menubar” puts the Tags menu in the menu bar. The Style group sets the width of a tab, whether Indent and Unindent use tab characters (Use Tabs for Indent Menu), the indentation of paragraphs that are written without line breaks and the spacing between lines; open source windows show the change at once. Typing has Select on Activate, which decides whether the click that brings a source window forward also moves the insertion point, “Enclose selected text when typing a bracket”, and “Right-to-left languages (Arabic, Hebrew, Persian)”, which aligns lines in these languages to the right; see Encodings. Syntax Highlighting has switches for @ in command names, expl3 code, fullwidth characters and index entries; the colors are set in Themes. Find chooses the find interface and whether the Advanced Find panel stays in front of other windows (“Keep the Advanced Find panel on top”); see Find and Replace. XML Tags in the Tag List chooses which tags of an XML document the Tags menu lists.

When a Document Opens decides whether new source windows show line numbers, highlight the current line, wrap lines, show invisible characters and use the block cursor. The Source menu changes these for the active window. The Insertion group sets the color of the block cursor, on which side of the insertion point it is drawn, and how wide it is.

Matching brackets

When you type a closing bracket, TeXShop shows its partner, so you can check that the pairs in a formula match. The Matching Brackets group chooses which pairs are checked and how the partner is shown: highlighted briefly (Parens Matching), blinking (Blink Highlight), with the text between the pair colored (Highlight Enclosed Characters), or also when the insertion point moves next to a bracket (Show Indicator in Moving). Beep for Isolated Parens and Flash Back for Isolated Parens warn when a closing bracket has no partner. Double-clicking a bracket selects everything up to its partner. The colors are Enclosed and Braces in the Highlights group of Themes, and Flash in its Source group.

Invisible characters

Source › Show Invisible Characters shows spaces, Japanese spaces, newlines and tabs in the active window, which helps when text behaves in a puzzling way. The Invisible group of Editor chooses which of them are shown and the symbol used for each; Show Invisible Characters under When a Document Opens shows them in every document. Their color is Invisible in the Highlights group of Themes.

Keyboard

Keyboard holds the key bindings, which replace a typed character with a text such as {} (see Key Bindings); command completion and its trigger key, with “Edit Command Completion…” for the list of completions (see Command Completion); the completion of labels and citation keys; and the shortcuts of all menu commands, which can be changed here (see Redefining Keyboard Menu Shortcuts).

Spell Checking

Check Spelling sets spell checking while typing, automatic correction and the dictionary. Under Method, choose “Use LaTeX-aware spell checking (recommended)”, which skips comments, mathematics, commands and the arguments of commands such as \label and \cite; “Edit LaTeX exclusion rules…” changes what it leaves out. “Legacy method” has three options of its own. See Checking Spelling.

Themes

A theme is a set of colors for the windows, syntax highlighting, matching brackets, invisible characters and other highlights. Light Mode Theme and Dark Mode Theme choose the theme used in each appearance of macOS. Below them, the list of themes can add, duplicate, rename, delete, restore, export and import themes; select a theme to change its colors. Changes to a theme are saved at once.

In Themes you set the background, text and cursor colors and the opacity (Alpha) of the source, preview and console windows, and the color of the selection in the source. Under the cursor and selection colors, “Use system color” uses the accent color and the highlight color chosen in System Settings › Appearance instead; when it is unchecked again, the theme’s own color comes back. Alpha uses a slider and a numeric field from 0% to 100%. Enter a whole percentage and press Return or leave the field to apply it. The arrow buttons beside the field raise or lower it by one percent. Values outside this range are adjusted to the nearest limit. Invalid text, including decimal values, restores the previous value when you finish editing; typed and pasted input follow the same rule.

See Syntax Highlighting for the colors of the source.

Typesetting

The quickest way to set up typesetting is an engine profile. Choose a profile, such as pdfLaTeX, LuaLaTeX or upLaTeX + dvipdfmx, in the Engine Profile menu at the top of the Engine group. A sheet lists the values the profile sets; turn off a value to keep its current setting, choose whether LaTeX runs with latexmk, and click OK. A profile sets the typesetting commands and method, the kpsewhich command, the BibTeX engine, the index program, MetaPost and the otf conversion; the Japanese profiles also set the encoding for new documents, the dictionary and the UTF-8-MAC conversion. Every other setting stays as it is. When the settings match no profile, the menu shows Custom.

The other settings of the Engine group choose what the toolbar selects beside the Typeset button when a document opens (Typeset New Documents With), the engine file used when Engine File is chosen there, and the Typesetting Method: Direct PDF, Via DVI or Personal Script. A % !TEX program line at the top of a document takes precedence. Alternate Engine is the engine that Typeset › Typeset with Alternate Engine uses; see Adding Typesetting Engines. After Typesetting chooses which window comes forward when typesetting ends: Bring Preview Forward, Continue Editing, or Show Preview and Return to Original Window. Source and Preview Synchronization chooses the Sync Method and whether files reached by Sync open as tabs in the window of the root file; see Synchronizing Source and Preview.

The Direct PDF and Via DVI groups hold the plain TeX and LaTeX commands that each method runs, with their options. If you add -shell-escape to a command, turn on Confirm Shell Escape to be asked before such a document is typeset; see Shell Escape Protection. The Personal Script group holds the commands of the Personal Script method. Related Tools holds the commands for BibTeX, the index and MetaPost. See Typesetting Documents and Alternate Typesetting Mode.

Paths holds the folders of the TeX programs (TeX Engines, usually /Library/TeX/texbin) and of Ghostscript, and Second TeX Engines, a second folder of TeX programs used for documents that contain the line % !TEX useAlternatePath. “Detect Paths…” looks for TeX Live and Ghostscript in the usual places, lists the installations it finds with their versions, newest first, and sets the one you choose. TeXShop also does this when it is first used. The Japanese pLaTeX group is described in Typesetting in Japanese.

Console

Console sets the font of the console, also for the Macro Editor if you like, and when the console appears: always while typesetting, or only when an error occurs. Console Resize chooses whether the console window can be resized in both directions or only vertically.

Preview

When a Document Opens sets how new Preview windows show a document: the display format, the magnification, the mouse mode, link popups, and the direction of two-page layouts. The other groups set page turning and link popups, refreshing when another application changes the PDF, the format of copied images, and the start page of the HTML window. See The Preview Window.

Updates

TeXShop can check for new versions automatically, daily, weekly or monthly. Turn on “Update to prereleases when available” to receive beta versions too. “Check for Updates...” checks now.
