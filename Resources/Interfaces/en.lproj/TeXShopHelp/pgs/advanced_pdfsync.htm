Synchronizing Source and Preview

Command-click a word in the source window, and the Preview window scrolls to the corresponding place and marks it. Command-click a place in the Preview window, and the source file opens, if necessary, at the corresponding line, which is marked. The colors of the two marks are set in Settings › Themes › SyncTeX, under Preview and Source.

SyncTeX

TeXShop synchronizes with SyncTeX. When TeX is run with the option -synctex=1, it writes a file such as Galois.synctex.gz beside the PDF, which records where each piece of the source ended up on the page. The typesetting commands that TeXShop sets up, the engine profiles and the engines in ~/Library/TeXShop/Engines already use this option; some of the optional engines in the Inactive folder do not. In an engine of your own, add -synctex=1 to the call of TeX (with one or two hyphens; every engine accepts both).

The synctex file contains the full paths of the source files. After a project folder is moved, copied or sent to someone else, synchronization does nothing until the document is typeset again.

SyncTeX is not completely exact: the place you are looking for may be a little before or after the mark.

Projects with several files

In a project whose chapter files name the root file with % !TEX root (see Setting a Project Root File), Command-click in a chapter file goes to its place in the Preview of the whole document, and Command-click in the Preview opens the chapter file that contains the clicked spot. With Settings › Typesetting › Source and Preview Synchronization › “Open files reached by Sync as tabs in the root file’s window” on, a file opened this way joins the window of the root file as a tab instead of opening its own window.

Sync Method

Settings › Typesetting › Source and Preview Synchronization › Sync Method has two choices:

SyncTeX (Recommended)
Uses the synctex file, as described above. This is the default.
Search PDF
Searches the PDF for the text around the click, and the source for the text around a click in the Preview. It needs no synctex file, but it fails where the typeset text differs from the source, as in formulas and text with many commands. To find the file of a spot in the Preview, it searches the files named in the \include and \input commands of the root file. For projects that include files in another way, list them in the root file with lines such as 
% !TEX projectfile = chapter2.tex
% !TEX projectfile = /Users/me/Book/chapter3.tex
A name is a full path or a path relative to the root file; these lines may be anywhere in the root file.

ConTeXt

For ConTeXt, add \setupsynctex[state=start,method=min] to the setup of the document and the line % !TEX useConTeXtSyncParser at the top of the root file; TeXShop then uses ConTeXt’s own synchronization code. See ConTeXt and MetaPost.

To synchronize with a source open in another editor, see Using an External Editor.
