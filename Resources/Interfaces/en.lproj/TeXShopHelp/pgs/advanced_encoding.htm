Encodings

TeXShop edits text in Unicode, so the source window accepts any character of any language. The encoding decides how this text is written to the file on disk and read back. UTF-8 can store every character, and LaTeX, XeLaTeX and LuaLaTeX read it by default. Older files and files from other systems may use another encoding, such as ISO Latin 9 or Shift JIS.

New documents

New documents are saved in the encoding chosen in Settings › Documents and Saving › Encoding › Encoding for new documents. The default is Unicode (UTF-8); keep it unless you exchange files with people who need another encoding.

A document is saved in the encoding it was opened with, so an older file keeps its encoding. Characters that the encoding of a file cannot represent are lost when the file is saved.

Opening files

When a file without an encoding line (see below) is opened, TeXShop detects its encoding. A byte order mark identifies UTF-8 and UTF-16 files. A file of ASCII characters only is read in the encoding for new documents. Otherwise TeXShop uses the encoding that the program which saved the file recorded with it, when macOS has kept this information, and then tries UTF-8, and then the encodings of your languages and the encoding for new documents. An encoding that the source declares, for instance with \usepackage[latin9]{inputenc}, is used as a hint.

Detection is a guess and works best with files that contain a fair amount of text. If it chooses the wrong encoding, close the file without saving, open it again with File › Open…, press Options in the Open dialog, and choose the encoding in its menu; the encoding chosen there is used for the files opened at that time, and the document keeps it. The menu first shows the encoding for new documents; left at that encoding, it does not count as a choice, and the encoding is detected as usual. Then add an encoding line to the file so that it always opens correctly. Detection can be turned off with the hidden setting

defaults write TeXShop EncodingAutoDetection NO

Files are then read in the encoding for new documents.

The encoding line

A line in one of the first twenty lines of a source file fixes its encoding for reading and for saving, overriding everything else:

% !TEX encoding = UTF-8 Unicode

Write the line as shown, with one space before the equals sign; %!TEX encoding =, without the space after %, is read too. The name must be written exactly as in the table below. The Encoding macro in the Macros menu inserts the line for you, with a list of encodings to choose from. The names that TeXworks uses, such as UTF-8 or ISO 8859-1, are also understood.

If the line names an encoding that TeXShop does not know, TeXShop reads the file as UTF-8 and says so. If the line names UTF-8 but the file is not valid UTF-8, TeXShop reports it and opens the file in ISO Latin 9, which reads any file; saving it without changing the line writes the same bytes back, so nothing is lost. To open a file without applying its encoding line, hold down Option while it opens.

Saving in another encoding

To choose the encoding when saving, turn on Settings › Documents and Saving › Encoding › Show Encoding in Save Dialog; the Save dialog then has an encoding menu. Edit › Transformations › Change Encoding chooses the encoding in which the open document is saved from then on. If the file has an encoding line, the line decides; edit the line instead. TeXShop keeps the byte order mark of a UTF-8 file and the byte order of a UTF-16 file.

Converting a file to another encoding loses every character that the new encoding cannot represent, and reading a file in the wrong encoding and saving it replaces its characters for good. Keep a copy of the original. The command line program iconv converts files without changing the original. The document “File Encoding and TeXShop” in the Help menu discusses these questions in more detail.

Right-to-left languages

Arabic, Hebrew and Persian are typed from right to left in the source window. When Settings › Editor › Typing › “Right-to-left languages (Arabic, Hebrew, Persian)” is on and syntax highlighting is on, lines that begin with Arabic or Hebrew script are aligned to the right, and other lines, for instance lines that begin with a LaTeX command, to the left. With the hidden setting

defaults write TeXShop RightJustifyIfAny YES

every line that contains such characters anywhere is aligned to the right. The alignment is only for editing; TeX lays out the typeset text by its own commands. To typeset these languages, use XeLaTeX or LuaLaTeX; see XeLaTeX and LuaLaTeX.

Typing other scripts

To type in another script, add an input source for it in System Settings › Keyboard, under Text Input, and switch input sources with the input menu in the menu bar.
