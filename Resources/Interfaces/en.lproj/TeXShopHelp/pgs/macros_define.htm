Defining New Macros

In the Macro Editor (Macros › Open Macro Editor…), click + below the list to add an item. The menu at the right end of the bar below the list (⋯) adds a submenu or a separator and duplicates the selected items; − deletes them. A new item or submenu is named at once: type its name and press Return. Submenus can be nested to any level. A little practice shows how the editor behaves.

Shortcuts

To give an item a keyboard shortcut, select it and click its shortcut in the list (or double-click the shortcut), then press the new shortcut: Command or Control with a key, or one of F1–F20, with Shift and Option as needed. If a menu command or another macro already uses the shortcut, TeXShop says so below the contents and does not change it; press another shortcut. To remove a shortcut, click “Remove Shortcut” (⊖) in the field or press Delete; Escape keeps the one it had. A shortcut that is inactive because a menu command or an earlier macro uses it is marked with a warning triangle in the list; select the item to see the reason below the contents. See Redefining Keyboard Menu Shortcuts for how menu and macro shortcuts work together.

Placeholders

In the contents, the placeholders that a macro replaces are shown as rounded tokens that say what they stand for, such as “Selected Text”: #SEL#, #INS#, #PASTE# and the marks • of a text macro (see Understanding Default Macros), and #FILEPATH# and the other paths of an AppleScript macro (see Defining AppleScript Macros). The macro keeps them as they are written, so copying and saving work as usual. Type a placeholder, or choose it from the Insert menu below the contents; the help button at its right lists them all. Deleting next to a token deletes all of it.
