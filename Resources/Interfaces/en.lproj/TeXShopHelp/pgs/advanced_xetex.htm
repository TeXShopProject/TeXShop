XeLaTeX and LuaLaTeX

XeLaTeX and LuaLaTeX are versions of LaTeX that read UTF-8 source directly and use the OpenType and TrueType fonts installed on the Mac as well as the fonts of TeX Live. Any script that Unicode encodes can be typed into the source and typeset, provided a font has its characters. Both are part of TeX Live, and both typeset ordinary LaTeX documents without changes.

Typesetting with XeLaTeX or LuaLaTeX

There are three ways, from the most general to the most specific:

  • Engine profile. In Settings › Typesetting › Engine Profile, choose XeLaTeX or LuaLaTeX. The profile sets the LaTeX and plain TeX commands of Direct PDF to xelatex and xetex, or lualatex and luatex, so that the LaTeX choice in the toolbar and Typeset › LaTeX use that engine. A sheet lists the values the profile sets before you confirm.
  • Engine file. The engines LuaLaTeX and XeLaTeX are in the pop-up menu beside the Typeset button. To typeset new documents with one of them, choose “Engine File” in Settings › Typesetting › Engine › Typeset New Documents With, and the engine in the Engine File menu; LuaLaTeX is chosen there at first.
  • Magic comment. A line at the top of the source chooses the engine for that document whatever else is set: 
    % !TEX program = LuaLaTeX

For the Japanese version of LuaLaTeX, see Typesetting in Japanese.

Using the fonts of the Mac

The fontspec package selects fonts by the names they have in the Font Book application. For example:

% !TEX program = XeLaTeX
\documentclass{article}
\usepackage{fontspec}
\setmainfont{Palatino}
\setsansfont{Helvetica Neue}
\begin{document}
Text in Palatino, \textsf{and in Helvetica Neue}.
\end{document}

Without fontspec, or without a font command, both engines use Latin Modern, the standard font of LaTeX. Packages such as polyglossia or babel set up hyphenation and conventions for other languages; their documentation is available with Help › Show Help for Package….

Typing other scripts

To type Greek, Cyrillic, Arabic, Hebrew or other scripts, add their input sources in System Settings › Keyboard and switch between them with the input menu in the menu bar. TeXShop can show lines in Arabic, Hebrew and Persian aligned to the right; see Encodings. Save such documents in UTF-8, the default encoding for new documents.
