Redefining Keyboard Menu Shortcuts

Choose Settings and select Keyboard. Search by Function finds command names and menu paths. Search by Key records a key and lists matching menu commands and macros with their assignment priority. Plain Escape, clicking the mode control again, changing categories, switching windows, or closing Settings ends recording. Choose Show in Macro Editor to edit a macro.

Choose Settings and select Keyboard to edit menu shortcuts. Select a command and click its shortcut (or double-click the command, or press Return), then press the new shortcut. Press Escape to keep the old one. A shortcut must use the Command or Control key, or be a function key F1–F20. If the shortcut is already used by another command, TeXShop says so below the list and does not change it; press another shortcut. To remove a shortcut, click “Remove Shortcut” (⊖) in the field or press Delete. The line below the list shows the default shortcut of the selected command; “Restore Default” and “Restore All…” restore shortcuts. Changes take effect immediately and are kept when TeXShop restarts.

If another menu command uses the default shortcut, Restore Default refuses to restore it; change the other command first.

When “Enable Autosave and Versions” is on in Documents and Saving, macOS adds “Duplicate” and “Close All” to the File menu. Their shortcuts can be changed like those of other commands. “Save As...” then keeps the shortcut macOS gives it and is dimmed in the list; with autosave off, it can be changed too.

For the same key and modifiers, menu commands take precedence over macros, using their customized shortcuts when present. Macros can use keys freed by customization. Assigning or restoring a menu shortcut used by a macro asks for confirmation; the macro remains available in the menu, but its shortcut becomes inactive. The Macro Editor marks inactive shortcuts and shows the conflicting command and key. Saving asks only about newly assigned or changed conflicting keys, including imported macros. You can return to editing, save with those keys inactive, or remove the conflicting keys and save. Among macros, the first occurrence of a key takes precedence. “Shortcut Unavailable” applies only to conflicts between menu commands. In the Preview window, Command-F and Command-G follow Find and Find Next, including custom assignments and removal.

Shortcuts set in KeyEquivalents.plist, described below, remain the defaults. Shortcuts for macros are set in the Macro Editor, and key bindings that insert text are set in the Key Bindings editor.

The keyboard menu shortcuts for TeXShop can be redefined. To do this, read the comments at the top of the file "KeyEquivalents.plist" and make appropriate changes. To do so, edit the file

~/Library/TeXShop/Menus/KeyEquivalents.plist
with TeXShop. Be sure to edit and save in UTF-8 format if you use Unicode characters.

Clicking a result row keeps key recording active. Only the result list scrolls vertically. Inactive results identify the winning assignment and key; macro paths use separators between groups.
