Starting with TeXShop 5.60, the easiest way is to choose "Keyboard Shortcuts…" in the TeXShop menu, just below "Settings…". The window lists the menu commands and their shortcuts, and a search field finds a command by name. Select a command and press "Change…" (or double-click it), then press the new shortcut and choose "Apply"; press Escape to cancel. A shortcut must use the Command or Control key, or be a function key F1–F20. If the shortcut is already used by another command, TeXShop says so and does not change it. "Remove Shortcut", "Restore Default", and "Restore All…" remove or restore shortcuts. Changes take effect immediately and are kept when TeXShop restarts.

Keys used by macros take precedence. If a saved shortcut is already used by another command when TeXShop starts, for instance because a macro was given the same keys, the shortcut is kept but not used, and the window lists the command after "Shortcut Unavailable". "Restore Default" is refused while another command uses the original shortcut; change that command first. In the Preview window, Command-F and Command-G follow the shortcuts of "Find…" and "Find Next"; if one of them is removed, it no longer works in the Preview window either.

Shortcuts set in KeyEquivalents.plist, described below, remain the defaults, and "Restore All…" does not change that file. Shortcuts for macros are set in the Macro Editor, and key bindings that insert text are set in the Key Bindings editor.

The keyboard menu shortcuts for TeXShop can be redefined. To do this, read the comments at the top of the file "KeyEquivalents.plist" and make appropriate changes. To do so, edit the file

~/Library/TeXShop/Menus/KeyEquivalents.plist
with TeXShop. Be sure to edit and save in UTF-8 format if you use Unicode characters.
