Redefining Keyboard Menu Shortcuts

Any menu command of TeXShop can be given a shortcut of your choice, or have its shortcut removed, in Settings › Keyboard. Shortcuts of macros are set in the Macro Editor.

Changing a menu shortcut

Choose TeXShop › Settings… and select Keyboard. The Menu Shortcuts group lists the menu commands with their shortcuts. Select a command and click its shortcut (or double-click the command, or press Return), then press the new shortcut. Escape or Return keeps the old one, and Tab moves on. A shortcut must use the Command or Control key, or be one of the function keys F1–F20. If another command already uses the shortcut, TeXShop says so below the list and does not change anything; press another shortcut. To remove a shortcut, click “Remove Shortcut” (⊖) in the field or press Delete.

Changes take effect immediately and are kept when TeXShop restarts. The line below the list shows the default shortcut of the selected command. “Restore Default” gives the selected command its default shortcut back, and “Restore All…” does this for all commands. If another command now uses the default shortcut, Restore Default does not restore it; change the other command first.

When “Enable Autosave and Versions” is on in Settings › Documents and Saving, macOS adds Duplicate and Close All to the File menu; their shortcuts can be changed like those of other commands. Save As… then keeps the shortcut macOS gives it and is dimmed in the list; with autosave off, it can be changed too.

Finding a command or a key

“Search by Function” finds a command by its name or by its menu path. “Search by Key” finds what a key does: press a shortcut, and the list shows the menu commands and macros that use it, which one is in effect and why the others are inactive. Clicking a result keeps the recording on; plain Escape, clicking the search mode again, choosing another category, switching windows or closing Settings ends it. For a macro, choose “Show in Macro Editor” to edit it. A menu command found with Search Settings opens Keyboard with the command in Search by Function; see Using Settings and Search Settings.

Macro shortcuts

Shortcuts of macros are set in the list of the Macro Editor, as described in Defining New Macros. For the same key and modifiers, a menu command takes precedence over a macro, and among macros the first one with the key takes it. Giving a menu command a shortcut that a macro uses asks for confirmation; the macro stays in the Macros menu, but its shortcut becomes inactive. The Macro Editor marks inactive shortcuts and shows which command uses the key. When you save macros whose new shortcuts are used by menu commands, the Macro Editor lets you go back to editing, save with those shortcuts inactive, or remove them and save.

In the Preview window, Command-F and Command-G follow Find and Find Next, including shortcuts you give them. Key bindings, which insert text when a single character is typed, are set in the Key Binding List of Settings › Keyboard; see Modifying Key Bindings.

Older methods

Two other ways to set shortcuts still work. Settings › Keyboard is easier and is recommended.

KeyEquivalents.plist

TeXShop reads the file ~/Library/TeXShop/Menus/KeyEquivalents.plist when it starts. The shortcuts set there become the default shortcuts in Settings › Keyboard, so Restore Default returns to them. The comments at the top of the file explain its format; edit it with TeXShop, save it in UTF-8 and start TeXShop again.

App Shortcuts of macOS

In macOS System Settings, Keyboard › Keyboard Shortcuts… › App Shortcuts can give a TeXShop menu command a shortcut by its exact title, in the language of your menus. Such a shortcut stops working when TeXShop renames the menu command, so set shortcuts in Settings › Keyboard instead.
