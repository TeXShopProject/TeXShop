Installing TeXShop

TeXShop requires macOS 14.6 or later. MacTeX installs it in /Applications/TeX. It can also be downloaded from the TeXShop web site:

https://texshop.app/

Move the downloaded TeXShop to /Applications or /Applications/TeX. After installing MacTeX, choose TeXShop › Check for Updates... once, since MacTeX may contain an earlier version.

The first launch

When TeXShop starts for the first time, it looks for TeX and Ghostscript and lists the installations it finds, newest first; choose one and click OK. It then asks for an engine profile, which sets up typesetting for the engine you use. Both can be changed later in Settings › Typesetting; see Choosing the engine.

Updates

TeXShop › Check for Updates... looks for a new version. When there is one, TeXShop shows what changed and offers to install it, then restarts where you left off. In Settings › Updates, “Automatically check for updates” and “Check interval” set whether and how often TeXShop looks by itself. Turn on “Update to prereleases when available” to be offered beta versions as well; a beta version of TeXShop turns it on when it first runs.

After an update, glance at Help › About This Release. It tells you when there is something to do by hand, usually nothing.

The folder ~/Library/TeXShop

TeXShop keeps the files you can change, such as the templates, macros, engines, key bindings, the command completion list and the themes, in the folder TeXShop in the Library folder of your home folder. TeXShop › Open ~/Library/TeXShop shows it in the Finder. TeXShop creates the folder when it first runs. If one of the settings files there, such as the macros, the key bindings, the command completion list or a theme, is missing or damaged, TeXShop puts its own copy in place without an error message and keeps the damaged file in ~/Library/TeXShop/Backups.

An update does not change the files you may have edited, such as the macros and the active engines; it renews only a few folders of optional items. When a version brings new macros, engines or other items, About This Release says so, and Obtaining New Library Items explains how to add them.
