Useful Web Sites

TeXShop
The web site of TeXShop.
TeXShop on GitHub
The source code of TeXShop, and the place to report problems (see Sending Bug Reports).
MacTeX
The TeX Live distribution for macOS, with TeXShop and other programs.
TeX Users Group (TUG)
The international TeX user group, home of TeX Live and of many TeX resources.
CTAN
The Comprehensive TeX Archive Network: packages, fonts and their documentation.
TeX Stack Exchange
Questions and answers about TeX, LaTeX and related programs.
learnlatex.org
A short course in LaTeX with examples that can be tried online.
The LaTeX Project
News and documentation from the team that maintains LaTeX.
MetaPost
The MetaPost drawing language.
XeTeX
XeTeX and XeLaTeX, which use the fonts installed on your Mac.
ConTeXt Garden
The documentation and community of ConTeXt.
