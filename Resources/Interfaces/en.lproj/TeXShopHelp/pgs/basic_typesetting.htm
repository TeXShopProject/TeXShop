Typesetting Documents

A first document

Choose File › New. In the toolbar of the new window, choose LatexTemplate in the Templates menu; the window fills with the lines every LaTeX document needs. Write your text between \begin{document} and \end{document}. A blank line starts a new paragraph.

Click Typeset in the toolbar, or press ⌘T (Typeset › Typeset). The first time, TeXShop asks where to save the document. TeX writes several files next to the source, so give each document a folder of its own. TeXShop then runs TeX and opens a Preview window with the typeset document.

From then on, write, typeset, and look at the result. TeXShop saves the source before every typesetting, and the Preview stays at the page you were reading. ⌘T works in the source, the Preview and the console, and ⌘1 (Window › Source ⇔ Preview) switches between the source and its Preview. Settings › Typesetting › After Typesetting chooses which window comes forward when TeX ends.

Opening a .tex file also opens the PDF file of the same name, if there is one. Closing the Preview window leaves the source open, and the Preview returns at the next typesetting; closing the source window closes the document.

The console

While TeX runs, its messages appear in the console. Settings › Console › Show console chooses whether the console comes forward at every typesetting (always) or only when TeX reports an error (when error occurs). File › Show Console (⌘0) brings forward the console of the active document, and ⌘0 in the console goes back to the window you came from. Console text can be selected and copied at any time.

When TeX finds an error, it prints a message at the end of the console and waits for an answer. Type it in the field at the bottom of the console and press Return; Return alone goes on to the next error, and the field lists the other answers TeX accepts. To stop TeX, click Abort in the console or choose File › Abort Typesetting (⌃⌥⌘A).

Finding errors

Goto Error in the console, or Edit › Goto Error (⌃⌘E), scrolls the source to the line of the first error and highlights it; choose it again for the next error. If the error is in another file of the project, that file is opened. Fixing a few errors and typesetting again is often quickest, since one error can cause several others. Goto Error relies on the file names and line numbers that TeX writes with -file-line-error, which the commands and engine files of TeXShop use.

LaTeX writes information for its next run, such as the table of contents and the cross-references, in an .aux file and other auxiliary files, so a document may need two or three runs until every reference is right. An error can leave these files damaged, and the document may then fail to typeset even after the error is fixed. Choose Typeset › Trash Aux & Typeset (⌥⌘T) to move the auxiliary files to the Trash and typeset again, or File › Trash Aux Files (⌃⌘A), which is also a button in the console. See Removing AUX Files.

Choosing the engine

Settings › Typesetting › Engine Profile sets up typesetting for an engine in one step. Choose the profile of the engine you use; a sheet lists the values it sets, and OK sets them. In the sheet, “Run LaTeX” can be set to With latexmk, so that latexmk runs BibTeX, the index and further passes as needed. Once one of these values is changed, the menu shows Custom. The TeXShop Manual lists what the profiles set.

For a single document, choose the engine in the Program pop-up menu next to Typeset in the toolbar. It lists plain TeX, LaTeX, BibTeX, MakeIndex and MetaPost, followed by the engine files in ~/Library/TeXShop/Engines, such as LuaLaTeX and XeLaTeX, and the choice holds for that window. To make it part of the document, put a line like this among the first 20 lines of the source:

% !TEX program = LuaLaTeX

⌘T then always typesets the file with that engine. The name is that of an engine file, or one of pdflatex, latex, pdftex and tex for the built-in LaTeX and plain TeX (see Alternate Typesetting Mode). Macros › Program inserts such a line, with the engine chosen from a list; it writes % !TEX TS-program =, which means the same. Settings › Typesetting › Typeset New Documents With sets the engine of documents without such a line. See Adding Typesetting Engines for engine files.

The Typeset menu also runs BibTeX, MakeIndex and MetaPost on the document; see BibTeX and MakeIndex.

Documents in several files

A book is often split into a root file, which has the preamble, and chapter files that it reads with \include or \input. Put a line such as % !TEX root = ../Book.tex at the top of each chapter file, naming the root file by its path from the chapter file. ⌘T in a chapter file then typesets the root file, and Goto Error and SyncTeX find the right chapter file. See Setting a Project Root File.

Going between the source and the Preview

Command-click a word in the source, and the Preview scrolls to the typeset text and marks it. Command-click in the Preview, and the source comes forward with the matching text marked; in a document with chapter files, the chapter file opens if needed. The match is not always exact, so look around the marked place. The colors of the marks are set in Settings › Themes › SyncTeX.

This uses SyncTeX, which the engines support when run with -synctex=1, as the commands and engine files of TeXShop are; Settings › Typesetting › Sync Method should be SyncTeX (Recommended). The SyncTeX file of a document records where its files are, so after a project folder has been moved, typeset once more before syncing.

Arranging the windows

Window › Use One Window puts the source and its Preview side by side in a single window, and Window › Use Separate Windows separates them again. To open every document this way, set Settings › General › Windows › Source and Preview to Use One Window; “Source position in the combined window” puts the source on the left or the right. Drag the divider to give the source more or less room; TeXShop opens every combined window with the same share. A chapter file with a % !TEX root line stays in separate windows; the root file itself can use one window. File › New opens only a source window: typeset the new document first, then choose Use One Window.

With separate windows, place and size the source and Preview windows as you like, then choose Source › Save Source Position and Preview › Save Preview Position; new windows open there.
