LaTeX Panel

Window › LaTeX Panel… opens a panel of LaTeX code: mathematical symbols, Greek letters, functions, accented and international characters, environments and typeface commands. Click in the source where the code should go, then click a button in the panel. Its code is inserted at the insertion point. The panel stays in front of the source windows while you work.

The buttons are arranged on pages. Choose a page with the buttons at the top of each part of the panel: Math, Greek, Symbols, Functions and International, and Environments, Typeface and Custom.

If text is selected when you click a typeface or environment button, the selected text goes inside the inserted code, as in \textbf{selected text}.

Some symbols need the amssymb package. Add this line to the preamble of a document that uses them:

\usepackage{amssymb}

Customizing the panel

The code each button inserts is kept in ~/Library/TeXShop/LatexPanel/completion.plist. Open this file in TeXShop to change it; the comments at its start explain how it is organized. The names of the standard buttons cannot be changed, but the code they insert can. In this code:

  • #SEL# stands for the selected text;
  • #INS# marks where the insertion point goes after the code is inserted;
  • #PASTE# stands for the text on the clipboard.

The Custom page has room for up to sixteen buttons of your own. Each is defined in the Customized list of the file by two strings, the name of the button and the code it inserts:

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Save the file in UTF-8, then quit and restart TeXShop to see the changes in the panel. If the file is missing or damaged, TeXShop replaces it with its own copy. See Modifying the Latex Panel and Files in ~/Library/TeXShop.
