Modifying Key Bindings

Key bindings replace a typed character with a text, for example ^ with ^{} and the insertion point between the braces; Key Bindings explains how to use them. This page explains how to change the list.

Turning key bindings on

“Use key bindings (default for new documents)” in Settings › Keyboard decides whether key bindings are on when a document opens; it is off at first. Source › Key Bindings turns them on or off for the active document only, and the optional KeyBindings toolbar item does the same.

Editing the list

The Key Binding List in Settings › Keyboard shows each input character with its output string. Double-click a cell to edit it in place. Click + below the list to add a key binding and − to delete the selected ones; drag rows to change their order. An input character is a single character. Changes are saved at once and apply immediately, also in documents that are already open; Edit › Undo reverts them.

An output string can contain these symbols, which the list shows as small labels:

#SEL#
the text that was selected when the key was typed
#INS#
where the insertion point goes
#PASTE#
the text on the clipboard
•
a mark, which Edit › Marks can move to

Add them with the Insert menu below the list, or type them as written above; Option-Return types a line break and Option-Tab a tab. The ? button beside the list shows all of them. Copying an output string copies the symbols as written above.

A check in the Paste column applies a key binding to pasted text as well: while key bindings are on for the document, each occurrence of its input character in text pasted or dropped into the source is replaced by its output string. Key bindings whose output string contains #SEL#, #INS#, #PASTE# or a mark cannot be checked.

Returning to the default list

The list is kept in the folder ~/Library/TeXShop/Keyboard. To return to the list that comes with TeXShop, quit TeXShop, move the Keyboard folder to the desktop and start TeXShop again; it creates the folder with its default contents.
