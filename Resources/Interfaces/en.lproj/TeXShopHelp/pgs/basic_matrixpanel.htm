Matrix Panel

Window › Matrix Panel… opens a panel that writes matrices and tables for you. Fill in the entries in its table, choose how the result should look, and insert it into the source at the insertion point.

Making a matrix or table

  1. Enter the size in Rows and Columns, up to 999 each.
  2. Under Environment, choose matrix for a matrix in a formula (an array environment) or tabular for a table of text. With tabular, “Embed in table environment” puts the table into a table float with a caption and a label.
  3. For a matrix, choose the left and right delimiters. The period leaves that side without a delimiter, and the last button uses the delimiter typed in the field beside it.
  4. The two buttons with pictures of a matrix add a border around the entries and lines between them.
  5. Fill in the entries. Clear empties them all; Identity Matrix and Zero Matrix fill them with an identity matrix or with zeros.
  6. Click Insert or press ⌘Return.

Working in the table

The table works like a spreadsheet. Click a cell to choose it, drag or Shift-click to choose several, and type to replace the value; double-click, press F2 or press Control-U to edit it. Return moves down, Tab moves right and the arrow keys move in any direction; Delete empties the cells chosen. Copy and Paste exchange cells with spreadsheet applications. Drag the number of a row to move the row. Undo and Redo work on the table while the panel is active.

When the matrix is made smaller, the cells outside it keep their values, shown in gray, and come back when it is made larger again. Make the panel larger to see more of the table.

Customizing the inserted code

The code the panel writes around the entries is kept in ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist: the beginning and end of the environments, the delimiters, the separators between entries and between rows, the lines of a border or grid, and the letter c that sets the alignment of each column. For example, change c to r to align the columns to the right. Keep the number and the order of the strings in the file, and restart TeXShop after changing it. See Files in ~/Library/TeXShop.
