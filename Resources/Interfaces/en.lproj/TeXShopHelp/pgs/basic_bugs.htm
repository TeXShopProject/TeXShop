Sending Bug Reports

To report a problem or suggest an improvement, open an issue on GitHub:

https://github.com/TeXShopProject/TeXShop/issues

Search the open and closed issues first: the problem may already be known or fixed in a newer version. Opening an issue needs a GitHub account.

A report that can be acted on quickly says:

  • the version of TeXShop (TeXShop › About TeXShop) and of macOS;
  • what you did, what you expected, and what happened instead;
  • for problems with typesetting, a short source file that shows the problem, and the output of the console or the log file;
  • for problems with windows or menus, a screenshot or a short screen recording.

Questions about TeX, LaTeX packages or TeX Live itself are better asked in the places listed in Useful Web Sites, such as TeX Stack Exchange.
