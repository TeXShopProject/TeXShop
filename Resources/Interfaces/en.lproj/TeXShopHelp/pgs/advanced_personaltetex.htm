Adding Personal Files to TeX Live

Style files, classes, bibliography databases and other files that are not part of TeX Live go in your personal TeX tree, the folder texmf in the Library folder of your home folder: ~/Library/texmf. Every program of TeX Live finds the files there, and they take precedence over files of the same name in TeX Live itself. Nothing needs to be registered after a file is added; the next typesetting finds it.

The Library folder is hidden in the Finder. To open it, choose Go › Go to Folder… in the Finder and type ~/Library. Create the folder texmf there if it does not exist yet.

Before adding a package

Most packages on CTAN are already part of TeX Live, and MacTeX installs all of them. To see whether TeX already has a file, choose File › Open Style File… in TeXShop and type its name, such as hyperref.sty; TeXShop opens the file that TeX would use. Add a package to your personal tree only when TeX Live does not have it, or when you need a version of your own. Because your copy takes precedence, remove it when TeX Live has caught up, or you keep using the old version.

Where files go

The folders inside texmf follow the same structure as TeX Live. Create the folders you need:

FolderContents
tex/latex/LaTeX packages and classes (.sty, .cls), each package in a folder of its own
tex/plain/files for plain TeX
tex/generic/files that work with any format
bibtex/bib/bibliography databases (.bib)
bibtex/bst/bibliography styles (.bst)
doc/documentation of the packages you added; Help › Show Help for Package… finds it there

For example, a package of your own macros and your bibliography database would be stored as

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

Then \usepackage{mymacros} and \bibliography{mybibliography} work in every document, wherever it is saved.

Checking the folder

To see which folder your TeX uses as the personal tree, type in Terminal

kpsewhich -var-value TEXMFHOME

On a Mac it is ~/Library/texmf unless the installation was set up otherwise. To see which copy of a file TeX will read, type for instance kpsewhich mymacros.sty.

Do not add files to the folders of TeX Live itself; see More About TeX Live.
