Removing AUX Files

When LaTeX typesets Galois.tex, it writes auxiliary files such as Galois.aux, Galois.toc and Galois.log, which the next run reads for cross-references, the table of contents and the like. If typesetting is stopped in the middle, for instance after an error, these files can be left damaged, and the next run reports errors that are not in the source, often just before \begin{document}. Moving the auxiliary files to the Trash and typesetting again cures this.

Trashing the files

  • File › Trash Aux Files (⌃⌘A), or the Trash Aux Files button in the console, moves the auxiliary files of the document to the Trash.
  • Typeset › Trash Aux & Typeset (⌥⌘T) does this and then typesets. In the Typeset menu, the item appears in place of Typeset while you hold down Option.

The files trashed are those in the folder of the source that have its name and one of these extensions:

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

Files that SyncTeX leaves with (busy) at the end of their name when typesetting is interrupted are trashed as well. The .bbl file of BibTeX is kept.

In a project whose chapter files name a root file with % !TEX root, the files of the root file are trashed, also when the command is given in a chapter file.

Variations

  • Hold down Shift while choosing Trash Aux Files or clicking the button to trash the PDF file of the document as well. Usually the old PDF is kept, so that the Preview window has something to show when typesetting fails.
  • Hold down Option while choosing Trash Aux Files or clicking the button to clean up a whole project: every file with one of the extensions above in the folder of the root file and in all folders below it is trashed, whatever its name. This also removes the .aux files that \include writes for chapters in subfolders.

Two hidden settings change the behavior. To add extensions to the list, for instance dvi, type in Terminal

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

and to return to the standard list

defaults write TeXShop OtherTrashExtensions -array

To make the Option behavior the standard behavior of Trash Aux Files:

defaults write TeXShop AggressiveTrashAUX YES
