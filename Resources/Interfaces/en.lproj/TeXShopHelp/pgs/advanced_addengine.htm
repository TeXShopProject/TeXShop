Adding Typesetting Engines

Besides plain TeX and LaTeX, TeXShop typesets with engines: small shell scripts with the extension .engine in the folder ~/Library/TeXShop/Engines. An engine can run a single program, or a chain of programs, for instance LuaLaTeX, then Biber, then LuaLaTeX twice more. TeXShop comes with engines such as LuaLaTeX, XeLaTeX and pdflatexmk; the subfolder Inactive holds many more.

Choosing an engine

The pop-up menu beside the Typeset button in the toolbar of the source window lists the engines. Choose one and press Typeset or ⌘T. The choice applies to that document only.

To typeset new documents with an engine, choose “Engine File” in Settings › Typesetting › Engine › Typeset New Documents With, and choose the engine in the Engine File menu below it. “Edit Engine List…” opens the Engines folder in the Finder; the Engine File menu follows the folder as you add, remove or rename files. If the chosen engine file is no longer in the folder, the menu shows it as not found and documents are typeset with LaTeX.

To tie a document to an engine, put a line like this in one of its first twenty lines:

% !TEX program = XeLaTeX

The name is the name of the engine file without .engine; tex and latex typeset plain TeX and LaTeX Via DVI, and pdftex and pdflatex typeset them Direct PDF. The line takes precedence over the toolbar, over Settings and over Typeset with Alternate Engine. The form % !TEX TS-program = is read the same way. Write the line exactly as shown, with one space on each side of the equals sign; the Program macro in the Macros menu inserts the line for you, with a list of engine names to choose from. In a project with a root file, only the root file needs the line.

Typeset › Typeset with Alternate Engine (⌃⌥⌘T) typesets once with the engine in Settings › Typesetting › Engine › Alternate Engine, pdflatexmk by default, without changing the toolbar. In the Typeset menu, the item appears in place of Typeset while you hold down Control and Option. It suits documents that are usually typeset in one fast pass and occasionally completely, with latexmk.

Writing an engine

The easiest way to make an engine is to duplicate one in the Engines folder in the Finder, rename the copy, and open it in TeXShop to edit it. An engine file must have the extension .engine and permission to be executed, which a duplicate keeps. Documents opened afterwards list the new engine in their toolbar. Here is XeLaTeX.engine:

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

The first line names the shell or language of the script; zsh, bash, tcsh, Perl and others all work, as long as the script is written in that language. TeXShop runs the engine in the folder of the source file and passes it three values:

$1
The name of the source file with its extension, without its folder, such as main.tex. A script that changes to another folder must note the full path first, for instance as "$PWD/$1". In a project, this is the root file.
$2
The rest of a line % !TEX parameter = … near the top of the source (root file), with several flags separated by spaces, for instance % !TEX parameter = -shell-escape. Without such a line it is a single space.
$3
The folder in the TeX Engines field of Settings › Typesetting › Paths, or the folder in Second TeX Engines when the document contains the line % !TEX useAlternatePath.

When the engine ends, TeXShop opens the PDF file with the name of the source and the extension .pdf in the Preview window, if there is one, and scrolls to the place shown before typesetting. A script that produces other output can say what to show with the following lines, written anywhere in the engine inside a comment of its language:

LineEffect
!TEX-noPreviewno Preview window, even if other lines below are present
!TEX-pdfPreviewshow the PDF file
!TEX-htmlPreviewshow the HTML file of the same name in the HTML window
!TEX-bothPreviewshow both the PDF file and the HTML file
!TEX-noConsoledo not show the console

For example, an engine that runs LuaLaTeX, Biber and LuaLaTeX twice more could read, in zsh, where ${1:r} is the name without its extension:

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

The Inactive folder

The subfolder Engines/Inactive contains engines for special workflows, often with documentation and samples, for instance for latexmk, ConTeXt, Sage, PreTeXt, pythontex and Typst. To use one, move it from its folder to the Engines folder itself. When TeXShop is updated, the Inactive folder is replaced with the current version, while the files directly in the Engines folder are never touched, so engines you edited are kept.

For more about engines, see the chapter “Engines and latexmk” in Help › TeXShop Manual.
