Shell Escape Protection

During typesetting, TeX can run other programs. By default TeX Live allows only a short list of trusted programs, for example to convert EPS graphics to PDF. Packages that need to run other programs ask for the option -shell-escape (also written --shell-escape).

With this option, a document can run any command, for example one that deletes all files in your home folder. Use it only for documents you trust, and not for files you receive from others.

Adding the option

  • In the LaTeX or plain TeX command of Settings › Typesetting › Direct PDF, for every document typeset Direct PDF.
  • In an engine file, for every document typeset with that engine; see Adding Typesetting Engines.
  • For one document typeset with one of the latexmk engines, such as pdflatexmk, with the line % !TEX parameter = -shell-escape at the top of the source.

One engine already has the option: sepdflatexmk, which comes with TeXShop and is in the Engines folder from the start, always typesets with --shell-escape. Choosing it in the toolbar of the source window or with a % !TEX program = sepdflatexmk line is enough, so use it only for documents you trust.

Confirm Shell Escape

Settings › Typesetting › Direct PDF › “Confirm Shell Escape”, off by default, guards the commands of the Direct PDF group. When it is on and the plain TeX or LaTeX command there contains -shell-escape or --shell-escape, TeXShop asks before it typesets a document for the first time after the document is opened:

  • OK typesets with the option.
  • Omit Shell Escape typesets without it.
  • Cancel does not typeset.

Once you choose OK or Omit Shell Escape, the answer holds for that document until it is closed, so you can typeset your own documents with the option and documents from others without it. Engine files are not checked, even if they contain -shell-escape, so sepdflatexmk typesets with the option without asking.
