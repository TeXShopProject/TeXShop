Including Graphics

Typesetting directly to PDF, LaTeX includes graphics in PDF, PNG and JPEG format. PDF keeps line art and text sharp at every size, so use it for diagrams and plots; PNG and JPEG suit screenshots and photographs.

Load the graphicx package in the preamble:

\usepackage{graphicx}

and include a graphic where it should appear:

\includegraphics[width=0.8\textwidth]{diagram}

The extension can be left out; LaTeX then looks for diagram.pdf, diagram.png, diagram.jpg and the other formats it knows. Change the width to change the size of the graphic. Put graphic files in the folder of the document, or give a path relative to it, such as figures/diagram.

EPS files

TeX Live converts EPS graphics to PDF automatically while it typesets, using epstopdf, as long as the document loads graphicx. The converted file, diagram-eps-converted-to.pdf, is written next to the EPS file and used from then on.

An EPS file opened in TeXShop is also converted: TeXShop writes a PDF file of the same name next to it, or in a temporary folder when the folder of the EPS file cannot be written to, and shows it.

TIFF files

LaTeX cannot include TIFF files. Choose File › Convert TIFF while a source window is active: a dialog shows the folder of the document, where only TIFF files can be chosen. Select one or several and click Convert. Each one is converted to a PNG file of the same name in the same folder; the TIFF files are kept.

Typesetting via DVI

Documents that use PostScript code, for example with the pstricks package, are typeset with the Via DVI method, which runs dvips by default. Graphics are then included in EPS format; PDF, PNG and JPEG files cannot be used. The engine profiles whose names end in “+ dvipdfmx” also typeset Via DVI, but they run dvipdfmx instead of dvips; with \usepackage[dvipdfmx]{graphicx}, PDF, PNG and JPEG files can be used there. See Alternate Typesetting Mode.
