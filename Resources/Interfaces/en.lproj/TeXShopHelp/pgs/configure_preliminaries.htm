Preliminaries

This chapter explains how to adapt TeXShop to the way you work: the settings worth checking first, how TeXShop keeps the files in ~/Library/TeXShop up to date, the hidden settings, and how to change the LaTeX Panel, the key bindings and the menu shortcuts.

The Settings window

Choose TeXShop › Settings… to open the Settings window. Its sidebar has ten categories: General, Documents and Saving, Editor, Keyboard, Spell Checking, Themes, Typesetting, Console, Preview and Updates. To find a setting without knowing its category, type a word in the Search Settings field at the top of the sidebar and choose a result: Settings shows the setting and highlights it. See Using Settings and Search Settings.

Many settings have a matching menu command, such as Source › Show Line Numbers and the “Line Numbers” setting in Editor. The menu command changes only the active document while it is open; the setting decides how documents look and behave when they are opened.

Most of what is kept in files can be changed in TeXShop itself. Settings › Keyboard holds the key bindings, the command completion list (“Edit Command Completion…”) and the menu shortcuts; macros are edited in the Macro Editor (Macros › Open Macro Editor…), and color themes in Settings › Themes.

The folder ~/Library/TeXShop

Templates, macros, engines, the LaTeX Panel file, key bindings, the command completion list, themes and other files you can change are kept in ~/Library/TeXShop, the TeXShop folder of the Library folder in your home folder. TeXShop › Open ~/Library/TeXShop opens it in the Finder. A new version of TeXShop keeps your changes there; Obtaining New Library Items explains which files it updates.

When a file that TeXShop needs, such as the macros, the LaTeX Panel file, the key bindings or a theme, is missing or damaged, TeXShop replaces it with its own copy when it starts, without a message. The damaged file is kept in ~/Library/TeXShop/Backups, so you can recover your changes from it.

To go back to the default contents of a folder, quit TeXShop, move the folder (Templates, for example) out of ~/Library/TeXShop, for instance to the desktop, and start TeXShop again. TeXShop creates the folder again with its default contents; copy back from the moved folder whatever you want to keep.

Hidden settings and magic comments

A few settings are not in the Settings window; they are changed with a command in Terminal. See Hidden Settings. Magic comments such as % !TEX program = lualatex at the top of a source file set the engine, the encoding, the root file and more for that file only. Help › Comment Lines and Hidden Settings lists all magic comments and hidden settings.
