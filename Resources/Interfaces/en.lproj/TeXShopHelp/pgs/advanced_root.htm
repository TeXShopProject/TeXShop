Setting a Project Root File

Large documents are often split into several files: a root file with the preamble that includes a file for each chapter. For example, a root file Main.tex could read

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

When you edit two.tex, TeXShop should typeset Main.tex, not the chapter, which has no preamble. To tell it so, put this line in one of the first twenty lines of each chapter file:

% !TEX root = ../Main.tex

The root file itself needs no such line. The name of the root file can be given

  • by its name alone, Main.tex, when it is in the same folder as the chapter file;
  • relative to the folder of the chapter file, ../Main.tex or ../../Main.tex;
  • by its full path, /Users/me/Book/Main.tex, which must be changed when the project moves.

The Root macro in the Macros menu inserts the line: it asks for the root file and offers a relative or an absolute line, replacing an earlier root line.

What the root line does

  • Typeset in a chapter file typesets the root file, and the Preview window of the root file shows the whole document. A % !TEX program line or other magic lines for typesetting belong in the root file.
  • Goto Error opens the file that contains an error, if it is not open, and goes to the line.
  • Synchronization from the Preview window opens the chapter file that contains the clicked spot; see Synchronizing Source and Preview.
  • Trash Aux Files removes the auxiliary files of the root file; see Removing AUX Files.
  • Window › Source ⇔ Preview (⌘1) in a chapter file brings the Preview window of the root file to the front. Pressing it again in the Preview window returns to the source window from which you came, or to the root file if you did not come from a source window.

Opening a chapter file

When a chapter file with a root line is opened, TeXShop also opens the root file and its Preview window. Two items in Settings › General › Project Root File control this: “Open the root file when opening a document” turns it on or off, and “Miniaturize the opened root window” sends the source window of the root file to the Dock, since it is rarely edited while you work on a chapter.

Finding and replacing in the whole project

To search all files of a project at once, choose Edit › Find › Find in TeX Sources with the Same TEX root… in one of its chapter files, or Find in TeX Sources with This File as TEX root… in the root file. It searches the root file and the .tex files in its folder and below that name it in a root line in their first 20 lines. See Find in TeX Sources and Find and Replace.

Root files named in .texshop files

A file with the extension .texshop next to a chapter file, such as two.texshop for two.tex, can also name the root file, and TeXShop still reads it. No menu command creates such files; use a % !TEX root line, which travels with the source.
