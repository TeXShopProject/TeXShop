Experiments

Edit › Experiment… lets you try a short but tricky piece of LaTeX, such as a formula, a table or a TikZ picture, before you put it into the document. It is available when a source window is active.

The command opens a source panel. If text is selected in the source window, it is copied into the panel; otherwise the panel shows what you left in it last time. Type or edit the fragment, for instance $$\sqrt{x^2 + y^2}$$, and press the Typeset button at the bottom of the panel. A preview panel shows the result. The first time it shows the top of the first page; when you typeset again, it keeps the part of the page you are looking at. The fragment can be anything from a formula to several pages.

How the fragment is typeset

TeXShop typesets a file made of the preamble of the document, everything up to \begin{document}, followed by the fragment and \end{document}. In a project with a root file, the preamble of the root file is used. Your document and its folder are not changed:

  • The file is typeset in a temporary folder that holds copies of the files and folders next to the document, so pictures are found as when the document is typeset, also with paths beginning with ./. If the folder of the document holds more than 5000 items, counting those in its subfolders, nothing is copied, and items that cannot be copied this way, such as files on another disk or online-only files of a cloud service, are left out; files next to the document are then still found, but not with paths beginning with ./.
  • A copy of the .aux file of the last typesetting of the document is read, so \ref, \pageref and \cite show the numbers of the document.

The engine is the one the document uses: a % !TEX program line at the top of the source, or else the choice in the toolbar of the source window. With LaTeX, the typesetting method of the document is followed: Direct PDF, Via DVI or Personal Script. If BibTeX or MakeIndex is chosen, pdfLaTeX is used. ConTeXt, MetaPost and plain TeX cannot be used for an experiment. Engines of your own are tried, but they may fail if they do not expect LaTeX or do not produce a PDF file.

The panels

The source panel shows text as the source window does, with the same font, tabs, line spacing, wrapping, syntax colors, current line highlight, block cursor, invisible characters, line numbers and bracket matching, and follows changes to them made in menus or Settings. Source › Font › Bigger (⌘=) and Smaller (⌘-) enlarge or reduce the text; like a font chosen with the Font panel, they change the source window too. Key bindings, command completion and Edit › Complete Label or Citation Key work in the panel. Command completion uses the trigger key chosen in Settings › Keyboard › Completion trigger.

The toolbar of the preview panel has the tools of the Preview window: Scroll, Select Text, Magnify and Select PDF. Magnify shows the page under the pointer at 150% while the mouse button is held, or 200%, 250% and 300% with Command, Option and Control; double-click for a larger glass. With Select PDF, draw a rectangle and copy it in the format chosen in Preview › Copy Format. The panel remembers its tool separately from the Preview window. Beside the tools are Zoom Out, Zoom In, Zoom to Content, which enlarges the typeset part of the page to fill the panel, and Zoom to Content Width, which makes the typeset part as wide as the panel. The panel also scrolls and zooms with the mouse and trackpad gestures.

The output of typesetting appears in a console of its own, the Experiment console. It comes to the front when typesetting starts; click a panel to bring that panel forward again. ⌘0 (File › Show Console) in a panel brings the Experiment console forward, and pressing it again returns to the panel. If Settings › Console › Show console is set to show the console only when an error occurs, the Experiment console stays hidden until TeX reports an error or waits for input.

The panels and the Experiment console float above the document windows. They can be moved and resized, and TeXShop remembers their sizes and places. Close a panel with its close button or ⌘W. Escape also closes the preview panel, and the source panel when command completion uses the Tab key; when Escape is the completion trigger, it completes commands in the source panel instead.

Keeping the result

When the fragment is right, copy it from the source panel and paste it into the document. The panels keep their contents when they are closed and reopened, but not when TeXShop quits, and they cannot be saved.

Each document has its own panels, which carry the name of the document in their title bars. With several documents open, close the panels you no longer need, so that it stays clear which document an experiment belongs to.
