Checking Spelling

TeXShop checks spelling with the spell checker and the dictionaries of macOS. LaTeX-aware spell checking is on from the start: it checks the text and skips TeX commands, mathematics, comments, and the arguments of commands such as \label, \ref, \cite and \usepackage, as well as arguments that are not prose, such as keys, colors and units, of common packages. Commands that the document defines with \newcommand, \def and the like are read, so an argument that a definition passes to \ref or into mathematics is skipped too. Text marked as another language, for example with \foreignlanguage, is checked in that language, but is not underlined while you type.

Checking a document

Misspelled words are underlined as you type while Edit › Spelling and Grammar › Check Spelling While Typing is on. To go through the document word by word, choose Edit › Spelling and Grammar › Show Spelling and Grammar (⌘:): the panel shows the first misspelled word after the insertion point. Click Find Next in the panel, or choose Check Document Now (⌘;), to go to the next one. Hold down Option while doing so to use the search of macOS, which skips no markup.

To replace a word everywhere, type the replacement in the field Replacement for Change All of the panel, or select a suggestion, and click Change All; one Undo takes back the change. Forget Learned Words… in the Spelling and Grammar submenu lists the words of the document that were learned for the current language, and removes the ones you select from the dictionary. Correct Spelling Automatically in the same submenu changes words as you type; it is off at first, which suits TeX, where it would also change commands.

Settings › Spell Checking

In the Check Spelling group, “Check spelling while typing” sets whether misspelled words are underlined in a document when it opens, and “Dictionary” is described below. The Method group chooses how TeX source is checked:

“Use LaTeX-aware spell checking (recommended)”
The method described above. “Edit LaTeX exclusion rules…” at the end of its line opens the rules that say what is skipped.
“Legacy method”
macOS checks everything, except what the three options below it leave out: “Do not check LaTeX commands”, “Do not check selected parameters”, which skips the parameters of some commands with special words, such as \usepackage, and “Do not check comments”. These options work only while syntax highlighting is on, and Check Document Now does not follow them.

Files that are not TeX source, such as Sweave files, are always checked with the legacy method.

Exclusion rules

The rules of LaTeX-aware spell checking are in the file ~/Library/TeXShop/SpellCheck/SpellingExclusions.txt. Open it with “Edit LaTeX exclusion rules…” in Settings or with Edit › Spelling and Grammar › Edit Spelling Exclusions…; it opens in TeXShop, and its top explains the format. For example, these lines skip the first argument of a command \mycommand and the contents of the environment proof:

skip-args  1  mycommand
skip-body  proof

Changes take effect the next time spelling is checked. If the file is deleted, TeXShop makes a new copy of the default file the next time it starts. Help › Spell Checking Help describes spell checking in more detail.

Dictionaries

“Dictionary” in Settings › Spell Checking chooses the dictionary of documents that are opened from then on; documents already open keep theirs. The menu shows each language under its own name, such as Deutsch or Français, with its code, such as de or fr_CA, as the tool tip. Automatic Language lets macOS choose the language from the text.

To use another dictionary for one document, choose it in the pop-up menu at the bottom of the Spelling and Grammar panel while that document is in front. Each open document keeps its own dictionary, and the panel switches when you switch documents. The choice is not kept when the document is closed.

To give a document its dictionary every time it opens, put a line like this among its first 20 lines:

% !TEX spellcheck = de-DE

The value is a language code, as in the tool tips of the Dictionary menu: fr for French, or fr-CA for the French of Canada. The line is read when the document is opened, so save, close and open the document again after adding it. In a document with chapter files, put the line in each file.

See Search Settings for finding settings in the Settings window.
