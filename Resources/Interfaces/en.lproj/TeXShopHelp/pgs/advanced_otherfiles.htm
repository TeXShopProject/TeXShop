Opening Other Files with TeXShop

TeXShop opens any text file, so you can read log files, aux files and other files of TeX next to your documents. It also opens PDF files and pictures.

Files treated as TeX sources

Files with the following extensions, and files without an extension, are TeX sources for TeXShop: they are shown with syntax highlighting and can be typeset.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

Other text files, such as .log, .aux, .bst, .engine or .txt files, open as plain text, without syntax highlighting.

To have TeXShop treat files with another extension as TeX sources, add the extension with a hidden setting in Terminal; for example, for ConTeXt files with the extension mkiv:

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

PDF files and pictures

PDF files and pictures with the extensions .png, .jpg, .jpeg, .tif, .tiff and .eps open in a window of their own. DVI and PostScript files (.dvi, .ps) are converted to PDF and shown.

Saving with another extension

A file keeps its extension when TeXShop saves it. A new document is saved as a .tex file unless you choose another type in the File Type menu of the Save dialog, such as sty, bib or mp.

TeXShop saves a file in the encoding it was opened with. It is meant for TeX and related files; a file in an unusual format may change if it is saved after editing in TeXShop. See Encodings.
