Modifying the LaTeX Panel

The LaTeX Panel (Window › LaTeX Panel…) has a Custom tab with up to sixteen buttons of your own. The names of the other buttons cannot be changed, but the text they insert can.

Both are set in the file ~/Library/TeXShop/LatexPanel/completion.plist. Open it in TeXShop and read the comments at its top, which explain how the file is organized. Each tab has a list of the texts its buttons insert, in the order of the buttons. In these texts, #SEL# stands for the selected text and #INS# for the place where the insertion point goes.

The buttons of the Custom tab are in the list named Customized. Each button is a pair of strings: its name, then the text it inserts. For example,

<string>Section</string>
<string>\section{#SEL##INS#}</string>

makes a button named Section that inserts \section{} around the selected text, with the insertion point inside the braces.

Save the file in UTF-8. TeXShop reads it when the LaTeX Panel first opens, so start TeXShop again to see your changes. Keep every entry of the lists of the other tabs: if the file cannot be used, TeXShop uses its own copy and, at the next start, replaces the file and keeps yours in ~/Library/TeXShop/Backups.
