ConTeXt and MetaPost

ConTeXt

ConTeXt is a macro package by Hans Hagen, an alternative to LaTeX with its own commands and a strong focus on typographic design. TeX Live includes ConTeXt, and the ConTeXt Garden distributes a version, updated often, that installs in your home folder.

The engines for ConTeXt are in ~/Library/TeXShop/Engines/Inactive/ConTeXt, together with the guide Setting-Up-ConTeXt.pdf and sample documents:

EngineTypesets with
ConTeXt.enginethe ConTeXt of TeX Live that runs on LuaTeX
ConTeXt-TL.enginethe ConTeXt of TeX Live that runs on luametatex
ConTeXt-CG.enginethe ConTeXt Garden version in your home folder

Move the engine you need to ~/Library/TeXShop/Engines, and put magic lines at the top of the root file of the document, for instance:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

For ConTeXt-CG, enter the folder of the programs of the ConTeXt Garden installation in the Second TeX Engines field of Settings › Typesetting › Paths, and add the line % !TEX useAlternatePath, which makes TeXShop give that folder to the engine instead of TeX Live.

For synchronization between source and preview, add \setupsynctex[state=start,method=min] to the setup of the document; the line % !TEX useConTeXtSyncParser makes TeXShop use ConTeXt’s own synchronization code. The ConTeXt chapter of Help › TeXShop Manual describes the installation of the ConTeXt Garden version and each engine in detail.

To list ConTeXt section commands such as \title and \subject in the Tags menu, turn on the hidden setting ConTeXtTags; see Hidden Settings.

MetaPost

MetaPost, by John Hobby, draws illustrations from a description in a programming language derived from Knuth’s METAFONT. Its manual is part of TeX Live: choose Help › Show Help for Package… and type metapost.

Typeset › MetaPost (⇧⌘M), or MetaPost in the pop-up menu beside the Typeset button, runs MetaPost on the file with the name of the active document and the extension .mp: on the document itself if it is a .mp file, and otherwise on the .mp file next to it, such as the one that the mfpic package writes for a .tex document. It runs the command in Settings › Typesetting › Related Tools › MetaPost, mpost by default. The engine profiles set this field: pmpost for pLaTeX + dvipdfmx and upmpost for upLaTeX + dvipdfmx, which typeset Japanese text in labels, and mpost for the other profiles. LuaLaTeX cannot include figures whose labels pmpost or upmpost typeset in Japanese; with LuaLaTeX, draw such figures in the document with the luamplib package.

To save a new file as a MetaPost file, choose the mp type in the File Format menu of the Save dialog.

The engine nv-metapost, by Nicola Vitacolonna, makes working with MetaPost easier and shows the figures of a file in the Preview window. It is in ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; the file README.rtf and the folder examples, one level up in MetaPostEngines-1.4.7, explain how to install and use it and give sample files. For instance, a file starting with

% !TEX program = nv-metapost
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

is typeset with nv-metapost once that engine is in the Engines folder.

MetaPost drawings can also be written inside a LaTeX document, with the luamplib package for LuaLaTeX, or with packages such as mfpic, which write the drawings to a .mp file that MetaPost processes between two typesetting runs.
