Hidden Settings

The Settings window has the settings most people need. Less common ones are hidden settings: they have no control in the Settings window and are changed with a command in Terminal. The reference “Comment Lines and Hidden Settings” lists every hidden setting with its command, grouped by topic. Open it with Help › Comment Lines and Hidden Settings, or with “Open the Comment Lines and Hidden Settings Manual…” in Settings › General › Advanced.

Changing a hidden setting

  1. Quit TeXShop.
  2. Open Terminal (in /Applications/Utilities), type the command and press Return.
  3. Start TeXShop again.

Each command has the form defaults write TeXShop name value. To return to the default value, use defaults delete TeXShop name.

Examples

defaults write TeXShop OtherTrashExtensions -array 'nav' 'snm'
File › Trash Aux Files also removes files with these extensions. Give the extensions without the dot. See Removing AUX Files.
defaults write TeXShop ConTeXtTags YES
The Tags menu lists the ConTeXt section commands, such as \title and \subject, instead of the LaTeX ones.
defaults write TeXShop RedConsoleAfterError YES
Text typed in the console to answer a TeX error, and all later output of that run, is shown in red.
defaults write TeXShop RefreshTime 2
While “Always Watch for PDF Changes by Other Apps” is on in Settings › Preview, TeXShop checks every 2 seconds whether a PDF has changed. The default is 1 second and the minimum 0.5.

Settings that are in the Settings window are not repeated among the hidden settings. For example, moving to the next or previous mark of Edit › Marks with Option or Control and the completion trigger key is turned on and off with “Move to the next or previous mark with Option or Control and the trigger key” in Settings › Keyboard. To find such a setting, use Search Settings; see Using Settings and Search Settings.
