Defining AppleScript Macros

AppleScript is a language of its own. Apple's AppleScript Language Guide, on Apple's developer website, describes it in full.

Paths and the document name

Before running an AppleScript macro, TeXShop replaces the following strings with the path of a file of the active document, in double quotes:

#FILEPATH#
the source file
#TEXPATH#
the .tex file
#NAMEPATH#
the source file without its extension
#FOLDERPATH#
the folder that contains the source, ending with a slash
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
the .pdf, .dvi, .ps, .log and .aux files
#INDPATH#, #BBLPATH#, #HTMLPATH#
the .ind, .bbl and .html files

For example, if #FILEPATH# gives /Users/name/Projects/Fourier/Fourier.tex, #FOLDERPATH# gives /Users/name/Projects/Fourier/. If the document has never been saved, #FILEPATH# is an empty string.

#DOCUMENTNAME# is replaced with the name of the document as the title of the source window shows it: with its extension, or without it if the extension is hidden. A script uses it to address the document that called it:

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

TeXShop commands

An AppleScript can do its work in two ways: it can run shell commands, as described in Writing Scripts with Shell Commands, or it can call TeXShop's own commands, as described in Writing Scripts with TeXShop Typesetting Commands. TeXShop understands these commands:

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

The first six commands typeset continuously, without stopping at errors. The next six typeset too, but stop at an error so that you can answer in the console. A typesetting command returns at once, before typesetting is finished. taskdone returns NO while typesetting is still running and YES when it is done. refreshpdf and refreshtext make PDF and text windows show the latest version of their files. goto line selects a line in the source:

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
