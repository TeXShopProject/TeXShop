Coexisting with Other TeX Distributions

Problems may arise when multiple TeX distributions are available on a system, especially if they set environment variables. This may lead to hard to detect problems where other files are used than the ones you expect.

MacTeX uses a data structure which allows multiple TeX distributions to coexist on one machine. The user can select the active distribution with the Reconfigure Distributions command of TeX Live Utility. The data structure sets a symbolic link, /Library/TeX/texbin, which always points to the binaries of the active distribution. Thus GUI programs can be configured once and for all by setting preferences for the binary directory to /Library/TeX/texbin, setting preferences to the location of pdftex to /Library/TeX/texbin/pdftex, etc.

This data structure is automatically installed by any of the MacTeX packages. A TeX Live installed without MacTeX, by the install script of TeX Live, does not create it; in that case set the TeX Engines path in TeXShop Settings > Typesetting > Paths to the binary folder of that TeX Live, or use "Detect Paths…" as described below.

Starting with TeXShop 6.00, TeXShop can find TeX and Ghostscript for you. When TeXShop is first used, and when you press "Detect Paths…" in the Typesetting category of TeXShop Settings, it looks in the usual places, such as /Library/TeX/texbin, the TeX Live folders, Homebrew, and MacPorts, and lists the installations it finds with their versions. The newest one is selected, but you can choose another one for TeX and for Ghostscript separately. The paths change only when you press "OK". Custom engines and the "Second TeX Engines" path are not changed.
