Coexisting with Other TeX Distributions

Several TeX installations can live on one Mac: TeX Live years installed by MacTeX or BasicTeX, a TeX Live installed with its own installer, or TeX from Homebrew or MacPorts. TeXShop uses the one in the TeX Engines field of Settings › Typesetting › Paths, and Ghostscript from the Ghostscript field below it.

Detect Paths

TeXShop can fill in both fields for you. When TeXShop is used for the first time, and whenever you press “Detect Paths…” in the Paths group of Settings › Typesetting, it looks for TeX and Ghostscript in the usual places: the folders listed in /etc/paths and /etc/paths.d and in the PATH of TeXShop, /Library/TeX/texbin, the TeX Live folders in /usr/local/texlive, /opt/texlive and /Applications/TeXLive, the TeX folders of UpTeX.app and pTeX.app, /usr/local/teTeX/bin, and the folders of Homebrew, MacPorts and Fink. It checks that the programs run and lists the installations it finds with their versions, newest first. The newest one is selected, but you can choose another one, separately for TeX and for Ghostscript. The paths change only when you press OK. An installation in another place can still be entered in the fields by hand.

“Detect Paths…” changes only TeX Engines and Ghostscript. Engine files that name their own folders, and the Second TeX Engines field, stay as they are.

TeX Live without MacTeX

The MacTeX and BasicTeX installers make /Library/TeX/texbin point to the TeX Live they install, so programs that use this path follow the newest installation. A TeX Live installed with the installer of TeX Live itself does not change this link. To use such an installation, choose it with “Detect Paths…” or enter the folder of its programs, for example /usr/local/texlive/2026/bin/universal-darwin, in TeX Engines.

Environment variables

Some distributions set environment variables such as TEXINPUTS or TEXMFHOME in shell startup files. TeX then reads files from other folders than you expect, and the same document can typeset differently in Terminal and in TeXShop. If TeX uses a wrong version of a file, check these variables first; in Terminal, kpsewhich followed by the file name shows which copy TeX finds.
