Double clicking on a bracket of the form (, {, [, ], }, or ) will select everything between that bracket and its matching bracket. Double clicking on a bracket with the option key down will select the bracket alone.

The Advanced Find Panel, chosen in Settings > Editor > Find Panel, finds and replaces with regular expressions. Every user starts with it: at the first launch of TeXShop 6.00, users of earlier versions are switched to it once, and can choose another method there again. Users who came from the OgreKit Find Panel find the OgreKit replacement syntax (\1) chosen under More Options. With the panel, the Find submenu of the Edit menu also has Find All (shift-command-F), Select All Matches, Use Selection for Replace (shift-command-E), Replace, Replace and Find (option-command-G), Replace All, Highlight All (shift-command-H) and Remove Highlights (control-shift-command-H); they work while the panel is closed. Find All lists every match in the panel with its line number; clicking a row selects the match. Highlight All, Select All and Remove Highlights are in the menu of Find All. Replace All is undone with a single Undo. The options under the fields and behind the button with three dots are remembered from session to session.

The panel uses the regular expressions of ICU. A brace that is not part of a repetition must be written \{ or \}. In the replacement, $1, $2, ... are the groups and \$ is a dollar sign; the OgreKit syntax, with \1, \2, ... and a literal $, can be chosen among the options. A backslash in the replacement is written twice. The ? button next to Regular expression opens a reference of the syntax and the replacement, and of where ICU and OgreKit differ. The fields use the source font and the colors of the source’s theme. With Regular expression off, they are colored as TeX is in the source; with it on, they show the parts of a pattern in the theme’s colors, errors in red and what OgreKit reads otherwise in orange; the line under the options explains them.

Edit Multiple Replace in the Find submenu keeps sets of find and replace pairs, applied in order with a single Undo. The Multiple Replace… button next to Replace All in the Advanced Find Panel opens it too. The sets are files in ~/Library/TeXShop/MultipleReplace, in the JSON format of CotEditor's replacement definitions. The Multiple Replace submenu applies a set to the whole text at once. Two sample sets, written when the folder does not exist yet, convert between Unicode characters and the commands of ajmacros as Character Type Conversion does, adding % after a command at the end of a line; a sample that was changed or removed is not written again.

Replace All, Find All and Multiple Replace run in the background, and the document cannot be edited until they end. When one takes long, a sheet on the document window shows how many it has found or how many rules it has done; its cancel button, or the Escape key, stops it and leaves the text as it was.

The panel also finds in the console, the log and the Experiment windows. Replacing is dimmed in the console, the log and the Experiment console, which show the output of TeX.

The OgreKit Find Panel by Isao Sonobe remains available as a legacy choice in Settings; switching to or from it requires restarting TeXShop. The TeXShop manual describes the Advanced Find Panel in detail.

Groups of lines can be commented out using a menu command, and later activated again. Groups of lines can be indented with a menu command, and later moved back. If a line starts with a series of tabs or spaces, new lines will start at the same position until the behavior is cancelled by backspacing. This behavior was added to TeXShop by Nicolás Ojeda Bär in Argentina, who can be reached at lojedaortiz@interlink.com.ar. Thanks!

The source window can be split in two pieces using the split tool at the top of the window. When it is split, two views of the same source are shown. You can type in either piece and your changes will immediately appear in the other as well. Thus you can modify one section of source while reading a second part of the source.

TeXShop can be instructed to keep a backup file every time a file is saved. When “Enable Autosave and Versions” is off, turn on “Keep the previous file as “name~” when saving” in Settings > Documents and Saving. The backup has the name of the file followed by a tilde.

A Statistics panel lists the number of words, line, and characters in a document. Internally, this panel calls

detex myfile | wc

The detex command removes tex commands, but the word count is still only approximate. Input and include files are counted automatically by this command.

File icons can be dragged and dropped onto the source text. If the file is a tex file, an \input command will be added with a relative path to the file. If the file is a graphic file, an \includegraphics command will be added instead. The following graphic types are recognized: pdf, jpg, jpeg, tif, tiff, eps, ps.

Dropping a cls file produces \documentclass and a file reference, dropping a sty file produces \usepackage, dropping a bib file produces \bibliographystyle, and dropping other text files produces \input.

Drag and drop resolves aliases. For example, if a graphic file is really an alias, the file can be drag-and-dropped to the source and this source will typeset fine. TeX itself cannot resolve aliases, although it can resolve symbolic links. So if the name of the graphic alias is typed directly into the source, it will cause an error during typesetting.

The behavior of drag and drop is user customizable. Customization is done with the Macro menu. Insert a new submenu titled "Drag & Drop". Inside this submenu place items named with the extension whose behavior you wish to customize, and place the code that should be inserted in the body of this item. For instance, if the item is .pdf, the code might be \includegraphics[#INS#]{%r}. In these inclusions, the following abbreviations may be used:

%F full path of an dropped file
%f dropped filename
%r relative path of the dropped file
%n filename without extension
%e extension.

If an extension is not mentioned in the Macro Editor, then it is handled in the default manner mentioned earlier. Thus for most people, no macro "Drag & Drop" submenu is needed.

Swap with Clipboard in the Edit menu replaces the selected text with the text on the clipboard, and puts the text it replaced on the clipboard. To exchange two pieces of text, copy the first piece, select the second piece and choose Swap with Clipboard, then select the place where the first piece was and paste. When nothing is selected, the command is an ordinary paste.

The submenus Character Type Conversion and Unicode Normalization in the Edit menu, also found in the contextual menu of the source window, rewrite the selected text; if nothing is selected, TeXShop asks whether to rewrite the whole document. Character Type Conversion is mainly for Japanese documents. It converts between hiragana and katakana, between fullwidth and halfwidth digits and letters, between characters such as circled numbers and the commands of the ajmacros package, and between characters outside JIS X 0208 and the \UTF and \CID commands of the otf package. It also changes curly quotes to TeX quotes. Unicode Normalization converts the selection to NFC, NFD, NFKC or NFKD, or to Modified NFC or Modified NFD, which leave CJK compatibility ideographs unchanged. Both commands can be undone.
