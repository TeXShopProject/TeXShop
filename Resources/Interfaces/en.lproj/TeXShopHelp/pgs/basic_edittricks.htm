Editing Tricks

Selecting

Double-click a bracket, such as ( or }, to select everything between it and its matching bracket; this helps to find a brace that is missing. Double-click with the Option key held down to select the bracket alone. Click or drag over the line numbers to select whole lines. The Matching Brackets group of Settings › Editor sets how matching brackets are shown while you type.

Comments and indentation

Source › Comment (⌘{) puts % at the start of the selected lines, and Source › Uncomment (⌘}) removes it. Source › Indent and Source › Unindent move the selected lines right or left, by a tab when “Use Tabs for Indent Menu” is on in Settings › Editor › Style, and otherwise by as many spaces as Tab Size. A new line starts with the same tabs and spaces as the line before it; press Delete to remove them.

Moving around the source

The Tags menu in the toolbar lists the chapters, sections and other divisions of the document; choose one to go there. A line that starts with %: adds the rest of the line to the menu as a tag of your own. “Tags Menu in Menubar” in Settings › Editor › Display puts the same menu in the menu bar. The Labels item of the toolbar lists the labels of the document. Edit › Line Number... (⌘L) goes to a line by its number.

Window › Split Window (⌃2), or the Split Source item of the toolbar, divides the source window into two parts that show the same text, so that you can read one part of the document while you write another. Hold down Option to split it side by side. What you type in one part appears in the other too.

Typing less

Source › Close Current Environment (⌃⌘C) adds the \end line of the environment that is still open, for example \end{itemize} after a list. Command completion finishes commands and environments you have begun to type; see Command Completion. Key bindings replace a typed character with text; see Key Bindings. The LaTeX panel, the Matrix panel and the Macros menu insert longer pieces of text.

Dropping files on the source

Drag a file from the Finder onto the source to insert a command for it:

FileInserted command
.pdf, .png, .jpg, .jpeg, .tif, .tiff, .eps, .ps\includegraphics[]{path}
.bib\bibliography{name}
.bst\bibliographystyle{name}
.sty\usepackage{name}
.cls\documentclass{name}
other files, such as .tex\input{path}

Here path is the path of the file from the folder of the source file, and name is the file name without its extension. A dropped alias is replaced by the file it stands for, which TeX could not find by itself. A file whose path contains a space is not inserted; TeXShop shows a warning instead.

To insert something else for a kind of file, open the Macro Editor (Macros › Open Macro Editor...) and add a submenu named Drag & Drop. In it, add an item named after the extension, such as .pdf, whose content is the text to insert, for example \includegraphics[#INS#]{%r}; an item named .* is used for every extension without an item of its own. The content can use these abbreviations:

%F
the full path of the dropped file
%f
the name of the file
%r
the path of the file from the folder of the source file
%n
the name of the file without its extension
%e
the extension

The status bar and text statistics

The status bar under the source shows the lines, characters and words of the document, with the numbers in the selection in parentheses, and the location, line and column of the insertion point. Characters are counted as they are seen, so an accented letter or an emoji counts as one, and TeX commands are counted as they are written; an emoji also counts as a word. The size of the saved file is shown at the right. Source › Show Status Bar shows or hides the status bar in every window.

Text Statistics… in the status bar, or Edit › Statistics..., counts the text without the TeX commands. The TeX Live program detex removes them from the document, or from the selection, and adds the files read with \input and \include; TeXShop counts what is left in the same way as the status bar. The document need not be saved. The count is made when the popover opens and when its refresh button is clicked.

The options button beside the refresh button shows how the characters are counted. Ignore line endings, Ignore whitespace and Treat consecutive whitespace as one leave out line endings and spaces, or count a run of them as one. Normalization applies NFC, NFD, NFKC, NFKD, NFKC Case-Fold, Modified NFC or Modified NFD first. Unit counts grapheme clusters (characters as they are seen, as the status bar counts them), Unicode scalars, UTF-16 code units or bytes; for bytes, Encoding chooses the encoding. Both columns are counted again at once, without running detex. The options are the same for every document; the encoding is the document’s each time the popover opens. When the options are hidden and the characters are not counted as the status bar counts them, the options button is shown in color.

The clipboard

Edit › Swap with Clipboard replaces the selection with the text on the clipboard and puts the selection on the clipboard. To exchange two pieces of text, copy the first, select the second and choose Swap with Clipboard, then select the place of the first and paste. When nothing is selected, it pastes.

Edit › Copy with Style copies the selection in the font of the source and with the colors of the Light Mode or Dark Mode theme, with or without the background color, to paste into a word processor, a presentation or an email. Each of its four items can be given a shortcut in Settings › Keyboard.

Converting characters

The submenus Character Type Conversion and Unicode Normalization of the Edit menu, also in the contextual menu of the source, rewrite the selection; if nothing is selected, TeXShop asks whether to rewrite the whole document. Character Type Conversion is mainly for Japanese documents. It converts between hiragana and katakana, between fullwidth and halfwidth digits and letters, between characters such as circled numbers and the commands of the ajmacros package, and between characters outside JIS X 0208 and the \UTF and \CID commands of the otf package. It also changes curly quotes into TeX quotes. Unicode Normalization converts the selection to NFC, NFD, NFKC or NFKD, or to Modified NFC or Modified NFD, which leave CJK compatibility ideographs unchanged. Both can be undone.

Backup files

When “Enable Autosave and Versions” is off in Settings › Documents and Saving, turn on “Keep the previous file as “name~” when saving” there to keep the previous version of a file each time it is saved. The backup has the name of the file followed by a tilde.

Finding and replacing, with regular expressions and Multiple Replace, is described in Find and Replace.
