Macros

The Macros menu, and the Macros item in the toolbar, hold commands that insert LaTeX code into the source or run AppleScript scripts. Some of the macros that come with TeXShop:

  • Set Typesetting Program…, Set Encoding… and Set Root File… write the % !TEX lines that choose the typesetting engine, the encoding and the root file of a document. Choose the engine or the encoding from the list that Set Typesetting Program… or Set Encoding… shows, or the root file in the dialog that Set Root File… opens; the line is written correctly at the top of the source.
  • Insert Begin/End turns the word at the insertion point or the selected word, such as theorem, into a \begin{theorem} … \end{theorem} pair, with the insertion point between them.
  • Submenus such as Headings, Mathematics, Lists, Tables and Figures insert common LaTeX code.

The Macro Editor

Choose Macros › Open Macro Editor… to see how each macro is defined, change it, or add macros of your own. The list on the left is the Macros menu: drag items to rearrange them, and use the bar below the list to add items, submenus and separators. The text of a macro is inserted into the source. In this text, rounded tokens stand for the selected text, the text on the clipboard and the place of the insertion point; choose them from the Insert menu below the text.

To give a macro a keyboard shortcut, select it in the list, click its shortcut (or double-click it) and press the keys. A shortcut uses the Command or Control key, or is a function key. If a menu command or another macro already uses it, the Macro Editor says so.

Macros are kept in ~/Library/TeXShop/Macros/Macros_Latex.plist. To give macros to others, select them in the Macro Editor and choose Macros › Save selection to file…; to add macros from such a file, choose Macros › Add macros from file….

The Macros Help chapter explains macros in detail, including AppleScript macros.
