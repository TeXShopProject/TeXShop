Writing Scripts with TeXShop Typesetting Commands

A document with a bibliography needs a sequence of typesetting runs: LaTeX writes the .aux file, BibTeX uses it to write the .bbl and .blg files, LaTeX runs again to add the bibliography to the document, and once more to update the references to it. Your projects may need similar sequences, and an AppleScript macro can run them for you.

The macro Macros › Applescript › Run LaTeX, BibTeX, Then LaTeX Twice, which comes with TeXShop, shows how. Here are its contents:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

The first line makes this an AppleScript macro run by ScriptRunner, so it can ask TeXShop to typeset (see AppleScript Macros). The next lines check #FILEPATH#, the full path of the source file. It is an empty string when the document has not been saved yet; in that case the script asks you to save it and stops.

The script then refers to the document by #DOCUMENTNAME#. TeXShop saves the document itself when a typesetting command starts, so the script does not need to save it.

The remaining commands run latexinteractive, bibtex, latex and latex. A typesetting command returns to the script at once, before typesetting is finished, so after each command a repeat loop waits until taskdone reports that the job is complete. The line delay 2 makes the script pause between the checks rather than asking continually and slowing down the computer. The commands are listed in Defining AppleScript Macros.
