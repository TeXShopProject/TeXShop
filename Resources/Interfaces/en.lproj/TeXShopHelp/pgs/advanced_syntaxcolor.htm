Syntax Highlighting

Changing the colors of syntax highlighting

When syntax highlighting is turned on in the source window, comments, commands, and the symbols $, {, and } are shown in their own colors. These colors belong to the theme. To change them, use the Syntax Highlighting group in the Themes category of the Settings window. Each theme has its own colors, so the Lite Mode Theme and the Dark Mode Theme can use different colors.

Earlier versions of TeXShop set these colors with hidden settings such as markerred, markergreen and markerblue. They are no longer used.

Adding to the list of file types

There is a hidden setting to add file extensions to the list of files that TeXShop recognizes as source files which can be typeset and syntax colored. This is useful when you want to use syntax highlighting when editing TeX files with non-standard extensions. For example,

defaults write TeXShop OtherTeXExtensions -array-add "lbx"

tells TeXShop to syntax color biblatex 'lbx' files.
