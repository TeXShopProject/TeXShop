Syntax Highlighting

The source window shows TeX in colors: comments, commands, footnotes, the markers $ and &, and the brackets ( ), { } and [ ] each have their own color. Source › Syntax Highlighting turns highlighting on or off for the active document. Documents open with it on; to open them with it off, use the hidden setting

defaults write TeXShop SyntaxColoringEnabled NO

What is highlighted

  • Commands are a backslash followed by letters. Settings › Editor › Syntax Highlighting › “@ as Part of Command Names” also counts @ as a letter, as in the internal commands of packages.
  • The text of \footnote, \footcite and \autocite, and of the commands that begin with \cite or \Cite, such as \citep and \citeauthor, is shown in the Footnote color. The hidden setting defaults write TeXShop SyntaxColorFootnote NO colors only the command.
  • Source › Highlight Index Entries shows the arguments of \index and \esindex in the Index color. Settings › Editor › Syntax Highlighting › “Highlight Index Entries by Default” turns it on when documents open.
  • Source › Highlight expl3 Code also colors the functions, variables and other parts of expl3 code, the programming layer of LaTeX, for those who write packages. “Highlight expl3 Code by Default” in the same group turns it on when documents open.
  • “Highlight Fullwidth Letters and Symbols” in the same group shows fullwidth letters, digits and symbols, easily mistaken for ASCII characters in Japanese text, in the Fullwidth colors.

Highlight Index Entries and Highlight expl3 Code apply to the active document; each source window has its own choice. Files that are not TeX sources, such as log files, are not highlighted; see Opening Other Files with TeXShop for the list of extensions and how to add one.

Changing the colors

The colors belong to the theme. Choose them in Settings › Themes:

  • the group Syntax Highlighting has Comment, Command, Footnote, Marker and Index;
  • the group Brackets has the colors of ( ), { } and [ ];
  • the group expl3 has function, __function, key, variable, __variable, argument and msg;
  • the group Highlights has, among others, the Fullwidth colors;
  • the group XML Syntax has the colors for HTML and XML files.

Each theme has its own colors, so the Light Mode Theme and the Dark Mode Theme can differ.
