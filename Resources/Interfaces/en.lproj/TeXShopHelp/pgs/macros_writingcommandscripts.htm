Writing Scripts with Shell Commands

This page uses the macro pdflatexc by Claus Gerhardt, in Macros › Claus Gerhardt Macros, to show how an AppleScript calls a shell script. The shell script itself is simple: it adds the folders of the TeX programs to the search path and runs pdflatex with --shell-escape. Your own scripts will probably do more, for instance run several programs in sequence; that is when these techniques become useful.

The shell script

The shell script is ~/Library/TeXShop/bin/pdflatexc. It does not depend on TeXShop: if its folder is in your search path, typing pdflatexc myfile.tex in Terminal runs it. Here it is:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

The AppleScript

The macro that calls this shell script is more interesting:

--Applescript
-- Apply only to an already saved file.
-- Claus Gerhardt, Nov. 2003

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

After the comments, the first seven lines are a recipe by Claus Gerhardt to save the source file and find the name of its document, which is put in frontName. The work is done by the compiled script setname.scpt in ~/Library/TeXShop/Scripts: these lines find the path ~/Library/TeXShop/Scripts/setname.scpt, load the script and call it with #NAMEPATH# and #TEXPATH#.

Often the same can be done more simply with

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

The recipe has two advantages. It also works when the front document is not the one that should receive the later commands, for instance a log file such as /Users/name/Examples/myfile.log. And if the file has never been saved, the recipe returns an error, while the save command would leave the script waiting behind a save dialog.

The next six lines set the variables dirName and baseName. If the source file is /Users/name/My Papers/Stuff/myfile.tex, dirName is '/Users/name/My Papers/Stuff', quoted for the shell because of the space in a folder name, and baseName is myfile.tex. Folder names may contain spaces this way; TeX does not allow them in the name of the file itself.

The next three lines call the shell script. The result is the same as typing cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc myfile.tex in Terminal. The final three lines update the Preview window.

Several of these lines are complicated, but they can be copied unchanged into new scripts.

Running shell commands from AppleScript

AppleScript runs a shell command in the form

do shell script "cmd input"

To build a command from parts, write it in the equivalent form

do shell script "cmd " & "input"

Notice the space after cmd. The ampersand joins two strings:

"cmd " & "input" = "cmd input"

A shell started by AppleScript begins in the root folder. The command

do shell script "cd " & dirName

changes to the folder in dirName, which is already quoted, so no further quotes are needed.

Each do shell script starts a new shell, so a later command would not be in that folder. To run further commands in the same folder, join them with semicolons into one command, as in Terminal:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

The script above does this with cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc and input2 = baseName. The lines

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & baseName

are simply a convenient way to put this sequence into one variable.
