Command Completion

Type the first letters of a command or an environment and press Escape: TeXShop completes it from its Completion file. Press Escape again to go through the other completions that begin with the same letters, from the bottom of the file toward the top; Shift-Escape goes the other way. One of them is the text you typed. For example, \begin{th followed by Escape offers \begin{theorem} and other environments.

A completion can do more than finish the word. The completion of \begin{theorem} also writes the \end{theorem} line, and puts marks (•) where you will type: the first mark is selected, so what you type replaces it. Pressing Escape several times often gives the same command with more arguments, as \newc does for \newcommand. A completion need not start with a backslash: at the start of a line or after a space, sec gives the same as \sec.

Settings

In Settings › Keyboard, “Completion trigger” chooses Escape or Tab as the key that completes; with None, command completion is off. The source panel of Edit › Experiment... uses the same key as the source window.

To add a word to the Completion file, select it and choose Source › Add to Command Completion List. To edit the file, click “Edit Command Completion…” in Settings › Keyboard. Studying the completions that are there is the best way to learn how to write new ones; the folder ~/Library/TeXShop/CommandCompletion also has a detailed document about them.

Marks

A mark (•) is a place to come back to; a mark with a note (•‹note›) also says what belongs there. Command completions, macros and key bindings can contain marks, and you can insert them yourself with Edit › Marks › Insert Mark (⌘8) and Insert Mark with Note (⌃⌘8). Insert Mark with Note inserts •‹› with the insertion point between the brackets, or turns the selected text into the note.

Next Mark (⌃⌘F) and Previous Mark (⌃⌘G) select the next or previous mark together with its note, so that typing replaces it. Hold down Option to delete just the • and select the note instead (⌃⌥⌘F, ⌃⌥⌘G).

The trigger key moves between marks too: with Escape as the trigger, Option-Escape goes to the next mark and Control-Escape to the previous one; with Tab, Option-Tab and Control-Tab. If another application needs these keys, turn off “Move to the next or previous mark with Option or Control and the trigger key” in Settings › Keyboard.

Label and Citation Key Completion

Edit › Complete Label or Citation Key (F5) completes a label or a citation key from a list. Choose it right after \ref{, \pageref{, \eqref{ or \autoref{, or after the first letters of a label typed there, and the list shows the labels defined with \label in the file; choose one with the arrow keys and press Return. After \cite{ and similar commands, the list shows citation keys from BibDesk when “Also offer BibDesk citation keys” in Settings › Keyboard is on. Elsewhere, it shows the word completions of macOS. On many keyboards, hold down the fn key (the Globe key) while pressing F5.

Key Bindings, Macros and Command Completion

These three features all put text into the source and are easily mixed up. Each suits a different job:

Key bindings
Typing one key inserts text: _ gives _{} around the selection, and ≤ (Option-comma on the U.S. layout) gives \leq. Settings › Keyboard turns them on for new documents and holds their list; Source › Key Bindings turns them on or off for the document in front. Type \ first to keep a key such as _ or ^ as it is. A character typed with a dead key, such as é from Option-E and E, cannot have a key binding.
Macros
Items of the Macros menu insert text or run AppleScript programs, and can have a keyboard shortcut with the Command or Control key or a function key. Macros › Open Macro Editor... adds, edits and orders them. Text you want on a Command key, such as \textbf around the selection on ⌘B, is best made a macro.
Command completion
Type the start of a command or an abbreviation and press the trigger key: \sec gives \section{•}, the trigger again gives the next match, and \benu gives a whole enumerate environment with marks. Unlike key bindings and macros, command completion replaces selected text.
