Printing

To print the typeset document, choose File › Print… (⌘P) in the Preview window or in the source window. In a project with a root file, the typeset root document is printed.

The print dialog has a TeXShop section with the same choices as Apple’s Preview. With Auto Rotate, each page is turned to suit the paper, so a page in landscape format prints sideways on portrait paper. With Scale to Fit, each page is scaled to fit the paper; choose Scale instead to print at a fixed percentage. Both are on at first, and the choices of the last print are kept for the document while it is open. The orientation of the paper follows the first page.

To print the source text, choose File › Print Source…. File › Page Setup… chooses the paper size.
