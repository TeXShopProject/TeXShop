Using an External Editor

You can write in another editor and use TeXShop to typeset and to show the PDF.

Opening only the preview

File › Open for Preview… asks for a source file and opens only its Preview window. If the file has not been typeset yet, or the PDF is older than the source, TeXShop typesets it first. Edit the source in your editor; to typeset, save it there and press Typeset in the Preview window or press ⌘T. TeXShop never opens or changes the source file in this mode. If the toolbar of the Preview window has no Typeset button, add one with Window › Customize Toolbar….

If you always work this way, turn on Settings › General › Startup › “Configure for External Editor”. File › Open… and Open Recent then open source files for preview only, and File › Open for Preview… becomes Open for Editing…, which opens a source file in TeXShop’s own editor when you need it. Other files, such as PDF, graphics and log files, open as before.

Keeping the preview current

When the PDF is rewritten by another program, for instance by your editor or by latexmk in Terminal, TeXShop reloads it when you return to TeXShop or to the Preview window, keeping the page and the magnification. With Settings › Preview › Refresh › “Always Watch for PDF Changes by Other Apps” on, it reloads the PDF as soon as it changes, even while TeXShop is in the background, for instance when the preview is placed beside your editor. A preview with annotations that have not been saved is not reloaded, so the annotations are not lost.

TeXShop also watches the source files open in its own editor. When another editor changes such a file, TeXShop reloads it, unless the copy in TeXShop has unsaved changes.

Synchronizing with the editor

Command-click in the Preview window can take you to the line in your editor, and Goto Error in the console can open the line of an error there. This needs “Configure for External Editor”, a hidden setting, and a command line program of the editor:

  • For TextMate, whose command mate is in /usr/local/bin: defaults write TeXShop TextMateSync YES.
  • For any other editor: defaults write TeXShop OtherEditorSync YES, and an executable script /usr/local/bin/othereditor that receives the line number as $1 and the full path of the file as $2. For BBEdit it reads: 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

For the other direction, from a line in the editor to the Preview window, the editor calls TeXShop through AppleScript with the commands sync_preview_line, sync_preview_index and sync_preview_name. The chapter “Using an External Editor” of Help › TeXShop Manual has a complete script.

The folder ~/Library/TeXShop/ExternalEditorScripts contains ready-made support with documentation: AppleScripts that typeset and preview a document of BBEdit in TeXShop, and a plug-in for Vim.

AppleScript commands for editors

An editor can call these AppleScript commands of a TeXShop document:

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Typeset, or run plain TeX, LaTeX, BibTeX, MakeIndex or MetaPost. The call returns at once, without waiting for typesetting to end; the preview is refreshed when it ends.
taskdone
Returns NO while typesetting is running and YES when it has finished.
refreshpdf
Reloads the PDF and brings the Preview window to the front.
refreshpdfbackground
Reloads the PDF without bringing TeXShop to the front, when the Preview window is already open.
refreshtext
Reads the source file again from disk.
open_for_externaleditor
Opens a source file as File › Open for Preview… does.

When the editor typesets through TeXShop, “Always Watch for PDF Changes by Other Apps” is not needed. See also Writing Scripts with TeXShop Typesetting Commands.
