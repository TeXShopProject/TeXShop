Understanding Default Macros

The best way to understand the default macros is to look at them in the Macro Editor (Macros › Open Macro Editor…): select a macro in the list, and its contents appear beside it.

For example, suppose you want a theorem environment. Type the word theorem, select it and choose Macros › Insert Begin/End. The word is replaced with

\begin{theorem}

\end{theorem}

and the insertion point is placed on the line between.

Insert Begin/End is an AppleScript macro (see AppleScript Macros). A text macro that does the same when a word is selected reads:

\begin{#SEL#}
#INS#
\end{#SEL#}

Placeholders in text macros

The text of a text macro is inserted into the source, with these replacements:

#SEL#
is replaced with the text that was selected when the macro was chosen, or with nothing if no text was selected.
#INS#
marks where the insertion point goes. Without it, the insertion point is placed at the end of the inserted text.
#PASTE#
is replaced with the text on the clipboard, or with nothing if the clipboard holds no text.
