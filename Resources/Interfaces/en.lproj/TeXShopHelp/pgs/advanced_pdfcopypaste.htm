Copy-Paste and Drag-Drop

A part of a page in the Preview window can be copied as a picture into another program, such as Keynote, Pages or Preview.

Selecting and copying

  1. Choose the Select PDF tool in the toolbar of the Preview window.
  2. Drag a rectangle over the part you want. It can contain text, formulas and pictures.
  3. Choose Edit › Copy (⌘C) and paste into the other program, or drag the selection into a document of that program. Dragging it to the desktop or a Finder window makes a file.

Preview › Save Selection to File… saves the selection under a name and in a folder you choose. With the Select PDF tool, Edit › Select All (⌘A) selects everything shown: the page in the Single Page and Double Page display formats, the whole document in MultiPage and Double MultiPage. In the latter two it works only for documents of at most 20 pages, so that the copy does not become enormous.

To copy text rather than a picture, use the Select Text tool.

The format of the copy

Settings › Preview › Copy Images › Image Copy Type sets the kind of picture: PDF, TIFF, JPEG or PNG, some in several qualities. PDF, the default, keeps text and lines sharp at any size, so a selection pasted into a Keynote slide can be enlarged freely. The submenu Preview › Copy Format shows and changes the same setting.

For TIFF, JPEG and PNG copies, two more items of the Copy Images group apply:

  • “Use Color Mapping” turns black into a text color and white into a background color, so that a copy matches the colors of a slide. Both colors are set in Settings › Themes › Color Mapping for Copied Images, under Text and Background, separately for each theme. PDF copies keep the colors of the page.
  • “Foreground Prominence” sets how strongly the text is emphasized in the copy.

The color that the theme gives to light pages in the Preview window is not part of the copy.
