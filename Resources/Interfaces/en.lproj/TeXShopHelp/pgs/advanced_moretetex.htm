More About TeX Live

Where TeX Live is installed

MacTeX installs TeX Live in /usr/local/texlive/2026, and BasicTeX in /usr/local/texlive/2026basic. TeX Live is released once a year, and each year is installed in a folder of its own, such as 2027, so several years can stay on the Mac side by side. To remove one, drag its folder to the Trash.

The folder /usr/local is hidden in the Finder. To look inside, choose Go › Go to Folder… in the Finder and type the path.

How TeXShop finds TeX

TeXShop runs TeX from the folder in the TeX Engines field of Settings › Typesetting › Paths. The default is /Library/TeX/texbin, a link that the MacTeX and BasicTeX installers point to the programs of the TeX Live just installed. When a new year of TeX Live is installed, the link follows it, and TeXShop uses the new TeX without any change in Settings.

To use another installation, enter the folder of its programs in TeX Engines, for example /usr/local/texlive/2026/bin/universal-darwin, or press “Detect Paths…” to choose among the installations TeXShop finds; see Coexisting with Other TeX Distributions.

Keep TeX Live as it is

The TeX Live folders belong to the system, and an update or a new year of TeX Live replaces them. Do not add or change files there. Put your own style files, classes and bibliographies in your personal tree instead, where TeX finds them first and where updates leave them alone; see Adding Personal Files to TeX Live.

Documentation

TeX Live contains documentation for almost every package. Help › Show Help for Package… opens the documentation of a package by its name, for example hyperref or tikz. Help › TeX Live Documentation lists where to find the TeX Live guide and other documentation online.
