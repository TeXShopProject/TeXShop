LaTeX 패널 수정

LaTeX 패널(윈도우 › LaTeX 패널...)에는 사용자 버튼을 16개까지 만들 수 있는 사용자화 탭이 있습니다. 다른 버튼의 이름은 바꿀 수 없지만, 버튼이 삽입하는 텍스트는 바꿀 수 있습니다.

둘 다 ~/Library/TeXShop/LatexPanel/completion.plist 파일에서 설정합니다. 이 파일을 TeXShop에서 열고, 파일의 구성을 설명하는 첫머리의 주석을 읽으십시오. 탭마다 버튼이 삽입하는 텍스트의 목록이 버튼 순서대로 있습니다. 이 텍스트에서 #SEL#은 선택한 텍스트를, #INS#은 삽입 위치가 놓일 곳을 나타냅니다.

사용자화 탭의 버튼은 Customized라는 이름의 목록에 있습니다. 각 버튼은 이름과 삽입할 텍스트, 두 문자열의 쌍입니다. 예를 들어

<string>Section</string>
<string>\section{#SEL##INS#}</string>

는 선택한 텍스트를 \section{}으로 감싸고 삽입 위치를 중괄호 안에 두는 Section이라는 버튼을 만듭니다.

파일은 UTF-8로 저장하십시오. TeXShop은 LaTeX 패널을 처음 열 때 이 파일을 읽으므로, 변경 내용을 보려면 TeXShop을 다시 시작하십시오. 다른 탭의 목록 항목은 하나도 지우지 마십시오. 파일을 사용할 수 없으면 TeXShop은 자체 사본을 사용하고, 다음에 시작할 때 파일을 바꾸며 사용자의 파일은 ~/Library/TeXShop/Backups에 보관합니다.
