When syntax highlighting is turned on in the source window, comments, commands, and the symbols $, {, and } are shown in their own colors. These colors belong to the theme. To change them, use the “구문 하이라이트” (Syntax Highlighting) group in the “테마” (Themes) category of the Settings window. Each theme has its own colors, so the theme for Light Mode and the theme for Dark Mode can use different colors.

Earlier versions of TeXShop set these colors with hidden settings such as markerred, markergreen and markerblue. They are no longer used.
