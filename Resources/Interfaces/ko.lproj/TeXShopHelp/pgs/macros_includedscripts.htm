기본 AppleScript 매크로

TeXShop에는 Will Robertson, Claus Gerhardt 등이 만든 AppleScript 매크로 모음이 들어 있습니다. 그중 일부는 여러 조판 명령을 차례로 실행합니다. 이 매크로를 복사하여 고치면 자신의 작업에 맞는 스크립트를 만들 수 있습니다. 이 페이지에서는 그중 몇 가지를 매크로 메뉴에 표시되는 이름으로 소개합니다.

Column macros, Insert reference, Open quickly…

이 매크로들은 Will Robertson이 만들었습니다. Column macros 하위 메뉴의 New tabular와 New array는 입력한 행과 열의 수만큼 tabular 환경이나 array 환경을 넣으며, Add column과 Delete column은 선택한 행에 열을 추가하거나 삭제합니다. Insert reference는 현재 파일에서 \label{…} 명령을 찾아 목록에서 레이블을 고르게 하고, 고른 레이블을 \ref{…}로 감싸서 넣습니다. 이 명령은 스크립트에서 바꿀 수 있습니다. 텍스트를 선택해 두었으면 그 텍스트가 들어 있는 레이블만 목록에 표시됩니다. Open quickly…는 현재 소스 파일이 있는 폴더의 .tex, .sty, .pdf 파일을 나열하고, 선택한 파일을 엽니다.

Paste Spreadsheet Cells

Alan Munn이 만든 이 매크로는 스프레드시트의 셀을 LaTeX 소스에 표로 붙여 넣습니다. Excel 같은 스프레드시트 응용 프로그램에서 셀 범위를 선택하여 복사합니다. 그런 다음 매크로 › Paste Spreadsheet Cells를 선택하고 표 스타일을 고릅니다.

cells
복사한 텍스트를 LaTeX 표의 셀로만 변환합니다.
booktabs
첫 줄을 머리글로 삼고, tabular 환경 안에 \toprule, \midrule, \bottomrule을 넣습니다.
simple
셀을 간단한 tabular 환경으로 감쌉니다.
longtable
첫 줄을 머리글로 삼아 longtable의 머리글 줄을 추가하고, 셀을 longtable 환경에 넣습니다.

이 매크로는 클립보드의 내용을 LaTeX 텍스트로 바꿉니다. 같은 셀을 다른 스타일로 붙여 넣으려면 먼저 스프레드시트에서 셀을 다시 복사하십시오.

Applescript › Save Copy with Unix Line Endings, Save Copy with Windows Line Endings, Save Copy with Classic Mac Line Endings

텍스트 파일은 줄 끝을 나타내는 방식이 서로 다릅니다. macOS와 Unix는 라인 피드를, Windows는 캐리지 리턴 뒤에 라인 피드를, 아주 오래된 Macintosh 파일은 캐리지 리턴만 사용합니다. TeXShop은 세 가지를 모두 읽습니다. 다른 사람의 편집기가 읽지 못한다면 이 매크로를 사용하십시오. 소스 파일이 MyFile.tex이면 Save Copy with Unix Line Endings는 저장된 파일의 사본을 라인 피드로 바꾸어 MyFile_Unix.tex로 기록합니다. Save Copy with Windows Line Endings는 MyFile_Windows.tex를, Save Copy with Classic Mac Line Endings는 MyFile_Mac.tex를 기록합니다. 이 매크로는 ~/Library/TeXShop/bin에 있는, Craig Stuart Sapp이 만든 flip 프로그램을 사용합니다.

Applescript › Run LaTeX, BibTeX, Then LaTeX Twice

참고 문헌 목록이 있는 문서는 여러 번 조판해야 합니다. LaTeX가 .aux 파일을 기록하면 BibTeX가 그 파일을 사용하여 .bbl 파일과 .blg 파일을 기록하고, LaTeX를 다시 실행하여 참고 문헌 목록을 추가한 뒤, 한 번 더 실행하여 목록에 대한 참조를 갱신합니다. 이 매크로는 이 과정을 차례로 실행합니다. 작동 방식은 TeXShop 조판 명령으로 스크립트 작성하기에서 설명합니다.

Claus Gerhardt Macros

이 하위 메뉴의 매크로는 대부분 ~/Library/TeXShop/bin에 있는 셸 스크립트를 호출합니다. 예를 들어 pdflatexc는 pdfLaTeX를, bibtexc는 BibTeX를 실행합니다. 이름이 Run으로 시작하는 매크로는 이름에 나온 프로그램을 그 순서대로 실행하고, Open PDF는 문서의 PDF를 엽니다. Run LaTeX, dvips and ps2pdf에는 Ghostscript도 필요합니다. 매크로는 저장된 파일에 대해 작동합니다. Run pdfLaTeX with Shell Escape를 예로 든 설명은 셸 명령으로 스크립트 작성하기에 있습니다.

Make HTML with TeX4ht

TeX4ht는 LaTeX 문서를 HTML 페이지와 그림 파일로 이루어진 웹 페이지로 변환합니다. Make HTML with TeX4ht는 문서에 htlatex를 실행하고, 만들어진 HTML 파일을 Safari에서 엽니다. 문서에서 tex4ht 패키지를 불러올 필요는 없으며, htlatex가 불러옵니다. Make HTML with TeX4ht, Remaking Images는 -r 옵션을 주어 htlatex를 실행합니다. 이 옵션을 사용하면 그림이 이미 있어도 다시 만듭니다.

Extract Pages from PDF…

Extract Pages from PDF…는 문서 PDF에서 선택한 페이지만 담은 PDF 파일을 만듭니다. 먼저 파일을 몇 개 만들지 묻고, 이어서 각 파일에 넣을 페이지를 묻습니다. 예를 들어 5~8페이지는 5:8로, 여러 범위는 3:4,6,8:12처럼 입력합니다. 문서 이름이 MyFile이면 파일은 MyFile-1.pdf, MyFile-2.pdf와 같은 이름으로 저장됩니다.

MetaPost

Run pdfLaTeX, MakeIndex, MetaPost, Then pdfLaTeX는 실행 도중에 로그 파일을 엽니다. MetaPost에 대해서는 ConTeXt와 MetaPost를 참조하십시오.
