ConTeXt와 MetaPost

ConTeXt

ConTeXt는 Hans Hagen이 만든 매크로 패키지로, 자체 명령 체계를 갖춘 LaTeX의 대안이며 타이포그래피 디자인에 중점을 둡니다. TeX Live에는 ConTeXt가 들어 있으며, ConTeXt Garden은 자주 업데이트되는 버전을 배포합니다. 이 버전은 홈 폴더에 설치됩니다.

ConTeXt용 엔진은 ~/Library/TeXShop/Engines/Inactive/ConTeXt에 있으며, 안내서 Setting-Up-ConTeXt.pdf와 예제 문서도 함께 들어 있습니다.

엔진조판에 사용하는 것
ConTeXt.engineLuaTeX에서 실행되는 TeX Live의 ConTeXt
ConTeXt-TL.engineluametatex에서 실행되는 TeX Live의 ConTeXt
ConTeXt-CG.engine홈 폴더에 설치한 ConTeXt Garden 버전

필요한 엔진을 ~/Library/TeXShop/Engines로 옮기고, 문서의 루트 파일 첫머리에 다음과 같은 매직 코멘트를 넣습니다.

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

ConTeXt-CG를 사용하려면 ConTeXt Garden 설치본의 프로그램 폴더를 설정 › 조판 › 경로의 두 번째 TeX 엔진 필드에 입력하고, % !TEX useAlternatePath 줄을 추가합니다. 이 줄이 있으면 TeXShop은 엔진에 TeX Live 대신 그 폴더를 넘겨 줍니다.

소스와 미리보기를 동기화하려면 문서의 설정 부분에 \setupsynctex[state=start,method=min]을 추가합니다. % !TEX useConTeXtSyncParser 줄이 있으면 TeXShop은 ConTeXt 자체의 동기화 코드를 사용합니다. ConTeXt Garden 버전을 설치하는 방법과 각 엔진은 도움말 › TeXShop 설명서 (영문)의 ConTeXt 장에서 자세히 설명합니다.

\title, \subject 같은 ConTeXt 섹션 명령을 태그 메뉴에 표시하려면 숨겨진 설정 ConTeXtTags를 켭니다. 숨겨진 설정을 참조하십시오.

MetaPost

John Hobby가 만든 MetaPost는 Knuth의 METAFONT에서 파생된 프로그래밍 언어로 기술한 내용에 따라 그림을 그립니다. MetaPost 설명서는 TeX Live에 들어 있습니다. 도움말 › 패키지 도움말 보기...를 선택하고 metapost를 입력하십시오.

조판 › MetaPost(⇧⌘M)를 선택하거나 조판 버튼 옆의 팝업 메뉴에서 MetaPost를 선택하면, 현재 문서와 이름이 같고 확장자가 .mp인 파일에 MetaPost를 실행합니다. 문서 자체가 .mp 파일이면 그 문서에, 그렇지 않으면 mfpic 패키지가 .tex 문서를 위해 만드는 파일처럼 문서 옆에 있는 .mp 파일에 실행합니다. 실행되는 명령은 설정 › 조판 › 관련 도구 › MetaPost에 있는 명령이며, 기본값은 mpost입니다. 엔진 프로파일이 이 필드를 설정합니다. pLaTeX + dvipdfmx는 pmpost로, upLaTeX + dvipdfmx는 upmpost로 설정하며, 이 두 프로그램은 레이블 안의 일본어 텍스트를 조판합니다. 나머지 프로파일은 mpost로 설정합니다. LuaLaTeX에서는 pmpost나 upmpost로 레이블을 일본어로 조판한 그림을 포함할 수 없습니다. LuaLaTeX에서는 이런 그림을 luamplib 패키지로 문서 안에서 그리십시오.

새 파일을 MetaPost 파일로 저장하려면 저장 대화상자의 파일 포맷 메뉴에서 mp 유형을 선택합니다.

Nicola Vitacolonna가 만든 nv-metapost 엔진과 nv-metafun 엔진은 MetaPost와 MetaFun 작업을 편리하게 해 주며, 파일에 들어 있는 그림을 미리보기 윈도우에 보여 줍니다. 이 엔진은 ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines에 있습니다. 설치 및 사용 방법은 한 단계 위의 MetaPostEngines-1.4.7 폴더에 있는 README.pdf 파일에 설명되어 있으며, 같은 폴더의 examples 폴더에 예제 파일이 있습니다. 예를 들어 다음과 같이 시작하는 파일은

% !TEX program = nv-metafun
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

nv-metafun 엔진을 Engines 폴더에 넣어 두면 nv-metafun으로 조판됩니다.

MetaPost 그림을 LaTeX 문서 안에 쓸 수도 있습니다. LuaLaTeX에서는 luamplib 패키지를 사용하고, 그 밖에는 mfpic 같은 패키지를 사용합니다. mfpic 같은 패키지는 그림을 .mp 파일에 기록하며, 두 번의 조판 사이에 MetaPost가 이 파일을 처리합니다.
