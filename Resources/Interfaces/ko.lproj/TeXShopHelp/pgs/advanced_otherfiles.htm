TeXShop으로 다른 파일 열기

TeXShop은 어떤 텍스트 파일이든 열 수 있으므로, 문서 옆에 생기는 로그 파일, aux 파일 등 TeX의 다른 파일도 읽을 수 있습니다. PDF 파일과 그림도 열 수 있습니다.

TeX 소스로 취급하는 파일

다음 확장자를 가진 파일과 확장자가 없는 파일은 TeXShop에서 TeX 소스로 취급합니다. 이런 파일은 구문 하이라이트로 표시되며 조판할 수 있습니다.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

.log, .aux, .bst, .engine, .txt 파일 같은 그 밖의 텍스트 파일은 구문 하이라이트 없이 일반 텍스트로 열립니다.

다른 확장자를 가진 파일도 TeX 소스로 취급하게 하려면 터미널에서 숨겨진 설정으로 확장자를 추가합니다. 예를 들어 확장자가 mkiv인 ConTeXt 파일이라면 다음과 같이 입력합니다.

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

PDF 파일과 그림

PDF 파일과, 확장자가 .png, .jpg, .jpeg, .tif, .tiff, .eps인 그림은 별도의 윈도우에서 열립니다. DVI 파일과 PostScript 파일(.dvi, .ps)은 PDF로 변환하여 표시합니다.

다른 확장자로 저장하기

TeXShop은 파일을 저장할 때 원래 확장자를 유지합니다. 새 문서는 저장 대화상자의 파일 포맷 메뉴에서 sty, bib, mp 같은 다른 유형을 선택하지 않으면 .tex 파일로 저장됩니다.

TeXShop은 파일을 열었을 때의 인코딩으로 저장합니다. TeXShop은 TeX와 관련 파일을 위한 프로그램이므로, 특수한 형식의 파일은 TeXShop에서 편집한 뒤 저장하면 내용이 바뀔 수 있습니다. 인코딩을 참조하십시오.
