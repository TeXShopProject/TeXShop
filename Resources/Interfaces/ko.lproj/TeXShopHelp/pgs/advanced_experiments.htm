실험

편집 › 실험...을 사용하면 수식, 표, TikZ 그림처럼 짧지만 까다로운 LaTeX 코드를 문서에 넣기 전에 시험해 볼 수 있습니다. 이 명령은 소스 윈도우가 활성화되어 있을 때 사용할 수 있습니다.

이 명령은 소스 패널을 엽니다. 소스 윈도우에서 텍스트를 선택해 두었으면 그 텍스트가 패널에 복사되고, 그렇지 않으면 지난번에 패널에 남겨 둔 내용이 표시됩니다. $$\sqrt{x^2 + y^2}$$ 같은 코드 조각을 입력하거나 고친 다음, 패널 아래쪽의 조판 버튼을 누릅니다. 미리보기 패널에 결과가 표시됩니다. 처음에는 첫 페이지의 맨 위가 표시되고, 다시 조판하면 보고 있던 부분이 그대로 유지됩니다. 코드 조각은 수식 하나에서 여러 페이지까지 무엇이든 될 수 있습니다.

코드 조각을 조판하는 방식

TeXShop은 문서의 프리앰블, 즉 \begin{document}까지의 모든 내용 뒤에 코드 조각과 \end{document}를 붙인 파일을 조판합니다. 루트 파일이 있는 프로젝트에서는 루트 파일의 프리앰블을 사용합니다. 문서와 그 폴더는 변경되지 않습니다.

  • 이 파일은 문서 옆에 있는 파일과 폴더의 사본이 들어 있는 임시 폴더에서 조판됩니다. 따라서 ./로 시작하는 경로를 포함하여, 문서를 조판할 때와 마찬가지로 그림을 찾을 수 있습니다. 문서의 폴더에 하위 폴더의 항목까지 합쳐 5000개가 넘는 항목이 있으면 아무것도 복사하지 않으며, 다른 디스크에 있는 파일이나 클라우드 서비스의 온라인 전용 파일처럼 이 방식으로 복사할 수 없는 항목은 빠집니다. 이 경우에도 문서 옆의 파일은 찾을 수 있지만, ./로 시작하는 경로로는 찾을 수 없습니다.
  • 문서를 마지막으로 조판할 때 생긴 .aux 파일의 사본을 읽으므로, \ref, \pageref, \cite에 문서의 번호가 표시됩니다.

엔진은 문서가 사용하는 엔진입니다. 소스 첫머리에 % !TEX program 줄이 있으면 그 엔진을, 없으면 소스 윈도우 도구 막대에서 선택한 엔진을 사용합니다. LaTeX에서는 문서의 조판 방식인 PDF 직접 생성, DVI 경유, 사용자 스크립트 중 하나를 따릅니다. BibTeX나 MakeIndex가 선택되어 있으면 pdfLaTeX를 사용합니다. ConTeXt, MetaPost, plain TeX는 실험에 사용할 수 없습니다. 직접 만든 엔진도 시도하지만, LaTeX를 전제로 하지 않거나 PDF 파일을 만들지 않는 엔진이라면 실패할 수 있습니다.

패널

소스 패널은 소스 윈도우와 같은 방식으로 텍스트를 보여 줍니다. 서체, 탭, 줄 간격, 워드랩, 구문 색상, 현재 줄 강조, 블럭 커서, 숨김문자, 행 번호, 괄호 짝 맞추기가 모두 같으며, 메뉴나 설정에서 이를 바꾸면 패널에도 반영됩니다. 소스 › 서체 › 크게(⌘=)와 작게(⌘-)로 텍스트를 크게 하거나 작게 할 수 있는데, 서체 패널에서 선택한 서체와 마찬가지로 소스 윈도우에도 적용됩니다. 키 바인딩, 명령어 완성, 편집 › 레이블 또는 인용 키 완성도 패널에서 작동합니다. 명령어 완성에는 설정 › 키보드 › 호출 키에서 선택한 키를 사용합니다.

미리보기 패널의 도구 막대에는 미리보기 윈도우와 같은 도구인 스크롤, 글자 선택, 확대경, 영역 선택이 있습니다. 확대경은 마우스 버튼을 누르고 있는 동안 포인터 아래의 페이지를 150%로 보여 주며, Command, Option, Control 키를 함께 누르면 각각 200%, 250%, 300%로 보여 줍니다. 이중 클릭하면 더 큰 확대경이 나타납니다. 영역 선택으로 사각형을 그리면 그 부분을 보기 › 파일 형식에서 선택한 형식으로 복사할 수 있습니다. 패널은 미리보기 윈도우와 별도로 선택한 도구를 기억합니다. 도구 옆에는 축소, 확대, 내용에 맞게 확대/축소, 내용 너비에 맞게 확대/축소가 있습니다. 내용에 맞게 확대/축소는 페이지의 조판된 부분이 패널에 가득 차도록 확대하고, 내용 너비에 맞게 확대/축소는 조판된 부분을 패널의 너비에 맞춥니다. 마우스와 트랙패드 제스처로도 패널을 스크롤하고 확대/축소할 수 있습니다.

조판 출력은 별도의 콘솔인 실험 콘솔에 표시됩니다. 조판이 시작되면 실험 콘솔이 앞으로 오며, 패널을 클릭하면 그 패널이 다시 앞으로 옵니다. 패널에서 ⌘0(파일 › 콘솔 보이기)을 누르면 실험 콘솔이 앞으로 오고, 다시 누르면 패널로 돌아갑니다. 설정 › 콘솔 › 콘솔 표시가 “오류 발생시 보이기”로 되어 있으면, TeX가 오류를 보고하거나 입력을 기다릴 때까지 실험 콘솔은 나타나지 않습니다.

패널과 실험 콘솔은 문서 윈도우 위에 떠 있습니다. 이동하거나 크기를 조절할 수 있으며, TeXShop은 그 크기와 위치를 기억합니다. 패널은 닫기 버튼이나 ⌘W로 닫습니다. Escape 키로도 미리보기 패널을 닫을 수 있고, 명령어 완성에 Tab 키를 사용할 때는 소스 패널도 닫을 수 있습니다. Escape 키가 호출 키이면 소스 패널에서 Escape 키는 명령어를 완성합니다.

결과 보관하기

코드 조각이 완성되면 소스 패널에서 복사하여 문서에 붙여 넣습니다. 패널은 닫았다가 다시 열어도 내용을 유지하지만, TeXShop을 종료하면 내용이 사라지며 패널의 내용을 저장할 수는 없습니다.

문서마다 패널이 따로 있으며, 패널의 제목 막대에는 문서의 이름이 표시됩니다. 여러 문서를 열어 두었다면 어느 문서의 실험인지 헷갈리지 않도록 더 이상 필요 없는 패널은 닫으십시오.
