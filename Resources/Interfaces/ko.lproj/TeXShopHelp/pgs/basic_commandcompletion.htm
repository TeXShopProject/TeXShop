명령어 완성

명령이나 환경의 처음 몇 글자를 입력하고 Escape 키를 누르면, TeXShop이 Completion 파일에 따라 나머지를 완성합니다. Escape 키를 다시 누르면 같은 글자로 시작하는 다른 후보가 파일의 아래쪽에서 위쪽 순서로 차례로 나타나며, Shift-Escape는 반대 방향으로 이동합니다. 후보 중에는 입력한 텍스트 그대로인 것도 있습니다. 예를 들어 \begin{th를 입력하고 Escape 키를 누르면 \begin{theorem} 등의 환경이 제시됩니다.

완성은 단어를 끝맺는 데 그치지 않습니다. \begin{theorem}의 완성은 \end{theorem} 행까지 쓰고, 입력할 곳에 마크(•)를 넣습니다. 첫 번째 마크가 선택되어 있으므로 입력하면 마크가 바뀝니다. Escape 키를 여러 번 누르면 인수가 더 많은 같은 명령이 나오는 경우가 많습니다. \newc로 \newcommand를 완성할 때가 그렇습니다. 완성할 텍스트가 백슬래시로 시작하지 않아도 됩니다. 행의 처음이나 공백 다음에서 sec는 \sec와 같은 결과를 냅니다.

Completion 파일에 해당하는 항목이 없으면 Escape 키는 대신 macOS의 단어 완성을 표시합니다.

설정

설정 › 키보드의 “호출 키”에서 완성에 사용할 키로 Escape와 Tab 중 하나를 선택합니다. 편집 › 실험...의 소스 패널도 소스 윈도우와 같은 키를 사용합니다.

Completion 파일에 단어를 추가하려면 단어를 선택하고 소스 › 명령어 완성 목록에 추가를 선택합니다. 파일을 편집하려면 설정 › 키보드에서 “명령어 완성 파일 편집…”을 클릭합니다. 새 완성을 쓰는 방법은 이미 있는 완성을 살펴보는 것이 가장 좋은 공부입니다. ~/Library/TeXShop/CommandCompletion 폴더에도 자세한 설명 문서가 있습니다.

마크

마크(•)는 나중에 돌아올 위치를 나타냅니다. 메모 있는 마크(•‹메모›)는 그곳에 무엇을 넣을지도 알려 줍니다. 명령어 완성, 매크로, 키 바인딩에는 마크가 들어 있을 수 있으며, 편집 › 마크 › 마크 삽입(⌘8)과 메모 있는 마크 삽입(⌃⌘8)으로 직접 넣을 수도 있습니다. 메모 있는 마크 삽입은 •‹›를 넣고 삽입 위치를 괄호 사이에 두거나, 선택한 텍스트를 메모로 바꿉니다.

다음 마크로 이동(⌃⌘F)과 이전 마크로 이동(⌃⌘G)은 다음 또는 이전 마크를 메모와 함께 선택하므로, 입력하면 마크가 바뀝니다. Option 키를 누르고 있으면 •만 삭제하고 메모를 선택합니다(⌃⌥⌘F, ⌃⌥⌘G).

호출 키로도 마크 사이를 이동할 수 있습니다. 호출 키가 Escape이면 Option-Escape로 다음 마크로, Control-Escape로 이전 마크로 이동하며, Tab이면 Option-Tab과 Control-Tab을 사용합니다. 다른 응용 프로그램에서 이 키가 필요하면 설정 › 키보드에서 “Option 또는 Control과 호출 키로 다음·이전 마크로 이동”을 끄십시오.

레이블과 인용 키 완성

편집 › 레이블 또는 인용 키 완성(F5)은 레이블이나 인용 키를 목록에서 골라 완성합니다. \ref{, \pageref{, \eqref{, \autoref{ 바로 다음이나, 그 뒤에 레이블의 처음 몇 글자를 입력한 다음에 선택하면 파일에서 \label로 정의한 레이블이 목록에 표시됩니다. 화살표 키로 하나를 선택하고 Return 키를 누르십시오. \cite{ 등의 명령 다음에서는 설정 › 키보드의 “BibDesk의 인용 키도 후보로 보여 주기”가 켜져 있으면 BibDesk의 인용 키가 목록에 표시됩니다. 그 밖의 위치에서는 macOS의 단어 완성이 표시됩니다. 많은 키보드에서는 fn 키(지구본 키)를 누른 채 F5를 눌러야 합니다.

키 바인딩, 매크로, 명령어 완성

이 세 기능은 모두 소스에 텍스트를 넣기 때문에 혼동하기 쉽습니다. 각각 알맞은 용도가 다릅니다.

키 바인딩
키 하나를 누르면 텍스트가 들어갑니다. _는 선택 범위를 감싸는 _{}를, ≤(US 자판에서 Option-쉼표)는 \leq를 넣습니다. 새 문서에서 사용할지와 목록은 설정 › 키보드에서, 앞에 있는 문서에서 켜고 끄는 것은 소스 › 키 바인딩에서 설정합니다. 먼저 \를 입력하면 키가 그대로 들어갑니다. 데드 키로 입력하는 문자(Option-E 다음에 E로 입력하는 é 등)에는 키 바인딩을 만들 수 없습니다.
매크로
매크로 메뉴의 항목은 텍스트를 넣거나 AppleScript 프로그램을 실행하며, Command 키나 Control 키, 기능 키를 사용하는 단축키를 붙일 수 있습니다. 매크로 › 매크로 편집기 열기...에서 추가, 편집, 정렬합니다. 선택 범위를 \textbf로 감싸 ⌘B에 지정하는 것처럼 Command 키에 붙이고 싶은 텍스트는 매크로로 만드는 것이 가장 좋습니다.
명령어 완성
명령어의 앞부분이나 약어를 입력하고 호출 키를 누릅니다. \sec는 \section{•}가 되고, 한 번 더 누르면 다음 후보가 되며, \benu는 마크가 있는 enumerate 환경 전체가 됩니다. 키 바인딩이나 매크로와 달리 명령어 완성은 선택한 텍스트를 바꿉니다.
