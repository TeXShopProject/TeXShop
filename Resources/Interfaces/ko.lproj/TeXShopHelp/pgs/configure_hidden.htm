숨겨진 설정

설정 윈도우에는 대부분의 사용자에게 필요한 설정이 있습니다. 그보다 드물게 쓰이는 설정은 숨겨진 설정으로, 설정 윈도우에 컨트롤이 없으며 터미널에서 명령으로 변경합니다. 참고 문서 “매직 코멘트와 숨겨진 설정”(영문)에 모든 숨겨진 설정이 명령과 함께 주제별로 정리되어 있습니다. 도움말 › 매직 코멘트와 숨겨진 설정 (영문)이나 설정 › 일반 › 고급의 “매직 코멘트와 숨겨진 설정 설명서 열기…”로 엽니다.

숨겨진 설정 변경

  1. TeXShop을 종료합니다.
  2. 터미널(/Applications/Utilities에 있습니다)을 열고 명령을 입력한 후 Return 키를 누릅니다.
  3. TeXShop을 다시 시작합니다.

각 명령의 형식은 defaults write TeXShop 이름 값입니다. 기본값으로 되돌리려면 defaults delete TeXShop 이름을 사용합니다.

예

defaults write TeXShop OtherTrashExtensions -array 'nav' 'snm'
파일 › 부수 파일 삭제가 이 확장자의 파일도 제거합니다. 확장자는 마침표 없이 씁니다. 부수 파일 삭제를 참조하십시오.
defaults write TeXShop ConTeXtTags YES
태그 메뉴에 LaTeX의 절 명령 대신 \title, \subject 같은 ConTeXt의 절 명령이 나열됩니다.
defaults write TeXShop RedConsoleAfterError YES
TeX 오류에 응답하여 콘솔에 입력한 텍스트와, 그 실행에서 이후에 나오는 모든 출력이 빨간색으로 표시됩니다.
defaults write TeXShop RefreshTime 2
설정 › 미리보기의 “다른 앱의 PDF 변경을 항상 감시”가 켜져 있는 동안, TeXShop이 2초마다 PDF가 변경되었는지 확인합니다. 기본값은 1초, 최솟값은 0.5초입니다.

설정 윈도우에 있는 설정은 숨겨진 설정에서 다시 다루지 않습니다. 예를 들어 Option 또는 Control과 완성의 호출 키로 편집 › 마크의 다음 마크나 이전 마크로 이동하는 기능은 설정 › 키보드의 “Option 또는 Control과 호출 키로 다음·이전 마크로 이동”으로 켜고 끕니다. 이런 설정을 찾으려면 설정 검색을 사용하십시오. 설정 검색을 참조하십시오.
