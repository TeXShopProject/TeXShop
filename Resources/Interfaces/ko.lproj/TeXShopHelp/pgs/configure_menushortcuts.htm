설정을 열고 키보드를 선택하십시오. 기능으로 검색은 명령 이름과 메뉴 경로를 찾습니다. 키로 검색은 키 입력을 받아 일치하는 메뉴 명령과 매크로를 보여 주고 할당 우선순위를 표시합니다. 명령의 실행 가능 여부는 문서 상태에 따라 달라집니다. 시스템에서 예약한 키는 감지할 수 없습니다. Escape를 누르거나 검색 모드를 다시 클릭하거나 카테고리 또는 윈도우를 바꾸거나 설정을 닫으면 키 기록이 끝납니다. 매크로 행은 읽기 전용입니다. 매크로 편집기에서 보기는 저장하지 않은 편집 내용을 유지하면서 해당 매크로를 선택합니다. 편집 때문에 매크로를 명확하게 식별할 수 없으면 현재 선택을 유지합니다.

설정의 키보드에서 메뉴 단축키를 편집합니다. 명령을 선택하고 “변경…”을 누른 다음 새 단축키를 누르고 “적용”을 선택합니다. Escape를 누르면 취소됩니다. Command 또는 Control 키를 포함하거나 F1–F20 기능 키를 사용해야 합니다. 다른 명령이 사용 중인 단축키이면 충돌을 알립니다. 단축키를 해제하거나 기본값으로 복원할 수도 있습니다. 변경 사항은 즉시 적용되며 TeXShop을 다시 시작해도 유지됩니다.

다른 메뉴 명령이 기본 단축키를 사용 중이면 기본값으로 복원할 수 없습니다. 먼저 해당 명령의 단축키를 변경하십시오.

키와 보조 키가 같으면 메뉴 명령이 매크로보다 우선하며, 사용자 지정 단축키가 있으면 그것을 사용합니다. 사용자 지정으로 비워진 키는 매크로가 사용할 수 있습니다. 매크로가 사용하는 키를 메뉴 명령에 할당하거나 복원할 때는 확인을 요청합니다. 매크로는 메뉴에서 계속 사용할 수 있지만 단축키는 비활성화됩니다. 매크로 편집기는 비활성 단축키와 충돌하는 명령 및 키를 표시합니다. 저장할 때는 가져온 매크로를 포함하여 새로 할당하거나 변경한 충돌 키만 확인합니다. 편집으로 돌아가거나, 충돌 키를 비활성 상태로 저장하거나, 충돌 키를 제거하고 저장할 수 있습니다. 변경하지 않은 기존 충돌은 저장을 중단하지 않습니다. 매크로끼리는 같은 키의 첫 번째 항목이 우선합니다. “단축키 사용 불가”는 메뉴 명령 사이의 충돌에만 해당합니다. 미리보기 창의 Command-F와 Command-G는 사용자 지정이나 해제를 포함하여 찾기와 다음 찾기의 단축키를 따릅니다.

아래에 설명된 KeyEquivalents.plist의 단축키는 기본값으로 사용됩니다. 모든 단축키를 복원해도 이 파일은 유지됩니다. 매크로 단축키는 매크로 편집기에서, 텍스트를 삽입하는 키 바인딩은 키 바인딩 편집기에서 설정합니다.

The keyboard menu shortcuts for TeXShop can be redefined. To do this, read the comments at the top of the file "KeyEquivalents.plist" and make appropriate changes. To do so, edit the file

~/Library/TeXShop/Menus/KeyEquivalents.plist
with TeXShop. Be sure to edit and save in UTF-8 format if you use Unicode characters.

결과 행을 클릭해도 키 기록은 계속됩니다. 세 구역은 항상 펼쳐져 있습니다. 비활성 결과에는 우선하는 할당과 키가 표시되며, 매크로 경로의 그룹은 구분자로 나뉩니다.
