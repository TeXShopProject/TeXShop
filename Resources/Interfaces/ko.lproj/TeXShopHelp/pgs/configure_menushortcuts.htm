설정에는 일반, 문서 및 저장, 편집기, 맞춤법 검사, 모양, 미리보기, 조판, 콘솔, 키보드, 업데이트의 10개 범주가 있습니다. 맞춤법 검사에서 “LaTeX 구조를 고려한 맞춤법 검사 사용(권장)” 또는 “기존 맞춤법 검사 사용”를 선택합니다. 새 방식에는 “LaTeX 제외 규칙 편집…”, 기존 방식에는 들여쓴 하위 옵션 세 개가 있습니다. 방식을 변경해도 값이 유지되며 입력 중 맞춤법 검사는 독립적입니다. 키보드의 키 바인딩과 명령어 완성은 검색 위에 있고 목록만 세로로 스크롤합니다. 창이 낮으면 입력 그룹을 하나씩 펼칠 수 있습니다. 완성 키가 Tab일 때 Tab을 검색하면 예약 안내와 완성 키 설정을 표시합니다. 일반에서 주석 행과 숨겨진 설정 설명을 열 수 있습니다.

설정을 열고 키보드를 선택하십시오. 기능으로 검색은 명령 이름과 메뉴 경로를 찾습니다. 키로 검색은 키 입력을 받아 일치하는 메뉴 명령과 매크로를 보여 주고 할당 우선순위를 표시합니다. 명령의 실행 가능 여부는 문서 상태에 따라 달라집니다. 시스템에서 예약한 키는 감지할 수 없습니다. Escape를 누르거나 검색 모드를 다시 클릭하거나 카테고리 또는 윈도우를 바꾸거나 설정을 닫으면 키 기록이 끝납니다. 매크로 행은 읽기 전용입니다. 매크로 편집기에서 보기는 저장하지 않은 편집 내용을 유지하면서 해당 매크로를 선택합니다. 편집 때문에 매크로를 명확하게 식별할 수 없으면 현재 선택을 유지합니다.

Choose Settings and select Keyboard to edit menu shortcuts. Select a command and press "변경…" (Change), then press the new shortcut and choose "적용" (Apply); press Escape to cancel. A shortcut must use the Command or Control key, or be a function key F1–F20. If the shortcut is already used by another command, TeXShop says so and does not change it. Shortcuts can also be removed or restored. Changes take effect immediately and are kept when TeXShop restarts.

다른 메뉴 명령이 기본 단축키를 사용 중이면 기본값으로 복원할 수 없습니다. 먼저 해당 명령의 단축키를 변경하십시오.

For the same key and modifiers, menu commands take precedence over macros, using their customized shortcuts when present. Macros can use keys freed by customization. Assigning or restoring a menu shortcut used by a macro asks for confirmation; the macro remains available in the menu, but its shortcut becomes inactive without changing its file. The Macro Editor marks inactive shortcuts and shows the conflicting command and key. Saving asks only about newly assigned or changed conflicting keys, including imported macros. You can return to editing, save with those keys inactive, or remove the conflicting keys and save. Existing unchanged conflicts do not interrupt saving. Among macros, the first occurrence of a key takes precedence. “Shortcut Unavailable” applies only to conflicts between menu commands. In the Preview window, Command-F and Command-G follow Find and Find Next, including custom assignments and removal.

Shortcuts set in KeyEquivalents.plist, described below, remain the defaults, and restoring all shortcuts does not change that file. Shortcuts for macros are set in the Macro Editor, and key bindings that insert text are set in the Key Bindings editor.

The keyboard menu shortcuts for TeXShop can be redefined. To do this, read the comments at the top of the file "KeyEquivalents.plist" and make appropriate changes. To do so, edit the file

~/Library/TeXShop/Menus/KeyEquivalents.plist
with TeXShop. Be sure to edit and save in UTF-8 format if you use Unicode characters.

결과 행을 클릭해도 키 기록은 계속됩니다. 세 구역은 항상 펼쳐져 있습니다. 비활성 결과에는 우선하는 할당과 키가 표시되며, 매크로 경로의 그룹은 구분자로 나뉩니다.

설정 검색

사이드바 위의 검색 필드에서 설정, 선택 사항 및 메뉴 명령을 찾습니다. 결과에는 각 설정의 이름과 범주가 표시됩니다. 공백으로 구분한 단어는 같은 설정을 설명해야 하며 범주 이름으로 검색 범위를 좁힐 수 있습니다. 대소문자, 라틴 문자 악센트, 전각 문자 및 히라가나와 가타카나의 차이를 정규화합니다. 검색어를 입력하기만 하면 현재 패널은 바뀌지 않습니다. 결과를 선택하면 해당 행으로 이동하여 값을 바꾸지 않고 강조하며, 이동을 일반 방문 기록에 추가합니다. 검색어를 지워도 현재 패널을 유지합니다. 검색 중에도 뒤로 및 앞으로는 검색어를 지우지 않고 방문 기록에 따라 이동합니다. 메뉴 명령 결과는 키보드의 기능 검색 목록을 필터링합니다. 키 기록 중에는 키 검색이 우선합니다. 개인 경로, 입력한 값 및 사용자가 만든 테마 이름은 검색하지 않습니다.
