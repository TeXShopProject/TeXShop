프린트

조판된 문서를 프린트하려면 미리보기 윈도우나 소스 윈도우에서 파일 › 프린트...(⌘P)를 선택합니다. 루트 파일이 있는 프로젝트에서는 조판된 루트 문서가 프린트됩니다.

프린트 대화상자에는 Apple의 미리보기 앱과 같은 선택 항목이 있는 TeXShop 섹션이 있습니다. 자동 회전을 선택하면 각 페이지가 용지에 맞게 회전하므로, 가로 방향 페이지는 세로 방향 용지에 옆으로 프린트됩니다. 크기에 맞게 조절을 선택하면 각 페이지가 용지에 맞게 확대되거나 축소됩니다. 정해진 비율로 프린트하려면 대신 크기 조절을 선택하십시오. 둘 다 처음에는 켜져 있으며, 마지막으로 프린트할 때의 선택은 문서가 열려 있는 동안 유지됩니다. 용지 방향은 첫 페이지를 따릅니다.

소스 텍스트를 프린트하려면 파일 › 소스 프린트...를 선택합니다. 용지 크기는 파일 › 페이지 설정...에서 선택합니다.
