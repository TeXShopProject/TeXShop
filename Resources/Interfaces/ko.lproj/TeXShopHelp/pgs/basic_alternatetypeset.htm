대체 조판 방식

TeXShop은 보통 PDF 직접 생성 방식으로 조판합니다. pdfLaTeX나 pdfTeX가 PDF 파일을 직접 만드는 방식입니다. 대체 방식인 DVI 경유는 LaTeX나 TeX로 DVI 파일을 만들고, dvips로 이를 PostScript로 변환한 후, Ghostscript로 PostScript를 PDF로 변환합니다. 이 단계는 TeX Live의 스크립트 simpdftex가 수행합니다.

DVI 경유 방식은 pstricks 패키지처럼 출력에 PostScript 코드를 넣는 문서에 필요합니다. EPS 그림 때문에 이 방식을 쓸 필요는 없습니다. PDF 직접 생성으로 조판할 때 TeX Live가 EPS 그림을 PDF로 변환합니다.

방식 선택

조판 › DVI 경유와 조판 › PDF 직접 생성은 활성 문서의 방식을 전환합니다. 열려 있는 다른 문서는 각자의 방식을 유지합니다. 문서가 처음에 사용하는 방식은 설정 › 조판 › 조판 방식에서 정합니다. 세 번째 선택 항목인 사용자 스크립트를 선택하면 사용자 스크립트 그룹의 명령이 대신 실행됩니다. DVI 경유의 명령은 plain TeX용과 LaTeX용 하나씩 설정 › 조판의 DVI 경유 그룹에 있습니다. 엔진 프로파일 메뉴의 기타에 있는 LaTeX + dvips + Ghostscript 프로파일을 선택하면 DVI 경유 조판에 맞게 설정됩니다.

문서에서 방식 선택

소스의 처음 20행 안에 다음 행 중 하나를 넣으면, 설정과 관계없이 그 문서의 프로그램과 방식이 정해집니다.

행조판 방식
% !TEX program = pdflatexLaTeX, PDF 직접 생성
% !TEX program = latexLaTeX, DVI 경유
% !TEX program = pdftexplain TeX, PDF 직접 생성
% !TEX program = texplain TeX, DVI 경유
% !TEX program = personallatexLaTeX, 사용자 스크립트
% !TEX program = personaltexplain TeX, 사용자 스크립트

DVI 경유의 옵션

Ghostscript는 기본적으로 PostScript의 투명도를 무시합니다. 투명도를 유지하려면 DVI 경유 그룹의 명령 끝에 --distilleropts "-dALLOWPSTRANSPARENCY"를 추가하십시오. 중간 PostScript 파일을 남기려면 --keep-psfile을 추가합니다. Ghostscript는 설정 › 조판 › 경로 › Ghostscript에 지정된 폴더에서 실행됩니다.
