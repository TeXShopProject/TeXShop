Shell Escape 보호

TeX는 조판하는 동안 다른 프로그램을 실행할 수 있습니다. TeX Live는 기본적으로 EPS 그림을 PDF로 변환하는 프로그램처럼 신뢰할 수 있는 몇몇 프로그램만 허용합니다. 다른 프로그램을 실행해야 하는 패키지는 -shell-escape 옵션(--shell-escape라고도 씀)을 요구합니다.

이 옵션을 사용하면 문서가 어떤 명령이든 실행할 수 있습니다. 예를 들어 홈 폴더의 모든 파일을 지우는 명령도 실행할 수 있습니다. 이 옵션은 신뢰할 수 있는 문서에만 사용하고, 다른 사람에게서 받은 파일에는 사용하지 마십시오.

옵션 추가하기

  • 설정 › 조판 › PDF 직접 생성의 LaTeX 명령이나 plain TeX 명령에 추가하면, PDF 직접 생성으로 조판하는 모든 문서에 적용됩니다.
  • 엔진 파일에 추가하면 그 엔진으로 조판하는 모든 문서에 적용됩니다. 조판 엔진 추가하기를 참고하십시오.
  • pdflatexmk 같은 latexmk 엔진으로 조판하는 문서 하나에만 적용하려면, 소스 첫머리에 % !TEX parameter = -shell-escape 줄을 넣습니다.

shell-escape 시 확인

설정 › 조판 › PDF 직접 생성 › “shell-escape 시 확인”은 PDF 직접 생성 그룹의 명령을 감시하며, 기본적으로 꺼져 있습니다. 이 설정이 켜져 있고 그 그룹의 plain TeX 명령이나 LaTeX 명령에 -shell-escape나 --shell-escape가 들어 있으면, TeXShop은 문서를 연 뒤 처음으로 조판하기 전에 다음과 같이 묻습니다.

  • “확인”을 누르면 옵션을 사용하여 조판합니다.
  • “Shell Escape 생략”을 누르면 옵션 없이 조판합니다.
  • “취소”를 누르면 조판하지 않습니다.

“확인”이나 “Shell Escape 생략”을 선택하면 그 문서를 닫을 때까지 그 대답이 유지됩니다. 따라서 자신의 문서는 옵션을 사용하여, 다른 사람의 문서는 옵션 없이 조판할 수 있습니다. 엔진 파일은 -shell-escape가 들어 있어도 확인하지 않습니다.
