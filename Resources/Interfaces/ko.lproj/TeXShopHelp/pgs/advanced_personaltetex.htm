TeX Live에 개인 파일 추가하기

TeX Live에 들어 있지 않은 스타일 파일, 클래스, 참고 문헌 데이터베이스 등은 개인 TeX 트리에 넣습니다. 개인 TeX 트리는 홈 폴더의 라이브러리 폴더 안에 있는 texmf 폴더, 즉 ~/Library/texmf입니다. TeX Live의 모든 프로그램이 이 폴더의 파일을 찾으며, TeX Live 자체에 이름이 같은 파일이 있어도 이 폴더의 파일이 우선합니다. 파일을 추가한 뒤에 따로 등록할 필요는 없으며, 다음 조판부터 바로 사용됩니다.

라이브러리 폴더는 Finder에서 가려져 있습니다. 이 폴더를 열려면 Finder에서 이동 › 폴더로 이동…을 선택하고 ~/Library를 입력합니다. 그 안에 texmf 폴더가 아직 없으면 만듭니다.

패키지를 추가하기 전에

CTAN에 있는 패키지는 대부분 이미 TeX Live에 들어 있으며, MacTeX는 그 전부를 설치합니다. TeX에 어떤 파일이 이미 있는지 알아보려면 TeXShop에서 파일 › 스타일 파일 열기...를 선택하고 hyperref.sty처럼 파일 이름을 입력합니다. 그러면 TeX가 사용할 파일이 열립니다. 개인 트리에는 TeX Live에 없는 패키지나, 따로 필요한 버전만 추가하십시오. 개인 트리의 파일이 우선하므로, TeX Live에 새 버전이 들어오면 개인 트리의 파일을 지우십시오. 그대로 두면 계속 이전 버전이 사용됩니다.

파일을 넣는 위치

texmf 안의 폴더는 TeX Live와 같은 구조를 따릅니다. 필요한 폴더를 만드십시오.

폴더내용
tex/latex/LaTeX 패키지와 클래스(.sty, .cls). 패키지마다 폴더를 따로 만듭니다
tex/plain/plain TeX용 파일
tex/generic/어느 포맷에서나 사용하는 파일
bibtex/bib/참고 문헌 데이터베이스(.bib)
bibtex/bst/참고 문헌 스타일(.bst)
doc/추가한 패키지의 문서. 도움말 › 패키지 도움말 보이기...가 이곳에서도 문서를 찾습니다

예를 들어 직접 만든 매크로 패키지와 참고 문헌 데이터베이스는 다음 위치에 둡니다.

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

이렇게 하면 문서를 어디에 저장하든 모든 문서에서 \usepackage{mymacros}와 \bibliography{mybibliography}를 사용할 수 있습니다.

폴더 확인하기

TeX가 개인 트리로 사용하는 폴더를 확인하려면 터미널에서 다음과 같이 입력합니다.

kpsewhich -var-value TEXMFHOME

설치할 때 따로 설정하지 않았다면 Mac에서는 ~/Library/texmf입니다. TeX가 어느 파일을 읽을지 확인하려면 예를 들어 kpsewhich mymacros.sty를 입력합니다.

TeX Live 자체의 폴더에는 파일을 추가하지 마십시오. TeX Live 자세히 알아보기를 참조하십시오.
