시작하기 전에

이 장에서는 TeXShop을 작업 방식에 맞추는 방법을 설명합니다. 먼저 확인할 만한 설정, TeXShop이 ~/Library/TeXShop의 파일을 최신 상태로 유지하는 방법, 숨겨진 설정, 그리고 LaTeX 패널, 키 바인딩, 메뉴 단축키를 변경하는 방법입니다.

설정 윈도우

TeXShop › 설정…을 선택하면 설정 윈도우가 열립니다. 사이드바에는 일반, 문서 및 저장, 편집기, 키보드, 맞춤법 검사, 테마, 조판, 콘솔, 미리보기, 업데이트의 10개 범주가 있습니다. 어느 범주에 있는지 모르는 설정을 찾으려면 사이드바 위의 설정 검색 필드에 단어를 입력하고 결과를 선택하십시오. 해당 설정이 표시되고 강조됩니다. 설정 검색을 참조하십시오.

많은 설정에는 대응하는 메뉴 명령이 있습니다. 예를 들어 소스 › 행번호 보이기와 편집기의 “행 번호 보이기” 설정이 그렇습니다. 메뉴 명령은 활성 문서가 열려 있는 동안 그 문서만 변경하고, 설정은 문서를 열 때의 모양과 동작을 정합니다.

예전에 파일을 편집해야 했던 일 대부분을 이제는 TeXShop 안에서 할 수 있습니다. 설정 › 키보드에는 키 바인딩, 명령어 완성 목록(“명령어 완성 파일 편집…”), 메뉴 단축키가 있습니다. 매크로는 매크로 편집기(매크로 › 매크로 편집기 열기...)에서, 색상 테마는 설정 › 테마에서 편집합니다.

~/Library/TeXShop 폴더

템플릿, 매크로, 엔진, LaTeX 패널 파일, 키 바인딩, 명령어 완성 목록, 테마 등 사용자가 변경할 수 있는 파일은 홈 폴더의 라이브러리 폴더 안에 있는 TeXShop 폴더, 즉 ~/Library/TeXShop에 보관됩니다. TeXShop › ~/라이브러리/TeXShop 폴더 열기를 선택하면 Finder에서 이 폴더가 열립니다. TeXShop의 새 버전은 이 폴더에서 사용자가 변경한 내용을 유지합니다. 어떤 파일을 업데이트하는지는 새 라이브러리 항목 받기에서 설명합니다.

매크로, LaTeX 패널 파일, 키 바인딩, 테마처럼 TeXShop에 필요한 파일이 없거나 손상되어 있으면, TeXShop은 시작할 때 메시지 없이 자체 사본으로 바꿉니다. 손상된 파일은 ~/Library/TeXShop/Backups에 보관되므로, 거기서 변경 내용을 되살릴 수 있습니다.

폴더의 내용을 기본 상태로 되돌리려면 TeXShop을 종료하고, 폴더(예: Templates)를 ~/Library/TeXShop 밖으로, 예를 들어 데스크탑으로 옮긴 다음 TeXShop을 다시 시작하십시오. TeXShop이 기본 내용으로 폴더를 다시 만듭니다. 남기고 싶은 것은 옮겨 둔 폴더에서 다시 복사하십시오.

숨겨진 설정과 매직 코멘트

설정 윈도우에 없는 설정도 몇 가지 있으며, 터미널에서 명령으로 변경합니다. 숨겨진 설정을 참조하십시오. 소스 파일 첫머리의 % !TEX program = lualatex 같은 매직 코멘트는 그 파일에 한해 엔진, 인코딩, 루트 파일 등을 정합니다. 모든 매직 코멘트와 숨겨진 설정은 도움말 › 매직 코멘트와 숨겨진 설정 (영문)에 정리되어 있습니다.
