미리보기 윈도우

미리보기 윈도우는 조판된 PDF 파일을 표시합니다. 조판할 때마다 갱신되며, 읽고 있던 페이지에 그대로 머뭅니다. 관련 설정은 설정 › 미리보기에 있습니다. 그중 “문서를 열 때” 그룹의 설정은 문서를 열 때 적용되며, 미리보기 메뉴는 맨 앞 윈도우의 설정을 변경합니다.

문서 안에서 이동

미리보기 › 보기 형식에서 페이지 배치 방법을 선택합니다. 단일 페이지와 두 페이지는 한 페이지 또는 한 쌍의 페이지를 표시하고, 연속 스크롤과 연속 두 페이지는 모든 페이지를 하나의 긴 열로 표시합니다. 윈도우가 처음 사용하는 형식은 “문서를 열 때”의 “페이지 형식”에서 정합니다. 미리보기 메뉴와 도구 막대의 이전 페이지와 다음 페이지는 페이지를 넘기고, 도구 막대의 페이지로 이동 필드는 번호로 페이지를 찾아가며, 도구 막대의 뒤로/앞으로에 있는 두 화살표는 웹 브라우저처럼 이전에 보던 위치로 돌아갑니다.

단일 페이지와 두 페이지에서는 페이지의 맨 위나 맨 아래를 넘어 스크롤하면 페이지가 넘어갑니다. 페이지 끝에서 멈추게 하려면 설정 › 미리보기 › 표시 및 탐색에서 “스크롤로 페이지를 넘기지 않음”을 켜십시오. 위쪽 및 아래쪽 화살표 키는 페이지 안에서 스크롤합니다. 왼쪽 및 오른쪽 화살표 키는 확대한 페이지가 윈도우보다 넓을 때 옆으로 스크롤하고, 그렇지 않을 때는 페이지를 넘깁니다. “왼쪽·오른쪽 화살표 키로 항상 페이지를 넘김”을 켜면 항상 페이지를 넘깁니다.

도구 막대에는 페이지에 관한 메뉴가 두 개 있습니다. 이 메뉴를 없앴다면 윈도우 › 도구 막대 사용자화...로 되돌릴 수 있습니다. 페이지 레이아웃은 보기 형식을 선택합니다. 두 페이지 배열은 이 문서에 한해 한 쌍의 페이지를 왼쪽에서 오른쪽으로 읽을지 오른쪽에서 왼쪽으로 읽을지, 첫 페이지를 표지로 따로 표시할지를 선택하며, 이 메뉴의 문서 설정 복원을 선택하면 설정의 값으로 돌아갑니다. 해당 설정은 “문서를 열 때”의 “페이지 방향”과 “첫 페이지를 표지로 따로 표시”이며, 매직 코멘트 % !TEX PageDirectionL2R, % !TEX PageDirectionR2L, % !TEX bookDisplay, % !TEX standardDisplay로 문서별로 지정할 수 있습니다.

배율

미리보기 › 배율에는 다음 항목이 있습니다.

윈도우에 맞추기
페이지가 윈도우의 폭에 꽉 차게 표시되며, 윈도우 크기를 바꾸면 배율도 바뀝니다.
내용 너비에 맞추기
윈도우에 맞추기와 비슷하지만 흰 여백을 제외합니다. 페이지에서 조판된 부분이 윈도우의 폭에 꽉 차게 표시됩니다.
고정 배율
도구 막대의 배율 필드나 확대(⇧⌘+)와 축소(⇧⌘_)로 정한 배율이 유지됩니다.
실제 크기
페이지를 종이 크기대로 표시합니다.

같은 하위 메뉴 끝에 있는 내용에 맞게 확대/축소와 내용 너비에 맞게 확대/축소는 페이지에서 조판된 부분이 윈도우에 들어맞거나 윈도우의 폭을 채우도록 배율을 한 번 설정합니다. 도구 막대나 이 명령, 또는 트랙패드에서 손가락을 오므리거나 벌려 배율을 바꾸면 윈도우는 고정 배율로 전환됩니다. 원래대로 돌아가려면 윈도우에 맞추기를 다시 선택하십시오. 배율 필드 옆의 단어를 클릭하면 배율 메뉴가 열립니다. 윈도우가 처음 사용하는 배율은 “문서를 열 때”의 “윈도우 크기를 변경한 후”와 “배율”에서 정합니다.

마우스 도구

도구 막대의 마우스 모드 항목에서 페이지 위에서 포인터가 할 일을 선택합니다. 스크롤은 페이지를 움직입니다. 텍스트 선택은 복사할 텍스트를 선택합니다. 확대경과 확대경 (크게)는 마우스 버튼을 누르고 있는 동안 돋보기를 표시합니다. 이중 클릭한 채로 누르고 있으면 더 큰 돋보기가, 세 번 클릭한 채로 누르고 있으면 윈도우 전체를 확대하는 돋보기가 나타나며, Command, Option 또는 Control 키를 누르면 더 크게 확대하고, 그중 하나와 함께 Shift 키를 누르면 덜 확대합니다. 직사각형 선택은 페이지의 영역을 선택하여 그림으로 복사합니다. 윈도우가 처음 사용하는 도구는 “문서를 열 때”의 “마우스 모드”에서 선택합니다.

직사각형 선택 도구로 페이지의 영역을 드래그한 다음 ⌘C로 복사하거나, 다른 응용 프로그램 또는 데스크탑으로 드래그합니다. 미리보기 › 선택 부분을 파일로 저장...은 선택 영역을 파일로 저장합니다. 미리보기 › 복사 형식에서 복사할 형식을 PDF로 할지 PNG, TIFF, JPEG 같은 그림으로 할지 선택하며, 기본값은 설정 › 미리보기 › 이미지 복사의 “복사할 이미지 형식”에서 정합니다. 복사하여 붙여넣기와 드래그 앤 드롭을 참조하십시오.

검색과 서랍

도구 막대의 PDF 검색 필드에 단어를 입력하고 Return을 누르면 처음 나오는 위치가 선택됩니다. ⌘G로 다음 위치로 이동합니다. 미리보기 윈도우가 앞에 있을 때 ⌘F를 누르면 이 필드로 이동합니다.

미리보기 › 서랍 여닫기나 도구 막대의 서랍 항목을 사용하면 서랍이 표시됩니다. 서랍의 위쪽에는 hyperref 패키지가 장과 절로 만드는 문서의 개요가 표시됩니다. 항목을 클릭하거나 화살표 키로 선택하고 Return을 누르면 그 위치로 이동합니다. 아래쪽은 두 번째 검색 필드로, 찾은 위치를 모두 페이지와 함께 나열합니다. 항목을 클릭하면 그 위치로 이동합니다.

링크와 링크 팝업

hyperref 패키지로 만든 링크는 미리보기에서 동작합니다. 참조를 클릭하면 해당 정리나 참고 문헌 항목으로 이동하고, 뒤로/앞으로의 왼쪽 화살표로 돌아옵니다. 웹 주소는 웹 브라우저에서 열립니다.

포인터를 링크 위에 올려 두면 링크된 위치가 팝업으로 표시되며, 오른쪽 아래 모서리에 페이지 번호가 표시됩니다. 팝업은 몇 초 후에 사라집니다. 팝업이 나타날 때 누르고 있는 키에 따라 팝업이 달라집니다.

Shift
팝업을 링크 아래가 아닌 위에 표시합니다.
Command
더 큰 팝업을 표시합니다.
Option
팝업을 고정하여 사라지지 않게 합니다. 팝업이 표시된 동안 Option 키를 눌러도 고정됩니다.
Control
이 링크에 한해 링크 팝업의 켬/끔을 반대로 합니다. 링크 팝업이 켜져 있으면 팝업이 나타나지 않으므로 Control-클릭할 때 방해가 되지 않고, 꺼져 있으면 팝업이 나타납니다.

고정된 팝업은 옮기거나 크기를 바꾸거나 스크롤할 수 있으며, 텍스트를 선택하여 복사할 수 있습니다. 클릭, 스크롤, 확대/축소, 링크 이동, 다른 윈도우에서의 작업을 해도 해당 페이지의 원래 위치에 그대로 머물며, 미리보기 윈도우에서 Escape 키를 누르면 사라집니다. 팝업이 고정된 동안에도 다른 팝업은 나타나며, Option 키를 누르면 그 팝업이 대신 고정됩니다.

미리보기 › 링크 팝업은 그 윈도우의 팝업을 켜거나 끄며, 문서를 열 때 켜져 있을지는 “문서를 열 때”의 “링크 팝업”에서 정합니다. 페이지 번호를 표시하지 않으려면 설정 › 미리보기 › 표시 및 탐색의 “링크 팝업에 페이지 번호 표시”를 끄십시오. 직사각형 선택 도구를 선택한 동안에는 팝업이 나타나지 않습니다.

윈도우 분할

윈도우 › 윈도우 분할(⌃2)이나 도구 막대의 미리보기 분할 항목을 사용하면 미리보기 윈도우가 두 부분으로 나뉘어 문서의 서로 다른 위치를 표시할 수 있습니다. 다시 선택하면 분할이 해제됩니다. Option 키를 누르고 있으면 좌우로 나뉩니다(윈도우 › 윈도우 세로 분할, ⌃⌥2). 각 부분은 자체 보기 형식과 배율을 가집니다. 마지막으로 클릭한 부분이 활성 부분이며, 강조 색상의 가는 선으로 표시됩니다. 도구 막대, 서랍, SyncTeX, 미리보기 메뉴는 활성 부분에 작용하며, 분할을 해제하면 활성 부분이 남습니다.

내부 링크를 Control-클릭하거나 마우스 오른쪽 버튼으로 클릭하고 “윈도우를 분할하여 링크 대상 표시”를 선택하면, 링크가 보이는 상태 그대로 다른 부분에 링크된 위치가 표시됩니다. 필요하면 윈도우가 먼저 분할됩니다.

윈도우 › 보기 전환(⌥2)은 분할된 윈도우의 두 부분을 서로 바꿉니다. 분할되지 않은 윈도우에서는 각자 위치, 보기 형식, 배율을 가진 두 보기 사이를 전환하므로, 문서의 두 위치를 오갈 수 있습니다.

전체 화면

윈도우 › 전체 화면 시작(⌃⌘F)을 선택하면 미리보기가 화면 전체에 표시됩니다. 이때 윈도우의 분할이 해제되고, 마지막으로 전체 화면에서 사용한 배율과 보기 형식이 적용되며, 전체 화면을 끝내면 원래 배율과 보기 형식으로 돌아갑니다. 분할 상태, 배율, 보기 형식을 그대로 유지하려면 설정 › 미리보기 › 표시 및 탐색에서 “전체 화면 시작 시 배율, 보기 형식, 분할 상태 유지”를 켜십시오. 전체 화면에서는 첫 번째 Escape 키가 고정된 팝업을 닫고, 두 번째 Escape 키가 전체 화면을 끝냅니다.

주석

미리보기 › 주석 도구 막대 보기를 선택하면 윈도우의 도구 막대 아래에 주석 도구가 표시됩니다. 주석 도구 막대 왼쪽 끝의 편집 모드를 클릭한 다음, 버튼을 사용하여 선택한 텍스트에 취소선, 하이라이트, 밑줄을 긋거나 도형, 화살표, 텍스트, 메모를 추가합니다. 주석은 소스의 일부가 아니며 다음 조판 때 PDF 파일이 새로 만들어지므로, 주석 도구 막대의 주석 저장…으로 저장하십시오. PDF 파일의 사본이 저장되며, 예를 들어 Fourier.tex라면 Fourier-Annotated.pdf라는 이름이 됩니다. 편집 모드에서 작업한 후에는 다시 조판하거나 윈도우를 닫기 전에 TeXShop이 주석을 저장할지 묻습니다. 주석에 대한 자세한 설명은 TeXShop 설명서에 있습니다.

그 밖의 기능

미리보기에서 Command-클릭하면 소스의 대응하는 위치로 이동합니다. 문서 조판을 참조하십시오. 미리보기 메뉴의 시계방향으로 회전과 반시계방향으로 회전은 페이지를 회전합니다. latexmk 같은 다른 응용 프로그램이 PDF 파일을 다시 쓰면 미리보기는 TeXShop이나 미리보기 윈도우로 돌아왔을 때 같은 위치에서 파일을 다시 불러옵니다. TeXShop이 뒤에 있을 때도 바로 다시 불러오게 하려면 설정 › 미리보기 › 새로 고침에서 “다른 앱의 PDF 변경을 항상 감시”를 켜십시오. 미리보기 › 미리보기 윈도우 위치 저장을 선택하면 새 미리보기 윈도우가 맨 앞 윈도우의 위치와 크기로 열립니다.
