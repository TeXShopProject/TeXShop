LaTeX 패널

윈도우 › LaTeX 패널...을 선택하면 수학 기호, 그리스 문자, 함수, 악센트가 붙은 문자와 각국 문자, 환경, 서체 명령 등 LaTeX 코드를 모은 패널이 열립니다. 소스에서 코드를 넣을 위치를 클릭한 다음 패널의 버튼을 클릭하면, 그 코드가 삽입 위치에 삽입됩니다. 작업하는 동안 패널은 소스 윈도우 앞에 머뭅니다.

버튼은 여러 페이지에 나뉘어 있습니다. 패널의 각 부분 위쪽에 있는 버튼으로 페이지를 선택합니다. 수학기호, 그리스 문자, 기호, 함수, 국제문자, 그리고 TeX 환경, 서체, 사용자화입니다.

서체 버튼이나 환경 버튼을 클릭할 때 텍스트가 선택되어 있으면, \textbf{선택한 텍스트}처럼 선택한 텍스트가 삽입되는 코드 안에 들어갑니다.

일부 기호에는 amssymb 패키지가 필요합니다. 이런 기호를 사용하는 문서의 프리앰블에 다음 행을 추가하십시오.

\usepackage{amssymb}

패널 사용자화

각 버튼이 삽입하는 코드는 ~/Library/TeXShop/LatexPanel/completion.plist에 있습니다. 변경하려면 이 파일을 TeXShop에서 여십시오. 파일 첫머리의 주석에 구성이 설명되어 있습니다. 표준 버튼의 이름은 바꿀 수 없지만, 버튼이 삽입하는 코드는 바꿀 수 있습니다. 이 코드에서

  • #SEL#은 선택한 텍스트를 나타냅니다.
  • #INS#은 코드를 삽입한 후 삽입 위치가 놓일 곳을 나타냅니다.
  • #PASTE#는 클립보드의 텍스트를 나타냅니다.

사용자화 페이지에는 사용자 버튼을 16개까지 만들 수 있습니다. 각 버튼은 파일의 Customized 목록에 버튼 이름과 삽입할 코드, 두 문자열로 정의합니다.

<string>Section</string>
<string>\section{#SEL##INS#}</string>

파일을 UTF-8로 저장한 다음 TeXShop을 종료했다가 다시 시작하면 변경 내용이 패널에 반영됩니다. 파일이 없거나 손상되어 있으면 TeXShop이 자체 사본으로 바꿉니다. LaTeX 패널 수정과 ~/Library/TeXShop의 파일을 참조하십시오.
