설정에는 일반, 문서 및 저장, 편집기, 맞춤법 검사, 모양, 미리보기, 조판, 콘솔, 키보드, 업데이트의 10개 범주가 있습니다. 맞춤법 검사에서 “LaTeX 구조를 고려한 맞춤법 검사 사용(권장)” 또는 “기존 맞춤법 검사 사용”를 선택합니다. 새 방식에는 “LaTeX 제외 규칙 편집…”, 기존 방식에는 들여쓴 하위 옵션 세 개가 있습니다. 방식을 변경해도 값이 유지되며 입력 중 맞춤법 검사는 독립적입니다. 키보드의 키 바인딩과 명령어 완성은 검색 위에 있고 목록만 세로로 스크롤합니다. 창이 낮으면 입력 그룹을 하나씩 펼칠 수 있습니다. 완성 키가 Tab일 때 Tab을 검색하면 예약 안내와 완성 키 설정을 표시합니다. 일반에서 주석 행과 숨겨진 설정 설명을 열 수 있습니다.

Settings uses a resizable window with a category sidebar and Back/Forward navigation. Command-left bracket and Command-right bracket navigate Settings while that window is active, taking precedence over menu shortcuts there. The last category is remembered; navigation history is cleared when Settings closes. Select categories with the mouse or arrow keys, then use Tab to reach their controls. Scroll the content when the window is small. References in older help to Settings tabs now mean sidebar categories. Theme color groups are shown together in Appearance. Escape cancels profile confirmation; Return does not apply it.

Command-bracket navigation also supports brackets produced with Option. Back and Forward buttons are available on every layout.

Starting with TeXShop 5.60, Settings changes are saved immediately. Press Return or leave a text field to validate it. Closing Settings or changing categories also validates unfinished input; invalid input does not replace the last saved value. There is no whole-window OK or Cancel. The Preview zoom setting is the default for newly opened PDFs; existing PDFs keep their zoom. Source and console font changes update open windows. Theme edits are saved before documents refresh; duplicate a theme before editing to retain the original. If saving fails, the last saved colors are restored. A settings profile asks for confirmation before resetting known engine, editing, display, hidden settings and the running Dock icon. Shortcuts, language, window layouts, automatic updates, theme files and unknown settings are preserved; theme selections may change.

Users should consider changing a small number of default settings provided by TeXShop. Some of these changes depend on characteristics of individual displays and cannot be set until you use the program.

By default, TeXShop opens source and preview windows in the spot they last appeared. This only makes sense when you deal with one document at a time. It is usually better to open source and preview windows in a predetermined optimal position. To make that happen, typeset a simple document. Then arrange the position and size of the source and preview windows. Side by side is best if your screen is large enough. Open TeXShop Settings. In the "General" category, select "All Windows Start At Fixed Position" and click "Set With Current Position." Make the same change in the "Preview" category.

A later addition to TeXShop makes this easier. Instead of opening TeXShop Settings, activate the source window and then choose ``Save Source Position'' in the Source Menu. Then activate the preview window and select ``Save Preview Position'' in the Preview Menu.

If you have a portable connected to a large monitor, the above commands will configure for display on the large monitor. It is possible to also configure for trips when the portable is used by itself without the monitor. This configuration can be done with the large monitor attached, or without. Arrange the source and preview windows as desired on the portable screen. Activate the source window and select the menu item ``Save Source Position for Portable'' in the Source Menu, Then activate the preview window and select ``Save Preview Position for Portable'' in the preview window.

Settings use vertically stacked groups with wrapping labels. Themes shows both color groups in one pane. Creating a theme uses a name sheet attached to Settings; replacing an existing theme requires confirmation. Cancelling either sheet leaves existing files unchanged.
