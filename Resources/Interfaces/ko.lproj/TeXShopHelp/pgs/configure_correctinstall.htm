새 라이브러리 항목 받기

TeXShop은 템플릿, 매크로, 엔진, 키 바인딩, LaTeX 패널 파일, 테마처럼 사용자가 변경할 수 있는 파일을 홈 폴더의 라이브러리 폴더 안에 있는 TeXShop 폴더, 즉 ~/Library/TeXShop에 보관합니다. TeXShop › ~/라이브러리/TeXshop 폴더열기를 선택하면 Finder에서 이 폴더가 열립니다. TeXShop을 처음 실행하면 기본 내용으로 이 폴더가 만들어집니다.

새 버전이 변경하는 것

TeXShop의 새 버전은 ~/Library/TeXShop의 대부분을 그대로 두므로 사용자가 변경한 내용이 유지됩니다. 다만 TeXShop 자체의 지원 파일이나 선택 항목을 담은 몇몇 위치는 새 버전이 최신 상태로 바꿉니다.

  • bin, Documents, ExternalEditorScripts, Scripts 폴더
  • 사용하도록 옮길 수 있는 엔진과 HTML 파일이 든 Engines/Inactive와 HTML/Inactive
  • 도움말 › HTML 명령 (영문)이 표시하는 페이지인 HTML/Help.html
  • 통째로 바뀌는 New 폴더

이 위치에서는 TeXShop에 들어 있는 모든 파일이 새 버전으로 바뀌므로, 그런 파일에 가한 변경은 사라집니다. 새 파일은 추가되며, 사용자가 다른 이름으로 추가한 파일은 그대로 남습니다. 이런 파일을 자신의 버전으로 유지하려면 다른 이름으로 저장하십시오.

Engines 폴더 자체에 있는 사용 중인 엔진은 변경되지 않습니다. 이 폴더를 마지막으로 업데이트한 TeXShop이 6.00보다 오래된 버전일 때만, TeXShop은 같은 이름의 파일이 없는 경우에 한해 html.engine을 Engines에 한 번 추가합니다. Macros 폴더에서는 TeXShop에 들어 있던 매크로 중 한 번도 편집하지 않은 매크로가 현재 텍스트로 업데이트될 수 있으며, 편집한 매크로와 사용자가 만든 매크로는 그대로 남습니다. 그 밖의 모든 것은 사용자가 변경한 대로 유지됩니다.

TeXShop은 ~/Library/TeXShop/New 안의 숨김 파일 .Version에 버전을 기록하고, 자신이 거기 기록된 버전보다 새로울 때만 폴더를 업데이트합니다. 따라서 TeXShop을 시작할 때마다 ~/Library/TeXShop이 다시 쓰이지는 않으며, 이전 버전의 TeXShop을 실행해도 폴더가 바뀌지 않습니다.

New 폴더

New 폴더에는 새 템플릿처럼 사용자가 직접 추가할 만한 항목이 들어 있습니다. 그런 항목을 Templates 같은 알맞은 폴더로 옮기고 원하는 대로 편집하십시오. 가져올 것이 있으면 도움말 › 이 버전에 대하여 (영문)에서 알려 줍니다.

없거나 손상된 파일

매크로, LaTeX 패널 파일, 키 바인딩, KeyEquivalents.plist, 테마처럼 TeXShop에 필요한 파일이 없거나 손상되어 있으면, TeXShop은 시작할 때 메시지 없이 자체 사본으로 바꿉니다. 손상된 파일은 ~/Library/TeXShop/Backups에 보관되므로, 거기서 변경 내용을 되살릴 수 있습니다.

폴더의 기본 내용 받기

Templates 같은 폴더의 최신 기본 내용을 받으려면 TeXShop을 종료하고, 그 폴더를 ~/Library/TeXShop 밖으로(예를 들어 데스크탑으로) 옮긴 다음 TeXShop을 다시 시작하십시오. 기본 내용으로 폴더가 만들어집니다. 그런 다음 남기고 싶은 것을 옮겨 둔 폴더에서 다시 복사하십시오.
