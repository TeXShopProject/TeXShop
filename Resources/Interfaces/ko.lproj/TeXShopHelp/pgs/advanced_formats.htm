TeX 포맷 만들고 사용하기

포맷 파일(확장자 .fmt)은 TeX가 매크로 묶음을 읽은 상태를 그대로 저장해 둔 것입니다. LaTeX 자체도 하나의 포맷으로, TeX는 매번 LaTeX 소스를 읽는 대신 이 포맷을 순식간에 불러옵니다. 긴 프리앰블로 자신만의 포맷을 만들어 조판이 더 빨리 시작되게 하거나, 프로젝트나 기관에서 제공하는 포맷을 사용할 수 있습니다.

포맷은 그것을 만든 엔진과 TeX Live 버전에서만 작동합니다. TeX Live 2026의 pdfLaTeX로 만든 포맷은 XeLaTeX나 다른 연도의 TeX Live에서 사용할 수 없습니다. 새 TeX Live를 설치한 뒤에는 포맷을 다시 만드십시오.

포맷 만들기

포맷에 넣을 줄을 파일에 쓰고, 마지막 줄에 \dump를 둡니다. 예를 들어 uo.tex는 다음과 같습니다.

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

터미널에서 이 파일이 있는 폴더로 이동하여 아래와 같이 입력합니다.

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

이 명령은 LaTeX 포맷을 불러온 뒤 uo.tex를 읽어 uo.fmt를 만듭니다. 이 포맷으로 조판하는 문서에서는 포맷에 들어 있는 줄을 빼고 \begin{document}로 시작합니다.

TeXShop에서 포맷 사용하기

  1. TeX가 어느 폴더에서든 찾을 수 있도록 uo.fmt를 ~/Library/texmf/web2c 폴더로 옮깁니다. 폴더가 없으면 만듭니다.
  2. Finder에서 ~/Library/TeXShop/Engines를 열고(TeXShop › ~/라이브러리/TeXShop 폴더 열기), XeLaTeX.engine 같은 엔진을 복제한 다음 사본의 이름을 예를 들어 Oregon.engine으로 바꿉니다. 이 이름은 TeXShop에 표시되는 이름이며, 포맷의 이름과 같을 필요는 없습니다.
  3. 사본을 TeXShop에서 열고, 엔진이 다음과 같이 되도록 마지막 줄을 고칩니다. 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

그 뒤에 여는 문서에서는 조판 버튼 옆의 팝업 메뉴에 Oregon이 나타납니다. 그 메뉴에서 무엇을 선택했든 한 문서에 이 포맷을 사용하려면 소스 첫머리에 다음 줄을 추가합니다.

% !TEX program = Oregon

이 포맷을 기본으로 사용하려면 설정 › 조판 › 엔진 › 새 문서 조판에서 “엔진 파일”을 선택하고, 엔진 파일 메뉴에서 Oregon을 선택합니다. 조판 엔진 추가하기를 참조하십시오.

plain TeX 포맷이라면 엔진에서 pdflatex 대신 pdftex를 사용합니다. DVI 경유로 사용할 포맷이라면 엔진에서 DVI 파일을 PDF로 변환하는 일도 해야 합니다. 예를 들어 zsh 스크립트에서는 dvipdfmx "${1:r}.dvi"를 추가합니다. TeXShop은 소스와 이름이 같은 PDF 파일을 보여 주기 때문입니다.
