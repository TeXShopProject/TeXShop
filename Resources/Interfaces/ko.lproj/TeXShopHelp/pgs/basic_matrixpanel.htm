행렬 패널

윈도우 › 행렬 패널...을 선택하면 행렬과 표를 대신 작성해 주는 패널이 열립니다. 패널의 표에 성분을 채우고 결과의 모양을 선택한 다음, 소스의 삽입 위치에 삽입합니다.

행렬이나 표 만들기

  1. 행:과 열:에 크기를 입력합니다. 각각 999까지 입력할 수 있습니다.
  2. 환경에서 수식 안의 행렬(array 환경)이면 matrix를, 텍스트 표이면 tabular를 선택합니다. tabular에서 “table 환경으로 삽입”을 켜면 표가 캡션과 레이블이 있는 table 플로트 안에 들어갑니다.
  3. 행렬이면 왼쪽과 오른쪽 구분 기호를 선택합니다. 마침표를 선택하면 그쪽에 구분 기호가 붙지 않으며, 마지막 버튼은 옆의 필드에 입력한 구분 기호를 사용합니다.
  4. 행렬 그림이 있는 두 버튼은 성분 바깥에 테두리를 두르고, 성분 사이에 선을 긋습니다.
  5. 성분을 채웁니다. 지우기는 모든 성분을 비우고, 단위행렬과 영행렬은 단위 행렬이나 0으로 채웁니다.
  6. 삽입을 클릭하거나 ⌘Return을 누릅니다.

표에서 작업하기

표는 스프레드시트처럼 동작합니다. 셀을 클릭하여 선택하고, 드래그하거나 Shift-클릭하여 여러 셀을 선택하며, 입력하면 값이 바뀝니다. 값을 편집하려면 이중 클릭하거나 F2 또는 Control-U를 누릅니다. Return 키는 아래로, Tab 키는 오른쪽으로 이동하고, 화살표 키는 각 방향으로 이동합니다. Delete 키는 선택한 셀을 비웁니다. 복사하기와 붙여넣기로 스프레드시트 응용 프로그램과 셀을 주고받을 수 있습니다. 행 번호를 드래그하면 행이 이동합니다. 패널이 활성화되어 있는 동안 실행 취소와 실행 복귀는 표에 적용됩니다.

행렬을 작게 하면 바깥으로 밀려난 셀은 값을 유지한 채 회색으로 표시되며, 다시 크게 하면 돌아옵니다. 표를 더 많이 보려면 패널을 크게 하십시오.

삽입되는 코드 사용자화

패널이 성분 주위에 쓰는 코드는 ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist에 있습니다. 환경의 시작과 끝, 구분 기호, 성분 사이와 행 사이의 구분자, 테두리와 격자의 선, 그리고 각 열의 정렬을 정하는 문자 c입니다. 예를 들어 c를 r로 바꾸면 열이 오른쪽으로 정렬됩니다. 파일 안 문자열의 개수와 순서는 그대로 두고, 변경한 후에는 TeXShop을 다시 시작하십시오. ~/Library/TeXShop의 파일을 참조하십시오.
