프로젝트 루트 파일 설정

큰 문서는 흔히 여러 파일로 나뉩니다. 프리앰블이 있는 루트 파일이 장마다 따로 된 파일을 포함하는 방식입니다. 예를 들어 루트 파일 Main.tex는 다음과 같을 수 있습니다.

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

two.tex를 편집할 때 TeXShop은 프리앰블이 없는 장 파일이 아니라 Main.tex를 조판해야 합니다. 이를 TeXShop에 알리려면 각 장 파일의 처음 20줄 안에 다음 줄을 넣습니다.

% !TEX root = ../Main.tex

루트 파일 자체에는 이런 줄이 필요 없습니다. 루트 파일은 다음과 같이 지정할 수 있습니다.

  • 장 파일과 같은 폴더에 있으면 이름만 씁니다: Main.tex
  • 장 파일의 폴더를 기준으로 한 상대 경로로 씁니다: ../Main.tex 또는 ../../Main.tex
  • 전체 경로로 씁니다: /Users/me/Book/Main.tex. 이 경우 프로젝트를 옮기면 경로를 바꿔야 합니다.

매크로 메뉴의 Root 매크로가 이 줄을 넣어 줍니다. 이 매크로는 루트 파일을 묻고, 상대 경로와 절대 경로 중 하나로 된 줄을 넣으며, 이미 있는 root 줄은 바꿉니다.

root 줄의 효과

  • 장 파일에서 조판하면 루트 파일이 조판되고, 루트 파일의 미리보기 윈도우에 문서 전체가 표시됩니다. % !TEX program 줄처럼 조판에 관한 매직 코멘트는 루트 파일에 넣습니다.
  • 편집 › 오류 지점으로 이동은 오류가 있는 파일이 열려 있지 않으면 그 파일을 열고 해당 줄로 이동합니다.
  • 미리보기 윈도우에서 동기화하면 클릭한 곳이 들어 있는 장 파일이 열립니다. 소스와 미리보기 동기화를 참조하십시오.
  • 파일 › 부수파일 삭제는 루트 파일의 부수 파일을 삭제합니다. 부수 파일 삭제를 참조하십시오.
  • 장 파일에서 윈도우 › 편집/보기 윈도우 맞바꾸기(⌘1)를 선택하면 루트 파일의 미리보기 윈도우가 앞으로 옵니다. 미리보기 윈도우에서 다시 선택하면 원래 있던 소스 윈도우로 돌아가며, 소스 윈도우에서 오지 않았다면 루트 파일로 갑니다.

장 파일 열기

root 줄이 있는 장 파일을 열면 TeXShop은 루트 파일과 그 미리보기 윈도우도 함께 엽니다. 이 동작은 설정 › 일반 › 프로젝트 루트 파일의 두 항목으로 조절합니다. “문서를 열 때 루트 파일 열기”는 이 동작을 켜거나 끄며, “루트 파일 창을 최소화”는 루트 파일의 소스 윈도우를 Dock으로 보냅니다. 장을 작업하는 동안에는 루트 파일을 편집할 일이 거의 없기 때문입니다.

프로젝트 전체에서 찾기 및 대치

프로젝트의 모든 파일을 한 번에 검색하려면 장 파일 중 하나에서 편집 › 찾기 › 같은 TEX root를 가진 TeX 소스에서 찾기…를, 루트 파일에서는 이 파일을 TEX root로 하는 TeX 소스에서 찾기…를 선택합니다. 루트 파일, 그리고 루트 파일의 폴더와 그 하위 폴더에 있는 .tex 파일 중 처음 20행 안의 root 줄로 그 루트 파일을 지정한 파일을 검색합니다. TeX 소스에서 찾기와 찾기 및 대치를 참조하십시오.

.texshop 파일로 지정한 루트 파일

장 파일 옆에 확장자가 .texshop인 파일(예: two.tex에 대한 two.texshop)이 있으면 이 파일로도 루트 파일을 지정할 수 있으며, TeXShop은 지금도 이 파일을 읽습니다. 이런 파일을 만드는 메뉴 명령은 없습니다. 소스와 함께 옮겨지는 % !TEX root 줄을 사용하십시오.
