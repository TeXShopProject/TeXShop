버그 보고

문제를 보고하거나 개선을 제안하려면 GitHub에서 이슈를 여십시오.

https://github.com/TeXShopProject/TeXShop/issues

먼저 열린 이슈와 닫힌 이슈를 검색해 보십시오. 이미 알려진 문제이거나 새 버전에서 고쳐졌을 수 있습니다. 이슈를 열려면 GitHub 계정이 필요합니다.

빨리 처리할 수 있는 보고에는 다음 내용이 들어 있습니다.

  • TeXShop(TeXShop › TeXShop에 대하여...)과 macOS의 버전
  • 무엇을 했고, 무엇을 기대했으며, 실제로 어떻게 되었는지
  • 조판 문제라면 문제를 재현하는 짧은 소스 파일과 콘솔 출력 또는 로그 파일
  • 윈도우나 메뉴 문제라면 스크린샷이나 짧은 화면 기록

TeX, LaTeX 패키지, TeX Live 자체에 관한 질문은 TeX Stack Exchange 등 유용한 웹 사이트에 소개된 곳에서 묻는 것이 좋습니다.
