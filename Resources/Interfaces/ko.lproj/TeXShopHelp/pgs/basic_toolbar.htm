도구 막대와 AppleScript

도구 막대 변경

소스 윈도우, 미리보기 윈도우, 그리고 둘을 함께 표시하는 윈도우에는 각각 자체 도구 막대가 있습니다. 도구 막대를 변경하려면 윈도우를 활성화하고 윈도우 › 도구 막대 사용자화...를 선택하거나, 도구 막대를 Control-클릭하여 나타나는 메뉴에서 도구 막대 사용자화…를 선택합니다. 항목을 도구 막대 안팎으로 드래그하거나, 기본 세트를 도구 막대로 드래그하여 처음 상태로 돌아갑니다. 윈도우 › 도구 막대 가리기는 활성 윈도우의 도구 막대를 가립니다.

소스 윈도우의 항목

조판과 그 옆의 프로그램 메뉴는 그 메뉴에서 선택한 프로그램으로 문서를 조판합니다. BibTeX, MakeIndex처럼 프로그램 하나만 실행하는 버튼도 있습니다. 템플릿과 매크로는 텍스트를 삽입합니다(템플릿과 스테이셔너리와 매크로 참조). 태그와 레이블은 소스를 절이나 레이블 위치로 스크롤합니다. 키 바인딩은 문서의 키 바인딩을 켜거나 끄며, 소스 분할은 윈도우를 나눕니다(Option-클릭하면 좌우로 나뉩니다).

전체 경로는 윈도우 제목에 파일 이름 대신 파일의 전체 경로를 표시합니다. 다시 클릭하면 이름만 표시합니다. 이 선택은 나중에 여는 윈도우에도 유지됩니다.

미리보기 윈도우의 항목

미리보기 윈도우에는 이전 페이지와 다음 페이지, 페이지로 이동, 뒤로/앞으로, 배율, 마우스 모드, PDF 검색, 서랍, 동기화 마크, 미리보기 분할, 그리고 페이지를 밝게 또는 어둡게 표시하는 화면 모드 등이 있습니다. 배율 필드 옆의 단어를 클릭하면 배율 메뉴가 열립니다.

페이지 레이아웃은 문서의 보기 형식을 단일 페이지, 두 페이지, 연속 스크롤, 연속 두 페이지 중에서 선택합니다. 두 페이지 배열은 문서가 열려 있는 동안 두 페이지를 왼쪽에서 오른쪽으로 놓을지 오른쪽에서 왼쪽으로 놓을지, 첫 페이지를 표지로 따로 표시할지를 선택합니다. 이 메뉴의 문서 설정 복원을 선택하면 설정과 문서의 매직 코멘트에 따른 상태로 돌아갑니다. 내용에 맞게 확대/축소와 내용 너비에 맞게 확대/축소는 흰 여백을 제외한 페이지의 조판된 부분이 윈도우나 윈도우 폭에 맞도록 배율을 한 번 바꿉니다. 미리보기 윈도우를 참조하십시오.

미리보기 › 주석 도구 막대 보기를 선택하면 도구 막대 아래에 두 번째 도구 막대가 나타나며, PDF에 메모, 하이라이트, 도형을 추가하는 도구가 들어 있습니다. 없애려면 오른쪽 끝의 닫기 버튼을 클릭하거나 미리보기 › 주석 도구 막대 가리기를 선택합니다. 주석은 TeXShop 설명서(도움말 › TeXShop 설명서 (영문))에서 설명합니다.

AppleScript

TeXShop은 AppleScript로 제어할 수 있습니다. 스크립트로 문서를 조판하고, BibTeX와 MakeIndex를 실행하고, 소스의 텍스트를 다룰 수 있습니다. 매크로 메뉴의 AppleScript 매크로가 이런 스크립트를 실행합니다. AppleScript 매크로를 참조하십시오. TeXShop이 이해하는 명령은 도움말 › 지난 자료 › TeXShop과 Applescript (영문)에서 설명하며, 스크립트 편집기에서 파일 › 사전 열기로 여는 TeXShop의 스크립팅 사전에도 나열되어 있습니다.
