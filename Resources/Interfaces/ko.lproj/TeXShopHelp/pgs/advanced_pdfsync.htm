소스와 미리보기 동기화

소스 윈도우에서 단어를 Command-클릭하면 미리보기 윈도우가 해당 위치로 스크롤하고 그곳을 표시합니다. 미리보기 윈도우에서 어떤 곳을 Command-클릭하면, 필요한 경우 소스 파일이 열리고 해당하는 줄이 표시됩니다. 두 표시의 색상은 설정 › 테마 › SyncTeX의 미리보기와 소스에서 설정합니다.

SyncTeX

TeXShop은 SyncTeX로 동기화합니다. -synctex=1 옵션을 주어 TeX를 실행하면 PDF 옆에 Galois.synctex.gz 같은 파일이 생깁니다. 이 파일에는 소스의 각 부분이 페이지의 어디에 놓였는지가 기록됩니다. TeXShop이 설정하는 조판 명령, 엔진 프로파일, TeXShop에 들어 있는 엔진은 이미 이 옵션을 사용합니다. 직접 만든 엔진에서는 TeX를 호출하는 부분에 -synctex=1을 추가하십시오. 하이픈은 하나든 둘이든 모든 엔진이 받아들입니다.

synctex 파일에는 소스 파일의 전체 경로가 들어 있습니다. 프로젝트 폴더를 옮기거나 복사하거나 다른 사람에게 보낸 뒤에는, 문서를 다시 조판할 때까지 동기화가 작동하지 않습니다.

SyncTeX가 완전히 정확하지는 않으므로, 찾는 곳이 표시된 곳보다 조금 앞이나 뒤에 있을 수 있습니다.

여러 파일로 된 프로젝트

장 파일이 % !TEX root로 루트 파일을 지정한 프로젝트(프로젝트 루트 파일 설정 참고)에서는, 장 파일에서 Command-클릭하면 문서 전체의 미리보기에서 해당 위치로 이동하고, 미리보기에서 Command-클릭하면 클릭한 곳이 들어 있는 장 파일이 열립니다. 설정 › 조판 › 소스와 미리보기 동기화 › “동기화로 여는 파일을 루트 파일 윈도우의 탭으로 열기”가 켜져 있으면, 이렇게 여는 파일은 별도의 윈도우가 아니라 루트 파일 윈도우의 탭으로 열립니다.

Sync 방식

설정 › 조판 › 소스와 미리보기 동기화 › Sync 방식에서는 두 가지 중 하나를 선택합니다.

SyncTeX(권장)
위에서 설명한 대로 synctex 파일을 사용합니다. 기본값입니다.
PDF 검색
소스에서 클릭한 곳 주변의 텍스트를 PDF에서 찾고, 미리보기에서 클릭한 곳 주변의 텍스트를 소스에서 찾습니다. synctex 파일이 필요 없지만, 수식이나 명령이 많은 텍스트처럼 조판된 텍스트가 소스와 다른 곳에서는 찾지 못합니다. 미리보기의 어떤 곳이 어느 파일에 있는지 찾을 때는 루트 파일의 \include 명령과 \input 명령에 지정된 파일을 검색합니다. 다른 방법으로 파일을 포함하는 프로젝트에서는 루트 파일에 다음과 같은 줄로 그 파일들을 나열합니다. 
% !TEX projectfile = chapter2.tex
% !TEX projectfile = /Users/me/Book/chapter3.tex
이름은 전체 경로나 루트 파일을 기준으로 한 상대 경로로 쓰며, 이 줄은 루트 파일의 어디에 있어도 됩니다.

ConTeXt

ConTeXt에서는 문서의 설정 부분에 \setupsynctex[state=start,method=min]을 추가하고, 루트 파일 첫머리에 % !TEX useConTeXtSyncParser 줄을 넣습니다. 그러면 TeXShop은 ConTeXt 자체의 동기화 코드를 사용합니다. ConTeXt와 MetaPost를 참고하십시오.

다른 에디터에서 열어 둔 소스와 동기화하는 방법은 외부 에디터 사용하기를 참고하십시오.
