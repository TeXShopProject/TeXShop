XeLaTeX와 LuaLaTeX

XeLaTeX와 LuaLaTeX는 UTF-8 소스를 직접 읽고, TeX Live의 서체뿐 아니라 Mac에 설치된 OpenType 서체와 TrueType 서체도 사용하는 LaTeX입니다. 서체에 해당 문자가 있기만 하면 유니코드에 들어 있는 어떤 문자든 소스에 입력하여 조판할 수 있습니다. 두 엔진 모두 TeX Live에 들어 있으며, 일반 LaTeX 문서도 고치지 않고 조판합니다.

XeLaTeX나 LuaLaTeX로 조판하기

방법은 세 가지입니다. 적용 범위가 넓은 것부터 차례로 소개합니다.

  • 엔진 프로파일. 설정 › 조판 › 엔진 프로파일에서 XeLaTeX나 LuaLaTeX를 선택합니다. 이 프로파일은 PDF 직접 생성의 LaTeX 명령과 plain TeX 명령을 xelatex와 xetex, 또는 lualatex와 luatex로 설정합니다. 따라서 도구 막대에서 LaTeX를 선택했을 때와 조판 › LaTeX를 선택했을 때 그 엔진이 사용됩니다. 적용하기 전에 프로파일이 설정하는 값이 시트에 표시됩니다.
  • 엔진 파일. LuaLaTeX 엔진과 XeLaTeX 엔진은 조판 버튼 옆의 팝업 메뉴에 있습니다. 새 문서를 둘 중 하나로 조판하려면 설정 › 조판 › 엔진 › 새 문서 조판에서 “엔진 파일”을 선택하고, 엔진 파일 메뉴에서 그 엔진을 선택합니다. 처음에는 엔진 파일 메뉴에 LuaLaTeX가 선택되어 있습니다.
  • 매직 코멘트. 소스 첫머리에 다음 줄을 넣으면 다른 설정과 관계없이 그 문서의 엔진이 정해집니다. 
    % !TEX program = LuaLaTeX

LuaLaTeX의 일본어 버전은 일본어 조판을 참고하십시오.

Mac의 서체 사용하기

fontspec 패키지는 서체 관리자 앱에 표시되는 이름으로 서체를 선택합니다. 예를 들면 다음과 같습니다.

% !TEX program = XeLaTeX
\documentclass{article}
\usepackage{fontspec}
\setmainfont{Palatino}
\setsansfont{Helvetica Neue}
\begin{document}
Text in Palatino, \textsf{and in Helvetica Neue}.
\end{document}

fontspec을 사용하지 않거나 서체 명령이 없으면 두 엔진 모두 LaTeX의 표준 서체인 Latin Modern을 사용합니다. polyglossia나 babel 같은 패키지는 다른 언어의 하이픈 처리와 관례를 설정합니다. 이 패키지들의 문서는 도움말 › 패키지 도움말 보이기...로 볼 수 있습니다.

다른 문자 입력하기

그리스 문자, 키릴 문자, 아랍 문자, 히브리 문자 등을 입력하려면 시스템 설정 › 키보드에서 해당 입력 소스를 추가하고, 메뉴 막대의 입력 메뉴로 입력 소스를 전환합니다. TeXShop은 아랍어, 히브리어, 페르시아어 줄을 오른쪽으로 정렬하여 보여 줄 수 있습니다. 인코딩을 참고하십시오. 이런 문서는 새 문서의 기본 인코딩인 UTF-8로 저장하십시오.
