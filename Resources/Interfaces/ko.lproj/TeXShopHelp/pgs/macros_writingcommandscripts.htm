셸 명령으로 스크립트 작성하기

이 페이지에서는 매크로 › Claus Gerhardt Macros에 있는 Claus Gerhardt의 Run pdfLaTeX with Shell Escape 매크로를 예로 들어, AppleScript가 셸 스크립트를 호출하는 방법을 보여 줍니다. 셸 스크립트 자체는 간단합니다. TeX 프로그램이 있는 폴더를 검색 경로에 추가하고, --shell-escape를 주어 pdflatex를 실행합니다. 직접 만드는 스크립트는 여러 프로그램을 차례로 실행하는 등 더 많은 일을 할 것이며, 그럴 때 이 기법이 유용합니다.

셸 스크립트

셸 스크립트는 ~/Library/TeXShop/bin/pdflatexc입니다. 이 스크립트는 TeXShop에 의존하지 않으므로, 이 폴더가 검색 경로에 있다면 터미널에서 pdflatexc myfile.tex를 입력하여 실행할 수 있습니다. 스크립트는 다음과 같습니다.

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

AppleScript

이 셸 스크립트를 호출하는 매크로가 더 흥미롭습니다.

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

주석 다음의 처음 일곱 줄은 Claus Gerhardt가 고안한 방법으로, 소스 파일을 저장하고 그 문서의 이름을 찾아 frontName에 넣습니다. 실제 작업은 ~/Library/TeXShop/Scripts에 있는 컴파일된 스크립트 setname.scpt가 합니다. 이 줄들은 ~/Library/TeXShop/Scripts/setname.scpt의 경로를 찾아 스크립트를 불러오고, #NAMEPATH#와 #TEXPATH#를 넘겨 호출합니다.

같은 일을 다음과 같이 더 간단하게 할 수 있는 경우도 많습니다.

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

그래도 이 방법에는 두 가지 장점이 있습니다. 맨 앞에 있는 문서가 뒤의 명령을 받아야 할 문서가 아닐 때, 예를 들어 /Users/name/Examples/myfile.log 같은 로그 파일일 때도 작동합니다. 또 파일을 한 번도 저장하지 않았으면 이 방법은 오류를 돌려주지만, save 명령은 스크립트를 저장 대화상자 뒤에서 기다리게 만듭니다.

그다음 여섯 줄은 변수 dirName과 baseName을 설정합니다. 소스 파일이 /Users/name/My Papers/Stuff/myfile.tex이면 dirName은 '/Users/name/My Papers/Stuff'가 되는데, 폴더 이름에 공백이 있으므로 셸을 위해 따옴표로 묶은 것입니다. baseName은 myfile.tex입니다. 파일 이름도 셸 스크립트에 넘길 때 같은 방식으로 따옴표로 묶으므로, 폴더 이름과 파일 이름 모두 공백이 있어도 됩니다.

그다음 세 줄은 셸 스크립트를 호출합니다. 결과는 터미널에서 cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex'를 입력한 것과 같습니다. 마지막 세 줄은 미리보기 윈도우를 갱신합니다.

이 중 몇몇 줄은 복잡하지만, 새 스크립트에 그대로 복사하여 사용할 수 있습니다.

AppleScript에서 셸 명령 실행하기

AppleScript는 다음과 같은 형식으로 셸 명령을 실행합니다.

do shell script "cmd input"

여러 부분을 이어 명령을 만들려면 같은 뜻의 다음 형식으로 씁니다.

do shell script "cmd " & "input"

cmd 뒤의 공백에 주의하십시오. 앰퍼샌드는 두 문자열을 잇습니다.

"cmd " & "input" = "cmd input"

AppleScript가 시작한 셸은 루트 폴더에서 시작합니다. 다음 명령은

do shell script "cd " & dirName

dirName에 들어 있는 폴더로 이동합니다. dirName은 이미 따옴표로 묶여 있으므로 따옴표를 더 붙일 필요가 없습니다.

do shell script는 실행할 때마다 새 셸을 시작하므로, 뒤에 오는 명령은 그 폴더에서 실행되지 않습니다. 같은 폴더에서 명령을 더 실행하려면 터미널에서처럼 세미콜론으로 이어 하나의 명령으로 만듭니다.

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

위의 스크립트는 cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc, input2 = baseName으로 이렇게 합니다. 다음 두 줄은

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

이 일련의 명령을 하나의 변수에 담는 편리한 방법일 뿐입니다.
