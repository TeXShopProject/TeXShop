매크로 메뉴 재배열하기

매크로 편집기(매크로 › 매크로 편집기 열기...)를 엽니다. 왼쪽 목록은 Finder 윈도우의 목록 보기처럼 매크로 메뉴를 계층 구조로 보여 줍니다. 항목을 옮기려면 다른 위치로 드래그합니다. 왼쪽이나 오른쪽으로 드래그하면 다른 단계, 즉 하위 메뉴의 안이나 밖으로 옮길 수 있습니다.

항목의 이름을 바꾸려면 항목을 선택하고 Return 키를 누르거나, Finder에서처럼 잠시 후 이름을 한 번 더 클릭합니다. 새 이름을 입력하고 Return 키를 누릅니다. Escape 키를 누르면 이전 이름이 유지됩니다.
