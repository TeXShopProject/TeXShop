BibTeX

BibTeX는 참고 문헌 데이터베이스, 즉 확장자가 .bib인 파일을 바탕으로 LaTeX 문서의 참고 문헌 목록을 만듭니다. 문서는 키로 항목을 인용하며, BibTeX는 인용된 항목만 목록에 넣습니다.

데이터베이스 mybibliography.bib에는 다음과 같은 항목이 들어 있고

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

문서는 이 항목을 인용하고, 스타일과 데이터베이스를 지정합니다.

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

BibTeX 실행하기

  1. 문서를 조판합니다. 인용은 [?]로 표시되고 참고 문헌 목록은 없습니다.
  2. 조판 › BibTeX(⇧⌘B)를 선택하거나, 조판 버튼 옆의 팝업 메뉴에서 BibTeX를 선택하고 조판 버튼을 누릅니다.
  3. 두 번 더 조판합니다. 첫 번째 조판에서 참고 문헌 목록이 추가되고, 두 번째 조판에서 인용이 채워집니다.

pdflatexmk 엔진이나 “latexmk 사용”으로 설정한 프로파일처럼 latexmk로 조판하면 BibTeX와 추가 조판이 자동으로 실행됩니다.

TeXShop에서 새 데이터베이스를 만들려면 저장 대화상자의 파일 포맷 메뉴에서 bib 유형을 선택하여 파일의 확장자가 .bib가 되게 합니다. 데이터베이스는 모든 문서에서 찾을 수 있는 개인 TeX 트리에 둘 수도 있습니다. TeX Live에 개인 파일 추가하기를 참조하십시오.

프로그램 선택하기

조판 › BibTeX는 설정 › 조판 › 관련 도구 › BibTeX 엔진에 있는 명령을 실행하며, 기본값은 bibtex입니다. 다른 프로그램을 사용하려면 필요한 옵션과 함께 이곳에 입력합니다. 예를 들어 biblatex 패키지를 사용하는 문서에는 biber를 입력합니다. 엔진 프로파일이 이 필드를 설정합니다. pLaTeX + dvipdfmx는 pbibtex로, upLaTeX + dvipdfmx와 LuaLaTeX(일본어)는 upbibtex로, 나머지 프로파일은 bibtex로 설정합니다.

한 문서에 사용할 프로그램을 지정하려면 문서의 처음 20줄 안에 다음과 같은 줄을 넣습니다.

% !BIB program = biber

이 줄은 설정보다 우선합니다. % !BIB TS-program = 형식도 같은 뜻으로 읽습니다.
