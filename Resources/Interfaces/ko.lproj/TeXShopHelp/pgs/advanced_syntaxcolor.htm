구문 하이라이트

소스 윈도우는 TeX를 색으로 구분하여 보여 줍니다. 주석, 명령, 각주, 마커 $와 &, 괄호 ( ), { }, [ ]가 각각 고유한 색으로 표시됩니다. 소스 › 구문 하이라이트는 현재 문서의 하이라이트를 켜거나 끕니다. 문서는 하이라이트가 켜진 상태로 열리며, 꺼진 상태로 열려면 다음 숨겨진 설정을 사용합니다.

defaults write TeXShop SyntaxColoringEnabled NO

하이라이트되는 것

  • 명령은 백슬래시 뒤에 영문자가 이어진 것입니다. 설정 › 편집기 › 구문 하이라이트 › “@를 명령 이름의 일부로 취급”을 켜면, 패키지의 내부 명령처럼 @도 영문자로 취급합니다.
  • \footnote, \footcite, \autocite, 그리고 \citep나 \citeauthor처럼 \cite나 \Cite로 시작하는 명령의 텍스트는 각주 색상으로 표시됩니다. 숨겨진 설정 defaults write TeXShop SyntaxColorFootnote NO를 사용하면 명령에만 색이 칠해집니다.
  • 소스 › 색인 항목 하이라이트는 \index와 \esindex의 인수를 색인 색상으로 표시합니다. 설정 › 편집기 › 구문 하이라이트 › “기본으로 색인 항목 하이라이트”를 켜면 문서를 열 때 이 기능이 켜집니다.
  • 소스 › expl3 코드 하이라이트는 패키지를 작성하는 사용자를 위해, LaTeX의 프로그래밍 계층인 expl3 코드의 함수, 변수 등에도 색을 칠합니다. 같은 그룹의 “기본으로 expl3 코드 하이라이트”를 켜면 문서를 열 때 이 기능이 켜집니다.
  • 같은 그룹의 “전각 영숫자·기호 하이라이트”는 일본어 텍스트에서 ASCII 문자와 혼동하기 쉬운 전각 영문자, 숫자, 기호를 전각 영숫자·기호 색상으로 표시합니다.

색인 항목 하이라이트와 expl3 코드 하이라이트는 현재 문서에 적용되며, 소스 윈도우마다 따로 선택합니다. 로그 파일처럼 TeX 소스가 아닌 파일은 하이라이트되지 않습니다. 확장자 목록과 확장자를 추가하는 방법은 TeXShop으로 다른 파일 열기를 참조하십시오.

색상 바꾸기

색상은 테마에 속하며, 설정 › 테마에서 선택합니다.

  • 구문 하이라이트 그룹: 주석문, 명령어, 각주, 마커, 색인
  • 괄호 그룹: ( ), { }, [ ]의 색상
  • expl3 그룹: function, __function, key, variable, __variable, argument, msg
  • 하이라이트 그룹: 전각 영숫자·기호 색상 등
  • XML 구문 그룹: HTML 파일과 XML 파일의 색상

테마마다 색상이 따로 있으므로, 밝은 테마와 어두운 테마의 색상을 다르게 할 수 있습니다.
