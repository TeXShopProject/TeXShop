매크로

매크로 메뉴와 도구 막대의 매크로 항목에는 소스에 LaTeX 코드를 삽입하거나 AppleScript 스크립트를 실행하는 명령이 들어 있습니다. TeXShop에 들어 있는 매크로의 예는 다음과 같습니다.

  • Program, Encoding, Root는 문서의 조판 엔진, 인코딩, 루트 파일을 정하는 % !TEX 행을 씁니다. Program이나 Encoding이 보여 주는 목록에서 엔진이나 인코딩을, Root가 여는 대화상자에서 루트 파일을 선택하면 소스 맨 위에 올바른 형식으로 행이 쓰입니다.
  • Insert Begin/End는 삽입 위치에 있는 단어나 선택한 단어(theorem 등)를 \begin{theorem} … \end{theorem} 쌍으로 바꾸고, 삽입 위치를 그 사이에 둡니다.
  • Headings, Mathematics, Lists, Tables, Figures 같은 하위 메뉴는 자주 쓰는 LaTeX 코드를 삽입합니다.

매크로 편집기

매크로 › 매크로 편집기 열기...를 선택하면 각 매크로의 정의를 보거나 변경하고, 직접 만든 매크로를 추가할 수 있습니다. 왼쪽 목록이 매크로 메뉴입니다. 항목을 드래그하여 순서를 바꾸고, 목록 아래의 막대로 항목, 하위 메뉴, 구분선을 추가합니다. 매크로의 텍스트는 소스에 삽입됩니다. 이 텍스트에서 모서리가 둥근 토큰은 선택한 텍스트, 클립보드의 텍스트, 삽입 위치를 나타내며, 텍스트 아래의 삽입 메뉴에서 선택하여 넣습니다.

매크로에 키보드 단축키를 지정하려면 목록에서 매크로를 선택하고 단축키 부분을 클릭(또는 이중 클릭)한 다음 키를 누릅니다. 단축키에는 Command 키나 Control 키를 사용하거나 기능 키를 사용합니다. 메뉴 명령이나 다른 매크로가 이미 사용하는 단축키이면 매크로 편집기가 알려 줍니다.

매크로는 ~/Library/TeXShop/Macros/Macros_Latex.plist에 보관됩니다. 매크로를 다른 사람에게 주려면 매크로 편집기에서 선택한 후 매크로 › 선택부분을 파일로 저장...을 선택하고, 그런 파일에서 매크로를 추가하려면 매크로 › 파일에서 매크로 추가...를 선택합니다.

매크로에 대한 자세한 내용은 AppleScript 매크로를 포함하여 매크로 도움말 장에서 설명합니다.
