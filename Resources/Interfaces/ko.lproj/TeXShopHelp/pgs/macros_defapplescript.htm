AppleScript 매크로 정의하기

AppleScript는 그 자체로 하나의 언어입니다. Apple 개발자 웹사이트에 있는 Apple의 AppleScript Language Guide에서 AppleScript를 자세히 설명합니다.

경로와 문서 이름

AppleScript 매크로를 실행하기 전에 TeXShop은 다음 문자열을 현재 문서와 관련된 파일의 경로로 바꿉니다. 경로는 큰따옴표로 묶입니다.

#FILEPATH#
소스 파일
#TEXPATH#
.tex 파일
#NAMEPATH#
확장자를 뺀 소스 파일
#FOLDERPATH#
소스가 들어 있는 폴더(끝에 슬래시가 붙음)
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
.pdf, .dvi, .ps, .log, .aux 파일
#INDPATH#, #BBLPATH#, #HTMLPATH#
.ind, .bbl, .html 파일

예를 들어 #FILEPATH#가 /Users/name/Projects/Fourier/Fourier.tex이면 #FOLDERPATH#는 /Users/name/Projects/Fourier/입니다. 문서를 한 번도 저장하지 않았으면 #FILEPATH#는 빈 문자열입니다.

#DOCUMENTNAME#은 소스 윈도우의 제목에 표시되는 문서 이름으로 바뀝니다. 확장자가 표시되면 확장자를 포함하고, 확장자가 가려져 있으면 포함하지 않습니다. 스크립트는 이를 사용하여 자신을 호출한 문서를 지정합니다.

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

TeXShop 명령

AppleScript로 작업하는 방법은 두 가지입니다. 셸 명령으로 스크립트 작성하기에서 설명하는 것처럼 셸 명령을 실행하거나, TeXShop 조판 명령으로 스크립트 작성하기에서 설명하는 것처럼 TeXShop 자체의 명령을 호출할 수 있습니다. TeXShop은 다음 명령을 이해합니다.

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

처음 여섯 명령은 오류에서 멈추지 않고 계속 조판합니다. 다음 여섯 명령도 조판하지만, 오류가 나면 멈추어 콘솔에서 응답할 수 있게 합니다. 조판 명령은 조판이 끝나기 전에 즉시 돌아옵니다. taskdone은 조판이 아직 진행 중이면 NO를, 끝났으면 YES를 돌려줍니다. refreshpdf와 refreshtext는 PDF 윈도우와 텍스트 윈도우가 각 파일의 최신 버전을 보여 주게 합니다. goto line은 소스에서 줄을 선택합니다.

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
