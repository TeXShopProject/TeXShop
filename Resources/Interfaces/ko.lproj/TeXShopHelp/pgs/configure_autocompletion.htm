Modifying Key Bindings

The Settings window contains a checkbox to turn key bindings on or off. By default it is off. When the item is on, typing certain characters inserts an entire string in the source file. For instance, typing ^ inserts ^{ }, with the cursor positioned inside the brackets.

Key binding elements can be modified and created using the Key Bindings Editor built into TeXShop.

While key bindings are on, a key binding checked in the Paste column also applies to pasted text: each of its input characters in the pasted text becomes its output string. Key bindings whose output string contains #SEL#, #INS#, #PASTE# or a mark (•) cannot be checked. For instance, when the encoding for new documents in Settings is not a Japanese one, giving ¥ the output string \ (a single backslash) and checking Paste turns the yen signs of pasted text into backslashes. When TeXShop is installed for the first time, the key binding of ¥ is already set this way.
