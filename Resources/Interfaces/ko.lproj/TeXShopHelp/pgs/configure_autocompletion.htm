키 바인딩 수정

키 바인딩은 입력한 문자를 다른 텍스트로 바꿉니다. 예를 들어 ^를 ^{}로 바꾸고 삽입 위치를 중괄호 사이에 둡니다. 사용 방법은 키 바인딩에서 설명합니다. 이 페이지에서는 목록을 변경하는 방법을 설명합니다.

키 바인딩 켜기

설정 › 키보드의 “키 바인딩 사용(새 문서의 기본값)”은 문서를 열 때 키 바인딩을 켤지를 정하며, 처음에는 꺼져 있습니다. 소스 › 키 바인딩은 활성 문서에 한해 키 바인딩을 켜거나 끄며, 도구 막대에 추가할 수 있는 키 바인딩 항목도 같은 일을 합니다.

목록 편집

설정 › 키보드의 키 바인딩 목록에는 각 입력 문자가 출력 문자열과 함께 표시됩니다. 셀을 이중 클릭하면 그 자리에서 편집할 수 있습니다. 목록 아래의 + 를 클릭하면 키 바인딩이 추가되고 − 를 클릭하면 선택한 키 바인딩이 삭제되며, 행을 드래그하면 순서가 바뀝니다. 입력 문자는 문자 하나입니다. 변경 내용은 즉시 저장되고 이미 열려 있는 문서에도 바로 적용되며, 편집 › 실행 취소로 되돌릴 수 있습니다.

출력 문자열에는 다음 기호를 쓸 수 있으며, 목록에는 작은 레이블로 표시됩니다.

#SEL#
키를 입력할 때 선택되어 있던 텍스트
#INS#
삽입 위치가 놓일 곳
#PASTE#
클립보드의 텍스트
•
편집 › 마크로 이동할 수 있는 마크

목록 아래의 삽입 메뉴로 추가하거나, 위에 적힌 대로 입력합니다. Option-Return은 줄바꿈을, Option-Tab은 탭을 입력합니다. 목록 옆의 ? 버튼을 클릭하면 모든 기호가 표시됩니다. 출력 문자열을 복사하면 기호는 위에 적힌 형태로 복사됩니다.

붙여넣기 열을 체크하면 붙여넣은 텍스트에도 키 바인딩이 적용됩니다. 문서의 키 바인딩이 켜져 있는 동안, 소스에 붙여넣거나 드롭한 텍스트에서 입력 문자가 나올 때마다 출력 문자열로 바뀝니다. 출력 문자열에 #SEL#, #INS#, #PASTE#나 마크가 들어 있는 키 바인딩은 체크할 수 없습니다.

기본 목록으로 되돌리기

목록은 ~/Library/TeXShop/Keyboard 폴더에 보관됩니다. TeXShop에 들어 있는 목록으로 되돌리려면 TeXShop을 종료하고 Keyboard 폴더를 데스크탑으로 옮긴 다음 TeXShop을 다시 시작하십시오. 기본 내용으로 폴더가 만들어집니다.
