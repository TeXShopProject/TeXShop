키 바인딩

키 바인딩을 사용하면 문자 하나를 입력했을 때 다른 텍스트가 삽입됩니다. TeXShop에 들어 있는 목록에서는 ^를 입력하면 ^{}가 입력되고 삽입 위치가 중괄호 사이에 놓이며, "를 입력하면 삽입 위치 양쪽에 TeX 따옴표 ``''가, ä를 입력하면 \"a가 입력됩니다. 키 바인딩은 선택한 텍스트를 안에 넣을 수도 있습니다. 단어를 선택하고 ^를 입력하면 ^{단어}가 됩니다. 목록에는 45개의 키 바인딩이 있습니다.

키 바인딩은 처음에 꺼져 있습니다. 여는 모든 문서에서 키 바인딩을 사용하려면 설정 › 키보드에서 “키 바인딩 사용(새 문서의 기본값)”을 켜십시오. 소스 › 키 바인딩은 맨 앞 문서의 키 바인딩을 켜거나 끕니다. 키 바인딩이 지정된 문자를 그대로 입력하고 싶을 때 등에 사용합니다. 도구 막대에 추가할 수 있는 키 바인딩 항목도 같은 일을 합니다.

키 바인딩 목록

설정 › 키보드의 키 바인딩 그룹에는 키 바인딩이 입력 문자와 출력 문자열의 쌍으로 나열됩니다. 셀을 이중 클릭하면 편집할 수 있습니다. 목록 아래의 + 를 클릭하면 키 바인딩이 추가되고 − 를 클릭하면 선택한 키 바인딩이 삭제되며, 행을 드래그하면 순서가 바뀝니다. 입력 문자는 문자 하나입니다. 변경 내용은 즉시 저장되고 열려 있는 문서에도 바로 적용되며, 편집 › 실행 취소로 되돌릴 수 있습니다.

출력 문자열에서 특수 항목은 작은 레이블로 표시됩니다. 선택한 텍스트, 삽입 위치, 클립보드의 텍스트, 편집 › 마크에서 사용하는 마크(•), 줄바꿈, 탭입니다. 목록 아래의 삽입에서 추가하거나 #SEL#, #INS#, #PASTE#, •를 직접 입력하고, 줄바꿈은 Option-Return, 탭은 Option-Tab으로 입력합니다. ? 버튼을 클릭하면 모든 항목이 나열됩니다.

붙여넣기 열을 체크하면 소스에 붙여넣거나 드롭한 텍스트에도 키 바인딩이 적용되어, 입력 문자가 나올 때마다 출력 문자열로 바뀝니다. 입력할 때와 마찬가지로 그 문서의 키 바인딩이 켜져 있을 때만 적용됩니다. 출력 문자열에 선택 영역, 삽입 위치, 클립보드, 마크가 들어 있는 키 바인딩은 체크할 수 없습니다.

엔 기호

일본어 키보드에서는 백슬래시 키를 누르면 엔 기호(¥)가 입력되기도 합니다. TeXShop에 들어 있는 목록에서 ¥은 백슬래시 하나로 바뀌며, 붙여넣기도 체크되어 있습니다. 따라서 새 문서의 인코딩이 UTF-8이면 키 바인딩을 켜기만 해도 소스에 입력하거나 붙여넣은 ¥이 \로 바뀝니다. 목록을 이전 버전의 TeXShop에서 가져왔다면 ¥의 출력 문자열을 백슬래시 하나로 바꾸고 붙여넣기를 직접 체크하십시오.

목록은 ~/Library/TeXShop/Keyboard/autocompletion.plist에 저장됩니다. 키 바인딩 수정을 참조하십시오.
