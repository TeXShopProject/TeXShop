TeX Live 설치

TeXShop을 사용하려면 TeX 배포판이 필요합니다. 표준 배포판은 TeX Live로, TeX 사용자 그룹들이 macOS, Windows, Linux 등을 위해 해마다 만듭니다. Mac에서는 TeX Users Group(TUG)이 만든 설치 패키지인 MacTeX로 설치합니다.

https://tug.org/mactex/

이 페이지에서는 두 가지 패키지를 제공합니다. 내려받은 패키지를 이중 클릭하고 설치 프로그램의 안내를 따르십시오. 설치가 끝나면 바로 TeX를 사용할 수 있습니다.

MacTeX
약 7GB인 TeX Live 전체에 Ghostscript가 포함되며, TeXShop 등의 응용 프로그램이 /Applications/TeX에 설치됩니다. TeX나 LaTeX 책에 실린 예제는 대부분 아무것도 추가하지 않고 그대로 조판할 수 있습니다. 실제 작업에는 이 패키지를 선택하십시오.
BasicTeX
약 140MB인 TeX Live의 일부로, TeX를 시험해 보거나 많은 LaTeX 문서를 조판하기에 충분합니다. TeXShop은 설치되지 않습니다. TeXShop 설치를 참조하십시오.

TeX Live가 설치되는 위치

MacTeX는 TeX Live를 /usr/local/texlive/2026에, BasicTeX는 /usr/local/texlive/2026basic에 설치합니다. 둘을 함께 설치할 수도 있습니다. 새 TeX Live는 해마다 4월 무렵에 나오며, 그 연도 이름의 폴더에 설치됩니다. 설치한 TeX Live를 제거하려면 해당 폴더를 휴지통으로 드래그합니다.

설치 프로그램은 /Library/TeX/texbin도 만듭니다. 이 경로는 현재 사용 중인 TeX Live의 프로그램을 가리키며, 새 TeX Live를 설치하면 그쪽을 따라갑니다. TeXShop은 이 경로에서 TeX를 실행하므로(설정 › 조판 › 경로 › TeX 엔진), 해가 바뀌어도 아무것도 변경할 필요가 없습니다. 같은 그룹의 “경로 자동 감지…”는 Mac에 설치된 TeX와 Ghostscript를 찾아 그중 하나를 선택할 수 있게 합니다.

연례 배포 사이에도 TeX Live의 패키지는 업데이트됩니다. 업데이트를 설치하려면 MacTeX가 /Applications/TeX에 설치하는 TeX Live Utility를 사용합니다.

다른 TeX 배포판

TeXShop은 MacPorts나 Homebrew로 설치한 TeX, 또는 MiKTeX와도 함께 사용할 수 있습니다. 이들 프로그램은 다른 폴더에 있으므로 “경로 자동 감지…”를 사용하거나 설정 › 조판 › 경로 › TeX 엔진에 폴더를 입력하십시오. 다른 TeX 배포판과 함께 사용하기를 참조하십시오.
