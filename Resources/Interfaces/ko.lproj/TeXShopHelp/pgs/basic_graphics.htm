그림 넣기

PDF로 직접 조판할 때 LaTeX는 PDF, PNG, JPEG 형식의 그림을 넣을 수 있습니다. PDF는 선 그림과 글자가 어떤 크기에서도 선명하므로 도표와 그래프에 적합하고, PNG와 JPEG는 스크린샷과 사진에 적합합니다.

프리앰블에서 graphicx 패키지를 읽어 들이고

\usepackage{graphicx}

그림이 나타날 위치에 다음과 같이 씁니다.

\includegraphics[width=0.8\textwidth]{diagram}

확장자는 생략할 수 있습니다. 그러면 LaTeX가 diagram.pdf, diagram.png, diagram.jpg 등 알고 있는 형식의 파일을 찾습니다. 그림의 크기를 바꾸려면 width를 바꾸십시오. 그림 파일은 문서의 폴더에 두거나, figures/diagram처럼 문서 폴더에서 본 경로로 지정합니다.

EPS 파일

문서가 graphicx를 읽어 들이면 TeX Live는 조판하는 동안 epstopdf로 EPS 그림을 자동으로 PDF로 변환합니다. 변환된 파일 diagram-eps-converted-to.pdf는 EPS 파일 옆에 저장되며, 이후에는 이 파일이 사용됩니다.

TeXShop에서 EPS 파일을 열 때도 변환됩니다. TeXShop은 같은 이름의 PDF 파일을 옆에 저장하고 표시합니다.

TIFF 파일

LaTeX는 TIFF 파일을 넣을 수 없습니다. 소스 윈도우가 활성화된 상태에서 파일 › TIFF 파일 변환을 선택하면, 문서의 폴더가 대화상자에 표시되며 TIFF 파일만 선택할 수 있습니다. 하나 이상을 선택하고 변환을 클릭하십시오. 각 파일이 같은 폴더에 같은 이름의 PNG 파일로 변환되며, TIFF 파일은 그대로 남습니다.

DVI 경유 조판

pstricks 패키지처럼 PostScript 코드를 사용하는 문서는 DVI 경유 방식으로 조판하며, 이 방식은 기본적으로 dvips를 실행합니다. 이때 그림은 EPS 형식으로 넣으며, PDF, PNG, JPEG 파일은 사용할 수 없습니다. 대체 조판 방식을 참조하십시오.
