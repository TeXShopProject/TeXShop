Defining New Macros

New items are created with the + button below the list, and new submenus and separators with the menu at its right end (⊙), which also duplicates the selected items; the − button deletes them. A new item or submenu is named at once: type its name and press Return. A little practice illustrates the basic behavior of the editor. Submenus can be created to any level.

To assign a keyboard shortcut to an item, select it and click its shortcut in the list (or double-click the shortcut), then press the new shortcut: Command or Control with a key, or one of F1–F20, with Shift and Option as needed. If a menu command or another macro already uses the shortcut, TeXShop says so below the contents and does not change it; press another shortcut. To remove a shortcut, click “Remove Shortcut” (⊖) in the field or press Delete; Escape keeps the one it had. A shortcut that is inactive because a menu command or an earlier macro uses it is marked with a warning triangle in the list; select the item to see the reason below the contents.

In the contents, the placeholders that a macro replaces (#SEL#, #INS#, #PASTE#, the marks •, and #FILEPATH# and the other paths of an AppleScript macro) are shown as rounded tokens which say what they stand for, such as “Selected Text”. The macro keeps them as they are written. Type a placeholder, or choose it from the Insert menu below the contents; the help button at the right lists them all. Deleting next to a token deletes all of it.
