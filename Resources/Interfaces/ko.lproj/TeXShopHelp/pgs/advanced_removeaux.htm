부수 파일 삭제

LaTeX는 Galois.tex를 조판할 때 Galois.aux, Galois.toc, Galois.log 같은 부수 파일을 기록합니다. 다음 조판에서는 상호 참조, 목차 등을 위해 이 파일을 읽습니다. 오류 등으로 조판이 도중에 멈추면 이 파일이 손상된 채 남을 수 있으며, 그러면 다음 조판에서 소스에 없는 오류가 보고됩니다. 이런 오류는 흔히 \begin{document} 바로 앞에서 나타납니다. 부수 파일을 휴지통으로 옮기고 다시 조판하면 해결됩니다.

파일을 휴지통으로 옮기기

  • 파일 › 부수파일 삭제(⌃⌘A)를 선택하거나 콘솔의 부수파일 삭제 버튼을 누르면 문서의 부수 파일이 휴지통으로 옮겨집니다.
  • 조판 › 부수 파일 삭제 후 조판(⌥⌘T)은 이 작업을 한 다음 조판합니다. 조판 메뉴에서는 Option 키를 누르고 있는 동안 조판하기 대신 이 항목이 나타납니다.

휴지통으로 옮겨지는 파일은 소스와 같은 폴더에 있고, 소스와 이름이 같으며, 확장자가 다음 중 하나인 파일입니다.

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

조판이 중단되어 SyncTeX가 이름 끝에 (busy)가 붙은 채 남긴 파일도 휴지통으로 옮겨집니다. BibTeX의 .bbl 파일은 남겨 둡니다.

장 파일이 % !TEX root로 루트 파일을 지정한 프로젝트에서는, 장 파일에서 명령을 실행해도 루트 파일의 부수 파일이 휴지통으로 옮겨집니다.

다른 동작

  • 부수파일 삭제를 선택하거나 버튼을 누를 때 Shift 키를 누르고 있으면 문서의 PDF 파일도 휴지통으로 옮겨집니다. 평소에는 조판이 실패해도 미리보기 윈도우에 보여 줄 것이 있도록 이전 PDF를 남겨 둡니다.
  • 부수파일 삭제를 선택하거나 버튼을 누를 때 Option 키를 누르고 있으면 프로젝트 전체를 정리합니다. 루트 파일의 폴더와 그 아래의 모든 폴더에서, 이름과 관계없이 위 확장자 중 하나를 가진 파일이 모두 휴지통으로 옮겨집니다. 하위 폴더에 있는 장에 대해 \include가 기록하는 .aux 파일도 이렇게 정리됩니다.

두 가지 숨겨진 설정으로 동작을 바꿀 수 있습니다. 목록에 확장자(예: dvi)를 추가하려면 터미널에서 다음과 같이 입력합니다.

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

표준 목록으로 되돌리려면 다음과 같이 입력합니다.

defaults write TeXShop OtherTrashExtensions -array

Option 키를 누를 때의 동작을 부수파일 삭제의 기본 동작으로 하려면 다음과 같이 입력합니다.

defaults write TeXShop AggressiveTrashAUX YES
