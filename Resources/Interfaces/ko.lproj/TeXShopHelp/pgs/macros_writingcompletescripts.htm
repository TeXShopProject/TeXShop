TeXShop 조판 명령으로 스크립트 작성하기

참고 문헌 목록이 있는 문서는 여러 번 차례로 조판해야 합니다. LaTeX가 .aux 파일을 기록하면 BibTeX가 그 파일을 사용하여 .bbl 파일과 .blg 파일을 기록하고, LaTeX를 다시 실행하여 문서에 참고 문헌 목록을 추가한 뒤, 한 번 더 실행하여 목록에 대한 참조를 갱신합니다. 다른 프로젝트에도 이와 비슷한 순서가 필요할 수 있으며, AppleScript 매크로로 이를 자동으로 실행할 수 있습니다.

TeXShop에 들어 있는 매크로 › Applescript › Run LaTeX, BibTeX, Then LaTeX Twice가 그 방법을 보여 줍니다. 내용은 다음과 같습니다.

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

첫 줄은 이 매크로를 ScriptRunner가 실행하는 AppleScript 매크로로 만듭니다. 그래서 이 매크로는 TeXShop에 조판을 요청할 수 있습니다(AppleScript 매크로 참조). 다음 줄들은 소스 파일의 전체 경로인 #FILEPATH#를 확인합니다. 문서를 아직 저장하지 않았으면 이 값은 빈 문자열이며, 이 경우 스크립트는 파일을 저장하라고 알리고 멈춥니다.

그다음 스크립트는 #DOCUMENTNAME#으로 문서를 지정합니다. 조판 명령이 시작되면 TeXShop이 직접 문서를 저장하므로, 스크립트에서 저장할 필요는 없습니다.

나머지 명령은 latexinteractive, bibtex, latex, latex를 실행합니다. 조판 명령은 조판이 끝나기 전에 즉시 스크립트로 돌아오므로, 각 명령 뒤의 repeat 반복문이 taskdone이 작업 완료를 알릴 때까지 기다립니다. delay 2 줄은 확인과 확인 사이에 스크립트를 잠시 멈추게 하여, 쉬지 않고 확인하느라 컴퓨터가 느려지지 않게 합니다. 명령 목록은 AppleScript 매크로 정의하기에 있습니다.
