시작하기 전에

TeXShop은 TeX와 LaTeX로 문서를 작성하는 macOS 응용 프로그램입니다. 편집 윈도우에서 소스를 작성하고, 클릭 한 번이나 ⌘T로 조판하면, 옆의 미리보기 윈도우에서 결과를 볼 수 있습니다. 어느 한쪽 윈도우에서 Command-클릭하면 다른 쪽 윈도우의 대응하는 위치가 표시됩니다.

TeXShop에는 TeX가 포함되어 있지 않습니다. TeXShop은 TeX 배포판의 프로그램을 실행하며, 보통은 MacTeX 설치 프로그램으로 Mac에 설치하는 TeX Live를 사용합니다. TeX Live 설치를 참조하십시오. TeXShop을 사용하려면 macOS 14.6 이상이 필요합니다.

처음 실행할 때 다른 엔진 프로파일을 선택하지 않았다면 TeXShop은 LaTeX 문서를 pdfLaTeX로 조판합니다. pdfLaTeX는 PDF 파일을 직접 만들고, 미리보기 윈도우는 그 파일을 표시합니다. 이 파일은 다른 사람에게 보내 어느 컴퓨터에서나 읽을 수 있는 일반 PDF 파일입니다. LuaLaTeX 등 다른 엔진으로 조판하려면 설정에서 엔진 프로파일을 선택하거나 문서 첫머리에 엔진 이름을 적습니다. 문서 조판을 참조하십시오.

이 도움말의 구성

기본 도움말
TeX Live와 TeXShop 설치, 조판, 미리보기 윈도우, 편집, 찾기 및 대치, 맞춤법 검사, 키 바인딩과 명령어 완성, 각종 패널, 매크로, 프린트, 설정.
고급 도움말
조판 엔진, 루트 파일이 있는 프로젝트, BibTeX와 MakeIndex, 인코딩, 외부 에디터, 구문 하이라이트 등.
매크로 도움말
매크로 메뉴, 매크로 편집기, AppleScript로 작성한 매크로.
TeXShop 설정 방법
권장 설정, ~/Library/TeXShop의 새 항목, 숨겨진 설정, 키 바인딩과 키보드 단축키.

도움말 메뉴에서 그 밖의 문서를 열 수 있습니다(모두 영문). “TeXShop 설명서”는 모든 기능을 자세히 설명합니다. “TeXShop 입문”은 처음 사용하는 사람을 위한 짧은 소개입니다. “이 버전에 대하여”는 업데이트 후에 따로 할 일이 있으면 알려 주고, “변경사항”은 버전마다 바뀐 내용을 정리합니다. “매직 코멘트와 숨겨진 설정”은 % !TEX program = 같은 매직 코멘트와 설정 윈도우에 표시되지 않는 설정을 정리한 문서입니다.

TeXShop 웹 사이트는 texshop.app입니다.
