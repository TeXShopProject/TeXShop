TeX Live 자세히 알아보기

TeX Live가 설치되는 위치

MacTeX는 TeX Live를 /usr/local/texlive/2026에, BasicTeX는 /usr/local/texlive/2026basic에 설치합니다. TeX Live는 해마다 한 번 배포되며 연도마다 2027처럼 별도의 폴더에 설치되므로, 여러 연도의 TeX Live를 한 Mac에 나란히 둘 수 있습니다. 그중 하나를 제거하려면 그 폴더를 휴지통으로 드래그합니다.

/usr/local 폴더는 Finder에서 가려져 있습니다. 안을 보려면 Finder에서 이동 › 폴더로 이동…을 선택하고 경로를 입력합니다.

TeXShop이 TeX를 찾는 방법

TeXShop은 설정 › 조판 › 경로의 TeX 엔진 필드에 있는 폴더에서 TeX를 실행합니다. 기본값은 /Library/TeX/texbin입니다. 이것은 MacTeX와 BasicTeX 설치 프로그램이 방금 설치한 TeX Live의 프로그램을 가리키도록 설정하는 링크입니다. 새 연도의 TeX Live를 설치하면 이 링크도 따라 바뀌므로, 설정을 바꾸지 않아도 TeXShop은 새 TeX를 사용합니다.

다른 설치본을 사용하려면 그 프로그램이 들어 있는 폴더(예: /usr/local/texlive/2026/bin/universal-darwin)를 TeX 엔진에 입력하거나, “경로 자동 감지…”를 눌러 TeXShop이 찾은 설치본 중에서 고릅니다. 다른 TeX 배포판과 함께 사용하기를 참조하십시오.

TeX Live는 그대로 두기

TeX Live 폴더는 시스템의 일부이며, 업데이트하거나 새 연도의 TeX Live를 설치하면 교체됩니다. 이곳에 파일을 추가하거나 이곳의 파일을 변경하지 마십시오. 직접 만든 스타일 파일, 클래스, 참고 문헌은 개인 트리에 넣으십시오. TeX는 개인 트리에서 먼저 파일을 찾으며, 업데이트해도 개인 트리는 바뀌지 않습니다. TeX Live에 개인 파일 추가하기를 참조하십시오.

문서

TeX Live에는 거의 모든 패키지의 문서가 들어 있습니다. 도움말 › 패키지 도움말 보이기...는 hyperref나 tikz처럼 패키지 이름으로 그 패키지의 문서를 엽니다. 도움말 › TeX Live 안내서 (영문)는 TeX Live 안내서와 그 밖의 문서를 온라인에서 찾을 수 있는 곳을 알려 줍니다.
