다른 TeX 배포판과 함께 사용하기

한 Mac에 여러 TeX 설치본이 있을 수 있습니다. MacTeX나 BasicTeX로 설치한 여러 연도의 TeX Live, TeX Live 자체의 설치 프로그램으로 설치한 TeX Live, Homebrew나 MacPorts로 설치한 TeX 등입니다. TeXShop은 설정 › 조판 › 경로의 TeX 엔진 필드에 있는 설치본을 사용하고, Ghostscript는 그 아래의 Ghostscript 필드에 있는 것을 사용합니다.

경로 자동 감지

두 필드는 TeXShop이 대신 채울 수 있습니다. TeXShop을 처음 사용할 때, 그리고 설정 › 조판의 경로 그룹에서 “경로 자동 감지…”를 누를 때마다 TeXShop은 일반적인 위치에서 TeX와 Ghostscript를 찾습니다. 찾는 위치는 /etc/paths와 /etc/paths.d에 나열된 폴더와 TeXShop의 PATH에 있는 폴더, /Library/TeX/texbin, /usr/local/texlive, /opt/texlive, /Applications/TeXLive의 TeX Live 폴더, UpTeX.app과 pTeX.app의 TeX 폴더, /usr/local/teTeX/bin, 그리고 Homebrew, MacPorts, Fink의 폴더입니다. TeXShop은 프로그램이 실행되는지 확인한 다음, 찾은 설치본을 버전과 함께 최신 순으로 보여 줍니다. 가장 최신 설치본이 선택되어 있지만, TeX와 Ghostscript 각각에 대해 다른 설치본을 고를 수 있습니다. 경로는 “확인”을 눌러야 바뀝니다. 다른 위치에 있는 설치본도 필드에 직접 입력하여 사용할 수 있습니다.

“경로 자동 감지…”는 TeX 엔진과 Ghostscript만 바꿉니다. 자체적으로 폴더를 지정하는 엔진 파일과 두 번째 TeX 엔진 필드는 그대로 둡니다.

MacTeX 없이 설치한 TeX Live

MacTeX와 BasicTeX 설치 프로그램은 /Library/TeX/texbin이 자신이 설치한 TeX Live를 가리키게 하므로, 이 경로를 사용하는 프로그램은 가장 최근에 설치한 TeX Live를 따라갑니다. TeX Live 자체의 설치 프로그램으로 설치한 TeX Live는 이 링크를 바꾸지 않습니다. 그런 설치본을 사용하려면 “경로 자동 감지…”로 선택하거나, 그 프로그램이 들어 있는 폴더(예: /usr/local/texlive/2026/bin/universal-darwin)를 TeX 엔진에 입력합니다.

환경 변수

일부 배포판은 셸 시작 파일에서 TEXINPUTS나 TEXMFHOME 같은 환경 변수를 설정합니다. 그러면 TeX가 예상과 다른 폴더에서 파일을 읽게 되어, 같은 문서라도 터미널과 TeXShop에서 조판 결과가 달라질 수 있습니다. TeX가 엉뚱한 버전의 파일을 사용한다면 먼저 이런 변수를 확인하십시오. 터미널에서 kpsewhich 뒤에 파일 이름을 붙여 입력하면 TeX가 어느 파일을 찾는지 알 수 있습니다.
