조판 엔진 추가하기

TeXShop은 plain TeX와 LaTeX 외에 엔진으로도 조판합니다. 엔진은 ~/Library/TeXShop/Engines 폴더에 있는, 확장자가 .engine인 작은 셸 스크립트입니다. 엔진은 프로그램 하나를 실행할 수도 있고, LuaLaTeX, Biber, 다시 LuaLaTeX 두 번처럼 여러 프로그램을 차례로 실행할 수도 있습니다. TeXShop에는 LuaLaTeX, XeLaTeX, pdflatexmk 같은 엔진이 들어 있으며, 하위 폴더 Inactive에는 훨씬 많은 엔진이 있습니다.

엔진 선택하기

소스 윈도우 도구 막대에서 조판 버튼 옆의 팝업 메뉴에 엔진 목록이 있습니다. 엔진을 선택하고 조판 버튼이나 ⌘T를 누릅니다. 이 선택은 그 문서에만 적용됩니다.

새 문서를 어떤 엔진으로 조판하려면 설정 › 조판 › 엔진 › 새 문서 조판에서 “엔진 파일”을 선택하고, 그 아래의 엔진 파일 메뉴에서 엔진을 고릅니다. “엔진 목록 편집…”을 누르면 Finder에서 Engines 폴더가 열립니다. 이 폴더에서 파일을 추가하거나 삭제하거나 이름을 바꾸면 엔진 파일 메뉴에 그대로 반영됩니다. 선택한 엔진 파일이 폴더에 더 이상 없으면 메뉴에 “(찾을 수 없음)”이 붙어 표시되고, 문서는 LaTeX로 조판됩니다.

문서를 특정 엔진으로 조판하게 하려면 문서의 처음 20줄 안에 다음과 같은 줄을 넣습니다.

% !TEX program = XeLaTeX

이름은 엔진 파일의 이름에서 .engine을 뺀 것입니다. tex와 latex는 plain TeX와 LaTeX를 DVI 경유로, pdftex와 pdflatex는 PDF 직접 생성으로 조판합니다. 이 줄은 도구 막대, 설정, 조판 › 대체 엔진으로 조판보다 우선합니다. % !TEX TS-program = 형식도 같은 뜻으로 읽습니다. 이 줄은 위에 보인 그대로, 등호 양쪽에 공백을 하나씩 두고 쓰십시오. 매크로 메뉴의 Program 매크로는 엔진 목록을 보여 주고 이 줄을 대신 넣어 줍니다. 루트 파일이 있는 프로젝트에서는 루트 파일에만 이 줄이 있으면 됩니다.

조판 › 대체 엔진으로 조판(⌃⌥⌘T)은 도구 막대의 선택을 바꾸지 않고, 설정 › 조판 › 엔진 › 대체 엔진에 지정된 엔진(기본값은 pdflatexmk)으로 한 번 조판합니다. 평소에는 빠르게 한 번만 조판하고, 가끔 latexmk로 완전하게 조판하는 문서에 알맞습니다.

엔진 만들기

엔진을 만드는 가장 쉬운 방법은 Finder에서 Engines 폴더의 엔진 하나를 복제하고, 사본의 이름을 바꾼 다음, TeXShop에서 열어 편집하는 것입니다. 엔진 파일은 확장자가 .engine이어야 하고 실행 권한이 있어야 하는데, 복제한 파일은 실행 권한을 그대로 유지합니다. 그 뒤에 여는 문서에서는 도구 막대에 새 엔진이 나타납니다. 다음은 XeLaTeX.engine입니다.

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

첫 줄은 스크립트의 셸이나 언어를 지정합니다. 스크립트를 그 언어로 작성하기만 하면 zsh, bash, tcsh, Perl 등 무엇이든 사용할 수 있습니다. TeXShop은 소스 파일이 있는 폴더에서 엔진을 실행하며, 다음 세 값을 넘겨 줍니다.

$1
폴더를 뺀, 확장자가 붙은 소스 파일 이름(예: main.tex). 다른 폴더로 이동하는 스크립트는 먼저 "$PWD/$1"처럼 전체 경로를 기록해 두어야 합니다. 프로젝트에서는 루트 파일입니다.
$2
소스(루트 파일) 첫머리 근처에 있는 % !TEX parameter = … 줄의 나머지 부분. 플래그가 여럿이면 공백으로 구분합니다(예: % !TEX parameter = -shell-escape). 이런 줄이 없으면 공백 하나입니다.
$3
설정 › 조판 › 경로의 TeX 엔진 필드에 있는 폴더. 문서에 % !TEX useAlternatePath 줄이 있으면 두 번째 TeX 엔진 필드에 있는 폴더입니다.

엔진이 끝나면 TeXShop은 소스와 이름이 같고 확장자가 .pdf인 PDF 파일이 있을 때 그 파일을 미리보기 윈도우에서 열고, 조판 전에 보이던 곳으로 스크롤합니다. 다른 결과물을 만드는 스크립트는 다음 줄로 무엇을 보여 줄지 지정할 수 있습니다. 이 줄은 엔진의 어디에든, 그 언어의 주석 안에 씁니다.

줄효과
!TEX-noPreview아래의 다른 줄이 있어도 미리보기 윈도우를 열지 않음
!TEX-pdfPreviewPDF 파일을 보여 줌
!TEX-htmlPreview이름이 같은 HTML 파일을 HTML 윈도우에서 보여 줌
!TEX-bothPreviewPDF 파일과 HTML 파일을 모두 보여 줌
!TEX-noConsole콘솔을 표시하지 않음

예를 들어 LuaLaTeX와 Biber를 실행한 뒤 LuaLaTeX를 두 번 더 실행하는 엔진은 zsh로 다음과 같이 쓸 수 있습니다. 여기서 ${1:r}은 확장자를 뺀 이름입니다.

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

Inactive 폴더

하위 폴더 Engines/Inactive에는 latexmk, ConTeXt, Sage, PreTeXt, pythontex, Typst 등 특수한 작업을 위한 엔진이 들어 있으며, 설명서와 예제가 함께 있는 경우가 많습니다. 엔진을 사용하려면 그 폴더에서 Engines 폴더로 옮깁니다. TeXShop이 업데이트되면 Inactive 폴더는 최신 버전으로 교체되지만, Engines 폴더에 바로 들어 있는 파일은 건드리지 않으므로 직접 편집한 엔진은 그대로 남습니다.

엔진에 대한 자세한 내용은 도움말 › TeXShop 설명서 (영문)에서 조판 엔진에 관한 장을 참고하십시오.
