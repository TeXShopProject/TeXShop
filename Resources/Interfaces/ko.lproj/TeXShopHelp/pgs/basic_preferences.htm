설정 변경

TeXShop › 설정…(⌘,)을 선택하면 TeXShop의 동작을 변경할 수 있습니다. 설정의 사이드바에는 일반, 문서 및 저장, 편집기, 키보드, 맞춤법 검사, 테마, 조판, 콘솔, 미리보기, 업데이트의 10개 범주가 있습니다. 각 범주는 짧은 개요로 시작하며, 설정은 이름이 붙은 그룹으로 정리되어 있습니다. 설정이 열려 있는 동안 뒤로와 앞으로, 또는 ⌘[와 ⌘]를 사용하면 방문한 범주로 돌아갈 수 있습니다.

설정은 문서가 열릴 때의 상태를 정하고, 메뉴 명령은 활성 문서가 열려 있는 동안 그 문서만 변경합니다. 예를 들어 소스 › 줄 번호 보기는 활성 윈도우의 줄 번호를 보이거나 가리고, 설정 › 편집기의 “줄 번호 보기”는 문서를 열 때 줄 번호를 표시할지를 정합니다. 이런 설정은 편집기 범주와 미리보기 범주 맨 위의 “문서를 열 때” 그룹에 모여 있습니다.

변경 내용은 바로 저장됩니다. 텍스트 필드의 값은 Return 키를 누르거나 필드를 벗어날 때 적용됩니다. “자동 저장 및 버전 사용”과, OgreKit 찾기 패널로 전환하거나 OgreKit 찾기 패널에서 다른 것으로 전환하는 변경은 TeXShop을 다시 시작한 후 적용됩니다.

설정 검색

사이드바 맨 위의 설정 검색 필드에 입력하면 설정, 선택 사항, 메뉴 명령을 찾을 수 있습니다. 각 결과에는 항목 이름과 범주가 표시됩니다. 공백으로 구분한 단어는 모두 같은 항목에 해당해야 하며, 범주 이름을 넣으면 검색 범위가 좁혀집니다. 대소문자, 라틴 문자의 악센트, 전각 문자, 히라가나와 가타카나의 차이는 무시됩니다. 결과를 선택하면 해당 설정으로 이동하여 강조 표시하며, 뒤로를 누르면 원래 있던 곳으로 돌아갑니다. 검색어를 지워도 화면의 범주는 그대로 유지됩니다. 메뉴 명령을 선택하면 키보드 범주가 열리고 그 명령이 목록에 표시되며, 거기서 단축키를 변경할 수 있습니다.

일반

시작 시 그룹의 “빈 문서 열기”는 파일 없이 TeXShop을 시작할 때 빈 문서를 열지 정합니다. “외부 편집기 사용”은 소스를 다른 편집기로 작성할 때 사용하며, 이 경우 TeXShop은 소스 파일의 미리보기만 표시합니다. 외부 편집기 사용하기를 참조하십시오.

윈도우 그룹에서는 문서의 소스와 미리보기를 별도의 윈도우로 열지 한 윈도우로 열지, 한 윈도우에서 소스를 어느 쪽에 둘지(“통합 윈도우에서 소스의 위치”), 그리고 새 윈도우를 탭으로 열지를 선택합니다(윈도우와 탭 참조). 윈도우 위치 그룹은 소스, 미리보기, 콘솔, HTML 윈도우가 열릴 위치를 정하며, “현재 위치 저장”은 지금 열려 있는 윈도우의 위치와 크기를 사용합니다. 프로젝트 루트 파일 그룹의 설정을 켜면 프로젝트의 장 파일을 열 때 루트 파일이 열립니다. 프로젝트 루트 파일 설정을 참조하십시오.

실행 중인 Dock 아이콘은 TeXShop이 Dock에 표시하는 아이콘을 현재 아이콘과 이전 디자인 중에서 선택합니다. 고급 그룹에는 “매직 코멘트와 숨겨진 설정 설명서 열기…” 버튼이 있으며, 매직 코멘트와 이 윈도우에 표시되지 않는 설정을 정리한 문서를 엽니다. 숨겨진 설정을 참조하십시오.

문서 및 저장

“새 문서의 인코딩”은 유니코드(UTF-8)이며, 거의 모든 사용자에게 알맞은 선택입니다. 인코딩 행이 없는 파일을 열면 TeXShop이 인코딩을 판별합니다. 파일 첫머리에 % !TEX encoding = … 행을 넣으면(매크로 › Encoding으로 넣을 수 있습니다) 그 파일의 인코딩이 고정됩니다. “저장 대화상자에 인코딩 표시”를 켜면 저장 대화상자에 인코딩 메뉴가 추가됩니다. 인코딩을 참조하십시오.

“자동 저장 및 버전 사용”은 작업하는 동안 편집 내용을 저장하고 이전 버전을 보관하는 macOS 기능을 켭니다. “저장할 때 이전 파일을 ‘이름~’으로 남기기”는 저장할 때마다 저장하기 전의 파일을 백업으로 남깁니다. paper.tex라면 paper~.tex 파일입니다. “UTF-8-MAC을 UTF-8로 자동 변환”은 저장할 때 か(U+304B)와 결합용 탁점(U+3099)처럼 따로 저장된 문자를 하나의 문자(이 예에서는 が, U+304C)로 합칩니다.

편집기

“서체”는 모든 소스 윈도우의 서체를 정합니다. 고정폭 서체를 사용하면 소스의 열이 가지런히 맞습니다. 같은 표시 그룹의 “줄 번호 크기”는 줄 번호를 작게 또는 크게 표시하고, “메뉴 막대에서 태그 메뉴 보기”는 태그 메뉴를 메뉴 막대에 넣습니다. 편집기 스타일 그룹은 탭의 폭, 들여쓰기와 내어쓰기에 탭 문자를 쓸지(“탭 문자 사용”), 줄바꿈 없이 쓴 문단의 들여쓰기, 줄 간격을 정하며, 열려 있는 소스 윈도우에 바로 반영됩니다. 입력 그룹에는 소스 윈도우를 앞으로 가져오는 클릭으로 삽입 위치도 옮길지를 정하는 “선택시 커서 이동”, “괄호 입력 시 선택한 텍스트를 감싸기”, 그리고 이 언어들의 줄을 오른쪽에 맞추는 “오른쪽에서 왼쪽으로 쓰는 언어(아랍어, 히브리어, 페르시아어)”가 있습니다(인코딩 참조). 구문 하이라이트 그룹에는 명령 이름의 @, expl3 코드, 전각 문자, 색인 항목에 관한 스위치가 있으며, 색상은 테마에서 설정합니다. 찾기 그룹에서는 찾기 인터페이스와, 고급 찾기 패널을 다른 윈도우 앞에 둘지(“고급 찾기 패널을 항상 맨 앞에 표시”)를 선택합니다. 찾기 및 대치를 참조하십시오. 태그 목록의 XML 태그 그룹에서는 XML 문서의 어느 태그를 태그 메뉴에 나열할지 선택합니다.

“문서를 열 때” 그룹은 새 소스 윈도우에서 줄 번호 표시, 현재 줄 하이라이트, 줄 바꾸기, 숨김문자 표시, 블록 커서 사용 여부를 정합니다. 활성 윈도우에서는 소스 메뉴로 변경합니다. 삽입 그룹에서는 블록 커서의 색상, 블록 커서를 삽입 위치의 어느 쪽에 그릴지, 몇 글자 폭으로 그릴지를 설정합니다.

괄호 짝 맞추기

닫는 괄호를 입력하면 TeXShop이 짝이 되는 괄호를 보여 주므로, 수식의 괄호 쌍이 맞는지 확인할 수 있습니다. 괄호 짝 맞추기 그룹에서는 어떤 괄호 쌍을 확인할지와 짝을 어떻게 보여 줄지를 선택합니다. 잠깐 하이라이트하거나(괄호 여닫기 체크), 깜박이거나(대응 괄호 깜박이기), 괄호 쌍 사이의 텍스트에 색을 칠하거나(괄호 안의 내용 하이라이트), 삽입 위치가 괄호 옆으로 이동할 때도 보여 줍니다(이동 중에도 표시). 홑괄호 경고음과 홑괄호 경고 색상은 짝이 없는 닫는 괄호를 알려 줍니다. 괄호를 이중 클릭하면 짝이 되는 괄호까지 모두 선택됩니다. 색상은 테마의 하이라이트 그룹에 있는 괄호 안의 내용과 중괄호, 그리고 소스 그룹의 플래시입니다.

숨김문자

소스 › 숨김문자 보기는 활성 윈도우에서 공백, 전각 공백, 줄바꿈, 탭을 표시합니다. 텍스트가 이상하게 동작할 때 도움이 됩니다. 편집기의 숨김문자 그룹에서는 어느 문자를 표시할지와 각 문자에 사용할 기호를 선택하며, “문서를 열 때”의 “숨김문자 보기”를 켜면 모든 문서에서 표시됩니다. 색상은 테마의 하이라이트 그룹에 있는 숨김문자입니다.

키보드

키보드 범주에는 입력한 문자를 {} 같은 텍스트로 바꾸는 키 바인딩(키 바인딩 참조), 명령어 완성과 그 호출 키 및 완성 목록을 편집하는 “명령어 완성 파일 편집…”(명령어 완성 참조), 레이블과 인용 키 완성, 그리고 모든 메뉴 명령의 단축키가 있으며, 단축키는 여기서 변경할 수 있습니다(메뉴 단축키 재지정 참조).

맞춤법 검사

맞춤법 검사 그룹에서는 입력 중 맞춤법 검사, 맞춤법 자동 수정, 사전을 설정합니다. 방식 그룹에서는 “LaTeX 구문을 고려한 맞춤법 검사 사용(권장)”을 선택하십시오. 이 방식은 주석, 수식, 명령, 그리고 \label이나 \cite 같은 명령의 인수를 건너뛰며, “LaTeX 제외 규칙 편집…”으로 건너뛸 대상을 변경할 수 있습니다. “기존 방식”에는 자체 옵션이 세 개 있습니다. 맞춤법 검사를 참조하십시오.

테마

테마는 윈도우, 구문 하이라이트, 괄호 짝 맞추기, 숨김문자, 그 밖의 하이라이트에 사용하는 색상의 묶음입니다. “밝은 테마”와 “어두운 테마”는 macOS의 각 화면 모드에서 사용할 테마를 선택합니다. 그 아래의 테마 목록에서는 테마를 추가, 복제, 이름 변경, 삭제, 복원, 내보내기, 가져오기 할 수 있으며, 테마를 선택하면 색상을 변경할 수 있습니다. 테마의 변경 내용은 즉시 저장됩니다.

테마에서는 소스, 미리보기, 콘솔 윈도우의 배경색, 글자색, 커서 색상과 불투명도, 그리고 소스의 선택 부분 색상을 설정합니다. 커서와 선택 부분 색상 아래의 “시스템 색상 사용”을 켜면 시스템 설정 › 화면 모드에서 선택한 강조 색상과 하이라이트 색상이 대신 사용되며, 다시 끄면 테마 자체의 색상으로 돌아갑니다. 불투명도는 0%에서 100%까지의 슬라이더와 숫자 입력 필드로 조절합니다. 정수 백분율을 입력하고 Return 키를 누르거나 필드를 벗어나면 적용됩니다. 필드 옆의 화살표 버튼으로 1%씩 올리거나 내립니다. 범위를 벗어난 값은 가장 가까운 한계값으로 조정됩니다. 소수 등 잘못된 입력은 편집을 마칠 때 이전 값으로 돌아갑니다. 직접 입력한 텍스트와 붙여넣은 텍스트에 같은 규칙이 적용됩니다.

소스의 색상에 대해서는 구문 하이라이트를 참조하십시오.

조판

조판을 설정하는 가장 빠른 방법은 엔진 프로파일입니다. 엔진 그룹 맨 위의 엔진 프로파일 메뉴에서 pdfLaTeX, LuaLaTeX, upLaTeX + dvipdfmx 같은 프로파일을 선택합니다. 프로파일이 설정하는 값이 시트에 나열됩니다. 현재 설정을 유지할 값은 끄고, LaTeX를 latexmk로 실행할지 선택한 다음 확인을 클릭합니다. 프로파일은 조판 명령과 조판 방식, kpsewhich 명령, BibTeX 엔진, 색인 프로그램, MetaPost, otf 변환을 설정하며, 일본어 프로파일은 새 문서의 인코딩, 사전, UTF-8-MAC 변환도 설정합니다. 그 밖의 설정은 그대로 유지됩니다. 설정이 어느 프로파일과도 일치하지 않으면 메뉴에 “사용자화”가 표시됩니다.

엔진 그룹의 나머지 설정은 문서를 열 때 도구 막대의 조판 버튼 옆에서 선택되는 것(새 문서 조판), 거기서 엔진 파일을 선택했을 때 사용할 엔진 파일, 그리고 조판 방식(PDF 직접 생성, DVI 경유, 사용자 스크립트)을 정합니다. 문서 첫머리의 % !TEX program 행이 이 설정보다 우선합니다. “대체 엔진”은 조판 › 대체 엔진으로 조판이 사용하는 엔진입니다. 조판 엔진 추가하기를 참조하십시오. “조판 후 동작”은 조판이 끝났을 때 어느 윈도우를 앞으로 가져올지를 “미리보기 윈도우를 앞으로”, “소스 윈도우에서 계속 편집”, “미리보기 윈도우를 표시한 후 원래 윈도우로 돌아가기” 중에서 선택합니다. 소스와 미리보기 동기화 그룹에서는 “동기화 방식”과, 동기화로 여는 파일을 루트 파일 윈도우의 탭으로 열지를 선택합니다. 소스와 미리보기 동기화를 참조하십시오.

PDF 직접 생성 그룹과 DVI 경유 그룹에는 각 방식이 실행하는 plain TeX 명령과 LaTeX 명령이 옵션과 함께 들어 있습니다. 명령에 -shell-escape를 추가했다면 “shell-escape 시 확인”을 켜십시오. 그런 문서를 조판하기 전에 확인을 요청합니다. Shell Escape 보호를 참조하십시오. 사용자 스크립트 그룹에는 사용자 스크립트 방식의 명령이 있습니다. 관련 도구 그룹에는 BibTeX, 색인 작성, MetaPost의 명령이 있습니다. 문서 조판과 대체 조판 방식을 참조하십시오.

경로 그룹에는 TeX 프로그램의 폴더(TeX 엔진, 보통 /Library/TeX/texbin), Ghostscript의 폴더, 그리고 % !TEX useAlternatePath 행이 있는 문서에 사용하는 또 하나의 TeX 프로그램 폴더인 “두 번째 TeX 엔진”이 있습니다. “경로 자동 감지…”는 일반적인 위치에서 TeX Live와 Ghostscript를 찾아, 찾은 설치본을 버전과 함께 최신 것부터 나열하고 선택한 것을 설정합니다. TeXShop을 처음 사용할 때도 이 작업을 합니다. 일본어 pLaTeX 그룹은 일본어 조판에서 설명합니다.

콘솔

콘솔 범주에서는 콘솔의 서체(원하면 매크로 편집기에도 적용)와 콘솔이 나타나는 시점, 즉 조판할 때 항상 나타날지 오류가 발생했을 때만 나타날지를 설정합니다. “콘솔 윈도우 크기 조절”은 콘솔 윈도우의 크기를 자유롭게 바꿀 수 있게 할지(자유롭게 크기 조절), 세로로만 바꿀 수 있게 할지(세로로만 크기 조절)를 정합니다.

미리보기

“문서를 열 때” 그룹은 새 미리보기 윈도우가 문서를 표시하는 방식을 정합니다. 페이지 형식, 배율, 마우스 모드, 링크 팝업, 두 페이지 표시의 방향입니다. 다른 그룹에서는 페이지 넘기기와 링크 팝업, 다른 응용 프로그램이 PDF를 변경했을 때의 새로 고침, 복사할 이미지의 형식, HTML 윈도우의 시작 페이지를 설정합니다. 미리보기 윈도우를 참조하십시오.

업데이트

TeXShop은 매일, 매주 또는 매월 새 버전을 자동으로 확인할 수 있습니다. 베타 버전도 받으려면 “가능한 경우 사전 발매 버전으로 업데이트”를 켜십시오. “업데이트 확인...”을 클릭하면 지금 바로 확인합니다.
