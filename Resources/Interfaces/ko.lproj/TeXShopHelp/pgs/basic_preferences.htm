범주 이름이나 설명이 일치하면 해당 범주의 맨 위로 이동하는 항목 하나가 표시됩니다. 개별 설정은 자체 이름, 선택 항목 또는 설명으로 검색됩니다. 같은 행의 색상 필드는 결과 하나로 표시됩니다.

Changing settings in the Settings window

설정에는 일반, 문서 및 저장, 편집기, 맞춤법 검사, 테마, 미리보기, 조판, 콘솔, 키보드, 업데이트의 10개 범주가 있습니다. 맞춤법 검사에서 “LaTeX 구문을 고려한 맞춤법 검사 사용(권장)” 또는 “기존 방식”을 선택합니다. 새 방식에는 “LaTeX 제외 규칙 편집…”, 기존 방식에는 들여쓴 하위 옵션 세 개가 있습니다. 완성 키가 Tab일 때 Tab을 검색하면 예약 안내와 완성 키 설정을 표시합니다. 일반에서 주석 행과 숨겨진 설정 설명을 열 수 있습니다.

Windows and display

Several items can be changed in the Settings window: the default font for the input window, the default magnification for the output window, and the default position of these windows when they first appear. You can configure the console so it always appears when typesetting, or only appears when there is an error. You can configure the source window so an initial click in the window only activates the window, or this initial click also sets the text insertion point.

Typesetting commands

The Settings window can also be used to change the commands executed when the "TeX" and "LaTeX" buttons are pushed. This is useful because some users prefer a version of TeX called etex, and there are pdf versions of etex called pdfetex and pdfelatex. Obviously the substituted command must produce a pdf output file. If the new programs are in the teTeX binary directory, it is enough to name them in the Settings window; the dialog will also accept fully qualified path names for files which live elsewhere.

Text encoding

TeXShop editing is done with Apple's Cocoa editing class, which uses Unicode for internal work. When TeXShop files are written to disk, they are usually converted to 8-bit ascii because TeX expects to receive such a file. There are several ways to do the conversion: Mac OS Roman, Iso Latin 1, Iso Latin 2, and others. A setting selects the method used. For many users, the choice will make no difference. Some TeX packages allow users to type accented European characters directly on the keyboard; these packages require the Iso Latin conversion. Thanks to Martin Heusse for providing the original code for this setting. The conversion method can also be selected directly from the Open and Save panels.

When TeXShop typesets a source file, it displays the result in the preview window, activating this window and bringing it to the front. A setting changes this behavior, showing the result in the preview window but keeping the source window active for further editing. This is particularly useful if you have a large monitor and the source and preview windows do not overlap. To change this setting, choose the 조판 category in Settings and change the "After Typesetting" item to "Continue Editing."

Japanese/Korean settings

Users in Japan and Korea will use other conversion settings, also provided.

일반의 설정 프로파일에서 기본 설정 묶음을 적용할 수 있습니다.

Invisible character settings

The item "Show Invisible Characters" in the Source menu makes certain invisible characters visible: the space character, a special wider space used in Japan, the newline character, and the tab character. The choice of which characters to show and how to represent them is made in the "Show Invisible Characters" section of the Settings window. Most users want invisible characters to be shown only on rare occasions when puzzling things happen, but if you want them to be shown by default, select the "On by Default" item in this section of the Settings window.

The color of invisible character representatives is orange, but this color can be changed by a hidden setting. See the "Hidden Settings" section of Advanced Help.

Brace matching settings

TeX makes extensive use of various kinds of braces: parentheses, curly brackets, etc. A common mistake is to write source in which the braces don't match. TeXShop has brace matching code to help avoid this error. The code is configured in the "Parens Targets & Highlight Color" and "Parens Matching Settings" sections of the Settings window.

When a brace is typed, this brace and its matching brace flash and temporarily turn color, and the background of the text between them also turns color. This makes it easy to make sure that the scope of the brace pair is correct. As soon as another character is typed, these temporary colors are removed.

Because temporary colors and flashes can be distracting, the user is given fine control over this behavior. First, the types of braces it affects can be selected. Many users, for instance, prefer that it not apply to ordinary parentheses "(, )" because they occur so often. Second, the temporary color of the braces can be modified; by default it is magenta.

The "Highlight Enclosed Characters" item determines whether the background of text between the braces temporarily changes color. The "Show Indicator in Moving" determines whether this code applies when moving the cursor through the source with the arrow keys. The "Blink Highlight" item determines whether the matching brace pair momentarily changes color and then returns to the usual color, or instead changes color until another character is typed. Finally, "Beep for Isolated Parens" and "Flash Back for Isolated Parens" cause the user to be notified when a brace is typed which has no matching brace.

The color of the temporary background for text inside a brace pair (default is yellow) can be changed by a hidden setting. See the "Hidden Settings" section of Advanced Help.

On Snow Leopard and above, matching braces are briefly marked with a yellow badge over the brace; this fulfills a request for greater visibility of the matching characters. This badge can be turned off; see the "Hidden settings" section of Advanced Help for details.

Hidden settings

Although most of the TeXShop's settings are available in the Settings window, some more low-level settings are only settable using the command line.

Background, Text and Cursor Colors

테마에서 소스, 미리보기 및 콘솔 창의 배경색, 글자색, 커서 색과 불투명도를 설정합니다. 불투명도는 0~100% 슬라이더와 숫자 입력 필드로 조절합니다. 정수 백분율을 입력하고 Return을 누르거나 다른 필드로 이동하면 적용됩니다. 필드 옆의 화살표 버튼으로 1%씩 올리거나 내립니다. 범위를 벗어난 정수는 0 또는 100으로 조정됩니다. 소수 등 잘못된 입력은 편집을 마칠 때 이전 값으로 돌아갑니다. 직접 입력한 텍스트와 붙여넣은 텍스트에 같은 규칙이 적용됩니다.

Adding to the list of file types

There is a hidden setting to add file extensions to the list of files that TeXShop recognizes as source files which can be typeset and syntax colored. This is useful when you want to use syntax coloring when editing TeX files with non-standard extensions. For example,

defaults write TeXShop OtherTeXExtensions -array-add "lbx"

tells TeXShop to syntax color biblatex 'lbx' files.

설정 검색

사이드바 위의 검색 필드에서 설정, 선택 사항, 메뉴 명령을 찾습니다. 각 결과에는 항목 이름과 범주가 표시됩니다. 공백으로 구분한 단어는 같은 항목에 해당하며 범주 이름으로 범위를 좁힐 수 있습니다. 대소문자, 라틴 문자 악센트, 전각 문자, 히라가나와 가타카나를 정규화합니다. 결과를 선택하면 해당 행으로 이동하여 강조하고 방문 기록에 추가합니다. 검색어를 지우면 표시 중인 범주를 유지합니다. 검색 중에도 뒤로 및 앞으로는 방문 기록에 따라 이동합니다. 메뉴 명령 결과는 키보드를 열고 기능 검색을 필터링합니다. 단축키를 기록하는 동안에는 키 기록을 우선합니다.

자동 저장 및 버전은 TeXShop을 다시 시작한 후 적용됩니다. 표준 검색 패널과 검색 막대 사이의 전환은 열린 문서의 소스, 콘솔, 로그에 즉시 적용됩니다. OgreKit으로 전환하거나 OgreKit에서 다른 방식으로 전환하면 다시 시작한 후 적용됩니다.
