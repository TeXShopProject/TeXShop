报告问题

要报告问题或提出改进建议，请在 GitHub 上提交 issue：

https://github.com/TeXShopProject/TeXShop/issues

请先搜索未关闭和已关闭的 issue：该问题可能已为人所知，或已在较新的版本中修复。提交 issue 需要 GitHub 帐户。

能够迅速得到处理的报告会说明：

  • TeXShop 的版本（“TeXShop”>“关于TeXShop”）和 macOS 的版本；
  • 你做了什么、预期的结果是什么，以及实际发生了什么；
  • 对于排版问题，提供能重现问题的简短源文件，以及控制台的输出或日志文件；
  • 对于窗口或菜单的问题，提供屏幕快照或简短的屏幕录制。

关于 TeX、LaTeX 宏包或 TeX Live 本身的问题，最好到“实用网站”中列出的地方提问，例如 TeX Stack Exchange。
