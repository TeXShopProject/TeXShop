删除辅助文件

LaTeX 排版 Galois.tex 时，会写出 Galois.aux、Galois.toc 和 Galois.log 等辅助文件，下一次运行会读取它们来处理交叉引用、目录等。如果排版在中途停止（例如出错之后），这些文件可能会损坏，下一次运行就会报告源文件中并不存在的错误，通常就在 \begin{document} 之前。把辅助文件移到废纸篓再重新排版，就能解决这个问题。

将文件移到废纸篓

  • “文件”>“删除 Aux 文件”（⌃⌘A）或控制台中的“删除 Aux 文件”按钮，会把文稿的辅助文件移到废纸篓。
  • “排版”>“删除 Aux 文件 & 开始排版”（⌥⌘T）会执行此操作，然后进行排版。在“排版”菜单中，按住 Option 键时，该项目会出现在“开始排版”的位置。

移到废纸篓的文件，是源文件所在文件夹中与源文件同名、并带有以下扩展名之一的文件：

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

排版中断时 SyncTeX 留下的、名称以 (busy) 结尾的文件也会被移到废纸篓。BibTeX 的 .bbl 文件会保留。

在各章节文件用 % !TEX root 指定根文件的项目中，移到废纸篓的是根文件的辅助文件，即使是在章节文件中执行该命令也是如此。

变体

  • 在选取“删除 Aux 文件”或点按该按钮时按住 Shift 键，会把文稿的 PDF 文件也移到废纸篓。通常旧的 PDF 会被保留，以便排版失败时预览窗口仍有内容可显示。
  • 在选取“删除 Aux 文件”或点按该按钮时按住 Option 键，会清理整个项目：根文件所在文件夹及其下所有文件夹中带有上述扩展名之一的每个文件，无论名称如何，都会被移到废纸篓。这也会移除 \include 为子文件夹中的各章写出的 .aux 文件。

有两项隐藏设置可以改变这一行为。要向列表中添加扩展名（例如 dvi），请在终端中键入

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

要恢复标准列表，请键入

defaults write TeXShop OtherTrashExtensions -array

要让按住 Option 键时的行为成为“删除 Aux 文件”的标准行为：

defaults write TeXShop AggressiveTrashAUX YES
