实用网站

TeXShop
TeXShop 的网站。
GitHub 上的 TeXShop
TeXShop 的源代码，也是报告问题的地方（请参阅“报告问题”）。
MacTeX
面向 macOS 的 TeX Live 发行版，附带 TeXShop 和其他程序。
TeX Users Group (TUG)
国际 TeX 用户组，TeX Live 和许多 TeX 资源的大本营。
CTAN
综合 TeX 档案网络（Comprehensive TeX Archive Network）：宏包、字体及其文档。
TeX Stack Exchange
关于 TeX、LaTeX 及相关程序的问答。
learnlatex.org
LaTeX 简明教程，附有可在线试用的示例。
The LaTeX Project
维护 LaTeX 的团队发布的新闻和文档。
MetaPost
MetaPost 绘图语言。
XeTeX
XeTeX 和 XeLaTeX，它们使用你的 Mac 上安装的字体。
ConTeXt Garden
ConTeXt 的文档和社区。
