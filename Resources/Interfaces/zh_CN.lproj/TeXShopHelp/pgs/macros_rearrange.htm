重新排列“宏”菜单

打开宏编辑器（“宏”>“打开宏编辑器…”）。左侧的列表以大纲形式显示“宏”菜单，就像访达窗口的列表视图一样。要移动某个项目，请把它拖到其他位置；向左或向右拖移可把它放到其他层级，即放进子菜单或移出子菜单。

要给某个项目重新命名，请选择它并按 Return 键，或者像在访达中一样，稍等片刻后再次点按它的名称。键入新名称并按 Return 键；按 Esc 键则保留原来的名称。
