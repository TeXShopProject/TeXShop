默认 AppleScript 宏

TeXShop 附带一组由 Will Robertson、Claus Gerhardt 等人编写的 AppleScript 宏。其中一些会依次运行一系列排版命令。通过拷贝和修改它们，你可以为自己的工作编写脚本。本页按它们在“宏”菜单中的名称介绍其中的一部分。

Column macros、Insert reference、Open quickly…

这些宏由 Will Robertson 编写。在 Column macros 子菜单中，New tabular 和 New array 会按你输入的行数和列数插入 tabular 或 array 环境，Add column 和 Delete column 会更改你所选的行。Insert reference 在当前文件中搜索 \label{…} 命令，让你从列表中选择一个标签；它插入用 \ref{…} 包围的标签，这个命令可以在脚本中更改。如果选择了文本，则只列出包含该文本的标签。Open quickly… 列出当前源文件所在文件夹中的 .tex、.sty 和 .pdf 文件，并打开你所选的文件。

Paste Spreadsheet Cells

这个宏由 Alan Munn 编写，它把电子表格中的单元格作为表格粘贴到你的 LaTeX 源文件中。在 Excel 或其他电子表格应用中选择一个单元格范围并拷贝。然后选取“宏”>“Paste Spreadsheet Cells”，并选择一种表格样式：

cells
只把拷贝的文本转换为 LaTeX 表格单元格。
booktabs
把第一行作为表头，并在 tabular 环境中放入 \toprule、\midrule 和 \bottomrule。
simple
在单元格外围加上简单的 tabular 环境。
longtable
把第一行作为表头，添加 longtable 的表头行，并把单元格放入 longtable 环境。

该宏会把剪贴板的内容替换为 LaTeX 文本。要以另一种样式粘贴同样的单元格，请先在电子表格中重新拷贝它们。

Applescript › Convert to MAC、Convert to Unix、Convert to Windows

文本文件以不同的方式结束各行：macOS 和 Unix 使用换行符，Windows 使用回车符加换行符，非常旧的 Macintosh 文件则只使用回车符。TeXShop 能读取这三种格式。如果别人的编辑器无法读取，请使用这些宏。对于源文件 MyFile.tex，Convert to Unix 会把已保存的文件拷贝为使用换行符、名为 MyFile_Unix.tex 的文件；Convert to Windows 写出 MyFile_Windows.tex，Convert to MAC 写出 MyFile_Mac.tex。这些宏使用 ~/Library/TeXShop/bin 中 Craig Stuart Sapp 编写的程序 flip。

Applescript › Bibliography

带有参考文献列表的文稿需要运行多次：LaTeX 写出 .aux 文件，BibTeX 用它写出 .bbl 和 .blg 文件，LaTeX 再次运行以加入参考文献列表，然后再运行一次以更新对它的引用。Bibliography 宏会依次运行 LaTeX、BibTeX、LaTeX 和 LaTeX。用 TeXShop 排版命令编写脚本说明了它的工作原理。

Claus Gerhardt Macros

这个子菜单中的大多数宏会调用 ~/Library/TeXShop/bin 中同名的 shell 脚本；bibtexcpl、mpostcpl 和 latex-makeindex-mpost 会依次调用其中的几个，openpdf 会打开文稿的 PDF。它们作用于已保存的文件。用 Shell 命令编写脚本以 pdflatexc 为例进行了说明。

htlatexc、htlatexr

TeX4ht 把 LaTeX 文稿转换为网页：一个 HTML 页面和一些图像文件。htlatexc 对文稿运行 htlatex，并在 Safari 浏览器中打开生成的 HTML 文件。文稿中不需要载入 tex4ht 宏包；htlatex 会载入它。htlatexr 以选项 -r 运行 htlatex，即使图像已经存在，也会重新生成。

pdfselectc

pdfselectc 生成包含文稿 PDF 中所选页面的 PDF 文件。它先询问要生成几个文件，然后询问每个文件的页面，例如 5:8 表示第 5 页到第 8 页，或者 3:4,6,8:12。如果文稿名为 MyFile，这些文件会保存为 MyFile-1.pdf、MyFile-2.pdf 等。

mpostc、mpostcpl、latex-makeindex-mpost

mpostc 先运行 MetaPost，再运行 pdfLaTeX；mpostcpl 运行 pdfLaTeX、MetaPost，再运行一次 pdfLaTeX。latex-makeindex-mpost 运行 pdfLaTeX、MakeIndex、MetaPost，再运行一次 pdfLaTeX，并在过程中打开日志文件。有关 MetaPost，请参阅 ConTeXt 和 MetaPost。
