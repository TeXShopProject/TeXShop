使用外部编辑器

你可以在其他编辑器中写作，而用 TeXShop 排版并显示 PDF。

只打开预览

“文件”>“打开以预览…”会要求你选择一个源文件，然后只打开它的预览窗口。如果该文件尚未排版，或者 PDF 比源文件旧，TeXShop 会先排版它。请在你的编辑器中编辑源文件；要排版时，先在编辑器中保存，然后点按预览窗口中的“排版”或按 ⌘T。在这种模式下，TeXShop 从不打开或更改源文件。如果预览窗口的工具栏中没有“排版”按钮，请用“窗口”>“自定义工具栏…”添加一个。

如果你总是这样工作，请打开“设置”>“通用”>“启动时”>“配置为外部编辑器”。这样，“文件”>“打开…”和“打开最近使用”会以仅预览的方式打开源文件，而“文件”>“打开以预览…”会变为“打开以编辑…”，需要时可以用它在 TeXShop 自己的编辑器中打开源文件。其他文件（例如 PDF、图形文件和日志文件）的打开方式与以前相同。

让预览保持最新

当 PDF 被其他程序（例如你的编辑器或终端中的 latexmk）重写时，TeXShop 会在你返回 TeXShop 或预览窗口时重新载入它，并保持页面和放大率不变。打开“设置”>“预览”>“刷新”>“始终监视其他应用对 PDF 的更改”后，PDF 一有变化就会重新载入，即使 TeXShop 在后台也是如此，例如当预览放在你的编辑器旁边时。带有未保存批注的预览不会重新载入，因此批注不会丢失。

TeXShop 也会监视在它自己的编辑器中打开的源文件。当其他编辑器更改了这样的文件时，TeXShop 会重新载入它，除非 TeXShop 中的副本有未保存的更改。

与编辑器同步

在预览窗口中按住 Command 键点按，可以跳到编辑器中的相应行；控制台中的“转到错误”可以在编辑器中打开出错的行。这需要“配置为外部编辑器”、一项隐藏设置以及编辑器的命令行程序：

  • 对于 TextMate（其命令 mate 位于 /usr/local/bin 中）：defaults write TeXShop TextMateSync YES。
  • 对于任何其他编辑器：defaults write TeXShop OtherEditorSync YES，以及一个可执行脚本 /usr/local/bin/othereditor，它以 $1 接收行号，以 $2 接收文件的完整路径。对于 BBEdit，脚本如下： 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

对于另一个方向（从编辑器中的某一行到预览窗口），编辑器通过 AppleScript 用命令 sync_preview_line、sync_preview_index 和 sync_preview_name 调用 TeXShop。“帮助”>“TeXShop 手册（英文）”的“Using an External Editor”一章中有完整的脚本。

文件夹 ~/Library/TeXShop/ExternalEditorScripts 中有现成的支持文件及说明文档：在 TeXShop 中排版和预览 BBEdit 文稿的 AppleScript，以及一个 Vim 插件。

供编辑器使用的 AppleScript 命令

编辑器可以调用 TeXShop 文稿的以下 AppleScript 命令：

typesetinteractive、texinteractive、latexinteractive、bibtexinteractive、makeindexinteractive、metapostinteractive
排版，或者运行 plain TeX、LaTeX、BibTeX、MakeIndex 或 MetaPost。调用会立即返回，不等待排版结束；排版结束时会刷新预览。
taskdone
排版正在进行时返回 NO，完成后返回 YES。
refreshpdf
重新载入 PDF，并把预览窗口移到最前面。
refreshpdfbackground
在预览窗口已打开时重新载入 PDF，而不把 TeXShop 移到最前面。
refreshtext
从磁盘重新读取源文件。
open_for_externaleditor
以“文件”>“打开以预览…”的方式打开源文件。

当编辑器通过 TeXShop 排版时，不需要“始终监视其他应用对 PDF 的更改”。另请参阅用 TeXShop 排版命令编写脚本。
