定义新宏

在宏编辑器（“宏”>“打开宏编辑器…”）中，点按列表下方的 + 可添加项目。列表下方栏右端的菜单（⋯）可添加子菜单或分隔线，以及复制所选的项目；− 会删除它们。新项目或子菜单会立即进入命名状态：键入名称并按 Return 键。子菜单可以嵌套任意多层。稍加练习就能了解编辑器的用法。

更改会在你编辑时立即保存，关闭窗口时不会询问是否保存。没有“保存”按钮，也没有“取消”按钮。“测试”会按编辑器中的当前内容，在当前文稿中运行所选的宏；在列表中连按某个宏效果相同。

快捷键

要为某个项目指定键盘快捷键，请选择它并点按列表中它的快捷键（或连按该快捷键），然后按下新的快捷键：Command 或 Control 加一个键，或者 F1–F20 之一，可根据需要加上 Shift 和 Option。如果某个菜单命令或其他宏已在使用该快捷键，TeXShop 会在内容下方提示，并且不做更改；请按下其他快捷键。要移除快捷键，请点按栏中的“移除快捷键”（⊖）或按 Delete 键；按 Esc 键则保留原来的快捷键。由于某个菜单命令或排在前面的宏正在使用而失效的快捷键，会在列表中以警告三角形标出；选择该项目即可在内容下方看到原因。菜单快捷键和宏快捷键如何协同工作，请参阅重新定义菜单键盘快捷键。

占位符

在内容中，宏所替换的占位符显示为圆角标记，标记上写着它代表什么，例如“所选文本”：文本宏的 #SEL#、#INS#、#PASTE# 和标记 •（请参阅了解默认宏），以及 AppleScript 宏的 #FILEPATH# 和其他路径（请参阅定义 AppleScript 宏）。宏会按原样保留这些写法，因此拷贝和保存都能照常进行。可以直接键入占位符，也可以从内容下方的“插入”菜单中选择；菜单右侧的帮助按钮会列出所有占位符。在标记旁边删除时，会删除整个标记。
