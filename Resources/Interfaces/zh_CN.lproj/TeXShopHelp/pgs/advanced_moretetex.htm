进一步了解 TeX Live

TeX Live 的安装位置

MacTeX 把 TeX Live 安装在 /usr/local/texlive/2026 中，BasicTeX 则安装在 /usr/local/texlive/2026basic 中。TeX Live 每年发布一次，每一年的版本安装在各自的文件夹中（例如 2027），因此 Mac 上可以并存多个年份的版本。要移除其中一个，请将它的文件夹拖到废纸篓。

文件夹 /usr/local 在访达中是隐藏的。要查看其中的内容，请在访达中选取“前往”>“前往文件夹…”，然后键入路径。

TeXShop 如何找到 TeX

TeXShop 从“设置”>“排版”>“路径”的“TeX 引擎”栏中的文件夹运行 TeX。默认为 /Library/TeX/texbin，这是一个链接，MacTeX 和 BasicTeX 安装器会让它指向刚安装的 TeX Live 的程序。安装新年份的 TeX Live 时，该链接会随之更新，TeXShop 无需更改任何设置就会使用新的 TeX。

要使用其他安装，请在“TeX 引擎”中输入其程序所在的文件夹，例如 /usr/local/texlive/2026/bin/universal-darwin，或者点按“自动检测路径…”，从 TeXShop 找到的安装中选择；请参阅与其他 TeX 发行版共存。

保持 TeX Live 原样

TeX Live 的文件夹属于系统，TeX Live 的更新或新年份版本会替换它们。请不要在其中添加或更改文件。请把你自己的样式文件、文档类和参考文献放在个人目录树中，TeX 会优先在那里查找，而且更新不会改动它们；请参阅向 TeX Live 添加个人文件。

说明文档

TeX Live 包含几乎每个宏包的说明文档。“帮助”>“显示宏包的帮助…”可按宏包名称（例如 hyperref 或 tikz）打开该宏包的说明文档。“帮助”>“TeX Live 文档（英文）”列出了在网上何处可以找到 TeX Live 指南和其他说明文档。
