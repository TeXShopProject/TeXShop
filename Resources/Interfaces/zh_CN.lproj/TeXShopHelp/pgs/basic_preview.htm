预览窗口

预览窗口显示排版生成的 PDF 文件。每次排版后它都会更新，并停留在你正在阅读的页面。它的设置位于“设置”>“预览”中：“打开文稿时”下的设置在打开文稿时生效，“预览”菜单则可为最前面的窗口更改这些设置。

在文稿中移动

“预览”>“显示样式”用于选择页面的排列方式：“单页”和“双页”一次显示一页或一对页面，“多页”和“对开多页”则将所有页面显示为一个长列。“打开文稿时”下的“默认页面格式”用于设置窗口开始时的显示样式。“预览”菜单和工具栏中的“上一页”和“下一页”用于翻页，工具栏中的“转到页”栏可按页码转到某一页，工具栏中“返回/前进”的两个箭头则像网页浏览器一样回到你之前所在的位置。

在“单页”和“双页”中，滚动超过页面的顶端或底端时会翻页；在“设置”>“预览”>“显示与浏览”中打开“滚动时不翻页”，即可改为停在页面边缘。上下方向键在页面内滚动。页面放大后比窗口宽时，左右方向键横向滚动，否则翻页；“左右方向键总是翻页”会让它们始终翻页。

工具栏中有两个用于页面的菜单；如果它们已被移除，可以用“窗口”>“自定义工具栏...”放回去。“页面布局”用于选择显示样式。“双页模式”仅针对此文稿选择一对页面是从左到右还是从右到左阅读，以及是否将第一页单独显示为封面；其中的“恢复文稿设置”会恢复为设置中的值。对应的设置是“打开文稿时”下的“页面方向”和“将第一页单独显示为封面”；魔法注释行 % !TEX PageDirectionL2R、% !TEX PageDirectionR2L、% !TEX bookDisplay 和 % !TEX standardDisplay 可为单份文稿设置它们。

放大

“预览”>“放大”提供以下选项：

“适合窗口”
页面填满窗口的宽度，调整窗口大小时放大率随之改变。
“适合内容宽度”
与“适合窗口”类似，但不含白色边距：页面上排版的部分填满窗口的宽度。
“固定放大率”
放大率保持为在工具栏的“放大”栏中设置的值，或用“放大”（⇧⌘+）和“缩小”（⇧⌘_）设置的值。
“实际大小”
按纸张的实际尺寸显示页面。

同一子菜单末尾的“缩放到内容”和“缩放到内容宽度”会一次性设置放大率，使页面上排版的部分适合窗口或填满窗口的宽度。使用工具栏、这些命令或在触控板上双指捏合更改放大率后，窗口会切换为“固定放大率”；再次选取“适合窗口”即可恢复。点按“放大”栏旁边的文字会打开“放大”菜单。“打开文稿时”下的“调整窗口大小后”和“放大”用于设置窗口开始时的放大率。

鼠标工具

工具栏中的“鼠标模式”项目用于选择指针在页面上的作用。“滚动”用于移动页面。“选择文本”用于选择要拷贝的文本。“放大镜”和“放大镜 (大号)”在按住鼠标按钮时显示放大镜：连按并按住可显示更大的放大镜，连按三次并按住可放大整个窗口，按下 Command、Option 或 Control 键可放大更多；同时再按下 Shift 键则放大得少一些。“选择PDF”用于选择页面的某个区域，作为图片拷贝。“打开文稿时”下的“默认鼠标模式”用于选择窗口开始时使用的工具。

使用“选择PDF”时，在页面上拖过一个区域，然后用 ⌘C 拷贝，或将其拖到其他应用或桌面上；“预览”>“保存选区到文件...”会将其存储为文件。“预览”>“副本样式”用于选择拷贝为 PDF 还是 PNG、TIFF 或 JPEG 等图片；“设置”>“预览”>“复制图像”中的“图像副本类型”用于设置默认值。请参阅“拷贝粘贴和拖放”。

搜索和辅助面板

在工具栏的“搜索”栏中输入一个词并按下 Return 键，即可选中它第一次出现的位置；⌘G 转到下一处。预览窗口在最前面时，⌘F 会转到此栏。

“预览”>“显示辅助面板”或工具栏中的“辅助面板”项目会显示辅助面板。其上半部分是文稿的大纲，由 hyperref 宏包根据章和节生成；点按某个条目即可转到那里，也可以用方向键选择条目并按下 Return 键。其下半部分是第二个搜索栏，它会列出每一处匹配及其所在页面；点按其中一项即可转到那里。

链接和链接预览

hyperref 宏包生成的链接在预览中可以使用：点按引用即可转到相应的定理或参考文献条目，工具栏中“返回/前进”的左箭头可以返回。网址会在你的网页浏览器中打开。

将指针停留在链接上，会在弹出框中显示链接目标，右下角显示页码。弹出框几秒后消失。弹出框出现时按住的键会改变它：

Shift
将弹出框显示在链接上方而不是下方。
Command
显示较大的弹出框。
Option
固定弹出框，使其保持显示。弹出框显示时按下 Option 键也会将其固定。
Control
对此链接反转“链接预览”：“链接预览”打开时不出现弹出框，因此不会妨碍按住 Control 键点按；“链接预览”关闭时则照样出现弹出框。

固定的弹出框可以移动、调整大小和滚动，其中的文本可以选择和拷贝。在你点按、滚动、缩放、跟随链接或在其他窗口中工作时，它都停留在所在页面的原位置，直到你在预览窗口中按下 Escape 键。固定了一个弹出框后，其他弹出框仍会出现，按 Option 键则会改为固定其中一个。

“预览”>“链接预览”用于为该窗口打开或关闭弹出框，“打开文稿时”下的“链接预览”用于设置打开文稿时是否打开此功能。“设置”>“预览”>“显示与浏览”中的“在链接预览中显示页码”会在弹出框中显示目标的页码；关闭此项则不显示。选择“选择PDF”工具时不会出现弹出框。

分割窗口

“窗口”>“分割窗口”（⌃2）或工具栏中的“分割窗口”项目会将预览窗口分成两部分，可以显示文稿中的不同位置；再次选取即可取消分割。按住 Option 键可将窗口左右分割（“窗口”>“垂直分割窗口”，⌃⌥2）。每部分都有自己的显示样式和放大率。最后点按的部分为当前部分，以强调色的细线标出：工具栏、辅助面板、SyncTeX 和“预览”菜单都作用于它，取消分割时也保留它。

按住 Control 键点按内部链接，或用鼠标右键点按它，然后选取“分割窗口并显示链接目标”，即可在另一部分中显示链接目标，同时链接仍保留在视图中；必要时会先分割窗口。

“窗口”>“切换视图”（⌥2）会交换分割窗口的两部分。在未分割的窗口中，它会在文稿的两个视图之间切换，每个视图都有自己的位置、显示样式和放大率，便于你在两个位置之间来回查看。

全屏幕

“窗口”>“进入全屏幕”（⌃⌘F）会在整个屏幕上显示预览。此时窗口会取消分割，并使用上次在全屏幕中使用的放大率和显示样式，退出全屏幕后会恢复原来的设置。要保留分割、放大率和显示样式，请在“设置”>“预览”>“显示与浏览”中打开“进入全屏幕时保持放大、页面格式和分割状态”。在全屏幕中，第一次按 Escape 键会关闭固定的弹出框，第二次按则退出全屏幕。

批注

“预览”>“显示批注工具栏”会在窗口的工具栏下方显示批注工具。点按批注工具栏左端的“编辑模式”，然后使用其中的按钮为所选文本添加删除线、高亮或下划线，或者添加形状、箭头、文本和注释。批注不属于源代码，下次排版时 PDF 文件会被替换，因此请用批注工具栏中的“保存批注…”存储批注；它会存储 PDF 文件的副本，例如 Fourier.tex 对应的副本名为 Fourier-Annotated.pdf。在“编辑模式”中操作过之后，TeXShop 会在再次排版或关闭窗口之前提示你存储批注。TeXShop 手册（英文）详细介绍了批注。

更多

在预览中按住 Command 键点按，即可转到源代码中的对应位置；请参阅“排版文稿”。“预览”菜单中的“顺时针旋转”和“逆时针旋转”用于旋转页面。latexmk 等其他应用改写 PDF 文件后，当你回到 TeXShop 或预览窗口时，预览会在原位置重新载入它；在“设置”>“预览”>“刷新”中打开“始终监视其他应用对PDF的更改”，即使 TeXShop 在后台也会立即重新载入。“预览”>“记住预览窗口位置”会让新的预览窗口以最前面窗口的位置和大小打开。
