Shell Escape 保护

在排版过程中，TeX 可以运行其他程序。默认情况下，TeX Live 只允许运行一小组受信任的程序，例如用于把 EPS 图形转换为 PDF 的程序。需要运行其他程序的宏包会要求使用选项 -shell-escape（也写作 --shell-escape）。

使用这个选项时，文稿可以运行任何命令，例如删除个人文件夹中所有文件的命令。请只对你信任的文稿使用它，不要对从别人那里收到的文件使用。

添加选项

  • 加在“设置”>“排版”>“直接生成 PDF”的 LaTeX 或 plain TeX 命令中：适用于以直接生成 PDF 方式排版的所有文稿。
  • 加在引擎文件中：适用于用该引擎排版的所有文稿；请参阅添加排版引擎。
  • 对于用某个 latexmk 引擎（例如 pdflatexmk）排版的单个文稿，在源文件开头加入 % !TEX parameter = -shell-escape 一行。

有一个引擎已经带有这个选项：TeXShop 自带、一开始就位于 Engines 文件夹中的 sepdflatexmk 总是使用 --shell-escape 排版。只要在源代码窗口的工具栏中选择它，或者使用 % !TEX program = sepdflatexmk 一行，就会这样排版，因此请只对你信任的文稿使用它。

shell-escape 时确认

“设置”>“排版”>“直接生成 PDF”>“shell-escape 时确认”默认关闭，用于保护“直接生成 PDF”组中的命令。此项打开时，如果那里的 plain TeX 或 LaTeX 命令中含有 -shell-escape 或 --shell-escape，TeXShop 会在文稿打开后第一次排版之前询问：

  • “好”：使用该选项排版。
  • “忽略 Shell Escape”：不使用该选项排版。
  • “取消”：不排版。

一旦你选择了“好”或“忽略 Shell Escape”，这一回答会对该文稿一直有效，直到文稿关闭，因此你可以用该选项排版自己的文稿，而不用它排版别人的文稿。引擎文件不会被检查，即使其中含有 -shell-escape 也是如此，因此 sepdflatexmk 会不经询问就使用该选项排版。
