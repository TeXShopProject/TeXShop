命令补全

键入命令或环境的前几个字母，然后按下 Escape 键：TeXShop 会根据其补全文件进行补全。再次按 Escape 键，会从文件底部向顶部依次给出以相同字母开头的其他补全；Shift-Escape 则按相反方向。其中之一就是你键入的文本。例如，\begin{th 之后按 Escape 键，会给出 \begin{theorem} 及其他环境。

补全不只是补完单词。\begin{theorem} 的补全还会写出 \end{theorem} 行，并在你要键入的地方放上标记（•）：第一个标记处于选中状态，因此你键入的内容会替换它。多次按 Escape 键常常会得到带有更多参数的同一命令，例如 \newc 补全为 \newcommand 时就是这样。补全不必以反斜杠开头：在行首或空格之后，sec 与 \sec 得到的结果相同。

补全文件中没有与文本对应的内容时，Escape 键会改为显示 macOS 的单词补全。

设置

在“设置”>“键盘”中，“触发按键”用于选择 Escape 或 Tab 作为补全键。“编辑”>“实验台…”的源代码面板使用与源代码窗口相同的键。

要将某个词添加到补全文件中，请选中它，然后选取“源代码”>“添加到命令补全列表”。要编辑该文件，请点按“设置”>“键盘”中的“编辑命令补全文件…”。研究已有的补全是学习编写新补全的最佳方法；~/Library/TeXShop/CommandCompletion 文件夹中也有一份关于补全的详细文档。

标记

标记（•）是一个以后要回来的位置；带注释的标记（•‹注释›）还会说明那里应填写什么。命令补全、宏和按键绑定中都可以含有标记，你也可以用“编辑”>“标记”>“插入标记”（⌘8）和“插入带注释的标记”（⌃⌘8）自行插入标记。“插入带注释的标记”会插入 •‹›，插入点位于尖括号之间；或者将所选文本变为注释。

“下一个标记”（⌃⌘F）和“上一个标记”（⌃⌘G）会连同注释一起选中下一个或上一个标记，这样键入的内容就会替换它。按住 Option 键则只删除 •，并改为选中注释（⌃⌥⌘F、⌃⌥⌘G）。

触发按键也可以在标记之间移动：以 Escape 键为触发按键时，Option-Escape 转到下一个标记，Control-Escape 转到上一个标记；以 Tab 键为触发按键时，则是 Option-Tab 和 Control-Tab。如果其他应用需要使用这些键，请在“设置”>“键盘”中关闭“用 Option 或 Control 加触发按键，移到下一个或上一个标记”。

补全引用标签和引用键

“编辑”>“补全引用标签或引用键”（F5）会从列表中补全引用标签或引用键。在 \ref{、\pageref{、\eqref{ 或 \autoref{ 之后，或者在其后键入的引用标签的前几个字母之后选取此项，列表就会显示文件中用 \label 定义的引用标签；用方向键选择一个，然后按下 Return 键。在 \cite{ 及类似命令之后，如果打开了“设置”>“键盘”中的“同时提供 BibDesk 中的引用键”，列表会显示 BibDesk 中的引用键。在其他位置，它会显示 macOS 的单词补全。在许多键盘上，需要按住 fn 键（地球仪键）再按 F5。

按键绑定、宏和命令补全

这三项功能都会将文本放入源代码，容易混淆。它们各自适合不同的用途：

按键绑定
按一个键即可插入文本：_ 会在所选内容两侧得到 _{}，≤（在美式键盘布局上为 Option-逗号）会得到 \leq。“设置”>“键盘”用于为新文稿打开按键绑定并保存其列表；“源代码”>“按键绑定”用于为最前面的文稿打开或关闭它们。先键入 \，可以让 _ 或 ^ 等键保持原样。用死键键入的字符（例如用 Option-E 再按 E 键入的 é）不能设置按键绑定。
宏
“宏”菜单中的项目插入文本或运行 AppleScript 程序，并可以设置使用 Command 或 Control 键或功能键的键盘快捷键。“宏”>“打开宏编辑器…”用于添加、编辑宏并调整其顺序。想要用 Command 键完成的文本操作，例如用 ⌘B 在所选内容两侧加上 \textbf，最好做成宏。
命令补全
键入命令的开头或缩写，然后按下触发按键：\sec 会得到 \section{•}，再按触发按键会得到下一个匹配项，\benu 则会得到带有标记的完整 enumerate 环境。与按键绑定和宏不同，命令补全会替换所选文本。
