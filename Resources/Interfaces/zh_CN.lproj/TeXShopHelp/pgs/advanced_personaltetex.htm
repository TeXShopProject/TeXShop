向 TeX Live 添加个人文件

不属于 TeX Live 的样式文件、文档类、参考文献数据库及其他文件，应放在你的个人 TeX 目录树中，即个人文件夹内“资源库”文件夹中的 texmf 文件夹：~/Library/texmf。TeX Live 的每个程序都能找到其中的文件，并且它们优先于 TeX Live 自身中的同名文件。添加文件后不需要注册任何东西；下次排版时就能找到它。

“资源库”文件夹在访达中是隐藏的。要打开它，请在访达中选取“前往”>“前往文件夹…”，然后键入 ~/Library。如果其中还没有 texmf 文件夹，请创建它。

添加宏包之前

CTAN 上的大多数宏包已经是 TeX Live 的一部分，MacTeX 会安装所有这些宏包。要查看 TeX 是否已有某个文件，请在 TeXShop 中选取“文件”>“打开样式文件…”并键入它的名称，例如 hyperref.sty；TeXShop 会打开 TeX 将会使用的那个文件。只有当 TeX Live 中没有某个宏包，或者你需要自己的版本时，才把它添加到个人目录树中。由于你的副本优先，当 TeX Live 已有更新的版本时，请移除你的副本，否则你会一直使用旧版本。

文件的放置位置

texmf 中的文件夹采用与 TeX Live 相同的结构。请创建你需要的文件夹：

文件夹内容
tex/latex/LaTeX 宏包和文档类（.sty、.cls），每个宏包放在单独的文件夹中
tex/plain/用于 plain TeX 的文件
tex/generic/适用于任何格式的文件
bibtex/bib/参考文献数据库（.bib）
bibtex/bst/参考文献样式（.bst）
doc/你添加的宏包的说明文档；“帮助”>“显示宏包的帮助…”会在这里找到它们

例如，你自己的宏组成的宏包和你的参考文献数据库可以存储为

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

这样，\usepackage{mymacros} 和 \bibliography{mybibliography} 在每个文稿中都能使用，无论文稿保存在哪里。

检查文件夹

要查看你的 TeX 把哪个文件夹用作个人目录树，请在终端中键入

kpsewhich -var-value TEXMFHOME

在 Mac 上，它是 ~/Library/texmf，除非安装时另有设置。要查看 TeX 会读取文件的哪个副本，可以键入例如 kpsewhich mymacros.sty。

请不要向 TeX Live 自身的文件夹中添加文件；请参阅进一步了解 TeX Live。
