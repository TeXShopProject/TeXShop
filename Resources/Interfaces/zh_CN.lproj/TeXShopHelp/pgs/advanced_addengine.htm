添加排版引擎

除了 plain TeX 和 LaTeX，TeXShop 还可以用引擎排版：引擎是文件夹 ~/Library/TeXShop/Engines 中扩展名为 .engine 的小型 shell 脚本。引擎可以运行单个程序，也可以运行一连串程序，例如先运行 LuaLaTeX，再运行 Biber，然后再运行两次 LuaLaTeX。TeXShop 自带 LuaLaTeX、XeLaTeX 和 pdflatexmk 等引擎；子文件夹 Inactive 中还有更多引擎。

选择引擎

源代码窗口工具栏中“排版”按钮旁边的弹出式菜单列出了各个引擎。选择一个引擎，然后点按“排版”或按 ⌘T。这一选择只适用于该文稿。

要用某个引擎排版新文稿，请在“设置”>“排版”>“引擎”>“新文稿的排版”中选择“引擎文件”，然后在其下方的“引擎文件”菜单中选择该引擎。“编辑引擎列表…”会在访达中打开 Engines 文件夹；当你在该文件夹中添加、移除文件或给文件重新命名时，“引擎文件”菜单会随之更新。如果所选的引擎文件已不在该文件夹中，菜单会将其显示为“未找到”，文稿则用 LaTeX 排版。

要将文稿与某个引擎绑定，请在文稿的前二十行之一中加入如下一行：

% !TEX program = XeLaTeX

名称是引擎文件去掉 .engine 后的名称；tex 和 latex 以经由 DVI 的方式排版 plain TeX 和 LaTeX，pdftex 和 pdflatex 则以直接生成 PDF 的方式排版。这一行优先于工具栏、“设置”和“使用替代引擎排版”。% !TEX TS-program = 这种形式也以同样方式读取。请严格按照所示格式书写这一行，等号两侧各有一个空格；“宏”菜单中的“Set Typesetting Program…”宏会为你插入这一行，并提供一个可供选择的引擎名称列表。在带有根文件的项目中，只有根文件需要这一行。

“排版”>“使用替代引擎排版”（⌃⌥⌘T）会用“设置”>“排版”>“引擎”>“替代引擎”中的引擎（默认为 pdflatexmk）排版一次，而不更改工具栏。在“排版”菜单中，按住 Control 键和 Option 键时，该项目会出现在“开始排版”的位置。它适合那些通常快速排版一遍、偶尔才用 latexmk 完整排版的文稿。

编写引擎

制作引擎最简单的方法是：在访达中复制 Engines 文件夹中的某个引擎，给副本重新命名，然后在 TeXShop 中打开它进行编辑。引擎文件必须具有扩展名 .engine 和执行权限，复制的副本会保留执行权限。此后打开的文稿会在工具栏中列出新的引擎。以下是 XeLaTeX.engine：

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

第一行指定脚本所用的 shell 或语言；zsh、bash、tcsh、Perl 等都可以，只要脚本是用该语言编写的。TeXShop 在源文件所在的文件夹中运行引擎，并向它传递三个值：

$1
源文件的名称（带扩展名，不带所在文件夹），例如 main.tex。会切换到其他文件夹的脚本必须先记下完整路径，例如写成 "$PWD/$1"。在项目中，这是根文件。
$2
源文件（根文件）开头附近 % !TEX parameter = … 一行的其余部分，多个选项以空格分隔，例如 % !TEX parameter = -shell-escape。没有这一行时，它是一个空格。
$3
“设置”>“排版”>“路径”的“TeX 引擎”栏中的文件夹；当文稿包含 % !TEX useAlternatePath 一行时，则是“第二组 TeX 引擎”中的文件夹。

引擎结束后，TeXShop 会在预览窗口中打开与源文件同名、扩展名为 .pdf 的 PDF 文件（如果存在），并滚动到排版前显示的位置。生成其他输出的脚本可以用以下几行指定要显示的内容，这些行可以写在引擎中的任何位置，放在该语言的注释中：

行效果
!TEX-noPreview不显示预览窗口，即使还有下面的其他行
!TEX-pdfPreview显示 PDF 文件
!TEX-htmlPreview在 HTML 窗口中显示同名的 HTML 文件
!TEX-bothPreview同时显示 PDF 文件和 HTML 文件
!TEX-noConsole不显示控制台

例如，一个运行 LuaLaTeX、Biber，再运行两次 LuaLaTeX 的引擎，用 zsh 可以写成下面这样，其中 ${1:r} 是不带扩展名的名称：

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

Inactive 文件夹

子文件夹 Engines/Inactive 中包含用于特殊工作流程的引擎，通常附有说明文档和示例，例如用于 latexmk、ConTeXt、Sage、PreTeXt 和 Typst 的引擎。要使用其中某个引擎，请将它从所在文件夹移到 Engines 文件夹本身中。更新 TeXShop 时，Inactive 文件夹中 TeXShop 自带的每个文件都会被替换为新版本，因此你对这些文件所做的更改会丢失；你添加的文件以及 TeXShop 不再自带的文件则保持不变。直接位于 Engines 文件夹中的文件永远不会被改动，因此你移到那里并编辑过的引擎会保留下来。

有关引擎的更多信息，请参阅“帮助”>“TeXShop 手册（英文）”中的“Engines and latexmk”一章。
