BibTeX

BibTeX 根据参考文献数据库（扩展名为 .bib 的文件）为 LaTeX 文稿生成参考文献列表。文稿用条目的键引用条目，BibTeX 只列出被引用的条目。

数据库 mybibliography.bib 中包含如下条目：

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

文稿引用这些条目，并指定样式和数据库：

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

运行 BibTeX

  1. 排版文稿。引用显示为 [?]，参考文献列表不存在。
  2. 选取“排版”>“BibTeX”（⇧⌘B），或者在“排版”按钮旁边的弹出式菜单中选择 BibTeX，然后点按“排版”。
  3. 再排版两次：第一次加入参考文献列表，第二次填入引用编号。

用 latexmk 排版时（例如使用 pdflatexmk 引擎，或使用以“使用latexmk”设置的引擎配置），latexmk 会自行运行 BibTeX 和额外的排版遍次。

要在 TeXShop 中新建数据库，请在保存对话框的“文件格式”菜单中选择 bib 类型，使文件获得扩展名 .bib。数据库也可以放在你的个人 TeX 目录树中，这样每个文稿都能找到它；请参阅向 TeX Live 添加个人文件。

选择程序

“排版”>“BibTeX”运行“设置”>“排版”>“相关工具”>“BibTeX引擎”中的命令，默认为 bibtex。可以在那里输入其他程序及其所需的选项，例如对使用 biblatex 宏包的文稿输入 biber。引擎配置会设置这一栏：pLaTeX + dvipdfmx 设为 pbibtex，upLaTeX + dvipdfmx 和 LuaLaTeX（日语）设为 upbibtex，其他配置设为 bibtex。

要为单个文稿选择程序，请在文稿的前二十行之一中加入如下一行：

% !BIB program = biber

这一行优先于该设置。% !BIB TS-program = 这种形式也以同样方式读取。
