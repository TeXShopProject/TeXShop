ConTeXt 和 MetaPost

ConTeXt

ConTeXt 是 Hans Hagen 开发的宏包，是 LaTeX 之外的另一种选择，有自己的命令，并特别注重版式设计。TeX Live 包含 ConTeXt，ConTeXt Garden 也发布一个经常更新、安装在个人文件夹中的版本。

用于 ConTeXt 的引擎位于 ~/Library/TeXShop/Engines/Inactive/ConTeXt 中，同一位置还有指南 Setting-Up-ConTeXt.pdf 和示例文稿：

引擎排版所用的版本
ConTeXt.engineTeX Live 中运行于 LuaTeX 的 ConTeXt
ConTeXt-TL.engineTeX Live 中运行于 luametatex 的 ConTeXt
ConTeXt-CG.engine个人文件夹中的 ConTeXt Garden 版本

将需要的引擎移到 ~/Library/TeXShop/Engines，并在文稿根文件的开头加入魔法注释，例如：

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

对于 ConTeXt-CG，请在“设置”>“排版”>“路径”的“第二组 TeX 引擎”栏中输入 ConTeXt Garden 安装中程序所在的文件夹，并加入 % !TEX useAlternatePath 一行，这样 TeXShop 会把该文件夹而不是 TeX Live 的文件夹交给引擎。

要在源文件和预览之间同步，请在文稿的设置部分加入 \setupsynctex[state=start,method=min]；% !TEX useConTeXtSyncParser 一行会让 TeXShop 使用 ConTeXt 自己的同步代码。“帮助”>“TeXShop 手册（英文）”的 ConTeXt 一章详细介绍了 ConTeXt Garden 版本的安装和每个引擎。

要在“标签”菜单中列出 \title 和 \subject 等 ConTeXt 章节命令，请打开隐藏设置 ConTeXtTags；请参阅隐藏设置。

MetaPost

MetaPost 由 John Hobby 开发，它根据一种由 Knuth 的 METAFONT 派生而来的编程语言所写的描述来绘制插图。它的手册是 TeX Live 的一部分：选取“帮助”>“显示宏包的帮助…”，然后键入 metapost。

“排版”>“MetaPost”（⇧⌘M），或“排版”按钮旁边弹出式菜单中的 MetaPost，会对与当前文稿同名、扩展名为 .mp 的文件运行 MetaPost：如果文稿本身是 .mp 文件，就对文稿本身运行；否则对它旁边的 .mp 文件运行，例如 mfpic 宏包为 .tex 文稿写出的文件。它运行“设置”>“排版”>“相关工具”>“MetaPost”中的命令，默认为 mpost。引擎配置会设置这一栏：pLaTeX + dvipdfmx 设为 pmpost，upLaTeX + dvipdfmx 设为 upmpost，它们可以排版标签中的日文文本；其他配置设为 mpost。LuaLaTeX 无法插入由 pmpost 或 upmpost 排版了日文标签的图形；使用 LuaLaTeX 时，请用 luamplib 宏包在文稿中绘制这样的图形。

要将新文件保存为 MetaPost 文件，请在保存对话框的“文件格式”菜单中选择 mp 类型。

Nicola Vitacolonna 开发的引擎 nv-metapost 让使用 MetaPost 更加方便，并能在预览窗口中显示文件中的图形。它位于 ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines 中；上一层 MetaPostEngines-1.4.7 中的文件 README.rtf 和文件夹 examples 说明了如何安装和使用它，并提供了示例文件。例如，以下列内容开头的文件

% !TEX program = nv-metapost
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

在该引擎放入 Engines 文件夹后，就会用 nv-metapost 排版。

MetaPost 图形也可以写在 LaTeX 文稿中：在 LuaLaTeX 中使用 luamplib 宏包，或者使用 mfpic 等宏包，它们把图形写入一个 .mp 文件，由 MetaPost 在两次排版之间处理。
