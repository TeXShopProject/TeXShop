制作和使用 TeX 格式

格式文件（扩展名为 .fmt）是 TeX 读取一组宏之后的快照。LaTeX 本身就是一种格式：TeX 能瞬间载入它，而不必每次都读取 LaTeX 的源文件。你可以用较长的导言区制作自己的格式，使排版更快开始，也可以使用某个项目或机构提供的格式。

格式只能用于制作它的引擎和 TeX Live 版本。用 TeX Live 2026 的 pdfLaTeX 制作的格式，不能用于 XeLaTeX，也不能用于其他年份的 TeX Live；安装新的 TeX Live 后，请重新制作格式。

制作格式

把格式应包含的各行放进一个文件，并以 \dump 结尾。例如 uo.tex：

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

在终端中切换到该文件所在的文件夹，然后键入

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

这会载入 LaTeX 格式，读取 uo.tex，并写出 uo.fmt。用这个格式排版的文稿要省略格式中已有的各行，直接以 \begin{document} 开头。

在 TeXShop 中使用格式

  1. 把 uo.fmt 移到文件夹 ~/Library/texmf/web2c 中（如有必要，请创建这些文件夹），这样 TeX 在任何文件夹中都能找到它。
  2. 在访达中打开 ~/Library/TeXShop/Engines（“TeXShop”>“打开 ~/Library/TeXShop”），复制一个引擎（例如 XeLaTeX.engine），并给副本重新命名，例如 Oregon.engine。这个名称会显示在 TeXShop 中，不必与格式的名称一致。
  3. 在 TeXShop 中打开该副本，修改最后一行，使引擎内容如下： 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

此后打开的文稿会在“排版”按钮旁边的弹出式菜单中列出 Oregon。无论那里选择的是什么，要让某个文稿使用该格式，请在源文件开头加入这一行：

% !TEX program = Oregon

要将它设为默认，请在“设置”>“排版”>“引擎”>“新文稿的排版”中选择“引擎文件”，并在“引擎文件”菜单中选择 Oregon。请参阅添加排版引擎。

对于 plain TeX 格式，请在引擎中使用 pdftex 而不是 pdflatex。对于以经由 DVI 方式使用的格式，引擎还必须把 DVI 文件转换为 PDF，例如在 zsh 脚本中使用 dvipdfmx "${1:r}.dvi"，因为 TeXShop 显示的是与源文件同名的 PDF 文件。
