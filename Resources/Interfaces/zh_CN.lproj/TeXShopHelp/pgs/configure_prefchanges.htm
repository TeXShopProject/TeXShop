建议更改的设置

TeXShop 使用默认设置即可工作，但其中几项设置取决于你的 TeX 安装、屏幕和使用习惯，值得首先检查。选取“TeXShop”>“设置…”可打开“设置”窗口；“搜索设置”说明了如何找到某项设置。

选择引擎配置

“设置”>“排版”>“引擎配置”可一步完成排版设置。请选择你所用引擎的配置；不太常用的配置在“其他”中。随后出现的对话框会列出该配置要设置的值，并标出将会更改的值。关闭你想保留的值，然后点按“好”；点按“取消”则不做任何更改。

选择“使用 latexmk”时，latexmk 会根据需要运行 BibTeX、索引程序和后续的排版遍次；否则每次排版只运行一次引擎。引擎配置会设置排版方式及其排版命令、kpsewhich 命令、BibTeX 引擎、索引程序、MetaPost 以及“自动转换为 otf 宏包的\UTF / \CID”。日语配置还会将新文稿的编码设为 UTF-8，并设置拼写检查词典和 UTF-8-MAC 的转换。其他所有设置都保持不变。以后更改其中某项设置时，菜单会显示“自定”；再次选择该配置即可恢复它的值。

TeX 和 Ghostscript 的路径另行设置，使用同一类别中“路径”组的“自动检测路径…”。TeXShop 首次启动时，会先询问路径，然后询问引擎配置。

排版命令

引擎配置所设置的命令位于“设置”>“排版”的“直接生成 PDF”组和“经由 DVI”组中，每组各有一个 plain TeX 命令和一个 LaTeX 命令，“排版方式”决定使用哪一组。“排版”>“直接生成 PDF”和“排版”>“经由 DVI”只为当前文稿切换排版方式。默认命令已经包含 -file-line-error 和 -synctex=1：前者让 TeXShop 能带你跳到出错的行，后者让源文件和预览之间的同步能够工作，因此大多数人从不需要编辑这些命令。如果文稿需要 -shell-escape，请先阅读 Shell Escape 保护。

选择查找界面

“设置”>“编辑器”>“查找界面”用于选择“查找”所打开的窗口或栏。“高级查找面板（推荐）”可以用正则表达式查找、列出所有匹配项，并一次替换多组字符串；请参阅查找和替换。“Apple 查找面板”和“Apple 查找栏”是 macOS 的标准查找功能，“OgreKit 查找面板（旧版）”也仍然可用。新的选择会立即生效，但切换到 OgreKit 查找面板或从它切换出去时，需要重新启动 TeXShop 才会生效。如果希望面板始终位于文稿窗口前面，请打开“高级查找面板始终显示在最前面”。

保持自动保存打开

“设置”>“文稿与保存”中的“启用自动保存和版本”默认是打开的，建议保持打开。这样，macOS 会在你工作时保存文稿，并且可以用“文件”>“复原到”>“浏览所有版本…”找回较早的版本。如果关闭此项，文件只在你保存时才会更改；此时“保存时将之前的文件保留为‘名称~’”会把之前的版本保留在旁边。更改此设置后，需要重新启动 TeXShop 才会生效。

固定窗口位置

默认情况下，每个窗口都会在上次关闭时的位置打开。如果你通常一次只处理一个文稿，最好让窗口在固定位置打开。先排版一个简短的文稿，然后排列它的源代码窗口和预览窗口；如果屏幕足够宽，可以左右并排。然后，在“设置”>“通用”>“窗口位置”中，为“源代码”和“预览”选择“所有窗口从固定位置打开”，并点按每一行的“设成当前位置”。“控制台”行和“HTML”行的用法相同。

菜单命令“源代码”>“记住源代码窗口位置”和“预览”>“记住预览窗口位置”可以在窗口中直接完成同样的设置。如果你使用便携式 Mac 并连接大显示器，请针对内建屏幕排列窗口，然后同时选取“源代码”>“记住源代码窗口位置（便携式 Mac 用）”和“预览”>“记住预览窗口位置（便携式 Mac 用）”；这样，在没有连接大显示器时，TeXShop 会使用这些位置。

字体和颜色

源代码窗口的字体在“设置”>“编辑器”>“文稿字体”中设置，控制台的字体在“设置”>“控制台”中设置。“设置”>“主题”用于选择和编辑源代码窗口、预览窗口和控制台窗口的配色主题；请参阅语法高亮。
