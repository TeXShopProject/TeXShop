用 Shell 命令编写脚本

本页以 Claus Gerhardt 编写的宏 pdflatexc（位于“宏”>“Claus Gerhardt Macros”中）为例，说明 AppleScript 如何调用 shell 脚本。这个 shell 脚本本身很简单：它把 TeX 程序所在的文件夹添加到搜索路径中，然后用 --shell-escape 运行 pdflatex。你自己的脚本可能会做更多的事情，例如依次运行多个程序；这时这些技巧就会派上用场。

shell 脚本

这个 shell 脚本是 ~/Library/TeXShop/bin/pdflatexc。它不依赖于 TeXShop：如果它所在的文件夹在你的搜索路径中，在终端中键入 pdflatexc myfile.tex 就能运行它。脚本如下：

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

AppleScript

调用这个 shell 脚本的宏更值得一看：

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

注释之后的前七行是 Claus Gerhardt 的一个方法，用于保存源文件并找出其文稿的名称，该名称存入 frontName。实际工作由 ~/Library/TeXShop/Scripts 中的已编译脚本 setname.scpt 完成：这几行找出路径 ~/Library/TeXShop/Scripts/setname.scpt，载入该脚本，并以 #NAMEPATH# 和 #TEXPATH# 调用它。

通常，同样的事情可以更简单地这样完成：

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

这个方法有两个优点。即使最前面的文稿并不是后续命令应作用的那个文稿（例如 /Users/name/Examples/myfile.log 这样的日志文件），它也能正常工作。而且，如果文件从未保存过，这个方法会返回错误，而 save 命令则会让脚本停在保存对话框后面一直等待。

接下来的六行设置变量 dirName 和 baseName。如果源文件是 /Users/name/My Papers/Stuff/myfile.tex，那么 dirName 是 '/Users/name/My Papers/Stuff'，由于文件夹名称中有空格，它为 shell 加上了引号；baseName 是 myfile.tex。文件名传给 shell 脚本时也以同样的方式加上引号，因此两者都可以包含空格。

接下来的三行调用 shell 脚本。其结果与在终端中键入 cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' 相同。最后三行更新预览窗口。

这些行中有几行比较复杂，但可以原样拷贝到新脚本中。

从 AppleScript 运行 shell 命令

AppleScript 以如下形式运行 shell 命令：

do shell script "cmd input"

要用几部分拼成一条命令，请写成如下等价形式：

do shell script "cmd " & "input"

注意 cmd 后面的空格。“&”符号用于连接两个字符串：

"cmd " & "input" = "cmd input"

由 AppleScript 启动的 shell 从根文件夹开始。命令

do shell script "cd " & dirName

会切换到 dirName 中的文件夹，该名称已经加上了引号，因此不需要再加引号。

每个 do shell script 都会启动一个新的 shell，因此后面的命令不会位于那个文件夹中。要在同一文件夹中运行更多命令，请像在终端中一样，用分号把它们连成一条命令：

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

上面的脚本就是这样做的，其中 cmd1 = cd，input1 = dirName，cmd2 = ~/Library/TeXShop/bin/pdflatexc，input2 = baseName。以下两行

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

只是把这一系列命令放进一个变量的简便方法。
