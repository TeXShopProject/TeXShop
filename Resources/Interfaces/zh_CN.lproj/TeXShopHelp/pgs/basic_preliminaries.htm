简介

TeXShop 是一款用 TeX 和 LaTeX 撰写文稿的 macOS 应用。你在编辑器窗口中编写源代码，点按一下或按下 ⌘T 即可排版，并在旁边的预览窗口中阅读结果。在任一窗口中按住 Command 键点按，都会显示另一窗口中的对应位置。

TeXShop 本身不含 TeX。它运行 TeX 发行版中的程序，通常是由 MacTeX 安装器安装到 Mac 上的 TeX Live；请参阅“安装 TeX Live”。TeXShop 需要 macOS 14.6 或更高版本。

除非首次启动时选择了其他引擎配置，否则 TeXShop 使用 pdfLaTeX 排版 LaTeX 文稿。pdfLaTeX 直接写出 PDF 文件，预览窗口显示的就是这个文件。它是普通的 PDF 文件，可以发送给他人，并在任何电脑上阅读。要使用 LuaLaTeX 等其他引擎排版，请在“设置”中选择引擎配置，或在文稿开头指定引擎；请参阅“排版文稿”。

本帮助的内容

基本帮助
安装 TeX Live 和 TeXShop、排版、预览窗口、编辑、查找和替换、拼写检查、按键绑定和命令补全、各种面板、宏、打印以及“设置”。
高级帮助
排版引擎、使用根文件的项目、BibTeX 和 MakeIndex、编码、外部编辑器、语法高亮及其他主题。
宏帮助
“宏”菜单、宏编辑器以及用 AppleScript 编写的宏。
如何配置 TeXShop？
推荐的设置、~/Library/TeXShop 中的新项目、隐藏设置、按键绑定和键盘快捷键。

“帮助”菜单还可以打开其他文档。“TeXShop 手册（英文）”详细介绍了每项功能。“TeXShop 入门（英文）”是面向新用户的简短介绍。“关于本发行版（英文）”说明更新后需要做些什么（如果需要的话），“更新内容（英文）”列出了每个版本的更改。“魔法注释行和隐藏设置（英文）”列出了 % !TEX program = 等魔法注释行，以及“设置”窗口中没有显示的设置。

TeXShop 网站是 texshop.app。
