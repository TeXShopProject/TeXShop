宏

“宏”菜单和工具栏中的“宏”项目包含一些命令，用于将 LaTeX 代码插入源代码或运行 AppleScript 脚本。TeXShop 附带的部分宏如下：

  • Program、Encoding 和 Root 写出 % !TEX 行，用于选择文稿的排版引擎、编码和根文件。从 Program 或 Encoding 显示的列表中选择引擎或编码，或在 Root 打开的对话框中选择根文件；这一行会被正确地写到源代码的开头。
  • Insert Begin/End 将插入点处的单词或所选单词（例如 theorem）变为一对 \begin{theorem} … \end{theorem}，插入点位于两者之间。
  • Headings、Mathematics、Lists、Tables 和 Figures 等子菜单用于插入常用的 LaTeX 代码。

宏编辑器

选取“宏”>“打开宏编辑器...”，即可查看每个宏的定义、更改宏，或添加你自己的宏。左侧的列表就是“宏”菜单：拖移项目即可重新排列，使用列表下方的按钮栏可添加项目、子菜单和分隔线。宏的文本会被插入源代码。在此文本中，圆角标记代表所选文本、剪贴板上的文本和插入点的位置；可以从文本下方的“插入”菜单中选择它们。

要为宏指定键盘快捷键，请在列表中选择它，点按（或连按）它的快捷键，然后按下按键。快捷键使用 Command 或 Control 键，或者是一个功能键。如果某个菜单命令或其他宏已使用该快捷键，宏编辑器会提示你。

宏保存在 ~/Library/TeXShop/Macros/Macros_Latex.plist 中。要将宏分享给他人，请在宏编辑器中选择它们，然后选取“宏”>“保存选区到文件...”；要从这样的文件中添加宏，请选取“宏”>“从文件添加宏...”。

“宏帮助”一章详细介绍了宏，包括 AppleScript 宏。
