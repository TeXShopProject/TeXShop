定义 AppleScript 宏

AppleScript 是一种独立的语言。Apple 开发者网站上的《AppleScript Language Guide》对它有完整的介绍。

路径和文稿名称

在运行 AppleScript 宏之前，TeXShop 会把以下字符串替换为当前文稿某个文件的路径，并加上双引号：

#FILEPATH#
源文件
#TEXPATH#
.tex 文件
#NAMEPATH#
不带扩展名的源文件
#FOLDERPATH#
包含源文件的文件夹，以斜杠结尾
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
.pdf、.dvi、.ps、.log 和 .aux 文件
#INDPATH#, #BBLPATH#, #HTMLPATH#
.ind、.bbl 和 .html 文件

例如，如果 #FILEPATH# 给出 /Users/name/Projects/Fourier/Fourier.tex，那么 #FOLDERPATH# 给出 /Users/name/Projects/Fourier/。如果文稿从未保存过，#FILEPATH# 是空字符串。

#DOCUMENTNAME# 会被替换为源代码窗口标题中显示的文稿名称：带扩展名；如果扩展名被隐藏，则不带扩展名。脚本用它来指向调用它的文稿：

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

TeXShop 命令

AppleScript 可以用两种方式完成工作：运行 shell 命令（如用 Shell 命令编写脚本中所述），或者调用 TeXShop 自己的命令（如用 TeXShop 排版命令编写脚本中所述）。TeXShop 能理解的命令包括以下这些：

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

前六个命令连续排版，遇到错误时不停止。接下来的六个命令也会排版，但遇到错误时会停止，以便你在控制台中作答。排版命令会立即返回，不等排版完成。taskdone 在排版仍在进行时返回 NO，完成后返回 YES。refreshpdf 和 refreshtext 让 PDF 窗口和文本窗口显示其文件的最新版本。goto line 会在源文件中选择一行：

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
