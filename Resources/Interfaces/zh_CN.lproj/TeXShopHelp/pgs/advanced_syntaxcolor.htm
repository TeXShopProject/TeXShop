语法高亮

源代码窗口以彩色显示 TeX：注释、命令、脚注、标记 $ 和 &，以及括号 ( )、{ } 和 [ ] 都有各自的颜色。“源代码”>“语法高亮”可为当前文稿打开或关闭高亮。文稿打开时高亮是打开的；要让文稿打开时关闭高亮，请使用隐藏设置

defaults write TeXShop SyntaxColoringEnabled NO

高亮的内容

  • 命令是反斜杠后跟字母。“设置”>“编辑器”>“语法高亮”>“将 @ 视为命令名的一部分”会把 @ 也算作字母，就像宏包的内部命令那样。
  • \footnote、\footcite 和 \autocite，以及以 \cite 或 \Cite 开头的命令（例如 \citep 和 \citeauthor）中的文本，以“脚注”颜色显示。隐藏设置 defaults write TeXShop SyntaxColorFootnote NO 只为命令本身着色。
  • “源代码”>“高亮索引条目”以“索引”颜色显示 \index 和 \esindex 的参数。“设置”>“编辑器”>“语法高亮”>“默认高亮索引条目”会在文稿打开时打开它。
  • “源代码”>“高亮expl3代码”还会为 expl3 代码（LaTeX 的编程层）中的函数、变量和其他部分着色，供编写宏包的人使用。同一组中的“默认高亮expl3代码”会在文稿打开时打开它。
  • 同一组中的“高亮全角字母数字符号”以“全角字母数字符号”颜色显示全角字母、数字和符号，它们在日文文本中很容易被误认为 ASCII 字符。

“高亮索引条目”和“高亮expl3代码”适用于当前文稿；每个源代码窗口都有自己的选择。不是 TeX 源文件的文件（例如日志文件）不会高亮；扩展名列表以及如何添加扩展名，请参阅用 TeXShop 打开其他文件。

更改颜色

颜色属于主题。请在“设置”>“主题”中选择颜色：

  • “语法高亮”组中有“注释”“命令”“脚注”“标记”和“索引”；
  • “括号”组中有 ( )、{ } 和 [ ] 的颜色；
  • “expl3”组中有 function、__function、key、variable、__variable、argument 和 msg；
  • “高亮”组中有“全角字母数字符号”颜色等；
  • “XML语法”组中有用于 HTML 和 XML 文件的颜色。

每个主题都有自己的颜色，因此“浅色主题”和“深色主题”可以不同。
