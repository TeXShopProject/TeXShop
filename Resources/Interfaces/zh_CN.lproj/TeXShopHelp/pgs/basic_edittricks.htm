编辑技巧

选择

连按 ( 或 } 等括号，即可选中它与配对括号之间的全部内容；这有助于找出缺失的花括号。按住 Option 键连按则只选中该括号本身。点按或拖过行号可选中整行。“设置”>“编辑器”的“括号匹配”组用于设置键入时如何显示配对的括号。

注释和缩进

“源代码”>“注释”（⌘{）会在所选各行的开头加上 %，“源代码”>“取消注释”（⌘}）则将其移除。“源代码”>“缩进”和“源代码”>“取消缩进”将所选各行向右或向左移动：在“设置”>“编辑器”>“样式”中打开“用制表符缩进菜单”时移动一个制表符，否则移动“制表符宽度”所设数量的空格。新的一行以与上一行相同的制表符和空格开头；按 Delete 键可将其删除。

在源代码中移动

工具栏中的“标签”菜单列出了文稿的章、节和其他结构单元；选取其中一项即可转到那里。以 %: 开头的行会将该行的其余部分作为你自己的标签加入此菜单。“设置”>“编辑器”>“显示”中的“在菜单栏显示标签菜单”会将同样的菜单放到菜单栏中。工具栏中的“标签”（Labels）项目列出文稿中的标签。“编辑”>“行号...”（⌘L）可按行号转到某一行。

“窗口”>“分割窗口”（⌃2）或工具栏中的“分割窗口”项目会将源代码窗口分成两部分，显示相同的文本，这样你可以一边阅读文稿的某一部分，一边编写另一部分。按住 Option 键可将其左右分割。在一部分中键入的内容也会出现在另一部分中。

少打字

“源代码”>“关闭当前环境”（⌃⌘C）会为仍未关闭的环境添加 \end 行，例如在列表之后添加 \end{itemize}。命令补全可补全你已开始键入的命令和环境；请参阅“命令补全”。按键绑定会将键入的字符替换为文本；请参阅“按键绑定”。LaTeX 面板、矩阵面板和“宏”菜单可插入较长的文本。

将文件拖放到源代码上

将文件从访达拖到源代码上，即可插入引用该文件的命令：

文件插入的命令
.pdf、.png、.jpg、.jpeg、.tif、.tiff、.eps、.ps\includegraphics[]{路径}
.bib\bibliography{名称}
.bst\bibliographystyle{名称}
.sty\usepackage{名称}
.cls\documentclass{名称}
其他文件，例如 .tex\input{路径}

其中路径是从源文件所在文件夹到该文件的路径，名称是不含扩展名的文件名。拖放的替身会被替换为它所指向的文件，因为 TeX 自己无法找到该文件。路径中含有空格的文件不会被插入；TeXShop 会改为显示警告。

要为某类文件插入其他内容，请打开宏编辑器（“宏”>“打开宏编辑器...”），并添加一个名为 Drag & Drop 的子菜单。在其中添加以扩展名命名的项目，例如 .pdf，其内容就是要插入的文本，例如 \includegraphics[#INS#]{%r}；名为 .* 的项目用于其他所有扩展名，即没有专属项目、也不在上表中的扩展名。内容中可以使用以下缩写：

%F
拖放文件的完整路径
%f
文件名
%r
从源文件所在文件夹到该文件的路径
%n
不含扩展名的文件名
%e
扩展名

状态栏和文本统计

源代码下方的状态栏显示文稿的行数、字符数和单词数，括号中是所选内容中的数量，此外还显示插入点的位置、行和列。字符按看到的样子计数，因此带重音的字母或表情符号都算作一个字符；TeX 命令按书写的样子计数；表情符号也算作一个单词。右侧显示存储文件的大小。“源代码”>“显示状态栏”用于在所有窗口中显示或隐藏状态栏。

状态栏中的“正文统计…”或“编辑”>“字数统计...”会统计去除 TeX 命令后的文本。TeX Live 的程序 detex 会从文稿或所选内容中去除这些命令，并加入用 \input 和 \include 读入的文件；TeXShop 再以与状态栏相同的方式统计剩下的内容。文稿无需事先存储。统计在弹出窗口打开时以及点按其刷新按钮时进行。

剪贴板

“编辑”>“与剪贴板交换”会用剪贴板上的文本替换所选内容，并将所选内容放到剪贴板上。要交换两段文本，请拷贝第一段，选中第二段并选取“与剪贴板交换”，然后选中第一段原来的位置并粘贴。未选中任何内容时，它的作用就是粘贴。

“编辑”>“带样式拷贝”会以源代码的字体和浅色或深色主题的颜色拷贝所选内容（可带或不带背景色），以便粘贴到文字处理应用、演示文稿或电子邮件中。它的四个项目都可以在“设置”>“键盘”中指定快捷键。

转换字符

“编辑”菜单中的子菜单“字符类型转换”和“Unicode规范化”（源代码的快捷菜单中也有）会改写所选内容；如果未选中任何内容，TeXShop 会询问是否改写整份文稿。“字符类型转换”主要用于日语文稿。它可以在平假名和片假名之间、全角和半角数字及字母之间、带圈数字等字符与 ajmacros 宏包的命令之间，以及 JIS X 0208 以外的字符与 otf 宏包的 \UTF 和 \CID 命令之间进行转换。它还可以将弯引号改为 TeX 引号。“Unicode规范化”会将所选内容转换为 NFC、NFD、NFKC 或 NFKD，或者转换为保留 CJK 兼容汉字不变的 Modified NFC 或 Modified NFD。两者都可以撤销。

备份文件

在“设置”>“文稿与保存”中关闭“启用自动保存和版本”时，打开该处的“保存时将之前的文件保留为‘名称~’”，即可在每次存储文件时保留其上一个版本。备份文件在文件名之后、扩展名之前加一个波浪号：paper.tex 的备份为 paper~.tex。

使用正则表达式和批量替换进行查找和替换的方法，请参阅“查找和替换”。
