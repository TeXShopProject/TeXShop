设置项目根文件

大型文稿通常拆分为多个文件：一个包含导言区的根文件，由它为每一章包含一个文件。例如，根文件 Main.tex 可以是

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

编辑 two.tex 时，TeXShop 应该排版 Main.tex，而不是没有导言区的章节文件。要让 TeXShop 知道这一点，请在每个章节文件的前二十行之一中加入这一行：

% !TEX root = ../Main.tex

根文件本身不需要这样的行。根文件的名称可以这样给出：

  • 当根文件与章节文件位于同一文件夹中时，只写名称 Main.tex；
  • 相对于章节文件所在文件夹的路径，../Main.tex 或 ../../Main.tex；
  • 完整路径 /Users/me/Book/Main.tex，项目移动后必须更改。

“宏”菜单中的“Root”宏会插入这一行：它会要求你选择根文件，并提供相对路径或绝对路径的写法，替换先前的 root 行。

root 行的作用

  • 在章节文件中排版会排版根文件，根文件的预览窗口显示整个文稿。% !TEX program 行或其他用于排版的魔法注释应放在根文件中。
  • “转到错误”会打开包含错误的文件（如果它尚未打开），并跳到相应的行。
  • 从预览窗口同步时，会打开包含所点按位置的章节文件；请参阅同步源文件和预览。
  • “删除 Aux 文件”会移除根文件的辅助文件；请参阅删除辅助文件。
  • 在章节文件中使用“窗口”>“源代码 ⇔ 预览”（⌘1）会把根文件的预览窗口移到最前面。在预览窗口中再次按下它，会返回你来时的源代码窗口；如果你不是从源代码窗口过来的，则返回根文件。

打开章节文件

打开带有 root 行的章节文件时，TeXShop 也会打开根文件及其预览窗口。“设置”>“通用”>“项目根文件”中有两个项目控制这一行为：“打开文稿时打开根文件”用于打开或关闭这一功能；“最小化打开的根文件窗口”会把根文件的源代码窗口最小化到程序坞中，因为在处理某一章时很少编辑根文件。

在整个项目中查找和替换

要一次搜索项目中的所有文件，请在某个章节文件中选取“编辑”>“查找”>“在 TEX root 相同的 TeX 源文件中查找…”，或者在根文件中选取“在以此文件为 TEX root 的 TeX 源文件中查找…”。它会搜索根文件，以及根文件所在文件夹及其下层中在前 20 行用 root 行指定该根文件的 .tex 文件。请参阅在 TeX 源文件中查找和查找和替换。

在 .texshop 文件中指定根文件

章节文件旁边扩展名为 .texshop 的文件（例如 two.tex 对应的 two.texshop）也可以指定根文件，TeXShop 仍然会读取它。没有任何菜单命令会创建这样的文件；请使用 % !TEX root 行，它会随源文件一起移动。
