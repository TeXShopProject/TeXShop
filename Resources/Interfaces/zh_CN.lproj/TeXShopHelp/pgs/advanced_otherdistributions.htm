与其他 TeX 发行版共存

一台 Mac 上可以有多个 TeX 安装：由 MacTeX 或 BasicTeX 安装的各个年份的 TeX Live、用 TeX Live 自己的安装程序安装的 TeX Live，或者来自 Homebrew 或 MacPorts 的 TeX。TeXShop 使用“设置”>“排版”>“路径”的“TeX 引擎”栏中的那一个，并使用其下方“Ghostscript”栏中的 Ghostscript。

自动检测路径

TeXShop 可以为你填写这两栏。首次使用 TeXShop 时，以及每当你点按“设置”>“排版”的“路径”组中的“自动检测路径…”时，它都会在常见的位置查找 TeX 和 Ghostscript：/etc/paths 和 /etc/paths.d 中以及 TeXShop 的 PATH 中列出的文件夹、/Library/TeX/texbin、/usr/local/texlive、/opt/texlive 和 /Applications/TeXLive 中的 TeX Live 文件夹、UpTeX.app 和 pTeX.app 的 TeX 文件夹、/usr/local/teTeX/bin，以及 Homebrew、MacPorts 和 Fink 的文件夹。它会检查这些程序能否运行，并按从新到旧的顺序列出找到的安装及其版本。最新的一个会被选中，但你可以分别为 TeX 和 Ghostscript 选择其他的安装。只有点按“好”时路径才会更改。位于其他位置的安装仍然可以手动输入到这两栏中。

“自动检测路径…”只更改“TeX 引擎”和“Ghostscript”。自行指定文件夹的引擎文件以及“第二组 TeX 引擎”栏保持不变。

不使用 MacTeX 的 TeX Live

MacTeX 和 BasicTeX 安装器会让 /Library/TeX/texbin 指向它们所安装的 TeX Live，因此使用这一路径的程序会跟随最新的安装。用 TeX Live 自己的安装程序安装的 TeX Live 不会更改这个链接。要使用这样的安装，请用“自动检测路径…”选择它，或者在“TeX 引擎”中输入其程序所在的文件夹，例如 /usr/local/texlive/2026/bin/universal-darwin。

环境变量

有些发行版会在 shell 的启动文件中设置 TEXINPUTS 或 TEXMFHOME 等环境变量。这样，TeX 会从你意料之外的文件夹中读取文件，同一个文稿在终端中和在 TeXShop 中的排版结果也可能不同。如果 TeX 使用了错误版本的文件，请先检查这些变量；在终端中，kpsewhich 后接文件名可以显示 TeX 找到的是哪个副本。
