更改设置

选取“TeXShop”>“设置…”（⌘,）即可更改 TeXShop 的工作方式。“设置”的边栏列出了十个类别：“通用”“文稿与保存”“编辑器”“键盘”“拼写检查”“主题”“排版”“控制台”“预览”和“更新”。每个类别以简短的概述开头，并将其设置按命名的组排列。在“设置”打开期间，“返回”和“前进”（或 ⌘[ 和 ⌘]）可回到你访问过的类别。

设置决定文稿开始时的状态；菜单命令只在当前文稿打开期间更改它。例如，“源代码”>“显示行号”用于显示或隐藏当前窗口的行号，而“设置”>“编辑器”中的“显示行号”决定文稿打开时是否显示行号。这类设置集中在“编辑器”和“预览”类别顶部的“打开文稿时”组中。

更改会在你进行时随即保存；文本栏在你按下 Return 键或离开该栏时取用其值。“启用自动保存和版本”以及切换到或离开 OgreKit 查找面板，在 TeXShop 重新启动后才会生效。

搜索设置

在边栏顶部的“搜索设置”中键入，即可查找设置、选项或菜单命令。每条结果都显示项目名称及其类别。用空格分隔的各个词必须都描述同一个项目，类别名称可以缩小搜索范围。大小写、拉丁字母的重音、全角字符以及平假名与片假名的区别都会被忽略。选择一条结果即可转到该设置，并高亮显示它；之后点按“返回”会回到原来的位置。清除搜索后，当前类别仍保留在屏幕上。选择菜单命令会打开“键盘”，并在其列表中显示该命令，你可以在那里更改它的快捷键。

通用

“启动时”用于选择 TeXShop 在没有文件的情况下启动时是否打开一份空文稿（“打开空文稿”）。“配置为外部编辑器”用于在其他编辑器中编写源代码：此时 TeXShop 只显示源文件的预览；请参阅“使用外部编辑器”。

“窗口”用于选择文稿的源代码和预览是在分离的窗口中还是在单一窗口中打开、源代码位于该窗口的哪一侧（“单一窗口中源代码的位置”），以及新窗口是否以标签页打开（请参阅“窗口和标签页”）。“窗口位置”用于选择源代码、预览、控制台和 HTML 窗口在何处打开；“设成当前位置”使用当前打开的窗口的位置和大小。“项目根文件”用于在打开项目的某个章节文件时打开其根文件；请参阅“设置项目根文件”。

“运行时的 Dock 图标”用于选择 TeXShop 在程序坞中显示的图标：当前的图标或较早的某个设计。“高级”中有“打开‘魔法注释行和隐藏设置’手册…”按钮，它会打开列出魔法注释行和此窗口中未显示的设置的文档；请参阅“隐藏设置”。

文稿与保存

“新文稿的编码”为“Unicode (UTF-8)”，这几乎适合所有人。打开没有编码行的文件时，TeXShop 会检测其编码；文件开头的 % !TEX encoding = … 行（可以用“宏”>“Encoding”为你写出）会固定该文件的编码。“在保存对话框中显示编码”会在保存对话框中添加编码菜单。请参阅“编码”。

“启用自动保存和版本”会打开 macOS 的一项功能：在你工作时保存所做的编辑，并保留较早的版本。“保存时将之前的文件保留为‘名称~’”会保留每次保存之前的文件作为备份：对于 paper.tex，备份文件为 paper~.tex。“自动将 UTF-8-MAC 转换为 UTF-8”会在保存时将分开存储的字符（例如 か + ゛）合并为单个字符。

编辑器

“文稿字体”用于设置所有源代码窗口的字体；等宽字体能使源代码的各列保持对齐。在同一“显示”组中，“行号字体大小”用于将行号设为小号或大号，“在菜单栏显示标签菜单”会将“标签”菜单放到菜单栏中。“样式”组用于设置制表符的宽度、“缩进”和“取消缩进”是否使用制表符（“用制表符缩进菜单”）、未换行书写的段落的缩进，以及行间距；已打开的源代码窗口会立即反映更改。“键入”中有“点选窗口时激活光标”（决定将源代码窗口调到前面的那次点按是否同时移动插入点）、“输入括号时将选中文本括起来”，以及将这些语言的行右对齐的“从右向左的语言（阿拉伯语、希伯来语、波斯语）”；请参阅“编码”。“语法高亮”中有针对命令名中的 @、expl3 代码、全角字符和索引条目的开关；颜色在“主题”中设置。“查找”用于选择查找界面，以及高级查找面板是否保持在其他窗口前面（“高级查找面板始终显示在最前面”）；请参阅“查找和替换”。“标签列表中的 XML 标签”用于选择“标签”菜单列出 XML 文稿中的哪些标签。

“打开文稿时”决定新的源代码窗口是否显示行号、高亮当前行、自动换行、显示不可见字符以及使用块状光标。“源代码”菜单可为当前窗口更改这些设置。“插入点”组用于设置块状光标的颜色、它绘制在插入点的哪一侧以及宽度。

括号匹配

键入右括号时，TeXShop 会显示与之配对的括号，以便你检查公式中的括号是否配对。“括号匹配”组用于选择检查哪些括号对以及如何显示配对的括号：短暂高亮（“配对括号”）、闪烁（“闪烁高亮”）、为括号之间的文本着色（“高亮括号内字符”），或者在插入点移到括号旁边时也显示（“移动时突出配对字符”）。右括号没有配对时，“字符未配对时发出响声”和“字符未配对时闪烁背景”会发出提醒。连按括号会选中到其配对括号为止的全部内容。颜色是“主题”中“高亮”组的“括号内字符”和“括号”，以及“源文件”组的“闪烁”。

不可见字符

“源代码”>“显示不可见字符”会在当前窗口中显示空格、日文空格、换行符和制表符，这有助于排查文本表现异常的原因。“编辑器”的“不可见符号”组用于选择显示其中哪些字符以及各自使用的符号；“打开文稿时”下的“显示不可见字符”会在每份文稿中显示它们。它们的颜色是“主题”中“高亮”组的“不可见符号”。

键盘

“键盘”包含：按键绑定，它会将键入的字符替换为 {} 等文本（请参阅“按键绑定”）；命令补全及其触发按键，以及用于编辑补全列表的“编辑命令补全文件…”（请参阅“命令补全”）；引用标签和引用键的补全；以及所有菜单命令的快捷键，可以在这里更改（请参阅“重新定义菜单键盘快捷键”）。

拼写检查

“检查拼写”用于设置键入时的拼写检查、自动纠正拼写和词典。在“方式”下选择“使用考虑LaTeX语法的拼写检查（推荐）”，它会跳过注释、数学公式、命令以及 \label 和 \cite 等命令的参数；“编辑 LaTeX 排除规则…”用于更改它排除的内容。“传统方式”有自己的三个选项。请参阅“拼写检查”。

主题

主题是一组颜色，用于窗口、语法高亮、括号匹配、不可见字符和其他高亮。“浅色主题”和“深色主题”用于选择在 macOS 各外观模式下使用的主题。在它们下方，主题列表可以添加、复制、重新命名、删除、恢复、导出和导入主题；选择一个主题即可更改其颜色。对主题的更改会立即保存。

在“主题”中，你可以设置源代码、预览和控制台窗口的背景色、文本颜色、光标颜色和不透明度（“Alpha 值”），以及源代码中所选内容的颜色。在光标颜色和所选内容颜色下方，“使用系统颜色”会改用在“系统设置”>“外观”中选择的强调色和高亮标记颜色；再次取消勾选时，会恢复主题自己的颜色。“Alpha 值”使用一个滑块和一个从 0% 到 100% 的数字栏。输入整数百分比，然后按下 Return 键或离开该栏即可应用。栏旁边的箭头按钮每次将其增加或减少百分之一。超出此范围的值会被调整为最接近的极限值。无效的文本（包括小数）会在你结束编辑时恢复为之前的值；键入和粘贴的输入都遵循同样的规则。

关于源代码的颜色，请参阅“语法高亮”。

排版

设置排版最快的方法是使用引擎配置。在“引擎”组顶部的“引擎配置”菜单中选择一个配置，例如 pdfLaTeX、LuaLaTeX 或 upLaTeX + dvipdfmx。会出现一个对话框列出该配置要设置的值；关闭某个值即可保留其当前设置，选择 LaTeX 是否用 latexmk 运行，然后点按“好”。配置会设置排版命令和排版方式、kpsewhich 命令、BibTeX 引擎、索引程序、MetaPost 以及 otf 转换；日语配置还会设置新文稿的编码、词典和 UTF-8-MAC 转换。其他所有设置保持不变。设置与任何配置都不匹配时，菜单显示“自定”。

“引擎”组中的其他设置用于选择：文稿打开时工具栏中“排版”按钮旁边选中的项目（“新文稿的排版”）、在那里选择“引擎文件”时使用的引擎文件，以及“排版方式”：“直接生成 PDF”“经由 DVI”或“个性化脚本”。文稿开头的 % !TEX program 行优先。“替代引擎”是“排版”>“使用替代引擎排版”所用的引擎；请参阅“添加排版引擎”。“排版后”用于选择排版结束时哪个窗口来到前面：“调出预览窗口”“继续编辑”或“显示预览后返回原窗口”。“源文件和预览同步”用于选择“同步方式”，以及通过同步定位的文件是否以标签页在根文件的窗口中打开；请参阅“同步源文件和预览”。

“直接生成 PDF”和“经由 DVI”组包含每种方式运行的 plain TeX 和 LaTeX 命令及其选项。如果在命令中加入 -shell-escape，请打开“shell-escape 时确认”，以便在排版这样的文稿之前先询问你；请参阅“Shell Escape 保护”。“个性化脚本”组包含“个性化脚本”方式的命令。“相关工具”包含 BibTeX、索引和 MetaPost 的命令。请参阅“排版文稿”和“替代排版方式”。

“路径”包含 TeX 程序所在的文件夹（“TeX 引擎”，通常为 /Library/TeX/texbin）和 Ghostscript 所在的文件夹，以及“第二组 TeX 引擎”，即用于含有 % !TEX useAlternatePath 行的文稿的另一个 TeX 程序文件夹。“自动检测路径…”会在常见位置查找 TeX Live 和 Ghostscript，按从新到旧的顺序列出找到的安装及其版本，并设置你选择的那个。TeXShop 首次使用时也会这样做。“日语 pLaTeX”组的说明请参阅“日语排版”。

控制台

“控制台”用于设置控制台的字体（如果你愿意，也可以用于宏编辑器），以及控制台何时出现：排版时一直显示，或仅在出现错误时显示。“控制台窗口调整”用于选择控制台窗口可以在两个方向上调整大小，还是只能在竖直方向上调整。

预览

“打开文稿时”用于设置新的预览窗口如何显示文稿：页面布局、放大率、鼠标模式、链接预览以及双页布局的方向。其他组用于设置翻页和链接预览、其他应用更改 PDF 时的刷新、拷贝图像的格式，以及 HTML 窗口的起始页。请参阅“预览窗口”。

更新

TeXShop 可以每天、每周或每月自动检查新版本。打开“包含预发布版本”即可同时收到 Beta 版本。“检查更新…”会立即检查。
