安装 TeX Live

TeXShop 需要一个 TeX 发行版。标准的发行版是 TeX Live，由各地的 TeX 用户组每年为 macOS、Windows、Linux 及其他系统制作。在 Mac 上，使用 MacTeX 安装 TeX Live。MacTeX 是 TeX 用户组（TUG）制作的安装器软件包：

https://tug.org/mactex/

该页面提供两个软件包。连按下载的软件包并按照安装器的提示操作；安装结束后，TeX 即可使用。

MacTeX
完整的 TeX Live，约 7 GB，附带 Ghostscript，并将 TeXShop 和其他应用安装到 /Applications/TeX 中。几乎所有 TeX 或 LaTeX 书籍中的示例无需添加任何东西即可使用。实际工作请选择此软件包。
BasicTeX
TeX Live 的一小部分，约 140 MB，足以试用 TeX 并排版许多 LaTeX 文稿。它不会安装 TeXShop；请参阅“安装 TeXShop”。

TeX Live 的安装位置

MacTeX 将 TeX Live 安装在 /usr/local/texlive/2026 中，BasicTeX 则安装在 /usr/local/texlive/2026basic 中。两者可以并存。每年 4 月前后会发布新的 TeX Live，安装在以年份命名的文件夹中。要移除某个安装，将其文件夹拖到废纸篓即可。

安装器还会创建 /Library/TeX/texbin，它指向当前使用的 TeX Live 中的程序，并在安装新的 TeX Live 时随之切换。TeXShop 从这里运行 TeX（“设置”>“排版”>“路径”>“TeX引擎”），因此新的年度版本无需更改任何设置。同一组中的“自动检测路径…”会查找 Mac 上安装的 TeX 和 Ghostscript，并让你从中选择一个。

在两次年度发布之间，TeX Live 中的宏包会不断更新。MacTeX 会在 /Applications/TeX 中安装 TeX Live Utility，用于安装这些更新。

其他 TeX 发行版

TeXShop 也可以使用 MacPorts 或 Homebrew 安装的 TeX，或者 MiKTeX。它们的程序位于其他文件夹中：请使用“自动检测路径…”，或在“设置”>“排版”>“路径”>“TeX引擎”中输入文件夹。请参阅“与其他 TeX 发行版共存”。
