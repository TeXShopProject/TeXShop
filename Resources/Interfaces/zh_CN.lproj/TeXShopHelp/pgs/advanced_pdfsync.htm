同步源文件和预览

在源代码窗口中按住 Command 键点按一个词，预览窗口就会滚动到相应位置并将其标出。在预览窗口中按住 Command 键点按某个位置，源文件就会打开（如有必要）并显示相应的行，该行会被标出。这两种标记的颜色在“设置”>“主题”>“SyncTeX”中的“预览”和“源文件”下设置。

SyncTeX

TeXShop 使用 SyncTeX 进行同步。用选项 -synctex=1 运行 TeX 时，它会在 PDF 旁边写出一个文件（例如 Galois.synctex.gz），记录源文件的每个部分最终出现在页面上的位置。“设置”>“排版”中的排版命令（按引擎配置所设置的那样），以及 TeXShop 放在 ~/Library/TeXShop/Engines 中且运行 TeX 的引擎，已经使用了这个选项。你在那里添加的引擎（包括 Inactive 文件夹中的可选引擎），只有在其命令中带有这个选项时才会使用它。在你自己的引擎中，请在调用 TeX 时加上 -synctex=1（用一个或两个连字符均可；每个引擎都接受这两种写法）。

synctex 文件中包含源文件的完整路径。项目文件夹被移动、拷贝或发送给他人后，在文稿重新排版之前，同步不会起作用。

SyncTeX 并不完全精确：你要找的位置可能在标记稍前或稍后的地方。

包含多个文件的项目

在各章节文件用 % !TEX root 指定根文件的项目中（请参阅设置项目根文件），在章节文件中按住 Command 键点按，会跳到整个文稿预览中的相应位置；在预览中按住 Command 键点按，会打开包含所点按位置的章节文件。打开“设置”>“排版”>“源文件和预览同步”>“在根文件的窗口中以标签页打开通过同步定位的文件”后，以这种方式打开的文件会作为标签页加入根文件的窗口，而不是打开自己的窗口。

同步方式

“设置”>“排版”>“源文件和预览同步”>“同步方式”有两个选项：

SyncTeX（推荐）
如上所述，使用 synctex 文件。这是默认选项。
搜索 PDF
在 PDF 中搜索所点按位置周围的文本；在预览中点按时，则在源文件中搜索点按位置周围的文本。它不需要 synctex 文件，但在排版后的文本与源文件不同的地方会失败，例如公式和包含大量命令的文本。为了找出预览中某个位置所属的文件，它会搜索根文件中 \include 和 \input 命令所指定的文件。对于以其他方式包含文件的项目，请在根文件中用如下几行列出这些文件： 
% !TEX projectfile = chapter2.tex
% !TEX projectfile = /Users/me/Book/chapter3.tex
名称可以是完整路径，也可以是相对于根文件的路径；这些行可以放在根文件中的任何位置。

ConTeXt

对于 ConTeXt，请在文稿的设置部分加入 \setupsynctex[state=start,method=min]，并在根文件的开头加入 % !TEX useConTeXtSyncParser 一行；这样 TeXShop 会使用 ConTeXt 自己的同步代码。请参阅 ConTeXt 和 MetaPost。

要与在其他编辑器中打开的源文件同步，请参阅使用外部编辑器。
