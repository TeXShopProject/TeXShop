用 TeXShop 打开其他文件

TeXShop 可以打开任何文本文件，因此你可以阅读文稿旁边的日志文件、aux 文件以及 TeX 的其他文件。它还可以打开 PDF 文件和图片。

视为 TeX 源文件的文件

带有以下扩展名的文件以及没有扩展名的文件，对 TeXShop 来说都是 TeX 源文件：它们会以语法高亮显示，并且可以排版。

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

其他文本文件（例如 .log、.aux、.bst、.engine 或 .txt 文件）以纯文本打开，不带语法高亮。

要让 TeXShop 把带有其他扩展名的文件视为 TeX 源文件，请在终端中用隐藏设置添加该扩展名；例如，对于扩展名为 mkiv 的 ConTeXt 文件：

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

PDF 文件和图片

PDF 文件以及扩展名为 .png、.jpg、.jpeg、.tif、.tiff 和 .eps 的图片会在单独的窗口中打开。DVI 和 PostScript 文件（.dvi、.ps）会被转换为 PDF 后显示。

以其他扩展名保存

TeXShop 保存文件时，文件会保留原来的扩展名。新文稿会保存为 .tex 文件，除非你在保存对话框的“文件格式”菜单中选择其他类型，例如 sty、bib 或 mp。

TeXShop 以文件打开时所用的编码保存文件。它是为 TeX 及相关文件设计的；格式特殊的文件在 TeXShop 中编辑后保存，可能会发生变化。请参阅编码。
