矩阵面板

“窗口”>“矩阵面板...”会打开一个为你编写矩阵和表格的面板。在其表格中填写各项，选择结果的样式，然后将其插入源代码的插入点处。

制作矩阵或表格

  1. 在“行”和“列”中输入大小，各自最多 999。
  2. 在“环境”下，选择 matrix 以在公式中制作矩阵（array 环境），或选择 tabular 以制作文本表格。选择 tabular 时，“嵌入table环境”会将表格放入带标题和标签的 table 浮动体中。
  3. 对于矩阵，请选择左右定界符。句点表示该侧不加定界符，最后一个按钮使用在其旁边的栏中键入的定界符。
  4. 两个带有矩阵图样的按钮用于在各项周围加边框，以及在各项之间加线。
  5. 填写各项。“清除”会清空所有项；“单位矩阵”和“零矩阵”会以单位矩阵或零填充各项。
  6. 点按“插入”或按下 ⌘Return。

在表格中操作

表格的用法与电子表格相同。点按单元格即可选择它，拖移或按住 Shift 键点按可选择多个单元格，键入即可替换其值；连按、按 F2 或按 Control-U 可编辑单元格。Return 键向下移动，Tab 键向右移动，方向键可向任意方向移动；Delete 键清空所选的单元格。“拷贝”和“粘贴”可与电子表格应用交换单元格。拖移行号即可移动该行。面板处于活跃状态时，“撤销”和“重做”作用于表格。

缩小矩阵时，矩阵之外的单元格会保留其值并显示为灰色，再次放大矩阵时会恢复。放大面板即可看到更多的表格内容。

自定插入的代码

面板在各项周围写出的代码保存在 ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist 中：环境的开头和结尾、定界符、各项之间和各行之间的分隔符、边框或网格的线，以及设定各列对齐方式的字母 c。例如，将 c 改为 r 即可使各列右对齐。请保持文件中字符串的数量和顺序不变，更改后重新启动 TeXShop。请参阅“~/Library/TeXShop 中的文件”。
