Palette Matrice

Fenêtre › Palette Matrice... ouvre une palette qui écrit pour vous des matrices et des tableaux. Remplissez les coefficients dans son tableau, choisissez l’aspect du résultat et insérez-le dans la source au point d’insertion.

Créer une matrice ou un tableau

  1. Saisissez la taille dans « Lignes » et « Colonnes », jusqu’à 999 chacune.
  2. Sous « Environnement », choisissez matrix pour une matrice dans une formule (un environnement array) ou tabular pour un tableau de texte. Avec tabular, « Incorporer dans un environnement table » place le tableau dans un flottant table avec une légende et un label.
  3. Pour une matrice, choisissez les délimiteurs gauche et droit. Le point laisse ce côté sans délimiteur, et le dernier bouton utilise le délimiteur saisi dans le champ voisin.
  4. Les deux boutons illustrés d’une matrice ajoutent un cadre autour des coefficients et des traits entre eux.
  5. Remplissez les coefficients. « Effacer » les vide tous ; « Matrice identité » et « Matrice nulle » les remplissent avec une matrice identité ou avec des zéros.
  6. Cliquez sur « Insérer » ou appuyez sur ⌘Return.

Travailler dans le tableau

Le tableau fonctionne comme un tableur. Cliquez sur une cellule pour la choisir, faites glisser le pointeur ou cliquez en maintenant la touche Maj enfoncée pour en choisir plusieurs, et saisissez du texte pour remplacer la valeur ; double-cliquez, appuyez sur F2 ou appuyez sur Contrôle-U pour la modifier. Retour descend, Tab va à droite et les touches fléchées se déplacent dans toutes les directions ; Supprimer vide les cellules choisies. Copier et Coller échangent des cellules avec les applications de tableur. Faites glisser le numéro d’une ligne pour déplacer la ligne. Annuler et Rétablir agissent sur le tableau tant que la palette est active.

Quand la matrice est réduite, les cellules qui se trouvent en dehors gardent leurs valeurs, affichées en gris, et reviennent quand elle est de nouveau agrandie. Agrandissez la palette pour voir une plus grande partie du tableau.

Personnaliser le code inséré

Le code que la palette écrit autour des coefficients est conservé dans ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist : le début et la fin des environnements, les délimiteurs, les séparateurs entre coefficients et entre lignes, les traits d’un cadre ou d’une grille, et la lettre c qui détermine l’alignement de chaque colonne. Par exemple, remplacez c par r pour aligner les colonnes à droite. Conservez le nombre et l’ordre des chaînes du fichier, et relancez TeXShop après l’avoir modifié. Voir Les fichiers de ~/Library/TeXShop.
