Ajouter des moteurs de composition

En plus de plain TeX et de LaTeX, TeXShop compose avec des moteurs : de petits scripts shell portant l’extension .engine, placés dans le dossier ~/Library/TeXShop/Engines. Un moteur peut exécuter un seul programme ou une chaîne de programmes, par exemple LuaLaTeX, puis Biber, puis encore deux fois LuaLaTeX. TeXShop est fourni avec des moteurs tels que LuaLaTeX, XeLaTeX et pdflatexmk ; le sous-dossier Inactive en contient beaucoup d’autres.

Choisir un moteur

Le menu local situé à côté du bouton « Composer » dans la barre d’outils de la fenêtre source liste les moteurs. Choisissez-en un, puis cliquez sur « Composer » ou appuyez sur ⌘T. Ce choix ne s’applique qu’à ce document.

Pour composer les nouveaux documents avec un moteur, choisissez « Fichier de moteur » dans Réglages › Composition › Moteur › « Composer les nouveaux documents avec », puis choisissez le moteur dans le menu « Fichier de moteur » situé en dessous. « Modifier la liste des moteurs… » ouvre le dossier Engines dans le Finder ; le menu « Fichier de moteur » suit le dossier à mesure que vous ajoutez, supprimez ou renommez des fichiers. Si le fichier de moteur choisi n’est plus dans le dossier, le menu l’indique comme introuvable et les documents sont composés avec LaTeX.

Pour associer un document à un moteur, placez une ligne comme celle-ci dans l’une de ses vingt premières lignes :

% !TEX program = XeLaTeX

Le nom est celui du fichier de moteur sans .engine ; tex et latex composent en plain TeX et en LaTeX via DVI, et pdftex et pdflatex les composent en PDF direct. Cette ligne a priorité sur la barre d’outils, sur les réglages et sur « Composer avec un moteur TeX alternatif ». La forme % !TEX TS-program = est lue de la même façon. Écrivez la ligne exactement comme ci-dessus, avec une espace de chaque côté du signe égal ; la macro Set Typesetting Program… du menu Macros insère la ligne pour vous, avec une liste de noms de moteurs parmi lesquels choisir. Dans un projet doté d’un fichier racine, seul le fichier racine a besoin de cette ligne.

Composition › Composer avec un moteur TeX alternatif (⌃⌥⌘T) compose une fois avec le moteur indiqué dans Réglages › Composition › Moteur › « Moteur TeX alternatif », pdflatexmk par défaut, sans modifier la barre d’outils. Dans le menu Composition, cette commande apparaît à la place de « Composer » tant que vous maintenez les touches Contrôle et Option enfoncées. Elle convient aux documents que l’on compose habituellement en une seule passe rapide et, de temps en temps, complètement, avec latexmk.

Écrire un moteur

Le plus simple pour créer un moteur est de dupliquer un moteur du dossier Engines dans le Finder, de renommer la copie, puis de l’ouvrir dans TeXShop pour la modifier. Un fichier de moteur doit porter l’extension .engine et avoir l’autorisation d’exécution, qu’une copie conserve. Les documents ouverts ensuite affichent le nouveau moteur dans leur barre d’outils. Voici XeLaTeX.engine :

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

La première ligne indique le shell ou le langage du script ; zsh, bash, tcsh, Perl et d’autres conviennent tous, à condition que le script soit écrit dans ce langage. TeXShop exécute le moteur dans le dossier du fichier source et lui transmet trois valeurs :

$1
Le nom du fichier source avec son extension, sans son dossier, par exemple main.tex. Un script qui change de dossier doit d’abord noter le chemin complet, par exemple sous la forme "$PWD/$1". Dans un projet, il s’agit du fichier racine.
$2
La suite d’une ligne % !TEX parameter = … placée en haut du fichier source (du fichier racine), avec plusieurs options séparées par des espaces, par exemple % !TEX parameter = -shell-escape. Sans une telle ligne, c’est une espace unique.
$3
Le dossier indiqué dans le champ « Moteurs TeX » de Réglages › Composition › Chemins, ou le dossier indiqué dans « Seconds moteurs TeX » lorsque le document contient la ligne % !TEX useAlternatePath.

Quand le moteur se termine, TeXShop ouvre dans la fenêtre d’aperçu le fichier PDF portant le nom du fichier source et l’extension .pdf, s’il existe, et défile jusqu’à l’endroit affiché avant la composition. Un script qui produit un autre résultat peut indiquer ce qu’il faut afficher avec les lignes suivantes, écrites n’importe où dans le moteur, dans un commentaire de son langage :

LigneEffet
!TEX-noPreviewpas de fenêtre d’aperçu, même si d’autres lignes ci-dessous sont présentes
!TEX-pdfPreviewafficher le fichier PDF
!TEX-htmlPreviewafficher dans la fenêtre HTML le fichier HTML du même nom
!TEX-bothPreviewafficher à la fois le fichier PDF et le fichier HTML
!TEX-noConsolene pas afficher la console

Par exemple, un moteur qui exécute LuaLaTeX, Biber, puis encore deux fois LuaLaTeX pourrait s’écrire ainsi en zsh, où ${1:r} est le nom sans son extension :

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

Le dossier Inactive

Le sous-dossier Engines/Inactive contient des moteurs destinés à des usages particuliers, souvent accompagnés de documentation et d’exemples, par exemple pour latexmk, ConTeXt, Sage, PreTeXt et Typst. Pour en utiliser un, déplacez-le de son dossier vers le dossier Engines lui-même. Lors d’une mise à jour de TeXShop, le dossier Inactive est remplacé par sa version actuelle, tandis que les fichiers placés directement dans le dossier Engines ne sont jamais touchés ; les moteurs que vous avez modifiés sont donc conservés.

Pour en savoir plus sur les moteurs, consultez le chapitre « Engines and latexmk » d’Aide › Manuel de TeXShop (en anglais).
