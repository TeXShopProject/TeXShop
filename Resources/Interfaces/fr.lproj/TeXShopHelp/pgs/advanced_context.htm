ConTeXt et MetaPost

ConTeXt

ConTeXt est un ensemble de macros créé par Hans Hagen, une alternative à LaTeX dotée de ses propres commandes et particulièrement attentive à la conception typographique. TeX Live comprend ConTeXt, et le ConTeXt Garden distribue une version, souvent mise à jour, qui s’installe dans votre dossier de départ.

Les moteurs pour ConTeXt se trouvent dans ~/Library/TeXShop/Engines/Inactive/ConTeXt, avec le guide Setting-Up-ConTeXt.pdf et des documents d’exemple :

MoteurCompose avec
ConTeXt.enginele ConTeXt de TeX Live qui s’exécute sur LuaTeX
ConTeXt-TL.enginele ConTeXt de TeX Live qui s’exécute sur luametatex
ConTeXt-CG.enginela version du ConTeXt Garden installée dans votre dossier de départ

Déplacez le moteur dont vous avez besoin dans ~/Library/TeXShop/Engines, et placez des lignes magiques en haut du fichier racine du document, par exemple :

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Pour ConTeXt-CG, saisissez le dossier des programmes de l’installation du ConTeXt Garden dans le champ « Seconds moteurs TeX » de Réglages › Composition › Chemins, et ajoutez la ligne % !TEX useAlternatePath, qui fait transmettre ce dossier au moteur par TeXShop à la place de celui de TeX Live.

Pour la synchronisation entre la source et l’aperçu, ajoutez \setupsynctex[state=start,method=min] à la configuration du document ; la ligne % !TEX useConTeXtSyncParser fait utiliser à TeXShop le code de synchronisation propre à ConTeXt. Le chapitre consacré à ConTeXt d’Aide › Manuel de TeXShop (en anglais) décrit en détail l’installation de la version du ConTeXt Garden et chacun des moteurs.

Pour lister dans le menu Étiquettes les commandes de section de ConTeXt telles que \title et \subject, activez le réglage caché ConTeXtTags ; consultez Réglages cachés.

MetaPost

MetaPost, de John Hobby, dessine des illustrations à partir d’une description écrite dans un langage de programmation dérivé de METAFONT de Knuth. Son manuel fait partie de TeX Live : choisissez Aide › Afficher l'aide pour le package... et tapez metapost.

Composition › MetaPost (⇧⌘M), ou MetaPost dans le menu local situé à côté du bouton « Composer », exécute MetaPost sur le fichier qui porte le nom du document actif et l’extension .mp : sur le document lui-même s’il s’agit d’un fichier .mp, et sinon sur le fichier .mp situé à côté, par exemple celui que le paquet mfpic écrit pour un document .tex. Il exécute la commande indiquée dans Réglages › Composition › « Outils associés » › « MetaPost », mpost par défaut. Les profils du moteur règlent ce champ : pmpost pour pLaTeX + dvipdfmx et upmpost pour upLaTeX + dvipdfmx, qui composent du texte japonais dans les étiquettes, et mpost pour les autres profils. LuaLaTeX ne peut pas inclure de figures dont pmpost ou upmpost ont composé les étiquettes en japonais ; avec LuaLaTeX, dessinez ces figures dans le document avec le paquet luamplib.

Pour enregistrer un nouveau fichier en tant que fichier MetaPost, choisissez le type mp dans le menu « Format de fichier » de la zone de dialogue d’enregistrement.

Les moteurs nv-metapost et nv-metafun, de Nicola Vitacolonna, facilitent le travail avec MetaPost et MetaFun et affichent les figures d’un fichier dans la fenêtre d’aperçu. Ils se trouvent dans ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines ; le fichier README.pdf et le dossier examples, un niveau plus haut dans MetaPostEngines-1.4.7, expliquent comment les installer et les utiliser et fournissent des fichiers d’exemple. Par exemple, un fichier qui commence par

% !TEX program = nv-metafun
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

est composé avec nv-metafun dès que ce moteur se trouve dans le dossier Engines.

Les dessins MetaPost peuvent aussi être écrits à l’intérieur d’un document LaTeX, avec le paquet luamplib pour LuaLaTeX, ou avec des paquets tels que mfpic, qui écrivent les dessins dans un fichier .mp que MetaPost traite entre deux compositions.
