Modifier les raccourcis de saisie

Les raccourcis de saisie remplacent un caractère saisi par un texte, par exemple ^ par ^{} avec le point d’insertion entre les accolades ; Raccourcis de saisie explique comment les utiliser. Cette page explique comment modifier la liste.

Activer les raccourcis de saisie

« Utiliser les raccourcis de saisie (valeur initiale des nouveaux documents) », dans Réglages › Clavier, détermine si les raccourcis de saisie sont activés à l’ouverture d’un document ; ce réglage est désactivé au départ. Source › Raccourcis de saisie les active ou les désactive pour le document actif seulement, et l’élément facultatif « Raccourcis de saisie » de la barre d’outils fait de même.

Modifier la liste

La « Liste des raccourcis de saisie » de Réglages › Clavier affiche chaque caractère saisi avec son texte produit. Double-cliquez sur une cellule pour la modifier sur place. Cliquez sur + sous la liste pour ajouter un raccourci de saisie et sur − pour supprimer ceux qui sont sélectionnés ; faites glisser des lignes pour changer leur ordre. Un caractère saisi est un caractère unique. Les modifications sont enregistrées aussitôt et s’appliquent immédiatement, y compris dans les documents déjà ouverts ; Édition › Annuler les annule.

Un texte produit peut contenir les symboles suivants, que la liste affiche sous forme de petites étiquettes :

#SEL#
le texte qui était sélectionné lorsque la touche a été tapée
#INS#
l’endroit où va le point d’insertion
#PASTE#
le texte du presse-papiers
•
un repère, vers lequel Édition › Repères permet de se déplacer

Ajoutez-les avec le menu « Insérer » situé sous la liste, ou tapez-les tels qu’ils sont écrits ci-dessus ; Option-Retour insère un saut de ligne et Option-Tab une tabulation. Le bouton ? situé à côté de la liste les affiche tous. Copier un texte produit copie les symboles tels qu’ils sont écrits ci-dessus.

Une coche dans la colonne « Coller » applique aussi un raccourci de saisie au texte collé : tant que les raccourcis de saisie sont activés pour le document, chaque occurrence de son caractère saisi dans un texte collé ou déposé dans la source est remplacée par son texte produit. Les raccourcis de saisie dont le texte produit contient #SEL#, #INS#, #PASTE# ou un repère ne peuvent pas être cochés.

Revenir à la liste par défaut

La liste est conservée dans le dossier ~/Library/TeXShop/Keyboard. Pour revenir à la liste fournie avec TeXShop, quittez TeXShop, déplacez le dossier Keyboard sur le bureau et relancez TeXShop ; il recrée le dossier avec son contenu par défaut.
