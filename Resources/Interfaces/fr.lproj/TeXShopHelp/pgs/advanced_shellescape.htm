Protection contre le shell-escape

Pendant la composition, TeX peut exécuter d’autres programmes. Par défaut, TeX Live n’autorise qu’une courte liste de programmes de confiance, par exemple pour convertir des images EPS en PDF. Les paquets qui ont besoin d’exécuter d’autres programmes demandent l’option -shell-escape (qui s’écrit aussi --shell-escape).

Avec cette option, un document peut exécuter n’importe quelle commande, par exemple une commande qui supprime tous les fichiers de votre dossier de départ. Ne l’utilisez que pour des documents auxquels vous faites confiance, et pas pour des fichiers que vous recevez d’autres personnes.

Ajouter l’option

  • Dans la commande LaTeX ou plain TeX de Réglages › Composition › « PDF direct », pour tous les documents composés en PDF direct.
  • Dans un fichier de moteur, pour tous les documents composés avec ce moteur ; consultez Ajouter des moteurs de composition.
  • Pour un seul document composé avec l’un des moteurs latexmk, comme pdflatexmk, avec la ligne % !TEX parameter = -shell-escape en haut du fichier source.

Un moteur comporte déjà l’option : sepdflatexmk, fourni avec TeXShop et présent dès le départ dans le dossier Engines, compose toujours avec --shell-escape. Il suffit de le choisir dans la barre d’outils de la fenêtre source ou avec une ligne % !TEX program = sepdflatexmk ; ne l’utilisez donc que pour des documents auxquels vous faites confiance.

Confirmer le shell-escape

Réglages › Composition › « PDF direct » › « Confirmer le shell-escape », désactivé par défaut, protège les commandes du groupe « PDF direct ». Lorsqu’il est activé et que la commande plain TeX ou LaTeX de ce groupe contient -shell-escape ou --shell-escape, TeXShop demande confirmation avant de composer un document pour la première fois après son ouverture :

  • « OK » compose avec l’option.
  • « Omettre le shell-escape » compose sans elle.
  • « Annuler » ne compose pas.

Une fois que vous avez choisi « OK » ou « Omettre le shell-escape », la réponse vaut pour ce document jusqu’à sa fermeture ; vous pouvez ainsi composer vos propres documents avec l’option et les documents d’autres personnes sans elle. Les fichiers de moteur ne sont pas vérifiés, même s’ils contiennent -shell-escape ; sepdflatexmk compose donc avec l’option sans rien demander.
