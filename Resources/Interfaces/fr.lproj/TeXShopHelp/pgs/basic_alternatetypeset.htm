Mode de composition alternatif

TeXShop compose normalement avec la méthode « PDF direct » : pdfLaTeX ou pdfTeX écrit directement le fichier PDF. La méthode alternative, « Via DVI », exécute LaTeX ou TeX pour produire un fichier DVI, le convertit en PostScript avec dvips, puis convertit le PostScript en PDF avec Ghostscript. Le script simpdftex de TeX Live effectue ces étapes.

« Via DVI » est nécessaire pour les documents qui placent du code PostScript dans le résultat, par exemple avec le paquet pstricks. Les images EPS n’en ont pas besoin : TeX Live les convertit en PDF pendant la composition en « PDF direct ».

Choisir la méthode

Composition › Via DVI et Composition › PDF direct changent la méthode du document actif ; les autres documents ouverts gardent la leur. Réglages › Composition › Méthode de composition détermine la méthode avec laquelle les documents commencent. Son troisième choix, « Script personnel », exécute à la place les commandes du groupe « Script personnel ». Les commandes de « Via DVI », l’une pour plain TeX et l’autre pour LaTeX, se trouvent dans le groupe « Via DVI » de Réglages › Composition. Le profil du moteur LaTeX + dvips + Ghostscript, sous « Autre » dans le menu « Profil du moteur », prépare la composition « Via DVI ».

Choisir la méthode dans le document

Une ligne placée parmi les 20 premières lignes de la source détermine le programme et la méthode de ce document, quels que soient les réglages :

LigneCompose avec
% !TEX program = pdflatexLaTeX, PDF direct
% !TEX program = latexLaTeX, Via DVI
% !TEX program = pdftexplain TeX, PDF direct
% !TEX program = texplain TeX, Via DVI
% !TEX program = personallatexLaTeX, Script personnel
% !TEX program = personaltexplain TeX, Script personnel

Options de « Via DVI »

Par défaut, Ghostscript ignore la transparence PostScript. Pour la conserver, ajoutez --distilleropts "-dALLOWPSTRANSPARENCY" à la fin de la commande du groupe « Via DVI ». Pour conserver le fichier PostScript intermédiaire, ajoutez --keep-psfile. Ghostscript est exécuté depuis le dossier indiqué dans Réglages › Composition › Chemins › Ghostscript.
