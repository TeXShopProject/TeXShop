Modèles et papeterie

Modèles

Le menu « Modèles » de la barre d’outils de la fenêtre source insère un modèle au point d’insertion, indenté comme la ligne courante. TeXShop est fourni avec ces modèles :

  • LatexTemplate, XeLaTeX Template, LatexSpanishTemplate et BeamerTemplate : le début d’un article LaTeX, d’un document XeLaTeX, d’un article LaTeX en espagnol et d’une présentation Beamer ;
  • TexTemplate : le \end qui termine un document plain TeX ;
  • GraphicsTemplate : le code pour inclure une image ;
  • TeX4ht-Header et TeX4ht-Interactive : du code pour les documents convertis en HTML avec TeX4ht ;
  • More : un sous-menu avec des préambules, des classes de document comme article, letter et memoir, des figures et des tableaux flottants, et des mises en page mathématiques comme align et les matrices.

Les modèles sont des fichiers ordinaires de ~/Library/TeXShop/Templates ; choisissez TeXShop › Ouvrir ~/Bibliothèque/TeXShop pour y accéder. Pour créer votre propre modèle, par exemple le préambule que vous utilisez pour chaque article, enregistrez dans ce dossier un fichier avec l’extension .tex, ou dupliquez un modèle et modifiez-le. Les sous-dossiers deviennent des sous-menus. Les modèles que vous ajoutez, renommez ou supprimez apparaissent dans le menu des fenêtres ouvertes ensuite.

Les mises à jour de TeXShop ne modifient pas ce dossier ; vos modèles sont donc conservés. Pour retrouver les modèles d’origine, déplacez le dossier Templates hors de ~/Library/TeXShop, par exemple sur le bureau, et relancez TeXShop : il recrée le dossier avec ses propres modèles.

Papeterie

Fichier › Nouveau depuis la papeterie... crée un nouveau document à partir d’un exemple complet : choisissez-en un dans la liste, qui affiche une description de chacun, et cliquez sur Créer ; la barre d’espace affiche le modèle sélectionné dans Coup d’œil. Le nouveau document est sans titre ; enregistrez-le où vous voulez. TeXShop est fourni avec de la papeterie pour un article AMS, une présentation Beamer, une lettre, un document PreTeXt, un projet avec un fichier racine et un chapitre, et un document XeLaTeX.

La papeterie est conservée dans ~/Library/TeXShop/Stationery. « Afficher dans le Finder » dans la fenêtre ouvre ce dossier. + dans la fenêtre ajoute un modèle vide dont vous tapez ensuite le nom ; − ou la touche Supprimer place le modèle sélectionné dans la corbeille. Le menu à l’extrémité droite de la barre et le menu contextuel ouvrent le modèle sélectionné pour le modifier, le renomment, modifient sa description, le dupliquent ou l’affichent dans le Finder. Vous pouvez aussi ajouter la vôtre : placez-y le fichier, par exemple Report.tex, avec un fichier Report.comment contenant une phrase qui le décrit.
