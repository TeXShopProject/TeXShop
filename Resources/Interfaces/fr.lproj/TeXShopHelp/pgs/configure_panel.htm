Modifier la palette LaTeX

La palette LaTeX (Fenêtre › Palette LaTeX...) comporte un onglet « Personnalisé » pouvant accueillir jusqu’à seize boutons de votre choix. Les noms des autres boutons ne peuvent pas être modifiés, mais le texte qu’ils insèrent peut l’être.

Les deux se règlent dans le fichier ~/Library/TeXShop/LatexPanel/completion.plist. Ouvrez-le dans TeXShop et lisez les commentaires placés en tête, qui expliquent l’organisation du fichier. Chaque onglet possède une liste des textes qu’insèrent ses boutons, dans l’ordre des boutons. Dans ces textes, #SEL# représente le texte sélectionné et #INS# l’endroit où va le point d’insertion.

Les boutons de l’onglet « Personnalisé » se trouvent dans la liste nommée Customized. Chaque bouton est une paire de chaînes : son nom, puis le texte qu’il insère. Par exemple,

<string>Section</string>
<string>\section{#SEL##INS#}</string>

crée un bouton nommé Section qui insère \section{} autour du texte sélectionné, avec le point d’insertion entre les accolades.

Enregistrez le fichier en UTF-8. TeXShop le lit à la première ouverture de la palette LaTeX ; relancez donc TeXShop pour voir vos modifications. Conservez toutes les entrées des listes des autres onglets : si le fichier est inutilisable, TeXShop utilise sa propre copie et, au démarrage suivant, remplace le fichier et conserve le vôtre dans ~/Library/TeXShop/Backups.
