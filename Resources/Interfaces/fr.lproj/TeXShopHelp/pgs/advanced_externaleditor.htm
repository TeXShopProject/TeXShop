Utiliser un éditeur externe

Vous pouvez écrire dans un autre éditeur et utiliser TeXShop pour composer et afficher le PDF.

N’ouvrir que l’aperçu

Fichier › Ouvrir pour aperçu... demande un fichier source et n’ouvre que sa fenêtre d’aperçu. Si le fichier n’a pas encore été composé, ou si le PDF est plus ancien que la source, TeXShop le compose d’abord. Modifiez la source dans votre éditeur ; pour composer, enregistrez-la dans l’éditeur, puis cliquez sur « Composer » dans la fenêtre d’aperçu ou appuyez sur ⌘T. Dans ce mode, TeXShop n’ouvre ni ne modifie jamais le fichier source. Si la barre d’outils de la fenêtre d’aperçu ne comporte pas de bouton « Composer », ajoutez-en un avec Fenêtre › Personnaliser la barre d'outils....

Si vous travaillez toujours de cette façon, activez Réglages › Général › Au démarrage › « Configurer pour éditeur externe ». Fichier › Ouvrir... et « Ouvrir l’élément récent » ouvrent alors les fichiers source pour l’aperçu seulement, et Fichier › Ouvrir pour aperçu... devient « Ouvrir pour éditer... », qui ouvre un fichier source dans l’éditeur de TeXShop lorsque vous en avez besoin. Les autres fichiers, comme les fichiers PDF, les images et les fichiers log, s’ouvrent comme avant.

Garder l’aperçu à jour

Lorsque le PDF est réécrit par un autre programme, par exemple par votre éditeur ou par latexmk dans Terminal, TeXShop le recharge lorsque vous revenez à TeXShop ou à la fenêtre d’aperçu, en conservant la page et l’agrandissement. Lorsque Réglages › Aperçu › Actualisation › « Toujours surveiller les modifications du PDF par d’autres apps » est activé, il recharge le PDF dès qu’il change, même quand TeXShop est en arrière-plan, par exemple quand l’aperçu est placé à côté de votre éditeur. Un aperçu comportant des annotations non enregistrées n’est pas rechargé, afin que les annotations ne soient pas perdues.

TeXShop surveille aussi les fichiers source ouverts dans son propre éditeur. Lorsqu’un autre éditeur modifie un tel fichier, TeXShop le recharge, sauf si la copie ouverte dans TeXShop comporte des modifications non enregistrées.

Synchroniser avec l’éditeur

Un Commande-clic dans la fenêtre d’aperçu peut vous mener à la ligne correspondante dans votre éditeur, et le bouton « Aller à l'erreur » de la console peut y ouvrir la ligne d’une erreur. Il faut pour cela « Configurer pour éditeur externe », un réglage caché et un programme en ligne de commande de l’éditeur :

  • Pour TextMate, dont la commande mate se trouve dans /usr/local/bin : defaults write TeXShop TextMateSync YES.
  • Pour tout autre éditeur : defaults write TeXShop OtherEditorSync YES, et un script exécutable /usr/local/bin/othereditor qui reçoit le numéro de ligne dans $1 et le chemin complet du fichier dans $2. Pour BBEdit, il s’écrit : 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

Dans l’autre sens, d’une ligne de l’éditeur vers la fenêtre d’aperçu, l’éditeur appelle TeXShop par AppleScript avec les commandes sync_preview_line, sync_preview_index et sync_preview_name. Le chapitre « Using an External Editor » d’Aide › Manuel de TeXShop (en anglais) contient un script complet.

Le dossier ~/Library/TeXShop/ExternalEditorScripts contient des outils prêts à l’emploi, avec leur documentation : des AppleScripts qui composent et affichent dans TeXShop un document de BBEdit, et un module pour Vim.

Commandes AppleScript pour les éditeurs

Un éditeur peut appeler ces commandes AppleScript d’un document TeXShop :

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Composent, ou exécutent plain TeX, LaTeX, BibTeX, MakeIndex ou MetaPost. L’appel rend la main aussitôt, sans attendre la fin de la composition ; l’aperçu est actualisé à la fin de celle-ci.
taskdone
Renvoie NO tant que la composition est en cours et YES lorsqu’elle est terminée.
refreshpdf
Recharge le PDF et amène la fenêtre d’aperçu au premier plan.
refreshpdfbackground
Recharge le PDF sans amener TeXShop au premier plan, lorsque la fenêtre d’aperçu est déjà ouverte.
refreshtext
Relit le fichier source sur le disque.
open_for_externaleditor
Ouvre un fichier source comme le fait Fichier › Ouvrir pour aperçu....

Lorsque l’éditeur compose par l’intermédiaire de TeXShop, « Toujours surveiller les modifications du PDF par d’autres apps » n’est pas nécessaire. Consultez aussi Écrire des scripts avec les commandes de composition de TeXShop.
