Macros

Le menu Macros, ainsi que l’élément « Macros » de la barre d’outils, contiennent des commandes qui insèrent du code LaTeX dans la source ou exécutent des scripts AppleScript. Voici quelques-unes des macros fournies avec TeXShop :

  • Program, Encoding et Root écrivent les lignes % !TEX qui choisissent le moteur de composition, l’encodage et le fichier racine d’un document. Choisissez le moteur ou l’encodage dans la liste qu’affiche Program ou Encoding, ou le fichier racine dans la zone de dialogue qu’ouvre Root ; la ligne est écrite correctement en tête de la source.
  • Insert Begin/End transforme le mot situé au point d’insertion ou le mot sélectionné, comme theorem, en une paire \begin{theorem} … \end{theorem}, avec le point d’insertion entre les deux.
  • Des sous-menus comme Headings, Mathematics, Lists, Tables et Figures insèrent du code LaTeX courant.

L’éditeur de macros

Choisissez Macros › Ouvrir l'éditeur de macros... pour voir comment chaque macro est définie, la modifier ou ajouter vos propres macros. La liste de gauche est le menu Macros : faites glisser les éléments pour les réorganiser, et utilisez la barre située sous la liste pour ajouter des éléments, des sous-menus et des séparateurs. Le texte d’une macro est inséré dans la source. Dans ce texte, des jetons arrondis représentent le texte sélectionné, le texte du presse-papiers et l’emplacement du point d’insertion ; choisissez-les dans le menu « Insérer » sous le texte.

Pour donner un raccourci clavier à une macro, sélectionnez-la dans la liste, cliquez sur son raccourci (ou double-cliquez dessus) et appuyez sur les touches. Un raccourci utilise la touche Commande ou Contrôle, ou est une touche de fonction. Si une commande de menu ou une autre macro l’utilise déjà, l’éditeur de macros le signale.

Les macros sont conservées dans ~/Library/TeXShop/Macros/Macros_Latex.plist. Pour donner des macros à d’autres personnes, sélectionnez-les dans l’éditeur de macros et choisissez Macros › Enregistrer la sélection dans un fichier... ; pour ajouter des macros depuis un tel fichier, choisissez Macros › Ajouter des macros à partir d’un fichier....

Le chapitre Aide sur les macros explique les macros en détail, y compris les macros AppleScript.
