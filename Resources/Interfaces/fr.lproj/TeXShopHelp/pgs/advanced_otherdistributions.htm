Coexister avec d’autres distributions TeX

Plusieurs installations de TeX peuvent cohabiter sur un même Mac : des années de TeX Live installées par MacTeX ou BasicTeX, un TeX Live installé avec son propre programme d’installation, ou TeX provenant de Homebrew ou de MacPorts. TeXShop utilise celle indiquée dans le champ « Moteurs TeX » de Réglages › Composition › Chemins, et Ghostscript d’après le champ « Ghostscript » situé en dessous.

Détecter les chemins

TeXShop peut remplir ces deux champs pour vous. À la première utilisation de TeXShop, et chaque fois que vous cliquez sur « Détecter les chemins… » dans le groupe « Chemins » de Réglages › Composition, il cherche TeX et Ghostscript aux emplacements habituels : les dossiers listés dans /etc/paths et /etc/paths.d et dans le PATH de TeXShop, /Library/TeX/texbin, les dossiers de TeX Live dans /usr/local/texlive, /opt/texlive et /Applications/TeXLive, les dossiers TeX de UpTeX.app et de pTeX.app, /usr/local/teTeX/bin, ainsi que les dossiers de Homebrew, de MacPorts et de Fink. Il vérifie que les programmes s’exécutent et liste les installations trouvées avec leur version, de la plus récente à la plus ancienne. La plus récente est sélectionnée, mais vous pouvez en choisir une autre, séparément pour TeX et pour Ghostscript. Les chemins ne changent que lorsque vous cliquez sur OK. Une installation située ailleurs peut toujours être saisie à la main dans les champs.

« Détecter les chemins… » ne modifie que « Moteurs TeX » et « Ghostscript ». Les fichiers de moteur qui indiquent leurs propres dossiers et le champ « Seconds moteurs TeX » restent inchangés.

TeX Live sans MacTeX

Les programmes d’installation de MacTeX et de BasicTeX font pointer /Library/TeX/texbin vers le TeX Live qu’ils installent ; les programmes qui utilisent ce chemin suivent donc l’installation la plus récente. Un TeX Live installé avec le programme d’installation de TeX Live lui-même ne modifie pas ce lien. Pour utiliser une telle installation, choisissez-la avec « Détecter les chemins… » ou saisissez le dossier de ses programmes, par exemple /usr/local/texlive/2026/bin/universal-darwin, dans « Moteurs TeX ».

Variables d’environnement

Certaines distributions définissent des variables d’environnement telles que TEXINPUTS ou TEXMFHOME dans les fichiers de démarrage du shell. TeX lit alors des fichiers dans d’autres dossiers que ceux auxquels vous vous attendez, et un même document peut être composé différemment dans Terminal et dans TeXShop. Si TeX utilise une mauvaise version d’un fichier, vérifiez d’abord ces variables ; dans Terminal, kpsewhich suivi du nom du fichier indique quelle copie TeX trouve.
