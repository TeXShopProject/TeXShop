BibTeX

BibTeX construit la bibliographie d’un document LaTeX à partir d’une base de données de références, un fichier portant l’extension .bib. Le document cite les entrées par leurs clés, et BibTeX ne liste que les entrées citées.

Une base de données mybibliography.bib contient des entrées comme

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

et le document les cite et indique le style et la base de données :

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

Exécuter BibTeX

  1. Composez le document. Les citations apparaissent sous la forme [?], et la bibliographie est absente.
  2. Choisissez Composition › BibTeX (⇧⌘B), ou choisissez BibTeX dans le menu local situé à côté du bouton « Composer » et cliquez sur « Composer ».
  3. Composez encore deux fois : la première composition ajoute la bibliographie, la seconde complète les citations.

La composition avec latexmk, par exemple avec le moteur pdflatexmk ou avec un profil réglé « Avec latexmk », exécute d’elle-même BibTeX et les passes supplémentaires.

Pour créer une nouvelle base de données dans TeXShop, choisissez le type bib dans le menu « Format de fichier » de la zone de dialogue d’enregistrement, afin que le fichier reçoive l’extension .bib. Une base de données peut aussi se trouver dans votre arborescence TeX personnelle, où tous les documents la trouvent ; consultez Ajouter des fichiers personnels à TeX Live.

Choisir le programme

Composition › BibTeX exécute la commande indiquée dans Réglages › Composition › « Outils associés » › « Moteur BibTeX », bibtex par défaut. Saisissez-y un autre programme avec les options dont il a besoin, par exemple biber pour les documents qui utilisent le paquet biblatex. Les profils du moteur règlent ce champ : pbibtex pour pLaTeX + dvipdfmx, upbibtex pour upLaTeX + dvipdfmx et LuaLaTeX (japonais), et bibtex pour les autres profils.

Pour choisir le programme d’un document, placez une ligne comme celle-ci dans l’une de ses vingt premières lignes :

% !BIB program = biber

Cette ligne a priorité sur le réglage. La forme % !BIB TS-program = est lue de la même façon.
