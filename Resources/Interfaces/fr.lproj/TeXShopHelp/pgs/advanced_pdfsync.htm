Synchroniser la source et l’aperçu

Cliquez sur un mot de la fenêtre source en maintenant la touche Commande enfoncée : la fenêtre d’aperçu défile jusqu’à l’endroit correspondant et le signale. Cliquez sur un endroit de la fenêtre d’aperçu en maintenant la touche Commande enfoncée : le fichier source s’ouvre, si nécessaire, à la ligne correspondante, qui est signalée. Les couleurs de ces deux marques se règlent dans Réglages › Thèmes › SyncTeX, sous « Aperçu » et « Source ».

SyncTeX

TeXShop synchronise avec SyncTeX. Lorsque TeX est exécuté avec l’option -synctex=1, il écrit à côté du PDF un fichier tel que Galois.synctex.gz, qui enregistre où chaque partie de la source a abouti sur la page. Les commandes de composition de Réglages › Composition, telles que les règlent les profils du moteur, et les moteurs que TeXShop place dans ~/Library/TeXShop/Engines et qui exécutent TeX utilisent déjà cette option. Un moteur que vous y ajoutez, y compris l’un des moteurs facultatifs du dossier Inactive, ne l’utilise que si sa commande la contient. Dans un moteur de votre cru, ajoutez -synctex=1 à l’appel de TeX (avec un ou deux tirets ; tous les moteurs acceptent les deux).

Le fichier synctex contient les chemins complets des fichiers source. Après le déplacement, la copie ou l’envoi d’un dossier de projet à quelqu’un d’autre, la synchronisation ne fait rien tant que le document n’a pas été recomposé.

SyncTeX n’est pas d’une exactitude absolue : l’endroit que vous cherchez peut se trouver un peu avant ou après la marque.

Projets à plusieurs fichiers

Dans un projet dont les fichiers de chapitre désignent le fichier racine avec % !TEX root (consultez Définir le fichier racine d’un projet), un Commande-clic dans un fichier de chapitre mène à l’endroit correspondant dans l’aperçu du document entier, et un Commande-clic dans l’aperçu ouvre le fichier de chapitre qui contient l’endroit cliqué. Lorsque Réglages › Composition › « Synchronisation de la source et de l’aperçu » › « Ouvrir les fichiers atteints par la synchro dans des onglets de la fenêtre du fichier racine » est activé, un fichier ouvert de cette façon s’ajoute sous forme d’onglet à la fenêtre du fichier racine au lieu de s’ouvrir dans sa propre fenêtre.

Méthode de synchronisation

Réglages › Composition › « Synchronisation de la source et de l’aperçu » › « Méthode de synchronisation » propose deux choix :

SyncTeX (recommandé)
Utilise le fichier synctex, comme décrit ci-dessus. C’est le choix par défaut.
Rechercher dans le PDF
Cherche dans le PDF le texte qui entoure le clic, et dans la source le texte qui entoure un clic dans l’aperçu. Cette méthode n’a pas besoin de fichier synctex, mais elle échoue là où le texte composé diffère de la source, comme dans les formules et dans le texte chargé de commandes. Pour trouver le fichier d’un endroit de l’aperçu, elle cherche dans les fichiers désignés par les commandes \include et \input du fichier racine. Pour les projets qui incluent des fichiers d’une autre manière, listez-les dans le fichier racine avec des lignes telles que 
% !TEX projectfile = chapter2.tex
% !TEX projectfile = /Users/me/Book/chapter3.tex
Un nom est un chemin complet ou un chemin relatif au fichier racine ; ces lignes peuvent se trouver n’importe où dans le fichier racine.

ConTeXt

Pour ConTeXt, ajoutez \setupsynctex[state=start,method=min] à la configuration du document et la ligne % !TEX useConTeXtSyncParser en haut du fichier racine ; TeXShop utilise alors le code de synchronisation propre à ConTeXt. Consultez ConTeXt et MetaPost.

Pour synchroniser avec une source ouverte dans un autre éditeur, consultez Utiliser un éditeur externe.
