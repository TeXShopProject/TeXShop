Inclure des images

Lorsqu’il compose directement en PDF, LaTeX inclut des images aux formats PDF, PNG et JPEG. Le PDF garde les dessins au trait et le texte nets à toutes les tailles ; utilisez-le pour les schémas et les graphiques. PNG et JPEG conviennent aux captures d’écran et aux photographies.

Chargez le paquet graphicx dans le préambule :

\usepackage{graphicx}

et incluez une image à l’endroit où elle doit apparaître :

\includegraphics[width=0.8\textwidth]{diagram}

L’extension peut être omise ; LaTeX cherche alors diagram.pdf, diagram.png, diagram.jpg et les autres formats qu’il connaît. Modifiez la largeur pour changer la taille de l’image. Placez les fichiers d’images dans le dossier du document, ou indiquez un chemin relatif à celui-ci, comme figures/diagram.

Fichiers EPS

TeX Live convertit automatiquement les images EPS en PDF pendant la composition, à l’aide d’epstopdf, à condition que le document charge graphicx. Le fichier converti, diagram-eps-converted-to.pdf, est écrit à côté du fichier EPS et utilisé dès lors.

Un fichier EPS ouvert dans TeXShop est aussi converti : TeXShop écrit un fichier PDF du même nom à côté de lui, ou dans un dossier temporaire quand le dossier du fichier EPS n’est pas accessible en écriture, et l’affiche.

Fichiers TIFF

LaTeX ne peut pas inclure de fichiers TIFF. Choisissez Fichier › Convertir TIFF pendant qu’une fenêtre source est active : une zone de dialogue montre le dossier du document, où seuls les fichiers TIFF peuvent être choisis. Sélectionnez-en un ou plusieurs et cliquez sur « Convertir ». Chacun est converti en un fichier PNG du même nom dans le même dossier ; les fichiers TIFF sont conservés.

Composer via DVI

Les documents qui utilisent du code PostScript, par exemple avec le paquet pstricks, sont composés avec la méthode « Via DVI », qui exécute dvips par défaut. Les images sont alors incluses au format EPS ; les fichiers PDF, PNG et JPEG ne peuvent pas être utilisés. Les profils du moteur dont le nom se termine par « + dvipdfmx » composent aussi « Via DVI », mais ils exécutent dvipdfmx au lieu de dvips ; avec \usepackage[dvipdfmx]{graphicx}, les fichiers PDF, PNG et JPEG peuvent y être utilisés. Voir Mode de composition alternatif.
