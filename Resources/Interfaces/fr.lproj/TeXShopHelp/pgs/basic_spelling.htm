Vérifier l’orthographe

TeXShop vérifie l’orthographe avec le correcteur orthographique et les dictionnaires de macOS. La vérification adaptée à LaTeX est activée d’emblée : elle vérifie le texte et ignore les commandes TeX, les mathématiques, les commentaires et les arguments de commandes comme \label, \ref, \cite et \usepackage, ainsi que les arguments qui ne sont pas de la prose, comme les clés, les couleurs et les unités, des paquets courants. Les commandes que le document définit avec \newcommand, \def et les commandes similaires sont lues ; un argument qu’une définition transmet à \ref ou place dans des mathématiques est donc ignoré lui aussi. Le texte marqué comme étant dans une autre langue, par exemple avec \foreignlanguage, est vérifié dans cette langue, mais n’est pas souligné pendant la saisie.

Vérifier un document

Les mots mal orthographiés sont soulignés pendant la saisie tant que Édition › Orthographe et grammaire › Vérifier l’orthographe lors de la saisie est activé. Pour parcourir le document mot par mot, choisissez Édition › Orthographe et grammaire › Afficher l’orthographe et la grammaire (⌘:) : la fenêtre montre le premier mot mal orthographié après le point d’insertion. Cliquez sur « Rechercher suivant » dans la fenêtre, ou choisissez « Vérifier le document maintenant » (⌘;), pour passer au suivant. Maintenez la touche Option enfoncée en le faisant pour utiliser la recherche de macOS, qui n’ignore aucun balisage.

Pour remplacer un mot partout, saisissez le remplacement dans le champ « Remplacement pour Tout remplacer » de la fenêtre, ou sélectionnez une suggestion, puis cliquez sur « Tout remplacer » ; une seule annulation reprend la modification. Après avoir modifié le document ou sélectionné un autre texte, cliquez de nouveau sur « Rechercher suivant » avant de remplacer un mot. Si vous avez modifié le champ « Remplacement pour Tout remplacer » et voulez une suggestion qui était sélectionnée, sélectionnez d’abord une autre suggestion, puis celle-là ; quand il n’y a qu’une suggestion, saisissez-la. « Oublier des mots appris… », dans le sous-menu « Orthographe et grammaire », énumère les mots du document qui ont été appris pour la langue en cours, et retire du dictionnaire ceux que vous sélectionnez. « Corriger l’orthographe automatiquement », dans le même sous-menu, modifie les mots pendant la saisie ; cette option est désactivée au départ, ce qui convient à TeX, où elle modifierait aussi les commandes.

Réglages › Orthographe

Dans le groupe « Vérifier l’orthographe », « Vérifier l’orthographe lors de la saisie » détermine si les mots mal orthographiés sont soulignés dans un document à son ouverture, « Correction automatique » détermine si « Corriger l’orthographe automatiquement » est activé dans un document à son ouverture, et « Dictionnaire » est décrit plus bas. Le groupe « Méthode » choisit la façon dont la source TeX est vérifiée :

« Utiliser la vérification adaptée à LaTeX (recommandé) »
La méthode décrite plus haut. « Modifier les exclusions LaTeX… », au bout de sa ligne, ouvre les règles qui indiquent ce qui est ignoré.
« Ancienne méthode »
macOS vérifie tout, sauf ce qu’excluent les trois options placées en dessous : « Ignorer les commandes LaTeX », « Ne pas vérifier les paramètres », qui ignore les paramètres de certaines commandes contenant des mots particuliers, comme \usepackage, et « Ne pas vérifier les commentaires ». Ces options ne fonctionnent que si le surlignage syntaxique est activé, et « Vérifier le document maintenant » n’en tient pas compte.

La méthode adaptée à LaTeX vérifie les documents qui n’ont pas encore été enregistrés et les fichiers dont l’extension est tex, ltx, latex, dtx, ins, sty, cls, clo, bbx, cbx ou lbx. Les autres fichiers, comme les fichiers Sweave, sont toujours vérifiés avec l’ancienne méthode.

Règles d’exclusion

Les règles de la vérification adaptée à LaTeX se trouvent dans le fichier ~/Library/TeXShop/SpellCheck/SpellingExclusions.txt. Ouvrez-le avec « Modifier les exclusions LaTeX… » dans les Réglages, ou avec Édition › Orthographe et grammaire › Modifier les exclusions orthographiques… ; il s’ouvre dans TeXShop, et son en-tête explique le format. Par exemple, ces lignes ignorent le premier argument d’une commande \mycommand et le contenu de l’environnement proof :

skip-args  1  mycommand
skip-body  proof

Les modifications prennent effet à la vérification suivante. Si le fichier est supprimé, TeXShop crée une nouvelle copie du fichier par défaut à son prochain démarrage. Pour ne rien ignorer du tout, n’y laissez que des lignes de commentaire.

Dictionnaires

« Dictionnaire », dans Réglages › Orthographe, choisit le dictionnaire des documents. Un nouveau choix s’applique aussi aux documents ouverts, sauf à ceux dont le dictionnaire a été choisi par une ligne % !TEX spellcheck ou dans la fenêtre « Orthographe et grammaire ». Le menu présente chaque langue sous son propre nom, comme Deutsch ou Français, avec son code, comme de ou fr_CA, en bulle d’aide. « Automatique par langue » laisse macOS choisir la langue d’après le texte.

Pour utiliser un autre dictionnaire pour un document, choisissez-le dans le menu local en bas de la fenêtre « Orthographe et grammaire » pendant que ce document est au premier plan. Chaque document ouvert garde son propre dictionnaire, et la fenêtre change quand vous changez de document. Le choix n’est pas conservé à la fermeture du document.

Pour qu’un document ait son dictionnaire à chaque ouverture, placez une ligne comme celle-ci parmi ses 20 premières lignes :

% !TEX spellcheck = de-DE

La valeur est un code de langue, comme dans les bulles d’aide du menu « Dictionnaire » : fr pour le français, ou fr_CA pour le français du Canada ; elle peut aussi s’écrire avec un trait d’union, comme fr-CA. La ligne est lue à l’ouverture du document ; après l’avoir ajoutée, enregistrez donc le document, fermez-le et rouvrez-le. Dans un document avec des fichiers de chapitre, placez la ligne dans chaque fichier.

Voir Rechercher dans les réglages pour trouver des réglages dans la fenêtre Réglages.
