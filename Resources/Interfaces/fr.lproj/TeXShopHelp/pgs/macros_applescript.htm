Macros AppleScript

Une macro dont le contenu commence par

--AppleScript

ou par

--AppleScript direct

s’exécute comme un AppleScript lorsqu’elle est choisie ; la casse des lettres n’a pas d’importance. Par exemple, Macros › Applescript › View pdf with Preview ouvre le PDF du document actif dans Aperçu, une fois le PDF composé. Son contenu est

--AppleScript direct

tell application "Preview"
  activate
  open POSIX file #PDFPATH#
end tell

Avant l’exécution du script, TeXShop remplace #PDFPATH# par le chemin du PDF ; Définir des macros AppleScript liste toutes les chaînes de ce type. « View pdf with Adobe Acrobat Reader DC », dans le même sous-menu, fait la même chose avec Adobe Acrobat.

--AppleScript direct et --AppleScript

Un script qui commence par --AppleScript direct est exécuté par TeXShop lui-même. Pendant son exécution, TeXShop ne répond à rien d’autre ; le script ne peut donc pas demander à TeXShop une action qui pourrait nécessiter une intervention de votre part. Par exemple, il ne peut pas demander à TeXShop d’exécuter LaTeX : si le fichier contenait une erreur, la console attendrait votre réponse, que TeXShop ne pourrait pas recevoir.

Un script qui commence par --AppleScript est exécuté par ScriptRunner, un petit programme intégré à TeXShop. Un tel script peut demander à TeXShop des actions qui pourraient nécessiter votre intervention, car ScriptRunner attend tandis que TeXShop reste actif.

Ainsi, --AppleScript direct convient aux macros simples, tandis que --AppleScript est nécessaire pour les scripts qui composent ou qui travaillent d’une autre façon avec TeXShop.
