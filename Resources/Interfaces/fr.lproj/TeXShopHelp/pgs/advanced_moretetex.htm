En savoir plus sur TeX Live

Où TeX Live est installé

MacTeX installe TeX Live dans /usr/local/texlive/2026, et BasicTeX dans /usr/local/texlive/2026basic. TeX Live paraît une fois par an, et chaque année s’installe dans son propre dossier, par exemple 2027 ; plusieurs années peuvent donc cohabiter sur le Mac. Pour en supprimer une, faites glisser son dossier dans la Corbeille.

Le dossier /usr/local est masqué dans le Finder. Pour en voir le contenu, choisissez Aller › Aller au dossier… dans le Finder et tapez le chemin.

Comment TeXShop trouve TeX

TeXShop exécute TeX depuis le dossier indiqué dans le champ « Moteurs TeX » de Réglages › Composition › Chemins. La valeur par défaut est /Library/TeX/texbin, un lien que les programmes d’installation de MacTeX et de BasicTeX font pointer vers les programmes du TeX Live qu’ils viennent d’installer. Quand une nouvelle année de TeX Live est installée, le lien la suit, et TeXShop utilise le nouveau TeX sans aucune modification des réglages.

Pour utiliser une autre installation, saisissez le dossier de ses programmes dans « Moteurs TeX », par exemple /usr/local/texlive/2026/bin/universal-darwin, ou cliquez sur « Détecter les chemins… » pour choisir parmi les installations que TeXShop trouve ; consultez Coexister avec d’autres distributions TeX.

Laisser TeX Live tel quel

Les dossiers de TeX Live appartiennent au système, et une mise à jour ou une nouvelle année de TeX Live les remplace. N’y ajoutez ni n’y modifiez aucun fichier. Placez plutôt vos propres fichiers de style, classes et bibliographies dans votre arborescence personnelle, où TeX les trouve en premier et où les mises à jour ne les touchent pas ; consultez Ajouter des fichiers personnels à TeX Live.

Documentation

TeX Live contient la documentation de presque tous les paquets. Aide › Afficher l'aide pour le package... ouvre la documentation d’un paquet d’après son nom, par exemple hyperref ou tikz. Aide › Documentation de TeX Live indique où trouver en ligne le guide de TeX Live et d’autres documentations.
