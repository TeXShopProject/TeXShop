Préliminaires

TeXShop est une application macOS pour écrire des documents en TeX et en LaTeX. Vous écrivez la source dans une fenêtre d’édition, vous la composez d’un clic ou avec ⌘T, et vous lisez le résultat dans une fenêtre d’aperçu placée à côté. Un clic en maintenant la touche Commande enfoncée dans l’une des deux fenêtres montre l’endroit correspondant dans l’autre.

TeXShop ne contient pas TeX. Il exécute les programmes d’une distribution TeX, en général TeX Live, que le programme d’installation MacTeX installe sur le Mac ; voir Installer TeX Live. TeXShop nécessite macOS 14.6 ou ultérieur.

Sauf si un autre profil du moteur est choisi au premier lancement, TeXShop compose les documents LaTeX avec pdfLaTeX, qui écrit directement un fichier PDF, et la fenêtre d’aperçu affiche ce fichier. C’est un fichier PDF ordinaire, que l’on peut envoyer à d’autres personnes et lire sur n’importe quel ordinateur. Pour composer avec un autre moteur, comme LuaLaTeX, choisissez un profil du moteur dans les Réglages ou indiquez le moteur en tête du document ; voir Composer des documents.

Contenu de cette aide

Aide de base
L’installation de TeX Live et de TeXShop, la composition, la fenêtre d’aperçu, l’édition, la recherche et le remplacement, la vérification orthographique, les raccourcis de saisie et la complétion des commandes, les palettes, les macros, l’impression et les Réglages.
Aide avancée
Les moteurs de composition, les projets avec un fichier racine, BibTeX et MakeIndex, les encodages, les éditeurs externes, le surlignage syntaxique et d’autres sujets.
Aide sur les macros
Le menu Macros, l’éditeur de macros et les macros écrites en AppleScript.
Comment configurer TeXShop ?
Les réglages recommandés, les nouveaux éléments pour ~/Library/TeXShop, les réglages cachés, les raccourcis de saisie et les raccourcis clavier.

Le menu Aide ouvre d’autres documents, en anglais. Le Manuel de TeXShop décrit en détail toutes les fonctions. Premiers pas avec TeXShop est une courte introduction pour les nouveaux utilisateurs. À propos de cette version indique ce qu’il faut faire après une mise à jour, s’il y a quelque chose à faire, et Changements énumère ce que chaque version a modifié. Commentaires spéciaux et réglages cachés énumère les lignes de commentaire magiques, comme % !TEX program =, et les réglages que la fenêtre Réglages n’affiche pas.

Le site web de TeXShop est texshop.app.
