Préliminaires

Les macros de TeXShop et l’éditeur de macros ont été écrits à l’origine par Mitsuhiro Shishikura ; les macros LaTeX par défaut ont été créées par Mitsuhiro Shishikura et Hirokazu Ogawa.

Les macros figurent dans le menu Macros et dans le menu local « Macros » de la barre d’outils de la fenêtre source. Il en existe deux sortes. Les macros de texte insèrent du texte dans la source, comme les boutons de la palette LaTeX. Les macros AppleScript exécutent un AppleScript ; consultez Macros AppleScript.

Où sont conservées les macros

Les macros sont stockées dans

~/Library/TeXShop/Macros/Macros_Latex.plist

et le menu Macros les affiche pour tous les moteurs de composition. Un ensemble distinct peut être conservé pour les moteurs intégrés plain TeX, BibTeX, MakeIndex et MetaPost : lorsque l’un d’eux est choisi pour le document, l’éditeur de macros enregistre ses macros dans un fichier qui lui est propre, comme Macros_Tex.plist, et laisse Macros_Latex.plist inchangé.

Les fichiers de macros sont des fichiers texte ordinaires, mais il est préférable de les modifier avec l’éditeur de macros : choisissez Macros › Ouvrir l'éditeur de macros.... Définir de nouvelles macros explique comment ajouter, supprimer et nommer des macros, et comment leur attribuer des raccourcis.

Si le dossier Macros est absent

Si le dossier Macros est absent au démarrage de TeXShop, TeXShop le recrée avec les macros par défaut. Si Macros_Latex.plist est endommagé, TeXShop le remplace par sa propre copie au démarrage, sans message, et conserve le fichier endommagé dans ~/Library/TeXShop/Backups. Pour repartir des macros par défaut, quittez TeXShop, déplacez le dossier Macros sur le bureau et relancez TeXShop ; le dossier déplacé conserve vos anciennes macros.

Partager des macros

Tant que l’éditeur de macros est ouvert, le menu Macros comporte deux commandes supplémentaires. « Enregistrer la sélection dans un fichier... » enregistre les macros sélectionnées dans un fichier distinct, que vous pouvez donner à d’autres personnes. « Ajouter des macros à partir d’un fichier... » ajoute les macros d’un tel fichier à votre liste ; organisez-les ensuite à votre guise dans l’éditeur de macros.
