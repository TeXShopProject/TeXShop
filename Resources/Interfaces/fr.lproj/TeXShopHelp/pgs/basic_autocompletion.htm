Raccourcis de saisie

Les raccourcis de saisie font qu’un caractère saisi insère un autre texte. Avec la liste fournie avec TeXShop, saisir ^ donne ^{} avec le point d’insertion entre les accolades, saisir " donne les guillemets TeX ``'' autour du point d’insertion, et saisir ä donne \"a. Un raccourci de saisie peut aussi placer le texte sélectionné à l’intérieur : sélectionnez un mot et saisissez ^ pour obtenir ^{mot}. La liste compte 45 raccourcis de saisie.

Les raccourcis de saisie sont désactivés au départ. Activez « Utiliser les raccourcis de saisie (valeur initiale des nouveaux documents) » dans Réglages › Clavier pour qu’ils soient activés dans chaque document que vous ouvrez. Source › Raccourcis de saisie les active ou les désactive pour le document au premier plan, par exemple pour saisir tel quel un caractère qui a un raccourci de saisie. L’élément « Raccourcis de saisie », que l’on peut ajouter à la barre d’outils, fait de même.

La liste des raccourcis de saisie

Le groupe « Raccourcis de saisie » de Réglages › Clavier énumère les raccourcis de saisie, avec pour chacun le « Caractère saisi » et le « Texte produit ». Double-cliquez sur une cellule pour la modifier ; cliquez sur + sous la liste pour ajouter un raccourci de saisie et sur − pour supprimer ceux qui sont sélectionnés, et faites glisser les lignes pour changer leur ordre. Un caractère saisi est un caractère unique. Les modifications sont enregistrées aussitôt et agissent aussi dans les documents ouverts ; Édition › Annuler les reprend.

Dans un texte produit, les éléments spéciaux apparaissent sous forme de petites étiquettes : le texte sélectionné, l’emplacement du point d’insertion, le texte du presse-papiers, un repère (•) pour Édition › Repères, un saut de ligne et une tabulation. Ajoutez-les avec « Insérer » sous la liste, ou saisissez-les : #SEL#, #INS#, #PASTE# et •, Option-Retour pour un saut de ligne et Option-Tab pour une tabulation. Le bouton ? les énumère tous.

Une coche dans la colonne « Coller » applique aussi le raccourci de saisie au texte que vous collez dans la source ou que vous y déposez : chaque occurrence du caractère saisi est remplacée par le texte produit. Comme pour la saisie, cela ne se produit que lorsque les raccourcis de saisie sont activés pour le document. Un raccourci de saisie dont le texte produit contient la sélection, le point d’insertion, le presse-papiers ou un repère ne peut pas être coché.

Le symbole yen

Sur un clavier japonais, la touche de la barre oblique inverse peut produire un symbole yen (¥). Dans la liste fournie avec TeXShop, ¥ donne une seule barre oblique inverse et sa case « Coller » est cochée. Ainsi, quand l’encodage des nouveaux documents est UTF-8, il suffit d’activer les raccourcis de saisie pour qu’un ¥ saisi ou collé dans la source devienne \. Si votre liste provient d’une version antérieure de TeXShop, réglez vous-même le texte produit de ¥ sur une seule barre oblique inverse et cochez sa case « Coller ».

La liste est enregistrée dans ~/Library/TeXShop/Keyboard/autocompletion.plist ; voir Modifier les raccourcis de saisie.
