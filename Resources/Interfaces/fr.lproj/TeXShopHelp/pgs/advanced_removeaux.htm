Supprimer les fichiers AUX

Lorsque LaTeX compose Galois.tex, il écrit des fichiers auxiliaires tels que Galois.aux, Galois.toc et Galois.log, que la composition suivante lit pour les renvois, la table des matières, etc. Si la composition s’arrête en cours de route, par exemple après une erreur, ces fichiers peuvent rester endommagés, et la composition suivante signale des erreurs qui ne sont pas dans la source, souvent juste avant \begin{document}. Placer les fichiers auxiliaires dans la Corbeille puis recomposer règle le problème.

Placer les fichiers dans la Corbeille

  • Fichier › Fichiers AUX à la corbeille (⌃⌘A), ou le bouton « Fichiers AUX à la corbeille » de la console, place les fichiers auxiliaires du document dans la Corbeille.
  • Composition › Fichiers AUX à la corbeille et composer (⌥⌘T) fait la même chose, puis compose. Dans le menu Composition, cette commande apparaît à la place de « Composer » tant que vous maintenez la touche Option enfoncée.

Les fichiers placés dans la Corbeille sont ceux du dossier de la source qui portent son nom et l’une de ces extensions :

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

Les fichiers que SyncTeX laisse avec (busy) à la fin de leur nom quand la composition est interrompue sont également placés dans la Corbeille. Le fichier .bbl de BibTeX est conservé.

Dans un projet dont les fichiers de chapitre désignent un fichier racine avec % !TEX root, ce sont les fichiers du fichier racine qui sont placés dans la Corbeille, y compris lorsque la commande est donnée depuis un fichier de chapitre.

Variantes

  • Maintenez la touche Maj enfoncée en choisissant « Fichiers AUX à la corbeille » ou en cliquant sur le bouton pour placer aussi le fichier PDF du document dans la Corbeille. D’habitude, l’ancien PDF est conservé, afin que la fenêtre d’aperçu ait quelque chose à afficher si la composition échoue.
  • Maintenez la touche Option enfoncée en choisissant « Fichiers AUX à la corbeille » ou en cliquant sur le bouton pour nettoyer tout un projet : tous les fichiers portant l’une des extensions ci-dessus, dans le dossier du fichier racine et dans tous les dossiers qu’il contient, sont placés dans la Corbeille, quel que soit leur nom. Cela supprime aussi les fichiers .aux que \include écrit pour les chapitres situés dans des sous-dossiers.

Deux réglages cachés modifient ce comportement. Pour ajouter des extensions à la liste, par exemple dvi, tapez dans Terminal

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

et pour revenir à la liste standard

defaults write TeXShop OtherTrashExtensions -array

Pour faire du comportement avec Option le comportement standard de « Fichiers AUX à la corbeille » :

defaults write TeXShop AggressiveTrashAUX YES
