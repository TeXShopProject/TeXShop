Créer et utiliser des formats TeX

Un fichier de format (extension .fmt) est un instantané de TeX après la lecture d’un ensemble de macros. LaTeX lui-même est un format : TeX le charge en un instant au lieu de relire chaque fois les sources de LaTeX. Vous pouvez créer votre propre format à partir d’un long préambule, pour que la composition démarre plus vite, ou utiliser un format fourni par un projet ou par un organisme.

Un format ne fonctionne qu’avec le moteur et la version de TeX Live qui l’ont créé. Un format créé avec pdfLaTeX de TeX Live 2026 ne peut être utilisé ni par XeLaTeX ni par une autre année de TeX Live ; recréez-le après l’installation d’un nouveau TeX Live.

Créer un format

Placez dans un fichier les lignes que le format doit contenir, en terminant par \dump. Par exemple, uo.tex :

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

Dans Terminal, placez-vous dans le dossier de ce fichier et tapez

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Cette commande charge le format LaTeX, lit uo.tex et écrit uo.fmt. Un document composé avec ce format omet les lignes contenues dans le format et commence par \begin{document}.

Utiliser un format dans TeXShop

  1. Déplacez uo.fmt dans le dossier ~/Library/texmf/web2c, en créant les dossiers si nécessaire, afin que TeX le trouve depuis n’importe quel dossier.
  2. Dans le Finder, ouvrez ~/Library/TeXShop/Engines (TeXShop › Ouvrir ~/Bibliothèque/TeXShop), dupliquez un moteur tel que XeLaTeX.engine et renommez la copie, par exemple Oregon.engine. Ce nom apparaît dans TeXShop et n’a pas besoin de correspondre au format.
  3. Ouvrez la copie dans TeXShop et modifiez sa dernière ligne pour que le moteur devienne : 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Les documents ouverts ensuite affichent Oregon dans le menu local situé à côté du bouton « Composer ». Pour utiliser le format pour un document, quel que soit le choix fait à cet endroit, ajoutez cette ligne en haut du fichier source :

% !TEX program = Oregon

Pour en faire le choix par défaut, choisissez « Fichier de moteur » dans Réglages › Composition › Moteur › « Composer les nouveaux documents avec », et Oregon dans le menu « Fichier de moteur ». Consultez Ajouter des moteurs de composition.

Pour un format plain TeX, utilisez pdftex au lieu de pdflatex dans le moteur. Pour un format destiné à être utilisé via DVI, le moteur doit aussi convertir le fichier DVI en PDF, par exemple avec dvipdfmx "${1:r}.dvi" dans un script zsh, car TeXShop affiche le fichier PDF qui porte le nom du fichier source.
