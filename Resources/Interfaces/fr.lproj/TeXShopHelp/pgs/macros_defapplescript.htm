Définir des macros AppleScript

AppleScript est un langage à part entière. L’AppleScript Language Guide d’Apple, sur le site web d’Apple destiné aux développeurs, le décrit en détail.

Chemins et nom du document

Avant d’exécuter une macro AppleScript, TeXShop remplace les chaînes suivantes par le chemin d’un fichier du document actif, entre guillemets doubles :

#FILEPATH#
le fichier source
#TEXPATH#
le fichier .tex
#NAMEPATH#
le fichier source sans son extension
#FOLDERPATH#
le dossier qui contient la source, terminé par une barre oblique
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
les fichiers .pdf, .dvi, .ps, .log et .aux
#INDPATH#, #BBLPATH#, #HTMLPATH#
les fichiers .ind, .bbl et .html

Par exemple, si #FILEPATH# donne /Users/name/Projects/Fourier/Fourier.tex, #FOLDERPATH# donne /Users/name/Projects/Fourier/. Si le document n’a jamais été enregistré, #FILEPATH# est une chaîne vide.

#DOCUMENTNAME# est remplacé par le nom du document tel que l’affiche le titre de la fenêtre source : avec son extension, ou sans elle si l’extension est masquée. Un script l’utilise pour s’adresser au document qui l’a appelé :

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

Commandes de TeXShop

Un AppleScript peut accomplir son travail de deux façons : il peut exécuter des commandes shell, comme décrit dans Écrire des scripts avec des commandes shell, ou appeler les commandes propres à TeXShop, comme décrit dans Écrire des scripts avec les commandes de composition de TeXShop. TeXShop comprend notamment les commandes suivantes :

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

Les six premières commandes composent en continu, sans s’arrêter aux erreurs. Les six suivantes composent aussi, mais s’arrêtent à une erreur afin que vous puissiez répondre dans la console. Une commande de composition rend la main aussitôt, avant la fin de la composition. taskdone renvoie NO tant que la composition est en cours et YES lorsqu’elle est terminée. refreshpdf et refreshtext font afficher aux fenêtres PDF et texte la dernière version de leurs fichiers. goto line sélectionne une ligne de la source :

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
