Imprimer

Pour imprimer le document composé, choisissez Fichier › Imprimer... (⌘P) dans la fenêtre d’aperçu ou dans la fenêtre source. Dans un projet avec un fichier racine, c’est le document racine composé qui est imprimé.

La zone de dialogue d’impression a une section TeXShop qui propose les mêmes choix qu’Aperçu d’Apple. Avec « Rotation automatique », chaque page est tournée pour s’adapter au papier ; une page au format paysage s’imprime donc de côté sur du papier en portrait. Avec « Ajuster », chaque page est mise à l’échelle pour tenir sur le papier ; choisissez plutôt « Échelle » pour imprimer à un pourcentage fixe. Les deux sont activés au départ, et les choix de la dernière impression sont conservés pour le document tant qu’il est ouvert. L’orientation du papier suit celle de la première page.

Pour imprimer le texte source, choisissez Fichier › Imprimer les sources.... Fichier › Format d’impression... choisit le format du papier.
