Écrire des scripts avec les commandes de composition de TeXShop

Un document comportant une bibliographie nécessite une suite de compositions : LaTeX écrit le fichier .aux, BibTeX l’utilise pour écrire les fichiers .bbl et .blg, LaTeX s’exécute de nouveau pour ajouter la bibliographie au document, puis une fois encore pour mettre à jour les références qui y renvoient. Vos projets peuvent nécessiter des suites semblables, et une macro AppleScript peut les exécuter pour vous.

La macro Macros › Applescript › Run LaTeX, BibTeX, Then LaTeX Twice, fournie avec TeXShop, montre comment faire. Voici son contenu :

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

La première ligne fait de ce script une macro AppleScript exécutée par ScriptRunner ; elle peut donc demander à TeXShop de composer (consultez Macros AppleScript). Les lignes suivantes vérifient #FILEPATH#, le chemin complet du fichier source. C’est une chaîne vide lorsque le document n’a pas encore été enregistré ; dans ce cas, le script vous demande de l’enregistrer et s’arrête.

Le script désigne ensuite le document par #DOCUMENTNAME#. TeXShop enregistre lui-même le document au lancement d’une commande de composition ; le script n’a donc pas besoin de l’enregistrer.

Les commandes restantes exécutent latexinteractive, bibtex, latex et latex. Une commande de composition rend aussitôt la main au script, avant la fin de la composition ; c’est pourquoi, après chaque commande, une boucle repeat attend que taskdone indique que la tâche est terminée. La ligne delay 2 fait marquer au script une pause entre deux vérifications, au lieu d’interroger sans cesse et de ralentir l’ordinateur. Les commandes sont listées dans Définir des macros AppleScript.
