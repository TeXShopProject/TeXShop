Signaler des bogues

Pour signaler un problème ou proposer une amélioration, ouvrez un ticket (issue) sur GitHub :

https://github.com/TeXShopProject/TeXShop/issues

Cherchez d’abord parmi les tickets ouverts et fermés : le problème est peut-être déjà connu ou corrigé dans une version plus récente. Ouvrir un ticket nécessite un compte GitHub.

Un signalement que l’on peut traiter rapidement indique :

  • la version de TeXShop (TeXShop › À propos de TeXShop) et celle de macOS ;
  • ce que vous avez fait, ce que vous attendiez et ce qui s’est produit à la place ;
  • pour les problèmes de composition, un court fichier source qui montre le problème, ainsi que la sortie de la console ou le fichier journal ;
  • pour les problèmes de fenêtres ou de menus, une capture d’écran ou un court enregistrement de l’écran.

Les questions sur TeX, sur les paquets LaTeX ou sur TeX Live lui-même sont plutôt à poser dans les lieux énumérés dans Sites web utiles, comme TeX Stack Exchange.
