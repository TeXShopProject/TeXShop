Comprendre les macros par défaut

Le meilleur moyen de comprendre les macros par défaut est de les examiner dans l’éditeur de macros (Macros › Ouvrir l'éditeur de macros...) : sélectionnez une macro dans la liste, et son contenu apparaît à côté.

Supposons par exemple que vous vouliez un environnement theorem. Tapez le mot theorem, sélectionnez-le et choisissez Macros › Insert Begin/End. Le mot est remplacé par

\begin{theorem}

\end{theorem}

et le point d’insertion est placé sur la ligne intermédiaire.

Insert Begin/End est une macro AppleScript (consultez Macros AppleScript). Une macro de texte qui fait la même chose lorsqu’un mot est sélectionné s’écrit :

\begin{#SEL#}
#INS#
\end{#SEL#}

Espaces réservés dans les macros de texte

Le texte d’une macro de texte est inséré dans la source, avec les remplacements suivants :

#SEL#
est remplacé par le texte qui était sélectionné lorsque la macro a été choisie, ou par rien si aucun texte n’était sélectionné.
#INS#
indique où va le point d’insertion. En son absence, le point d’insertion est placé à la fin du texte inséré.
#PASTE#
est remplacé par le texte du presse-papiers, ou par rien si le presse-papiers ne contient pas de texte.
•
est un repère, vers lequel Édition › Repères permet de se déplacer.

Dans l’éditeur de macros, ces espaces réservés s’affichent sous forme de jetons arrondis ; Définir de nouvelles macros explique comment les insérer. Avec ces connaissances, les macros par défaut sont faciles à comprendre et à modifier.
