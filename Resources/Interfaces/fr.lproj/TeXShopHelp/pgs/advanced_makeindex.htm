MakeIndex

MakeIndex trie les entrées d’index d’un document LaTeX et écrit l’index. Pour ajouter un index à un document :

  1. Placez \usepackage{makeidx} et \makeindex dans le préambule.
  2. Placez \printindex à l’endroit où l’index doit apparaître, souvent juste avant \end{document}.
  3. Marquez les entrées dans le texte : 
    There are many animals in the world\index{animal}.
Examples include bears\index{animal!bear}
and tigers\index{animal!tiger}.

Pour créer l’index, composez le document, puis choisissez Composition › MakeIndex (⇧⌘I), ou choisissez MakeIndex dans le menu local situé à côté du bouton « Composer » et cliquez sur « Composer », puis composez de nouveau. La composition avec latexmk exécute MakeIndex d’elle-même.

MakeIndex exécute le programme indiqué dans Réglages › Composition › « Outils associés » › « Programme d’index », suivi du nom du fichier idx. La valeur par défaut est makeindex. Indiquez un autre programme, comme mendex ou upmendex pour les documents japonais, avec les options dont il a besoin, par exemple upmendex -s mystyle.ist. Les profils du moteur règlent ce champ : makeindex pour les profils occidentaux, mendex pour pLaTeX + dvipdfmx, et upmendex pour upLaTeX + dvipdfmx et LuaLaTeX (japonais).
