Ajouter des fichiers personnels à TeX Live

Les fichiers de style, les classes, les bases de données bibliographiques et les autres fichiers qui ne font pas partie de TeX Live se placent dans votre arborescence TeX personnelle, le dossier texmf du dossier Bibliothèque de votre dossier de départ : ~/Library/texmf. Tous les programmes de TeX Live y trouvent les fichiers, et ceux-ci ont priorité sur les fichiers du même nom de TeX Live lui-même. Il n’y a rien à enregistrer après l’ajout d’un fichier : la composition suivante le trouve.

Le dossier Bibliothèque est masqué dans le Finder. Pour l’ouvrir, choisissez Aller › Aller au dossier… dans le Finder et tapez ~/Library. Créez-y le dossier texmf s’il n’existe pas encore.

Avant d’ajouter un paquet

La plupart des paquets de CTAN font déjà partie de TeX Live, et MacTeX les installe tous. Pour savoir si TeX dispose déjà d’un fichier, choisissez Fichier › Ouvrir le fichier style... dans TeXShop et tapez son nom, par exemple hyperref.sty ; TeXShop ouvre le fichier que TeX utiliserait. N’ajoutez un paquet à votre arborescence personnelle que si TeX Live ne l’a pas, ou si vous avez besoin de votre propre version. Comme votre copie est prioritaire, supprimez-la quand TeX Live a rattrapé son retard ; sinon, vous continuez à utiliser l’ancienne version.

Où placer les fichiers

Les dossiers à l’intérieur de texmf suivent la même structure que TeX Live. Créez les dossiers dont vous avez besoin :

DossierContenu
tex/latex/paquets et classes LaTeX (.sty, .cls), chaque paquet dans son propre dossier
tex/plain/fichiers pour plain TeX
tex/generic/fichiers qui fonctionnent avec n’importe quel format
bibtex/bib/bases de données bibliographiques (.bib)
bibtex/bst/styles bibliographiques (.bst)
doc/documentation des paquets que vous avez ajoutés ; Aide › Afficher l’aide d’un paquet... la trouve à cet endroit

Par exemple, un paquet contenant vos propres macros et votre base de données bibliographique seraient enregistrés ainsi :

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

Dès lors, \usepackage{mymacros} et \bibliography{mybibliography} fonctionnent dans tous les documents, où qu’ils soient enregistrés.

Vérifier le dossier

Pour savoir quel dossier votre TeX utilise comme arborescence personnelle, tapez dans Terminal

kpsewhich -var-value TEXMFHOME

Sur un Mac, il s’agit de ~/Library/texmf, sauf si l’installation a été configurée autrement. Pour savoir quelle copie d’un fichier TeX lira, tapez par exemple kpsewhich mymacros.sty.

N’ajoutez pas de fichiers aux dossiers de TeX Live lui-même ; consultez En savoir plus sur TeX Live.
