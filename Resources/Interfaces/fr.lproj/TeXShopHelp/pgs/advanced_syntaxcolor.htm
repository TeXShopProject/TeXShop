Surlignage syntaxique

La fenêtre source affiche TeX en couleurs : les commentaires, les commandes, les notes en bas de page, les marqueurs $ et &, ainsi que les délimiteurs ( ), { } et [ ] ont chacun leur couleur. Source › Surlignage syntaxique active ou désactive le surlignage pour le document actif. Les documents s’ouvrent avec le surlignage activé ; pour les ouvrir avec le surlignage désactivé, utilisez le réglage caché

defaults write TeXShop SyntaxColoringEnabled NO

Ce qui est surligné

  • Les commandes sont une barre oblique inverse suivie de lettres. Réglages › Éditeur › Surlignage syntaxique › « @ fait partie des noms de commande » compte aussi @ comme une lettre, comme dans les commandes internes des paquets.
  • Le texte de \footnote, \footcite et \autocite, ainsi que celui des commandes qui commencent par \cite ou \Cite, comme \citep et \citeauthor, s’affiche dans la couleur « Note en bas de page ». Le réglage caché defaults write TeXShop SyntaxColorFootnote NO ne colore que la commande.
  • Source › Surligner les entrées d'index affiche les arguments de \index et de \esindex dans la couleur « Index ». Réglages › Éditeur › Surlignage syntaxique › « Surligner les entrées d'index par défaut » l’active à l’ouverture des documents.
  • Source › Surligner le code expl3 colore aussi les fonctions, les variables et les autres éléments du code expl3, la couche de programmation de LaTeX, à l’intention de ceux qui écrivent des paquets. « Surligner le code expl3 par défaut », dans le même groupe, l’active à l’ouverture des documents.
  • « Surligner les lettres et symboles pleine chasse », dans le même groupe, affiche dans les couleurs « Pleine chasse » les lettres, chiffres et symboles pleine chasse, faciles à confondre avec des caractères ASCII dans un texte japonais.

« Surligner les entrées d'index » et « Surligner le code expl3 » s’appliquent au document actif ; chaque fenêtre source a son propre choix. Les fichiers qui ne sont pas des sources TeX, comme les fichiers journaux, ne sont pas surlignés ; consultez Ouvrir d’autres fichiers avec TeXShop pour la liste des extensions et la façon d’en ajouter une.

Modifier les couleurs

Les couleurs font partie du thème. Choisissez-les dans Réglages › Thèmes :

  • le groupe « Surlignage syntaxique » comporte « Commentaire », « Commande », « Note en bas de page », « Marqueur » et « Index » ;
  • le groupe « Délimiteurs » comporte les couleurs de ( ), { } et [ ] ;
  • le groupe « expl3 » comporte function, __function, key, variable, __variable, argument et msg ;
  • le groupe « Surlignage » comporte, entre autres, les couleurs « Pleine chasse » ;
  • le groupe « Syntaxe XML » comporte les couleurs des fichiers HTML et XML.

Chaque thème a ses propres couleurs ; le « Thème pour le mode clair » et le « Thème pour le mode sombre » peuvent donc différer.
