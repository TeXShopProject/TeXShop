Réglages cachés

La fenêtre Réglages contient les réglages dont la plupart des utilisateurs ont besoin. Les réglages moins courants sont des réglages cachés : ils n’ont pas de commande dans la fenêtre Réglages et se modifient avec une commande dans Terminal. Le document de référence « Commentaires spéciaux et réglages cachés », en anglais, liste tous les réglages cachés avec leur commande, classés par thème. Ouvrez-le avec Aide › Commentaires spéciaux et réglages cachés (en anglais), ou avec « Ouvrir le manuel des commentaires spéciaux et réglages cachés… » dans Réglages › Général › Avancé.

Modifier un réglage caché

  1. Quittez TeXShop.
  2. Ouvrez Terminal (dans Applications › Utilitaires), tapez la commande et appuyez sur Retour.
  3. Relancez TeXShop.

Chaque commande a la forme defaults write TeXShop nom valeur. Pour revenir à la valeur par défaut, utilisez defaults delete TeXShop nom.

Exemples

defaults write TeXShop OtherTrashExtensions -array 'nav' 'snm'
Fichier › Fichiers AUX à la corbeille supprime aussi les fichiers portant ces extensions. Indiquez les extensions sans le point. Consultez Supprimer les fichiers AUX.
defaults write TeXShop ConTeXtTags YES
Le menu Étiquettes liste les commandes de section de ConTeXt, comme \title et \subject, au lieu de celles de LaTeX.
defaults write TeXShop RedConsoleAfterError YES
Le texte saisi dans la console pour répondre à une erreur de TeX, ainsi que toute la suite des messages de cette composition, s’affiche en rouge.
defaults write TeXShop RefreshTime 2
Tant que « Toujours surveiller les modifications du PDF par d’autres apps » est activé dans Réglages › Aperçu, TeXShop vérifie toutes les 2 secondes si un PDF a changé. La valeur par défaut est de 1 seconde et le minimum de 0,5.

Les réglages présents dans la fenêtre Réglages ne sont pas repris parmi les réglages cachés. Par exemple, le passage au repère suivant ou précédent d’Édition › Repères avec Option ou Contrôle et la touche de déclenchement de la complétion s’active et se désactive avec « Aller au repère suivant ou précédent avec Option ou Contrôle et la touche de déclenchement » dans Réglages › Clavier. Pour trouver un tel réglage, utilisez la recherche dans les réglages ; consultez Rechercher dans les réglages.
