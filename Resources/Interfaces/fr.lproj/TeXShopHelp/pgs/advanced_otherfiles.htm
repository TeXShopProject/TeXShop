Ouvrir d’autres fichiers avec TeXShop

TeXShop ouvre n’importe quel fichier texte ; vous pouvez donc lire les fichiers journaux, les fichiers aux et les autres fichiers de TeX situés à côté de vos documents. Il ouvre aussi les fichiers PDF et les images.

Fichiers traités comme des sources TeX

Les fichiers portant les extensions suivantes, ainsi que les fichiers sans extension, sont des sources TeX pour TeXShop : ils s’affichent avec le surlignage syntaxique et peuvent être composés.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

Les autres fichiers texte, comme les fichiers .log, .aux, .bst, .engine ou .txt, s’ouvrent en texte brut, sans surlignage syntaxique.

Pour que TeXShop traite comme des sources TeX les fichiers portant une autre extension, ajoutez cette extension avec un réglage caché dans Terminal ; par exemple, pour des fichiers ConTeXt d’extension mkiv :

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

Fichiers PDF et images

Les fichiers PDF et les images portant les extensions .png, .jpg, .jpeg, .tif, .tiff et .eps s’ouvrent dans leur propre fenêtre. Les fichiers DVI et PostScript (.dvi, .ps) sont convertis en PDF et affichés.

Enregistrer avec une autre extension

Un fichier conserve son extension lorsque TeXShop l’enregistre. Un nouveau document est enregistré en tant que fichier .tex, sauf si vous choisissez un autre type dans le menu « Format de fichier » de la zone de dialogue d’enregistrement, comme sty, bib ou mp.

TeXShop enregistre un fichier dans l’encodage avec lequel il a été ouvert. Il est conçu pour TeX et les fichiers associés ; un fichier dans un format inhabituel peut être modifié s’il est enregistré après avoir été modifié dans TeXShop. Consultez Encodages.
