Définir le fichier racine d’un projet

Les documents volumineux sont souvent répartis en plusieurs fichiers : un fichier racine contenant le préambule, qui inclut un fichier par chapitre. Par exemple, un fichier racine Main.tex pourrait contenir

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

Lorsque vous modifiez two.tex, TeXShop doit composer Main.tex, et non le chapitre, qui n’a pas de préambule. Pour le lui indiquer, placez cette ligne dans l’une des vingt premières lignes de chaque fichier de chapitre :

% !TEX root = ../Main.tex

Le fichier racine lui-même n’a pas besoin d’une telle ligne. Le nom du fichier racine peut être indiqué

  • par son nom seul, Main.tex, lorsqu’il se trouve dans le même dossier que le fichier de chapitre ;
  • par rapport au dossier du fichier de chapitre, ../Main.tex ou ../../Main.tex ;
  • par son chemin complet, /Users/me/Book/Main.tex, qu’il faut modifier lorsque le projet est déplacé.

La macro Root du menu Macros insère la ligne : elle demande le fichier racine et propose une ligne relative ou absolue, qui remplace une éventuelle ligne root précédente.

Ce que fait la ligne root

  • Composer dans un fichier de chapitre compose le fichier racine, et la fenêtre d’aperçu du fichier racine affiche le document entier. Une ligne % !TEX program et les autres lignes magiques relatives à la composition se placent dans le fichier racine.
  • Édition › Aller à l’erreur ouvre le fichier qui contient une erreur, s’il n’est pas ouvert, et va à la ligne concernée.
  • La synchronisation depuis la fenêtre d’aperçu ouvre le fichier de chapitre qui contient l’endroit cliqué ; consultez Synchroniser la source et l’aperçu.
  • « Fichiers AUX à la corbeille » supprime les fichiers auxiliaires du fichier racine ; consultez Supprimer les fichiers AUX.
  • Fenêtre › Source ⇔ Aperçu (⌘1) dans un fichier de chapitre amène au premier plan la fenêtre d’aperçu du fichier racine. La même commande dans la fenêtre d’aperçu ramène à la fenêtre source d’où vous veniez, ou au fichier racine si vous ne veniez pas d’une fenêtre source.

Ouvrir un fichier de chapitre

À l’ouverture d’un fichier de chapitre comportant une ligne root, TeXShop ouvre aussi le fichier racine et sa fenêtre d’aperçu. Deux options de Réglages › Général › « Fichier racine du projet » le contrôlent : « Ouvrir le fichier racine à l’ouverture d’un document » active ou désactive ce comportement, et « Minimiser la fenêtre du fichier racine ouverte » place la fenêtre source du fichier racine dans le Dock, puisqu’on la modifie rarement pendant le travail sur un chapitre.

Rechercher et remplacer dans tout le projet

Pour chercher dans tous les fichiers d’un projet à la fois, choisissez Édition › Rechercher › Rechercher dans les sources TeX de même TEX root… dans l’un de ses fichiers de chapitre, ou Rechercher dans les sources TeX ayant ce fichier pour TEX root… dans le fichier racine. La recherche porte sur le fichier racine et sur les fichiers .tex de son dossier et des dossiers inférieurs qui le désignent par une ligne root dans leurs 20 premières lignes. Consultez Rechercher dans les sources TeX et Rechercher et remplacer.

Fichiers racine indiqués dans des fichiers .texshop

Un fichier portant l’extension .texshop placé à côté d’un fichier de chapitre, par exemple two.texshop pour two.tex, peut aussi indiquer le fichier racine, et TeXShop le lit toujours. Aucune commande de menu ne crée de tels fichiers ; utilisez une ligne % !TEX root, qui accompagne la source partout.
