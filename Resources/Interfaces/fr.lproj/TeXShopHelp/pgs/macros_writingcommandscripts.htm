Écrire des scripts avec des commandes shell

Cette page s’appuie sur la macro Run pdfLaTeX with Shell Escape de Claus Gerhardt, dans Macros › Claus Gerhardt Macros, pour montrer comment un AppleScript appelle un script shell. Le script shell lui-même est simple : il ajoute les dossiers des programmes TeX au chemin de recherche et exécute pdflatex avec --shell-escape. Vos propres scripts en feront sans doute davantage, par exemple exécuter plusieurs programmes à la suite ; c’est alors que ces techniques deviennent utiles.

Le script shell

Le script shell est ~/Library/TeXShop/bin/pdflatexc. Il ne dépend pas de TeXShop : si son dossier figure dans votre chemin de recherche, taper pdflatexc myfile.tex dans Terminal l’exécute. Le voici :

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

L’AppleScript

La macro qui appelle ce script shell est plus intéressante :

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Après les commentaires, les sept premières lignes sont une recette de Claus Gerhardt qui enregistre le fichier source et trouve le nom de son document, placé dans frontName. Le travail est effectué par le script compilé setname.scpt de ~/Library/TeXShop/Scripts : ces lignes trouvent le chemin ~/Library/TeXShop/Scripts/setname.scpt, chargent le script et l’appellent avec #NAMEPATH# et #TEXPATH#.

Souvent, on peut obtenir le même résultat plus simplement avec

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

La recette présente deux avantages. Elle fonctionne aussi lorsque le document au premier plan n’est pas celui qui doit recevoir les commandes suivantes, par exemple un fichier journal tel que /Users/name/Examples/myfile.log. Et si le fichier n’a jamais été enregistré, la recette renvoie une erreur, alors que la commande save laisserait le script en attente derrière une zone de dialogue d’enregistrement.

Les six lignes suivantes définissent les variables dirName et baseName. Si le fichier source est /Users/name/My Papers/Stuff/myfile.tex, dirName vaut '/Users/name/My Papers/Stuff', mis entre guillemets pour le shell à cause de l’espace dans un nom de dossier, et baseName vaut myfile.tex. Le nom de fichier est mis entre guillemets de la même façon lorsqu’il est transmis au script shell ; tous deux peuvent donc contenir des espaces.

Les trois lignes suivantes appellent le script shell. Le résultat est le même que si l’on tapait cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' dans Terminal. Les trois dernières lignes mettent à jour la fenêtre d’aperçu.

Plusieurs de ces lignes sont compliquées, mais elles peuvent être recopiées telles quelles dans de nouveaux scripts.

Exécuter des commandes shell depuis AppleScript

AppleScript exécute une commande shell sous la forme

do shell script "cmd input"

Pour construire une commande à partir de plusieurs éléments, écrivez-la sous la forme équivalente

do shell script "cmd " & "input"

Remarquez l’espace après cmd. L’esperluette réunit deux chaînes :

"cmd " & "input" = "cmd input"

Un shell lancé par AppleScript démarre dans le dossier racine. La commande

do shell script "cd " & dirName

passe dans le dossier indiqué par dirName, qui est déjà entre guillemets ; aucun autre guillemet n’est donc nécessaire.

Chaque do shell script lance un nouveau shell ; une commande ultérieure ne se trouverait donc pas dans ce dossier. Pour exécuter d’autres commandes dans le même dossier, réunissez-les en une seule commande avec des points-virgules, comme dans Terminal :

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

Le script ci-dessus procède ainsi avec cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc et input2 = baseName. Les lignes

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

sont simplement un moyen pratique de placer cette suite dans une seule variable.
