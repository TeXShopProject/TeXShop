Définir de nouvelles macros

Dans l’éditeur de macros (Macros › Ouvrir l'éditeur de macros...), cliquez sur + sous la liste pour ajouter un élément. Le menu situé à l’extrémité droite de la barre placée sous la liste (⋯) ajoute un sous-menu ou un séparateur et duplique les éléments sélectionnés ; − les supprime. Un nouvel élément ou sous-menu se nomme aussitôt : tapez son nom et appuyez sur Retour. Les sous-menus peuvent être imbriqués sur autant de niveaux que vous le souhaitez. Un peu de pratique suffit pour comprendre le fonctionnement de l’éditeur.

Les modifications sont conservées au fur et à mesure, et la fermeture de la fenêtre ne demande pas s’il faut les enregistrer. Il n’y a pas de boutons « Enregistrer » ni « Annuler ». « Tester » exécute la macro sélectionnée, telle qu’elle est dans l’éditeur, dans le document actif ; un double-clic sur une macro de la liste fait de même.

Raccourcis

Pour attribuer un raccourci clavier à un élément, sélectionnez-le et cliquez sur son raccourci dans la liste (ou double-cliquez sur le raccourci), puis appuyez sur le nouveau raccourci : Commande ou Contrôle avec une touche, ou l’une des touches F1 à F20, avec Maj et Option si nécessaire. Si une commande de menu ou une autre macro utilise déjà ce raccourci, TeXShop l’indique sous le contenu et ne le modifie pas ; appuyez sur un autre raccourci. Pour supprimer un raccourci, cliquez sur « Supprimer le raccourci » (⊖) dans le champ ou appuyez sur Supprimer ; Échap conserve le raccourci précédent. Un raccourci inactif parce qu’une commande de menu ou une macro précédente l’utilise est signalé par un triangle d’avertissement dans la liste ; sélectionnez l’élément pour en voir la raison sous le contenu. Lorsque la raison est une commande de menu dont le raccourci peut être retiré dans Réglages, « Retirer… » apparaît à côté. Il demande confirmation, puis retire ce raccourci de menu. Consultez Redéfinir les raccourcis clavier des menus pour savoir comment les raccourcis des menus et ceux des macros fonctionnent ensemble.

Espaces réservés

Dans le contenu, les espaces réservés qu’une macro remplace s’affichent sous forme de jetons arrondis qui indiquent ce qu’ils représentent, comme « Texte sélectionné » : #SEL#, #INS#, #PASTE# et les repères • d’une macro de texte (consultez Comprendre les macros par défaut), ainsi que #FILEPATH# et les autres chemins d’une macro AppleScript (consultez Définir des macros AppleScript). La macro les conserve tels qu’ils sont écrits ; la copie et l’enregistrement fonctionnent donc comme d’habitude. Tapez un espace réservé, ou choisissez-le dans le menu « Insérer » situé sous le contenu ; le bouton d’aide placé à sa droite les liste tous. Supprimer à côté d’un jeton supprime le jeton entier.
