Installer TeX Live

TeXShop a besoin d’une distribution TeX. La distribution standard est TeX Live, que les groupes d’utilisateurs de TeX produisent chaque année pour macOS, Windows, Linux et d’autres systèmes. Sur le Mac, elle s’installe avec MacTeX, un paquet d’installation réalisé par le TeX Users Group (TUG) :

https://tug.org/mactex/

La page propose deux paquets. Double-cliquez sur celui que vous avez téléchargé et suivez le programme d’installation ; quand il a terminé, TeX est prêt à l’emploi.

MacTeX
TeX Live complet, avec Ghostscript, ainsi que TeXShop et d’autres applications dans /Applications/TeX. Presque tous les exemples d’un livre sur TeX ou LaTeX fonctionnent sans rien ajouter. Choisissez ce paquet pour un vrai travail.
BasicTeX
Une petite partie de TeX Live, suffisante pour essayer TeX et composer de nombreux documents LaTeX. Il n’installe pas TeXShop ; voir Installer TeXShop.

Où TeX Live est installé

MacTeX installe TeX Live dans /usr/local/texlive/2026, et BasicTeX dans /usr/local/texlive/2026basic. Les deux peuvent être installés côte à côte. Un nouveau TeX Live paraît chaque année, vers avril, dans un dossier qui porte le nom de son année. Pour supprimer une installation, faites glisser son dossier dans la Corbeille.

Le programme d’installation crée aussi /Library/TeX/texbin, qui mène aux programmes du TeX Live utilisé et suit un nouveau TeX Live lorsqu’il est installé. TeXShop exécute TeX depuis cet emplacement (Réglages › Composition › Chemins › Moteurs TeX) ; il n’y a donc rien à changer d’une année sur l’autre. « Détecter les chemins… », dans le même groupe, cherche les installations de TeX et de Ghostscript présentes sur le Mac et vous laisse en choisir une.

Entre deux versions annuelles, les paquets de TeX Live reçoivent des mises à jour. MacTeX installe TeX Live Utility dans /Applications/TeX pour les installer.

Autres distributions TeX

TeXShop fonctionne aussi avec un TeX installé par MacPorts ou Homebrew, ou avec MiKTeX. Leurs programmes se trouvent dans d’autres dossiers : utilisez « Détecter les chemins… », ou saisissez le dossier dans Réglages › Composition › Chemins › Moteurs TeX. Voir Coexister avec d’autres distributions TeX.
