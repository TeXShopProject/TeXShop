Palette LaTeX

Fenêtre › Palette LaTeX... ouvre une palette de code LaTeX : symboles mathématiques, lettres grecques, fonctions, caractères accentués et internationaux, environnements et commandes de typographie. Cliquez dans la source là où le code doit aller, puis cliquez sur un bouton de la palette. Son code est inséré au point d’insertion. La palette reste devant les fenêtres source pendant que vous travaillez.

Les boutons sont répartis sur des pages. Choisissez une page avec les boutons en haut de chaque partie de la palette : « Mathématiques », « Grec », « Symboles », « Fonctions » et « International », puis « Environnements », « Typographie » et « Personnalisé ».

Si du texte est sélectionné quand vous cliquez sur un bouton de typographie ou d’environnement, le texte sélectionné se place à l’intérieur du code inséré, comme dans \textbf{texte sélectionné}.

Certains symboles nécessitent le paquet amssymb. Ajoutez cette ligne au préambule d’un document qui les utilise :

\usepackage{amssymb}

Personnaliser la palette

Le code que chaque bouton insère est conservé dans ~/Library/TeXShop/LatexPanel/completion.plist. Ouvrez ce fichier dans TeXShop pour le modifier ; les commentaires placés au début expliquent son organisation. Les noms des boutons standard ne peuvent pas être modifiés, mais le code qu’ils insèrent peut l’être. Dans ce code :

  • #SEL# représente le texte sélectionné ;
  • #INS# marque l’endroit où va le point d’insertion après l’insertion du code ;
  • #PASTE# représente le texte du presse-papiers.

La page « Personnalisé » peut accueillir jusqu’à seize boutons personnels. Chacun est défini dans la liste Customized du fichier par deux chaînes, le nom du bouton et le code qu’il insère :

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Enregistrez le fichier en UTF-8, puis quittez et relancez TeXShop pour voir les modifications dans la palette. Si le fichier est absent ou endommagé, TeXShop le remplace par sa propre copie. Voir Modifier la palette LaTeX et Les fichiers de ~/Library/TeXShop.
