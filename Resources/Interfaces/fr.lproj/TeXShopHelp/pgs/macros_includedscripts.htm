Macros AppleScript par défaut

TeXShop est fourni avec une collection de macros AppleScript de Will Robertson, Claus Gerhardt et d’autres. Certaines exécutent une série de commandes de composition à la suite. En les copiant et en les modifiant, vous pouvez construire des scripts adaptés à votre propre travail. Cette page décrit certaines d’entre elles, sous le nom qu’elles portent dans le menu Macros.

Column macros, Insert reference, Open quickly…

Ces macros sont de Will Robertson. Dans le sous-menu Column macros, New tabular et New array insèrent un environnement tabular ou array avec le nombre de lignes et de colonnes que vous indiquez, et Add column et Delete column modifient les lignes que vous sélectionnez. Insert reference cherche les commandes \label{…} dans le fichier courant et vous laisse choisir un label dans une liste ; elle insère le label entouré de \ref{…}, une commande que vous pouvez changer dans le script. Si du texte est sélectionné, seuls les labels qui le contiennent sont listés. Open quickly… liste les fichiers .tex, .sty et .pdf du dossier du fichier source courant et ouvre ceux que vous choisissez.

Paste Spreadsheet Cells

Cette macro, d’Alan Munn, colle sous forme de tableau dans votre source LaTeX des cellules d’une feuille de calcul. Sélectionnez une plage de cellules dans Excel ou dans un autre tableur et copiez-les. Choisissez ensuite Macros › Paste Spreadsheet Cells, puis un style de tableau :

cells
convertit le texte copié en cellules de tableau LaTeX uniquement.
booktabs
prend la première ligne comme en-tête et place \toprule, \midrule et \bottomrule dans un environnement tabular.
simple
entoure les cellules d’un environnement tabular simple.
longtable
prend la première ligne comme en-tête, ajoute les lignes d’en-tête d’un longtable et place les cellules dans un environnement longtable.

La macro remplace le contenu du presse-papiers par le texte LaTeX. Pour coller les mêmes cellules dans un autre style, copiez-les d’abord de nouveau dans le tableur.

Applescript › Save Copy with Unix Line Endings, Save Copy with Windows Line Endings, Save Copy with Classic Mac Line Endings

Les fichiers texte terminent leurs lignes de différentes manières : macOS et Unix par un saut de ligne, Windows par un retour chariot suivi d’un saut de ligne, et les très anciens fichiers Macintosh par un retour chariot seul. TeXShop lit les trois. Si l’éditeur de quelqu’un d’autre en est incapable, utilisez ces macros. Pour un fichier source MyFile.tex, Save Copy with Unix Line Endings écrit une copie du fichier enregistré nommée MyFile_Unix.tex, avec des sauts de ligne ; Save Copy with Windows Line Endings écrit MyFile_Windows.tex et Save Copy with Classic Mac Line Endings écrit MyFile_Mac.tex. Ces macros utilisent le programme flip de Craig Stuart Sapp, situé dans ~/Library/TeXShop/bin.

Applescript › Run LaTeX, BibTeX, Then LaTeX Twice

Un document comportant une bibliographie nécessite plusieurs compositions : LaTeX écrit le fichier .aux, BibTeX l’utilise pour écrire les fichiers .bbl et .blg, LaTeX s’exécute de nouveau pour ajouter la bibliographie, puis une fois encore pour mettre à jour les références qui y renvoient. Cette macro les exécute l’une après l’autre. Écrire des scripts avec les commandes de composition de TeXShop explique son fonctionnement.

Claus Gerhardt Macros

La plupart des macros de ce sous-menu appellent des scripts shell situés dans ~/Library/TeXShop/bin, comme pdflatexc, qui exécute pdfLaTeX, et bibtexc, qui exécute BibTeX. Chaque macro dont le nom commence par Run exécute les programmes que ce nom indique, dans cet ordre, et Open PDF ouvre le PDF du document. Run LaTeX, dvips and ps2pdf nécessite en outre Ghostscript. Elles travaillent sur un fichier enregistré. Écrire des scripts avec des commandes shell prend Run pdfLaTeX with Shell Escape comme exemple.

Make HTML with TeX4ht

TeX4ht convertit un document LaTeX en page web : une page HTML et des fichiers d’image. Make HTML with TeX4ht exécute htlatex sur le document et ouvre le fichier HTML obtenu dans Safari. Le paquet tex4ht n’a pas besoin d’être chargé dans le document ; htlatex le charge. Make HTML with TeX4ht, Remaking Images exécute htlatex avec l’option -r, qui recrée les images même si elles existent déjà.

Extract Pages from PDF…

Extract Pages from PDF… crée des fichiers PDF contenant des pages choisies du PDF du document. Elle demande d’abord combien de fichiers créer, puis les pages de chaque fichier, par exemple 5:8 pour les pages 5 à 8, ou 3:4,6,8:12. Si le document s’appelle MyFile, les fichiers sont enregistrés sous les noms MyFile-1.pdf, MyFile-2.pdf, etc.

MetaPost

Run pdfLaTeX, MakeIndex, MetaPost, Then pdfLaTeX ouvre les fichiers journaux au passage. Consultez ConTeXt et MetaPost au sujet de MetaPost.
