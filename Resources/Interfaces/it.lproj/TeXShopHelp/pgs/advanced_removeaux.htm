Eliminare i file ausiliari

Quando LaTeX compila Galois.tex, scrive file ausiliari come Galois.aux, Galois.toc e Galois.log, che l’esecuzione successiva legge per i riferimenti incrociati, l’indice generale e simili. Se la compilazione si interrompe a metà, per esempio dopo un errore, questi file possono restare danneggiati, e l’esecuzione successiva segnala errori che non sono nel sorgente, spesso subito prima di \begin{document}. Spostare i file ausiliari nel Cestino e compilare di nuovo risolve il problema.

Spostare i file nel Cestino

  • File › Cestina file ausiliari (⌃⌘A), o il pulsante «Cestina file ausiliari» nella console, sposta nel Cestino i file ausiliari del documento.
  • Compila › Cestina file ausiliari e compila (⌥⌘T) fa lo stesso e poi compila. Nel menu Compila, questa voce compare al posto di Compila mentre tieni premuto il tasto Opzione.

Vengono spostati nel Cestino i file che si trovano nella cartella del sorgente, hanno il suo nome e una di queste estensioni:

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

Vengono spostati nel Cestino anche i file che SyncTeX lascia con (busy) alla fine del nome quando la compilazione viene interrotta. Il file .bbl di BibTeX viene conservato.

In un progetto i cui file di capitolo indicano un file principale con % !TEX root, vengono spostati nel Cestino i file del file principale, anche quando il comando viene dato in un file di capitolo.

Varianti

  • Tieni premuto Maiuscole mentre scegli Cestina file ausiliari o fai clic sul pulsante per spostare nel Cestino anche il file PDF del documento. Di solito il vecchio PDF viene conservato, così la finestra di anteprima ha qualcosa da mostrare quando la compilazione non riesce.
  • Tieni premuto Opzione mentre scegli Cestina file ausiliari o fai clic sul pulsante per ripulire un intero progetto: ogni file con una delle estensioni sopra elencate nella cartella del file principale e in tutte le cartelle sottostanti viene spostato nel Cestino, qualunque sia il suo nome. In questo modo vengono eliminati anche i file .aux che \include scrive per i capitoli nelle sottocartelle.

Due impostazioni nascoste modificano il comportamento. Per aggiungere estensioni all’elenco, per esempio dvi, digita nel Terminale

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

e per tornare all’elenco standard

defaults write TeXShop OtherTrashExtensions -array

Per rendere il comportamento con Opzione quello standard di Cestina file ausiliari:

defaults write TeXShop AggressiveTrashAUX YES
