Definire macro AppleScript

AppleScript è un linguaggio a sé. La AppleScript Language Guide di Apple, sul sito web per sviluppatori di Apple, lo descrive in modo completo.

Percorsi e nome del documento

Prima di eseguire una macro AppleScript, TeXShop sostituisce le stringhe seguenti con il percorso di un file del documento attivo, tra virgolette doppie:

#FILEPATH#
il file sorgente
#TEXPATH#
il file .tex
#NAMEPATH#
il file sorgente senza estensione
#FOLDERPATH#
la cartella che contiene il sorgente, terminata da una barra
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
i file .pdf, .dvi, .ps, .log e .aux
#INDPATH#, #BBLPATH#, #HTMLPATH#
i file .ind, .bbl e .html

Per esempio, se #FILEPATH# dà /Users/name/Projects/Fourier/Fourier.tex, #FOLDERPATH# dà /Users/name/Projects/Fourier/. Se il documento non è mai stato salvato, #FILEPATH# è una stringa vuota.

#DOCUMENTNAME# viene sostituito dal nome del documento così come lo mostra il titolo della finestra sorgente: con l’estensione, oppure senza se l’estensione è nascosta. Uno script lo usa per rivolgersi al documento che lo ha richiamato:

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

Comandi di TeXShop

Un AppleScript può svolgere il suo lavoro in due modi: può eseguire comandi della shell, come descritto in Scrivere script con comandi della shell, oppure può richiamare i comandi propri di TeXShop, come descritto in Scrivere script con i comandi di composizione di TeXShop. Tra gli altri, TeXShop riconosce questi comandi:

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

I primi sei comandi compongono senza interruzioni, senza fermarsi agli errori. I sei successivi compongono anch’essi, ma si fermano a un errore in modo che tu possa rispondere nella console. Un comando di composizione restituisce subito il controllo, prima che la composizione sia terminata. taskdone restituisce NO mentre la composizione è ancora in corso e YES quando è terminata. refreshpdf e refreshtext fanno sì che le finestre PDF e di testo mostrino la versione più recente dei loro file. goto line seleziona una riga del sorgente:

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
