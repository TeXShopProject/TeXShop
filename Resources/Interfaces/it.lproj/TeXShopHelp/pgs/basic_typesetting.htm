Compilare i documenti

Un primo documento

Scegli File › Nuovo. Nella barra strumenti della nuova finestra, scegli LatexTemplate nel menu «Modelli»; la finestra si riempie delle righe che servono a ogni documento LaTeX. Scrivi il testo tra \begin{document} e \end{document}. Una riga vuota inizia un nuovo paragrafo.

Fai clic su «Compila» nella barra strumenti, oppure premi ⌘T (Compila › Compila). La prima volta, TeXShop chiede dove salvare il documento. TeX scrive diversi file accanto al sorgente, quindi dai a ogni documento una cartella tutta sua. Poi TeXShop esegue TeX e apre una finestra di anteprima con il documento compilato.

Da quel momento scrivi, compila e guarda il risultato. TeXShop salva il sorgente prima di ogni compilazione, e l’anteprima resta alla pagina che stavi leggendo. ⌘T funziona nel sorgente, nell’anteprima e nella console, e ⌘1 (Finestra › Sorgente ⇔ Anteprima) passa dal sorgente alla sua anteprima e viceversa. Impostazioni › Compilazione › «Dopo la compilazione» sceglie quale finestra viene in primo piano quando TeX termina.

Aprendo un file .tex si apre anche il file PDF con lo stesso nome, se esiste. Chiudendo la finestra di anteprima il sorgente resta aperto, e l’anteprima ricompare alla compilazione successiva; chiudendo la finestra sorgente si chiude il documento.

La console

Mentre TeX è in esecuzione, i suoi messaggi compaiono nella console. Impostazioni › Console › «Mostra la console» sceglie se la console viene in primo piano a ogni compilazione («Sempre») o solo quando TeX segnala un errore («In caso di errore»). File › Mostra console (⌘0) porta in primo piano la console del documento attivo, e ⌘0 nella console torna alla finestra da cui provenivi. Il testo della console si può selezionare e copiare in qualsiasi momento.

Quando TeX trova un errore, scrive un messaggio alla fine della console e attende una risposta. Scrivila nel campo in fondo alla console e premi A capo; A capo da solo passa all’errore successivo, e il campo elenca le altre risposte che TeX accetta. Per fermare TeX, fai clic su «Interrompi» nella console oppure scegli File › Interrompi compilazione (⌃⌥⌘A).

Trovare gli errori

«Vai all’errore» nella console, oppure Modifica › Vai all’errore (⌃⌘E), fa scorrere il sorgente fino alla riga del primo errore e la evidenzia; sceglilo di nuovo per l’errore successivo. Se l’errore si trova in un altro file del progetto, quel file viene aperto. Spesso la cosa più rapida è correggere alcuni errori e compilare di nuovo, perché un errore può causarne diversi altri. «Vai all’errore» si basa sui nomi dei file e sui numeri di riga che TeX scrive con -file-line-error, opzione usata dai comandi e dai file dei motori di TeXShop.

LaTeX scrive informazioni per l’esecuzione successiva, come l’indice e i riferimenti incrociati, in un file .aux e in altri file ausiliari, quindi un documento può richiedere due o tre esecuzioni prima che tutti i riferimenti siano giusti. Un errore può lasciare questi file danneggiati, e allora il documento può non compilarsi nemmeno dopo aver corretto l’errore. Scegli Compila › Cestina file ausiliari e compila (⌥⌘T) per spostare i file ausiliari nel Cestino e compilare di nuovo, oppure File › Cestina file ausiliari (⌃⌘A), disponibile anche come pulsante «Cestina file ausiliari» nella console. Consulta Eliminare i file ausiliari.

Scegliere il motore

Impostazioni › Compilazione › «Profilo del motore» imposta in un solo passaggio la compilazione per un motore. Scegli il profilo del motore che usi; un foglio elenca i valori che imposta, e OK li applica. Nel foglio, «Esecuzione di LaTeX» si può impostare su «Con latexmk», così che latexmk esegua BibTeX, l’indice analitico e le passate aggiuntive quando servono. Non appena uno di questi valori viene cambiato, il menu mostra «Personalizzato». Il Manuale di TeXShop elenca che cosa impostano i profili.

Per un solo documento, scegli il motore nel menu a comparsa «Programma» accanto a «Compila» nella barra strumenti. Elenca plain TeX, LaTeX, BibTeX, MakeIndex e MetaPost, seguiti dai file dei motori in ~/Library/TeXShop/Engines, come LuaLaTeX e XeLaTeX, e la scelta vale per quella finestra. Per renderla parte del documento, metti una riga come questa tra le prime 20 righe del sorgente:

% !TEX program = LuaLaTeX

A quel punto ⌘T compila sempre il file con quel motore. Il nome è quello di un file del motore, oppure uno tra pdflatex, latex, pdftex e tex per LaTeX e plain TeX integrati (consulta Modalità di compilazione alternativa). Macro › Set Typesetting Program… inserisce una riga di questo tipo, con il motore scelto da un elenco; scrive % !TEX TS-program =, che ha lo stesso significato. Impostazioni › Compilazione › «Compila i nuovi documenti con» imposta il motore dei documenti che non hanno una riga del genere. Per i file dei motori consulta Aggiungere motori di compilazione.

Il menu Compila esegue anche BibTeX, MakeIndex e MetaPost sul documento; consulta BibTeX e MakeIndex.

Documenti in più file

Un libro viene spesso diviso in un file principale, che contiene il preambolo, e in file dei capitoli che il file principale legge con \include o \input. Metti una riga come % !TEX root = ../Book.tex all’inizio di ogni file di capitolo, indicando il file principale con il suo percorso a partire dal file del capitolo. A quel punto ⌘T in un file di capitolo compila il file principale, e «Vai all’errore» e SyncTeX trovano il file di capitolo giusto. Consulta Impostare il file principale di un progetto.

Passare dal sorgente all’anteprima

Fai Comando-clic su una parola del sorgente, e l’anteprima scorre fino al testo composto e lo contrassegna. Fai Comando-clic nell’anteprima, e il sorgente viene in primo piano con il testo corrispondente contrassegnato; in un documento con file dei capitoli, il file del capitolo si apre se necessario. La corrispondenza non è sempre esatta, quindi guarda anche intorno al punto contrassegnato. I colori dei contrassegni si impostano in Impostazioni › Temi › SyncTeX.

Questa funzione usa SyncTeX, che i motori supportano quando vengono eseguiti con -synctex=1, come fanno i comandi e i file dei motori di TeXShop; Impostazioni › Compilazione › «Metodo di sincronizzazione» deve essere «SyncTeX (consigliato)». Il file SyncTeX di un documento registra dove si trovano i suoi file, quindi dopo aver spostato la cartella di un progetto compila ancora una volta prima di sincronizzare.

Disporre le finestre

Finestra › Usa un’unica finestra mette il sorgente e la sua anteprima uno accanto all’altra in una sola finestra, e Finestra › Usa finestre separate li separa di nuovo. Per aprire ogni documento in questo modo, imposta Impostazioni › Generali › Finestre › «Sorgente e anteprima» su «Usa un’unica finestra»; «Posizione del sorgente nella finestra combinata» mette il sorgente a sinistra o a destra. Trascina il divisore per dare al sorgente più o meno spazio; TeXShop apre ogni finestra combinata con la stessa proporzione. Un file di capitolo con una riga % !TEX root resta in finestre separate; il file principale invece può usare un’unica finestra. File › Nuovo apre solo una finestra sorgente: compila prima il nuovo documento, poi scegli «Usa un’unica finestra».

Con finestre separate, disponi e ridimensiona come preferisci le finestre sorgente e dell’anteprima, poi scegli Sorgente › Salva posizione sorgente e Anteprima › Salva posizione anteprima; le nuove finestre si apriranno in quella posizione.
