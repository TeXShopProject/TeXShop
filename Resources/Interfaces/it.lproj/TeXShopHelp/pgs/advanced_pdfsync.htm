Sincronizzare sorgente e anteprima

Fai Comando-clic su una parola nella finestra sorgente: la finestra di anteprima scorre fino al punto corrispondente e lo contrassegna. Fai Comando-clic su un punto della finestra di anteprima: il file sorgente si apre, se necessario, alla riga corrispondente, che viene contrassegnata. I colori dei due contrassegni si impostano in Impostazioni › Temi › SyncTeX, alle voci Anteprima e Sorgente.

SyncTeX

TeXShop sincronizza con SyncTeX. Quando TeX viene eseguito con l’opzione -synctex=1, scrive accanto al PDF un file come Galois.synctex.gz, che registra dove è finita sulla pagina ciascuna parte del sorgente. I comandi di composizione in Impostazioni › Composizione, così come li impostano i profili del motore, e i motori che TeXShop mette in ~/Library/TeXShop/Engines e che eseguono TeX usano già questa opzione. Un motore che aggiungi lì, compreso uno dei motori facoltativi della cartella Inactive, la usa solo se il suo comando la contiene. In un motore tuo, aggiungi -synctex=1 alla chiamata di TeX (con uno o due trattini; ogni motore accetta entrambe le forme).

Il file synctex contiene i percorsi completi dei file sorgente. Dopo che la cartella di un progetto è stata spostata, copiata o inviata a un’altra persona, la sincronizzazione non funziona finché il documento non viene composto di nuovo.

SyncTeX non è del tutto esatto: il punto che cerchi può trovarsi poco prima o poco dopo il contrassegno.

Progetti con più file

In un progetto i cui file dei capitoli indicano il file principale con % !TEX root (consulta Impostare il file principale di un progetto), un Comando-clic in un file di capitolo porta al punto corrispondente nell’anteprima dell’intero documento, e un Comando-clic nell’anteprima apre il file di capitolo che contiene il punto su cui hai fatto clic. Con Impostazioni › Composizione › Sincronizzazione di sorgente e anteprima › «Aprire come pannelli nella finestra del file principale i file raggiunti dalla sincronizzazione» attivato, un file aperto in questo modo si aggiunge come pannello alla finestra del file principale invece di aprirsi in una finestra propria.

Metodo di sincronizzazione

Impostazioni › Composizione › Sincronizzazione di sorgente e anteprima › «Metodo di sincronizzazione» offre due scelte:

SyncTeX (consigliato)
Usa il file synctex, come descritto sopra. È la scelta predefinita.
Cerca nel PDF
Cerca nel PDF il testo attorno al clic e, per un clic nell’anteprima, cerca nel sorgente il testo attorno al clic. Non richiede un file synctex, ma non funziona dove il testo composto è diverso dal sorgente, come nelle formule e nel testo con molti comandi. Per trovare il file di un punto dell’anteprima, cerca nei file indicati nei comandi \include e \input del file principale. Per i progetti che includono i file in altro modo, elencali nel file principale con righe come 
% !TEX projectfile = chapter2.tex
% !TEX projectfile = /Users/me/Book/chapter3.tex
Un nome è un percorso completo o un percorso relativo al file principale; queste righe possono trovarsi in qualunque punto del file principale.

ConTeXt

Per ConTeXt, aggiungi \setupsynctex[state=start,method=min] all’impostazione del documento e la riga % !TEX useConTeXtSyncParser all’inizio del file principale; TeXShop usa allora il codice di sincronizzazione proprio di ConTeXt. Consulta ConTeXt e MetaPost.

Per sincronizzare con un sorgente aperto in un altro editor, consulta Usare un editor esterno.
