Inserire immagini

Compilando direttamente in PDF, LaTeX inserisce immagini in formato PDF, PNG e JPEG. Il PDF mantiene nitidi linee e testo a qualsiasi dimensione, quindi usalo per diagrammi e grafici; PNG e JPEG sono adatti a schermate e fotografie.

Carica il pacchetto graphicx nel preambolo:

\usepackage{graphicx}

e inserisci un’immagine nel punto in cui deve comparire:

\includegraphics[width=0.8\textwidth]{diagram}

L’estensione si può omettere; LaTeX cerca allora diagram.pdf, diagram.png, diagram.jpg e gli altri formati che conosce. Cambia la larghezza per cambiare la dimensione dell’immagine. Metti i file delle immagini nella cartella del documento, oppure indica un percorso relativo a essa, come figures/diagram.

File EPS

TeX Live converte automaticamente in PDF le immagini EPS durante la compilazione, usando epstopdf, purché il documento carichi graphicx. Il file convertito, diagram-eps-converted-to.pdf, viene scritto accanto al file EPS e usato da quel momento in poi.

Anche un file EPS aperto in TeXShop viene convertito: TeXShop scrive accanto a esso un file PDF con lo stesso nome, oppure in una cartella temporanea quando non si può scrivere nella cartella del file EPS, e lo mostra.

File TIFF

LaTeX non può inserire file TIFF. Scegli File › Converti TIFF mentre è attiva una finestra sorgente: una finestra di dialogo mostra la cartella del documento, in cui si possono scegliere solo file TIFF. Selezionane uno o più e fai clic su «Converti». Ciascuno viene convertito in un file PNG con lo stesso nome nella stessa cartella; i file TIFF vengono conservati.

Compilare tramite DVI

I documenti che usano codice PostScript, per esempio con il pacchetto pstricks, si compilano con il metodo Tramite DVI, che per impostazione predefinita esegue dvips. Le immagini vanno allora inserite in formato EPS; i file PDF, PNG e JPEG non si possono usare. Anche i profili del motore il cui nome termina con «+ dvipdfmx» compilano Tramite DVI, ma eseguono dvipdfmx invece di dvips; con \usepackage[dvipdfmx]{graphicx}, lì si possono usare file PDF, PNG e JPEG. Consulta Modalità di compilazione alternativa.
