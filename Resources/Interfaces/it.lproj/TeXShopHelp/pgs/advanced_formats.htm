Creare e usare i formati TeX

Un file di formato (estensione .fmt) è un’istantanea di TeX dopo che ha letto un insieme di macro. Anche LaTeX è un formato: TeX lo carica in un attimo invece di leggere ogni volta i sorgenti di LaTeX. Puoi creare un formato tuo a partire da un preambolo lungo, così che la compilazione parta più in fretta, oppure usare un formato fornito da un progetto o da un’organizzazione.

Un formato funziona solo con il motore e con la versione di TeX Live che lo hanno creato. Un formato creato con pdfLaTeX di TeX Live 2026 non può essere usato da XeLaTeX né da un altro anno di TeX Live; crealo di nuovo dopo aver installato un nuovo TeX Live.

Creare un formato

Scrivi in un file le righe che il formato deve contenere, terminando con \dump. Per esempio, uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

Nel Terminale, spostati nella cartella di questo file e digita

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Questo comando carica il formato LaTeX, legge uo.tex e scrive uo.fmt. Un documento compilato con questo formato omette le righe già contenute nel formato e inizia con \begin{document}.

Usare un formato in TeXShop

  1. Sposta uo.fmt nella cartella ~/Library/texmf/web2c, creando le cartelle se necessario, così che TeX lo trovi da qualunque cartella.
  2. Nel Finder, apri ~/Library/TeXShop/Engines (TeXShop › Apri ~/Library/TeXShop), duplica un motore come XeLaTeX.engine e rinomina la copia, per esempio Oregon.engine. Il nome compare in TeXShop e non deve per forza coincidere con quello del formato.
  3. Apri la copia in TeXShop e modificane l’ultima riga in modo che il motore diventi: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

I documenti aperti in seguito elencano Oregon nel menu a comparsa accanto al pulsante «Compila». Per usare il formato in un documento qualunque sia la scelta fatta lì, aggiungi questa riga all’inizio del sorgente:

% !TEX program = Oregon

Per renderlo predefinito, scegli «File del motore» in Impostazioni › Compilazione › Motore › «Compila i nuovi documenti con» e Oregon nel menu «File del motore». Consulta Aggiungere motori di compilazione.

Per un formato plain TeX, usa pdftex invece di pdflatex nel motore. Per un formato da usare Tramite DVI, il motore deve anche convertire il file DVI in PDF, per esempio con dvipdfmx "${1:r}.dvi" in uno script zsh, perché TeXShop mostra il file PDF che ha il nome del sorgente.
