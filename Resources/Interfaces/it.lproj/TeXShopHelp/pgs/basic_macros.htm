Macro

Il menu Macro, e l’elemento «Macro» della barra strumenti, contengono comandi che inseriscono codice LaTeX nel sorgente o eseguono script AppleScript. Alcune delle macro fornite con TeXShop:

  • Program, Encoding e Root scrivono le righe % !TEX che scelgono il motore di compilazione, la codifica e il file principale di un documento. Scegli il motore o la codifica dall’elenco che mostra Program o Encoding, oppure il file principale nella finestra di dialogo che apre Root; la riga viene scritta correttamente all’inizio del sorgente.
  • Insert Begin/End trasforma la parola nel punto di inserimento o la parola selezionata, come theorem, in una coppia \begin{theorem} … \end{theorem}, con il punto di inserimento tra le due righe.
  • Sottomenu come Headings, Mathematics, Lists, Tables e Figures inseriscono codice LaTeX di uso comune.

L’Editor delle macro

Scegli Macro › Apri Editor delle macro... per vedere come è definita ogni macro, modificarla o aggiungere macro tue. L’elenco a sinistra è il menu Macro: trascina le voci per riordinarle, e usa la barra sotto l’elenco per aggiungere voci, sottomenu e separatori. Il testo di una macro viene inserito nel sorgente. In questo testo, dei segnaposto arrotondati rappresentano il testo selezionato, il testo negli appunti e la posizione del punto di inserimento; sceglili dal menu «Inserisci» sotto il testo.

Per assegnare a una macro una scorciatoia da tastiera, selezionala nell’elenco, fai clic sulla sua scorciatoia (o fai doppio clic) e premi i tasti. Una scorciatoia usa il tasto Comando o Controllo, oppure è un tasto funzione. Se un comando di menu o un’altra macro la usa già, l’Editor delle macro lo segnala.

Le macro sono conservate in ~/Library/TeXShop/Macros/Macros_Latex.plist. Per dare delle macro ad altri, selezionale nell’Editor delle macro e scegli Macro › Salva la selezione in un file...; per aggiungere le macro di un file di questo tipo, scegli Macro › Aggiungi macro da un file....

Il capitolo Aiuto sulle macro spiega le macro in dettaglio, comprese le macro AppleScript.
