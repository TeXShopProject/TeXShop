Aggiungere motori di compilazione

Oltre che con plain TeX e LaTeX, TeXShop compila con i motori: piccoli script di shell con l’estensione .engine che si trovano nella cartella ~/Library/TeXShop/Engines. Un motore può eseguire un solo programma o una catena di programmi, per esempio LuaLaTeX, poi Biber, poi altre due volte LuaLaTeX. TeXShop include motori come LuaLaTeX, XeLaTeX e pdflatexmk; la sottocartella Inactive ne contiene molti altri.

Scegliere un motore

Il menu a comparsa accanto al pulsante «Compila» nella barra strumenti della finestra sorgente elenca i motori. Scegline uno e premi «Compila» o ⌘T. La scelta vale solo per quel documento.

Per compilare i nuovi documenti con un motore, scegli «File del motore» in Impostazioni › Compilazione › Motore › «Compila i nuovi documenti con», poi scegli il motore nel menu «File del motore» che si trova sotto. «Modifica l’elenco dei motori…» apre la cartella Engines nel Finder; il menu «File del motore» segue la cartella man mano che aggiungi, rimuovi o rinomini file. Se il file del motore scelto non è più nella cartella, il menu lo mostra come non trovato e i documenti vengono compilati con LaTeX.

Per legare un documento a un motore, scrivi una riga come questa in una delle sue prime venti righe:

% !TEX program = XeLaTeX

Il nome è quello del file del motore senza .engine; tex e latex compilano plain TeX e LaTeX tramite DVI, mentre pdftex e pdflatex li compilano con PDF diretto. La riga ha la precedenza sulla barra strumenti, sulle impostazioni e su «Compila con motore alternativo». La forma % !TEX TS-program = viene letta allo stesso modo. Scrivi la riga esattamente come mostrato, con uno spazio su ciascun lato del segno di uguale; la macro Set Typesetting Program… del menu Macro inserisce la riga per te, con un elenco di nomi di motori tra cui scegliere. In un progetto con un file principale, solo il file principale ha bisogno della riga.

Compila › Compila con motore alternativo (⌃⌥⌘T) compila una volta con il motore indicato in Impostazioni › Compilazione › Motore › «Motore alternativo», pdflatexmk come impostazione predefinita, senza cambiare la barra strumenti. Nel menu Compila, questa voce compare al posto di Compila mentre tieni premuti i tasti Controllo e Opzione. È adatta ai documenti che di solito si compilano in un solo passaggio veloce e ogni tanto per intero, con latexmk.

Scrivere un motore

Il modo più semplice per creare un motore è duplicarne uno nella cartella Engines nel Finder, rinominare la copia e aprirla in TeXShop per modificarla. Un file del motore deve avere l’estensione .engine e il permesso di esecuzione, che la copia conserva. I documenti aperti in seguito elencano il nuovo motore nella loro barra strumenti. Ecco XeLaTeX.engine:

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

La prima riga indica la shell o il linguaggio dello script; zsh, bash, tcsh, Perl e altri funzionano tutti, purché lo script sia scritto in quel linguaggio. TeXShop esegue il motore nella cartella del file sorgente e gli passa tre valori:

$1
Il nome del file sorgente con la sua estensione, senza la cartella, per esempio main.tex. Uno script che passa a un’altra cartella deve prima annotare il percorso completo, per esempio come "$PWD/$1". In un progetto, è il file principale.
$2
Il resto di una riga % !TEX parameter = … vicino all’inizio del sorgente (del file principale), con più opzioni separate da spazi, per esempio % !TEX parameter = -shell-escape. Senza una riga del genere è un singolo spazio.
$3
La cartella indicata nel campo «Motori TeX» di Impostazioni › Compilazione › Percorsi, oppure quella di «Secondi motori TeX» quando il documento contiene la riga % !TEX useAlternatePath.

Quando il motore termina, TeXShop apre nella finestra di anteprima il file PDF con il nome del sorgente e l’estensione .pdf, se esiste, e scorre fino al punto mostrato prima della compilazione. Uno script che produce un altro tipo di output può indicare che cosa mostrare con le righe seguenti, scritte in un punto qualsiasi del motore all’interno di un commento del suo linguaggio:

RigaEffetto
!TEX-noPreviewnessuna finestra di anteprima, anche se sono presenti altre righe tra quelle sotto
!TEX-pdfPreviewmostra il file PDF
!TEX-htmlPreviewmostra nella finestra HTML il file HTML con lo stesso nome
!TEX-bothPreviewmostra sia il file PDF sia il file HTML
!TEX-noConsolenon mostra la console

Per esempio, un motore che esegue LuaLaTeX, Biber e altre due volte LuaLaTeX potrebbe essere scritto così in zsh, dove ${1:r} è il nome senza estensione:

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

La cartella Inactive

La sottocartella Engines/Inactive contiene motori per flussi di lavoro particolari, spesso con documentazione ed esempi, per esempio per latexmk, ConTeXt, Sage, PreTeXt e Typst. Per usarne uno, spostalo dalla sua cartella nella cartella Engines stessa. Quando TeXShop viene aggiornato, la cartella Inactive viene sostituita con la versione attuale, mentre i file che si trovano direttamente nella cartella Engines non vengono mai toccati, quindi i motori che hai modificato vengono conservati.

Per saperne di più sui motori, consulta il capitolo «Engines and latexmk» in Aiuto › Manuale di TeXShop (in inglese).
