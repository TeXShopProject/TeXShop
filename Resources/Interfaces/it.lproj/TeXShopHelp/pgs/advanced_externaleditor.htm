Usare un editor esterno

Puoi scrivere in un altro editor e usare TeXShop per comporre e per mostrare il PDF.

Aprire solo l’anteprima

File › Apri per Anteprima... chiede un file sorgente e apre solo la sua finestra di anteprima. Se il file non è ancora stato composto, o se il PDF è più vecchio del sorgente, TeXShop lo compone prima. Modifica il sorgente nel tuo editor; per comporre, salvalo lì e premi «Compila» nella finestra di anteprima oppure premi ⌘T. In questa modalità TeXShop non apre né modifica mai il file sorgente. Se la barra strumenti della finestra di anteprima non ha il pulsante «Compila», aggiungilo con Finestra › Personalizza la barra strumenti....

Se lavori sempre in questo modo, attiva Impostazioni › Generali › All’avvio › «Configura per Editor Esterno». File › Apri... e Apri Recenti aprono allora i file sorgente solo per l’anteprima, e File › Apri per Anteprima... diventa «Apri per Editare...», che apre un file sorgente nell’editor di TeXShop quando ti serve. Gli altri file, come PDF, immagini e file di log, si aprono come prima.

Mantenere aggiornata l’anteprima

Quando il PDF viene riscritto da un altro programma, per esempio dal tuo editor o da latexmk nel Terminale, TeXShop lo ricarica quando torni a TeXShop o alla finestra di anteprima, mantenendo la pagina e l’ingrandimento. Con Impostazioni › Anteprima › Aggiornamento › «Controlla sempre le modifiche al PDF fatte da altre app» attivato, ricarica il PDF appena cambia, anche mentre TeXShop è in secondo piano, per esempio quando l’anteprima è affiancata al tuo editor. Un’anteprima con annotazioni non salvate non viene ricaricata, così le annotazioni non vanno perse.

TeXShop controlla anche i file sorgente aperti nel suo editor. Quando un altro editor modifica uno di questi file, TeXShop lo ricarica, a meno che la copia in TeXShop abbia modifiche non salvate.

Sincronizzare con l’editor

Un Comando-clic nella finestra di anteprima può portarti alla riga corrispondente nel tuo editor, e «Vai all’errore» nella console può aprire lì la riga di un errore. Servono «Configura per Editor Esterno», un’impostazione nascosta e un programma a riga di comando dell’editor:

  • Per TextMate, il cui comando mate si trova in /usr/local/bin: defaults write TeXShop TextMateSync YES.
  • Per qualsiasi altro editor: defaults write TeXShop OtherEditorSync YES e uno script eseguibile /usr/local/bin/othereditor che riceve il numero di riga come $1 e il percorso completo del file come $2. Per BBEdit è così: 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

Per la direzione opposta, da una riga dell’editor alla finestra di anteprima, l’editor chiama TeXShop tramite AppleScript con i comandi sync_preview_line, sync_preview_index e sync_preview_name. Il capitolo «Using an External Editor» in Aiuto › Manuale di TeXShop (in inglese) contiene uno script completo.

La cartella ~/Library/TeXShop/ExternalEditorScripts contiene un supporto già pronto con la relativa documentazione: AppleScript che compongono e mostrano in anteprima in TeXShop un documento di BBEdit, e un plug-in per Vim.

Comandi AppleScript per gli editor

Un editor può chiamare questi comandi AppleScript di un documento di TeXShop:

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Compongono, oppure eseguono plain TeX, LaTeX, BibTeX, MakeIndex o MetaPost. La chiamata ritorna subito, senza attendere la fine della composizione; l’anteprima viene aggiornata quando questa termina.
taskdone
Restituisce NO mentre la composizione è in corso e YES quando è terminata.
refreshpdf
Ricarica il PDF e porta in primo piano la finestra di anteprima.
refreshpdfbackground
Ricarica il PDF senza portare TeXShop in primo piano, quando la finestra di anteprima è già aperta.
refreshtext
Rilegge il file sorgente dal disco.
open_for_externaleditor
Apre un file sorgente come fa File › Apri per Anteprima....

Quando l’editor compone tramite TeXShop, «Controlla sempre le modifiche al PDF fatte da altre app» non serve. Consulta anche Scrivere script con i comandi di composizione di TeXShop.
