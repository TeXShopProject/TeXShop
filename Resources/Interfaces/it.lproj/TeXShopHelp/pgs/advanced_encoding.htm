Codifiche

TeXShop modifica il testo in Unicode, quindi la finestra sorgente accetta qualunque carattere di qualunque lingua. La codifica stabilisce come questo testo viene scritto nel file su disco e riletto. UTF-8 può memorizzare ogni carattere, e LaTeX, XeLaTeX e LuaLaTeX lo leggono per impostazione predefinita. I file meno recenti e i file provenienti da altri sistemi possono usare un’altra codifica, come ISO Latin 9 o Shift JIS.

Nuovi documenti

I nuovi documenti vengono salvati nella codifica scelta in Impostazioni › Documenti e salvataggio › Codifica › «Codifica dei nuovi documenti». Il valore predefinito è Unicode (UTF-8); mantienilo, a meno che tu non scambi file con persone che hanno bisogno di un’altra codifica.

Un documento viene salvato nella codifica con cui è stato aperto, quindi un file meno recente mantiene la sua codifica. I caratteri che la codifica di un file non può rappresentare vanno persi quando il file viene salvato.

Aprire i file

Quando si apre un file senza riga di codifica (vedi sotto), TeXShop ne rileva la codifica. Un indicatore dell’ordine dei byte (BOM) identifica i file UTF-8 e UTF-16. Un file composto solo da caratteri ASCII viene letto nella codifica dei nuovi documenti. Altrimenti TeXShop usa la codifica che il programma che ha salvato il file ha registrato insieme al file, se macOS ha conservato questa informazione, poi prova UTF-8 e poi le codifiche delle tue lingue e la codifica dei nuovi documenti. Una codifica dichiarata nel sorgente, per esempio con \usepackage[latin9]{inputenc}, viene usata come indizio.

Il rilevamento è una stima e funziona meglio con file che contengono una buona quantità di testo. Se sceglie la codifica sbagliata, chiudi il file senza salvarlo, aprilo di nuovo con File › Apri..., premi «Opzioni» nella finestra di dialogo Apri e scegli la codifica nel suo menu; la codifica scelta lì viene usata per i file aperti in quel momento, e il documento la mantiene. Il menu mostra all’inizio la codifica dei nuovi documenti; se lo lasci su quella codifica, non conta come scelta e la codifica viene rilevata come di consueto. Poi aggiungi al file una riga di codifica, così si aprirà sempre correttamente. Il rilevamento si può disattivare con l’impostazione nascosta

defaults write TeXShop EncodingAutoDetection NO

I file vengono allora letti nella codifica dei nuovi documenti.

La riga di codifica

Una riga posta in una delle prime venti righe di un file sorgente ne fissa la codifica per la lettura e per il salvataggio, con precedenza su tutto il resto:

% !TEX encoding = UTF-8 Unicode

Scrivi la riga come mostrato, con uno spazio prima del segno di uguale; viene letta anche %!TEX encoding =, senza lo spazio dopo %. Il nome deve essere scritto esattamente come nella tabella qui sotto. La macro Encoding del menu Macro inserisce la riga per te, con un elenco di codifiche tra cui scegliere. Vengono riconosciuti anche i nomi usati da TeXworks, come UTF-8 o ISO 8859-1.

Se la riga indica una codifica che TeXShop non conosce, TeXShop legge il file come UTF-8 e lo segnala. Se la riga indica UTF-8 ma il file non è UTF-8 valido, TeXShop lo segnala e apre il file in ISO Latin 9, che legge qualunque file; salvandolo senza modificare la riga si riscrivono gli stessi byte, quindi non si perde nulla. Per aprire un file senza applicare la sua riga di codifica, tieni premuto Opzione mentre si apre.

Salvare in un’altra codifica

Per scegliere la codifica al momento del salvataggio, attiva Impostazioni › Documenti e salvataggio › Codifica › «Mostra la codifica nel dialogo Salva»; la finestra di dialogo Salva ha allora un menu delle codifiche. Modifica › Trasformazioni › Cambia codifica sceglie la codifica in cui il documento aperto verrà salvato da quel momento in poi. Se il file ha una riga di codifica, decide la riga; modifica invece la riga. TeXShop conserva l’indicatore dell’ordine dei byte di un file UTF-8 e l’ordine dei byte di un file UTF-16.

Convertire un file in un’altra codifica fa perdere ogni carattere che la nuova codifica non può rappresentare, e leggere un file nella codifica sbagliata e poi salvarlo ne sostituisce i caratteri definitivamente. Conserva una copia dell’originale. Il programma da riga di comando iconv converte i file senza modificare l’originale. Il documento «Codifica dei file e TeXShop» (in inglese) nel menu Aiuto tratta queste questioni più in dettaglio.

Lingue da destra a sinistra

L’arabo, l’ebraico e il persiano si scrivono da destra a sinistra nella finestra sorgente. Quando Impostazioni › Editor › Digitazione › «Lingue da destra a sinistra (arabo, ebraico, persiano)» è attivato e l’evidenziazione della sintassi è attiva, le righe che iniziano con caratteri arabi o ebraici sono allineate a destra, e le altre righe, per esempio quelle che iniziano con un comando LaTeX, a sinistra. Con l’impostazione nascosta

defaults write TeXShop RightJustifyIfAny YES

ogni riga che contiene questi caratteri in qualunque punto viene allineata a destra. L’allineamento serve solo per la modifica; TeX impagina il testo composto secondo i propri comandi. Per comporre queste lingue, usa XeLaTeX o LuaLaTeX; consulta XeLaTeX e LuaLaTeX.

Scrivere in altri sistemi di scrittura

Per scrivere in un altro sistema di scrittura, aggiungi una sorgente di input in Impostazioni di Sistema › Tastiera, nella sezione «Immetti testo», e passa da una sorgente di input all’altra con il menu delle sorgenti di input nella barra dei menu.
