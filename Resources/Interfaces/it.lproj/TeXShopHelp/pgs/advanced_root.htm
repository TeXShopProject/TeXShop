Impostare il file principale di un progetto

I documenti lunghi sono spesso divisi in più file: un file principale con il preambolo, che include un file per ogni capitolo. Per esempio, un file principale Main.tex potrebbe essere così:

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

Quando modifichi two.tex, TeXShop deve comporre Main.tex, non il capitolo, che non ha preambolo. Per indicarglielo, scrivi questa riga in una delle prime venti righe di ogni file di capitolo:

% !TEX root = ../Main.tex

Il file principale non ha bisogno di questa riga. Il nome del file principale si può indicare

  • con il solo nome, Main.tex, quando si trova nella stessa cartella del file di capitolo;
  • in modo relativo alla cartella del file di capitolo, ../Main.tex o ../../Main.tex;
  • con il percorso completo, /Users/me/Book/Main.tex, che va modificato quando il progetto viene spostato.

La macro Root del menu Macro inserisce la riga: chiede il file principale e propone una riga relativa o assoluta, sostituendo una riga root precedente.

Che cosa fa la riga root

  • Compila in un file di capitolo compone il file principale, e la finestra di anteprima del file principale mostra l’intero documento. Una riga % !TEX program o altre righe speciali per la composizione vanno nel file principale.
  • Vai all'Errore apre il file che contiene un errore, se non è aperto, e va alla riga.
  • La sincronizzazione dalla finestra di anteprima apre il file di capitolo che contiene il punto su cui hai fatto clic; consulta Sincronizzare sorgente e anteprima.
  • Butta i File Ausiliari nel Cestino elimina i file ausiliari del file principale; consulta Eliminare i file ausiliari.
  • Finestra › Sorgente ⇔ Anteprima (⌘1) in un file di capitolo porta in primo piano la finestra di anteprima del file principale. Usandolo di nuovo nella finestra di anteprima torni alla finestra sorgente da cui sei arrivato, oppure al file principale se non sei arrivato da una finestra sorgente.

Aprire un file di capitolo

Quando si apre un file di capitolo con una riga root, TeXShop apre anche il file principale e la sua finestra di anteprima. Due voci in Impostazioni › Generali › «File principale del progetto» lo controllano: «Aprire il file principale quando si apre un documento» attiva o disattiva questo comportamento, e «Riduci la finestra principale all'apertura» manda nel Dock la finestra sorgente del file principale, che raramente si modifica mentre lavori su un capitolo.

Trovare e sostituire in tutto il progetto

Per cercare in tutti i file di un progetto in una volta, scegli Modifica › Trova › Cerca nei sorgenti TeX con la stessa TEX root… in uno dei suoi file di capitolo, oppure Cerca nei sorgenti TeX con questo file come TEX root… nel file principale. La ricerca riguarda il file principale e i file .tex nella sua cartella e nelle sottocartelle che lo indicano in una riga root nelle prime 20 righe. Consulta Cerca nei sorgenti TeX e Trova e sostituisci.

File principali indicati nei file .texshop

Anche un file con l’estensione .texshop accanto a un file di capitolo, come two.texshop per two.tex, può indicare il file principale, e TeXShop lo legge ancora. Nessun comando di menu crea questi file; usa una riga % !TEX root, che viaggia insieme al sorgente.
