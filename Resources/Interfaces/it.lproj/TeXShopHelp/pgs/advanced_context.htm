ConTeXt e MetaPost

ConTeXt

ConTeXt è un pacchetto di macro di Hans Hagen, un’alternativa a LaTeX con comandi propri e una forte attenzione al progetto tipografico. TeX Live include ConTeXt, e ConTeXt Garden distribuisce una versione, aggiornata spesso, che si installa nella tua cartella Inizio.

I motori per ConTeXt si trovano in ~/Library/TeXShop/Engines/Inactive/ConTeXt, insieme alla guida Setting-Up-ConTeXt.pdf e ad alcuni documenti di esempio:

MotoreCompila con
ConTeXt.engineil ConTeXt di TeX Live che funziona su LuaTeX
ConTeXt-TL.engineil ConTeXt di TeX Live che funziona su luametatex
ConTeXt-CG.enginela versione di ConTeXt Garden nella tua cartella Inizio

Sposta il motore che ti serve in ~/Library/TeXShop/Engines e scrivi delle righe speciali all’inizio del file principale del documento, per esempio:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Per ConTeXt-CG, inserisci la cartella dei programmi dell’installazione di ConTeXt Garden nel campo «Secondi motori TeX» di Impostazioni › Compilazione › Percorsi e aggiungi la riga % !TEX useAlternatePath, con cui TeXShop passa al motore quella cartella invece di quella di TeX Live.

Per la sincronizzazione tra sorgente e anteprima, aggiungi \setupsynctex[state=start,method=min] all’impostazione del documento; la riga % !TEX useConTeXtSyncParser fa sì che TeXShop usi il codice di sincronizzazione proprio di ConTeXt. Il capitolo su ConTeXt di Aiuto › Manuale di TeXShop (in inglese) descrive in dettaglio l’installazione della versione di ConTeXt Garden e ogni motore.

Per elencare nel menu Tag i comandi di sezione di ConTeXt come \title e \subject, attiva l’impostazione nascosta ConTeXtTags; consulta Impostazioni nascoste.

MetaPost

MetaPost, di John Hobby, disegna illustrazioni a partire da una descrizione in un linguaggio di programmazione derivato da METAFONT di Knuth. Il suo manuale fa parte di TeX Live: scegli Aiuto › Mostra aiuto per il pacchetto... e digita metapost.

Compila › MetaPost (⇧⌘M), oppure MetaPost nel menu a comparsa accanto al pulsante «Compila», esegue MetaPost sul file che ha il nome del documento attivo e l’estensione .mp: sul documento stesso se è un file .mp, altrimenti sul file .mp che gli sta accanto, come quello che il pacchetto mfpic scrive per un documento .tex. Esegue il comando di Impostazioni › Compilazione › Strumenti correlati › MetaPost, che è mpost per impostazione predefinita. I profili del motore impostano questo campo: pmpost per pLaTeX + dvipdfmx e upmpost per upLaTeX + dvipdfmx, che compilano il testo giapponese nelle etichette, e mpost per gli altri profili. LuaLaTeX non può includere figure le cui etichette in giapponese sono state composte da pmpost o upmpost; con LuaLaTeX, disegna queste figure all’interno del documento con il pacchetto luamplib.

Per salvare un nuovo file come file MetaPost, scegli il tipo mp nel menu «Tipo di file» della finestra di dialogo Salva.

Il motore nv-metapost, di Nicola Vitacolonna, semplifica il lavoro con MetaPost e mostra le figure di un file nella finestra di anteprima. Si trova in ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; il file README.rtf e la cartella examples, un livello più su in MetaPostEngines-1.4.7, spiegano come installarlo e usarlo e forniscono file di esempio. Per esempio, un file che inizia con

% !TEX program = nv-metapost
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

viene compilato con nv-metapost quando quel motore si trova nella cartella Engines.

I disegni MetaPost si possono scrivere anche all’interno di un documento LaTeX, con il pacchetto luamplib per LuaLaTeX, oppure con pacchetti come mfpic, che scrivono i disegni in un file .mp elaborato da MetaPost tra due compilazioni.
