Scrivere script con i comandi di compilazione di TeXShop

Un documento con una bibliografia richiede una sequenza di compilazioni: LaTeX scrive il file .aux, BibTeX lo usa per scrivere i file .bbl e .blg, LaTeX viene eseguito di nuovo per aggiungere la bibliografia al documento e un’altra volta ancora per aggiornarne i riferimenti. I tuoi progetti potrebbero richiedere sequenze simili, e una macro AppleScript può eseguirle al posto tuo.

La macro Macro › Applescript › Run LaTeX, BibTeX, Then LaTeX Twice, fornita con TeXShop, mostra come fare. Ecco il suo contenuto:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

La prima riga fa di questa una macro AppleScript eseguita da ScriptRunner, così può chiedere a TeXShop di compilare (consulta Macro AppleScript). Le righe successive controllano #FILEPATH#, il percorso completo del file sorgente. È una stringa vuota quando il documento non è ancora stato salvato; in tal caso lo script ti chiede di salvarlo e si ferma.

Lo script si riferisce poi al documento tramite #DOCUMENTNAME#. TeXShop salva il documento da sé quando inizia un comando di compilazione, quindi lo script non ha bisogno di salvarlo.

I comandi rimanenti eseguono latexinteractive, bibtex, latex e latex. Un comando di compilazione restituisce subito il controllo allo script, prima che la compilazione sia terminata, perciò dopo ogni comando un ciclo repeat attende finché taskdone segnala che il lavoro è completato. La riga delay 2 fa sì che lo script faccia una pausa tra un controllo e l’altro, invece di chiedere di continuo e rallentare il computer. I comandi sono elencati in Definire macro AppleScript.
