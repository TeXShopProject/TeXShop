Segnalare problemi

Per segnalare un problema o suggerire un miglioramento, apri una issue su GitHub:

https://github.com/TeXShopProject/TeXShop/issues

Cerca prima tra le issue aperte e chiuse: il problema potrebbe essere già noto o risolto in una versione più recente. Per aprire una issue serve un account GitHub.

Una segnalazione su cui si può intervenire rapidamente indica:

  • la versione di TeXShop (TeXShop › Informazioni su TeXShop) e di macOS;
  • che cosa hai fatto, che cosa ti aspettavi e che cosa è successo invece;
  • per i problemi di compilazione, un breve file sorgente che mostri il problema, e l’output della console o il file di log;
  • per i problemi con finestre o menu, un’istantanea dello schermo o una breve registrazione dello schermo.

Le domande su TeX, sui pacchetti LaTeX o su TeX Live stesso è meglio porle nei luoghi elencati in Siti web utili, come TeX Stack Exchange.
