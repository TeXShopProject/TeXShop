Aprire altri file con TeXShop

TeXShop apre qualsiasi file di testo, quindi puoi leggere i file di log, i file aux e altri file di TeX accanto ai tuoi documenti. Apre anche file PDF e immagini.

File trattati come sorgenti TeX

I file con le estensioni seguenti, e i file senza estensione, sono per TeXShop sorgenti TeX: vengono mostrati con l’evidenziazione della sintassi e si possono compilare.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

Gli altri file di testo, come i file .log, .aux, .bst, .engine o .txt, si aprono come testo semplice, senza evidenziazione della sintassi.

Per fare in modo che TeXShop tratti come sorgenti TeX i file con un’altra estensione, aggiungi l’estensione con un’impostazione nascosta nel Terminale; ad esempio, per i file ConTeXt con estensione mkiv:

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

File PDF e immagini

I file PDF e le immagini con estensione .png, .jpg, .jpeg, .tif, .tiff ed .eps si aprono in una finestra propria. I file DVI e PostScript (.dvi, .ps) vengono convertiti in PDF e mostrati.

Salvare con un’altra estensione

Quando TeXShop salva un file, ne mantiene l’estensione. Un nuovo documento viene salvato come file .tex, a meno che tu non scelga un altro tipo, come sty, bib o mp, nel menu «Tipo di file» della finestra di dialogo Salva.

TeXShop salva un file nella codifica con cui è stato aperto. È pensato per TeX e per i file correlati; un file in un formato insolito può cambiare se viene salvato dopo essere stato modificato in TeXShop. Consulta Codifiche.
