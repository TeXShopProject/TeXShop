Stampa

Per stampare il documento compilato, scegli File › Stampa... (⌘P) nella finestra di anteprima o nella finestra sorgente. In un progetto con un file principale viene stampato il documento principale compilato.

La finestra di dialogo di stampa ha una sezione TeXShop con le stesse scelte dell’app Anteprima di Apple. Con «Rotazione automatica», ogni pagina viene ruotata in base alla carta, quindi una pagina in formato orizzontale viene stampata di traverso su carta verticale. Con «Adatta in scala», ogni pagina viene ridimensionata per entrare nella carta; scegli invece «Scala» per stampare con una percentuale fissa. All’inizio sono entrambe attive, e le scelte dell’ultima stampa vengono conservate per il documento finché resta aperto. L’orientamento della carta segue quello della prima pagina.

Per stampare il testo del sorgente, scegli File › Stampa sorgente.... File › Formato di stampa... sceglie il formato della carta.
