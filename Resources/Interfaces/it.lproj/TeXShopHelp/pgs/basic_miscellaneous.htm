Finestre e pannelli

Le finestre di TeXShop si possono raccogliere come pannelli di un’unica finestra, come nelle altre app di macOS. In Impostazioni › Generali, «Apri finestre come pannelli» sceglie quando ciò avviene: «Mai», «Automaticamente», che segue l’impostazione dei pannelli di macOS, oppure «Sempre».

Con «Sempre» e con finestre separate per sorgente e anteprima, il sorgente di ogni documento che apri diventa un pannello della finestra sorgente e la sua anteprima un pannello della finestra di anteprima; le console e i log vengono raccolti allo stesso modo. Selezionando un pannello di una finestra, il pannello corrispondente dell’altra viene in primo piano quando compila o sincronizzi. Se sorgente e anteprima sono mostrati in un’unica finestra («Sorgente e anteprima» in Impostazioni › Generali impostato su «Usa un’unica finestra»), ogni pannello contiene un intero documento. Finestra › Usa un’unica finestra e Finestra › Usa finestre separate passano il documento attivo da un modo all’altro.

Una finestra che mostra insieme sorgente e anteprima, con o senza pannelli, funziona bene a tutto schermo: la console resta allora sospesa sopra di essa mentre compila.

Aprire un progetto in pannelli

Per un libro i cui capitoli sono file separati, il file principale può chiedere a TeXShop di aprire i capitoli come pannelli della sua finestra. Metti questa riga tra le prime 20 righe del file principale:

% !TEX useTabs

Quando si apre il file principale, i file indicati dai suoi comandi \include si aprono come pannelli. Sulla stessa riga possono seguire dei nomi brevi per i pannelli, tra parentesi e separati da virgole; un elemento vuoto tra due virgole mantiene il nome di quel file:

% !TEX useTabs (Intro, Groups, , Fields)

Per dare un pannello anche ai file dei comandi \input, usa questa impostazione nascosta nel Terminale:

defaults write TeXShop TabsAlsoForInputFiles YES

Per scegliere tu i file, metti una riga useTabsWithFiles tra le prime 20 righe del file principale e aggiungi una riga tabbedFile per ogni pannello, tutte tra le sue prime 50 righe. Un nome per il pannello può seguire tra parentesi:

% !TEX useTabsWithFiles
% !TEX tabbedFile{chapter1/Introduction.tex} (Introduction)
% !TEX tabbedFile{Galois.log}
% !TEX tabbedFile{~/Graphics/diagram.pdf}

Un percorso è relativo alla cartella del file principale, parte dalla tua cartella Inizio con ~, oppure è un percorso completo. Scrivi sempre l’estensione, anche quando il Finder la nasconde: questi pannelli possono mostrare anche log, file PDF e immagini. Ogni file si apre come se lo aprissi tu, quindi un file sorgente può portare con sé la sua anteprima.
