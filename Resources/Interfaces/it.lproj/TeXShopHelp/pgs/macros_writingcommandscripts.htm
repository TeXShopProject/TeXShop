Scrivere script con comandi della shell

Questa pagina usa la macro pdflatexc di Claus Gerhardt, in Macro › Claus Gerhardt Macros, per mostrare come un AppleScript richiama uno script della shell. Lo script della shell in sé è semplice: aggiunge al percorso di ricerca le cartelle dei programmi TeX ed esegue pdflatex con --shell-escape. I tuoi script probabilmente faranno di più, per esempio eseguiranno diversi programmi in sequenza; è allora che queste tecniche diventano utili.

Lo script della shell

Lo script della shell è ~/Library/TeXShop/bin/pdflatexc. Non dipende da TeXShop: se la sua cartella è nel tuo percorso di ricerca, digitando pdflatexc myfile.tex in Terminale lo si esegue. Eccolo:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

L’AppleScript

La macro che richiama questo script della shell è più interessante:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Dopo i commenti, le prime sette righe sono una ricetta di Claus Gerhardt per salvare il file sorgente e trovare il nome del suo documento, che viene messo in frontName. Il lavoro lo fa lo script compilato setname.scpt in ~/Library/TeXShop/Scripts: queste righe trovano il percorso ~/Library/TeXShop/Scripts/setname.scpt, caricano lo script e lo richiamano con #NAMEPATH# e #TEXPATH#.

Spesso si può ottenere lo stesso risultato in modo più semplice con

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

La ricetta ha due vantaggi. Funziona anche quando il documento in primo piano non è quello che deve ricevere i comandi successivi, per esempio un file di log come /Users/name/Examples/myfile.log. E se il file non è mai stato salvato, la ricetta restituisce un errore, mentre il comando save lascerebbe lo script in attesa dietro una finestra di dialogo di salvataggio.

Le sei righe successive impostano le variabili dirName e baseName. Se il file sorgente è /Users/name/My Papers/Stuff/myfile.tex, dirName è '/Users/name/My Papers/Stuff', racchiuso tra virgolette per la shell a causa dello spazio nel nome di una cartella, e baseName è myfile.tex. Il nome del file viene racchiuso tra virgolette allo stesso modo quando viene passato allo script della shell, quindi entrambi possono contenere spazi.

Le tre righe successive richiamano lo script della shell. Il risultato è lo stesso che si otterrebbe digitando cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' in Terminale. Le ultime tre righe aggiornano la finestra di anteprima.

Alcune di queste righe sono complicate, ma si possono copiare senza modifiche in nuovi script.

Eseguire comandi della shell da AppleScript

AppleScript esegue un comando della shell nella forma

do shell script "cmd input"

Per costruire un comando a partire da più parti, scrivilo nella forma equivalente

do shell script "cmd " & "input"

Nota lo spazio dopo cmd. La e commerciale unisce due stringhe:

"cmd " & "input" = "cmd input"

Una shell avviata da AppleScript parte dalla cartella radice. Il comando

do shell script "cd " & dirName

passa alla cartella contenuta in dirName, che è già racchiusa tra virgolette, quindi non servono altre virgolette.

Ogni do shell script avvia una nuova shell, quindi un comando successivo non si troverebbe in quella cartella. Per eseguire altri comandi nella stessa cartella, uniscili con il punto e virgola in un unico comando, come in Terminale:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

Lo script qui sopra fa proprio questo con cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc e input2 = baseName. Le righe

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

sono semplicemente un modo comodo per mettere questa sequenza in un’unica variabile.
