Ottenere i nuovi elementi della libreria

TeXShop conserva i file che puoi modificare, come modelli, macro, motori, associazioni dei tasti, il file del Pannello LaTeX e i temi, in ~/Library/TeXShop, la cartella TeXShop della cartella Libreria nella tua cartella Inizio. TeXShop › Apri ~/Library/TeXShop la apre nel Finder. Quando TeXShop viene eseguito per la prima volta, crea questa cartella con il contenuto predefinito.

Che cosa cambia una nuova versione

Una nuova versione di TeXShop lascia invariata la maggior parte di ~/Library/TeXShop, così le tue modifiche vengono conservate. Alcune posizioni contengono file di supporto di TeXShop stesso o elementi facoltativi, e una nuova versione li aggiorna:

  • le cartelle bin, Documents, ExternalEditorScripts e Scripts;
  • Engines/Inactive e HTML/Inactive, che contengono motori e file HTML che puoi spostare per usarli;
  • HTML/Help.html, la pagina mostrata da Aiuto › Comandi HTML (in inglese);
  • la cartella New, che viene sostituita per intero.

In queste posizioni ogni file fornito con TeXShop viene sostituito dalla sua nuova versione, quindi le modifiche che hai fatto a un file di questo tipo vanno perse; i nuovi file vengono aggiunti e i file che hai aggiunto con altri nomi restano come sono. Per conservare una tua versione di uno di questi file, salvala con un altro nome.

I motori in uso, nella cartella Engines stessa, non vengono modificati. Solo quando la cartella è stata aggiornata l’ultima volta da una versione di TeXShop precedente alla 6.00, TeXShop aggiunge html.engine a Engines, una sola volta e solo se lì non c’è già un file con quel nome. Nella cartella Macros, alcune macro fornite con TeXShop e mai modificate, come quella che apre il sito web di TeXShop, vengono aggiornate al testo attuale; le macro modificate e le tue macro restano come sono. Tutto il resto conserva le tue modifiche.

TeXShop registra la propria versione in un file nascosto .Version in ~/Library/TeXShop/New e aggiorna la cartella solo quando è più recente della versione registrata lì. Così ~/Library/TeXShop non viene riscritta a ogni avvio di TeXShop, e una versione meno recente di TeXShop si può eseguire senza modificarla.

La cartella New

La cartella New contiene elementi che potresti voler aggiungere tu stesso, per esempio nuovi modelli. Sposta l’elemento nella cartella giusta, come Templates, e modificalo come preferisci. Aiuto › Info su questa versione (in inglese) indica quando c’è qualcosa da prendere.

File mancanti e danneggiati

Quando un file di cui TeXShop ha bisogno, come le macro, il file del Pannello LaTeX, le associazioni dei tasti, KeyEquivalents.plist o un tema, manca o è danneggiato, TeXShop lo sostituisce con una propria copia all’avvio, senza alcun messaggio. Il file danneggiato viene conservato in ~/Library/TeXShop/Backups, così puoi recuperare da lì le tue modifiche.

Ottenere il contenuto predefinito di una cartella

Per ottenere il contenuto predefinito più recente di una cartella, per esempio Templates, esci da TeXShop, sposta quella cartella fuori da ~/Library/TeXShop (per esempio sulla scrivania) e avvia di nuovo TeXShop. TeXShop crea la cartella con il suo contenuto predefinito. Poi ricopia dalla cartella spostata ciò che vuoi conservare.
