Protezione da shell escape

Durante la compilazione TeX può eseguire altri programmi. Per impostazione predefinita TeX Live consente solo un breve elenco di programmi affidabili, ad esempio per convertire la grafica EPS in PDF. I pacchetti che devono eseguire altri programmi richiedono l’opzione -shell-escape (scritta anche --shell-escape).

Con questa opzione un documento può eseguire qualsiasi comando, ad esempio uno che elimina tutti i file della tua cartella Inizio. Usala solo per documenti di cui ti fidi, e non per i file che ricevi da altri.

Aggiungere l’opzione

  • Nel comando LaTeX o plain TeX di Impostazioni › Compilazione › PDF diretto, per tutti i documenti compilati con PDF diretto.
  • In un file del motore, per tutti i documenti compilati con quel motore; consulta Aggiungere motori di compilazione.
  • Per un singolo documento compilato con uno dei motori latexmk, come pdflatexmk, con la riga % !TEX parameter = -shell-escape all’inizio del sorgente.

Un motore ha già l’opzione: sepdflatexmk, fornito con TeXShop e presente fin dall’inizio nella cartella Engines, compila sempre con --shell-escape. Basta sceglierlo nella barra strumenti della finestra sorgente o con una riga % !TEX program = sepdflatexmk, quindi usalo solo per documenti di cui ti fidi.

Chiedi conferma per shell-escape

Impostazioni › Compilazione › PDF diretto › «Chiedi conferma per shell-escape», disattivata per impostazione predefinita, protegge i comandi del gruppo PDF diretto. Quando è attiva e il comando plain TeX o LaTeX di quel gruppo contiene -shell-escape o --shell-escape, TeXShop chiede conferma prima di compilare un documento per la prima volta dopo la sua apertura:

  • «OK» compila con l’opzione.
  • «Ometti shell-escape» compila senza l’opzione.
  • «Annulla» non compila.

Dopo che hai scelto «OK» o «Ometti shell-escape», la risposta vale per quel documento finché non viene chiuso; così puoi compilare i tuoi documenti con l’opzione e quelli ricevuti da altri senza. I file del motore non vengono controllati, anche se contengono -shell-escape, quindi sepdflatexmk compila con l’opzione senza chiedere.
