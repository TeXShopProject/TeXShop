Modalità di composizione alternativa

Di solito TeXShop compone con il metodo PDF diretto: pdfLaTeX o pdfTeX scrive direttamente il file PDF. Il metodo alternativo, Tramite DVI, esegue LaTeX o TeX per creare un file DVI, lo converte in PostScript con dvips e converte il PostScript in PDF con Ghostscript. Questi passaggi li esegue lo script simpdftex di TeX Live.

Tramite DVI serve per i documenti che inseriscono codice PostScript nel risultato, per esempio con il pacchetto pstricks. Le immagini EPS non ne hanno bisogno: TeX Live le converte in PDF durante la composizione con PDF diretto.

Scegliere il metodo

Compilatore › Tramite DVI e Compilatore › PDF diretto cambiano il metodo del documento attivo; gli altri documenti aperti mantengono il proprio. Impostazioni › Composizione › «Metodo di composizione» imposta il metodo con cui iniziano i documenti. La sua terza scelta, «Script personale», esegue invece i comandi del gruppo «Script personale». I comandi di Tramite DVI, uno per plain TeX e uno per LaTeX, si trovano nel gruppo «Tramite DVI» di Impostazioni › Composizione. Il profilo del motore LaTeX + dvips + Ghostscript, sotto «Altro» nel menu «Profilo del motore», imposta la composizione Tramite DVI.

Scegliere il metodo nel documento

Una riga tra le prime 20 righe del sorgente imposta il programma e il metodo per quel documento, indipendentemente dalle impostazioni:

RigaCompone con
% !TEX program = pdflatexLaTeX, PDF diretto
% !TEX program = latexLaTeX, Tramite DVI
% !TEX program = pdftexplain TeX, PDF diretto
% !TEX program = texplain TeX, Tramite DVI
% !TEX program = personallatexLaTeX, Script personale
% !TEX program = personaltexplain TeX, Script personale

Opzioni per Tramite DVI

Per impostazione predefinita Ghostscript ignora la trasparenza PostScript. Per mantenerla, aggiungi --distilleropts "-dALLOWPSTRANSPARENCY" alla fine del comando nel gruppo «Tramite DVI». Per conservare il file PostScript intermedio, aggiungi --keep-psfile. Ghostscript viene eseguito dalla cartella indicata in Impostazioni › Composizione › Percorsi › Ghostscript.
