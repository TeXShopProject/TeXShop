Macro AppleScript predefinite

TeXShop include una raccolta di macro AppleScript di Will Robertson, Claus Gerhardt e altri. Alcune eseguono in sequenza una serie di comandi di compilazione. Copiandole e modificandole, puoi costruire script per il tuo lavoro. Questa pagina ne descrive alcune, con i nomi che hanno nel menu Macro.

Column macros, Insert reference, Open quickly…

Queste macro sono di Will Robertson. Nel sottomenu Column macros, New tabular e New array inseriscono un ambiente tabular o array con il numero di righe e di colonne che inserisci, e Add column e Delete column modificano le righe che selezioni. Insert reference cerca nel file corrente i comandi \label{…} e ti permette di scegliere un’etichetta da un elenco; inserisce l’etichetta racchiusa in \ref{…}, un comando che puoi cambiare nello script. Se è selezionato del testo, vengono elencate solo le etichette che lo contengono. Open quickly… elenca i file .tex, .sty e .pdf nella cartella del file sorgente corrente e apre quelli che scegli.

Paste Spreadsheet Cells

Questa macro, di Alan Munn, incolla nel sorgente LaTeX celle di un foglio di calcolo sotto forma di tabella. Seleziona un intervallo di celle in Excel o in un’altra applicazione per fogli di calcolo e copiale. Poi scegli Macro › Paste Spreadsheet Cells e scegli uno stile di tabella:

cells
converte il testo copiato soltanto in celle di tabella LaTeX.
booktabs
prende la prima riga come intestazione e colloca \toprule, \midrule e \bottomrule in un ambiente tabular.
simple
racchiude le celle in un semplice ambiente tabular.
longtable
prende la prima riga come intestazione, aggiunge le righe di intestazione di una longtable e mette le celle in un ambiente longtable.

La macro sostituisce il contenuto degli appunti con il testo LaTeX. Per incollare le stesse celle in un altro stile, copiale prima di nuovo nel foglio di calcolo.

Applescript › Save Copy with Unix Line Endings, Save Copy with Windows Line Endings, Save Copy with Classic Mac Line Endings

I file di testo terminano le righe in modi diversi: macOS e Unix con un avanzamento di riga (line feed), Windows con un ritorno a capo (carriage return) seguito da un avanzamento di riga, e i file Macintosh molto vecchi con un solo ritorno a capo. TeXShop li legge tutti e tre. Se l’editor di qualcun altro non ci riesce, usa queste macro. Per un file sorgente MyFile.tex, Save Copy with Unix Line Endings scrive una copia del file salvato chiamata MyFile_Unix.tex con avanzamenti di riga; Save Copy with Windows Line Endings scrive MyFile_Windows.tex e Save Copy with Classic Mac Line Endings scrive MyFile_Mac.tex. Le macro usano il programma flip di Craig Stuart Sapp in ~/Library/TeXShop/bin.

Applescript › Run LaTeX, BibTeX, Then LaTeX Twice

Un documento con una bibliografia richiede diverse esecuzioni: LaTeX scrive il file .aux, BibTeX lo usa per scrivere i file .bbl e .blg, LaTeX viene eseguito di nuovo per aggiungere la bibliografia e un’altra volta ancora per aggiornarne i riferimenti. Questa macro le esegue una dopo l’altra. Scrivere script con i comandi di compilazione di TeXShop spiega come funziona.

Claus Gerhardt Macros

La maggior parte delle macro di questo sottomenu richiama script della shell in ~/Library/TeXShop/bin, come pdflatexc, che esegue pdfLaTeX, e bibtexc, che esegue BibTeX. Ogni macro il cui nome inizia con Run esegue i programmi che nomina, in quell’ordine, e Open PDF apre il PDF del documento. Run LaTeX, dvips and ps2pdf richiede inoltre Ghostscript. Funzionano su un file salvato. Scrivere script con comandi della shell prende come esempio Run pdfLaTeX with Shell Escape.

Make HTML with TeX4ht

TeX4ht converte un documento LaTeX in una pagina web: una pagina HTML e alcuni file di immagine. Make HTML with TeX4ht esegue htlatex sul documento e apre in Safari il file HTML risultante. Non è necessario caricare il pacchetto tex4ht nel documento; lo carica htlatex. Make HTML with TeX4ht, Remaking Images esegue htlatex con l’opzione -r, che crea di nuovo le immagini anche quando esistono già.

Extract Pages from PDF…

Extract Pages from PDF… crea file PDF che contengono pagine scelte del PDF del documento. Prima chiede quanti file creare, poi le pagine di ciascun file, per esempio 5:8 per le pagine da 5 a 8 oppure 3:4,6,8:12. Se il documento si chiama MyFile, i file vengono salvati come MyFile-1.pdf, MyFile-2.pdf e così via.

MetaPost

Run pdfLaTeX, MakeIndex, MetaPost, Then pdfLaTeX apre strada facendo i file di log. Per MetaPost consulta ConTeXt e MetaPost.
