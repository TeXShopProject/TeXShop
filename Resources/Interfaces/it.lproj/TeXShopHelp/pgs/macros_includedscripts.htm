Macro AppleScript predefinite

TeXShop include una raccolta di macro AppleScript di Will Robertson, Claus Gerhardt e altri. Alcune eseguono in sequenza una serie di comandi di composizione. Copiandole e modificandole, puoi costruire script per il tuo lavoro. Questa pagina ne descrive alcune, con i nomi che hanno nel menu Macro.

Column macros, Insert reference, Open quickly…

Queste macro sono di Will Robertson. Nel sottomenu Column macros, New tabular e New array inseriscono un ambiente tabular o array con il numero di righe e di colonne che inserisci, e Add column e Delete column modificano le righe che selezioni. Insert reference cerca nel file corrente i comandi \label{…} e ti permette di scegliere un’etichetta da un elenco; inserisce l’etichetta racchiusa in \ref{…}, un comando che puoi cambiare nello script. Se è selezionato del testo, vengono elencate solo le etichette che lo contengono. Open quickly… elenca i file .tex, .sty e .pdf nella cartella del file sorgente corrente e apre quelli che scegli.

Paste Spreadsheet Cells

Questa macro, di Alan Munn, incolla nel sorgente LaTeX celle di un foglio di calcolo sotto forma di tabella. Seleziona un intervallo di celle in Excel o in un’altra applicazione per fogli di calcolo e copiale. Poi scegli Macro › Paste Spreadsheet Cells e scegli uno stile di tabella:

cells
converte il testo copiato soltanto in celle di tabella LaTeX.
booktabs
prende la prima riga come intestazione e colloca \toprule, \midrule e \bottomrule in un ambiente tabular.
simple
racchiude le celle in un semplice ambiente tabular.
longtable
prende la prima riga come intestazione, aggiunge le righe di intestazione di una longtable e mette le celle in un ambiente longtable.

La macro sostituisce il contenuto degli appunti con il testo LaTeX. Per incollare le stesse celle in un altro stile, copiale prima di nuovo nel foglio di calcolo.

Applescript › Convert to MAC, Convert to Unix, Convert to Windows

I file di testo terminano le righe in modi diversi: macOS e Unix con un avanzamento di riga (line feed), Windows con un ritorno a capo (carriage return) seguito da un avanzamento di riga, e i file Macintosh molto vecchi con un solo ritorno a capo. TeXShop li legge tutti e tre. Se l’editor di qualcun altro non ci riesce, usa queste macro. Per un file sorgente MyFile.tex, Convert to Unix scrive una copia del file salvato chiamata MyFile_Unix.tex con avanzamenti di riga; Convert to Windows scrive MyFile_Windows.tex e Convert to MAC scrive MyFile_Mac.tex. Le macro usano il programma flip di Craig Stuart Sapp in ~/Library/TeXShop/bin.

Applescript › Bibliography

Un documento con una bibliografia richiede diverse esecuzioni: LaTeX scrive il file .aux, BibTeX lo usa per scrivere i file .bbl e .blg, LaTeX viene eseguito di nuovo per aggiungere la bibliografia e un’altra volta ancora per aggiornarne i riferimenti. La macro Bibliography esegue LaTeX, BibTeX, LaTeX e LaTeX uno dopo l’altro. Scrivere script con i comandi di composizione di TeXShop spiega come funziona.

Claus Gerhardt Macros

La maggior parte delle macro di questo sottomenu richiama gli script della shell con lo stesso nome in ~/Library/TeXShop/bin; bibtexcpl, mpostcpl e latex-makeindex-mpost ne richiamano diversi in successione, e openpdf apre il PDF del documento. Funzionano su un file salvato. Scrivere script con comandi della shell prende come esempio pdflatexc.

htlatexc, htlatexr

TeX4ht converte un documento LaTeX in una pagina web: una pagina HTML e alcuni file di immagine. htlatexc esegue htlatex sul documento e apre in Safari il file HTML risultante. Non è necessario caricare il pacchetto tex4ht nel documento; lo carica htlatex. htlatexr esegue htlatex con l’opzione -r, che crea di nuovo le immagini anche quando esistono già.

pdfselectc

pdfselectc crea file PDF che contengono pagine scelte del PDF del documento. Prima chiede quanti file creare, poi le pagine di ciascun file, per esempio 5:8 per le pagine da 5 a 8 oppure 3:4,6,8:12. Se il documento si chiama MyFile, i file vengono salvati come MyFile-1.pdf, MyFile-2.pdf e così via.

mpostc, mpostcpl, latex-makeindex-mpost

mpostc esegue MetaPost e poi pdfLaTeX; mpostcpl esegue pdfLaTeX, MetaPost e di nuovo pdfLaTeX. latex-makeindex-mpost esegue pdfLaTeX, MakeIndex, MetaPost e di nuovo pdfLaTeX, aprendo strada facendo i file di log. Per MetaPost consulta ConTeXt e MetaPost.
