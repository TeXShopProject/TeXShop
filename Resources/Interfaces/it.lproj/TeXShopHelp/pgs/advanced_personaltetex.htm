Aggiungere file personali a TeX Live

I file di stile, le classi, i database bibliografici e gli altri file che non fanno parte di TeX Live vanno nel tuo albero TeX personale, la cartella texmf nella cartella Libreria della tua cartella Inizio: ~/Library/texmf. Tutti i programmi di TeX Live trovano i file che si trovano lì, e questi hanno la precedenza sui file con lo stesso nome presenti in TeX Live. Dopo aver aggiunto un file non occorre registrare nulla: la compilazione successiva lo trova.

Nel Finder la cartella Libreria è nascosta. Per aprirla, scegli Vai › Vai alla cartella… nel Finder e digita ~/Library. Crea lì la cartella texmf, se non esiste ancora.

Prima di aggiungere un pacchetto

La maggior parte dei pacchetti di CTAN fa già parte di TeX Live, e MacTeX li installa tutti. Per sapere se TeX dispone già di un file, scegli File › Apri file di stile... in TeXShop e digitane il nome, ad esempio hyperref.sty; TeXShop apre il file che TeX userebbe. Aggiungi un pacchetto al tuo albero personale solo se TeX Live non lo contiene o se ti serve una tua versione. Poiché la tua copia ha la precedenza, eliminala quando TeX Live si è aggiornato, altrimenti continuerai a usare la versione vecchia.

Dove vanno i file

Le cartelle all’interno di texmf seguono la stessa struttura di TeX Live. Crea le cartelle che ti servono:

CartellaContenuto
tex/latex/pacchetti e classi LaTeX (.sty, .cls), ogni pacchetto in una cartella propria
tex/plain/file per plain TeX
tex/generic/file che funzionano con qualsiasi formato
bibtex/bib/database bibliografici (.bib)
bibtex/bst/stili bibliografici (.bst)
doc/documentazione dei pacchetti che hai aggiunto; Aiuto › Mostra aiuto per il pacchetto... la trova lì

Ad esempio, un pacchetto con le tue macro e il tuo database bibliografico verrebbero memorizzati come

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

A quel punto \usepackage{mymacros} e \bibliography{mybibliography} funzionano in ogni documento, ovunque sia salvato.

Verificare la cartella

Per sapere quale cartella il tuo TeX usa come albero personale, digita nel Terminale

kpsewhich -var-value TEXMFHOME

Su un Mac è ~/Library/texmf, a meno che l’installazione non sia stata configurata diversamente. Per sapere quale copia di un file TeX leggerà, digita ad esempio kpsewhich mymacros.sty.

Non aggiungere file alle cartelle di TeX Live stesso; consulta Altre informazioni su TeX Live.
