Cerca nei sorgenti TeX

In un documento diviso in un file principale e in file dei capitoli si può cercare, e sostituire, in tutti i file contemporaneamente. Con uno dei suoi file in primo piano, scegli Modifica › Trova › Cerca nei sorgenti TeX con la stessa TEX root…; quando in primo piano c’è il file principale stesso, la voce è «Cerca nei sorgenti TeX con questo file come TEX root…». La stessa voce si trova nel menu di «Trova tutto» nel pannello di ricerca avanzata, e «Applica ai sorgenti TeX con la stessa TEX root…» nel menu di «Sostituisci tutto» della finestra Sostituzione multipla apre la finestra con l’insieme scelto lì; per il file principale stesso la voce è «Applica ai sorgenti TeX con questo file come TEX root…». Le voci sono disattivate per un documento senza nome e per un file il cui nome non termina con .tex (in minuscolo), e la voce «Applica» anche quando nella finestra Sostituzione multipla non è scelto alcun insieme.

In quali file si cerca

La finestra cerca nel file principale e nei file .tex della sua cartella e delle cartelle sottostanti che lo indicano in una riga % !TEX root tra le loro prime 20 righe; consulta Impostare il file principale di un progetto. Quando l’impostazione nascosta UseOldHeadingCommands è attiva, si cerca anche nei file che lo indicano in una vecchia riga %SourceDoc. La riga sotto le modalità indica in quale file principale si cerca, e il suo pulsante ? ripete questa regola. I file indicati in \input o \include non vengono seguiti, e un file principale indicato in un file .texshop non viene usato. I collegamenti simbolici a file, le cartelle raggiunte tramite collegamenti simbolici o alias, e la cartella TeXShop Backups vengono esclusi.

L’elenco a sinistra mostra i file; disattiva lì un file o una cartella per escluderlo. Se alcuni file o cartelle non si sono potuti leggere, il pulsante «File non letti» in basso li elenca con il motivo.

Cercare e sostituire

I campi di ricerca e di sostituzione e le opzioni sono quelli del pannello di ricerca avanzata. Scegli una modalità:

  • «Trova» elenca ogni corrispondenza con il suo numero di riga.
  • «Sostituisci» mostra ogni riga prima e dopo la sostituzione. Ogni corrispondenza ha una casella di controllo; una corrispondenza disattivata non viene sostituita.
  • «Sostituzione multipla» applica un insieme della finestra Sostituzione multipla ed elenca i gruppi di righe modificate, ciascuno con una casella di controllo. «Modifica…» apre l’insieme in quella finestra.

Fai clic su una riga per mostrare la corrispondenza nel suo documento; fai doppio clic per portare quella finestra in primo piano. L’elenco segue le tue modifiche, e il pulsante ↻ (⌘R) raccoglie di nuovo i file. Il pulsante di interruzione, il tasto Esc o ⌘. interrompe una ricerca lunga.

In un documento aperto si cerca nel testo così com’è sullo schermo, con le modifiche non salvate; un file non aperto viene letto nella codifica con cui TeXShop lo aprirebbe. In alcuni file si può solo cercare, non sostituire, per esempio in un file su cui non si può scrivere o che la sua codifica non è in grado di salvare senza modificarlo. Questi file sono contrassegnati con ⊘, e il contrassegno ne indica il motivo.

Sostituisci tutto

«Sostituisci tutto» chiede conferma prima di sostituire. Se nel frattempo un file è cambiato, non viene sostituito nulla e l’elenco viene rifatto. Con «Salva copie di sicurezza» attivo, ogni file da modificare viene prima copiato nella cartella TeXShop Backups, in una cartella che porta la data e l’ora, accanto al file principale.

I file non aperti vengono poi scritti direttamente, nella loro codifica e con i loro caratteri di fine riga e permessi; questa operazione non si può annullare. I documenti aperti vengono modificati sullo schermo e non vengono salvati, e un solo Annulla in un documento ripristina le sue sostituzioni. Interrompendo «Sostituisci tutto», i file già elaborati restano sostituiti e gli altri restano invariati. Al termine si cerca di nuovo nei file, e la riga in basso indica quante corrispondenze sono state sostituite. Se alcuni file non si sono potuti modificare, un foglio li elenca con il motivo, e «Mostra nel Finder» apre la cartella della copia di sicurezza.

Non eseguire «Sostituisci tutto» mentre un’altra applicazione continua a scrivere questi file.
