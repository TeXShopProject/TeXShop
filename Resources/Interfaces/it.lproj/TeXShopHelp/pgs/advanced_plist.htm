File in ~/Library/TeXShop

TeXShop conserva i file che puoi personalizzare nella cartella ~/Library/TeXShop, che crea la prima volta che viene eseguito. TeXShop › Apri ~/Library/TeXShop apre la cartella nel Finder. Per portare le tue personalizzazioni su un altro Mac, copia lì questa cartella.

Che cosa contiene la cartella

La maggior parte di questi file si modifica in TeXShop stesso, e non serve aprirli:

Le abbreviazioni dei menu in KeyEquivalents.plist diventano i valori predefiniti dell’elenco delle abbreviazioni in Impostazioni › Tastiera; le abbreviazioni modificate nelle impostazioni hanno la precedenza. Consulta Ridefinire le abbreviazioni da tastiera dei menu.

Modificare un file a mano

I file con l’estensione .plist sono testo XML. Si possono aprire e modificare in TeXShop, in un altro editor di testo o in Xcode. Diversi di essi iniziano con commenti che ne spiegano il formato. Conservali in UTF-8, la codifica in cui sono scritti. Modifica i colori dei temi in Impostazioni › Temi anziché nei loro file.

Se un file che hai modificato smette di funzionare, spostalo fuori dalla cartella, oppure sposta la sua cartella sulla scrivania, e riavvia TeXShop: il file viene creato di nuovo con il contenuto originale.

File mancanti o danneggiati

Quando uno dei file di cui TeXShop ha bisogno, come le macro, le associazioni dei tasti, i testi del Pannello LaTeX e del Pannello Matrici, le abbreviazioni dei menu, l’elenco per il completamento dei comandi, le esclusioni dell’ortografia o i temi standard, manca oppure risulta danneggiato all’avvio di TeXShop, TeXShop lo sostituisce con una propria copia senza messaggi di errore. Un file danneggiato viene spostato nella cartella ~/Library/TeXShop/Backups, in una cartella che porta la data e l’ora, così puoi recuperare da lì le tue modifiche.

I file che potresti eliminare di proposito, come modelli, documenti modello, motori e i tuoi temi, non vengono ripristinati.
