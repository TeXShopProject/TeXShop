BibTeX

BibTeX costruisce la bibliografia di un documento LaTeX a partire da un database di riferimenti, un file con estensione .bib. Il documento cita le voci tramite le loro chiavi, e BibTeX elenca solo le voci citate.

Un database mybibliography.bib contiene voci come

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

e il documento le cita e indica lo stile e il database:

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

Eseguire BibTeX

  1. Componi il documento. Le citazioni appaiono come [?] e la bibliografia manca.
  2. Scegli Compilatore › BibTeX (⇧⌘B), oppure scegli BibTeX nel menu a comparsa accanto al pulsante «Compila» e premi «Compila».
  3. Componi altre due volte: la prima esecuzione aggiunge la bibliografia, la seconda completa le citazioni.

La composizione con latexmk, ad esempio con il motore pdflatexmk o con un profilo «Con latexmk», esegue da sola BibTeX e i passaggi aggiuntivi.

Per creare un nuovo database in TeXShop, scegli il tipo bib nel menu «Tipo di file» della finestra di dialogo Salva, così che il file riceva l’estensione .bib. Un database può trovarsi anche nel tuo albero TeX personale, dove ogni documento lo trova; consulta Aggiungere file personali a TeX Live.

Scegliere il programma

Compilatore › BibTeX esegue il comando indicato in Impostazioni › Composizione › Strumenti correlati › Motore BibTeX, per impostazione predefinita bibtex. Inserisci lì un altro programma con le opzioni necessarie, ad esempio biber per i documenti che usano il pacchetto biblatex. I profili del motore impostano questo campo: pbibtex per pLaTeX + dvipdfmx, upbibtex per upLaTeX + dvipdfmx e LuaLaTeX (giapponese), e bibtex per gli altri profili.

Per scegliere il programma per un solo documento, inserisci una riga come questa in una delle sue prime venti righe:

% !BIB program = biber

La riga ha la precedenza sull’impostazione. La forma % !BIB TS-program = viene letta allo stesso modo.
