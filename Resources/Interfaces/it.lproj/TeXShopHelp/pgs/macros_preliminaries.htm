Preliminari

Le macro di TeXShop e l’Editor delle macro sono stati scritti originariamente da Mitsuhiro Shishikura; le macro LaTeX predefinite sono state create da Mitsuhiro Shishikura e Hirokazu Ogawa.

Le macro sono elencate nel menu Macro e nel menu a comparsa Macro della barra strumenti della finestra sorgente. Ne esistono due tipi. Le macro di testo inseriscono testo nel sorgente, come i pulsanti del Pannello LaTeX. Le macro AppleScript eseguono un AppleScript; consulta Macro AppleScript.

Dove sono conservate le macro

Le macro sono memorizzate in

~/Library/TeXShop/Macros/Macros_Latex.plist

e il menu Macro le mostra per ogni motore di compilazione. Per i motori integrati plain TeX, BibTeX, MakeIndex e MetaPost si può conservare una serie separata: quando per il documento è scelto uno di questi, l’Editor delle macro salva le sue macro in un file a parte, come Macros_Tex.plist, e lascia invariato Macros_Latex.plist.

I file delle macro sono normali file di testo, ma è meglio modificarli con l’Editor delle macro: scegli Macro › Apri Editor delle macro.... Definire nuove macro spiega come aggiungere, eliminare e dare un nome alle macro e come assegnare loro delle scorciatoie.

Se la cartella Macros manca

Se all’avvio di TeXShop la cartella Macros manca, TeXShop la crea di nuovo con le macro predefinite. Se Macros_Latex.plist è danneggiato, all’avvio TeXShop lo sostituisce con la propria copia, senza alcun messaggio, e conserva il file danneggiato in ~/Library/TeXShop/Backups. Per ricominciare con le macro predefinite, esci da TeXShop, sposta la cartella Macros sulla Scrivania e avvia di nuovo TeXShop; la cartella spostata conserva le tue vecchie macro.

Condividere le macro

Mentre l’Editor delle macro è aperto, il menu Macro contiene due comandi in più. «Salva la selezione in un file...» salva le macro selezionate in un file a parte, che puoi dare ad altri. «Aggiungi macro da un file...» aggiunge al tuo elenco le macro di un file di questo tipo; poi disponile come preferisci nell’Editor delle macro.
