Scripts schrijven met zetcommando’s van TeXShop

Een document met een literatuurlijst heeft een reeks zetrondes nodig: LaTeX schrijft het .aux-bestand, BibTeX gebruikt dat om de .bbl- en .blg-bestanden te schrijven, LaTeX wordt opnieuw uitgevoerd om de literatuurlijst aan het document toe te voegen, en nog een keer om de verwijzingen ernaar bij te werken. Uw projecten hebben misschien vergelijkbare reeksen nodig, en een AppleScript-macro kan ze voor u uitvoeren.

De macro Macro’s › Applescript › Bibliography, die bij TeXShop wordt geleverd, laat zien hoe dat gaat. Dit is de inhoud ervan:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

De eerste regel maakt hiervan een AppleScript-macro die door ScriptRunner wordt uitgevoerd, zodat hij TeXShop kan vragen te zetten (zie AppleScript-macro’s). De volgende regels controleren #FILEPATH#, het volledige pad van het bronbestand. Dat is een lege tekenreeks als het document nog niet is bewaard; in dat geval vraagt het script u het te bewaren en stopt het.

Daarna verwijst het script naar het document met #DOCUMENTNAME#. TeXShop bewaart het document zelf wanneer een zetcommando begint, zodat het script het niet hoeft te bewaren.

De overige commando’s voeren latexinteractive, bibtex, latex en latex uit. Een zetcommando keert meteen naar het script terug, voordat het zetten klaar is; daarom wacht na elk commando een repeat-lus totdat taskdone meldt dat de taak klaar is. De regel delay 2 laat het script tussen de controles even pauzeren, in plaats van voortdurend te vragen en de computer te vertragen. De commando’s staan in AppleScript-macro’s definiëren.
