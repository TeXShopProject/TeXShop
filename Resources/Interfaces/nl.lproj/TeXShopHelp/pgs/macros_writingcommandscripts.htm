Scripts schrijven met shell-commando’s

Deze pagina gebruikt de macro Run pdfLaTeX with Shell Escape van Claus Gerhardt, in Macro’s › Claus Gerhardt Macros, om te laten zien hoe een AppleScript een shellscript aanroept. Het shellscript zelf is eenvoudig: het voegt de mappen van de TeX-programma’s aan het zoekpad toe en voert pdflatex uit met --shell-escape. Uw eigen scripts doen waarschijnlijk meer, bijvoorbeeld meerdere programma’s na elkaar uitvoeren; juist dan komen deze technieken van pas.

Het shellscript

Het shellscript is ~/Library/TeXShop/bin/pdflatexc. Het is niet afhankelijk van TeXShop: als de map ervan in uw zoekpad staat, voert u het uit door in Terminal pdflatexc myfile.tex te typen. Dit is het script:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

Het AppleScript

De macro die dit shellscript aanroept, is interessanter:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Na het commentaar vormen de eerste zeven regels een recept van Claus Gerhardt om het bronbestand te bewaren en de naam van het document te vinden, die in frontName wordt gezet. Het werk wordt gedaan door het gecompileerde script setname.scpt in ~/Library/TeXShop/Scripts: deze regels bepalen het pad ~/Library/TeXShop/Scripts/setname.scpt, laden het script en roepen het aan met #NAMEPATH# en #TEXPATH#.

Vaak kan hetzelfde eenvoudiger met

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

Het recept heeft twee voordelen. Het werkt ook als het voorste document niet het document is dat de latere commando’s moet ontvangen, bijvoorbeeld een logbestand zoals /Users/name/Examples/myfile.log. En als het bestand nog nooit is bewaard, geeft het recept een fout terug, terwijl het commando save het script zou laten wachten achter een bewaarvenster.

De volgende zes regels stellen de variabelen dirName en baseName in. Als het bronbestand /Users/name/My Papers/Stuff/myfile.tex is, is dirName gelijk aan '/Users/name/My Papers/Stuff', tussen aanhalingstekens gezet voor de shell vanwege de spatie in een mapnaam, en is baseName gelijk aan myfile.tex. De bestandsnaam wordt op dezelfde manier tussen aanhalingstekens gezet wanneer hij aan het shellscript wordt doorgegeven, zodat beide spaties mogen bevatten.

De volgende drie regels roepen het shellscript aan. Het resultaat is hetzelfde als wanneer u in Terminal cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' typt. De laatste drie regels werken het voorvertoningsvenster bij.

Verscheidene van deze regels zijn ingewikkeld, maar ze kunnen ongewijzigd naar nieuwe scripts worden gekopieerd.

Shell-commando’s uitvoeren vanuit AppleScript

AppleScript voert een shell-commando uit in de vorm

do shell script "cmd input"

Om een commando uit delen op te bouwen, schrijft u het in de gelijkwaardige vorm

do shell script "cmd " & "input"

Let op de spatie na cmd. Het en-teken voegt twee tekenreeksen samen:

"cmd " & "input" = "cmd input"

Een shell die door AppleScript wordt gestart, begint in de rootmap. Het commando

do shell script "cd " & dirName

gaat naar de map in dirName, die al tussen aanhalingstekens staat, zodat er geen extra aanhalingstekens nodig zijn.

Elke do shell script start een nieuwe shell, zodat een later commando niet in die map zou staan. Om verdere commando’s in dezelfde map uit te voeren, voegt u ze met puntkomma’s samen tot één commando, zoals in Terminal:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

Het script hierboven doet dat met cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc en input2 = baseName. De regels

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

zijn gewoon een handige manier om deze reeks in één variabele te zetten.
