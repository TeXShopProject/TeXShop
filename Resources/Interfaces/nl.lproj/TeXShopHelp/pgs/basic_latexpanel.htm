LaTeX-venster

Venster › LaTeX-venster... opent een paneel met LaTeX-code: wiskundige symbolen, Griekse letters, functies, letters met accenten en internationale tekens, omgevingen en commando’s voor lettertypen. Klik in de bron op de plaats waar de code moet komen en klik dan op een knop in het paneel. De code ervan wordt bij het invoegpunt ingevoegd. Het paneel blijft vóór de bronvensters staan terwijl u werkt.

De knoppen zijn over pagina’s verdeeld. Kies een pagina met de knoppen bovenaan elk deel van het paneel: ‘Wiskunde’, ‘Grieks’, ‘Symbolen’, ‘Functies’ en ‘Internationaal’, en ‘Omgevingen’, ‘Lettertype’ en ‘Aangepast’.

Als er tekst is geselecteerd wanneer u op een knop voor een lettertype of omgeving klikt, komt de geselecteerde tekst in de ingevoegde code te staan, zoals in \textbf{geselecteerde tekst}.

Sommige symbolen hebben het pakket amssymb nodig. Voeg deze regel toe aan de preambule van een document dat ze gebruikt:

\usepackage{amssymb}

Het paneel aanpassen

De code die elke knop invoegt, staat in ~/Library/TeXShop/LatexPanel/completion.plist. Open dit bestand in TeXShop om het te wijzigen; het commentaar aan het begin legt uit hoe het is opgebouwd. De namen van de standaardknoppen kunnen niet worden gewijzigd, maar de code die ze invoegen wel. In deze code:

  • staat #SEL# voor de geselecteerde tekst;
  • geeft #INS# aan waar het invoegpunt komt nadat de code is ingevoegd;
  • staat #PASTE# voor de tekst op het klembord.

De pagina ‘Aangepast’ heeft ruimte voor maximaal zestien eigen knoppen. Elke knop wordt in de lijst Customized van het bestand gedefinieerd door twee strings, de naam van de knop en de code die hij invoegt:

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Bewaar het bestand in UTF-8, stop TeXShop en start het opnieuw om de wijzigingen in het paneel te zien. Als het bestand ontbreekt of beschadigd is, vervangt TeXShop het door zijn eigen exemplaar. Zie Het LaTeX-venster aanpassen en Bestanden in ~/Library/TeXShop.
