Alternatieve zetmethode

TeXShop zet normaal met de methode Direct PDF: pdfLaTeX of pdfTeX schrijft het PDF-bestand direct. De alternatieve methode, Via DVI, voert LaTeX of TeX uit om een DVI-bestand te maken, zet dat met dvips om in PostScript en zet de PostScript met Ghostscript om in PDF. Het script simpdftex van TeX Live voert deze stappen uit.

Via DVI is nodig voor documenten die PostScript-code in de uitvoer zetten, bijvoorbeeld met het pakket pstricks. EPS-afbeeldingen hebben het niet nodig: TeX Live zet ze tijdens het zetten met Direct PDF om in PDF.

De methode kiezen

Zet › Via DVI en Zet › Direct PDF wijzigen de methode van het actieve document; andere geopende documenten houden hun eigen methode. Instellingen › Zetten › ‘Zetmethode’ bepaalt de methode waarmee documenten beginnen. De derde keuze, ‘Eigen script’, voert in plaats daarvan de commando’s van de groep Eigen script uit. De commando’s van Via DVI, één voor plain TeX en één voor LaTeX, staan in de groep Via DVI van Instellingen › Zetten. Het engineprofiel LaTeX + dvips + Ghostscript, onder ‘Overige’ in het menu ‘Engineprofiel’, stelt zetten Via DVI in.

De methode in het document kiezen

Een regel in de eerste 20 regels van de bron bepaalt het programma en de methode voor dat document, wat de instellingen ook zijn:

RegelZet met
% !TEX program = pdflatexLaTeX, Direct PDF
% !TEX program = latexLaTeX, Via DVI
% !TEX program = pdftexplain TeX, Direct PDF
% !TEX program = texplain TeX, Via DVI
% !TEX program = personallatexLaTeX, Eigen script
% !TEX program = personaltexplain TeX, Eigen script

Opties voor Via DVI

Ghostscript negeert transparantie in PostScript standaard. Om die te behouden, voegt u --distilleropts "-dALLOWPSTRANSPARENCY" toe aan het eind van het commando in de groep Via DVI. Om het tussenliggende PostScript-bestand te bewaren, voegt u --keep-psfile toe. Ghostscript wordt uitgevoerd vanuit de map in Instellingen › Zetten › Paden › ‘Ghostscript’.
