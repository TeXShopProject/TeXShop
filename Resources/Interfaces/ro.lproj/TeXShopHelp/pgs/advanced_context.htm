ConTeXt și MetaPost

ConTeXt

ConTeXt este un pachet de macrocomenzi creat de Hans Hagen, o alternativă la LaTeX cu propriile comenzi și cu un accent puternic pe designul tipografic. TeX Live include ConTeXt, iar ConTeXt Garden distribuie o versiune actualizată des, care se instalează în dosarul de reședință.

Motoarele pentru ConTeXt se află în ~/Library/TeXShop/Engines/Inactive/ConTeXt, împreună cu ghidul Setting-Up-ConTeXt.pdf și cu documente exemplu:

MotorCompilează cu
ConTeXt.engineConTeXt-ul din TeX Live care rulează pe LuaTeX
ConTeXt-TL.engineConTeXt-ul din TeX Live care rulează pe luametatex
ConTeXt-CG.engineversiunea ConTeXt Garden din dosarul de reședință

Mutați motorul de care aveți nevoie în ~/Library/TeXShop/Engines și puneți linii speciale la începutul fișierului principal al documentului, de exemplu:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Pentru ConTeXt-CG, introduceți dosarul programelor instalării ConTeXt Garden în câmpul „Al doilea set de motoare TeX” din Configurări › Compilare › Căi și adăugați linia % !TEX useAlternatePath, care face ca TeXShop să transmită motorului acel dosar în locul celui din TeX Live.

Pentru sincronizarea dintre sursă și previzualizare, adăugați \setupsynctex[state=start,method=min] în configurarea documentului; linia % !TEX useConTeXtSyncParser face ca TeXShop să folosească propriul cod de sincronizare al ConTeXt. Capitolul despre ConTeXt din Ajutor › Manualul TeXShop (în engleză) descrie în detaliu instalarea versiunii ConTeXt Garden și fiecare motor.

Pentru a lista în meniul „Etichete” comenzile de secționare ConTeXt, precum \title și \subject, activați configurarea ascunsă ConTeXtTags; consultați Configurări ascunse.

MetaPost

MetaPost, creat de John Hobby, desenează ilustrații pornind de la o descriere într-un limbaj de programare derivat din METAFONT-ul lui Knuth. Manualul lui face parte din TeX Live: alegeți Ajutor › Afișați ajutorul pentru pachet... și tastați metapost.

Compilare › MetaPost (⇧⌘M) sau MetaPost din meniul pop-up de lângă butonul „Compilare” rulează MetaPost pe fișierul cu numele documentului activ și extensia .mp: pe documentul însuși dacă este un fișier .mp, altfel pe fișierul .mp de lângă el, de exemplu cel pe care pachetul mfpic îl scrie pentru un document .tex. Rulează comanda din Configurări › Compilare › „Instrumente asociate” › „MetaPost”, implicit mpost. Profilurile motorului setează acest câmp: pmpost pentru pLaTeX + dvipdfmx și upmpost pentru upLaTeX + dvipdfmx, care compilează text japonez în etichete, și mpost pentru celelalte profiluri. LuaLaTeX nu poate include figuri ale căror etichete au fost culese în japoneză de pmpost sau upmpost; cu LuaLaTeX, desenați astfel de figuri în document cu pachetul luamplib.

Pentru a salva un fișier nou ca fișier MetaPost, alegeți tipul mp în meniul de format al fișierului din dialogul de salvare.

Motorul nv-metapost, creat de Nicola Vitacolonna, ușurează lucrul cu MetaPost și afișează figurile unui fișier în fereastra de previzualizare. Se află în ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; fișierul README.rtf și dosarul examples, cu un nivel mai sus, în MetaPostEngines-1.4.7, explică instalarea și folosirea lui și oferă fișiere exemplu. De exemplu, un fișier care începe cu

% !TEX program = nv-metapost
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

este compilat cu nv-metapost după ce acel motor se află în dosarul Engines.

Desenele MetaPost pot fi scrise și într-un document LaTeX, cu pachetul luamplib pentru LuaLaTeX sau cu pachete precum mfpic, care scriu desenele într-un fișier .mp pe care MetaPost îl prelucrează între două compilări.
