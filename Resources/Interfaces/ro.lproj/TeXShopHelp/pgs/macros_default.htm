Înțelegerea macrocomenzilor implicite

Cel mai bun mod de a înțelege macrocomenzile implicite este să le priviți în Editorul de Macro (Macro › Deschide Editorul de Macro...): selectați o macrocomandă din listă, iar conținutul ei apare alături.

De exemplu, să presupunem că doriți un mediu theorem. Tastați cuvântul theorem, selectați-l și alegeți Macro › Insert Begin/End. Cuvântul este înlocuit cu

\begin{theorem}

\end{theorem}

iar punctul de inserare este plasat pe rândul dintre ele.

Insert Begin/End este o macrocomandă AppleScript (consultați Macrocomenzi AppleScript). O macrocomandă text care face același lucru când este selectat un cuvânt arată așa:

\begin{#SEL#}
#INS#
\end{#SEL#}

Substituenți în macrocomenzile text

Textul unei macrocomenzi text este inserat în sursă, cu aceste înlocuiri:

#SEL#
este înlocuit cu textul care era selectat când a fost aleasă macrocomanda sau cu nimic, dacă nu era selectat niciun text.
#INS#
marchează locul în care ajunge punctul de inserare. Fără el, punctul de inserare este plasat la sfârșitul textului inserat.
#PASTE#
este înlocuit cu textul din clipboard sau cu nimic, dacă în clipboard nu există text.
•
este un marcaj, la care se poate ajunge cu Editare › Marcaje.

În Editorul de Macro, acești substituenți sunt afișați ca jetoane rotunjite; Definirea macrocomenzilor noi explică cum le inserați. Cu aceste cunoștințe, macrocomenzile implicite sunt ușor de înțeles și de modificat.
