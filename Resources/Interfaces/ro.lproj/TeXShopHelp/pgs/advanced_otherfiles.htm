Deschiderea altor fișiere cu TeXShop

TeXShop deschide orice fișier text, așa că puteți citi fișierele jurnal, fișierele aux și alte fișiere TeX de lângă documentele dvs. Deschide și fișiere PDF și imagini.

Fișiere tratate ca surse TeX

Fișierele cu extensiile următoare, precum și fișierele fără extensie, sunt surse TeX pentru TeXShop: sunt afișate cu evidențierea sintaxei și pot fi compilate.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

Celelalte fișiere text, precum fișierele .log, .aux, .bst, .engine sau .txt, se deschid ca text simplu, fără evidențierea sintaxei.

Pentru ca TeXShop să trateze ca surse TeX fișierele cu altă extensie, adăugați extensia cu o configurare ascunsă în Terminal; de exemplu, pentru fișierele ConTeXt cu extensia mkiv:

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

Fișiere PDF și imagini

Fișierele PDF și imaginile cu extensiile .png, .jpg, .jpeg, .tif, .tiff și .eps se deschid într-o fereastră proprie. Fișierele DVI și PostScript (.dvi, .ps) sunt convertite în PDF și afișate.

Salvarea cu altă extensie

Un fișier își păstrează extensia când TeXShop îl salvează. Un document nou este salvat ca fișier .tex, cu excepția cazului în care alegeți alt tip în meniul de format al fișierului din dialogul de salvare, de exemplu sty, bib sau mp.

TeXShop salvează un fișier în codificarea cu care a fost deschis. Este gândit pentru TeX și fișierele înrudite; un fișier într-un format neobișnuit se poate modifica dacă este salvat după ce a fost editat în TeXShop. Consultați Codificări.
