Instalarea TeX Live

TeXShop are nevoie de o distribuție TeX. Cea standard este TeX Live, pe care grupurile de utilizatori TeX o realizează în fiecare an pentru macOS, Windows, Linux și alte sisteme. Pe Mac se instalează cu MacTeX, un pachet de instalare realizat de TeX Users Group (TUG):

https://tug.org/mactex/

Pagina oferă două pachete. Faceți dublu clic pe cel descărcat și urmați programul de instalare; când acesta se termină, TeX este gata de folosire.

MacTeX
TeX Live complet, de aproximativ 7 GB, cu Ghostscript, precum și TeXShop și alte aplicații în /Applications/TeX. Aproape orice exemplu dintr-o carte despre TeX sau LaTeX funcționează fără să adăugați nimic. Alegeți acest pachet pentru munca propriu-zisă.
BasicTeX
O mică parte din TeX Live, de aproximativ 140 MB, suficientă pentru a încerca TeX și pentru a compila multe documente LaTeX. Nu instalează TeXShop; consultați Instalarea TeXShop.

Unde se instalează TeX Live

MacTeX instalează TeX Live în /usr/local/texlive/2026, iar BasicTeX în /usr/local/texlive/2026basic. Cele două pot fi instalate una lângă alta. Un nou TeX Live apare în fiecare an, în jurul lunii aprilie, într-un dosar care poartă numele anului. Pentru a elimina o instalare, trageți dosarul ei în Coș.

Programul de instalare creează și /Library/TeX/texbin, care duce la programele instalării TeX Live în uz și urmează noul TeX Live atunci când acesta este instalat. TeXShop rulează TeX de acolo (Configurări › Compunere › Căi › Motoare TeX), așa că pentru un an nou nu trebuie schimbat nimic. Butonul „Detectați căile…” din același grup caută instalările TeX și Ghostscript de pe Mac și vă permite să alegeți una.

Între versiunile anuale, pachetele din TeX Live primesc actualizări. MacTeX instalează TeX Live Utility în /Applications/TeX pentru a le instala.

Alte distribuții TeX

TeXShop funcționează și cu TeX instalat prin MacPorts sau Homebrew, ori cu MiKTeX. Programele acestora se află în alte dosare: folosiți „Detectați căile…” sau introduceți dosarul în Configurări › Compunere › Căi › Motoare TeX. Consultați Coexistența cu alte distribuții TeX.
