Scrierea scripturilor cu comenzi shell

Această pagină folosește macrocomanda pdflatexc a lui Claus Gerhardt, din Macro › Claus Gerhardt Macros, pentru a arăta cum apelează un script AppleScript un script shell. Scriptul shell în sine este simplu: adaugă dosarele programelor TeX la calea de căutare și rulează pdflatex cu --shell-escape. Scripturile dvs. vor face probabil mai mult, de exemplu vor rula mai multe programe unul după altul; atunci devin utile aceste tehnici.

Scriptul shell

Scriptul shell este ~/Library/TeXShop/bin/pdflatexc. Nu depinde de TeXShop: dacă dosarul lui se află în calea dvs. de căutare, tastarea pdflatexc myfile.tex în Terminal îl rulează. Iată-l:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

Scriptul AppleScript

Macrocomanda care apelează acest script shell este mai interesantă:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

După comentarii, primele șapte linii sunt o rețetă a lui Claus Gerhardt pentru a salva fișierul sursă și a afla numele documentului lui, care este pus în frontName. Treaba o face scriptul compilat setname.scpt din ~/Library/TeXShop/Scripts: aceste linii găsesc calea ~/Library/TeXShop/Scripts/setname.scpt, încarcă scriptul și îl apelează cu #NAMEPATH# și #TEXPATH#.

Adesea, același lucru se poate face mai simplu cu

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

Rețeta are două avantaje. Funcționează și când documentul din față nu este cel care trebuie să primească comenzile următoare, de exemplu un fișier jurnal precum /Users/name/Examples/myfile.log. Iar dacă fișierul nu a fost salvat niciodată, rețeta returnează o eroare, în timp ce comanda save ar lăsa scriptul să aștepte în spatele unui dialog de salvare.

Următoarele șase linii setează variabilele dirName și baseName. Dacă fișierul sursă este /Users/name/My Papers/Stuff/myfile.tex, dirName este '/Users/name/My Papers/Stuff', pus între ghilimele pentru shell din cauza spațiului din numele unui dosar, iar baseName este myfile.tex. Numele fișierului este pus între ghilimele în același mod când este transmis scriptului shell, așa că ambele pot conține spații.

Următoarele trei linii apelează scriptul shell. Rezultatul este același ca atunci când tastați cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' în Terminal. Ultimele trei linii actualizează fereastra de previzualizare.

Câteva dintre aceste linii sunt complicate, dar pot fi copiate neschimbate în scripturi noi.

Rularea comenzilor shell din AppleScript

AppleScript rulează o comandă shell în forma

do shell script "cmd input"

Pentru a construi o comandă din bucăți, scrieți-o în forma echivalentă

do shell script "cmd " & "input"

Observați spațiul de după cmd. Ampersandul unește două șiruri:

"cmd " & "input" = "cmd input"

Un shell pornit de AppleScript începe în dosarul rădăcină. Comanda

do shell script "cd " & dirName

trece în dosarul din dirName, care este deja pus între ghilimele, așa că nu mai sunt necesare alte ghilimele.

Fiecare do shell script pornește un shell nou, așa că o comandă ulterioară nu s-ar afla în acel dosar. Pentru a rula alte comenzi în același dosar, uniți-le cu punct și virgulă într-o singură comandă, ca în Terminal:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

Scriptul de mai sus face acest lucru cu cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc și input2 = baseName. Liniile

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

sunt doar un mod comod de a pune această succesiune într-o singură variabilă.
