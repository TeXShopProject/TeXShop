Mai multe despre TeX Live

Unde este instalat TeX Live

MacTeX instalează TeX Live în /usr/local/texlive/2026, iar BasicTeX în /usr/local/texlive/2026basic. TeX Live apare o dată pe an, iar fiecare an se instalează în propriul dosar, de exemplu 2027, astfel încât mai mulți ani pot rămâne unul lângă altul pe Mac. Pentru a elimina unul, trageți dosarul lui în Coș.

Dosarul /usr/local este ascuns în Finder. Pentru a vedea ce conține, alegeți Accesare › Accesare dosar… în Finder și tastați calea.

Cum găsește TeXShop TeX-ul

TeXShop rulează TeX din dosarul indicat în câmpul „Motoare TeX” din Configurări › Compilare › Căi. Valoarea implicită este /Library/TeX/texbin, o legătură pe care programele de instalare MacTeX și BasicTeX o îndreaptă spre programele TeX Live tocmai instalate. Când se instalează un an nou de TeX Live, legătura îl urmează, iar TeXShop folosește noul TeX fără nicio modificare în Configurări.

Pentru a folosi altă instalare, introduceți în „Motoare TeX” dosarul programelor ei, de exemplu /usr/local/texlive/2026/bin/universal-darwin, sau apăsați „Detectați căile…” pentru a alege dintre instalările găsite de TeXShop; consultați Coexistența cu alte distribuții TeX.

Lăsați TeX Live așa cum este

Dosarele TeX Live aparțin sistemului, iar o actualizare sau un an nou de TeX Live le înlocuiește. Nu adăugați și nu modificați fișiere acolo. Puneți în schimb fișierele de stil, clasele și bibliografiile proprii în arborele personal, unde TeX le găsește primele și unde actualizările nu le ating; consultați Adăugarea fișierelor personale în TeX Live.

Documentație

TeX Live conține documentație pentru aproape fiecare pachet. Ajutor › Afișați ajutorul pentru pachet... deschide documentația unui pachet după numele lui, de exemplu hyperref sau tikz. Ajutor › Documentația TeX Live (în engleză) arată unde se găsesc online ghidul TeX Live și alte documentații.
