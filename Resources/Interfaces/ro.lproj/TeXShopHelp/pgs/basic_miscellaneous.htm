Ferestre și file

Ferestrele TeXShop pot fi grupate ca file ale unei singure ferestre, ca în alte aplicații macOS. În Configurări › General, „Deschideți ferestrele noi ca file” alege când se întâmplă acest lucru: „Niciodată”, „Automat”, care urmează configurarea filelor din macOS, sau „Întotdeauna”.

Cu „Întotdeauna” și cu ferestre separate pentru sursă și previzualizare, sursa fiecărui document pe care îl deschideți devine o filă a ferestrei sursă, iar previzualizarea ei o filă a ferestrei de previzualizare; consolele și jurnalele sunt grupate în același mod. Selectarea unei file dintr-o fereastră aduce în prim-plan fila corespunzătoare din cealaltă când compilați sau sincronizați. Dacă sursa și previzualizarea sunt afișate într-o singură fereastră („Sursă și previzualizare” din Configurări › General setat la „Folosiți o singură fereastră”), fiecare filă conține un document întreg. Fereastră › Folosiți o singură fereastră și Fereastră › Folosiți ferestre separate trec documentul activ de la un mod la celălalt.

O fereastră care afișează împreună sursa și previzualizarea, cu sau fără file, funcționează bine pe tot ecranul: consola plutește atunci deasupra ei în timp ce compilați.

Deschiderea unui proiect în file

Pentru o carte ale cărei capitole sunt fișiere separate, fișierul principal poate cere TeXShop să deschidă capitolele ca file ale ferestrei sale. Puneți această linie printre primele 20 de linii ale fișierului principal:

% !TEX useTabs

Când se deschide fișierul principal, fișierele indicate de comenzile sale \include se deschid ca file. Pe aceeași linie pot urma nume scurte pentru file, între paranteze și separate prin virgule; un spațiu gol între două virgule păstrează numele fișierului respectiv:

% !TEX useTabs (Intro, Groups, , Fields)

Pentru a da file și fișierelor din comenzile \input, folosiți această configurare ascunsă în Terminal:

defaults write TeXShop TabsAlsoForInputFiles YES

Pentru a alege singur fișierele, puneți o linie useTabsWithFiles printre primele 20 de linii ale fișierului principal și adăugați câte o linie tabbedFile pentru fiecare filă, toate printre primele lui 50 de linii. Între paranteze poate urma un nume pentru filă:

% !TEX useTabsWithFiles
% !TEX tabbedFile{chapter1/Introduction.tex} (Introduction)
% !TEX tabbedFile{Galois.log}
% !TEX tabbedFile{~/Graphics/diagram.pdf}

O cale este relativă la dosarul fișierului principal, începe din dosarul dumneavoastră de reședință cu ~ sau este o cale completă. Scrieți întotdeauna extensia, chiar și atunci când Finder o ascunde: aceste file pot afișa și jurnale, fișiere PDF și imagini. Fiecare fișier se deschide așa cum s-ar deschide dacă l-ați deschide singur, astfel încât un fișier sursă își poate aduce și previzualizarea.

Pentru celelalte linii de comentariu speciale, consultați Ajutor › Linii de comentarii și configurări ascunse.
