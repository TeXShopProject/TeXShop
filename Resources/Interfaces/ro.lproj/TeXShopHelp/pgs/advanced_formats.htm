Crearea și utilizarea formatelor TeX

Un fișier de format (extensia .fmt) este o imagine a stării lui TeX după ce a citit un set de macrocomenzi. LaTeX însuși este un format: TeX îl încarcă într-o clipă, în loc să citească de fiecare dată sursele LaTeX. Puteți crea un format propriu dintr-un preambul lung, astfel încât compilarea să pornească mai repede, sau puteți folosi un format oferit de un proiect ori de o organizație.

Un format funcționează numai cu motorul și cu versiunea TeX Live care l-au creat. Un format creat cu pdfLaTeX din TeX Live 2026 nu poate fi folosit de XeLaTeX sau de alt an al TeX Live; creați-l din nou după instalarea unui TeX Live nou.

Crearea unui format

Puneți într-un fișier liniile pe care trebuie să le conțină formatul, terminând cu \dump. De exemplu, uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

În Terminal, treceți în dosarul acestui fișier și tastați

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Comanda încarcă formatul LaTeX, citește uo.tex și scrie uo.fmt. Un document compilat cu acest format omite liniile care sunt în format și începe cu \begin{document}.

Folosirea unui format în TeXShop

  1. Mutați uo.fmt în dosarul ~/Library/texmf/web2c, creând dosarele dacă este nevoie, pentru ca TeX să îl găsească din orice dosar.
  2. În Finder, deschideți ~/Library/TeXShop/Engines (TeXShop › Deschideți ~/Library/TeXShop), duplicați un motor precum XeLaTeX.engine și redenumiți copia, de exemplu Oregon.engine. Numele apare în TeXShop și nu trebuie să corespundă formatului.
  3. Deschideți copia în TeXShop și modificați ultima linie, astfel încât motorul să arate așa: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Documentele deschise după aceea listează Oregon în meniul pop-up de lângă butonul „Compilare”. Pentru a folosi formatul într-un document indiferent de ce este ales acolo, adăugați această linie la începutul sursei:

% !TEX program = Oregon

Pentru a-l face implicit, alegeți „Fișier de motor” în Configurări › Compilare › Motor › „Compilați documentele noi cu”, iar în meniul „Fișier de motor” alegeți Oregon. Consultați Adăugarea motoarelor de compilare.

Pentru un format plain TeX, folosiți în motor pdftex în loc de pdflatex. Pentru un format folosit „Prin DVI”, motorul trebuie să convertească și fișierul DVI în PDF, de exemplu cu dvipdfmx "${1:r}.dvi" într-un script zsh, deoarece TeXShop afișează fișierul PDF cu numele sursei.
