Scrierea scripturilor cu comenzile de compilare ale TeXShop

Un document cu bibliografie are nevoie de o succesiune de compilări: LaTeX scrie fișierul .aux, BibTeX îl folosește pentru a scrie fișierele .bbl și .blg, LaTeX rulează din nou pentru a adăuga bibliografia în document și încă o dată pentru a actualiza trimiterile la ea. Proiectele dvs. pot avea nevoie de succesiuni asemănătoare, iar o macrocomandă AppleScript le poate rula în locul dvs.

Macrocomanda Macro › Applescript › Bibliography, livrată cu TeXShop, arată cum. Iată conținutul ei:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

Prima linie face din aceasta o macrocomandă AppleScript rulată de ScriptRunner, astfel încât îi poate cere lui TeXShop să compileze (consultați Macrocomenzi AppleScript). Liniile următoare verifică #FILEPATH#, calea completă a fișierului sursă. Acesta este un șir gol când documentul nu a fost încă salvat; în acest caz, scriptul vă cere să-l salvați și se oprește.

Scriptul se referă apoi la document prin #DOCUMENTNAME#. TeXShop salvează singur documentul când începe o comandă de compilare, așa că scriptul nu trebuie să-l salveze.

Comenzile rămase rulează latexinteractive, bibtex, latex și latex. O comandă de compilare revine imediat în script, înainte ca compilarea să se termine, așa că după fiecare comandă o buclă repeat așteaptă până când taskdone raportează că lucrarea s-a încheiat. Linia delay 2 face ca scriptul să facă o pauză între verificări, în loc să întrebe continuu și să încetinească computerul. Comenzile sunt listate în Definirea macrocomenzilor AppleScript.
