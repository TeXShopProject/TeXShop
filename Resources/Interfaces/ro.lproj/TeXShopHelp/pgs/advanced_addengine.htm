Adăugarea motoarelor de compilare

Pe lângă plain TeX și LaTeX, TeXShop compilează cu motoare: scripturi shell mici, cu extensia .engine, aflate în dosarul ~/Library/TeXShop/Engines. Un motor poate rula un singur program sau un șir de programe, de exemplu LuaLaTeX, apoi Biber, apoi încă de două ori LuaLaTeX. TeXShop vine cu motoare precum LuaLaTeX, XeLaTeX și pdflatexmk; subdosarul Inactive conține multe altele.

Alegerea unui motor

Meniul pop-up de lângă butonul „Compilare” din bara de instrumente a ferestrei sursă listează motoarele. Alegeți unul și apăsați „Compilare” sau ⌘T. Alegerea se aplică numai documentului respectiv.

Pentru a compila documentele noi cu un motor, alegeți „Fișier de motor” în Configurări › Compunere › Motor › „Culege documentele noi cu”, apoi alegeți motorul în meniul „Fișier de motor” de dedesubt. „Editează lista de motoare…” deschide dosarul Engines în Finder; meniul „Fișier de motor” urmează dosarul pe măsură ce adăugați, eliminați sau redenumiți fișiere. Dacă fișierul de motor ales nu mai este în dosar, meniul îl arată ca negăsit, iar documentele sunt compilate cu LaTeX.

Pentru a lega un document de un motor, puneți o linie ca aceasta într-una dintre primele douăzeci de linii ale lui:

% !TEX program = XeLaTeX

Numele este numele fișierului de motor fără .engine; tex și latex compilează plain TeX și LaTeX „Prin DVI”, iar pdftex și pdflatex le compilează „PDF direct”. Linia are prioritate față de bara de instrumente, de Configurări și de „Compilare cu motorul alternativ”. Forma % !TEX TS-program = este citită la fel. Scrieți linia exact ca mai sus, cu câte un spațiu de fiecare parte a semnului egal; macrocomanda Program din meniul „Macro” inserează linia în locul dvs., cu o listă de nume de motoare din care să alegeți. Într-un proiect cu fișier principal, doar fișierul principal are nevoie de această linie.

Compilare › Compilare cu motorul alternativ (⌃⌥⌘T) compilează o dată cu motorul din Configurări › Compunere › Motor › „Motor alternativ”, implicit pdflatexmk, fără să modifice bara de instrumente. În meniul „Compilare”, articolul apare în locul articolului „Compilare” cât timp țineți apăsate Control și Opțiune. Este potrivit pentru documentele compilate de obicei rapid, într-o singură trecere, și din când în când complet, cu latexmk.

Scrierea unui motor

Cel mai simplu mod de a face un motor este să duplicați unul din dosarul Engines în Finder, să redenumiți copia și să o deschideți în TeXShop pentru a o edita. Un fișier de motor trebuie să aibă extensia .engine și permisiunea de a fi executat, pe care un duplicat o păstrează. Documentele deschise după aceea listează noul motor în bara lor de instrumente. Iată XeLaTeX.engine:

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

Prima linie indică shellul sau limbajul scriptului; zsh, bash, tcsh, Perl și altele funcționează toate, cu condiția ca scriptul să fie scris în limbajul respectiv. TeXShop rulează motorul în dosarul fișierului sursă și îi transmite trei valori:

$1
Numele fișierului sursă cu extensia lui, fără dosar, de exemplu main.tex. Un script care trece în alt dosar trebuie să rețină mai întâi calea completă, de exemplu ca "$PWD/$1". Într-un proiect, acesta este fișierul principal.
$2
Restul unei linii % !TEX parameter = … de la începutul sursei (al fișierului principal), cu mai multe opțiuni separate prin spații, de exemplu % !TEX parameter = -shell-escape. Fără o astfel de linie, este un singur spațiu.
$3
Dosarul din câmpul „Motoare TeX” din Configurări › Compunere › Căi sau dosarul din „Al doilea set de motoare TeX” când documentul conține linia % !TEX useAlternatePath.

Când motorul se termină, TeXShop deschide în fereastra de previzualizare fișierul PDF cu numele sursei și extensia .pdf, dacă există, și derulează la locul afișat înainte de compilare. Un script care produce alt rezultat poate spune ce să se afișeze cu liniile următoare, scrise oriunde în motor, într-un comentariu al limbajului său:

LinieEfect
!TEX-noPreviewnicio fereastră de previzualizare, chiar dacă sunt prezente și alte linii de mai jos
!TEX-pdfPreviewafișează fișierul PDF
!TEX-htmlPreviewafișează în fereastra HTML fișierul HTML cu același nume
!TEX-bothPreviewafișează atât fișierul PDF, cât și fișierul HTML
!TEX-noConsolenu afișează consola

De exemplu, un motor care rulează LuaLaTeX, Biber și încă de două ori LuaLaTeX ar putea arăta astfel în zsh, unde ${1:r} este numele fără extensie:

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

Dosarul Inactive

Subdosarul Engines/Inactive conține motoare pentru fluxuri de lucru speciale, adesea cu documentație și exemple, de exemplu pentru latexmk, ConTeXt, Sage, PreTeXt, pythontex și Typst. Pentru a folosi unul, mutați-l din dosarul lui în dosarul Engines propriu-zis. Când TeXShop este actualizat, dosarul Inactive este înlocuit cu versiunea curentă, în timp ce fișierele aflate direct în dosarul Engines nu sunt atinse niciodată, astfel încât motoarele pe care le-ați editat se păstrează.

Pentru mai multe despre motoare, consultați capitolul „Engines and latexmk” din Ajutor › Manualul TeXShop (în engleză).
