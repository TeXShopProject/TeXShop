Definirea macrocomenzilor AppleScript

AppleScript este un limbaj de sine stătător. AppleScript Language Guide de la Apple, aflat pe site-ul web Apple pentru dezvoltatori, îl descrie complet.

Căile și numele documentului

Înainte de a rula o macrocomandă AppleScript, TeXShop înlocuiește șirurile următoare cu calea unui fișier al documentului activ, între ghilimele duble:

#FILEPATH#
fișierul sursă
#TEXPATH#
fișierul .tex
#NAMEPATH#
fișierul sursă fără extensie
#FOLDERPATH#
dosarul care conține sursa, terminat cu o bară oblică
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
fișierele .pdf, .dvi, .ps, .log și .aux
#INDPATH#, #BBLPATH#, #HTMLPATH#
fișierele .ind, .bbl și .html

De exemplu, dacă #FILEPATH# dă /Users/name/Projects/Fourier/Fourier.tex, #FOLDERPATH# dă /Users/name/Projects/Fourier/. Dacă documentul nu a fost salvat niciodată, #FILEPATH# este un șir gol.

#DOCUMENTNAME# este înlocuit cu numele documentului așa cum îl arată titlul ferestrei sursă: cu extensia lui sau fără ea, dacă extensia este ascunsă. Un script îl folosește pentru a se adresa documentului care l-a apelat:

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

Comenzile TeXShop

Un script AppleScript își poate face treaba în două moduri: poate rula comenzi shell, așa cum se descrie în Scrierea scripturilor cu comenzi shell, sau poate apela comenzile proprii ale TeXShop, așa cum se descrie în Scrierea scripturilor cu comenzile de compilare ale TeXShop. Printre altele, TeXShop înțelege aceste comenzi:

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

Primele șase comenzi compilează continuu, fără să se oprească la erori. Următoarele șase compilează și ele, dar se opresc la o eroare, pentru ca dvs. să puteți răspunde în consolă. O comandă de compilare revine imediat, înainte ca compilarea să se termine. taskdone returnează NO cât timp compilarea încă rulează și YES după ce s-a terminat. refreshpdf și refreshtext fac ferestrele PDF și text să arate cea mai recentă versiune a fișierelor lor. goto line selectează o linie din sursă:

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
