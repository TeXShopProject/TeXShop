Macrocomenzi

Meniul „Macro” și articolul „Macro” din bara de instrumente conțin comenzi care inserează cod LaTeX în sursă sau rulează scripturi AppleScript. Câteva dintre macrocomenzile incluse în TeXShop:

  • Set Typesetting Program…, Set Encoding… și Set Root File… scriu liniile % !TEX care aleg motorul de compilare, codificarea și fișierul principal al unui document. Alegeți motorul sau codificarea din lista pe care o afișează Set Typesetting Program… sau Set Encoding…, ori fișierul principal în dialogul pe care îl deschide Set Root File…; linia este scrisă corect la începutul sursei.
  • Insert Begin/End transformă cuvântul de la punctul de inserare sau cuvântul selectat, de exemplu theorem, într-o pereche \begin{theorem} … \end{theorem}, cu punctul de inserare între ele.
  • Submeniuri precum Headings, Mathematics, Lists, Tables și Figures inserează cod LaTeX uzual.

Editorul de Macro

Alegeți Macro › Deschideți Editorul de Macro... pentru a vedea cum este definită fiecare macrocomandă, pentru a o modifica sau pentru a adăuga macrocomenzi proprii. Lista din stânga este meniul „Macro”: trageți articolele pentru a le rearanja și folosiți bara de sub listă pentru a adăuga articole, submeniuri și separatoare. Textul unei macrocomenzi este inserat în sursă. În acest text, elementele cu colțuri rotunjite reprezintă textul selectat, textul din clipboard și locul punctului de inserare; alegeți-le din meniul „Inserați” de sub text.

Pentru a atribui unei macrocomenzi o scurtătură de tastatură, selectați-o în listă, faceți clic pe scurtătura ei (sau faceți dublu clic pe ea) și apăsați tastele. O scurtătură folosește tasta Comandă sau Control ori este o tastă funcțională. Dacă o comandă de meniu sau altă macrocomandă o folosește deja, Editorul de Macro vă spune acest lucru.

Macrocomenzile sunt păstrate în ~/Library/TeXShop/Macros/Macros_Latex.plist. Pentru a da macrocomenzi altor persoane, selectați-le în Editorul de Macro și alegeți Macro › Salvați selecția în fișier...; pentru a adăuga macrocomenzi dintr-un astfel de fișier, alegeți Macro › Adăugați macrocomenzi din fișier....

Capitolul Ajutor pentru macrocomenzi explică macrocomenzile în detaliu, inclusiv macrocomenzile AppleScript.
