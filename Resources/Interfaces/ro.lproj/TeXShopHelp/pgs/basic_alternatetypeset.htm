Modul de compilare alternativ

În mod normal, TeXShop compilează cu metoda „PDF direct”: pdfLaTeX sau pdfTeX scrie direct fișierul PDF. Metoda alternativă, „Prin DVI”, rulează LaTeX sau TeX pentru a crea un fișier DVI, îl convertește în PostScript cu dvips și convertește fișierul PostScript în PDF cu Ghostscript. Acești pași sunt executați de scriptul simpdftex din TeX Live.

Metoda „Prin DVI” este necesară pentru documentele care pun cod PostScript în rezultat, de exemplu cu pachetul pstricks. Imaginile EPS nu au nevoie de ea: TeX Live le convertește în PDF în timpul compilării cu „PDF direct”.

Alegerea metodei

Compilare › Prin DVI și Compilare › PDF direct schimbă metoda documentului activ; celelalte documente deschise o păstrează pe a lor. Configurări › Compilare › Metoda de compilare stabilește metoda cu care încep documentele. A treia ei opțiune, „Script personal”, rulează în schimb comenzile din grupul „Script personal”. Comenzile pentru „Prin DVI”, una pentru plain TeX și una pentru LaTeX, se află în grupul „Prin DVI” din Configurări › Compilare. Profilul motorului LaTeX + dvips + Ghostscript, aflat la „Altele” în meniul „Profilul motorului”, pregătește compilarea „Prin DVI”.

Alegerea metodei în document

O linie aflată printre primele 20 de linii ale sursei stabilește programul și metoda pentru acel document, oricare ar fi configurările:

LinieCompilează cu
% !TEX program = pdflatexLaTeX, PDF direct
% !TEX program = latexLaTeX, Prin DVI
% !TEX program = pdftexplain TeX, PDF direct
% !TEX program = texplain TeX, Prin DVI
% !TEX program = personallatexLaTeX, Script personal
% !TEX program = personaltexplain TeX, Script personal

Opțiuni pentru Prin DVI

În mod implicit, Ghostscript ignoră transparența PostScript. Pentru a o păstra, adăugați --distilleropts "-dALLOWPSTRANSPARENCY" la sfârșitul comenzii din grupul „Prin DVI”. Pentru a păstra fișierul PostScript intermediar, adăugați --keep-psfile. Ghostscript este rulat din dosarul indicat în Configurări › Compilare › Căi › Ghostscript.
