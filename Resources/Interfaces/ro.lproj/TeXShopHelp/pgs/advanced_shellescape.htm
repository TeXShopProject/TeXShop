Protecția față de shell escape

În timpul compilării, TeX poate rula alte programe. Implicit, TeX Live permite doar o listă scurtă de programe de încredere, de exemplu pentru a converti grafica EPS în PDF. Pachetele care trebuie să ruleze alte programe cer opțiunea -shell-escape (scrisă și --shell-escape).

Cu această opțiune, un document poate rula orice comandă, de exemplu una care șterge toate fișierele din dosarul de reședință. Folosiți-o numai pentru documente în care aveți încredere, nu și pentru fișiere primite de la alții.

Adăugarea opțiunii

  • În comanda LaTeX sau plain TeX din Configurări › Compunere › „PDF direct”, pentru toate documentele compilate „PDF direct”.
  • Într-un fișier de motor, pentru toate documentele compilate cu acel motor; consultați Adăugarea motoarelor de compilare.
  • Pentru un singur document compilat cu unul dintre motoarele latexmk, precum pdflatexmk, cu linia % !TEX parameter = -shell-escape la începutul sursei.

Un motor are deja opțiunea: sepdflatexmk, care vine cu TeXShop și se află de la început în dosarul Engines, compilează întotdeauna cu --shell-escape. Este suficient să-l alegeți în bara de instrumente a ferestrei sursă sau cu o linie % !TEX program = sepdflatexmk, așa că folosiți-l numai pentru documente în care aveți încredere.

Confirmare la shell-escape

Configurări › Compunere › „PDF direct” › „Confirmare la shell-escape”, dezactivată implicit, protejează comenzile din grupul „PDF direct”. Când este activată și comanda plain TeX sau LaTeX de acolo conține -shell-escape sau --shell-escape, TeXShop întreabă înainte de a compila un document pentru prima dată după deschiderea lui:

  • „OK” compilează cu opțiunea.
  • „Omiteți shell escape” compilează fără ea.
  • „Anulați” nu compilează.

După ce alegeți „OK” sau „Omiteți shell escape”, răspunsul rămâne valabil pentru acel document până când este închis, astfel încât puteți compila documentele proprii cu opțiunea, iar documentele altora fără ea. Fișierele de motor nu sunt verificate, chiar dacă conțin -shell-escape, așa că sepdflatexmk compilează cu opțiunea fără să întrebe.
