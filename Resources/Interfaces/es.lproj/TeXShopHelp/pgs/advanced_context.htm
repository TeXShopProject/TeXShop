ConTeXt y MetaPost

ConTeXt

ConTeXt es un paquete de macros de Hans Hagen, una alternativa a LaTeX con sus propios comandos y una fuerte orientación al diseño tipográfico. TeX Live incluye ConTeXt, y ConTeXt Garden distribuye una versión, actualizada a menudo, que se instala en su carpeta de inicio.

Los motores para ConTeXt están en ~/Library/TeXShop/Engines/Inactive/ConTeXt, junto con la guía Setting-Up-ConTeXt.pdf y documentos de ejemplo:

MotorCompone con
ConTeXt.engineel ConTeXt de TeX Live que funciona sobre LuaTeX
ConTeXt-TL.engineel ConTeXt de TeX Live que funciona sobre luametatex
ConTeXt-CG.enginela versión de ConTeXt Garden de su carpeta de inicio

Mueva el motor que necesite a ~/Library/TeXShop/Engines y escriba líneas mágicas al principio del archivo raíz del documento, por ejemplo:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Para ConTeXt-CG, escriba la carpeta de los programas de la instalación de ConTeXt Garden en el campo «Segundos motores TeX» de Ajustes › Composición › Rutas, y añada la línea % !TEX useAlternatePath, que hace que TeXShop pase esa carpeta al motor en lugar de la de TeX Live.

Para la sincronización entre código y vista previa, añada \setupsynctex[state=start,method=min] a la configuración del documento; la línea % !TEX useConTeXtSyncParser hace que TeXShop use el código de sincronización propio de ConTeXt. El capítulo sobre ConTeXt de Ayuda › Manual de TeXShop (en inglés) describe en detalle la instalación de la versión de ConTeXt Garden y cada motor.

Para que el menú Marcas muestre comandos de sección de ConTeXt como \title y \subject, active el ajuste oculto ConTeXtTags; consulte Ajustes ocultos.

MetaPost

MetaPost, de John Hobby, dibuja ilustraciones a partir de una descripción en un lenguaje de programación derivado de METAFONT de Knuth. Su manual forma parte de TeX Live: elija Ayuda › Mostrar ayuda del paquete... y escriba metapost.

Componer › MetaPost (⇧⌘M), o MetaPost en el menú desplegable junto al botón «Componer», ejecuta MetaPost sobre el archivo que tiene el nombre del documento activo y la extensión .mp: sobre el propio documento si es un archivo .mp y, si no, sobre el archivo .mp situado junto a él, como el que escribe el paquete mfpic para un documento .tex. Ejecuta el comando de Ajustes › Composición › Herramientas relacionadas › MetaPost, mpost por omisión. Los perfiles del motor establecen este campo: pmpost para pLaTeX + dvipdfmx y upmpost para upLaTeX + dvipdfmx, que componen texto japonés en las etiquetas, y mpost para los demás perfiles. LuaLaTeX no puede incluir figuras cuyas etiquetas en japonés hayan compuesto pmpost o upmpost; con LuaLaTeX, dibuje esas figuras dentro del documento con el paquete luamplib.

Para guardar un archivo nuevo como archivo de MetaPost, elija el tipo mp en el menú «Formato del archivo» del diálogo Guardar.

Los motores nv-metapost y nv-metafun, de Nicola Vitacolonna, facilitan el trabajo con MetaPost y MetaFun y muestran las figuras de un archivo en la ventana de vista previa. Están en ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; el archivo README.pdf y la carpeta examples, un nivel más arriba en MetaPostEngines-1.4.7, explican cómo instalarlos y usarlos y contienen archivos de ejemplo. Por ejemplo, un archivo que empiece con

% !TEX program = nv-metafun
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

se compone con nv-metafun una vez que ese motor está en la carpeta Engines.

Los dibujos de MetaPost también se pueden escribir dentro de un documento LaTeX, con el paquete luamplib para LuaLaTeX, o con paquetes como mfpic, que escriben los dibujos en un archivo .mp que MetaPost procesa entre dos composiciones.
