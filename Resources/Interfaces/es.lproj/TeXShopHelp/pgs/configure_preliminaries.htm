Preliminares

Por favor, lee sólo las primeras dos secciones (justo debajo) si eres un usuario nuevo que está instalando TeXShop por primera vez. Si estás actualizando desde versiones anteriores, lee esas dos secciones y las cuatro siguientes. Si estás familiarizado con TeXShop y quieres personalizarlo, lee las restantes secciones.

La primera vez que se ejecuta TeXShop, éste coloca sus ajustes, macros, plantillas y motores de composición predeterminados en la carpeta Library del usuario. Si, más tarde, actualizas TeXShop, estos ajustes, macros, etc. no se modifican automáticamente, puesto que el usuario puede haberlas editado. En algunos casos (pocos), se han hecho cambios importantes en las opciones predeterminadas; aquí detallamos estos cambios para que los usuarios de versiones previas puedan modificar los ajustes y las plantillas de manera adecuada.

TeXShop tiene algunos ajustes ocultos, que pueden resultar útiles a usuarios avanzados. Tales usuarios también pueden modificar el comportamiento del programa añadiendo varios archivos plist. Se dan detalles más adelante.

Las nuevas versiones de TeXShop a veces requieren ítem de menús adicionales y otros componentes en la interfaz. Estos nuevos ítem aparecen en inglés, aunque el resto del interfaz haya sido localizado a otra lengua. Las traducciones de estos ítems son bienvenidas como issues en GitHub.
