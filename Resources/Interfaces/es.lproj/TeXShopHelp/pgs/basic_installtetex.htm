Instalar TeX Live

TeXShop necesita una distribución de TeX. La distribución estándar es TeX Live, que los grupos de usuarios de TeX publican cada año para macOS, Windows, Linux y otros sistemas. En el Mac se instala con MacTeX, un paquete de instalación preparado por el TeX Users Group (TUG):

https://tug.org/mactex/

La página ofrece dos paquetes. Haga doble clic en el que haya descargado y siga el instalador; cuando termine, TeX está listo para usarse.

MacTeX
TeX Live completo, unos 7 GB, con Ghostscript, y TeXShop y otras aplicaciones en /Applications/TeX. Casi cualquier ejemplo de un libro sobre TeX o LaTeX funciona sin añadir nada. Elija este paquete para el trabajo real.
BasicTeX
Una pequeña parte de TeX Live, unos 140 MB, suficiente para probar TeX y para componer muchos documentos LaTeX. No instala TeXShop; consulte Instalar TeXShop.

Dónde se instala TeX Live

MacTeX instala TeX Live en /usr/local/texlive/2026, y BasicTeX en /usr/local/texlive/2026basic. Ambos pueden estar instalados a la vez. Cada año, hacia abril, aparece un nuevo TeX Live en una carpeta con el nombre de su año. Para eliminar una instalación, arrastre su carpeta a la Papelera.

El instalador crea además /Library/TeX/texbin, que lleva a los programas del TeX Live en uso y pasa al nuevo TeX Live cuando este se instala. TeXShop ejecuta TeX desde allí (Ajustes › Composición › Rutas › Motores TeX), de modo que no hay que cambiar nada con cada año nuevo. «Detectar rutas…», en el mismo grupo, busca las instalaciones de TeX y de Ghostscript del Mac y permite elegir una.

Entre una edición anual y la siguiente, los paquetes de TeX Live reciben actualizaciones. MacTeX instala TeX Live Utility en /Applications/TeX para instalarlas.

Otras distribuciones de TeX

TeXShop también funciona con TeX instalado mediante MacPorts o Homebrew, o con MiKTeX. Sus programas están en otras carpetas: use «Detectar rutas…» o escriba la carpeta en Ajustes › Composición › Rutas › Motores TeX. Consulte Coexistencia con otras distribuciones de TeX.
