Siempre ha sido posible colorear la salida que proporciona LaTeX. Para hacerlo, añade la línea

\usepackage{color}

en el preámbulo, e inserta una línea como

\color{blue}

antes de que LaTeX comience a componer páginas. Para colorear una sección limitada de texto, usa un comando como

{\color{red} !`Esto es muy importante!}

Para definir colores a medida, usa un comando como

\definecolor{mycolor}{rgb}{0.2, 0.7, 0.8}

Los usuarios pueden estar familiarizados con una lista de colores identificados por sus nombres en inglés, como «BrickRed»; estos nombres los define automáticamente el driver dvips. Para poder emplearlos con cualquier motor de composición, usa la sintaxis

\usepackage[dvipsnames,usenames]{color}

Cuando coloreamos la salida, puede ser difícil leerla en la ventana con el pdf previsto. El color de las páginas de la vista previa se puede cambiar en la categoría Temas de la ventana de Ajustes: el color bajo «Páginas claras» en la fila PDF rellena las páginas mientras se muestran claras. Cada tema tiene su propio color, de modo que el tema del modo claro y el del modo oscuro pueden usar colores distintos. Este color no se imprime ni aparece al copiar parte de una página. Las páginas que se muestran oscuras con el elemento Aspecto de la barra de herramientas de la ventana del PDF no se rellenan con este color.

Las versiones anteriores de TeXShop usaban los ajustes ocultos Pdfbackground_R, Pdfbackground_G y Pdfbackground_B para este color. Ahora solo los usa «Migrar ajustes anteriores», que crea un tema a partir de los ajustes de versiones anteriores.
