Texto en color

El paquete xcolor colorea el texto del documento compuesto. Cárguelo en el preámbulo:

\usepackage{xcolor}

Después, \color{blue} cambia a azul hasta el final del grupo o entorno actual, y \textcolor{red}{This is very important!} colorea solo su argumento. Para definir colores propios, use por ejemplo

\definecolor{mycolor}{rgb}{0.2, 0.7, 0.8}

La opción dvipsnames añade una lista de colores con nombre, como BrickRed y ForestGreen:

\usepackage[dvipsnames]{xcolor}

La documentación de xcolor, que se abre con Ayuda › Mostrar ayuda del paquete…, muestra todos los colores y opciones.

El color de las páginas en la ventana de vista previa

El texto en color puede ser difícil de leer sobre una página blanca. Las páginas de la ventana de vista previa pueden tener otro color en Ajustes › Temas: en el grupo «Ventanas», el color bajo «Páginas claras» en la fila «PDF» rellena las páginas mientras se muestran claras. Cada tema tiene su propio color, de modo que el tema de «Modo claro» y el de «Modo oscuro» pueden usar colores distintos.

El color solo sirve para ver las páginas: no se imprime y no aparece al copiar una parte de una página. Las páginas que se muestran oscuras con el elemento «Aspecto» de la barra de herramientas de la ventana de vista previa no se rellenan con este color. El color del propio texto lo establece el documento, con xcolor como se ha indicado.
