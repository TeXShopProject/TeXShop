Macros AppleScript predefinidas

TeXShop incluye una colección de macros AppleScript de Will Robertson, Claus Gerhardt y otros autores. Algunas ejecutan una serie de órdenes de composición una tras otra. Copiándolas y modificándolas, puede crear scripts para su propio trabajo. Esta página describe algunas de ellas, con los nombres que tienen en el menú Macros.

Column macros, Insert reference, Open quickly…

Estas macros son de Will Robertson. En el submenú Column macros, New tabular y New array insertan un entorno tabular o array con el número de filas y columnas que indique, y Add column y Delete column modifican las filas que seleccione. Insert reference busca órdenes \label{…} en el archivo actual y le permite elegir una etiqueta de una lista; inserta la etiqueta dentro de \ref{…}, una orden que puede cambiar en el script. Si hay texto seleccionado, solo se muestran las etiquetas que lo contienen. Open quickly… muestra los archivos .tex, .sty y .pdf de la carpeta del archivo fuente actual y abre los que elija.

Paste Spreadsheet Cells

Esta macro, de Alan Munn, pega celdas de una hoja de cálculo en su archivo fuente LaTeX como una tabla. Seleccione un rango de celdas en Excel o en otra aplicación de hojas de cálculo y cópielas. Después elija Macros › Paste Spreadsheet Cells y elija un estilo de tabla:

cells
convierte el texto copiado solo en celdas de tabla de LaTeX.
booktabs
toma la primera línea como cabecera y coloca \toprule, \midrule y \bottomrule en un entorno tabular.
simple
rodea las celdas con un entorno tabular sencillo.
longtable
toma la primera línea como cabecera, añade las líneas de cabecera de un longtable y coloca las celdas en un entorno longtable.

La macro sustituye el contenido del portapapeles por el texto LaTeX. Para pegar las mismas celdas con otro estilo, cópielas antes de nuevo en la hoja de cálculo.

Applescript › Convert to MAC, Convert to Unix, Convert to Windows

Los archivos de texto terminan sus líneas de maneras distintas: macOS y Unix con un salto de línea, Windows con un retorno de carro seguido de un salto de línea, y los archivos de Macintosh muy antiguos solo con un retorno de carro. TeXShop lee los tres. Si el editor de otra persona no puede hacerlo, use estas macros. Para un archivo fuente MyFile.tex, Convert to Unix escribe una copia del archivo guardado llamada MyFile_Unix.tex con saltos de línea; Convert to Windows escribe MyFile_Windows.tex y Convert to MAC escribe MyFile_Mac.tex. Las macros usan el programa flip de Craig Stuart Sapp, situado en ~/Library/TeXShop/bin.

Applescript › Bibliography

Un documento con bibliografía necesita varias composiciones: LaTeX escribe el archivo .aux, BibTeX lo usa para escribir los archivos .bbl y .blg, LaTeX vuelve a ejecutarse para añadir la bibliografía, y una vez más para actualizar las referencias a ella. La macro Bibliography ejecuta LaTeX, BibTeX, LaTeX y LaTeX una tras otra. Scripts con los comandos de composición de TeXShop explica cómo funciona.

Claus Gerhardt Macros

Las macros de este submenú llaman a scripts de shell del mismo nombre situados en ~/Library/TeXShop/bin. Funcionan con un archivo guardado. Scripts con comandos de shell explica pdflatexc como ejemplo.

htlatexc, htlatexr

TeX4ht convierte un documento LaTeX en una página web: una página HTML y archivos de imagen. htlatexc ejecuta htlatex sobre el documento y abre en Safari el archivo HTML resultante. No hace falta cargar el paquete tex4ht en el documento; htlatex lo carga. htlatexr ejecuta htlatex con la opción -r, que vuelve a crear las imágenes aunque ya existan.

pdfselectc

pdfselectc crea archivos PDF que contienen páginas seleccionadas del PDF del documento. Primero pregunta cuántos archivos debe crear y luego las páginas de cada archivo, como 5:8 para las páginas 5 a 8 o 3:4,6,8:12. Si el documento se llama MyFile, los archivos se guardan como MyFile-1.pdf, MyFile-2.pdf, etc.

mpostc, mpostcpl, latex-makeindex-mpost

mpostc ejecuta MetaPost y después pdfLaTeX; mpostcpl ejecuta pdfLaTeX, MetaPost y otra vez pdfLaTeX. latex-makeindex-mpost ejecuta pdfLaTeX, MakeIndex, MetaPost y otra vez pdfLaTeX, abriendo por el camino los archivos log. Para MetaPost, consulte ConTeXt y MetaPost.
