Macros AppleScript predefinidas

TeXShop incluye una colección de macros AppleScript de Will Robertson, Claus Gerhardt y otros autores. Algunas ejecutan una serie de comandos de composición una tras otra. Copiándolas y modificándolas, puede crear scripts para su propio trabajo. Esta página describe algunas de ellas, con los nombres que tienen en el menú Macros.

Column macros, Insert reference, Open quickly…

Estas macros son de Will Robertson. En el submenú Column macros, New tabular y New array insertan un entorno tabular o array con el número de filas y columnas que indique, y Add column y Delete column modifican las filas que seleccione. Insert reference busca comandos \label{…} en el archivo actual y le permite elegir una etiqueta de una lista; inserta la etiqueta dentro de \ref{…}, un comando que puede cambiar en el script. Si hay texto seleccionado, solo se muestran las etiquetas que lo contienen. Open quickly… muestra los archivos .tex, .sty y .pdf de la carpeta del archivo fuente actual y abre los que elija.

Paste Spreadsheet Cells

Esta macro, de Alan Munn, pega celdas de una hoja de cálculo en su archivo fuente LaTeX como una tabla. Seleccione un rango de celdas en Excel o en otra aplicación de hojas de cálculo y cópielas. Después elija Macros › Paste Spreadsheet Cells y elija un estilo de tabla:

cells
convierte el texto copiado solo en celdas de tabla de LaTeX.
booktabs
toma la primera línea como cabecera y coloca \toprule, \midrule y \bottomrule en un entorno tabular.
simple
rodea las celdas con un entorno tabular sencillo.
longtable
toma la primera línea como cabecera, añade las líneas de cabecera de un longtable y coloca las celdas en un entorno longtable.

La macro sustituye el contenido del portapapeles por el texto LaTeX. Para pegar las mismas celdas con otro estilo, cópielas antes de nuevo en la hoja de cálculo.

Applescript › Save Copy with Unix Line Endings, Save Copy with Windows Line Endings, Save Copy with Classic Mac Line Endings

Los archivos de texto terminan sus líneas de maneras distintas: macOS y Unix con un salto de línea, Windows con un retorno de carro seguido de un salto de línea, y los archivos de Macintosh muy antiguos solo con un retorno de carro. TeXShop lee los tres. Si el editor de otra persona no puede hacerlo, use estas macros. Para un archivo fuente MyFile.tex, Save Copy with Unix Line Endings escribe una copia del archivo guardado llamada MyFile_Unix.tex con saltos de línea; Save Copy with Windows Line Endings escribe MyFile_Windows.tex y Save Copy with Classic Mac Line Endings escribe MyFile_Mac.tex. Las macros usan el programa flip de Craig Stuart Sapp, situado en ~/Library/TeXShop/bin.

Applescript › Run LaTeX, BibTeX, Then LaTeX Twice

Un documento con bibliografía necesita varias composiciones: LaTeX escribe el archivo .aux, BibTeX lo usa para escribir los archivos .bbl y .blg, LaTeX vuelve a ejecutarse para añadir la bibliografía, y una vez más para actualizar las referencias a ella. Esta macro las ejecuta una tras otra. Scripts con los comandos de composición de TeXShop explica cómo funciona.

Claus Gerhardt Macros

La mayoría de las macros de este submenú llaman a scripts de shell situados en ~/Library/TeXShop/bin, como pdflatexc, que ejecuta pdfLaTeX, y bibtexc, que ejecuta BibTeX. Cada macro cuyo nombre empieza por Run ejecuta los programas que nombra, en ese orden, y Open PDF abre el PDF del documento. Run LaTeX, dvips and ps2pdf necesita además Ghostscript. Funcionan con un archivo guardado. Scripts con comandos de shell explica Run pdfLaTeX with Shell Escape como ejemplo.

Make HTML with TeX4ht

TeX4ht convierte un documento LaTeX en una página web: una página HTML y archivos de imagen. Make HTML with TeX4ht ejecuta htlatex sobre el documento y abre en Safari el archivo HTML resultante. No hace falta cargar el paquete tex4ht en el documento; htlatex lo carga. Make HTML with TeX4ht, Remaking Images ejecuta htlatex con la opción -r, que vuelve a crear las imágenes aunque ya existan.

Extract Pages from PDF…

Extract Pages from PDF… crea archivos PDF que contienen páginas seleccionadas del PDF del documento. Primero pregunta cuántos archivos debe crear y luego las páginas de cada archivo, como 5:8 para las páginas 5 a 8 o 3:4,6,8:12. Si el documento se llama MyFile, los archivos se guardan como MyFile-1.pdf, MyFile-2.pdf, etc.

MetaPost

Run pdfLaTeX, MakeIndex, MetaPost, Then pdfLaTeX abre por el camino los archivos log. Para MetaPost, consulte ConTeXt y MetaPost.
