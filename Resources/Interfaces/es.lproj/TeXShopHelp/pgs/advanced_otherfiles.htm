Abrir otros archivos con TeXShop

TeXShop abre cualquier archivo de texto, así que puede leer los archivos log, los archivos aux y otros archivos de TeX que haya junto a sus documentos. También abre archivos PDF e imágenes.

Archivos que se tratan como fuentes TeX

Los archivos con las extensiones siguientes, y los archivos sin extensión, son fuentes TeX para TeXShop: se muestran con resaltado de sintaxis y se pueden componer.

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

Los demás archivos de texto, como los archivos .log, .aux, .bst, .engine o .txt, se abren como texto simple, sin resaltado de sintaxis.

Para que TeXShop trate como fuentes TeX los archivos con otra extensión, añada la extensión con un ajuste oculto en Terminal; por ejemplo, para archivos de ConTeXt con la extensión mkiv:

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

Archivos PDF e imágenes

Los archivos PDF y las imágenes con las extensiones .png, .jpg, .jpeg, .tif, .tiff y .eps se abren en una ventana propia. Los archivos DVI y PostScript (.dvi, .ps) se convierten a PDF y se muestran.

Guardar con otra extensión

Un archivo conserva su extensión cuando TeXShop lo guarda. Un documento nuevo se guarda como archivo .tex, salvo que elija otro tipo en el menú «Formato del archivo» del diálogo Guardar, como sty, bib o mp.

TeXShop guarda un archivo en la codificación con la que se abrió. Está pensado para archivos de TeX y relacionados; un archivo en un formato poco habitual puede cambiar si se guarda después de editarlo en TeXShop. Consulte Codificaciones.
