Informar de errores

Para informar de un problema o sugerir una mejora, abra una incidencia (issue) en GitHub:

https://github.com/TeXShopProject/TeXShop/issues

Busque primero entre las incidencias abiertas y cerradas: puede que el problema ya se conozca o esté resuelto en una versión más reciente. Para abrir una incidencia hace falta una cuenta de GitHub.

Un informe con el que se puede actuar rápidamente indica:

  • la versión de TeXShop (TeXShop › Acerca de TeXShop) y la de macOS;
  • qué hizo, qué esperaba y qué ocurrió en cambio;
  • en los problemas de composición, un archivo fuente breve que muestre el problema, y la salida de la consola o el archivo log;
  • en los problemas con ventanas o menús, una captura de pantalla o una grabación de pantalla breve.

Las preguntas sobre TeX, los paquetes de LaTeX o el propio TeX Live es mejor hacerlas en los lugares que se enumeran en Sitios web útiles, como TeX Stack Exchange.
