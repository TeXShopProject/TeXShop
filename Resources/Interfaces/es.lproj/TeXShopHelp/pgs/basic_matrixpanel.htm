Panel de matrices

Ventana › Panel de matrices... abre un panel que escribe matrices y tablas por usted. Rellene las entradas en su tabla, elija qué aspecto debe tener el resultado e insértelo en el código fuente en el punto de inserción.

Crear una matriz o una tabla

  1. Indique el tamaño en Filas y Columnas, hasta 999 de cada.
  2. En Entorno, elija matrix para una matriz dentro de una fórmula (un entorno array) o tabular para una tabla de texto. Con tabular, «Embeber en entorno table» pone la tabla dentro de un flotante table con un pie y una etiqueta.
  3. Para una matriz, elija los delimitadores izquierdo y derecho. El punto deja ese lado sin delimitador, y el último botón usa el delimitador escrito en el campo que tiene al lado.
  4. Los dos botones con dibujos de una matriz añaden un borde alrededor de las entradas y líneas entre ellas.
  5. Rellene las entradas. Borrar las vacía todas; Matriz identidad y Matriz cero las rellenan con una matriz identidad o con ceros.
  6. Haga clic en Insertar o pulse ⌘Retorno.

Trabajar en la tabla

La tabla funciona como una hoja de cálculo. Haga clic en una celda para elegirla, arrastre o haga clic con Mayúsculas para elegir varias, y escriba para sustituir el valor; haga doble clic, pulse F2 o pulse Control-U para editarlo. Retorno baja, Tabulador va a la derecha y las teclas de flecha mueven en cualquier dirección; la tecla de borrar vacía las celdas elegidas. Copiar y Pegar intercambian celdas con aplicaciones de hoja de cálculo. Arrastre el número de una fila para mover la fila. Deshacer y Rehacer funcionan en la tabla mientras el panel está activo.

Cuando se reduce la matriz, las celdas que quedan fuera conservan sus valores, que se muestran en gris, y vuelven cuando se amplía de nuevo. Agrande el panel para ver más parte de la tabla.

Personalizar el código insertado

El código que el panel escribe alrededor de las entradas se guarda en ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist: el principio y el final de los entornos, los delimitadores, los separadores entre entradas y entre filas, las líneas de un borde o una cuadrícula, y la letra c que establece la alineación de cada columna. Por ejemplo, cambie c por r para alinear las columnas a la derecha. Mantenga el número y el orden de las cadenas del archivo, y reinicie TeXShop después de modificarlo. Consulte Archivos de ~/Library/TeXShop.
