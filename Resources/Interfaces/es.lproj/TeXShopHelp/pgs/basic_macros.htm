Macros

El menú Macros, y el elemento Macros de la barra de herramientas, contienen comandos que insertan código LaTeX en el código fuente o ejecutan scripts de AppleScript. Algunas de las macros que incluye TeXShop:

  • Set Typesetting Program…, Set Encoding… y Set Root File… escriben las líneas % !TEX que eligen el motor de composición, la codificación y el archivo raíz de un documento. Elija el motor o la codificación de la lista que muestra Set Typesetting Program… o Set Encoding…, o el archivo raíz en el diálogo que abre Set Root File…; la línea se escribe correctamente al principio del código fuente.
  • Insert Begin/End convierte la palabra situada en el punto de inserción o la palabra seleccionada, como theorem, en un par \begin{theorem} … \end{theorem}, con el punto de inserción entre ambos.
  • Submenús como Headings, Mathematics, Lists, Tables y Figures insertan código LaTeX habitual.

El editor de macros

Elija Macros › Abrir editor de macros... para ver cómo está definida cada macro, modificarla o añadir macros propias. La lista de la izquierda es el menú Macros: arrastre los elementos para reorganizarlos y use la barra que hay bajo la lista para añadir elementos, submenús y separadores. El texto de una macro se inserta en el código fuente. En este texto, unas fichas redondeadas representan el texto seleccionado, el texto del portapapeles y el lugar del punto de inserción; elíjalas en el menú Insertar, bajo el texto.

Para asignar un atajo de teclado a una macro, selecciónela en la lista, haga clic en su atajo (o haga doble clic en él) y pulse las teclas. Un atajo usa la tecla Comando o Control, o es una tecla de función. Si un comando de menú u otra macro ya lo usa, el editor de macros lo indica.

Las macros se guardan en ~/Library/TeXShop/Macros/Macros_Latex.plist. Para dar macros a otras personas, selecciónelas en el editor de macros y elija Macros › Guardar selección en archivo...; para añadir macros desde un archivo así, elija Macros › Añadir macros desde archivo...

El capítulo Ayuda para macros explica las macros en detalle, incluidas las macros AppleScript.
