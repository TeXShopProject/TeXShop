Incluir gráficos

Al componer directamente a PDF, LaTeX incluye gráficos en formato PDF, PNG y JPEG. PDF mantiene nítidos los dibujos de líneas y el texto a cualquier tamaño, así que úselo para diagramas y gráficas; PNG y JPEG son adecuados para capturas de pantalla y fotografías.

Cargue el paquete graphicx en el preámbulo:

\usepackage{graphicx}

e incluya un gráfico donde deba aparecer:

\includegraphics[width=0.8\textwidth]{diagram}

La extensión se puede omitir; LaTeX busca entonces diagram.pdf, diagram.png, diagram.jpg y los demás formatos que conoce. Cambie el ancho para cambiar el tamaño del gráfico. Ponga los archivos de los gráficos en la carpeta del documento, o indique una ruta relativa a ella, como figures/diagram.

Archivos EPS

TeX Live convierte automáticamente los gráficos EPS a PDF mientras compone, con epstopdf, siempre que el documento cargue graphicx. El archivo convertido, diagram-eps-converted-to.pdf, se escribe junto al archivo EPS y se usa a partir de entonces.

Un archivo EPS abierto en TeXShop también se convierte: TeXShop escribe un archivo PDF con el mismo nombre junto a él y lo muestra.

Archivos TIFF

LaTeX no puede incluir archivos TIFF. Elija Archivo › Convertir TIFF mientras una ventana de código está activa: un cuadro de diálogo muestra la carpeta del documento, donde solo se pueden elegir archivos TIFF. Seleccione uno o varios y haga clic en Convertir. Cada uno se convierte en un archivo PNG con el mismo nombre en la misma carpeta; los archivos TIFF se conservan.

Componer vía DVI

Los documentos que usan código PostScript, por ejemplo con el paquete pstricks, se componen con el método Vía DVI, que por omisión ejecuta dvips. Los gráficos se incluyen entonces en formato EPS; no se pueden usar archivos PDF, PNG ni JPEG. Consulte Modo alternativo de composición.
