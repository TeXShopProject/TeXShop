BibTeX

BibTeX construye la bibliografía de un documento LaTeX a partir de una base de datos de referencias, un archivo con la extensión .bib. El documento cita las entradas por sus claves, y BibTeX incluye solo las entradas citadas.

Una base de datos mybibliography.bib contiene entradas como

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

y el documento las cita e indica el estilo y la base de datos:

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

Ejecutar BibTeX

  1. Componga el documento. Las citas aparecen como [?] y falta la bibliografía.
  2. Elija Componer › BibTeX (⇧⌘B), o elija BibTeX en el menú desplegable junto al botón «Componer» y pulse «Componer».
  3. Componga dos veces más: la primera composición añade la bibliografía y la segunda completa las citas.

Componer con latexmk, por ejemplo con el motor pdflatexmk o con un perfil configurado «Con latexmk», ejecuta BibTeX y las pasadas adicionales por sí solo.

Para crear una base de datos nueva en TeXShop, elija el tipo bib en el menú «Formato» del diálogo Guardar, para que el archivo reciba la extensión .bib. Una base de datos también puede estar en su árbol TeX personal, donde la encuentran todos los documentos; consulte Añadir archivos personales a TeX Live.

Elegir el programa

Componer › BibTeX ejecuta la orden de Ajustes › Composición › Herramientas relacionadas › Motor BibTeX, bibtex por omisión. Escriba ahí otro programa con las opciones que necesite, por ejemplo biber para documentos que usan el paquete biblatex. Los perfiles del motor establecen este campo: pbibtex para pLaTeX + dvipdfmx, upbibtex para upLaTeX + dvipdfmx y LuaLaTeX (japonés), y bibtex para los demás perfiles.

Para elegir el programa de un documento, escriba una línea como esta en una de sus veinte primeras líneas:

% !BIB program = biber

La línea tiene prioridad sobre el ajuste. La forma % !BIB TS-program = se lee igual.
