Barra de herramientas y AppleScript

Cambiar la barra de herramientas

La ventana de código, la ventana de vista previa y la ventana que muestra ambas tienen cada una su propia barra de herramientas. Para cambiar una, active la ventana y elija Ventana › Personalizar barra de herramientas..., o haga clic con la tecla Control en la barra de herramientas y elija allí Personalizar barra de herramientas…. Arrastre elementos a la barra de herramientas o fuera de ella, o arrastre el conjunto por omisión a la barra de herramientas para empezar de nuevo. Ventana › Ocultar barra de herramientas oculta la barra de herramientas de la ventana activa.

Elementos de la ventana de código

Componer, con el menú Programa a su lado, compone el documento con el programa elegido allí; también hay botones para programas concretos, como BibTeX y MakeIndex. Plantillas y Macros insertan texto (consulte Plantillas y documentos modelo y Macros). Marcas y Etiquetas desplazan el código fuente hasta una sección o una etiqueta. Autocompleción activa o desactiva las combinaciones de teclas para el documento, y Dividir ventana divide la ventana (haga clic con la tecla Opción para dividirla en dos partes una junto a otra).

Ruta completa muestra la ruta completa del archivo en el título de la ventana en lugar de solo su nombre; haga clic de nuevo para mostrar el nombre. La elección se conserva para las ventanas que se abran después.

Elementos de la ventana de vista previa

La ventana de vista previa tiene, entre otros, Página anterior y Página siguiente, Ir a la página, Atrás/Adelante, Escala, Modo de ratón, Buscar, Cajón, Marcas de sincronización, Dividir ventana y Aspecto, que muestra las páginas claras u oscuras. Haga clic en la palabra situada junto al campo de la escala para abrir el menú Aumento.

Disposición de página elige Página simple, Página doble, Multipágina o Multipágina doble para el documento. Con páginas dobles elige, para el documento mientras está abierto, si dos páginas van de izquierda a derecha o de derecha a izquierda y si la primera página se muestra sola como portada; «Restaurar ajustes del documento», en este menú, vuelve a los Ajustes y a las líneas de comentario mágicas del documento. Zoom al contenido y Zoom al ancho del contenido cambian el aumento una sola vez para que la parte compuesta de la página, sin sus márgenes blancos, quepa en la ventana o en su ancho. Consulte La ventana de vista previa.

PDF › Mostrar barra de herramientas de anotaciones muestra una segunda barra de herramientas bajo la barra de herramientas, con las herramientas para añadir notas, resaltados y formas al PDF. Haga clic en el botón de cerrar de su extremo derecho, o elija PDF › Ocultar barra de herramientas de anotaciones, para quitarla. Las anotaciones se describen en el Manual de TeXShop (Ayuda › Manual de TeXShop (en inglés)).

AppleScript

TeXShop se puede controlar con AppleScript: los scripts pueden componer documentos, ejecutar BibTeX y MakeIndex y trabajar con el texto del código fuente. Las macros de AppleScript del menú Macros ejecutan scripts de este tipo; consulte Macros AppleScript. Los comandos que entiende TeXShop se explican en Ayuda › Documentos anteriores › Notas sobre AppleScript en TeXShop (en inglés), y se enumeran en el diccionario de scripts de TeXShop, que Editor de Scripts abre con Archivo › Abrir diccionario….
