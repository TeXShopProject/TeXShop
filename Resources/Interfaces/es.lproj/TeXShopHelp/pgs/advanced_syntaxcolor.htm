Resaltado de sintaxis

La ventana de código muestra TeX en colores: los comentarios, los comandos, las notas al pie, los marcadores $ y &, y los delimitadores ( ), { } y [ ] tienen cada uno su color. Código › Resaltado de sintaxis activa o desactiva el resaltado en el documento activo. Los documentos se abren con el resaltado activado; para abrirlos con él desactivado, use el ajuste oculto

defaults write TeXShop SyntaxColoringEnabled NO

Qué se resalta

  • Los comandos son una barra invertida seguida de letras. Ajustes › Editor › Resaltado de sintaxis › «@ en nombres de comando» cuenta también @ como letra, como en los comandos internos de los paquetes.
  • El texto de \footnote, \footcite y \autocite, y de los comandos que empiezan por \cite o \Cite, como \citep y \citeauthor, se muestra con el color «Nota al pie». El ajuste oculto defaults write TeXShop SyntaxColorFootnote NO colorea solo el comando.
  • Código › Resaltar las entradas del índice muestra los argumentos de \index y \esindex con el color «Índice». Ajustes › Editor › Resaltado de sintaxis › «Resaltar las entradas del índice por omisión» lo activa al abrir los documentos.
  • Código › Resaltar el código expl3 colorea además las funciones, variables y otras partes del código expl3, la capa de programación de LaTeX, para quienes escriben paquetes. «Resaltar el código expl3 por omisión», del mismo grupo, lo activa al abrir los documentos.
  • «Realzar letras y símbolos de ancho completo», del mismo grupo, muestra con los colores «Ancho completo» las letras, dígitos y símbolos de ancho completo, que en un texto japonés se confunden fácilmente con caracteres ASCII.

«Resaltar las entradas del índice» y «Resaltar el código expl3» se aplican al documento activo; cada ventana de código tiene su propia elección. Los archivos que no son fuentes TeX, como los archivos log, no se resaltan; consulte Abrir otros archivos con TeXShop para ver la lista de extensiones y cómo añadir una.

Cambiar los colores

Los colores pertenecen al tema. Elíjalos en Ajustes › Temas:

  • el grupo «Resaltado de sintaxis» tiene «Comentario», «Comando», «Nota al pie», «Marcador» e «Índice»;
  • el grupo «Delimitadores» tiene los colores de ( ), { } y [ ];
  • el grupo «expl3» tiene function, __function, key, variable, __variable, argument y msg;
  • el grupo «Resaltados» tiene, entre otros, los colores «Ancho completo»;
  • el grupo «Sintaxis XML» tiene los colores para los archivos HTML y XML.

Cada tema tiene sus propios colores, de modo que el tema de «Modo claro» y el de «Modo oscuro» pueden ser distintos.
