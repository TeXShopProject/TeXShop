Panel LaTeX

Ventana › Panel LaTeX... abre un panel de código LaTeX: símbolos matemáticos, letras griegas, funciones, caracteres acentuados e internacionales, entornos y comandos de tipografía. Haga clic en el lugar del código fuente donde debe ir el código y después haga clic en un botón del panel. Su código se inserta en el punto de inserción. El panel se queda delante de las ventanas de código mientras usted trabaja.

Los botones están organizados en páginas. Elija una página con los botones de la parte superior de cada parte del panel: Matemáticas, Griego, Símbolos, Funciones e Internacional, y Entornos, Tipografía y Personalizado.

Si hay texto seleccionado al hacer clic en un botón de tipografía o de entorno, el texto seleccionado queda dentro del código insertado, como en \textbf{texto seleccionado}.

Algunos símbolos necesitan el paquete amssymb. Añada esta línea al preámbulo de un documento que los use:

\usepackage{amssymb}

Personalizar el panel

El código que inserta cada botón se guarda en ~/Library/TeXShop/LatexPanel/completion.plist. Abra este archivo en TeXShop para modificarlo; los comentarios del principio explican cómo está organizado. Los nombres de los botones estándar no se pueden cambiar, pero el código que insertan sí. En este código:

  • #SEL# representa el texto seleccionado;
  • #INS# marca dónde queda el punto de inserción después de insertar el código;
  • #PASTE# representa el texto del portapapeles.

La página Personalizado tiene sitio para un máximo de dieciséis botones propios. Cada uno se define en la lista Customized del archivo mediante dos cadenas, el nombre del botón y el código que inserta:

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Guarde el archivo en UTF-8 y después salga de TeXShop y vuelva a abrirlo para ver los cambios en el panel. Si el archivo falta o está dañado, TeXShop lo sustituye por su propia copia. Consulte Modificar el panel LaTeX y Archivos de ~/Library/TeXShop.
