Usar un editor externo

Puede escribir en otro editor y usar TeXShop para componer y mostrar el PDF.

Abrir solo la vista previa

Archivo › Abrir para previsualizar... pide un archivo fuente y abre solo su ventana de vista previa. Si el archivo aún no se ha compuesto, o si el PDF es más antiguo que el archivo fuente, TeXShop lo compone primero. Edite el archivo fuente en su editor; para componerlo, guárdelo allí y pulse «Componer» en la ventana de vista previa o pulse ⌘T. En este modo TeXShop nunca abre ni modifica el archivo fuente. Si la barra de herramientas de la ventana de vista previa no tiene botón «Componer», añádalo con Ventana › Personalizar barra de herramientas...

Si trabaja siempre de esta manera, active Ajustes › General › Al iniciar › «Configurar para editor externo». Archivo › Abrir... y «Abrir recientes» abren entonces los archivos fuente solo para previsualizarlos, y Archivo › Abrir para previsualizar... se convierte en «Abrir para editar...», que abre un archivo fuente en el editor de TeXShop cuando lo necesite. Los demás archivos, como los PDF, los gráficos y los archivos log, se abren como siempre.

Mantener actualizada la vista previa

Cuando otro programa reescribe el PDF, por ejemplo su editor o latexmk en Terminal, TeXShop lo recarga cuando vuelve a TeXShop o a la ventana de vista previa, conservando la página y el aumento. Con Ajustes › Vista previa › Actualización › «Vigilar siempre los cambios del PDF hechos por otras apps» activado, recarga el PDF en cuanto cambia, incluso con TeXShop en segundo plano, por ejemplo cuando la vista previa está junto a su editor. Una vista previa con anotaciones sin guardar no se recarga, para que no se pierdan las anotaciones.

TeXShop también vigila los archivos fuente abiertos en su propio editor. Cuando otro editor modifica uno de esos archivos, TeXShop lo recarga, salvo que la copia de TeXShop tenga cambios sin guardar.

Sincronizar con el editor

Un clic con la tecla Comando en la ventana de vista previa puede llevarle a la línea en su editor, e «Ir al error» en la consola puede abrir allí la línea de un error. Esto requiere «Configurar para editor externo», un ajuste oculto y un programa de línea de comandos del editor:

  • Para TextMate, cuyo comando mate está en /usr/local/bin: defaults write TeXShop TextMateSync YES.
  • Para cualquier otro editor: defaults write TeXShop OtherEditorSync YES, y un script ejecutable /usr/local/bin/othereditor que recibe el número de línea como $1 y la ruta completa del archivo como $2. Para BBEdit es así: 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

Para el sentido contrario, de una línea del editor a la ventana de vista previa, el editor llama a TeXShop mediante AppleScript con los comandos sync_preview_line, sync_preview_index y sync_preview_name. El capítulo «Using an External Editor» de Ayuda › Manual de TeXShop (en inglés) contiene un script completo.

La carpeta ~/Library/TeXShop/ExternalEditorScripts contiene soluciones listas para usar con su documentación: AppleScripts que componen y previsualizan en TeXShop un documento de BBEdit, y un complemento para Vim.

Comandos AppleScript para editores

Un editor puede llamar a estos comandos AppleScript de un documento de TeXShop:

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Componen, o ejecutan plain TeX, LaTeX, BibTeX, MakeIndex o MetaPost. La llamada vuelve de inmediato, sin esperar a que termine la composición; la vista previa se actualiza cuando termina.
taskdone
Devuelve NO mientras la composición está en marcha y YES cuando ha terminado.
refreshpdf
Recarga el PDF y trae al frente la ventana de vista previa.
refreshpdfbackground
Recarga el PDF sin traer TeXShop al frente, cuando la ventana de vista previa ya está abierta.
refreshtext
Vuelve a leer del disco el archivo fuente.
open_for_externaleditor
Abre un archivo fuente como lo hace Archivo › Abrir para previsualizar...

Cuando el editor compone a través de TeXShop, no hace falta «Vigilar siempre los cambios del PDF hechos por otras apps». Consulte también Scripts con los comandos de composición de TeXShop.
