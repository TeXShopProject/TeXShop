Añadir motores de composición

Además de con plain TeX y LaTeX, TeXShop compone con motores: pequeños scripts de shell con la extensión .engine situados en la carpeta ~/Library/TeXShop/Engines. Un motor puede ejecutar un solo programa o una cadena de programas, por ejemplo LuaLaTeX, luego Biber y luego dos veces más LuaLaTeX. TeXShop incluye motores como LuaLaTeX, XeLaTeX y pdflatexmk; la subcarpeta Inactive contiene muchos más.

Elegir un motor

El menú desplegable junto al botón «Componer» de la barra de herramientas de la ventana de código muestra los motores. Elija uno y pulse «Componer» o ⌘T. La elección se aplica solo a ese documento.

Para componer los documentos nuevos con un motor, elija «Archivo de motor» en Ajustes › Composición › Motor › Componer documentos nuevos con, y elija el motor en el menú «Archivo de motor» que hay debajo. «Editar la lista de motores…» abre la carpeta Engines en el Finder; el menú «Archivo de motor» sigue a la carpeta a medida que añade, elimina o renombra archivos. Si el archivo de motor elegido ya no está en la carpeta, el menú lo muestra como no encontrado y los documentos se componen con LaTeX.

Para asociar un documento a un motor, escriba una línea como esta en una de sus veinte primeras líneas:

% !TEX program = XeLaTeX

El nombre es el del archivo de motor sin .engine; tex y latex componen plain TeX y LaTeX vía DVI, y pdftex y pdflatex los componen en PDF directo. La línea tiene prioridad sobre la barra de herramientas, sobre los ajustes y sobre «Componer con motor alternativo». La forma % !TEX TS-program = se lee igual. Escriba la línea exactamente como se muestra, con un espacio a cada lado del signo igual; la macro Set Typesetting Program… del menú Macros inserta la línea por usted, con una lista de nombres de motores entre los que elegir. En un proyecto con archivo raíz, solo el archivo raíz necesita la línea.

Componer › Componer con motor alternativo (⌃⌥⌘T) compone una vez con el motor indicado en Ajustes › Composición › Motor › Motor alternativo, pdflatexmk por omisión, sin cambiar la barra de herramientas. En el menú Componer, esta opción aparece en lugar de «Componer» mientras se mantienen pulsadas las teclas Control y Opción. Es útil para documentos que normalmente se componen en una sola pasada rápida y de vez en cuando por completo, con latexmk.

Escribir un motor

La forma más sencilla de crear un motor es duplicar uno de la carpeta Engines en el Finder, renombrar la copia y abrirla en TeXShop para editarla. Un archivo de motor debe tener la extensión .engine y permiso de ejecución, que la copia conserva. Los documentos que se abran después muestran el nuevo motor en su barra de herramientas. Este es XeLaTeX.engine:

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

La primera línea indica la shell o el lenguaje del script; zsh, bash, tcsh, Perl y otros funcionan, siempre que el script esté escrito en ese lenguaje. TeXShop ejecuta el motor en la carpeta del archivo fuente y le pasa tres valores:

$1
El nombre del archivo fuente con su extensión, sin su carpeta, por ejemplo main.tex. Un script que cambie a otra carpeta debe anotar antes la ruta completa, por ejemplo como "$PWD/$1". En un proyecto, es el archivo raíz.
$2
El resto de una línea % !TEX parameter = … situada al principio del archivo fuente (archivo raíz), con varias opciones separadas por espacios, por ejemplo % !TEX parameter = -shell-escape. Sin esa línea, es un único espacio.
$3
La carpeta del campo «Motores TeX» de Ajustes › Composición › Rutas, o la carpeta de «Segundos motores TeX» cuando el documento contiene la línea % !TEX useAlternatePath.

Cuando el motor termina, TeXShop abre en la ventana de vista previa el archivo PDF con el nombre del archivo fuente y la extensión .pdf, si existe, y se desplaza al lugar que se mostraba antes de componer. Un script que produzca otra salida puede indicar qué mostrar con las líneas siguientes, escritas en cualquier parte del motor dentro de un comentario de su lenguaje:

LíneaEfecto
!TEX-noPreviewsin ventana de vista previa, aunque estén presentes otras de las líneas siguientes
!TEX-pdfPreviewmostrar el archivo PDF
!TEX-htmlPreviewmostrar en la ventana HTML el archivo HTML del mismo nombre
!TEX-bothPreviewmostrar el archivo PDF y el archivo HTML
!TEX-noConsoleno mostrar la consola

Por ejemplo, un motor que ejecute LuaLaTeX, Biber y dos veces más LuaLaTeX podría ser así en zsh, donde ${1:r} es el nombre sin la extensión:

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

La carpeta Inactive

La subcarpeta Engines/Inactive contiene motores para flujos de trabajo especiales, a menudo con documentación y ejemplos, por ejemplo para latexmk, ConTeXt, Sage, PreTeXt y Typst. Para usar uno, muévalo desde su carpeta a la propia carpeta Engines. Cuando se actualiza TeXShop, cada archivo de la carpeta Inactive que incluye TeXShop se sustituye por su versión nueva, así que se pierden los cambios que usted haya hecho en esos archivos; los archivos que usted haya añadido y los que TeXShop ya no incluye se quedan como están. Los archivos situados directamente en la carpeta Engines nunca se tocan, de modo que los motores que haya movido allí y editado se conservan.

Para saber más sobre los motores, consulte el capítulo «Engines and latexmk» en Ayuda › Manual de TeXShop (en inglés).
