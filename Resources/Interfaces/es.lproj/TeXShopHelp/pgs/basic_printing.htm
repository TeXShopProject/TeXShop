Imprimir

Para imprimir el documento compuesto, elija Archivo › Imprimir... (⌘P) en la ventana de vista previa o en la ventana de código. En un proyecto con archivo raíz, se imprime el documento raíz compuesto.

El cuadro de diálogo de impresión tiene una sección TeXShop con las mismas opciones que la app Vista Previa de Apple. Con Rotación automática, cada página se gira para adaptarse al papel, de modo que una página en formato apaisado se imprime de lado en papel vertical. Con Ajustar dimensiones, cada página se escala para que quepa en el papel; elija en su lugar «Ajustar escala» para imprimir con un porcentaje fijo. Ambas están activadas al principio, y las opciones de la última impresión se conservan para el documento mientras está abierto. La orientación del papel sigue a la primera página.

Para imprimir el texto del código fuente, elija Archivo › Imprimir el código... Archivo › Ajustar página elige el tamaño del papel.
