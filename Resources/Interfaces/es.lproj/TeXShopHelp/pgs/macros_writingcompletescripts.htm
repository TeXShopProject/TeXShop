Scripts con los comandos de composición de TeXShop

Un documento con bibliografía necesita una secuencia de composiciones: LaTeX escribe el archivo .aux, BibTeX lo usa para escribir los archivos .bbl y .blg, LaTeX vuelve a ejecutarse para añadir la bibliografía al documento, y una vez más para actualizar las referencias a ella. Sus proyectos pueden necesitar secuencias parecidas, y una macro AppleScript puede ejecutarlas por usted.

La macro Macros › Applescript › Bibliography, incluida en TeXShop, muestra cómo hacerlo. Este es su contenido:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

La primera línea convierte esto en una macro AppleScript que ejecuta ScriptRunner, de modo que puede pedir a TeXShop que componga (consulte Macros AppleScript). Las líneas siguientes comprueban #FILEPATH#, la ruta completa del archivo fuente. Es una cadena vacía cuando el documento aún no se ha guardado; en ese caso, el script le pide que lo guarde y se detiene.

A continuación, el script se refiere al documento mediante #DOCUMENTNAME#. TeXShop guarda el documento por sí mismo cuando empieza un comando de composición, así que el script no necesita guardarlo.

Los comandos restantes ejecutan latexinteractive, bibtex, latex y latex. Un comando de composición devuelve el control al script de inmediato, antes de que termine la composición, así que después de cada comando un bucle repeat espera hasta que taskdone indica que el trabajo ha terminado. La línea delay 2 hace que el script haga una pausa entre comprobaciones en lugar de preguntar continuamente y ralentizar el ordenador. Los comandos se enumeran en Definir macros AppleScript.
