Scripts con comandos de shell

Esta página usa la macro Run pdfLaTeX with Shell Escape de Claus Gerhardt, en Macros › Claus Gerhardt Macros, para mostrar cómo un AppleScript llama a un script de shell. El script de shell en sí es sencillo: añade las carpetas de los programas de TeX a la ruta de búsqueda y ejecuta pdflatex con --shell-escape. Sus propios scripts probablemente harán más, por ejemplo ejecutar varios programas uno tras otro; es entonces cuando estas técnicas resultan útiles.

El script de shell

El script de shell es ~/Library/TeXShop/bin/pdflatexc. No depende de TeXShop: si su carpeta está en la ruta de búsqueda, al escribir pdflatexc myfile.tex en Terminal se ejecuta. Es este:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

El AppleScript

La macro que llama a este script de shell es más interesante:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Después de los comentarios, las siete primeras líneas son una receta de Claus Gerhardt para guardar el archivo fuente y averiguar el nombre de su documento, que se guarda en frontName. El trabajo lo hace el script compilado setname.scpt de ~/Library/TeXShop/Scripts: estas líneas obtienen la ruta ~/Library/TeXShop/Scripts/setname.scpt, cargan el script y lo llaman con #NAMEPATH# y #TEXPATH#.

A menudo se puede conseguir lo mismo de forma más sencilla con

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

La receta tiene dos ventajas. También funciona cuando el documento de delante no es el que debe recibir los comandos posteriores, por ejemplo un archivo log como /Users/name/Examples/myfile.log. Y si el archivo no se ha guardado nunca, la receta devuelve un error, mientras que el comando save dejaría el script esperando detrás de un diálogo de guardar.

Las seis líneas siguientes establecen las variables dirName y baseName. Si el archivo fuente es /Users/name/My Papers/Stuff/myfile.tex, dirName es '/Users/name/My Papers/Stuff', entre comillas para la shell por el espacio del nombre de una carpeta, y baseName es myfile.tex. El nombre del archivo se pone entre comillas de la misma manera al pasarlo al script de shell, así que ambos pueden contener espacios.

Las tres líneas siguientes llaman al script de shell. El resultado es el mismo que escribir cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' en Terminal. Las tres últimas líneas actualizan la ventana de vista previa.

Varias de estas líneas son complicadas, pero se pueden copiar sin cambios en scripts nuevos.

Ejecutar comandos de shell desde AppleScript

AppleScript ejecuta un comando de shell de esta forma:

do shell script "cmd input"

Para construir un comando a partir de partes, escríbalo de esta forma equivalente:

do shell script "cmd " & "input"

Observe el espacio después de cmd. El signo & une dos cadenas:

"cmd " & "input" = "cmd input"

Una shell iniciada por AppleScript empieza en la carpeta raíz. El comando

do shell script "cd " & dirName

cambia a la carpeta de dirName, que ya está entre comillas, así que no hacen falta más comillas.

Cada do shell script inicia una shell nueva, de modo que un comando posterior no estaría en esa carpeta. Para ejecutar más comandos en la misma carpeta, únalos con punto y coma en un solo comando, como en Terminal:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

El script anterior hace esto con cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc e input2 = baseName. Las líneas

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

son simplemente una forma cómoda de guardar esta secuencia en una variable.
