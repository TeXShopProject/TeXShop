Establecer el archivo raíz de un proyecto

Los documentos grandes suelen dividirse en varios archivos: un archivo raíz con el preámbulo que incluye un archivo por capítulo. Por ejemplo, un archivo raíz Main.tex podría ser así:

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

Cuando edita two.tex, TeXShop debe componer Main.tex, no el capítulo, que no tiene preámbulo. Para indicárselo, escriba esta línea en una de las veinte primeras líneas de cada archivo de capítulo:

% !TEX root = ../Main.tex

El archivo raíz no necesita esa línea. El nombre del archivo raíz se puede indicar

  • solo por su nombre, Main.tex, cuando está en la misma carpeta que el archivo de capítulo;
  • de forma relativa a la carpeta del archivo de capítulo, ../Main.tex o ../../Main.tex;
  • por su ruta completa, /Users/me/Book/Main.tex, que hay que cambiar si se mueve el proyecto.

La macro Root del menú Macros inserta la línea: pide el archivo raíz y ofrece una línea relativa o absoluta, que sustituye a una línea raíz anterior.

Qué hace la línea raíz

  • Componer en un archivo de capítulo compone el archivo raíz, y la ventana de vista previa del archivo raíz muestra el documento completo. Una línea % !TEX program u otras líneas mágicas para la composición deben ir en el archivo raíz.
  • «Ir al error» abre el archivo que contiene un error, si no está abierto, y va a la línea.
  • La sincronización desde la ventana de vista previa abre el archivo de capítulo que contiene el punto en el que se ha hecho clic; consulte Sincronización entre código y vista previa.
  • «Borrar archivos aux» elimina los archivos auxiliares del archivo raíz; consulte Borrar archivos AUX.
  • Ventana › Código ⇔ PDF (⌘1) en un archivo de capítulo trae al frente la ventana de vista previa del archivo raíz. Al usarlo de nuevo en la ventana de vista previa, se vuelve a la ventana de código de la que se venía, o al archivo raíz si no se venía de una ventana de código.

Abrir un archivo de capítulo

Cuando se abre un archivo de capítulo con línea raíz, TeXShop abre también el archivo raíz y su ventana de vista previa. Dos opciones de Ajustes › General › Archivo raíz del proyecto controlan esto: «Abrir el archivo raíz al abrir un documento» lo activa o desactiva, y «Miniaturizar la ventana raíz abierta» envía al Dock la ventana de código del archivo raíz, ya que rara vez se edita mientras se trabaja en un capítulo.

Buscar y reemplazar en todo el proyecto

Para buscar a la vez en todos los archivos de un proyecto, elija Edición › Buscar › Buscar en fuentes TeX con la misma TEX root… en uno de sus archivos. Busca en el archivo raíz y en los archivos que lo indican en una línea raíz. Consulte Buscar en fuentes TeX y Buscar y reemplazar.

Archivos raíz indicados en archivos .texshop

Un archivo con la extensión .texshop junto a un archivo de capítulo, como two.texshop para two.tex, también puede indicar el archivo raíz, y TeXShop sigue leyéndolo. Ninguna orden de menú crea estos archivos; use una línea % !TEX root, que viaja con el archivo fuente.
