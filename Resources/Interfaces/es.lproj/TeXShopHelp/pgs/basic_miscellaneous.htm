Ventanas y pestañas

Las ventanas de TeXShop se pueden reunir como pestañas de una sola ventana, como en otras apps de macOS. En Ajustes › General, «Abrir nuevas ventanas como pestañas» elige cuándo ocurre: Nunca, Automáticamente, que sigue el ajuste de pestañas de macOS, o Siempre.

Con Siempre y ventanas de código y de vista previa separadas, el código fuente de cada documento que abra se convierte en una pestaña de la ventana de código, y su vista previa en una pestaña de la ventana de vista previa; las consolas y los logs se reúnen de la misma manera. Al seleccionar una pestaña de una ventana, la pestaña correspondiente de la otra pasa al frente cuando compone o sincroniza. Si el código fuente y la vista previa se muestran en una sola ventana («Código y vista previa», en Ajustes › General, puesto en «Usar una ventana»), cada pestaña contiene un documento completo. Ventana › Usar una ventana y Ventana › Usar ventanas separadas cambian el documento activo de una forma a la otra.

Una ventana que muestra a la vez el código fuente y la vista previa, con o sin pestañas, funciona bien en pantalla completa: la consola flota entonces sobre ella mientras compone.

Abrir un proyecto en pestañas

En un libro cuyos capítulos son archivos separados, el archivo raíz puede pedir a TeXShop que abra los capítulos como pestañas de su ventana. Ponga esta línea entre las 20 primeras líneas del archivo raíz:

% !TEX useTabs

Cuando se abre el archivo raíz, los archivos indicados en sus comandos \include se abren como pestañas. En la misma línea se pueden poner nombres cortos para las pestañas, entre paréntesis y separados por comas; un espacio en blanco entre dos comas conserva el nombre de ese archivo:

% !TEX useTabs (Intro, Groups, , Fields)

Para dar pestañas también a los archivos de los comandos \input, use este ajuste oculto en Terminal:

defaults write TeXShop TabsAlsoForInputFiles YES

Para elegir usted mismo los archivos, ponga una línea useTabsWithFiles entre las 20 primeras líneas del archivo raíz y añada una línea tabbedFile por cada pestaña, todo ello entre sus 50 primeras líneas. Puede seguir un nombre para la pestaña entre paréntesis:

% !TEX useTabsWithFiles
% !TEX tabbedFile{chapter1/Introduction.tex} (Introduction)
% !TEX tabbedFile{Galois.log}
% !TEX tabbedFile{~/Graphics/diagram.pdf}

Una ruta es relativa a la carpeta del archivo raíz, empieza en su carpeta de inicio con ~, o es una ruta completa. Escriba siempre la extensión, aunque el Finder la oculte: estas pestañas también pueden mostrar logs, archivos PDF y gráficos. Cada archivo se abre como se abriría si lo abriera usted, de modo que un archivo fuente puede traer consigo su vista previa.
