Crear y usar formatos de TeX

Un archivo de formato (extensión .fmt) es una instantánea de TeX después de haber leído un conjunto de macros. El propio LaTeX es un formato: TeX lo carga en un momento en lugar de leer cada vez el código de LaTeX. Puede crear un formato propio a partir de un preámbulo largo, para que la composición empiece antes, o usar un formato que le proporcione un proyecto o una organización.

Un formato solo funciona con el motor y la versión de TeX Live que lo crearon. Un formato creado con pdfLaTeX de TeX Live 2026 no lo puede usar XeLaTeX ni otro año de TeX Live; vuelva a crearlo después de instalar un nuevo TeX Live.

Crear un formato

Escriba en un archivo las líneas que debe contener el formato, terminando con \dump. Por ejemplo, uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

En Terminal, cambie a la carpeta de este archivo y escriba

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Esto carga el formato LaTeX, lee uo.tex y escribe uo.fmt. Un documento compuesto con este formato omite las líneas que ya están en el formato y empieza con \begin{document}.

Usar un formato en TeXShop

  1. Mueva uo.fmt a la carpeta ~/Library/texmf/web2c, creando las carpetas si hace falta, para que TeX lo encuentre desde cualquier carpeta.
  2. En el Finder, abra ~/Library/TeXShop/Engines (TeXShop › Abrir ~/Library/TeXShop), duplique un motor como XeLaTeX.engine y renombre la copia, por ejemplo Oregon.engine. El nombre aparece en TeXShop y no tiene por qué coincidir con el del formato.
  3. Abra la copia en TeXShop y cambie su última línea para que el motor quede así: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Los documentos que se abran después muestran Oregon en el menú desplegable junto al botón «Componer». Para usar el formato en un documento independientemente de lo elegido ahí, añada esta línea al principio del archivo fuente:

% !TEX program = Oregon

Para que sea el predeterminado, elija «Archivo de motor» en Ajustes › Composición › Motor › Componer documentos nuevos con, y Oregon en el menú «Archivo de motor». Consulte Añadir motores de composición.

Para un formato de plain TeX, use pdftex en lugar de pdflatex en el motor. Para un formato que se vaya a usar vía DVI, el motor también debe convertir el archivo DVI a PDF, por ejemplo con dvipdfmx "${1:r}.dvi" en un script de zsh, porque TeXShop muestra el archivo PDF con el nombre del archivo fuente.
