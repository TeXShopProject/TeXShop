Pueden surgir problemas si hay varias distribuciones de TeX instaladas en el sistema, especialmente si estas distribuciones establecen variables de entorno. Esto puede llevar a que sea difícil detectar los problemas, puesto que quizás se están usando otros archivos diferentes a los esperados.

A partir de TeXShop 6.00, TeXShop puede encontrar TeX y Ghostscript por sí mismo. La primera vez que se usa TeXShop, y al pulsar «Configurar automáticamente…» en la categoría «Composición» de los ajustes, busca en los lugares habituales, como /Library/TeX/texbin, las carpetas de TeX Live, Homebrew y MacPorts, y muestra las instalaciones encontradas con sus versiones. Se selecciona la más reciente, pero puedes elegir otra para TeX y para Ghostscript por separado. Las rutas solo cambian al pulsar «Usar estas rutas». Los motores personalizados y la ruta alternativa no se modifican.

En enero de 2007, Gerben Wierda y Jerome Laurens idearon una nueva estructura de datos que permite que varias distribuciones de TeX convivan en una misma máquina. El usuario puede elegir la distribución activa con el panel de preferencias «TeX Distribution». La estructura de datos crea un enlace simbólico, /Library/TeX/texbin, que siempre apunta a los programas de la distribución activa. Así, los programas con interfaz gráfica se pueden configurar de una vez por todas indicando /Library/TeX/texbin como directorio de los programas, /Library/TeX/texbin/pdftex como ubicación de pdftex, etc.

Esta estructura de datos la instala automáticamente cualquiera de los paquetes MacTeX, y también se instala al descargar el TeX de Gerben Wierda con i-Installer. Es de esperar que en el futuro todas las distribuciones de TeX para Mac OS X adopten esta estructura de datos.
