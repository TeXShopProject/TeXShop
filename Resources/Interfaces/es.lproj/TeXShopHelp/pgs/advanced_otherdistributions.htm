Coexistencia con otras distribuciones de TeX

Pueden surgir problemas si hay varias distribuciones de TeX instaladas en el sistema, especialmente si estas distribuciones establecen variables de entorno. Esto puede llevar a que sea difícil detectar los problemas, puesto que quizás se están usando otros archivos diferentes a los esperados.

A partir de TeXShop 6.00, TeXShop puede encontrar TeX y Ghostscript por sí mismo. La primera vez que se usa TeXShop, y al pulsar «Detectar rutas…» en la categoría «Composición» de los ajustes, busca en los lugares habituales, como /Library/TeX/texbin, las carpetas de TeX Live, Homebrew y MacPorts, y muestra las instalaciones encontradas con sus versiones. Se selecciona la más reciente, pero puedes elegir otra para TeX y para Ghostscript por separado. Las rutas solo cambian al pulsar «Aceptar». Los motores personalizados y la ruta «Segundos motores TeX» no se modifican.

MacTeX usa una estructura de datos que permite que varias distribuciones de TeX convivan en una misma máquina. El usuario puede elegir la distribución activa con el comando «Reconfigure Distributions» de TeX Live Utility. La estructura de datos crea un enlace simbólico, /Library/TeX/texbin, que siempre apunta a los programas de la distribución activa. Así, los programas con interfaz gráfica se pueden configurar de una vez por todas indicando /Library/TeX/texbin como directorio de los programas, /Library/TeX/texbin/pdftex como ubicación de pdftex, etc.

Esta estructura de datos la instala automáticamente cualquiera de los paquetes MacTeX. Un TeX Live instalado sin MacTeX, con el script de instalación de TeX Live, no la crea; en ese caso, indica la carpeta de programas de ese TeX Live en Ajustes > Composición > Rutas > Motores TeX de TeXShop, o usa «Detectar rutas…» (descrito arriba).
