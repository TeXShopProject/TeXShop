Modo alternativo de composición

Normalmente TeXShop compone con el método PDF directo: pdfLaTeX o pdfTeX escriben directamente el archivo PDF. El método alternativo, Vía DVI, ejecuta LaTeX o TeX para crear un archivo DVI, lo convierte a PostScript con dvips y convierte el PostScript a PDF con Ghostscript. El script simpdftex de TeX Live realiza estos pasos.

Vía DVI es necesario para los documentos que introducen código PostScript en el resultado, por ejemplo con el paquete pstricks. Las imágenes EPS no lo necesitan: TeX Live las convierte a PDF al componer con PDF directo.

Elegir el método

Componer › Vía DVI y Componer › PDF directo cambian el método del documento activo; los demás documentos abiertos conservan el suyo. Ajustes › Composición › Método de composición establece el método con el que empiezan los documentos. Su tercera opción, Script personal, ejecuta en su lugar los comandos del grupo Script personal. Los comandos de Vía DVI, uno para plain TeX y otro para LaTeX, están en el grupo Vía DVI de Ajustes › Composición. El perfil del motor LaTeX + dvips + Ghostscript, en Otros del menú Perfil del motor, prepara la composición Vía DVI.

Elegir el método en el documento

Una línea entre las 20 primeras líneas del código fuente establece el programa y el método de ese documento, sean cuales sean los ajustes:

LíneaCompone con
% !TEX program = pdflatexLaTeX, PDF directo
% !TEX program = latexLaTeX, Vía DVI
% !TEX program = pdftexplain TeX, PDF directo
% !TEX program = texplain TeX, Vía DVI
% !TEX program = personallatexLaTeX, Script personal
% !TEX program = personaltexplain TeX, Script personal

Opciones de Vía DVI

Por omisión, Ghostscript no tiene en cuenta la transparencia de PostScript. Para conservarla, añada --distilleropts "-dALLOWPSTRANSPARENCY" al final del comando del grupo Vía DVI. Para conservar el archivo PostScript intermedio, añada --keep-psfile. Ghostscript se ejecuta desde la carpeta indicada en Ajustes › Composición › Rutas › Ghostscript.
