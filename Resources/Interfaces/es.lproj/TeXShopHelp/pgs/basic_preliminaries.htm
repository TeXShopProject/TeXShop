Preliminares

TeXShop es una aplicación de macOS para escribir documentos en TeX y LaTeX. El código fuente se escribe en una ventana de edición, se compone con un clic o con ⌘T y el resultado se lee en una ventana de vista previa situada al lado. Un clic con la tecla Comando en cualquiera de las dos ventanas muestra el lugar correspondiente en la otra.

TeXShop no contiene TeX. Ejecuta los programas de una distribución de TeX, normalmente TeX Live, que el instalador MacTeX instala en el Mac; consulte Instalar TeX Live. TeXShop requiere macOS 14.6 o posterior.

Tal como se instala, TeXShop compone los documentos LaTeX con pdfLaTeX, que escribe directamente un archivo PDF, y la ventana de vista previa muestra ese archivo. Es un archivo PDF normal, que se puede enviar a otras personas y leer en cualquier ordenador. Para componer con otro motor, como LuaLaTeX, elija un perfil del motor en Ajustes o indique el motor al principio del documento; consulte Componer documentos.

Contenido de esta ayuda

Ayuda básica
Instalación de TeX Live y de TeXShop, composición, la ventana de vista previa, edición, búsqueda y reemplazo, revisión ortográfica, combinaciones de teclas y autocompletado de comandos, los paneles, las macros, la impresión y los ajustes.
Ayuda avanzada
Motores de composición, proyectos con un archivo raíz, BibTeX y MakeIndex, codificaciones, editores externos, resaltado de sintaxis y otros temas.
Ayuda para macros
El menú Macros, el editor de macros y las macros escritas en AppleScript.
¿Cómo configuro TeXShop?
Ajustes recomendados, nuevos elementos para ~/Library/TeXShop, ajustes ocultos, combinaciones de teclas y atajos de teclado.

El menú Ayuda abre otros documentos, en inglés. El Manual de TeXShop describe en detalle todas las funciones. Primeros pasos con TeXShop es una introducción breve para usuarios nuevos. Acerca de esta versión indica qué hay que hacer después de una actualización, si es que hay que hacer algo, y Cambios enumera lo que ha cambiado en cada versión. Líneas mágicas y ajustes ocultos enumera las líneas de comentario mágicas, como % !TEX program =, y los ajustes que la ventana de Ajustes no muestra.

El sitio web de TeXShop es texshop.app.
