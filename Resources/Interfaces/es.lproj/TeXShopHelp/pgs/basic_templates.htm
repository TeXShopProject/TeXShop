Plantillas y documentos modelo

Plantillas

El menú Plantillas de la barra de herramientas de la ventana de código inserta una plantilla en el punto de inserción, con la misma sangría que la línea actual. TeXShop incluye estas plantillas:

  • LatexTemplate, XeLaTeX Template, LatexSpanishTemplate y BeamerTemplate: el principio de un artículo LaTeX, de un documento XeLaTeX, de un artículo LaTeX en español y de una presentación Beamer;
  • TexTemplate: el \end que cierra un documento plain TeX;
  • GraphicsTemplate: el código para incluir un gráfico;
  • TeX4ht-Header y TeX4ht-Interactive: código para documentos que se convierten a HTML con TeX4ht;
  • More: un submenú con preámbulos, clases de documento como article, letter y memoir, figuras y tablas flotantes, y disposiciones matemáticas como align y matrices.

Las plantillas son archivos normales de ~/Library/TeXShop/Templates; elija TeXShop › Abrir ~/Library/TeXShop para llegar allí. Para crear una plantilla propia, por ejemplo el preámbulo que usa en todos sus artículos, guarde un archivo con la extensión .tex en esta carpeta, o duplique una plantilla y modifíquela. Las subcarpetas se convierten en submenús. Las plantillas que añada, renombre o elimine aparecen en el menú de las ventanas que se abran después.

Las actualizaciones de TeXShop no modifican esta carpeta, así que sus plantillas se conservan. Para recuperar las plantillas originales, saque la carpeta Templates de ~/Library/TeXShop, por ejemplo al escritorio, y reinicie TeXShop: vuelve a crear la carpeta con sus propias plantillas.

Documentos modelo

Archivo › Nuevo desde documento modelo... empieza un documento nuevo a partir de un ejemplo completo: elija uno en la lista, que muestra una descripción de cada uno, y haga clic en Aceptar. El documento nuevo no tiene título; guárdelo donde quiera. TeXShop incluye documentos modelo para un artículo de la AMS, una presentación Beamer, una carta, un documento PreTeXt, un proyecto con un archivo raíz y un capítulo, y un documento XeLaTeX.

Los documentos modelo se guardan en ~/Library/TeXShop/Stationery. Para añadir uno propio, ponga allí el archivo, por ejemplo Report.tex, junto con un archivo Report.comment que contenga una frase que lo describa.
