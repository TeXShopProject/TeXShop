Sitios web útiles

TeXShop
El sitio web de TeXShop.
TeXShop en GitHub
El código fuente de TeXShop y el lugar para informar de problemas (consulte Informar de errores).
MacTeX
La distribución TeX Live para macOS, con TeXShop y otros programas.
TeX Users Group (TUG)
El grupo internacional de usuarios de TeX, sede de TeX Live y de muchos recursos de TeX.
CTAN
The Comprehensive TeX Archive Network: paquetes, tipos de letra y su documentación.
TeX Stack Exchange
Preguntas y respuestas sobre TeX, LaTeX y programas relacionados.
learnlatex.org
Un curso breve de LaTeX con ejemplos que se pueden probar en línea.
The LaTeX Project
Noticias y documentación del equipo que mantiene LaTeX.
MetaPost
El lenguaje de dibujo MetaPost.
XeTeX
XeTeX y XeLaTeX, que usan los tipos de letra instalados en su Mac.
ConTeXt Garden
La documentación y la comunidad de ConTeXt.
