シェルコマンドでスクリプトを書く

このページでは、「マクロ」→「Claus Gerhardt Macros」にあるClaus Gerhardtのマクロpdflatexcを使って、AppleScriptからシェルスクリプトを呼び出す方法を説明します。シェルスクリプト自体は単純で、TeXのプログラムのフォルダを検索パスに加え、pdflatexを--shell-escape付きで実行するだけです。自分のスクリプトでは、いくつかのプログラムを順に実行するなど、もっと多くのことをするでしょう。そのときにここで説明する技法が役に立ちます。

シェルスクリプト

シェルスクリプトは~/Library/TeXShop/bin/pdflatexcです。TeXShopには依存しないので、そのフォルダが検索パスに入っていれば、ターミナルでpdflatexc myfile.texと入力して実行できます。内容は次のとおりです。

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

AppleScript

このシェルスクリプトを呼び出すマクロの方が、興味深い内容です。

--Applescript
-- Apply only to an already saved file.
-- Claus Gerhardt, Nov. 2003

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

コメントの後の最初の7行は、ソースファイルを保存し、その書類の名前を調べてfrontNameに入れるための、Claus Gerhardtによる決まった手順です。実際の処理は、~/Library/TeXShop/Scriptsにあるコンパイル済みのスクリプトsetname.scptが行います。これらの行は~/Library/TeXShop/Scripts/setname.scptのパスを求め、スクリプトを読み込み、#NAMEPATH#と#TEXPATH#を渡して呼び出します。

多くの場合、同じことは次のようにもっと簡単にできます。

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

この手順には2つの利点があります。1つは、手前の書類が、後のコマンドを受け取るべき書類ではないとき、たとえば/Users/name/Examples/myfile.logのようなログファイルのときにも働くことです。もう1つは、ファイルを一度も保存していないとき、この手順ならエラーを返しますが、saveコマンドでは保存ダイアログの後ろでスクリプトが待ったままになることです。

続く6行は、変数dirNameとbaseNameを設定します。ソースファイルが/Users/name/My Papers/Stuff/myfile.texなら、dirNameは'/Users/name/My Papers/Stuff'です。フォルダの名前に空白があるので、シェル用にクォートしてあります。baseNameはmyfile.texです。このようにすれば、フォルダの名前には空白があってもかまいません。ファイル自体の名前には、TeXが空白を許しません。

次の3行で、シェルスクリプトを呼び出します。結果は、ターミナルでcd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc myfile.texと入力したのと同じです。最後の3行で、プレビューのウインドウを更新します。

いくつかの行は複雑ですが、新しいスクリプトにはそのままコピーして使えます。

AppleScriptからシェルコマンドを実行する

AppleScriptでは、シェルコマンドを次の形で実行します。

do shell script "cmd input"

コマンドを部品から組み立てるには、これと同じ意味の次の形で書きます。

do shell script "cmd " & "input"

cmdの後の空白に注意してください。アンパサンドは2つの文字列をつなぎます。

"cmd " & "input" = "cmd input"

AppleScriptが起動したシェルは、ルートフォルダから始まります。次のコマンドは、

do shell script "cd " & dirName

dirNameにあるフォルダに移動します。dirNameはすでにクォートされているので、さらにクォートする必要はありません。

do shell scriptはそのたびに新しいシェルを起動するので、後のコマンドはそのフォルダにいません。同じフォルダでさらにコマンドを実行するには、ターミナルと同じように、セミコロンでつないで1つのコマンドにします。

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

上のスクリプトでは、cmd1 = cd、input1 = dirName、cmd2 = ~/Library/TeXShop/bin/pdflatexc、input2 = baseNameとして、これを行っています。次の2行は、

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & baseName

この一連のコマンドを1つの変数に入れるための便利な書き方にすぎません。
