設定には「一般」「書類と保存」「エディタ」「スペルチェック」「外観」「プレビュー」「タイプセット」「コンソール」「キーボード」「アップデート」の10分類があります。「スペルチェック」では「LaTeXの構造を考慮する（推奨）」と「従来方式を使う」のどちらかを選びます。新方式の下には「LaTeXの除外規則を編集…」、従来方式の下には字下げした3項目があります。方式を変えても子項目の値は保持します。入力中のスペルチェックは独立した設定です。「キーボード」ではキーバインドとコマンド補完を検索欄より上に置き、ショートカット一覧だけを縦にスクロールします。高さが足りないときは入力設定を一つずつ開けます。Tabを補完キーにしてキー検索でTabを押すと、予約の説明と補完キーの設定行を表示します。「一般」からコメント行と隠し設定の説明を開けます。無効な子項目の保存値を保持し、廃止された分類を記憶していた場合は「一般」を開きます。

「設定」の「キーボード」で変更します。「機能で検索」はコマンド名やメニューの階層で、「キーで検索」は押したキーで絞り込みます。キーの割当ての優先順位を示し、今の書類で実行できるかとは区別します。検索だけでは設定を変更せず、Command-QやCommand-Wも実行しません。システムが使うキーは検出できません。修飾なしのEsc、切り替えの再クリック、カテゴリ移動、別のウインドウへの移動、設定を閉じる操作で記録を終了します。マクロの行は読み取り専用です。「マクロエディタで表示」は未保存の編集を保って該当マクロを選び、編集によって対象が一意に決まらなくなった場合は選択を変えません。

「設定…」を開き、「キーボード」カテゴリを選ぶと、メニューコマンドのショートカットを変更できます。コマンドを選んで「変更…」を押し（ダブルクリックでもかまいません）、新しいショートカットのキーを押して「適用」を選びます。Escape キーで取り消せます。ショートカットには Command キーか Control キーを含めるか、ファンクションキー F1～F20 を使います。ほかのコマンドがすでに使っているショートカットは、そのことを知らせて変更しません。「割り当てを解除」「初期状態に戻す」「すべて元に戻す…」で、ショートカットを外したり元に戻したりできます。変更はすぐに反映され、TeXShop を起動し直しても保たれます。

ほかのメニューコマンドが既定のキーを使っている間は、「初期状態に戻す」で復元できません。先にそのコマンドの割り当てを変更してください。

同じキーと修飾キーの場合は、メニューコマンドのキー（変更した場合はカスタムキー）がマクロより優先されます。カスタマイズで空いたキーはマクロで使えます。マクロが使用中のキーをメニューに割り当てる、または初期状態に戻す場合は確認します。マクロ自体はメニューから実行できますが、そのキーは無効になります。マクロのファイルは変更しません。マクロエディタでは無効なキーに印を付け、競合する相手とキーを表示します。保存時の確認は、新しく割り当てた・変更したキーの競合だけが対象です。取り込んだマクロも含みます。「編集に戻る」「このまま保存（重なるキーは無効）」「重なるキーを外して保存」から選べます。以前からの競合でキーを変更していなければ、保存を止めません。マクロ同士では先に並ぶものが優先されます。「割り当てできません」はメニューコマンド同士の競合だけに使われます。プレビューのCommand-FとCommand-Gは「検索パネル...」「次を検索」のカスタム割り当てや解除にも従います。

下で説明する KeyEquivalents.plist で設定したショートカットは、引き続き既定値として使われます。「すべて元に戻す…」もこのファイルは変更しません。マクロのショートカットはマクロエディタで、文字を入力するキーバインドはキーバインドの編集画面で設定します。

TeXShop のメニュー項目のショートカットキーは再定義することができます。再定義するには「KeyEquivalents.plist」というファイルの冒頭にあるコメントを読み、適切な変更を施します。TeXShop を使ってファイル──~/Library/TeXShop/Menus/KeyEquivalents.plist を編集します。もし Unicode 文字を使用するのであれば、かならず UTF-8 形式で編集し保存してください。

結果の行をクリックしてもキーの記録は続きます。一覧だけが縦にスクロールします。無効な結果には優先される相手とキーを表示し、マクロの階層は区切り記号で分けます。

設定を検索

サイドバー上部の「設定を検索」で、カテゴリ名、項目名、選択肢、メニューコマンドを探せます。空白で区切った語は、同じカテゴリ内ですべて一致する必要があります。大文字・小文字、欧文のアクセント、全角・半角、ひらがな・カタカナの違いを吸収します。結果を選ぶと該当箇所へ移動して強調します。設定値や無効な項目の状態は変えません。検索語を消すと検索前のカテゴリに戻ります。メニューコマンドに一致した場合は「キーボード」の「機能で探す」に同じ語を入れます。キー記録中は「キーで探す」が優先されます。入力した値、個人のパス、自分で作ったテーマ名は検索しません。
