TeXShop 5.60 からは、TeXShop メニューの「設定…」のすぐ下にある「キーボードショートカット…」を使うのがいちばん簡単です。ウインドウにはメニューのコマンドとそのショートカットが並び、検索欄でコマンドを名前で探せます。コマンドを選んで「変更…」を押し（ダブルクリックでもかまいません）、新しいショートカットのキーを押して「適用」を選びます。Escape キーで取り消せます。ショートカットには Command キーか Control キーを含めるか、ファンクションキー F1～F20 を使います。ほかのコマンドがすでに使っているショートカットは、そのことを知らせて変更しません。「割り当てを解除」「初期状態に戻す」「すべて元に戻す…」で、ショートカットを外したり元に戻したりできます。変更はすぐに反映され、TeXShop を起動し直しても保たれます。

マクロに割り当てたキーが優先されます。保存したショートカットを、TeXShop の起動時にほかのコマンドがすでに使っている場合（マクロに同じキーを割り当てたときなど）は、設定は残したまま使わず、ウインドウの上部に「割り当てできません」としてそのコマンドを示します。元のショートカットをほかのコマンドが使っている間は、「初期状態に戻す」はできません。先にそのコマンドのショートカットを変えてください。プレビューのウインドウの Command-F と Command-G は、「検索パネル...」と「次を検索」のショートカットに従います。どちらかの割り当てを解除すると、プレビューでもそのキーは働かなくなります。

下で説明する KeyEquivalents.plist で設定したショートカットは、引き続き既定値として使われます。「すべて元に戻す…」もこのファイルは変更しません。マクロのショートカットはマクロエディタで、文字を入力するキーバインドはキーバインドの編集画面で設定します。

TeXShop のメニュー項目のショートカットキーは再定義することができます。再定義するには「KeyEquivalents.plist」というファイルの冒頭にあるコメントを読み、適切な変更を施します。TeXShop を使ってファイル──~/Library/TeXShop/Menus/KeyEquivalents.plist を編集します。もし Unicode 文字を使用するのであれば、かならず UTF-8 形式で編集し保存してください。
