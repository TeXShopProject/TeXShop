TUGのTeX Liveは /usr/local/texlive というディレクトリにインストールされますが、ファインダからは見ることができません。けれどもインストーラによって、アクティブなTeXディストリビューションのディレクトリへのシンボリック・リンクが /Library/TeX/Root に作成されます。ですから、ディストリビューション内のファイルを調べるには /Library/TeX/Root へ行ってください。

アクティブなディストリビューションのドキュメント類は /Library/TeX/Documentation にあります（これは実際には、ディストリビューション内のいろいろなドキュメント・フォルダへのリンクです）。

追加のスタイルファイルやフォントなどをTeX Liveそのものに格納しておくこともできます。けれどもTeX Liveは所有者がルートで、ユーザが書き込めないフォルダに置かれています。そのうえ、後のバージョンがリリースされたときに簡単にアップグレードできるよう、このディレクトリは手を加えないままにしておくのがよいでしょう。ライブラリ・フォルダ内にTeX Liveのディレクトリ構造をそっくり写した構造を作り、そこに個人的なファイルを格納するほうがよいのです。

ファイルは適切なディレクトリに置いてやらねばなりません。TeX LiveはTeXワーキンググループの考案したディレクトリ構造を用いています。LaTeXが使うスタイルファイルに、new.styという名前のスタイルファイルを追加したいとしましょう。TeX Liveの中を見てみると、このファイルを置くのにふさわしい場所は次のところだとわかります。

/usr/local/texlive/2008/texmf/tex/latex/misc/

ということで、ホーム・ディレクトリのライブラリ・フォルダ内に、次のような一連のサブディレクトリを作成してください。

Library --> texmf --> tex --> latex --> misc

そして「new.sty」をこのmiscディレクトリの中に格納します。

TeX Liveは、BibTeXのbibファイルを ~/Library/texmf/bibtex/bib から、BibTeXのbstファイルを ~/Library/texmf/bibtex/bst から探します。

MacTeXは、/Applications/TeXにTeX Live Utilityもインストールします。複数のTeXディストリビューションがインストールされている場合は、TeX Live Utilityの「Configure」メニューから「Reconfigure Distributions」を選ぶと、使うディストリビューションを切り替えられます。切り替えたディストリビューションは、コマンドラインから呼び出すTeX、ターミナルでのMANページ、それに/Library/TeX/texbinを通してTeXを見つけるすべてのGUIアプリケーションで使われます。MacTeXを使わずにインストールしたTeX LiveがTeX Live Utilityに表示されない場合は、代わりに設定の「タイプセット > パス > TeXエンジン」に、そのTeX Liveのバイナリのフォルダ（たとえば/usr/local/texlive/2026/bin/universal-darwin）を指定してください。
