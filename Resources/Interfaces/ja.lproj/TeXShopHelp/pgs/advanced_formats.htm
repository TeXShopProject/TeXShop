TeXのフォーマットを作成して使う

フォーマットファイル（拡張子.fmt）は、TeXが一組のマクロを読み込んだ状態を保存したものです。LaTeX自体も1つのフォーマットで、TeXは毎回LaTeXのソースを読む代わりに、フォーマットを一瞬で読み込みます。長いプリアンブルから自分のフォーマットを作ってタイプセットの開始を速くしたり、プロジェクトや組織が用意したフォーマットを使ったりできます。

フォーマットは、それを作ったエンジンとTeX Liveの版でしか使えません。TeX Live 2026のpdfLaTeXで作ったフォーマットは、XeLaTeXでも別の年のTeX Liveでも使えません。新しいTeX Liveをインストールしたら、作り直してください。

フォーマットを作る

フォーマットに含める行をファイルに書き、最後に\dumpを置きます。たとえばuo.texは次のようにします。

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

ターミナルでこのファイルのフォルダに移動し、次のように入力します。

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

これでLaTeXのフォーマットが読み込まれ、uo.texが読まれて、uo.fmtが書き出されます。このフォーマットでタイプセットする書類では、フォーマットに含めた行を省いて\begin{document}から始めます。

TeXShopでフォーマットを使う

  1. uo.fmtを~/Library/texmf/web2cフォルダに移します（フォルダがなければ作ります）。こうすると、TeXがどのフォルダからでも見つけます。
  2. Finderで~/Library/TeXShop/Enginesを開き（「TeXShop」→「~/Library/TeXShopを開く」）、XeLaTeX.engineなどのエンジンを複製して、たとえばOregon.engineと名前を変えます。この名前はTeXShopに表示されるもので、フォーマットの名前と同じである必要はありません。
  3. 複製したファイルをTeXShopで開き、最後の行を変えて次の内容にします。 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

そのあとに開いた書類では、「タイプセット」ボタンの横のポップアップメニューにOregonが表示されます。そこで何を選んでいても特定の書類でこのフォーマットを使うには、ソースの先頭に次の行を加えます。

% !TEX program = Oregon

これを既定にするには、「設定」→「タイプセット」→「エンジン」の「新しい書類のタイプセット」で「エンジンファイル」を選び、「エンジンファイル」メニューでOregonを選びます。タイプセットエンジンを追加するを参照してください。

plain TeXのフォーマットでは、エンジンでpdflatexの代わりにpdftexを使います。DVI経由で使うフォーマットでは、エンジンでDVIファイルをPDFに変換する必要もあります。TeXShopはソースと同じ名前のPDFファイルを表示するからです。たとえばzshのスクリプトならdvipdfmx "${1:r}.dvi"のようにします。
