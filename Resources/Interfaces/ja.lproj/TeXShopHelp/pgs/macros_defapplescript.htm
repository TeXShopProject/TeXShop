AppleScriptマクロを定義する

AppleScriptは、それ自体が1つの言語です。AppleのデベロッパWebサイトにある、AppleのAppleScript Language Guideに詳しく説明されています。

パスと書類の名前

AppleScriptマクロを実行する前に、TeXShopは次の文字列を、作業中の書類のファイルのパスに置き換えます。パスはダブルクォートで囲まれます。

#FILEPATH#
ソースファイル
#TEXPATH#
.texファイル
#NAMEPATH#
拡張子を除いたソースファイル
#FOLDERPATH#
ソースのあるフォルダ。末尾はスラッシュです
#PDFPATH#、#DVIPATH#、#PSPATH#、#LOGPATH#、#AUXPATH#
.pdf、.dvi、.ps、.log、.auxの各ファイル
#INDPATH#、#BBLPATH#、#HTMLPATH#
.ind、.bbl、.htmlの各ファイル

たとえば、#FILEPATH#が/Users/name/Projects/Fourier/Fourier.texなら、#FOLDERPATH#は/Users/name/Projects/Fourier/です。書類を一度も保存していなければ、#FILEPATH#は空の文字列です。

#DOCUMENTNAME#は、ソースのウインドウのタイトルに表示されているとおりの書類の名前に置き換わります。拡張子を表示していれば拡張子付き、隠していれば拡張子なしです。スクリプトでは、これを使って自分を呼び出した書類を指定します。

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

TeXShopのコマンド

AppleScriptが仕事をする方法は2つあります。シェルコマンドでスクリプトを書くで説明するようにシェルコマンドを実行するか、TeXShopのタイプセットコマンドでスクリプトを書くで説明するようにTeXShop自身のコマンドを呼び出すかです。TeXShopは次のコマンドを理解します。

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

最初の6つのコマンドは、エラーで止まらずに続けてタイプセットします。次の6つもタイプセットしますが、エラーで止まり、コンソールで応答できるようにします。タイプセットのコマンドは、タイプセットが終わる前にすぐ戻ります。taskdoneは、タイプセットがまだ実行中ならNOを、終わっていればYESを返します。refreshpdfとrefreshtextは、PDFとテキストのウインドウにファイルの最新の版を表示させます。goto lineはソースの行を選択します。

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
