ConTeXtとMetaPost

ConTeXt

ConTeXtは、Hans Hagenによるマクロパッケージです。LaTeXに代わるもので、独自のコマンドを持ち、組版のデザインを特に重視しています。TeX LiveにはConTeXtが含まれています。また、ConTeXt Gardenは、頻繁に更新され、ホームフォルダにインストールする版を配布しています。

ConTeXt用のエンジンは、ガイドSetting-Up-ConTeXt.pdfとサンプルの書類とともに、~/Library/TeXShop/Engines/Inactive/ConTeXtにあります。

エンジンタイプセットに使うもの
ConTeXt.engineTeX LiveのConTeXtで、LuaTeXで動くもの
ConTeXt-TL.engineTeX LiveのConTeXtで、luametatexで動くもの
ConTeXt-CG.engineホームフォルダにあるConTeXt Gardenの版

必要なエンジンを~/Library/TeXShop/Enginesに移し、書類のルートファイルの先頭にマジックコメントを書きます。たとえば次のようにします。

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

ConTeXt-CGを使うときは、ConTeXt Gardenのインストールのプログラムがあるフォルダを「設定」→「タイプセット」→「パス」の「第二のTeXエンジン」欄に入力し、% !TEX useAlternatePathの行を加えます。この行があると、TeXShopはTeX Liveの代わりにそのフォルダをエンジンに渡します。

ソースとプレビューを同期するには、書類の設定に\setupsynctex[state=start,method=min]を加えます。% !TEX useConTeXtSyncParserの行があると、TeXShopはConTeXt独自の同期のコードを使います。ConTeXt Gardenの版のインストールと各エンジンについては、「ヘルプ」→「TeXShopマニュアル（英語）」のConTeXtの章に詳しく書かれています。

ConTeXtの\titleや\subjectなどの見出しのコマンドを「タグ」メニューに表示するには、隠し設定ConTeXtTagsをオンにします。隠し設定を参照してください。

MetaPost

MetaPostは、John Hobbyによるプログラムで、KnuthのMETAFONTから派生したプログラミング言語での記述から図を描きます。マニュアルはTeX Liveに含まれています。「ヘルプ」→「パッケージのヘルプを表示...」を選び、metapostと入力してください。

「タイプセット」→「MetaPost」（⇧⌘M）、または「タイプセット」ボタンの横のポップアップメニューの「MetaPost」は、作業中の書類（拡張子.mpのファイル）にMetaPostを実行します。実行するのは「設定」→「タイプセット」→「周辺ツール」の「MetaPost」にあるコマンドで、初期値はmpostです。エンジンのプロファイルはこの欄を設定します。pLaTeX + dvipdfmxではpmpost、upLaTeX + dvipdfmxではupmpostになり、ラベルの日本語をタイプセットできます。ほかのプロファイルではmpostです。pmpostやupmpostで日本語のラベルをタイプセットした図は、LuaLaTeXでは取り込めません。LuaLaTeXでは、そうした図はluamplibパッケージを使って書類の中で描いてください。

新しいファイルをMetaPostのファイルとして保存するには、保存ダイアログのファイルの種類のメニューでmpを選びます。

Nicola Vitacolonnaによるエンジンnv-metapostとnv-metafunを使うと、MetaPostとMetaFunでの作業が楽になり、ファイルの中の図をプレビューのウインドウに表示できます。これらは~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Enginesにあります。インストールと使い方は1つ上のMetaPostEngines-1.4.7フォルダにあるREADME.pdfに説明されていて、同じフォルダのexamplesフォルダにはサンプルファイルがあります。たとえば、次のように始まるファイルは、nv-metafunのエンジンをEnginesフォルダに置けばnv-metafunでタイプセットされます。

% !TEX program = nv-metafun
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

MetaPostの図は、LaTeXの書類の中に書くこともできます。LuaLaTeXではluamplibパッケージを使います。mfpicなどのパッケージでは、図が.mpファイルに書き出され、2回のタイプセットの間にMetaPostがそれを処理します。
