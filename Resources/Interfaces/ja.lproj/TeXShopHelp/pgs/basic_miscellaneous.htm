ウインドウとタブ

TeXShopのウインドウは、ほかのmacOSのアプリケーションと同じように、ひとつのウインドウのタブにまとめられます。「設定」→「一般」の「新しいウインドウをタブで開く」で、どんなときにまとめるかを選びます。「しない」、macOSのタブの設定に従う「自動」、「すべて」のどれかです。

「すべて」を選び、ソースとプレビューを別々のウインドウにしていると、開いた書類のソースはソースウインドウの、プレビューはプレビューウインドウのタブになります。コンソールとログも同じようにまとめられます。一方のウインドウでタブを選ぶと、タイプセットやSyncのときに、もう一方のウインドウでも対応するタブが手前に出ます。ソースとプレビューをひとつのウインドウに表示しているとき（「設定」→「一般」の「ソースとプレビュー」が「1つのウインドウに統合」のとき）は、ひとつのタブにひとつの書類全体が入ります。「ウインドウ」→「ソースとプレビューを統合」と「ウインドウ」→「ソースとプレビューを分離」で、作業中の書類をどちらの形にするか切り替えられます。

ソースとプレビューを一緒に表示するウインドウは、タブの有無にかかわらず、フルスクリーンで使うと便利です。タイプセットするとき、コンソールはその上に浮かんで表示されます。

プロジェクトをタブで開く

章ごとにファイルを分けた本では、ルートファイルの指定で、章のファイルをそのウインドウのタブとして開けます。ルートファイルの最初の20行のうちに次の行を入れます。

% !TEX useTabs

ルートファイルを開くと、その\includeコマンドで指定したファイルがタブとして開きます。同じ行に、タブの短い名前を丸括弧に入れてコンマで区切って続けることもできます。コンマの間を空けると、そのファイルは元の名前のままです。

% !TEX useTabs (Intro, Groups, , Fields)

\inputコマンドで読むファイルもタブで開くには、ターミナルで次の隠し設定を使います。

defaults write TeXShop TabsAlsoForInputFiles YES

タブで開くファイルを自分で選ぶには、ルートファイルの最初の20行のうちにuseTabsWithFilesの行を書き、タブごとにtabbedFileの行を加えます。これらはすべてルートファイルの最初の50行のうちに書きます。タブの名前は、丸括弧に入れて続けられます。

% !TEX useTabsWithFiles
% !TEX tabbedFile{chapter1/Introduction.tex} (Introduction)
% !TEX tabbedFile{Galois.log}
% !TEX tabbedFile{~/Graphics/diagram.pdf}

パスは、ルートファイルのフォルダからの相対パスか、~で始まるホームフォルダからのパスか、フルパスで書きます。Finderで拡張子が隠れていても、拡張子は必ず書いてください。これらのタブには、ログ、PDFファイル、画像も表示できます。それぞれのファイルは自分で開いたときと同じように開くので、ソースファイルではプレビューも一緒に開くことがあります。

ほかのマジックコメントについては、「ヘルプ」→「マジックコメントと隠し設定（英語）」を参照してください。
