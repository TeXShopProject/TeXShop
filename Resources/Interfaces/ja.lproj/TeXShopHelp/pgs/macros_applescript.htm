AppleScriptマクロ

内容が

--AppleScript

または

--AppleScript direct

で始まるマクロは、選ぶとAppleScriptとして実行されます。大文字と小文字は区別しません。たとえば、「マクロ」→「Applescript」→「View pdf with Preview」は、作業中の書類のPDFを（タイプセット済みなら）プレビューで開きます。その内容は次のとおりです。

--AppleScript direct

tell application "Preview"
  activate
  open POSIX file #PDFPATH#
end tell

スクリプトを実行する前に、TeXShopは#PDFPATH#をPDFのパスに置き換えます。このような文字列の一覧は、AppleScriptマクロを定義するにあります。同じサブメニューの「View pdf with Adobe Acrobat Reader DC」は、同じことをAdobe Acrobatで行います。

--AppleScript directと--AppleScript

--AppleScript directで始まるスクリプトは、TeXShop自身が実行します。実行中のTeXShopはほかのことに応答しないので、このスクリプトからは、入力が必要になるかもしれない作業をTeXShopに頼めません。たとえば、LaTeXの実行は頼めません。ファイルにエラーがあるとコンソールが入力を待ちますが、TeXShopはその入力を受け取れないからです。

--AppleScriptで始まるスクリプトは、TeXShopの中にある小さなプログラムScriptRunnerが実行します。このスクリプトからは、入力が必要になるかもしれない作業もTeXShopに頼めます。ScriptRunnerが待っている間も、TeXShopは動き続けるからです。

したがって、単純なマクロには--AppleScript directが向いていて、タイプセットするなどTeXShopと協調して働くスクリプトには--AppleScriptが必要です。
