ソースとプレビューの同期

ソースのウインドウで語をCommandキーを押しながらクリックすると、プレビューのウインドウが対応する箇所までスクロールし、そこに印を付けます。プレビューのウインドウで箇所をCommandキーを押しながらクリックすると、ソースファイルが（必要なら開いて）対応する行に移動し、その行に印が付きます。2つの印の色は、「設定」→「テーマ」→「SyncTeX」の「プレビュー」と「ソース」で設定します。

SyncTeX

TeXShopはSyncTeXで同期します。TeXをオプション-synctex=1付きで実行すると、PDFの隣にGalois.synctex.gzのようなファイルが書き出されます。このファイルには、ソースの各部分がページのどこに組まれたかが記録されています。エンジンのプロファイルが設定する「設定」→「タイプセット」のコマンドと、TeXShopが~/Library/TeXShop/Enginesに置くエンジンのうちTeXを実行するものは、すでにこのオプションを使っています。自分で加えたエンジンは、Inactiveフォルダから移した任意のエンジンも含めて、コマンドにこのオプションがあるときだけ使います。自作のエンジンでは、TeXの呼び出しに-synctex=1を加えてください（ハイフンは1つでも2つでもかまいません。どのエンジンもどちらも受け付けます）。

synctexファイルにはソースファイルの完全なパスが入っています。プロジェクトのフォルダを移動したり、コピーしたり、ほかの人に送ったりしたあとは、書類をタイプセットし直すまで同期は働きません。

SyncTeXは完全に正確ではありません。探している箇所が、印の少し前や後にあることもあります。

複数のファイルからなるプロジェクト

章のファイルが% !TEX rootでルートファイルを指定しているプロジェクトでは（プロジェクトのルートファイルを設定するを参照）、章のファイルでCommandクリックすると、書類全体のプレビューの対応する箇所に移動し、プレビューでCommandクリックすると、クリックした箇所を含む章のファイルが開きます。「設定」→「タイプセット」→「ソースとプレビューの同期」の「Syncで開くファイルを、ルートファイルのウインドウのタブにする」がオンのときは、こうして開いたファイルは新しいウインドウではなく、ルートファイルのウインドウにタブとして加わります。

Sync方式

「設定」→「タイプセット」→「ソースとプレビューの同期」の「Sync方式」には、2つの選択肢があります。

SyncTeX（推奨）
上で説明したとおり、synctexファイルを使います。これが初期値です。
PDFを検索
クリックした箇所の周りの文字列をPDFの中から探し、プレビューでクリックしたときはその周りの文字列をソースの中から探します。synctexファイルは要りませんが、数式やコマンドの多い文章など、タイプセットした文字列がソースと異なる箇所ではうまくいきません。プレビューの箇所がどのファイルにあるかは、ルートファイルの\includeと\inputのコマンドで指定されたファイルの中から探します。別の方法でファイルを読み込むプロジェクトでは、ルートファイルに次のような行でファイルを列挙してください。 
% !TEX projectfile = chapter2.tex
% !TEX projectfile = /Users/me/Book/chapter3.tex
名前は、完全なパスか、ルートファイルからの相対パスで書きます。これらの行はルートファイルのどこにあってもかまいません。

ConTeXt

ConTeXtでは、書類の設定に\setupsynctex[state=start,method=min]を加え、ルートファイルの先頭に% !TEX useConTeXtSyncParserの行を書きます。するとTeXShopはConTeXt独自の同期のコードを使います。ConTeXtとMetaPostを参照してください。

ほかのエディタで開いているソースと同期するには、外部エディタを使うを参照してください。
