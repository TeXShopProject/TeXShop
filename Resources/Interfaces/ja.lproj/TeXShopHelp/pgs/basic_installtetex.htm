TeX Liveのインストール

TeXShopを使うにはTeXディストリビューションが必要です。標準はTeX Liveで、TeXのユーザ会が毎年、macOS、Windows、Linuxなどのために作っています。Macでは、TeXユーザ会（TUG）が作るインストーラパッケージ、MacTeXでインストールします。

https://tug.org/mactex/

このページには2つのパッケージがあります。ダウンロードしたパッケージをダブルクリックしてインストーラの指示に従えば、終わったときにはTeXが使えるようになっています。

MacTeX
TeX Liveの全体（約7GB）で、Ghostscriptと、/Applications/TeXに入るTeXShopなどのアプリケーションが含まれます。TeXやLaTeXの本に載っている例は、ほとんど何も足さずに使えます。実際の仕事にはこちらを選んでください。
BasicTeX
TeX Liveの一部（約140MB）で、TeXを試したり、多くのLaTeX文書をタイプセットしたりするには十分です。TeXShopはインストールされません。「TeXShopのインストール」を参照してください。

TeX Liveのインストール先

MacTeXはTeX Liveを/usr/local/texlive/2026に、BasicTeXは/usr/local/texlive/2026basicにインストールします。両方を並べてインストールすることもできます。TeX Liveは毎年4月ごろに新しい版が出て、その年の名前のフォルダに入ります。インストールしたものを削除するには、そのフォルダをゴミ箱に入れます。

インストーラは/Library/TeX/texbinも作ります。ここから、使用中のTeX Liveのプログラムを呼び出せ、新しいTeX Liveをインストールするとそちらに切り替わります。TeXShopはTeXをここから実行するので（「設定」→「タイプセット」→「パス」→「TeXエンジン」）、年が変わっても設定を変える必要はありません。同じグループの「パスの自動検出…」は、MacにあるTeXとGhostscriptを探して、使うものを選ばせてくれます。

年に一度のリリースの間にも、TeX Liveのパッケージは更新されます。更新をインストールするには、MacTeXが/Applications/TeXに入れるTeX Live Utilityを使います。

ほかのTeXディストリビューション

TeXShopは、MacPortsやHomebrewでインストールしたTeXや、MiKTeXでも使えます。これらのプログラムは別のフォルダにあるので、「パスの自動検出…」を使うか、「設定」→「タイプセット」→「パス」→「TeXエンジン」にそのフォルダを入力してください。「他のTeXディストリビューションとの共存」を参照してください。
