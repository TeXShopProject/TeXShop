タイプセットエンジンを追加する

TeXShopは、plain TeXとLaTeXのほかに、エンジンでもタイプセットします。エンジンは、~/Library/TeXShop/Enginesフォルダにある拡張子.engineの小さなシェルスクリプトです。1つのプログラムだけを実行するものも、LuaLaTeX、Biber、LuaLaTeXをさらに2回、のように一連のプログラムを実行するものも作れます。TeXShopにはLuaLaTeX、XeLaTeX、pdflatexmkなどのエンジンが付属し、Inactiveサブフォルダにはさらに多くのエンジンがあります。

エンジンを選ぶ

ソースのウインドウのツールバーで、「タイプセット」ボタンの横のポップアップメニューにエンジンが並んでいます。1つ選んで「タイプセット」を押すか、⌘Tを押します。この選択はその書類だけに働きます。

新しい書類をエンジンでタイプセットするには、「設定」→「タイプセット」→「エンジン」の「新しい書類のタイプセット」で「エンジンファイル」を選び、その下の「エンジンファイル」メニューでエンジンを選びます。「エンジン一覧を編集…」を押すと、FinderでEnginesフォルダが開きます。「エンジンファイル」メニューは、このフォルダでファイルを追加・削除・名称変更すると、それに合わせて変わります。選んでいたエンジンファイルがフォルダからなくなると、メニューには「（見つかりません）」と表示され、書類はLaTeXでタイプセットされます。

書類を特定のエンジンと結び付けるには、最初の20行のどこかに次のような行を書きます。

% !TEX program = XeLaTeX

名前は、エンジンファイルの名前から.engineを除いたものです。texとlatexはplain TeXとLaTeXをDVI経由で、pdftexとpdflatexはPDF直接生成でタイプセットします。この行は、ツールバー、設定、「代替エンジンでタイプセット」のいずれよりも優先されます。% !TEX TS-program =という形も同じように読み取られます。行は書いてあるとおりに、等号の両側に空白を1つずつ入れて書いてください。「マクロ」メニューの「Set Typesetting Program…」マクロでエンジンの一覧から選べば、この行を入力してくれます。ルートファイルのあるプロジェクトでは、この行はルートファイルにだけ書けば十分です。

「タイプセット」→「代替エンジンでタイプセット」（⌃⌥⌘T）は、ツールバーの選択を変えずに、「設定」→「タイプセット」→「エンジン」の「代替エンジン」で指定したエンジン（初期値はpdflatexmk）で1回だけタイプセットします。「タイプセット」メニューでは、ControlキーとOptionキーを押している間、「タイプセット」の代わりにこの項目が現れます。ふだんは手早く1回だけタイプセットし、ときどきlatexmkで完全にタイプセットする書類に向いています。

エンジンを書く

エンジンを作るいちばん簡単な方法は、FinderでEnginesフォルダにあるエンジンを複製し、名前を変え、TeXShopで開いて編集することです。エンジンファイルには拡張子.engineと実行権限が必要ですが、複製すれば実行権限は引き継がれます。新しいエンジンは、そのあとに開いた書類のツールバーに表示されます。XeLaTeX.engineの内容は次のとおりです。

#!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
xelatex  -file-line-error -synctex=1 "$1"

1行目には、スクリプトのシェルまたは言語を書きます。スクリプトがその言語で書かれていれば、zsh、bash、tcsh、Perlなど何でも使えます。TeXShopはエンジンをソースファイルのフォルダで実行し、次の3つの値を渡します。

$1
ソースファイルの名前。拡張子は付き、フォルダは付きません（main.texなど）。ほかのフォルダに移動するスクリプトでは、先に完全なパスを"$PWD/$1"のように控えておく必要があります。プロジェクトでは、ルートファイルの名前です。
$2
ソース（ルートファイル）の先頭近くにある% !TEX parameter = …の行の残りの部分です。% !TEX parameter = -shell-escapeのように書き、複数のフラグは空白で区切ります。この行がなければ空白1つです。
$3
「設定」→「タイプセット」→「パス」の「TeXエンジン」欄のフォルダです。書類に% !TEX useAlternatePathの行があるときは、「第二のTeXエンジン」欄のフォルダです。

エンジンが終わると、TeXShopはソースと同じ名前で拡張子が.pdfのPDFファイルをプレビューのウインドウに開き（ファイルがあれば）、タイプセット前に表示していた位置までスクロールします。ほかの出力を作るスクリプトでは、次の行で何を表示するかを指定できます。エンジンのどこに書いてもかまいませんが、その言語のコメントの中に書きます。

行働き
!TEX-noPreviewプレビューのウインドウを表示しません。以下のほかの行があっても同じです
!TEX-pdfPreviewPDFファイルを表示します
!TEX-htmlPreview同じ名前のHTMLファイルをHTMLウインドウに表示します
!TEX-bothPreviewPDFファイルとHTMLファイルの両方を表示します
!TEX-noConsoleコンソールを表示しません

たとえば、LuaLaTeX、Biber、LuaLaTeXをさらに2回実行するエンジンは、zshでは次のように書けます。${1:r}は拡張子を除いた名前です。

#!/bin/zsh
export PATH="/Library/TeX/texbin:$PATH"
lualatex -file-line-error -synctex=1 "$1"
biber "${1:r}"
lualatex -file-line-error -synctex=1 "$1"
lualatex -file-line-error -synctex=1 "$1"

Inactiveフォルダ

Engines/Inactiveサブフォルダには、特別な作業のためのエンジンが、多くはドキュメントやサンプルとともに入っています。latexmk、ConTeXt、Sage、PreTeXt、Typstなどのためのものです。使うときは、そのフォルダからEnginesフォルダの直下に移動します。TeXShopをアップデートするとInactiveフォルダは最新の版に置き換わりますが、Enginesフォルダの直下にあるファイルには手を付けないので、編集したエンジンは残ります。

エンジンについて詳しくは、「ヘルプ」→「TeXShopマニュアル（英語）」の「Engines and latexmk」の章を参照してください。
