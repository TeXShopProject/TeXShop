TeXShopには文書をタイプセットする方式がいくつか組み込まれていますが、タイプセットの方式を追加することもできます。追加した方式を「エンジン」と呼びます。

エンジンは、TeXのソースファイルから始まってPDFファイルで終わる一連の処理の中で、どのようなプログラムでも呼び出せます。厳密には最後のPDFファイルさえ必須ではありません。TeXShopに付属するエンジンの1つは、TeX Liveのプログラムtex4htを使ってLaTeXのソースをHTMLファイルに変換し、TeXShopはそのHTMLファイルを自分のHTMLウインドウに、PDFと並べて表示します。エンジンが呼び出すプログラムの手順はシェルスクリプトに書きます。

~/Library/TeXShopにはEnginesというフォルダがあり、その中のファイルはタイプセットプログラムを呼び出すシェルスクリプトです。TeXShopは起動時にこのフォルダを調べ、中にあるスクリプトの名前をタイプセット方式のポップアップメニューに加えます。その項目を選んで「タイプセット」ボタンを押すと、スクリプトが呼び出されます。自分で書いたスクリプトをEnginesフォルダに加えることもできます。スクリプトの名前には空白を含めず、拡張子を「.engine」にし、実行権限を付けておく必要があります。

~/Library/TeXShop/Enginesにある項目は、TeXShopの設定でデフォルトのタイプセット方式として選ぶこともできます。設定に表示される方式の名前には拡張子が付きません。

ソースの最初の20行のどこかに次のような行を書くと、その文書で使うプログラムを指定できます。

% !TEX TS-program = xelatex

等号の前後には空白を1つずつ入れます。TeXShopに付属するマクロを使うと、この行を簡単に追加できます。このマクロは有効なエンジンをすべて一覧にするので、ダイアログのリストから目的のエンジンを選べます。

この書式はのちにTeXworksなどのフロントエンドでも採用されました。共同作業をしやすくするため、TeXShopはTeXworks形式の次の行も受け付けます。

% !TEX program = xelatex

「% !TEX TS-program = ...」の行は、ツールバーで選んだタイプセット方式より優先されます。たとえば上のようにxelatexを指定する行がソースにあれば、ツールバーのポップアップメニューでpdflatexを選んでいても、「タイプセット」ボタンを押したとき、「タイプセット」メニューの「タイプセット」を選んだとき、そのキーボードショートカットを使ったときのいずれもxelatexでタイプセットされます。ルートファイルと複数の章ファイルからなるプロジェクトでは、ルートファイルにだけ「% !TEX TS-program」の行を書けば十分です。

新しいエンジンファイルを書くときは、~/Library/TeXShop/Enginesにある既存のエンジンを複製して始めると便利です。複製したファイルには実行権限が自動的に付いています。そのファイルをTeXShopで編集して新しいエンジンを作ります。

~/Library/TeXShop/EnginesフォルダにはInactiveというサブフォルダがあり、追加のエンジンスクリプトが多数入っています。これらを見ると、エンジンファイルの書き方が実例でわかります。エンジンが呼び出されると、変数「$1」には、そのとき作業中だったソースファイルの名前（フォルダを含まないファイル名）が入り、エンジンはそのファイルがあるフォルダを作業ディレクトリとして起動します。たとえば/Users/me/paper/main.texなら、「$1」はmain.texで、エンジンは/Users/me/paperで実行されます。そのため、スクリプトで別のフォルダに移動する場合は、先に「$PWD/$1」などとしてフルパスを控えておく必要があります。このファイルの拡張子は「.tex」とは限りません。エンジンスクリプトでは、いくつもの中間段階を経て各種の補助ファイルを作り、それを別のコマンドラインプログラムで処理してもかまいません。TeXShopは、最終的にソースファイルと同じ名前で拡張子が「.pdf」のPDFファイルができることを想定しています。その場合、TeXShopはエンジンの実行が終わると自動的にPDFファイルを開き、タイプセット前のPDFと同じ位置までスクロールします。PDFファイルができなかった場合、TeXShopはこの手順を省きます。そのときは、必要に応じて結果を適切なプログラムで開く処理をエンジンスクリプトに書いてください。

エンジンスクリプトはどのような言語で書いてもかまいません。ほとんどのエンジンはtcshかzshを使っていますが、perlなどの言語で書いたスクリプトも動作します。

エンジンでは次のような方法がよく使われます。入力ファイルをタイプセットして、同じ名前で拡張子の違う補助ファイルを作り、その補助ファイルを別のプログラムで処理するという方法です。Inactiveフォルダにあるsageエンジンがその例で、補助ファイルの拡張子は「.sage」で、数式処理システムSageで処理する必要があります。このような場合には、sageエンジンにある次のコードが役立ちます。

sagename=${filename/%tex/sagetex.sage}

ここで${filename/%tex/sagetex.sage}は、ファイル名の末尾の「tex」を、sagetexが書き出すファイルの名前の「sagetex.sage」に置き換えます。
