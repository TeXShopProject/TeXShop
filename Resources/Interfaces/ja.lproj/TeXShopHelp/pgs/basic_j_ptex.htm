pTeXとTeXShopで日本語環境を構築する

TeXShopにTeXは含まれていないので、TeXShopとは別にTeXをインストールしておく必要があります。pLaTeXやupLaTeXで日本語の文書を作成するにはpTeXやupTeXを含むTeXが必要ですが、TeX Live（MacTeX）にはpTeXもupTeXも含まれています。pTeX（Publishing TeX）は、横組みだけでなく縦組みの日本語組版にも対応した日本語TeXで、アスキーにより作成されました。upTeXはpTeXをUnicodeに対応させたものです。TeX Live（MacTeX）の入手については「TeX Liveの入手とインストール」を参照してください。

日本語の文書をタイプセットするには、「設定」の「タイプセット」にある「エンジンのプロファイル」で日本語用のプロファイルを選びます。日本語用のプロファイルは次の3つです。upLaTeXとpLaTeXのプロファイルでは、ソースをいったんdviファイルにしてから、dvipdfmxでPDFファイルに変換します。

プロファイルタイプセットの流れ
upLaTeX + dvipdfmxuplatex → dvipdfmx
pLaTeX + dvipdfmxplatex → dvipdfmx
LuaLaTeX（日本語）lualatex
※プロファイルを選ぶと、設定される値が一覧になります。

画像の扱いについてはヘルプ項目「画像を入れる」を、TeXShop自体のインストールについては「TeXShopの入手とインストール」を参照してください。TeXShopとTeXのインストールは、どちらが先でもかまいません。日本語TeXについての情報は、TeX Wiki（https://texwiki.texjp.org/）にまとめられています。
