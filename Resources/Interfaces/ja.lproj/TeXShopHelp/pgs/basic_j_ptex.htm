日本語の文書をタイプセットする

TeX Live（MacTeX）には、日本語のTeXエンジンpTeXとupTeX、それを使うpLaTeXとupLaTeXが含まれています。pTeXは横組みだけでなく縦組みにも対応した日本語のTeXで、upTeXはpTeXをUnicodeに対応させたものです。LuaTeX-jaパッケージを使えば、LuaLaTeXでも日本語の文書をタイプセットできます。TeX Liveの入手については「TeX Liveのインストール」を参照してください。日本語のTeXについての情報は、TeX Wiki（https://texwiki.texjp.org/）にまとめられています。

日本語用のエンジンのプロファイル

日本語の書類のための設定は、エンジンのプロファイルを使うのがいちばん手早い方法です。「設定」→「タイプセット」→「エンジンのプロファイル」で、日本語用の3つのプロファイルのどれかを選びます。

プロファイルタイプセットBibTeX、索引作成、MetaPost
upLaTeX + dvipdfmxuplatexのあとdvipdfmxupbibtex、upmendex、upmpost
pLaTeX + dvipdfmxplatexのあとdvipdfmxpbibtex、mendex、pmpost
LuaLaTeX（日本語）lualatexupbibtex、upmendex、mpost

日本語のプロファイルは、新しい書類のエンコーディングをUTF-8にし、スペルチェックの辞書を「言語を自動判別」にし、「UTF-8-MACをUTF-8に自動変換」をオンにします。「pLaTeX + dvipdfmx」は「otfパッケージの \UTF / \CIDに自動変換」もオンにし、ほかのプロファイルはこれをオフにします。設定される値は、確定する前にシートに一覧で表示されます。

画像の扱いについては「画像を入れる」を、エンコーディングと¥・\については「日本語のエンコーディングと¥・\」を参照してください。

pLaTeXでJIS X 0208にない文字を使う

pTeXはUTF-8のソースを読めますが、内部ではJIS X 0208の文字しか扱えないので、「森鷗外」の「鷗」のようなそれ以外の文字は失われます。otfパッケージを使うと、こうした文字を\UTF{9DD7}のようなコマンドで出力できます。「設定」→「タイプセット」の「日本語pLaTeX用」グループにある「otfパッケージの \UTF / \CIDに自動変換」をオンにすると、こうした文字をそのまま入力できます。

  • 書類を保存するとき、JIS X 0208にない文字はすべて\UTF{XXXX}として書き出され、エディタで選んだ異体字は\CID{番号}として書き出されます。番号は、ヒラギノで描いたときのAdobe-Japan1のCIDです。こうしたコマンドが行末に来たときは、出力に余分な空白が入らないよう直後に%を付けます。U+2015（HORIZONTAL BAR）は、pTeXが読めるU+2014（EM DASH）にします。
  • 書類を開くときは、この設定のオンとオフにかかわらず、これらのコマンドを元の文字に戻します。そのため、ソースウインドウにはいつも文字そのものが表示されます。

書類には\usepackage{otf}が必要です。たとえば、ソースウインドウには

\documentclass{jsarticle}
\usepackage{otf}
\begin{document}
森鷗外は日本の文豪です。
\end{document}

と表示されますが、ファイルには森\UTF{9DD7}外と書かれています。upLaTeXとLuaLaTeXはUnicodeを直接扱うので、変換は必要ありません。

テキストの一部を手作業で変換するには、そこを選択して「編集」→「文字種一括変換」→「Unicode文字 → \UTF / \CID」か「\UTF / \CID → Unicode文字」を使います。同じサブメニューでは、ひらがなとカタカナ、全角と半角の数字や英字、丸数字などの文字とajmacrosパッケージのコマンドの間の変換や、全角引用符からTeXの引用符への変換もできます。何も選択していないときは、書類全体を変換するかどうかを尋ねられます。どの変換も取り消せます。

日本語のためのほかの設定

  • 「設定」→「エディタ」→「不可視文字」→「全角スペース」をオンにすると、不可視文字を表示するときに全角スペースも表示されます。
  • 「設定」→「エディタ」→「シンタックスハイライト」→「全角英数記号を強調」をオンにすると、ASCIIの文字と見間違えやすい全角の英字、数字、記号に、テーマの「全角英数記号」の色が付きます。
  • 「設定」→「プレビュー」→「ページの方向」で、縦組みに必要な右から左へのページの並びにできます。書類ごとには、% !TEX PageDirectionR2Lと% !TEX PageDirectionL2Rの行で向きを指定します。

\UTF / \CIDへの変換とUnicodeの正規化については、TUG 2013での寺田侑祐のスライド（https://tug.org/tug2013/slides/Terada-TeXShop.pdf）で詳しく説明しています。
