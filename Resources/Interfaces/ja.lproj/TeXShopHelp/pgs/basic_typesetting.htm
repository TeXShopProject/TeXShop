書類をタイプセットする

最初の書類

「ファイル」→「新規」を選びます。新しいウインドウのツールバーで、「テンプレート」メニューから「LatexTemplate」を選ぶと、どのLaTeX文書にも必要な行がウインドウに入ります。本文は\begin{document}と\end{document}の間に書きます。空行を入れると新しい段落になります。

ツールバーの「タイプセット」をクリックするか、⌘Tを押します（「タイプセット」→「タイプセット」）。最初は、書類を保存する場所を尋ねられます。TeXはソースの隣にいくつものファイルを書き出すので、書類ごとにフォルダを分けてください。続いてTeXShopがTeXを実行し、タイプセットした書類をプレビューウインドウに表示します。

あとは、書いてはタイプセットし、結果を確かめることを繰り返します。TeXShopはタイプセットのたびにソースを保存し、プレビューは読んでいたページのまま表示されます。⌘Tはソース、プレビュー、コンソールのどこでも使えます。⌘1（「ウインドウ」→「ソース／プレビューを切換」）でソースとそのプレビューを行き来できます。TeXが終わったときにどのウインドウを手前にするかは、「設定」→「タイプセット」→「タイプセット後の動作」で選びます。

.texファイルを開くと、同じ名前のPDFファイルがあればそれも開きます。プレビューウインドウを閉じてもソースは開いたままで、次にタイプセットするとプレビューがまた現れます。ソースウインドウを閉じると、書類が閉じます。

コンソール

TeXの実行中は、そのメッセージがコンソールに表示されます。「設定」→「コンソール」→「コンソールを表示する」で、タイプセットのたびにコンソールを手前に出すか（「常に表示」）、TeXがエラーを報告したときだけ出すか（「エラーがあったとき表示」）を選びます。「ファイル」→「コンソールを表示」（⌘0）で、作業中の書類のコンソールが手前に出ます。コンソールで⌘0を押すと、元のウインドウに戻ります。コンソールのテキストは、いつでも選択してコピーできます。

TeXはエラーを見つけると、コンソールの末尾にメッセージを出して返事を待ちます。コンソールの下の欄に返事を入力してReturnキーを押してください。Returnキーだけを押すと次のエラーに進みます。TeXが受け付けるほかの返事は、この欄に表示されます。TeXを止めるには、コンソールの「強制終了」をクリックするか、「ファイル」→「タイプセットを中断」（⌃⌥⌘A）を選びます。

エラーを探す

コンソールの「エラー箇所」ボタンか、「編集」→「エラー箇所へ移動」（⌃⌘E）を使うと、最初のエラーの行までソースがスクロールし、その行が強調されます。もう一度選ぶと次のエラーに進みます。エラーがプロジェクトのほかのファイルにあれば、そのファイルが開きます。ひとつのエラーがほかのエラーを引き起こすこともあるので、いくつか直したらもう一度タイプセットするのが早道です。「エラー箇所へ移動」は、TeXが-file-line-errorで書き出すファイル名と行番号を使います。TeXShopのコマンドとエンジンファイルは、このオプションを付けています。

LaTeXは、目次や相互参照など次の実行で使う情報を.auxファイルなどの作業ファイルに書き出します。そのため、すべての参照が正しくなるまでに2、3回の実行が必要なことがあります。エラーが起きると作業ファイルが壊れ、エラーを直してもタイプセットできないことがあります。そのときは「タイプセット」→「作業ファイルを削除 & タイプセット」（⌥⌘T）で作業ファイルをゴミ箱に入れてタイプセットし直すか、「ファイル」→「作業ファイルを削除」（⌃⌘A）を選びます。後者はコンソールのボタンにもあります。「作業ファイルを削除する」を参照してください。

エンジンを選ぶ

「設定」→「タイプセット」→「エンジンのプロファイル」で、エンジンに合わせたタイプセットの設定をまとめて行えます。使うエンジンのプロファイルを選ぶと、設定される値がシートに一覧になり、「OK」でそれらが設定されます。シートの「LaTeXの実行：」で「latexmkを使う」を選ぶと、latexmkが必要に応じてBibTeX、索引作成、追加の実行を行います。設定された値のどれかを変えると、メニューの表示は「カスタム」になります。各プロファイルが設定する値は、TeXShopマニュアル（英語）に一覧があります。

ひとつの書類だけエンジンを変えるには、ツールバーの「タイプセット」の横にある「プログラム」ポップアップメニューで選びます。このメニューには、plain TeX、LaTeX、BibTeX、MakeIndex、MetaPostと、それに続いて~/Library/TeXShop/EnginesにあるLuaLaTeXやXeLaTeXなどのエンジンファイルが並び、選んだものはそのウインドウで有効です。これを書類の一部にするには、ソースの最初の20行のうちに次のような行を入れます。

% !TEX program = LuaLaTeX

こうすると、⌘Tでいつもそのエンジンでタイプセットされます。名前にはエンジンファイルの名前か、内蔵のLaTeXとplain TeXを表すpdflatex、latex、pdftex、texのどれかを書きます（「もうひとつのタイプセット方式」を参照）。「マクロ」→「Program」を使うと、一覧から選んだエンジンでこのような行を入れられます。このマクロが書くのは% !TEX TS-program =の行ですが、意味は同じです。このような行のない書類のエンジンは、「設定」→「タイプセット」→「新しい書類のタイプセット」で決まります。エンジンファイルについては「タイプセットエンジンを追加する」を参照してください。

「タイプセット」メニューからは、BibTeX、MakeIndex、MetaPostも書類に対して実行できます。「BibTeX」と「MakeIndex」を参照してください。

複数のファイルからなる書類

本などは、プリアンブルのあるルートファイルと、そこから\includeや\inputで読み込む章のファイルに分けることがよくあります。それぞれの章のファイルの先頭に% !TEX root = ../Book.texのような行を入れ、章のファイルから見たパスでルートファイルを指定します。こうすると、章のファイルで⌘Tを押せばルートファイルがタイプセットされ、「エラー箇所へ移動」やSyncTeXも正しい章のファイルを見つけます。「プロジェクトのルートファイルを設定する」を参照してください。

ソースとプレビューを行き来する

ソースの語をCommandキーを押しながらクリックすると、プレビューがタイプセットされたその文字までスクロールして印を付けます。プレビューでCommandキーを押しながらクリックすると、ソースが手前に出て、対応する文字に印が付きます。章のファイルに分かれた書類では、必要なら章のファイルが開きます。対応は必ずしも正確ではないので、印の付いた場所の周りも見てください。印の色は「設定」→「テーマ」→「SyncTeX」で設定します。

これにはSyncTeXを使います。エンジンを-synctex=1付きで実行するとSyncTeXが使え、TeXShopのコマンドとエンジンファイルはそうしています。「設定」→「タイプセット」→「Sync方式」は「SyncTeX（推奨）」にしておいてください。SyncTeXのファイルには書類のファイルの場所が記録されているので、プロジェクトのフォルダを動かしたあとは、もう一度タイプセットしてから使ってください。

ウインドウの配置

「ウインドウ」→「ソースとプレビューを統合」で、ソースとそのプレビューがひとつのウインドウに左右に並び、「ウインドウ」→「ソースとプレビューを分離」で別々に戻ります。どの書類もこの形で開くには、「設定」→「一般」→「ウインドウ」→「ソースとプレビュー」を「1つのウインドウに統合」にします。「統合したウインドウでのソースの位置」で、ソースを左右どちらに置くかを選びます。境界線をドラッグするとソースの幅を変えられ、統合したウインドウはどれも同じ割合で開きます。% !TEX rootの行がある章のファイルは、別々のウインドウのままになります。ルートファイル自体はひとつのウインドウで使えます。「ファイル」→「新規」ではソースウインドウだけが開くので、新しい書類はまずタイプセットしてから「ソースとプレビューを統合」を選びます。

別々のウインドウで使うときは、ソースウインドウとプレビューウインドウを好きな位置と大きさにしてから、「ソース」→「ソースウインドウの位置を保存」と「プレビュー」→「プレビューウインドウの位置を保存」を選ぶと、新しいウインドウがそこに開きます。
