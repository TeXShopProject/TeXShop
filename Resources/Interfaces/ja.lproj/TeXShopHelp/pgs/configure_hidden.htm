隠し設定

設定ウインドウには、たいていの人が必要とする設定が並んでいます。あまり使われない設定は隠し設定になっていて、設定ウインドウに項目がなく、ターミナルでコマンドを使って変更します。資料「マジックコメントと隠し設定」には、すべての隠し設定がそのコマンドとともに話題ごとにまとめられています。「ヘルプ」→「マジックコメントと隠し設定（英語）」、または「設定」→「一般」→「詳細」の「マジックコメントと隠し設定のマニュアルを開く…」で開きます。

隠し設定を変更する

  1. TeXShopを終了します。
  2. ターミナル（「アプリケーション」フォルダの「ユーティリティ」フォルダにあります）を開き、コマンドを入力してReturnキーを押します。
  3. TeXShopをもう一度起動します。

コマンドはdefaults write TeXShop 名前 値の形です。デフォルトの値に戻すには、defaults delete TeXShop 名前を使います。

例

defaults write TeXShop OtherTrashExtensions -array 'nav' 'snm'
「ファイル」→「作業ファイルを削除」で、これらの拡張子のファイルも削除します。拡張子はドットを付けずに指定します。「作業ファイルを削除する」を参照してください。
defaults write TeXShop ConTeXtTags YES
「タグ」メニューに、LaTeXの見出しコマンドではなく、\titleや\subjectなどのConTeXtの見出しコマンドを表示します。
defaults write TeXShop RedConsoleAfterError YES
TeXのエラーに答えてコンソールに入力した文字と、そのタイプセットのそれ以降の出力を、すべて赤で表示します。
defaults write TeXShop RefreshTime 2
「設定」→「プレビュー」の「ほかのアプリによるPDFの変更を常に監視」がオンのとき、TeXShopはPDFが変わったかどうかを2秒ごとに確かめます。デフォルトは1秒で、最小は0.5秒です。

設定ウインドウにある設定は、隠し設定には重ねて載せていません。たとえば、Optionキー・Controlキーと補完の呼び出しキーで「編集」→「マーク」の次・前のマークへ移動する機能は、「設定」→「キーボード」の「Option・Controlと呼び出すキーで、次・前のマークへ移動」でオン・オフします。こうした設定は「設定を検索」で探せます（「設定を検索」を参照）。
