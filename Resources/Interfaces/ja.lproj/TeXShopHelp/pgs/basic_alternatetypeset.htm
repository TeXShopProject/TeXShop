もうひとつのタイプセット方式

TeXShopは、ふつうは「PDF直接生成」の方式でタイプセットします。pdfLaTeXやpdfTeXがPDFファイルを直接書き出す方式です。もうひとつの「DVI経由」では、LaTeXかTeXでDVIファイルを作り、dvipsでそれをPostScriptに変換し、GhostscriptでPostScriptをPDFに変換します。この手順はTeX Liveのスクリプトsimpdftexが行います。

「DVI経由」が必要なのは、pstricksパッケージを使う場合など、出力にPostScriptのコードを入れる書類です。EPSの画像には必要ありません。「PDF直接生成」でタイプセットするとき、TeX LiveがEPSをPDFに変換します。

方式を選ぶ

「タイプセット」→「DVI経由」と「タイプセット」→「PDF直接生成」は、作業中の書類の方式を切り替えます。ほかの開いている書類の方式は変わりません。書類を開いたときの方式は「設定」→「タイプセット」→「コンパイル法」で設定します。3つめの選択肢「パーソナルスクリプト」を選ぶと、代わりに「パーソナルスクリプト」グループのコマンドを実行します。「DVI経由」のコマンドは、plain TeX用とLaTeX用のひとつずつが「設定」→「タイプセット」の「DVI経由」グループにあります。「エンジンのプロファイル」メニューの「その他」にあるプロファイル「LaTeX + dvips + Ghostscript」を選ぶと、「DVI経由」でタイプセットするよう設定されます。

書類の中で方式を選ぶ

ソースの最初の20行のうちに次のような行を入れると、設定にかかわらず、その書類のプログラムと方式が決まります。

行タイプセットの方法
% !TEX program = pdflatexLaTeX、PDF直接生成
% !TEX program = latexLaTeX、DVI経由
% !TEX program = pdftexplain TeX、PDF直接生成
% !TEX program = texplain TeX、DVI経由
% !TEX program = personallatexLaTeX、パーソナルスクリプト
% !TEX program = personaltexplain TeX、パーソナルスクリプト

「DVI経由」のオプション

Ghostscriptは、初期状態ではPostScriptの透明効果を無視します。透明効果を残すには、「DVI経由」グループのコマンドの末尾に--distilleropts "-dALLOWPSTRANSPARENCY"を加えます。途中で作るPostScriptファイルを残すには--keep-psfileを加えます。Ghostscriptは、「設定」→「タイプセット」→「パス」→「Ghostscript」のフォルダから実行されます。
