新しいマクロを定義する

新規の項目（新規マクロ）は一覧の下の ＋ ボタンで、新規のサブメニュー（サブメニュー）と新規の区切り線（区切り）は一覧の下の右端のメニュー（⊙）で作成できます。このメニューでは選んだ項目の複製もでき、－ ボタンは選んだ項目を削除します。新規の項目とサブメニューは、作るとすぐ名前を入れられる状態になります。名前を入れて return キーを押します。少しいじってみれば、エディタの基本的な動作は明らかになるでしょう。サブメニューはどの階層にも作成できます。

いずれの項目にも、ショートカットを個別に割り当てることができます。項目を選んで一覧のショートカットをクリックし（ショートカットのダブルクリックでもかまいません）、割り当てるキーを押します。使えるのは、command か control を含む組み合わせと、F1～F20 です（shift と option は必要に応じて加えます）。メニューコマンドやほかのマクロがすでに使っているショートカットは、そのことを内容の欄の下に知らせて変更しません。別のショートカットを押してください。ショートカットを外すには、欄の中の「解除」（⊖）をクリックするか、delete キーを押します。esc キーを押すと、元のショートカットのままになります。メニューコマンドや先に並ぶマクロが使っているために無効なショートカットには、一覧で黄色の三角の印が付きます。その項目を選ぶと、理由が内容の欄の下に出ます。

内容の欄では、マクロが置き換えるプレースホルダ（#SEL#・#INS#・#PASTE#、マーク•、AppleScript のマクロの #FILEPATH# などのパス）を、「選択中の文字列」のように何を表すかを書いた角丸の札で表示します。マクロには書いたとおりの文字のまま保存されます。プレースホルダは、そのまま打つか、内容の欄の下の「挿入」メニューから入れます。右の「?」ボタンで一覧を表示します。札の隣で削除すると、札ごと消えます。
