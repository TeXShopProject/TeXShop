その他のファイルをTeXShopで開く

TeXShopはどんなテキストファイルでも開けるので、書類の隣にあるログファイル、auxファイルなどのTeXのファイルを読めます。PDFファイルや画像も開けます。

TeXのソースとして扱うファイル

次の拡張子を持つファイルと、拡張子のないファイルは、TeXShopではTeXのソースとして扱われます。シンタックスハイライト付きで表示され、タイプセットできます。

asy  bbx  bib  cbx  clo  cls  ctx  def  dtx  fd  fdd  gabc  gtex
htx  html  ins  lbx  lhs  ltx  lua  lytex  ly  md  mf  mp  ptx
Rnw  sk  skt  Stex  sty  tex  typ  xml

.log、.aux、.bst、.engine、.txtなどのその他のテキストファイルは、シンタックスハイライトなしのプレーンテキストとして開きます。

ほかの拡張子のファイルもTeXのソースとして扱わせるには、ターミナルで隠し設定にその拡張子を加えます。たとえば、拡張子mkivのConTeXtのファイルなら次のようにします。

defaults write TeXShop OtherTeXExtensions -array-add "mkiv"

PDFファイルと画像

PDFファイルと、拡張子.png、.jpg、.jpeg、.tif、.tiff、.epsの画像は、専用のウインドウで開きます。DVIファイルとPostScriptファイル（.dvi、.ps）は、PDFに変換して表示します。

別の拡張子で保存する

TeXShopで保存しても、ファイルの拡張子は変わりません。新しい書類は、保存ダイアログの「ファイルフォーマット」のメニューでsty、bib、mpなどの別の種類を選ばない限り、.texファイルとして保存されます。

TeXShopは、ファイルを開いたときのエンコーディングで保存します。TeXShopはTeXとその関連ファイルのためのものなので、特殊な形式のファイルをTeXShopで編集して保存すると、内容が変わることがあります。エンコーディングを参照してください。
