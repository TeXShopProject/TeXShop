役に立つWebサイト

TeXShop
TeXShopのWebサイトです。
GitHubのTeXShop
TeXShopのソースコードがあり、問題を報告する場所でもあります（「バグレポートを送る」を参照）。
MacTeX
macOS用のTeX Liveのディストリビューションで、TeXShopなどのプログラムも含まれています。
TeX Users Group（TUG）
国際的なTeXのユーザ会で、TeX Liveをはじめ多くのTeXの資料の拠点です。
CTAN
Comprehensive TeX Archive Network。パッケージ、フォントとそのドキュメントがあります。
TeX Stack Exchange
TeX、LaTeXと関連するプログラムについての質問と回答の場です。
learnlatex.org
オンラインで試せる例の付いたLaTeXの短い講座です。
The LaTeX Project
LaTeXを保守しているチームによるニュースとドキュメントです。
MetaPost
図を描く言語MetaPostのページです。
XeTeX
Macにインストールされたフォントを使えるXeTeXとXeLaTeXのページです。
ConTeXt Garden
ConTeXtのドキュメントとコミュニティです。
