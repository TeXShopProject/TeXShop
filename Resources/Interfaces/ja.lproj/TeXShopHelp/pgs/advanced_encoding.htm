エンコーディング

TeXShopはテキストをUnicodeで編集するので、ソースのウインドウにはどの言語のどの文字でも入力できます。このテキストをディスク上のファイルにどう書き込み、どう読み戻すかを決めるのがエンコーディングです。UTF-8はあらゆる文字を保存でき、LaTeX、XeLaTeX、LuaLaTeXは標準でUTF-8を読みます。古いファイルやほかのシステムで作られたファイルは、ISO Latin 9やShift JISなど、別のエンコーディングのことがあります。

新しい書類

新しい書類は、「設定」→「書類と保存」→「エンコーディング」の「新しい書類のエンコーディング」で選んだエンコーディングで保存されます。初期値はUnicode（UTF-8）です。別のエンコーディングが必要な相手とファイルをやり取りするのでなければ、そのままにしてください。

書類は開いたときのエンコーディングで保存されるので、古いファイルのエンコーディングは保たれます。ファイルのエンコーディングで表せない文字は、保存すると失われます。

ファイルを開く

エンコーディングの行（後述）のないファイルを開くと、TeXShopはそのエンコーディングを判別します。バイト順マーク（BOM）があればUTF-8やUTF-16と分かります。ASCII文字だけのファイルは、新しい書類のエンコーディングで読みます。それ以外では、ファイルを保存したプログラムがファイルとともに記録したエンコーディングを（macOSがその情報を残していれば）使い、次にUTF-8を、さらに使用している言語のエンコーディングと新しい書類のエンコーディングを試します。\usepackage[latin9]{inputenc}のようにソースでエンコーディングを宣言していれば、それも手がかりにします。

判別は推測なので、ある程度の量のテキストがあるファイルほどうまくいきます。違うエンコーディングで開いてしまったときは、保存せずにファイルを閉じ、「ファイル」→「開く...」で開き直します。そのとき開くダイアログで「オプション」を押し、「エンコーディング：」メニューでエンコーディングを選びます。ここで選んだエンコーディングはそのとき開くファイルに使われ、書類はそのエンコーディングを保ちます。このメニューには、最初は新しい書類のエンコーディングが表示されています。それを変えずにおくと選んだことにはならず、いつもどおり判別されます。そのあとでファイルにエンコーディングの行を加えておけば、いつも正しく開けます。判別は、次の隠し設定でオフにできます。

defaults write TeXShop EncodingAutoDetection NO

オフにすると、ファイルは新しい書類のエンコーディングで読まれます。

エンコーディングの行

ソースファイルの最初の20行のどこかに次の行を書くと、読み込みと保存のエンコーディングがほかのすべてに優先して決まります。

% !TEX encoding = UTF-8 Unicode

行は上のとおりに、等号の前に空白を1つ入れて書きます。%の後の空白を省いた%!TEX encoding =も読み取られます。名前は下の表のとおりに正確に書きます。「マクロ」メニューの「Encoding」マクロでエンコーディングの一覧から選べば、この行を入力してくれます。TeXworksが使うUTF-8やISO 8859-1などの名前も理解します。

TeXShopが知らないエンコーディングが行に書かれていると、TeXShopはファイルをUTF-8で読み、そのことを知らせます。行にUTF-8と書かれているのにファイルが正しいUTF-8でないときは、そのことを知らせてファイルをISO Latin 9で開きます。ISO Latin 9はどんなファイルでも読めるので、行を変えずに保存すれば同じバイト列が書き戻され、何も失われません。エンコーディングの行を適用せずにファイルを開くには、Optionキーを押しながら開きます。

別のエンコーディングで保存する

保存するときにエンコーディングを選ぶには、「設定」→「書類と保存」→「エンコーディング」の「保存ダイアログにエンコーディングを表示」をオンにします。保存ダイアログにエンコーディングのメニューが加わります。「編集」→「変換」→「エンコーディングを変換」では、開いている書類をそれ以降どのエンコーディングで保存するかを選べます。ファイルにエンコーディングの行があるときは行が優先されるので、行の方を書き換えてください。TeXShopは、UTF-8のファイルのバイト順マークと、UTF-16のファイルのバイト順を保ちます。

ファイルを別のエンコーディングに変換すると、新しいエンコーディングで表せない文字はすべて失われます。また、ファイルを違うエンコーディングで読んで保存すると、文字は元に戻らない形で置き換わります。元のファイルのコピーを残しておいてください。コマンドラインのプログラムiconvを使えば、元のファイルを変えずに変換できます。こうした問題については、「ヘルプ」メニューの「ファイルエンコーディングの解説（英語）」で詳しく説明しています。

日本語のエンコーディングと、円記号¥とバックスラッシュ\の扱いについては、日本語のエンコーディングと¥・\を参照してください。

右から左に書く言語

アラビア語、ヘブライ語、ペルシア語は、ソースのウインドウでも右から左に入力されます。「設定」→「エディタ」→「入力」の「右から左に書く言語（Arabic、Hebrew、Persian）」がオンで、シンタックスハイライトもオンのときは、アラビア文字やヘブライ文字で始まる行が右寄せになり、LaTeXのコマンドで始まる行などそれ以外の行は左寄せになります。次の隠し設定を使うと、そうした文字をどこかに含む行はすべて右寄せになります。

defaults write TeXShop RightJustifyIfAny YES

この寄せ方は編集のためだけのものです。タイプセットした文章のレイアウトは、TeXが独自のコマンドで決めます。これらの言語をタイプセットするには、XeLaTeXかLuaLaTeXを使います。XeLaTeXとLuaLaTeXを参照してください。

ほかの文字体系を入力する

ほかの文字体系で入力するには、「システム設定」→「キーボード」の「テキスト入力」でその入力ソースを追加し、メニューバーの入力メニューで入力ソースを切り替えます。
