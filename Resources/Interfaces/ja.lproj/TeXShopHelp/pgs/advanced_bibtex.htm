BibTeX

BibTeXは、文献のデータベース（拡張子.bibのファイル）からLaTeXの書類の参考文献リストを作ります。書類では項目をキーで引用し、BibTeXは引用された項目だけを並べます。

データベースmybibliography.bibには、次のような項目を書きます。

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

書類では項目を引用し、スタイルとデータベースを指定します。

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

BibTeXを実行する

  1. 書類をタイプセットします。引用は[?]と表示され、参考文献リストはまだありません。
  2. 「タイプセット」→「BibTeX」（⇧⌘B）を選ぶか、「タイプセット」ボタンの横のポップアップメニューで「BibTeX」を選んで「タイプセット」を押します。
  3. さらに2回タイプセットします。1回目で参考文献リストが加わり、2回目で引用の番号が埋まります。

pdflatexmkのエンジンや、「latexmkを使う」に設定したプロファイルなど、latexmkでタイプセットするときは、BibTeXと追加のタイプセットが自動的に実行されます。

TeXShopで新しいデータベースを作るには、保存ダイアログの「ファイルフォーマット」のメニューでbibを選び、ファイルに拡張子.bibが付くようにします。データベースは個人用のTeXツリーに置くこともでき、そうすればどの書類からも見つかります。個人用のファイルをTeX Liveに追加するを参照してください。

プログラムを選ぶ

「タイプセット」→「BibTeX」は、「設定」→「タイプセット」→「周辺ツール」の「BibTeXエンジン」にあるコマンドを実行します。初期値はbibtexです。ここには、必要なオプションを付けて別のプログラムを入力できます。たとえばbiblatexパッケージを使う書類ではbiberにします。エンジンのプロファイルはこの欄を設定します。pLaTeX + dvipdfmxではpbibtex、upLaTeX + dvipdfmxとLuaLaTeX（日本語）ではupbibtex、ほかのプロファイルではbibtexになります。

書類ごとにプログラムを選ぶには、最初の20行のどこかに次のような行を書きます。

% !BIB program = biber

この行は設定よりも優先されます。% !BIB TS-program =という形も同じように読み取られます。
