設定には「一般」「書類と保存」「エディタ」「スペルチェック」「外観」「プレビュー」「タイプセット」「コンソール」「キーボード」「アップデート」の10分類があります。「スペルチェック」では「LaTeXの構造を考慮する（推奨）」と「従来方式を使う」のどちらかを選びます。新方式の下には「LaTeXの除外規則を編集…」、従来方式の下には字下げした3項目があります。方式を変えても子項目の値は保持します。入力中のスペルチェックは独立した設定です。「キーボード」ではキーバインドとコマンド補完を検索欄より上に置き、ショートカット一覧だけを縦にスクロールします。3つの区画は常に開いています。一覧には残りの高さを使い、一覧だけを縦にスクロールします。Tabを補完キーにしてキー検索でTabを押すと、予約の説明と補完キーの設定行を表示します。「一般」からコメント行と隠し設定の説明を開けます。無効な子項目の保存値を保持し、廃止された分類を記憶していた場合は「一般」を開きます。

Cocoa プログラムには Apple の提供するスペルチェック機能が最初から備わっています。Mac OS X 10.4 以上のスペルチェッカーでは、LaTeX のコマンドにもいくらかは対応していますが、Apple のスペルチェッカーは LaTeX のコマンドを理解せず、多くのコマンドにスペルミスの印を付けてしまいます。しかしながら、他のスペルサービスを Apple の技術に付け加えることができます ； そうするとすべての Cocoa プログラムで利用できるようになります。

TeXShop は自動スペルチェックをサポートしています──メニューコマンドで入・切ができます。設定でデフォルトの（入・切）状態を設定することができます。

Aspell は Unix マシン用に Kevin Adkinson さんが作成した「より賢い Ispell」です。それが Anton Leuski さんによって Mac OS X に移植され、スペルサービス化されました。この新しいスペルチェッカーは LaTeX をサポートしています。これを入手するには以下のサイトを訪れます──

http://cocoaspell.leuski.net/

他には、Rick Zaccone さんの Excalibur という LaTeX スペルチェッカーがよく使われています。このスペルチェッカーは TeXShop ファイルを開くことができます。入手するには、以下のサイトを訪れます──

http://www.eg.bucknell.edu/~excalibr/excalibur.html

設定を検索

サイドバー上部の「設定を検索」で、設定項目、選択肢、メニューコマンドを探せます。結果には項目名と所属カテゴリ名を表示します。空白で区切った語は同じ項目に一致する必要があり、カテゴリ名で絞り込むこともできます。大文字・小文字、欧文のアクセント、全角・半角、ひらがな・カタカナの違いを吸収します。語を入力しただけでは表示中のペインは変わりません。結果を選ぶとその行まで移動して強調し、通常の履歴に移動を追加します。設定値や無効な項目の状態は変えません。検索語を消しても表示中のペインに留まります。検索中も戻る・進むは履歴に従って移動し、検索語は消しません。メニューコマンドの結果は「キーボード」の「機能で検索」で絞り込みます。キー記録中は「キーで検索」が優先されます。入力した値、個人のパス、自分で作ったテーマ名は検索しません。
