スペルをチェックする

CocoaプログラムにはAppleの提供するスペルチェック機能が最初から備わっています。TeXShopは入力中のスペルチェックに対応しており、メニューコマンドで入・切を切り替えられます。最初の状態は設定で選べます。

Appleのスペルチェッカーは、そのままではLaTeXのコマンドを理解せず、多くのコマンドにスペルミスの印を付けてしまいます。TeXShopの「設定」の「スペルチェック」で「LaTeXの構文を考慮する（推奨）」を選ぶと、TeXShopはコマンド、数式、コメント、参照の引数などを除いて、本文だけを検査します。

デフォルトの辞書は「設定」の「スペルチェック」にある「辞書」で選びます。ふだん英語で書くなら英語の辞書を、フランス語で書くならフランス語の辞書を選びます。「言語を自動判別」を選ぶと、テキストに応じて適切な辞書が自動的に選ばれます。

設定の「辞書」で選ぶのは、TeXShopで新しくファイルを開いたときに使うデフォルトの辞書です。すでに開いているファイルの辞書は変わりません。

「辞書」のメニューには、各言語がその言語自身の名前（たとえば「Deutsch」や「Français」）で表示されるので、辞書は言語の名前で選びます。スペルチェッカーがその言語に使うコード（「de」や「fr_CA」など）は、メニュー項目のツールチップに表示されます。

辞書を設定したあとでTeXShopで複数のソースファイルを開くと、どのファイルにもデフォルトの辞書が割り当てられます。辞書は「編集」メニューの「スペルと文法」で変更できるので、必要ならファイルごとに別の辞書を使えます。たとえば英語、フランス語、ドイツ語、日本語で顧客への手紙を書いているなら、4つのソースファイルにそれぞれの辞書を割り当てられます。ソースファイルを切り替えると、そのたびに「スペルと文法」パネルが対応する辞書に切り替わります。

ファイルを閉じるとこの対応は失われるので、複数の言語で書く場合は、ファイルを開くたびに適切な辞書を選び直す必要があります。

ただし、次のようなマジックコメントを書いておくと、ファイルを開いたときに使う辞書を固定できます。

% !TEX spellcheck = de-DE

この例では、このファイルを開いたときには必ずドイツ語の辞書を使うことになります。ファイルを開いたあとで「スペルと文法」を使って辞書を変えることもできますが、次にファイルを閉じて開き直すと、またドイツ語の辞書が使われます。

この行は書類を開いたときに読み取られるので、ソースファイルに初めて書き加えたときは、ファイルを保存して開き直すまで有効になりません。ルートファイルのあるプロジェクトでは、取り込まれる各ソースファイルにこの行が必要です。

このコマンドでは、Appleの辞書を、言語についてはISO 639-1またはISO 639-2の規格で、地域についてはISO 3166-1の規格で指定します。地域の指定は、同じ言語でも使われる地域による違いを区別するためのものです。たとえばフランス語はISO 639-1では「fr」、ISO 639-2では「fre」で、フランスのフランス語の地域指定は「FR」、カナダのフランス語の地域指定は「CA」です。したがってカナダでフランス語の辞書を選ぶには「spellcheck = fr」でもかまいませんが、「spellcheck = fr-CA」とするほうがより適切です。これらはISO規格なので、ほかのプラットフォームでも同様のコマンドが使えます（TeXShop自体はMacでしか動きませんが）。言語の規格は次のサイトにあります。

https://www.loc.gov/standards/iso639-2/php/English_list.php

地域の規格は次のサイトにあります。

https://www.iso.org/iso-3166-country-codes.html

以前のTeXShopは辞書について特別な処理をせず、ユーザは「スペルと文法」を使うだけでした。その後、上記の方式が部分的に実装され、TeXShop 3.81で完全に実装されました。TeXShopが「スペルと文法」の標準の動作にそのまま従っていた以前の方式を好む方は、次の隠し設定で元の動作に戻せます。

defaults write TeXShop OriginalSpelling YES
