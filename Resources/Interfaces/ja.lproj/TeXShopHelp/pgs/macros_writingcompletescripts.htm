TeXShopのタイプセットコマンドでスクリプトを書く

参考文献リストのある書類には、一連のタイプセットが必要です。LaTeXが.auxファイルを書き出し、BibTeXがそれを使って.bblファイルと.blgファイルを書き出し、もう一度LaTeXを実行して参考文献リストを書類に加え、さらにもう一度実行してリストへの参照を更新します。自分のプロジェクトでも似たような手順が必要になることがあり、AppleScriptマクロでそれを実行できます。

TeXShopに付属するマクロ「マクロ」→「Applescript」→「Bibliography」がその方法を示しています。内容は次のとおりです。

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

1行目で、このマクロはScriptRunnerが実行するAppleScriptマクロになるので、TeXShopにタイプセットを頼めます（AppleScriptマクロを参照）。続く行では、ソースファイルの完全なパスである#FILEPATH#を調べます。書類をまだ保存していなければ空の文字列なので、その場合スクリプトは保存するよう求めて止まります。

次にスクリプトは、#DOCUMENTNAME#で書類を指定します。TeXShopはタイプセットのコマンドが始まるときに自分で書類を保存するので、スクリプトで保存する必要はありません。

残りのコマンドは、latexinteractive、bibtex、latex、latexを実行します。タイプセットのコマンドは、タイプセットが終わる前にすぐスクリプトに戻るので、各コマンドの後のrepeatループで、taskdoneが作業の完了を知らせるまで待ちます。delay 2の行は、確認の合間にスクリプトを休ませ、絶えず問い合わせてコンピュータを遅くしないようにするためのものです。コマンドの一覧は、AppleScriptマクロを定義するにあります。
