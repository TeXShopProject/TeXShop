シンタックスハイライト

ソースウインドウでシンタックスハイライトが有効になっているときは、コメント、コマンド、「 $ 」 「 { 」 「 } 」といった記号が、それぞれの色で表示されます。これらの色はテーマの一部です。設定ウインドウの「テーマ」の「シンタックスハイライト」で変えられます。色はテーマごとに設定するので、ライトモード時のテーマとダークモード時のテーマで別の色にできます。

以前のTeXShopでは、markerred・markergreen・markerblueなどの隠れた設定でこれらの色を設定していました。これらの設定は今は使われません。
