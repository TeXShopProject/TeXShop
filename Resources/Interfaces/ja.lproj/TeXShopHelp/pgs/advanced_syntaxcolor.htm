シンタックスハイライト

ソースのウインドウでは、TeXが色分けして表示されます。コメント、コマンド、脚注、記号$と&、括弧( )、{ }、[ ]にそれぞれの色があります。「ソース」→「シンタックスハイライト」で、作業中の書類のハイライトをオン・オフできます。書類はハイライトがオンの状態で開きます。オフで開くようにするには、次の隠し設定を使います。

defaults write TeXShop SyntaxColoringEnabled NO

色分けされるもの

  • コマンドは、バックスラッシュに続く英字の並びです。「設定」→「エディタ」→「シンタックスハイライト」の「@ をコマンド名の一部と見なす」をオンにすると、パッケージの内部コマンドのように@も英字として扱います。
  • \footnote、\footcite、\autociteと、\citepや\citeauthorのように\citeか\Citeで始まるコマンドの中の文字列は「脚注」の色で表示されます。隠し設定defaults write TeXShop SyntaxColorFootnote NOを使うと、コマンドだけに色を付けます。
  • 「ソース」→「索引をハイライト」を選ぶと、\indexと\esindexの引数が「索引」の色で表示されます。「設定」→「エディタ」→「シンタックスハイライト」の「索引を既定でハイライト」をオンにすると、書類を開いたときにオンになります。
  • 「ソース」→「expl3コードをハイライト」を選ぶと、LaTeXのプログラミング層であるexpl3のコードの関数、変数などにも色を付けます。パッケージを書く人のための機能です。同じグループの「expl3コードを既定でハイライト」をオンにすると、書類を開いたときにオンになります。
  • 同じグループの「全角英数記号を強調」をオンにすると、日本語の文章でASCII文字と見間違えやすい全角の英字、数字、記号を「全角英数記号」の色で表示します。

「索引をハイライト」と「expl3コードをハイライト」は作業中の書類に働き、ソースのウインドウごとに別々に選べます。ログファイルなど、TeXのソースではないファイルには色を付けません。対象の拡張子と、拡張子を加える方法については、その他のファイルをTeXShopで開くを参照してください。

色を変える

色はテーマに属しています。「設定」→「テーマ」で選びます。

  • 「シンタックスハイライト」グループには、「コメント」「コマンド」「脚注」「記号類」「索引」があります。
  • 「括弧類」グループには、( )、{ }、[ ]の色があります。
  • 「expl3」グループには、function、__function、key、variable、__variable、argument、msgがあります。
  • 「強調表示」グループには、「全角英数記号」の色などがあります。
  • 「XML構文」グループには、HTMLとXMLのファイルの色があります。

テーマごとに色が異なるので、「ライトモード時のテーマ」と「ダークモード時のテーマ」で別の色にできます。
