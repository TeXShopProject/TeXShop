まえがき

TeXShopは、TeXやLaTeXで文書を書くためのmacOSのアプリケーションです。エディタのウインドウでソースを書き、クリックひとつか⌘Tでタイプセットすると、その結果が隣のプレビューウインドウに表示されます。どちらかのウインドウでCommandキーを押しながらクリックすると、もう一方のウインドウの対応する場所が示されます。

TeXShopにTeXは含まれていません。TeXShopはTeXディストリビューションのプログラムを実行します。ふつうはTeX Liveで、MacTeXのインストーラでMacに入れます。「TeX Liveのインストール」を参照してください。TeXShopにはmacOS 14.6以降が必要です。

初めて起動したときに、TeXShopはエンジンのプロファイルを提案します。macOSで優先する言語の先頭が日本語なら「LuaLaTeX（日本語）」、それ以外なら「pdfLaTeX」です。「OK」をクリックすると、表示されたプロファイルか、代わりに選んだプロファイルが適用されます。「キャンセル」をクリックするとpdfLaTeXのままです。pdfLaTeXはPDFファイルを直接書き出し、プレビューウインドウはそのファイルを表示します。これはふつうのPDFファイルなので、ほかの人に送ることも、どのコンピュータで読むこともできます。LuaLaTeXなど別のエンジンでタイプセットするには、設定でエンジンのプロファイルを選ぶか、文書の先頭にエンジンの名前を書きます。「書類をタイプセットする」を参照してください。日本語の文書については「日本語の文書をタイプセットする」を参照してください。

このヘルプの内容

基本的なヘルプ
TeX LiveとTeXShopのインストール、タイプセット、プレビューウインドウ、編集、検索と置換、スペルチェック、キーバインドとコマンド補完、各パネル、マクロ、プリント、設定。
上級向けのヘルプ
タイプセットのエンジン、ルートファイルのあるプロジェクト、BibTeXとMakeIndex、エンコーディング、外部エディタ、シンタックスハイライトなど。
マクロ・ヘルプ
「マクロ」メニュー、マクロエディタ、AppleScriptで書くマクロ。
TeXShopの設定はどうすればよいか？
おすすめの設定、~/Library/TeXShopの新しい項目、隠し設定、キーバインド、キーボードショートカット。

「ヘルプ」メニューからは、ほかの資料も開けます。「TeXShopマニュアル（英語）」はすべての機能を詳しく説明しています。「TeXShop入門（英語）」は初めて使う人向けの短い入門です。「このリリースについて（英語）」はアップデートのあとに手作業ですることがあればそれを伝え、「更新履歴（英語）」は各バージョンでの変更を一覧にしています。「マジックコメントと隠し設定（英語）」は、% !TEX program =のようなマジックコメントと、設定ウインドウにない設定の一覧です。

TeXShopのWebサイトはtexshop.appです。
