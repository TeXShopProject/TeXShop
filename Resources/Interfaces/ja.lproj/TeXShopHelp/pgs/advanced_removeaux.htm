作業ファイルを削除する

LaTeXはGalois.texをタイプセットするとき、Galois.aux、Galois.toc、Galois.logなどの作業ファイルを書き出し、次の回に相互参照や目次などのためにそれを読みます。エラーのあとなど、タイプセットが途中で止まると、これらのファイルが壊れたまま残ることがあり、次の回にソースにはないエラーが、多くは\begin{document}の直前で報告されます。作業ファイルをゴミ箱に入れてタイプセットし直せば直ります。

ファイルをゴミ箱に入れる

  • 「ファイル」→「作業ファイルを削除」（⌃⌘A）、またはコンソールの「作業ファイルを削除」ボタンで、書類の作業ファイルをゴミ箱に入れます。
  • 「タイプセット」→「作業ファイルを削除 & タイプセット」（⌥⌘T）は、これを行ってからタイプセットします。「タイプセット」メニューでは、Optionキーを押している間、「タイプセット」の代わりにこの項目が現れます。

ゴミ箱に入るのは、ソースのフォルダにあって、ソースと同じ名前を持ち、次のいずれかの拡張子が付いたファイルです。

4ct  4tc  aux  bcf  blg  brf  css  ent  fdb_latexmk  fff  fls
gaux  glo  glog  gtex  idv  idx  ilg  ind  lg  loa  lof  log
lot  mlf  mtc  out  pdfsync  run.xml  synctex  synctex.gz  toc
ttt  wrm  xref

タイプセットが中断されたときにSyncTeXが残す、名前の末尾に(busy)の付いたファイルもゴミ箱に入ります。BibTeXの.bblファイルは残します。

章のファイルが% !TEX rootでルートファイルを指定しているプロジェクトでは、章のファイルで実行しても、ルートファイルの作業ファイルがゴミ箱に入ります。

操作のバリエーション

  • Shiftキーを押しながら「作業ファイルを削除」を選ぶかボタンをクリックすると、書類のPDFファイルもゴミ箱に入ります。ふだんは古いPDFを残します。タイプセットに失敗したときにも、プレビューのウインドウに表示するものがあるようにするためです。
  • Optionキーを押しながら「作業ファイルを削除」を選ぶかボタンをクリックすると、プロジェクト全体を片付けます。ルートファイルのフォルダとその下のすべてのフォルダにある、上の拡張子のいずれかを持つファイルが、名前にかかわらずすべてゴミ箱に入ります。サブフォルダにある章のために\includeが書き出す.auxファイルも削除されます。

2つの隠し設定で動作を変えられます。一覧に拡張子（たとえばdvi）を加えるには、ターミナルで次のように入力します。

defaults write TeXShop OtherTrashExtensions -array-add "dvi"

標準の一覧に戻すには次のようにします。

defaults write TeXShop OtherTrashExtensions -array

Optionキーを押したときの動作を「作業ファイルを削除」の標準の動作にするには、次のようにします。

defaults write TeXShop AggressiveTrashAUX YES
