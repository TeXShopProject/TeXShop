「設定」→「キーボード」には新しい書類の初期値としてキーバインドをオン／オフするチェックボックスがあります ； デフォルトではオフになっています。キーバインドをオンにすると、特定の文字を打ち込むことで一連の文字列をソースファイルに挿入することができます。たとえば、^ を打ち込むと、カーソルを間に挟んだ括弧──^{ } が挿入されます。

キーバインドの内容は，TeXShopに内蔵されているキーバインドエディタで編集できます。

キーバインドがオンのとき、「ペースト」にチェックを入れたキーバインドは、ペーストした文字列にも適用されます。ペーストした文字列の中の入力文字が、それぞれ出力文字列に置き換わります。出力文字列に #SEL#、#INS#、#PASTE#、マーク（•）を含むキーバインドはチェックできません。たとえば「設定」の「新しい書類のエンコーディング」が日本語以外のとき、入力文字 ¥ の出力文字列を半角の \ 1文字にしてチェックを入れると、ペーストした文字列の ¥ が \ になります。TeXShopを初めてインストールした場合は、¥ の行は最初からこのとおりになっています。
