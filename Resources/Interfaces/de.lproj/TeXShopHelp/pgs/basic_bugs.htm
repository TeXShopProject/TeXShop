Fehler melden

Um ein Problem zu melden oder eine Verbesserung vorzuschlagen, legen Sie ein Issue auf GitHub an:

https://github.com/TeXShopProject/TeXShop/issues

Durchsuchen Sie zuerst die offenen und geschlossenen Issues: Das Problem ist vielleicht schon bekannt oder in einer neueren Version behoben. Zum Anlegen eines Issues brauchen Sie ein GitHub-Konto.

Ein Bericht, der sich schnell bearbeiten lässt, nennt:

  • die Version von TeXShop (TeXShop › Über TeXShop) und von macOS;
  • was Sie getan haben, was Sie erwartet haben und was stattdessen geschah;
  • bei Problemen beim Setzen eine kurze Quelltextdatei, die das Problem zeigt, und die Ausgabe der Konsole oder die Protokolldatei;
  • bei Problemen mit Fenstern oder Menüs ein Bildschirmfoto oder eine kurze Bildschirmaufnahme.

Fragen zu TeX, zu LaTeX-Paketen oder zu TeX Live selbst stellen Sie besser an den Orten, die unter Nützliche Websites aufgeführt sind, etwa bei TeX Stack Exchange.
