TeX Live beschaffen und installieren

Die Standard-TeX-Distribution heißt TeX Live. Jedes Jahr erstellt die TeX Users Group (TUG) eine neue Version. Diese Distribution läuft unter macOS (sowohl auf Apple Silicon als auch auf Intel), unter Linux, unter Windows und auf vielen anderen Architekturen.

Die MacTeX-Arbeitsgruppe der TUG hat ein Apple-Installationspaket erstellt, das diese Distribution und alles Weitere enthält, was man braucht, um TeX unter macOS zu benutzen. Das Paket ist in wenigen Minuten und fast ohne Zutun des Benutzers installiert. Es enthält die vollständige TeX-Live-Distribution, Ghostscript und die Programme TeXShop, TeX Live Utility, BibDesk, LaTeXiT und hintview, die in /Applications/TeX installiert werden. Aktuelle Links zu dem Paket finden Sie unter

www.tug.org/mactex/

Das MacTeX-Paket ist auch auf zahlreichen CTAN-Servern erhältlich. Falls der Link auf der oben genannten Seite nicht funktioniert, gehen Sie auf

www.ctan.org/

und klicken Sie auf den Link „our directories“, auf der folgenden Seite auf den Link „systems“, auf der nächsten Seite auf „mac“ und schließlich auf „mactex“.
