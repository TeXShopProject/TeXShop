TeX Live installieren

TeXShop braucht eine TeX-Distribution. Die übliche ist TeX Live, das die TeX-Anwendervereinigungen jedes Jahr für macOS, Windows, Linux und andere Systeme herausgeben. Auf dem Mac wird es mit MacTeX installiert, einem Installationspaket der TeX Users Group (TUG):

https://tug.org/mactex/

Die Seite bietet zwei Pakete an. Doppelklicken Sie auf das geladene Paket und folgen Sie dem Installationsprogramm; danach ist TeX einsatzbereit.

MacTeX
Das vollständige TeX Live mit Ghostscript sowie TeXShop und weiteren Programmen im Ordner „TeX“ des Ordners „Programme“ (/Applications/TeX). Fast jedes Beispiel aus einem Buch über TeX oder LaTeX funktioniert, ohne dass Sie etwas hinzufügen müssen. Wählen Sie dieses Paket für die eigentliche Arbeit.
BasicTeX
Ein kleiner Teil von TeX Live, genug, um TeX auszuprobieren und viele LaTeX-Dokumente zu setzen. TeXShop wird damit nicht installiert; siehe TeXShop installieren.

Wo TeX Live installiert wird

MacTeX installiert TeX Live in /usr/local/texlive/2026, BasicTeX in /usr/local/texlive/2026basic. Beide können nebeneinander installiert sein. Jedes Jahr, etwa im April, erscheint ein neues TeX Live in einem Ordner, der nach seinem Jahr benannt ist. Um eine Installation zu entfernen, ziehen Sie ihren Ordner in den Papierkorb.

Das Installationsprogramm legt außerdem /Library/TeX/texbin an. Dieser Pfad führt zu den Programmen des verwendeten TeX Live und folgt einem neu installierten TeX Live. TeXShop ruft TeX von dort auf (Einstellungen › Satz › Pfade › TeX-Engines), sodass Sie für ein neues Jahr nichts ändern müssen. „Pfade erkennen …“ in derselben Gruppe sucht die TeX- und Ghostscript-Installationen auf dem Mac und lässt Sie eine davon wählen.

Zwischen den jährlichen Ausgaben erhalten die Pakete von TeX Live Aktualisierungen. Um sie zu installieren, legt MacTeX das Programm TeX Live Utility in den Ordner „TeX“ des Ordners „Programme“.

Andere TeX-Distributionen

TeXShop arbeitet auch mit TeX aus MacPorts oder Homebrew oder mit MiKTeX. Deren Programme liegen in anderen Ordnern: Verwenden Sie „Pfade erkennen …“ oder geben Sie den Ordner unter Einstellungen › Satz › Pfade › TeX-Engines ein. Siehe Mehrere TeX-Distributionen nebeneinander.
