Einen externen Editor verwenden

Sie können in einem anderen Editor schreiben und TeXShop zum Setzen und zum Anzeigen des PDF verwenden.

Nur die Vorschau öffnen

Ablage › Zur Voransicht öffnen… fragt nach einer Quelltextdatei und öffnet nur ihr Vorschaufenster. Wurde die Datei noch nicht gesetzt oder ist das PDF älter als der Quelltext, setzt TeXShop sie zuerst. Bearbeiten Sie den Quelltext in Ihrem Editor; zum Setzen sichern Sie ihn dort und klicken im Vorschaufenster auf „Setzen“ oder drücken ⌘T. In diesem Modus öffnet oder ändert TeXShop die Quelltextdatei nie. Hat die Symbolleiste des Vorschaufensters keine Taste „Setzen“, fügen Sie sie mit Fenster › Symbolleiste anpassen… hinzu.

Wenn Sie immer so arbeiten, schalten Sie Einstellungen › Allgemein › Beim Start › „Externen Editor benutzen“ ein. Ablage › Öffnen… und „Benutzte Dokumente“ öffnen Quelltextdateien dann nur zur Voransicht, und aus Ablage › Zur Voransicht öffnen… wird „Zum Bearbeiten öffnen…“, das eine Quelltextdatei im Editor von TeXShop öffnet, wenn Sie ihn brauchen. Andere Dateien, etwa PDF-, Bild- und Log-Dateien, öffnen sich wie bisher.

Die Vorschau aktuell halten

Wenn ein anderes Programm das PDF neu schreibt, etwa Ihr Editor oder latexmk im Terminal, lädt TeXShop es neu, sobald Sie zu TeXShop oder zum Vorschaufenster zurückkehren, und behält dabei Seite und Vergrößerung bei. Ist Einstellungen › Vorschau › Aktualisierung › „PDF-Änderungen durch andere Apps ständig überwachen“ eingeschaltet, lädt TeXShop das PDF neu, sobald es sich ändert, auch wenn TeXShop im Hintergrund ist, etwa wenn die Vorschau neben Ihrem Editor steht. Eine Vorschau mit ungesicherten Anmerkungen wird nicht neu geladen, damit die Anmerkungen nicht verloren gehen.

TeXShop überwacht auch die Quelltextdateien, die in seinem eigenen Editor geöffnet sind. Ändert ein anderer Editor eine solche Datei, lädt TeXShop sie neu, sofern die Kopie in TeXShop keine ungesicherten Änderungen hat.

Mit dem Editor synchronisieren

Ein Befehlstaste-Klick im Vorschaufenster kann Sie zur Zeile in Ihrem Editor bringen, und „Gehe zu Fehler“ in der Konsole kann die Zeile eines Fehlers dort öffnen. Dafür braucht es „Externen Editor benutzen“, eine versteckte Einstellung und ein Befehlszeilenprogramm des Editors:

  • Für TextMate, dessen Befehl mate in /usr/local/bin liegt: defaults write TeXShop TextMateSync YES.
  • Für jeden anderen Editor: defaults write TeXShop OtherEditorSync YES und ein ausführbares Skript /usr/local/bin/othereditor, das die Zeilennummer als $1 und den vollständigen Pfad der Datei als $2 erhält. Für BBEdit lautet es: 
    #!/bin/sh
/usr/local/bin/bbedit "$2:$1"

Für die andere Richtung, von einer Zeile im Editor zum Vorschaufenster, ruft der Editor TeXShop über AppleScript mit den Befehlen sync_preview_line, sync_preview_index und sync_preview_name auf. Das Kapitel „Using an External Editor“ in Hilfe › TeXShop Handbuch (Englisch) enthält ein vollständiges Skript.

Der Ordner ~/Library/TeXShop/ExternalEditorScripts enthält fertige Unterstützung mit Dokumentation: AppleScripts, die ein Dokument aus BBEdit in TeXShop setzen und anzeigen, und ein Plug-in für Vim.

AppleScript-Befehle für Editoren

Ein Editor kann diese AppleScript-Befehle eines TeXShop-Dokuments aufrufen:

typesetinteractive, texinteractive, latexinteractive, bibtexinteractive, makeindexinteractive, metapostinteractive
Setzen bzw. plain TeX, LaTeX, BibTeX, MakeIndex oder MetaPost ausführen. Der Aufruf kehrt sofort zurück, ohne auf das Ende des Setzens zu warten; die Vorschau wird aktualisiert, wenn es endet.
taskdone
Gibt NO zurück, solange gesetzt wird, und YES, wenn das Setzen beendet ist.
refreshpdf
Lädt das PDF neu und holt das Vorschaufenster nach vorn.
refreshpdfbackground
Lädt das PDF neu, ohne TeXShop nach vorn zu holen, wenn das Vorschaufenster bereits geöffnet ist.
refreshtext
Liest die Quelltextdatei erneut vom Volume.
open_for_externaleditor
Öffnet eine Quelltextdatei wie Ablage › Zur Voransicht öffnen….

Wenn der Editor über TeXShop setzt, wird „PDF-Änderungen durch andere Apps ständig überwachen“ nicht gebraucht. Siehe auch Skripte mit TeXShop-Satzbefehlen schreiben.
