Das Makromenü neu anordnen

Öffnen Sie den Makro Editor und betrachten Sie das Makro-Menü auf der linken Seite. Das Makro-Menü wird in einer Listenansicht, die der Listenansicht des Finders gleicht, angezeigt. Um einzelne Einträge neu anzuordnen, ziehen Sie diese einfach von einem Ort zum anderen. Beachten Sie, dass die Einträge auf verschiedenen Ebenen platziert werden können indem man Sie nach links oder rechts verschiebt. Um einen Eintrag umzubenennen, wählen Sie ihn aus und drücken den Zeilenschalter, oder klicken Sie nach einem Moment noch einmal auf seinen Namen, wie im Finder. Geben Sie den neuen Namen ein und drücken Sie den Zeilenschalter; mit Escape bleibt der alte Name.
