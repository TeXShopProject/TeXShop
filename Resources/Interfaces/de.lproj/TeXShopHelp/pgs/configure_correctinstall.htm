Neue Objekte für die Library

TeXShop bewahrt die Dateien, die Sie ändern können, etwa Vorlagen, Makros, Engines, Tastenbelegungen, die Datei der LaTeX-Palette und Themen, in ~/Library/TeXShop auf, dem Ordner TeXShop im Ordner „Library“ Ihres Benutzerordners. TeXShop › Den Ordner „~/Library/TeXShop“ im Finder öffnen öffnet ihn im Finder. Beim ersten Start legt TeXShop diesen Ordner mit dem Standardinhalt an.

Was eine neue Version ändert

Eine neue Version von TeXShop lässt den größten Teil von ~/Library/TeXShop unberührt, sodass Ihre Änderungen erhalten bleiben. Einige Stellen enthalten die eigenen Hilfsdateien von TeXShop oder optionale Objekte, und eine neue Version bringt sie auf den neuesten Stand:

  • die Ordner bin, Documents, ExternalEditorScripts und Scripts;
  • Engines/Inactive und HTML/Inactive mit Engines und HTML-Dateien, die Sie in Gebrauch nehmen können;
  • HTML/Help.html, die Seite, die Hilfe › HTML-Befehle (Englisch) zeigt;
  • den Ordner New, der als Ganzes ersetzt wird.

An diesen Stellen wird jede Datei, die mit TeXShop kommt, durch ihre neue Version ersetzt; Änderungen, die Sie an einer solchen Datei vorgenommen haben, gehen also verloren. Neue Dateien werden hinzugefügt, und Dateien, die Sie unter anderen Namen hinzugefügt haben, bleiben, wie sie sind. Um Ihre eigene Fassung einer dieser Dateien zu behalten, sichern Sie sie unter einem anderen Namen.

Die verwendeten Engines im Ordner Engines selbst werden nicht geändert. Nur wenn der Ordner zuletzt von einer Version von TeXShop vor 6.00 aktualisiert wurde, fügt TeXShop einmalig html.engine zu Engines hinzu, und nur, wenn dort keine Datei dieses Namens liegt. Im Ordner Macros werden einige Makros, die mit TeXShop kamen und nie bearbeitet wurden, etwa das Makro, das die Website von TeXShop öffnet, auf ihren aktuellen Text gebracht; bearbeitete und eigene Makros bleiben, wie sie sind. Alles andere behält Ihre Änderungen.

TeXShop hält seine Version in einer unsichtbaren Datei .Version in ~/Library/TeXShop/New fest und aktualisiert den Ordner nur, wenn es neuer ist als die dort festgehaltene Version. So wird ~/Library/TeXShop nicht bei jedem Start von TeXShop neu geschrieben, und eine ältere Version von TeXShop kann laufen, ohne ihn zu ändern.

Der Ordner New

Der Ordner New enthält Objekte, die Sie vielleicht selbst hinzufügen möchten, etwa neue Vorlagen. Verschieben Sie ein solches Objekt in den richtigen Ordner, etwa Templates, und bearbeiten Sie es nach Belieben. Hilfe › Über diese Version (Englisch) sagt, wann es etwas zu übernehmen gibt.

Fehlende und beschädigte Dateien

Fehlt eine Datei, die TeXShop braucht, etwa die Makros, die Datei der LaTeX-Palette, die Tastenbelegungen, KeyEquivalents.plist oder ein Thema, oder ist sie beschädigt, ersetzt TeXShop sie beim Start ohne Meldung durch seine eigene Kopie. Die beschädigte Datei wird in ~/Library/TeXShop/Backups aufbewahrt, sodass Sie Ihre Änderungen daraus zurückholen können.

Den Standardinhalt eines Ordners erhalten

Um den neuesten Standardinhalt eines Ordners zu erhalten, etwa von Templates, beenden Sie TeXShop, bewegen diesen Ordner aus ~/Library/TeXShop heraus (zum Beispiel auf den Schreibtisch) und starten TeXShop erneut. Es legt den Ordner mit seinem Standardinhalt an. Kopieren Sie dann aus dem verschobenen Ordner zurück, was Sie behalten möchten.
