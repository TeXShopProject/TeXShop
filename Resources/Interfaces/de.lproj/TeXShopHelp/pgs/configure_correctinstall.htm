Neue Objekte in ~/Library/TeXShop erhalten

Das Standardverhalten von TeXShop lässt sich auf zwei Arten ändern: über die Einstellungen und durch Bearbeiten von Dateien in ~/Library/TeXShop. Dabei ist ~/Library der Ordner „Library“ in Ihrem Benutzerordner.

Neue Versionen von TeXShop ändern diese Anpassungen in der Regel nicht, denn niemand mag Änderungen hinter seinem Rücken. Manchmal erfordern neue Funktionen aber einige Anpassungen. Sie werden im Dokument „Über diese Version (Englisch)“ im Menü „Hilfe“ beschrieben, das für jede Version von TeXShop neu geschrieben wird. TeXShop funktioniert auch dann, wenn die dort beschriebenen Anpassungen nicht vorgenommen werden; einige neue Funktionen arbeiten dann aber möglicherweise nicht wie beschrieben.

TeXShop aktualisiert die Objekte in ~/Library/TeXShop normalerweise nicht, mit einigen Ausnahmen: Jede neue Version aktualisiert die Ordner bin, Documents, Engines/Inactive, ExternalEditorScripts, HTML/Inactive und Scripts sowie die Datei HTML/Help.html, die Seite, die „Hilfe“ > „HTML-Befehle (Englisch)“ anzeigt. Dort wird jede Datei, die TeXShop mitbringt, durch ihre neue Version ersetzt; Änderungen, die Sie an einer solchen Datei vorgenommen haben, gehen also verloren. Neue Standarddateien kommen hinzu, und Dateien, die Sie unter anderen Namen hinzugefügt haben, bleiben unverändert. Wenn Sie eine eigene Fassung einer dieser Dateien behalten möchten, etwa von Help.html, sichern Sie sie unter einem anderen Namen. Aktive Engine-Dateien werden nicht geändert, da sie im Ordner Engines liegen und nicht im Unterordner Inactive; nur wenn eine Library aktualisiert wird, die zuletzt von einer Version vor 6.00 beta 10 aktualisiert wurde, kopiert TeXShop einmalig html.engine in den Ordner Engines, sofern dort noch keine Datei dieses Namens liegt. Im Ordner Macros können Makros, die mit einer früheren Version von TeXShop kamen und nie bearbeitet wurden, auf ihren aktuellen Text gebracht werden; bearbeitete und eigene Makros bleiben, wie sie sind. Alles andere in ~/Library/TeXShop behält Ihre Änderungen.

Der Vorteil dieses Aufbaus: Manche Engines legen Hilfsdateien in den Ordnern bin und Scripts ab. Bei einer Aktualisierung von TeXShop werden diese Hilfsdateien automatisch erneuert, ohne dass Sie etwas tun müssen. Ebenso kommen gelegentlich neue Engines in den Ordner Engines/Inactive, die Sie automatisch erhalten.

Jede neue Version von TeXShop schreibt den Ordner ~/Library/TeXShop/New neu. Er enthält neue Objekte, die Sie vielleicht in Ihre anderen Konfigurationsordner übernehmen möchten. Neue Vorlagen erscheinen zum Beispiel in ~/Library/TeXShop/New. Wenn Sie diese Vorlagen verwenden möchten, verschieben Sie sie nach ~/Library/TeXShop/Templates und passen Sie sie nach Bedarf an. Der Inhalt von ~/Library/TeXShop/New wird immer in „Über diese Version (Englisch)“ beschrieben; Sie müssen den Ordner also nur ansehen, wenn Sie dort dazu aufgefordert werden.

Ein technisches Detail ist nützlich zu wissen: Eine unsichtbare Datei in ~/Library/TeXShop/New enthält die Versionsnummer der TeXShop-Version, die den Ordner geschrieben hat. ~/Library/TeXShop wird nur aktualisiert, wenn die Versionsnummer von TeXShop höher ist als die in dieser Datei. Deshalb wird ~/Library/TeXShop nicht bei jedem Start von TeXShop aktualisiert, und ältere Versionen von TeXShop können gefahrlos gestartet werden, ohne ~/Library/TeXShop zu verändern.

In seltenen Fällen möchten Sie vielleicht die neuesten Standarddateien eines Ordners in ~/Library/TeXShop erhalten. Verschieben Sie diesen Ordner auf den Schreibtisch; beim nächsten Start legt TeXShop ihn neu an. Danach können Sie Ihre eigenen Änderungen aus der Kopie auf dem Schreibtisch übernehmen. Verschieben Sie zum Beispiel den Ordner Templates aus ~/Library/TeXShop auf den Schreibtisch, so erzeugt der nächste Start von TeXShop den neuesten Standardordner Templates. Dieser drastische Schritt ist zum Glück nur selten nötig.
