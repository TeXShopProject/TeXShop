Matrix Palette

Fenster › Matrix Palette... öffnet eine Palette, die Matrizen und Tabellen für Sie schreibt. Füllen Sie die Einträge in ihrer Tabelle aus, wählen Sie, wie das Ergebnis aussehen soll, und fügen Sie es an der Einfügemarke in den Quelltext ein.

Eine Matrix oder Tabelle erstellen

  1. Geben Sie die Größe unter „Zeilen“ und „Spalten“ ein, jeweils bis 999.
  2. Wählen Sie unter „Umgebung“ matrix für eine Matrix in einer Formel (eine Umgebung array) oder tabular für eine Tabelle mit Text. Bei tabular setzt „In table-Umgebung einbetten“ die Tabelle in ein Gleitobjekt table mit Beschriftung und Label.
  3. Wählen Sie für eine Matrix die linke und rechte Klammer. Der Punkt lässt diese Seite ohne Klammer, und die letzte Taste verwendet die Klammer, die im Feld daneben eingegeben ist.
  4. Die beiden Tasten mit dem Bild einer Matrix fügen einen Rahmen um die Einträge und Linien zwischen ihnen hinzu.
  5. Füllen Sie die Einträge aus. „Löschen“ leert alle; „Einheitsmatrix“ und „Nullmatrix“ füllen sie mit einer Einheitsmatrix oder mit Nullen.
  6. Klicken Sie auf „Einfügen“ oder drücken Sie ⌘Zeilenschalter.

In der Tabelle arbeiten

Die Tabelle funktioniert wie eine Tabellenkalkulation. Klicken Sie auf eine Zelle, um sie zu wählen, ziehen Sie oder klicken Sie mit gedrückter Umschalttaste, um mehrere zu wählen, und tippen Sie, um den Wert zu ersetzen; doppelklicken Sie, drücken Sie F2 oder Control-U, um ihn zu bearbeiten. Der Zeilenschalter geht nach unten, die Tabulatortaste nach rechts und die Pfeiltasten in jede Richtung; die Rückschritttaste leert die gewählten Zellen. Kopieren und Einsetzen tauschen Zellen mit Tabellenkalkulationen aus. Ziehen Sie die Nummer einer Zeile, um die Zeile zu bewegen. Widerrufen und Wiederholen wirken auf die Tabelle, solange die Palette aktiv ist.

Wird die Matrix verkleinert, behalten die Zellen außerhalb ihre Werte, grau dargestellt, und kommen zurück, wenn sie wieder vergrößert wird. Vergrößern Sie die Palette, um mehr von der Tabelle zu sehen.

Den eingefügten Code anpassen

Der Code, den die Palette um die Einträge schreibt, steht in ~/Library/TeXShop/MatrixPanel/matrixpanel_1.plist: Anfang und Ende der Umgebungen, die Klammern, die Trennzeichen zwischen Einträgen und zwischen Zeilen, die Linien eines Rahmens oder Gitters und der Buchstabe c, der die Ausrichtung jeder Spalte festlegt. Ändern Sie zum Beispiel c in r, um die Spalten rechtsbündig auszurichten. Behalten Sie Anzahl und Reihenfolge der Zeichenketten in der Datei bei und starten Sie TeXShop nach einer Änderung neu. Siehe Dateien in ~/Library/TeXShop.
