ConTeXt und MetaPost

ConTeXt

ConTeXt ist ein Makropaket von Hans Hagen, eine Alternative zu LaTeX mit eigenen Befehlen und einem starken Schwerpunkt auf typografischer Gestaltung. TeX Live enthält ConTeXt, und die Website ConTeXt Garden verteilt eine häufig aktualisierte Version, die in Ihrem Benutzerordner installiert wird.

Die Engines für ConTeXt liegen in ~/Library/TeXShop/Engines/Inactive/ConTeXt, zusammen mit der Anleitung Setting-Up-ConTeXt.pdf und Beispieldokumenten:

EngineSetzt mit
ConTeXt.enginedem ConTeXt von TeX Live, das auf LuaTeX läuft
ConTeXt-TL.enginedem ConTeXt von TeX Live, das auf luametatex läuft
ConTeXt-CG.engineder Version des ConTeXt Garden in Ihrem Benutzerordner

Bewegen Sie die benötigte Engine nach ~/Library/TeXShop/Engines und schreiben Sie magische Zeilen an den Anfang der Hauptdatei des Dokuments, zum Beispiel:

% !TEX program = ConTeXt-TL
% !TEX useConTeXtSyncParser

Für ConTeXt-CG geben Sie den Ordner der Programme der ConTeXt-Garden-Installation im Feld „Zweite TeX-Engines“ unter Einstellungen › Satz › Pfade ein und fügen die Zeile % !TEX useAlternatePath hinzu; damit übergibt TeXShop der Engine diesen Ordner statt TeX Live.

Für die Synchronisierung zwischen Quelltext und Vorschau fügen Sie \setupsynctex[state=start,method=min] in die Einrichtung des Dokuments ein; die Zeile % !TEX useConTeXtSyncParser lässt TeXShop den eigenen Synchronisierungscode von ConTeXt verwenden. Das ConTeXt-Kapitel in Hilfe › TeXShop Handbuch (Englisch) beschreibt die Installation der Version des ConTeXt Garden und jede Engine im Einzelnen.

Um Gliederungsbefehle von ConTeXt wie \title und \subject im Menü „Markierungen“ aufzuführen, schalten Sie die versteckte Einstellung ConTeXtTags ein; siehe Versteckte Einstellungen.

MetaPost

MetaPost von John Hobby zeichnet Abbildungen nach einer Beschreibung in einer Programmiersprache, die von Knuths METAFONT abgeleitet ist. Sein Handbuch gehört zu TeX Live: Wählen Sie Hilfe › Hilfe für Paket einblenden... und geben Sie metapost ein.

Setzen › MetaPost (⇧⌘M) oder MetaPost im Einblendmenü neben der Taste „Setzen“ startet MetaPost für die Datei mit dem Namen des aktiven Dokuments und der Endung .mp: für das Dokument selbst, wenn es eine .mp-Datei ist, sonst für die .mp-Datei daneben, etwa die, die das Paket mfpic für ein .tex-Dokument schreibt. Ausgeführt wird der Befehl unter Einstellungen › Satz › Zugehörige Programme › MetaPost, als Vorgabe mpost. Die Engine-Profile setzen dieses Feld: pmpost für pLaTeX + dvipdfmx und upmpost für upLaTeX + dvipdfmx, die japanischen Text in Beschriftungen setzen, und mpost für die übrigen Profile. LuaLaTeX kann keine Abbildungen einbinden, deren Beschriftungen pmpost oder upmpost auf Japanisch gesetzt haben; zeichnen Sie solche Abbildungen mit LuaLaTeX im Dokument selbst mit dem Paket luamplib.

Um eine neue Datei als MetaPost-Datei zu sichern, wählen Sie im Sichern-Dialog im Menü „Dateiformat“ den Typ mp.

Die Engines nv-metapost und nv-metafun von Nicola Vitacolonna erleichtern die Arbeit mit MetaPost und MetaFun und zeigen die Abbildungen einer Datei im Vorschaufenster. Sie liegen in ~/Library/TeXShop/Engines/Inactive/MetaPostEngines-1.4.7/Engines; die Datei README.pdf und der Ordner examples eine Ebene höher in MetaPostEngines-1.4.7 erklären, wie man sie installiert und verwendet, und enthalten Beispieldateien. Eine Datei, die zum Beispiel so beginnt,

% !TEX program = nv-metafun
beginfig(1);
  pickup pencircle scaled 2mm;
  draw fullcircle scaled 2cm withcolor red;
endfig;
end

wird mit nv-metafun gesetzt, sobald diese Engine im Ordner „Engines“ liegt.

MetaPost-Zeichnungen lassen sich auch in einem LaTeX-Dokument schreiben, mit dem Paket luamplib für LuaLaTeX oder mit Paketen wie mfpic, die die Zeichnungen in eine .mp-Datei schreiben, die MetaPost zwischen zwei Satzläufen verarbeitet.
