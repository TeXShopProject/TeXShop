Versteckte Einstellungen

Das Fenster „Einstellungen“ enthält die Einstellungen, die die meisten brauchen. Seltenere sind versteckte Einstellungen: Sie haben kein Bedienelement im Fenster „Einstellungen“ und werden mit einem Befehl im Terminal geändert. Das Nachschlagewerk „Kommentarzeilen und versteckte Einstellungen“ (auf Englisch) listet jede versteckte Einstellung mit ihrem Befehl auf, nach Themen geordnet. Öffnen Sie es mit Hilfe › Kommentarzeilen und versteckte Einstellungen (Englisch) oder mit „Handbuch zu Kommentarzeilen und versteckten Einstellungen öffnen…“ unter Einstellungen › Allgemein › Erweitert.

Eine versteckte Einstellung ändern

  1. Beenden Sie TeXShop.
  2. Öffnen Sie das Terminal (in /Programme/Dienstprogramme), tippen Sie den Befehl ein und drücken Sie den Zeilenschalter.
  3. Starten Sie TeXShop erneut.

Jeder Befehl hat die Form defaults write TeXShop Name Wert. Um zum Standardwert zurückzukehren, verwenden Sie defaults delete TeXShop Name.

Beispiele

defaults write TeXShop OtherTrashExtensions -array 'nav' 'snm'
Ablage › Aux-Dateien löschen entfernt auch Dateien mit diesen Endungen. Geben Sie die Endungen ohne Punkt an. Siehe Aux-Dateien entfernen.
defaults write TeXShop ConTeXtTags YES
Das Menü „Markierungen“ listet die Gliederungsbefehle von ConTeXt wie \title und \subject statt der von LaTeX auf.
defaults write TeXShop RedConsoleAfterError YES
Text, der in der Konsole als Antwort auf einen TeX-Fehler getippt wird, und alle weitere Ausgabe dieses Durchlaufs erscheinen rot.
defaults write TeXShop RefreshTime 2
Solange „PDF-Änderungen durch andere Apps ständig überwachen“ unter Einstellungen › Vorschau eingeschaltet ist, prüft TeXShop alle 2 Sekunden, ob sich ein PDF geändert hat. Standard ist 1 Sekunde, das Minimum 0.5.

Einstellungen, die im Fenster „Einstellungen“ stehen, werden bei den versteckten Einstellungen nicht wiederholt. So schalten Sie zum Beispiel das Springen zur nächsten oder vorherigen Marke von Bearbeiten › Marken mit Wahl- oder Control-Taste und der Auslösetaste mit „Mit Wahl- oder Control-Taste und der Auslösetaste zur nächsten oder vorherigen Marke springen“ unter Einstellungen › Tastatur ein und aus. Um eine solche Einstellung zu finden, verwenden Sie „Einstellungen suchen“; siehe Einstellungen suchen.
