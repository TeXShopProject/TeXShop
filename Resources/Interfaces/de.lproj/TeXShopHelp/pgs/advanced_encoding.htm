Codierungen

TeXShop bearbeitet Text in Unicode, daher nimmt das Quelltextfenster jedes Zeichen jeder Sprache an. Die Codierung bestimmt, wie dieser Text in die Datei auf dem Volume geschrieben und wieder gelesen wird. UTF-8 kann jedes Zeichen speichern, und LaTeX, XeLaTeX und LuaLaTeX lesen es standardmäßig. Ältere Dateien und Dateien von anderen Systemen verwenden womöglich eine andere Codierung, etwa ISO Latin 9 oder Shift JIS.

Neue Dokumente

Neue Dokumente werden in der Codierung gesichert, die unter Einstellungen › Dokumente und Sichern › Codierung › Codierung für neue Dokumente gewählt ist. Vorgabe ist Unicode (UTF-8); behalten Sie sie bei, sofern Sie keine Dateien mit Personen austauschen, die eine andere Codierung brauchen.

Ein Dokument wird in der Codierung gesichert, mit der es geöffnet wurde; eine ältere Datei behält also ihre Codierung. Zeichen, die die Codierung einer Datei nicht darstellen kann, gehen beim Sichern verloren.

Dateien öffnen

Wird eine Datei ohne Codierungszeile (siehe unten) geöffnet, erkennt TeXShop ihre Codierung. Ein Byte Order Mark kennzeichnet UTF-8- und UTF-16-Dateien. Eine Datei nur aus ASCII-Zeichen wird in der Codierung für neue Dokumente gelesen. Andernfalls verwendet TeXShop die Codierung, die das Programm, das die Datei gesichert hat, mit ihr vermerkt hat, sofern macOS diese Information bewahrt hat, und versucht dann UTF-8, danach die Codierungen Ihrer Sprachen und die Codierung für neue Dokumente. Eine Codierung, die der Quelltext angibt, etwa mit \usepackage[latin9]{inputenc}, dient als Hinweis.

Die Erkennung ist eine Vermutung und gelingt am besten bei Dateien mit einer gewissen Menge Text. Wählt sie die falsche Codierung, schließen Sie die Datei ohne zu sichern, öffnen Sie sie erneut mit Ablage › Öffnen …, klicken Sie im Öffnen-Dialog auf „Optionen“ und wählen Sie die Codierung in dessen Menü; die dort gewählte Codierung gilt für die dabei geöffneten Dateien, und das Dokument behält sie. Das Menü zeigt zunächst die Codierung für neue Dokumente; bleibt diese stehen, gilt sie nicht als Wahl, und die Codierung wird wie üblich erkannt. Fügen Sie der Datei dann eine Codierungszeile hinzu, damit sie immer richtig geöffnet wird. Die Erkennung lässt sich mit der versteckten Einstellung

defaults write TeXShop EncodingAutoDetection NO

ausschalten. Dateien werden dann in der Codierung für neue Dokumente gelesen.

Die Codierungszeile

Eine Zeile in einer der ersten zwanzig Zeilen einer Quelltextdatei legt ihre Codierung für das Lesen und das Sichern fest und hat Vorrang vor allem anderen:

% !TEX encoding = UTF-8 Unicode

Schreiben Sie die Zeile wie gezeigt, mit einem Leerzeichen vor dem Gleichheitszeichen; %!TEX encoding = ohne das Leerzeichen nach % wird ebenfalls gelesen. Der Name muss genau wie in der folgenden Tabelle geschrieben werden. Das Makro „Encoding“ im Menü „Makros“ fügt die Zeile für Sie ein, mit einer Liste von Codierungen zur Auswahl. Auch die Namen, die TeXworks verwendet, etwa UTF-8 oder ISO 8859-1, werden verstanden.

Nennt die Zeile eine Codierung, die TeXShop nicht kennt, liest TeXShop die Datei als UTF-8 und weist darauf hin. Nennt die Zeile UTF-8, ist die Datei aber kein gültiges UTF-8, meldet TeXShop dies und öffnet die Datei in ISO Latin 9, das jede Datei lesen kann; wird sie gesichert, ohne die Zeile zu ändern, werden dieselben Bytes zurückgeschrieben, sodass nichts verloren geht. Um eine Datei zu öffnen, ohne ihre Codierungszeile anzuwenden, halten Sie beim Öffnen die Wahltaste gedrückt.

In einer anderen Codierung sichern

Um die Codierung beim Sichern zu wählen, schalten Sie Einstellungen › Dokumente und Sichern › Codierung › „Codierung im Sichern-Dialog anzeigen“ ein; der Sichern-Dialog hat dann ein Menü für die Codierung. Bearbeiten › Transformationen › Codierung ändern wählt die Codierung, in der das geöffnete Dokument von da an gesichert wird. Hat die Datei eine Codierungszeile, entscheidet die Zeile; ändern Sie dann die Zeile. TeXShop behält das Byte Order Mark einer UTF-8-Datei und die Byte-Reihenfolge einer UTF-16-Datei bei.

Beim Umwandeln einer Datei in eine andere Codierung geht jedes Zeichen verloren, das die neue Codierung nicht darstellen kann, und wird eine Datei in der falschen Codierung gelesen und gesichert, sind ihre Zeichen endgültig ersetzt. Bewahren Sie eine Kopie des Originals auf. Das Befehlszeilenprogramm iconv wandelt Dateien um, ohne das Original zu ändern. Das Dokument „Dateicodierung und TeXShop (Englisch)“ im Menü „Hilfe“ behandelt diese Fragen ausführlicher.

Sprachen mit Schreibrichtung von rechts nach links

Arabisch, Hebräisch und Persisch werden im Quelltextfenster von rechts nach links eingegeben. Ist Einstellungen › Editor › Eingabe › „Rechts-nach-links-Sprachen (Arabisch, Hebräisch, Persisch)“ eingeschaltet und die Syntaxhervorhebung aktiv, werden Zeilen, die mit arabischer oder hebräischer Schrift beginnen, rechtsbündig angezeigt und andere Zeilen, etwa solche, die mit einem LaTeX-Befehl beginnen, linksbündig. Mit der versteckten Einstellung

defaults write TeXShop RightJustifyIfAny YES

wird jede Zeile rechtsbündig angezeigt, die solche Zeichen an irgendeiner Stelle enthält. Die Ausrichtung dient nur dem Bearbeiten; den gesetzten Text ordnet TeX nach seinen eigenen Befehlen an. Um diese Sprachen zu setzen, verwenden Sie XeLaTeX oder LuaLaTeX; siehe XeLaTeX und LuaLaTeX.

Andere Schriften eingeben

Um in einer anderen Schrift zu schreiben, fügen Sie unter Systemeinstellungen › Tastatur im Abschnitt „Texteingabe“ eine Eingabequelle dafür hinzu und wechseln die Eingabequelle mit dem Eingabemenü in der Menüleiste.
