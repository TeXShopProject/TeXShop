TeXShop wird von den im vorigen Abschnitt beschriebenen MacTeX-Paketen automatisch installiert. Sie können es auch von der TeXShop-Webseite laden:

https://texshop.app/

Neue Versionen von TeXShop enthalten manchmal überarbeitete Makros, Engines und Vorlagen. Diese erscheinen nicht automatisch, wenn Sie von einer älteren Version von TeXShop aktualisieren. Wie Sie sie bekommen, steht in „Über diese Version (Englisch)“ im Menü „Hilfe“.

Ein grober Weg zu den neuen Standarddateien: Gehen Sie zu ~/Library/TeXShop; dabei ist ~/Library der Ordner „Library“ in Ihrem Benutzerordner. Verschieben Sie den gesamten Ordner „Macros“ (oder „Engines“ oder „Templates“) auf den Schreibtisch. Beim nächsten Start legt TeXShop den fehlenden Ordner neu an. Übernehmen Sie danach Ihre eigenen Änderungen aus dem alten Ordner auf dem Schreibtisch.

Viel einfachere Wege zum Aktualisieren beschreibt der Abschnitt „Wie konfiguriere ich TeXShop?“ der Hilfe.
