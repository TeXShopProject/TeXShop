TeXShop installieren

TeXShop benötigt macOS 14.6 oder neuer. MacTeX installiert es im Ordner „TeX“ des Ordners „Programme“ (/Applications/TeX). Sie können es auch von der Website von TeXShop laden:

https://texshop.app/

Ziehen Sie das geladene TeXShop in den Ordner „Programme“ (/Applications) oder in dessen Unterordner „TeX“. Wählen Sie nach der Installation von MacTeX einmal TeXShop › Nach Updates suchen …, da MacTeX eine ältere Version enthalten kann.

Der erste Start

Beim ersten Start sucht TeXShop nach TeX und Ghostscript und listet die gefundenen Installationen auf, die neueste zuerst; wählen Sie eine aus und klicken Sie auf „OK“. Danach fragt TeXShop nach einem Engine-Profil, das den Satz für die von Ihnen verwendete Engine einrichtet. Beides können Sie später unter Einstellungen › Satz ändern; siehe Die Engine wählen.

Updates

TeXShop › Nach Updates suchen … sucht nach einer neuen Version. Gibt es eine, zeigt TeXShop die Änderungen und bietet die Installation an; danach startet es neu und macht dort weiter, wo Sie aufgehört haben. Unter Einstellungen › Updates legen „Automatisch nach Updates suchen“ und „Suchintervall“ fest, ob und wie oft TeXShop selbst sucht. Schalten Sie „Vorabversionen einschließen“ ein, um auch Betaversionen angeboten zu bekommen; eine Betaversion von TeXShop schaltet diese Option beim ersten Start ein.

Werfen Sie nach einem Update einen Blick in Hilfe › Über diese Version (Englisch). Dort steht, ob Sie etwas von Hand erledigen müssen; meist ist nichts zu tun.

Der Ordner ~/Library/TeXShop

Die Dateien, die Sie ändern können, etwa Vorlagen, Makros, Engines, Tastenbelegungen, die Liste der Befehlsvervollständigung und die Themen, bewahrt TeXShop im Ordner TeXShop im Ordner „Library“ Ihres Benutzerordners auf. TeXShop › Den Ordner „~/Library/TeXShop“ im Finder öffnen zeigt ihn im Finder. TeXShop legt den Ordner beim ersten Start an. Fehlt dort eine der Einstellungsdateien, etwa die Makros, die Tastenbelegungen, die Liste der Befehlsvervollständigung oder ein Thema, oder ist sie beschädigt, setzt TeXShop ohne Fehlermeldung seine eigene Kopie ein und bewahrt die beschädigte Datei in ~/Library/TeXShop/Backups auf.

Ein Update ändert keine Dateien, die Sie bearbeitet haben könnten, etwa die Makros und die aktiven Engines; es erneuert nur einige Ordner mit optionalen Objekten. Bringt eine Version neue Makros, Engines oder andere Objekte, steht das in „Über diese Version“, und Neue Objekte für die Library erklärt, wie Sie sie hinzufügen.
