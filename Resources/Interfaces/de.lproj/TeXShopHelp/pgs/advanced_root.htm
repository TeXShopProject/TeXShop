Die Hauptdatei eines Projekts festlegen

Große Dokumente werden oft auf mehrere Dateien verteilt: eine Hauptdatei mit der Präambel, die für jedes Kapitel eine Datei einbindet. Eine Hauptdatei Main.tex könnte zum Beispiel so lauten:

\documentclass[11pt]{book}
\includeonly{Chapter2/two}
\begin{document}
\include{Chapter1/one}
\include{Chapter2/two}
\include{Chapter3/three}
\end{document}

Wenn Sie two.tex bearbeiten, soll TeXShop Main.tex setzen, nicht das Kapitel, das keine Präambel hat. Damit TeXShop das weiß, schreiben Sie diese Zeile in eine der ersten zwanzig Zeilen jeder Kapiteldatei:

% !TEX root = ../Main.tex

Die Hauptdatei selbst braucht keine solche Zeile. Der Name der Hauptdatei kann angegeben werden

  • nur mit ihrem Namen, Main.tex, wenn sie im selben Ordner wie die Kapiteldatei liegt;
  • relativ zum Ordner der Kapiteldatei, ../Main.tex oder ../../Main.tex;
  • mit ihrem vollständigen Pfad, /Users/me/Book/Main.tex, der geändert werden muss, wenn das Projekt verschoben wird.

Das Makro „Root“ im Menü „Makros“ fügt die Zeile ein: Es fragt nach der Hauptdatei und bietet eine relative oder eine absolute Zeile an; eine frühere Root-Zeile wird dabei ersetzt.

Was die Root-Zeile bewirkt

  • Setzen in einer Kapiteldatei setzt die Hauptdatei, und das Vorschaufenster der Hauptdatei zeigt das ganze Dokument. Eine Zeile % !TEX program und andere magische Zeilen für das Setzen gehören in die Hauptdatei.
  • „Gehe zu Fehler“ öffnet die Datei, die einen Fehler enthält, falls sie nicht geöffnet ist, und springt in die Zeile.
  • Die Synchronisierung aus dem Vorschaufenster öffnet die Kapiteldatei, die die angeklickte Stelle enthält; siehe Quelltext und Vorschau synchronisieren.
  • „Aux-Dateien in den Papierkorb legen“ entfernt die Hilfsdateien der Hauptdatei; siehe Aux-Dateien entfernen.
  • Fenster › Quelltext ⇔ Vorschau (⌘1) holt in einer Kapiteldatei das Vorschaufenster der Hauptdatei nach vorn. Erneutes Wählen im Vorschaufenster kehrt zum Quelltextfenster zurück, aus dem Sie gekommen sind, oder zur Hauptdatei, wenn Sie nicht aus einem Quelltextfenster gekommen sind.

Eine Kapiteldatei öffnen

Wird eine Kapiteldatei mit einer Root-Zeile geöffnet, öffnet TeXShop auch die Hauptdatei und ihr Vorschaufenster. Zwei Einstellungen unter Einstellungen › Allgemein › Projekt-Hauptdatei steuern dies: „Beim Öffnen eines Dokuments auch die Hauptdatei öffnen“ schaltet es ein oder aus, und „Fenster der geöffneten Hauptdatei im Dock ablegen“ legt das Quelltextfenster der Hauptdatei im Dock ab, da es selten bearbeitet wird, während Sie an einem Kapitel arbeiten.

Im ganzen Projekt suchen und ersetzen

Um alle Dateien eines Projekts auf einmal zu durchsuchen, wählen Sie in einer seiner Kapiteldateien Bearbeiten › Suchen › In TeX-Quellen mit derselben TEX root suchen … oder in der Hauptdatei „In TeX-Quellen mit dieser Datei als TEX root suchen …“. Durchsucht werden die Hauptdatei und die .tex-Dateien in ihrem Ordner und darunter, die sie in ihren ersten 20 Zeilen in einer Root-Zeile nennen. Siehe In TeX-Quellen suchen und Suchen und Ersetzen.

Hauptdateien in .texshop-Dateien

Eine Datei mit der Endung .texshop neben einer Kapiteldatei, etwa two.texshop für two.tex, kann ebenfalls die Hauptdatei nennen, und TeXShop liest sie weiterhin. Kein Menübefehl erstellt solche Dateien; verwenden Sie eine Zeile % !TEX root, die mit dem Quelltext mitwandert.
