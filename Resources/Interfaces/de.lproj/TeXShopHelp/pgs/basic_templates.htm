Vorlagen

Das Menü „Vorlagen“

Das Menü „Vorlagen“ in der Symbolleiste des Quelltextfensters fügt an der Einfügemarke eine Vorlage ein, eingerückt wie die aktuelle Zeile. TeXShop bringt diese Vorlagen mit:

  • LatexTemplate, XeLaTeX Template, LatexSpanishTemplate und BeamerTemplate: der Anfang eines LaTeX-Artikels, eines XeLaTeX-Dokuments, eines spanischen LaTeX-Artikels und einer Beamer-Präsentation;
  • TexTemplate: das \end, das ein plain-TeX-Dokument abschließt;
  • GraphicsTemplate: der Code zum Einbinden einer Grafik;
  • TeX4ht-Header und TeX4ht-Interactive: Code für Dokumente, die mit TeX4ht in HTML umgewandelt werden;
  • More: ein Untermenü mit Präambeln, Dokumentklassen wie article, letter und memoir, Gleitobjekten für Abbildungen und Tabellen sowie mathematischen Anordnungen wie align und Matrizen.

Die Vorlagen sind gewöhnliche Dateien in ~/Library/TeXShop/Templates; mit TeXShop › Den Ordner „~/Library/TeXShop“ im Finder öffnen gelangen Sie dorthin. Um eine eigene Vorlage anzulegen, zum Beispiel die Präambel, die Sie für jeden Artikel verwenden, sichern Sie eine Datei mit der Endung .tex in diesem Ordner oder duplizieren eine Vorlage und ändern sie. Unterordner werden zu Untermenüs. Vorlagen, die Sie hinzufügen, umbenennen oder entfernen, erscheinen im Menü der danach geöffneten Fenster.

Updates von TeXShop ändern diesen Ordner nicht, Ihre Vorlagen bleiben also erhalten. Um die ursprünglichen Vorlagen zurückzubekommen, verschieben Sie den Ordner Templates aus ~/Library/TeXShop heraus, zum Beispiel auf den Schreibtisch, und starten TeXShop neu: Es legt den Ordner mit seinen eigenen Vorlagen neu an.

Neue Dokumente aus einem Formularblock

Ablage › Neu aus Formularblock … beginnt ein neues Dokument mit einem vollständigen Muster: Wählen Sie im Fenster „Formularblock auswählen“ einen in der Spalte „Formularblock“, neben der die Spalte „Beschreibung“ jeden erklärt, und klicken Sie auf „Erstellen“; die Leertaste zeigt den ausgewählten Formularblock in der Übersicht. Das neue Dokument hat keinen Titel; sichern Sie es, wo Sie möchten. TeXShop bringt Formularblöcke für einen AMS-Artikel, eine Beamer-Präsentation, einen Brief, ein PreTeXt-Dokument, ein Projekt mit Hauptdatei und Kapitel sowie ein XeLaTeX-Dokument mit.

Die Formularblöcke stehen in ~/Library/TeXShop/Stationery. „Im Finder anzeigen“ im Fenster öffnet diesen Ordner. Um das vorderste Dokument als Formularblock hinzuzufügen, klicken Sie im Fenster auf + und geben Sie einen Namen und eine Beschreibung ein; − legt den ausgewählten Formularblock in den Papierkorb, und ein Klick auf die Beschreibung des ausgewählten Formularblocks ändert sie. Sie können die Datei auch selbst dort ablegen, zum Beispiel Report.tex, zusammen mit einer Datei Report.comment, die einen beschreibenden Satz enthält.
