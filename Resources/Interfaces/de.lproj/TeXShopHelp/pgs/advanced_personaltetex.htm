Persönliche Dateien zu TeX Live hinzufügen

Stildateien, Klassen, Literaturdatenbanken und andere Dateien, die nicht zu TeX Live gehören, kommen in Ihren persönlichen TeX-Baum, den Ordner texmf im Ordner „Library“ Ihres Benutzerordners: ~/Library/texmf. Alle Programme von TeX Live finden die Dateien dort, und sie haben Vorrang vor gleichnamigen Dateien in TeX Live selbst. Nach dem Hinzufügen einer Datei muss nichts registriert werden; der nächste Satzlauf findet sie.

Der Ordner „Library“ ist im Finder ausgeblendet. Um ihn zu öffnen, wählen Sie im Finder „Gehe zu“ › „Gehe zum Ordner …“ und geben ~/Library ein. Legen Sie dort den Ordner texmf an, falls es ihn noch nicht gibt.

Bevor Sie ein Paket hinzufügen

Die meisten Pakete auf CTAN sind bereits Teil von TeX Live, und MacTeX installiert sie alle. Um zu sehen, ob TeX eine Datei schon hat, wählen Sie in TeXShop Ablage › Öffne Stil-Datei… und geben ihren Namen ein, etwa hyperref.sty; TeXShop öffnet die Datei, die TeX verwenden würde. Fügen Sie ein Paket nur dann Ihrem persönlichen Baum hinzu, wenn TeX Live es nicht enthält oder wenn Sie eine eigene Version brauchen. Da Ihre Kopie Vorrang hat, entfernen Sie sie wieder, sobald TeX Live eine neuere Version hat; sonst verwenden Sie weiter die alte.

Wohin die Dateien gehören

Die Ordner in texmf haben dieselbe Struktur wie TeX Live. Legen Sie die Ordner an, die Sie brauchen:

OrdnerInhalt
tex/latex/LaTeX-Pakete und -Klassen (.sty, .cls), jedes Paket in einem eigenen Ordner
tex/plain/Dateien für plain TeX
tex/generic/Dateien, die mit jedem Format funktionieren
bibtex/bib/Literaturdatenbanken (.bib)
bibtex/bst/Literaturstile (.bst)
doc/Dokumentation der hinzugefügten Pakete; Hilfe › Hilfe für Paket einblenden… findet sie dort

Ein Paket mit eigenen Makros und Ihre Literaturdatenbank würden zum Beispiel so abgelegt:

~/Library/texmf/tex/latex/mymacros/mymacros.sty
~/Library/texmf/bibtex/bib/mybibliography.bib

Dann funktionieren \usepackage{mymacros} und \bibliography{mybibliography} in jedem Dokument, wo immer es gesichert ist.

Den Ordner prüfen

Welchen Ordner Ihr TeX als persönlichen Baum verwendet, zeigt die Eingabe im Terminal

kpsewhich -var-value TEXMFHOME

Auf einem Mac ist es ~/Library/texmf, sofern die Installation nicht anders eingerichtet wurde. Welche Kopie einer Datei TeX liest, zeigt zum Beispiel kpsewhich mymacros.sty.

Fügen Sie den Ordnern von TeX Live selbst keine Dateien hinzu; siehe Mehr über TeX Live.
