Jede TeX-Distribution erwartet persönliche Ergänzungen (etwa eigene Style-Dateien oder Pakete, die nicht zur eigentlichen Distribution gehören) in einem lokalen Ordner bzw. Verzeichnis. Dieser Ordner heißt „texmf“ und hat eine bestimmte Struktur von Unterordnern, damit die TeX-Programme die Dateien richtig finden.

Auf dem Mac liegt der lokale texmf-Ordner im Ordner „Library“ Ihres Benutzerordners. Man schreibt dafür meist „~/Library/texmf“, wobei „~“ für „Ihren Benutzerordner“ steht (also den Ordner, den Sie sehen, wenn Sie in einem Finder-Fenster auf das Symbol Ihres Benutzerordners klicken).

Wann gehört etwas in den lokalen texmf-Ordner?

Bevor Sie etwas in den lokalen texmf-Ordner legen, sollten Sie prüfen, ob das betreffende Paket nicht schon zu TeX Live gehört und damit in der MacTeX-Distribution enthalten ist. Am einfachsten geht das mit TeX Live Utility. Das gilt besonders für Pakete auf CTAN: Die meisten davon sind in TeX Live enthalten und sollten Ihnen bereits zur Verfügung stehen.

Wenn Sie wissen, dass ein Paket nicht zu TeX Live gehört, legen Sie es in Ihren lokalen texmf-Ordner.

Was gehört wohin?

Der texmf-Ordner enthält eine Reihe von Ordnern, die ihrerseits weitere Ordner enthalten. Für die meisten Benutzer sind die folgenden drei Ordner der obersten Ebene am wichtigsten:

OrdnerWas hineingehört
bibtexHierher gehören bib- und bst-Dateien. Er sollte mindestens die folgenden Ordner enthalten:
 
bstLegen Sie bst-Dateien hier ab.
bibLegen Sie bib-Dateien hier ab.
 
texHierher gehören neue Pakete. Er sollte die folgenden Ordner enthalten:
 
latexLegen Sie LaTeX-Pakete hier ab.
plainLegen Sie Dateien für plain TeX hier ab.
xelatexLegen Sie Pakete speziell für XeLaTeX hier ab.
xetexLegen Sie Dateien für plain XeTeX hier ab.
contextLegen Sie ConTeXt-Dateien hier ab.
genericLegen Sie Dateien, die mit jeder TeX-Variante funktionieren, hier ab.
 
docLegen Sie hier die Dokumentation der Pakete ab, die Sie im Ordner „tex“ installiert haben. Dann findet texdoc sie (ebenso wie „Hilfe für Paket einblenden...“ im Menü „Hilfe“ von TeXShop).

Weitere Ordner der obersten Ebene sind fonts, scripts und source.

Umgebungsvariablen

In anderen Unix-Umgebungen teilt man tex den Ort persönlicher Eingabedateien manchmal über die Umgebungsvariablen TEXINPUTS, BSTINPUTS und BIBINPUTS mit. Mit TeX Live ist das fast nie nötig; legen Sie persönliche Eingabedateien stattdessen in passende Unterordner von ~/Library/texmf.

Unter ganz besonderen Umständen können diese Umgebungsvariablen gesetzt werden. Unter Mac OS X kann man Programmen Umgebungsvariablen mitteilen, indem man im Benutzerordner eine Datei ~/.MacOSX/environment.plist anlegt. Diese Umgebungsvariablen werden von allen Shells des Benutzers und allen Carbon- und Cocoa-Programmen übernommen; legen Sie die Datei daher mit Vorsicht an.

Hier ist eine Beispieldatei environment.plist von Nathan Potter. Danke! Für weitere Details besuchen Sie http://developer.apple.com/qa/qa2001/qa1067.html.
