AppleScript-Makros definieren

AppleScript ist eine eigene Sprache. Apples AppleScript Language Guide auf der Entwickler-Website von Apple beschreibt sie vollständig.

Pfade und Dokumentname

Bevor ein AppleScript-Makro ausgeführt wird, ersetzt TeXShop die folgenden Zeichenfolgen durch den Pfad einer Datei des aktiven Dokuments, in doppelten Anführungszeichen:

#FILEPATH#
die Quelltextdatei
#TEXPATH#
die .tex-Datei
#NAMEPATH#
die Quelltextdatei ohne Endung
#FOLDERPATH#
der Ordner, der den Quelltext enthält, mit einem Schrägstrich am Ende
#PDFPATH#, #DVIPATH#, #PSPATH#, #LOGPATH#, #AUXPATH#
die .pdf-, .dvi-, .ps-, .log- und .aux-Datei
#INDPATH#, #BBLPATH#, #HTMLPATH#
die .ind-, .bbl- und .html-Datei

Ergibt #FILEPATH# zum Beispiel /Users/name/Projects/Fourier/Fourier.tex, so ergibt #FOLDERPATH# /Users/name/Projects/Fourier/. Wurde das Dokument noch nie gesichert, ist #FILEPATH# eine leere Zeichenfolge.

#DOCUMENTNAME# wird durch den Namen des Dokuments ersetzt, wie ihn der Titel des Quelltextfensters zeigt: mit Endung, oder ohne, wenn die Endung ausgeblendet ist. Ein Skript verwendet ihn, um das Dokument anzusprechen, das es aufgerufen hat:

tell document #DOCUMENTNAME# of application "TeXShop"
  latex
end tell

Befehle von TeXShop

Ein AppleScript kann seine Arbeit auf zwei Arten erledigen: Es kann Shell-Befehle ausführen, wie unter Skripte mit Shell-Befehlen schreiben beschrieben, oder die eigenen Befehle von TeXShop aufrufen, wie unter Skripte mit TeXShop-Satzbefehlen schreiben beschrieben. TeXShop versteht diese Befehle:

typeset
latex
tex
bibtex
makeindex
metapost
typesetinteractive
latexinteractive
texinteractive
bibtexinteractive
makeindexinteractive
metapostinteractive
taskdone
refreshpdf
refreshtext
goto line

Die ersten sechs Befehle setzen durchgehend, ohne bei Fehlern anzuhalten. Die nächsten sechs setzen ebenfalls, halten aber bei einem Fehler an, damit Sie in der Konsole antworten können. Ein Satzbefehl kehrt sofort zurück, bevor das Setzen beendet ist. taskdone gibt NO zurück, solange noch gesetzt wird, und YES, wenn das Setzen fertig ist. refreshpdf und refreshtext lassen PDF- und Textfenster die neueste Version ihrer Dateien anzeigen. goto line wählt eine Zeile im Quelltext aus:

tell document #DOCUMENTNAME# of application "TeXShop"
  goto line 37
end tell
