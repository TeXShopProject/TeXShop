Skripte mit TeXShop-Satzbefehlen schreiben

Ein Dokument mit Literaturverzeichnis braucht eine Folge von Satzläufen: LaTeX schreibt die .aux-Datei, BibTeX schreibt daraus die .bbl- und .blg-Dateien, LaTeX läuft erneut, um das Literaturverzeichnis in das Dokument aufzunehmen, und noch einmal, um die Verweise darauf zu aktualisieren. Ihre Projekte brauchen vielleicht ähnliche Folgen, und ein AppleScript-Makro kann sie für Sie ausführen.

Das mit TeXShop gelieferte Makro Makros › Applescript › Bibliography zeigt, wie das geht. Hier ist sein Inhalt:

--Applescript

set fileName to #FILEPATH#
if fileName is equal to  ""
activate
display dialog "Please save the file first"  buttons {"OK"} default button "OK"
return
end if

set frontName to #DOCUMENTNAME#

tell document frontName of application "TeXShop"

    latexinteractive

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    bibtex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

    latex

    repeat
        delay 2
        if taskdone
            exit repeat
        end if
    end repeat

end tell

Die erste Zeile macht daraus ein AppleScript-Makro, das ScriptRunner ausführt; es kann TeXShop daher setzen lassen (siehe AppleScript-Makros). Die nächsten Zeilen prüfen #FILEPATH#, den vollständigen Pfad der Quelltextdatei. Er ist eine leere Zeichenfolge, wenn das Dokument noch nicht gesichert wurde; in diesem Fall bittet das Skript Sie, es zu sichern, und hört auf.

Danach spricht das Skript das Dokument über #DOCUMENTNAME# an. TeXShop sichert das Dokument selbst, wenn ein Satzbefehl beginnt; das Skript muss es also nicht sichern.

Die übrigen Befehle führen latexinteractive, bibtex, latex und latex aus. Ein Satzbefehl kehrt sofort zum Skript zurück, bevor das Setzen beendet ist; daher wartet nach jedem Befehl eine repeat-Schleife, bis taskdone meldet, dass die Aufgabe erledigt ist. Die Zeile delay 2 lässt das Skript zwischen den Prüfungen pausieren, statt ständig nachzufragen und den Computer zu bremsen. Die Befehle sind unter AppleScript-Makros definieren aufgeführt.
