Die erweiterte Suchmaske, die Sie unter Einstellungen > Editor > Suchoberfläche wählen, sucht und ersetzt mit regulären Ausdrücken. Alle Benutzer beginnen mit ihr: Beim ersten Start von TeXShop 6.00 wechseln auch Benutzer früherer Versionen einmal zu ihr, gleich welche Methode sie hatten, und können dort wieder eine andere wählen. Wer die OgreKit Suchmaske benutzt hat, findet in „Weitere Optionen“ die Ersetzungssyntax OgreKit (\1) gewählt. „Alle suchen“ listet alle Treffer mit ihrer Zeilennummer in der Suchmaske auf; ein Klick auf eine Zeile wählt den Treffer aus. „Alle hervorheben“, „Alle auswählen“ und „Hervorhebungen entfernen“ befinden sich im Menü von „Alle suchen“. „Alles ersetzen“ wird mit einem einzigen „Widerrufen“ rückgängig gemacht. Die Optionen unter den Feldern und hinter der Taste mit den drei Punkten werden gesichert und stehen Ihnen beim nächsten Start wieder zur Verfügung.

Die Suchmaske verwendet die regulären Ausdrücke von ICU. Eine geschweifte Klammer, die nicht Teil einer Wiederholung ist, muss als \{ oder \} geschrieben werden. Im Ersatztext stehen $1, $2, ... für die Gruppen und \$ für ein Dollarzeichen; die OgreKit-Syntax mit \1, \2, ... und einem $, das für sich selbst steht, kann in den Optionen gewählt werden. Ein Backslash im Ersatztext wird doppelt geschrieben. Die Taste „?“ neben „Regulärer Ausdruck“ öffnet eine Kurzreferenz der Syntax und des Ersatztextes, die auch zeigt, worin sich ICU und OgreKit unterscheiden. Die Felder verwenden die Schrift der Quelle und die Farben ihres Themas. Ist „Regulärer Ausdruck“ ausgeschaltet, werden sie wie TeX in der Quelle eingefärbt; ist er eingeschaltet, zeigen sie die Teile eines Musters in den Farben des Themas, Fehler in Rot und das, was OgreKit anders liest, in Orange; die Zeile unter den Optionen erklärt die Farben.

„Mehrfach ersetzen bearbeiten …“ im Untermenü „Suchen“ verwaltet Regelsätze aus Paaren von Suchtext und Ersatztext, die der Reihe nach angewendet und mit einem einzigen „Widerrufen“ rückgängig gemacht werden. Die Taste „Mehrfach ersetzen …“ rechts neben „Alles ersetzen“ in der erweiterten Suchmaske führt ebenfalls dorthin. Die Regelsätze sind Dateien in ~/Library/TeXShop/MultipleReplace im JSON-Format der Ersetzungsdefinitionen von CotEditor. Das Untermenü „Mehrfach ersetzen“ wendet einen Regelsatz auf einmal auf den ganzen Text an.

„Alles ersetzen“, „Alle suchen“ und „Mehrfach ersetzen“ laufen im Hintergrund, und das Dokument kann erst bearbeitet werden, wenn sie beendet sind. Dauert einer dieser Vorgänge länger, zeigt ein Dialog am Dokumentfenster, wie viele Treffer er gefunden oder wie viele Regeln er ausgeführt hat; die Taste „Abbrechen“ des Dialogs oder die Escape-Taste hält ihn an und lässt den Text, wie er war.

Die Suchmaske sucht auch in den Fenstern der Konsole, der Log-Datei und von Experiment. In der Konsole, der Log-Datei und der Experiment-Konsole, die die Ausgabe von TeX zeigen, ist das Ersetzen abgeblendet.

Die OgreKit-Suchmaske von Isao Sonobe steht in den Einstellungen weiterhin als veraltete Wahl zur Verfügung; der Wechsel zu ihr oder von ihr zu einer anderen Suche erfordert einen Neustart von TeXShop. Das TeXShop-Handbuch beschreibt die erweiterte Suchmaske ausführlich.

Ganze Zeilengruppen können mit einem einfachen Menü-Befehl auskommentiert werden und später wieder aktiviert werden. Zeilengruppen können mit einem Menü-Befehl eingerückt werden und später wieder zurück. Wenn eine Zeile mit einer Reihe von Tabulatorsprüngen oder Leerzeichen beginnt, so werden nachfolgende Zeilen an der selben Stelle beginnen bis dies durch Drücken der Rückstelltaste rückgängig gemacht wird. Diese Funktion wurde von Nicolás Ojeda Bär aus Argentinien hinzugefügt. er ist unter lojedaortiz@interlink.com.ar zu erreichen. Danke!

Das Quelltext-Fenster kann mit Hilfe des Aufteilungswerkzeugs in der Werkzeugleiste in zwei Teile aufgeteilt werden. Nach der Auffteilung wird zwei Mal der selbe Quelltext angezeigt. Wenn Sie auf einer Seite etwas ändern, wird diese Änderung auf der anderen Seite sogleich übernommen. So können Sie eine Stelle bearbeiten und gleichzeitig eine andere betrachten.

TeXShop kann bei jedem Sichern eine Sicherungskopie anlegen. Wenn „Automatisch sichern und Versionen aktivieren“ ausgeschaltet ist, schalten Sie unter Einstellungen > Dokumente und Sichern „Beim Sichern die vorherige Datei als ‚Name~‘ behalten“ ein. Die Sicherungskopie hat den Namen der Datei, gefolgt von einer Tilde.

Eine Statistik-Palette zählt die Anzahl der Wörter, Zeilen und Zeichen im Dokument. Intern ruft diese Funktion den Befehl

detex myfile | wc

auf. Der „detex“-Befehl filtert „tex“-Befehle aus, jedoch bleiben die angegebenen Zahlen nur Näherungswerte. Input- und inlcude-Dateien werden automatisch gezählt.

Dateisymbole können per „Drag and Drop“ in den Quelltext eingefügt werden. Ist die einzufügende Datei ein tex-Dokument, wird der „\input“-Befehl zusammen mit dem relativen Pfad eingefügt. Handelt es sich bei der einzufügenden Datei um eine Grafik, so wird der Befehl „\includegraphics“ eingefügt. Folgende Grafikformate werden unterstützt: pdf, jpg, jpeg, tif, tiff, eps, ps.

Wird eine cls-Datei eingefügt, so wird der Befehl „\documentclass“ mit einer Dateireferenz hinzugefügt. Eine sty-Datei produziert „\usepackage“ eine bib-Datei „\bibliographystyle“ und eine Text-Datei „\input“.

Drag & drop löst Aliase auf. Das bedeutet, das eine per drag&drop eingefügte Grafik, die eigentlich ein Alias ist, korrekt gesetzt wird und zu keiner Fehlermeldung führt. TeX selbst kann zwar keine Aliase, jedoch smbolische Verknüpfungen auflösen. Wird also der Name der (Alias-)Datei direkt im Quelltext eingegeben, wird beim Setzen ein Fehler angezeigt.

Das Verhalten bei „Drag and Drop“ kann an Ihre Bedürfnisse angepasst werden. Dies geschieht über das Makro-Menü. Fügen Sie hier ein neues Untermenü mit dem Namen „Drag & Drop“ ein. In diesem Untermenü müssen Sie einzelne Objekte mit dem Suffix-Namen der Datei erstellen, deren Verhalten Sie anpassen möchten. Erstellen Sie den entsprechenden Code hierzu in diesem Objekt. Ist das Objekt z. B. „pdf“, so wäre der Code „\includegraphics[#INS#]{%r}“. Hierbei können folgende Abkürzungen benutzt werden:

%F der volle Pfad der einzufügenden Datei
%f der Dateiname der einzufügenden Datei
%r der relative Pfad der einzufügenden Datei
%n der Dateiname der einzufügenden Datei ohne Suffix
%e das Suffix der einzufügenden Datei

Wird im Makro-Editor ein Suffix nicht aufgeführt, so werden die jeweiligen Dateien wie oben Beschrieben normal behandelt. Daher werden die meisten kein Makro-„Drag & Drop“-Menü benötigen.
