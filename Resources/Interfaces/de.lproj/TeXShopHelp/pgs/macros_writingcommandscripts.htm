Skripte mit Shell-Befehlen schreiben

Diese Seite zeigt am Makro pdflatexc von Claus Gerhardt unter Makros › Claus Gerhardt Macros, wie ein AppleScript ein Shell-Skript aufruft. Das Shell-Skript selbst ist einfach: Es fügt die Ordner der TeX-Programme dem Suchpfad hinzu und startet pdflatex mit --shell-escape. Ihre eigenen Skripte werden wahrscheinlich mehr tun, etwa mehrere Programme nacheinander starten; dann werden diese Techniken nützlich.

Das Shell-Skript

Das Shell-Skript ist ~/Library/TeXShop/bin/pdflatexc. Es hängt nicht von TeXShop ab: Liegt sein Ordner in Ihrem Suchpfad, startet die Eingabe pdflatexc myfile.tex im Terminal das Skript. Hier ist es:

#!/bin/tcsh
# pdflatexc
# Claus Gerhardt
#
# Usage
# pdflatexc filename.tex

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)

pdflatex --shell-escape "$1"

Das AppleScript

Das Makro, das dieses Shell-Skript aufruft, ist interessanter:

--Applescript
-- Apply only to an already saved file.

set scriptPath to (do shell script "dirname " & "~/Library/TeXShop/Scripts/ex")
set scriptPath to scriptPath & "/setname.scpt"
set scriptName to POSIX file scriptPath as alias
set scriptLiB to (load script scriptName)
tell scriptLib
set frontName to setname(#NAMEPATH#,#TEXPATH#)
end tell

set fileName to  #TEXPATH#
set n to (number of characters of contents of fileName)
set fileNamequoted to quoted form of fileName
set baseName to do shell script "basename " & fileNamequoted
set m to (number of characters of contents of baseName)
set dirName to quoted form of (characters 1 thru (n - m - 1) of fileName as string)

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName
do shell script shellScript

tell document frontName of application "TeXShop"
    refreshpdf
end tell

Nach den Kommentaren sind die ersten sieben Zeilen ein Rezept von Claus Gerhardt, das die Quelltextdatei sichert und den Namen ihres Dokuments ermittelt, der in frontName abgelegt wird. Die Arbeit erledigt das kompilierte Skript setname.scpt in ~/Library/TeXShop/Scripts: Diese Zeilen ermitteln den Pfad ~/Library/TeXShop/Scripts/setname.scpt, laden das Skript und rufen es mit #NAMEPATH# und #TEXPATH# auf.

Oft geht dasselbe einfacher mit

set frontName to #DOCUMENTNAME#
tell document frontName of application "TeXShop"
    save
end tell

Das Rezept hat zwei Vorteile. Es funktioniert auch, wenn das vorderste Dokument nicht dasjenige ist, das die späteren Befehle erhalten soll, etwa eine Log-Datei wie /Users/name/Examples/myfile.log. Und wurde die Datei noch nie gesichert, gibt das Rezept einen Fehler zurück, während der Befehl save das Skript hinter einem Sichern-Dialog warten ließe.

Die nächsten sechs Zeilen setzen die Variablen dirName und baseName. Ist die Quelltextdatei /Users/name/My Papers/Stuff/myfile.tex, so ist dirName gleich '/Users/name/My Papers/Stuff', wegen des Leerzeichens in einem Ordnernamen für die Shell in Anführungszeichen gesetzt, und baseName ist myfile.tex. Der Dateiname wird ebenso in Anführungszeichen gesetzt, wenn er an das Shell-Skript übergeben wird, sodass beide Leerzeichen enthalten dürfen.

Die nächsten drei Zeilen rufen das Shell-Skript auf. Das Ergebnis ist dasselbe wie die Eingabe von cd '/Users/name/My Papers/Stuff'; ~/Library/TeXShop/bin/pdflatexc 'myfile.tex' im Terminal. Die letzten drei Zeilen aktualisieren das Vorschaufenster.

Einige dieser Zeilen sind kompliziert, lassen sich aber unverändert in neue Skripte kopieren.

Shell-Befehle aus AppleScript ausführen

AppleScript führt einen Shell-Befehl in der Form

do shell script "cmd input"

aus. Um einen Befehl aus Teilen zusammenzusetzen, schreiben Sie ihn in der gleichwertigen Form

do shell script "cmd " & "input"

Beachten Sie das Leerzeichen nach cmd. Das kaufmännische Und verbindet zwei Zeichenfolgen:

"cmd " & "input" = "cmd input"

Eine von AppleScript gestartete Shell beginnt im Wurzelordner. Der Befehl

do shell script "cd " & dirName

wechselt in den Ordner in dirName, der bereits in Anführungszeichen steht; weitere Anführungszeichen sind also nicht nötig.

Jedes do shell script startet eine neue Shell; ein späterer Befehl wäre also nicht mehr in diesem Ordner. Um weitere Befehle im selben Ordner auszuführen, verbinden Sie sie wie im Terminal mit Semikolons zu einem Befehl:

do shell script "cmd1 " & "input1" & ";" & "cmd2 " & "input2"

Das Skript oben tut dies mit cmd1 = cd, input1 = dirName, cmd2 = ~/Library/TeXShop/bin/pdflatexc und input2 = baseName. Die Zeilen

set shellScript to "cd " & dirName & ";"
set shellScript to shellScript & "~/Library/TeXShop/bin/pdflatexc  " & quoted form of baseName

sind nur ein bequemer Weg, diese Folge in einer Variablen abzulegen.
