Syntaxhervorhebung

Das Quelltextfenster zeigt TeX farbig an: Kommentare, Befehle, Fußnoten, die Zeichen $ und & sowie die Klammern ( ), { } und [ ] haben jeweils eine eigene Farbe. Quelltext › Syntaxhervorhebung schaltet die Hervorhebung für das aktive Dokument ein oder aus. Dokumente öffnen sich mit eingeschalteter Hervorhebung; um sie ausgeschaltet zu öffnen, verwenden Sie die versteckte Einstellung

defaults write TeXShop SyntaxColoringEnabled NO

Was hervorgehoben wird

  • Befehle sind ein Backslash, gefolgt von Buchstaben. Einstellungen › Editor › Syntaxhervorhebung › „@ als Teil von Befehlsnamen“ zählt auch @ als Buchstaben, wie in den internen Befehlen von Paketen.
  • Der Text von \footnote, \footcite und \autocite erscheint in der Farbe „Fußnote“. Die versteckte Einstellung defaults write TeXShop SyntaxColorFootnote NO färbt nur den Befehl.
  • Quelltext › Indexeinträge hervorheben zeigt die Argumente von \index und \esindex in der Farbe „Index“. Einstellungen › Editor › Syntaxhervorhebung › „Indexeinträge standardmäßig hervorheben“ schaltet dies beim Öffnen von Dokumenten ein.
  • Quelltext › expl3-Code hervorheben färbt außerdem die Funktionen, Variablen und anderen Teile von expl3-Code, der Programmierebene von LaTeX, für alle, die Pakete schreiben. „expl3-Code standardmäßig hervorheben“ in derselben Gruppe schaltet dies beim Öffnen von Dokumenten ein.
  • „Vollbreite Buchstaben und Symbole hervorheben“ in derselben Gruppe zeigt Buchstaben, Ziffern und Symbole voller Breite, die sich in japanischem Text leicht mit ASCII-Zeichen verwechseln lassen, in den Farben „Vollbreit“.

„Indexeinträge hervorheben“ und „expl3-Code hervorheben“ gelten für das aktive Dokument; jedes Quelltextfenster hat seine eigene Wahl. Dateien, die keine TeX-Quelltexte sind, etwa Log-Dateien, werden nicht hervorgehoben; die Liste der Endungen und wie man eine hinzufügt, steht unter Andere Dateien mit TeXShop öffnen.

Die Farben ändern

Die Farben gehören zum Thema. Wählen Sie sie unter Einstellungen › Themen:

  • Die Gruppe „Syntaxhervorhebung“ enthält „Kommentar“, „Befehl“, „Fußnote“, „Markierung“ und „Index“;
  • die Gruppe „Klammern“ enthält die Farben von ( ), { } und [ ];
  • die Gruppe „expl3“ enthält function, __function, key, variable, __variable, argument und msg;
  • die Gruppe „Hervorhebungen“ enthält unter anderem die Farben „Vollbreit“;
  • die Gruppe „XML-Syntax“ enthält die Farben für HTML- und XML-Dateien.

Jedes Thema hat seine eigenen Farben, sodass sich Hellmodus-Thema und Dunkelmodus-Thema unterscheiden können.
