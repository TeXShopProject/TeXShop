Mehrere TeX-Distributionen nebeneinander

Auf einem Mac können mehrere TeX-Installationen nebeneinander bestehen: Jahrgänge von TeX Live, die mit MacTeX oder BasicTeX installiert wurden, ein TeX Live, das mit seinem eigenen Installationsprogramm installiert wurde, oder TeX aus Homebrew oder MacPorts. TeXShop verwendet die Installation im Feld „TeX-Engines“ unter Einstellungen › Satz › Pfade und Ghostscript aus dem Feld „Ghostscript“ darunter.

Pfade erkennen

TeXShop kann beide Felder für Sie ausfüllen. Beim ersten Start von TeXShop und immer, wenn Sie in der Gruppe „Pfade“ unter Einstellungen › Satz auf „Pfade erkennen …“ klicken, sucht TeXShop TeX und Ghostscript an den üblichen Orten: in den Ordnern, die in /etc/paths und /etc/paths.d aufgeführt sind, und im PATH von TeXShop, in /Library/TeX/texbin, in den Ordnern von TeX Live in /usr/local/texlive, /opt/texlive und /Applications/TeXLive, in den TeX-Ordnern von UpTeX.app und pTeX.app, in /usr/local/teTeX/bin sowie in den Ordnern von Homebrew, MacPorts und Fink. Es prüft, ob die Programme laufen, und listet die gefundenen Installationen mit ihren Versionen auf, die neueste zuerst. Die neueste ist ausgewählt, Sie können aber eine andere wählen, getrennt für TeX und für Ghostscript. Die Pfade ändern sich erst, wenn Sie auf „OK“ klicken. Eine Installation an einem anderen Ort können Sie weiterhin von Hand in die Felder eingeben.

„Pfade erkennen …“ ändert nur „TeX-Engines“ und „Ghostscript“. Engine-Dateien, die ihre eigenen Ordner angeben, und das Feld „Zweite TeX-Engines“ bleiben unverändert.

TeX Live ohne MacTeX

Die Installationsprogramme von MacTeX und BasicTeX richten /Library/TeX/texbin auf das TeX Live, das sie installieren, sodass Programme, die diesen Pfad verwenden, der neuesten Installation folgen. Ein TeX Live, das mit dem Installationsprogramm von TeX Live selbst installiert wurde, ändert diesen Link nicht. Um eine solche Installation zu verwenden, wählen Sie sie mit „Pfade erkennen …“ oder geben Sie den Ordner ihrer Programme unter „TeX-Engines“ ein, zum Beispiel /usr/local/texlive/2026/bin/universal-darwin.

Umgebungsvariablen

Manche Distributionen setzen in den Startdateien der Shell Umgebungsvariablen wie TEXINPUTS oder TEXMFHOME. TeX liest dann Dateien aus anderen Ordnern als erwartet, und dasselbe Dokument kann im Terminal anders gesetzt werden als in TeXShop. Wenn TeX eine falsche Version einer Datei verwendet, prüfen Sie zuerst diese Variablen; im Terminal zeigt kpsewhich, gefolgt vom Dateinamen, welche Kopie TeX findet.
