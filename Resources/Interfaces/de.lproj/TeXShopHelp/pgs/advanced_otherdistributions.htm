Zusammenarbeit mit anderen TeX Distributionen

Probleme können auftreten, wenn mehere TeX Distributionen auf dem System installiert sind, besonders, wenn Sie Umgebungsvariabeln bestimmen. Dies kann dazuführen, dass Probleme schwerer zu finden sind, da andere Dateien verwendet werden, als Sie erwarten.

MacTeX verwendet eine Datenstruktur, mit der mehrere TeX-Distributionen auf einem Rechner nebeneinander bestehen können. Die aktive Distribution wählt man in TeX Live Utility mit dem Befehl „Reconfigure Distributions“. Die Datenstruktur legt den symbolischen Link /Library/TeX/texbin an, der immer auf die Programme der aktiven Distribution zeigt. GUI-Programme lassen sich deshalb ein für alle Mal einrichten, indem man als Programmverzeichnis /Library/TeX/texbin, als Ort von pdftex /Library/TeX/texbin/pdftex usw. einstellt.

Diese Datenstruktur wird von jedem der MacTeX-Pakete automatisch installiert. Ein ohne MacTeX mit dem Installationsskript von TeX Live installiertes TeX Live legt sie nicht an; stellen Sie in diesem Fall in den TeXShop-Einstellungen unter Satz > Pfade > TeX-Engines den Programmordner dieses TeX Live ein, oder verwenden Sie „Pfade erkennen…“ (siehe unten).

Ab TeXShop 6.00 kann TeXShop TeX und Ghostscript selbst finden. Beim ersten Start und mit der Taste „Pfade erkennen…“ unter „Satz“ in den Einstellungen sucht TeXShop an den üblichen Orten, etwa in /Library/TeX/texbin, in den TeX-Live-Ordnern, bei Homebrew und bei MacPorts, und zeigt die gefundenen Installationen mit ihren Versionen an. Die neueste ist ausgewählt; für TeX und für Ghostscript kann jeweils eine andere gewählt werden. Die Pfade ändern sich erst mit „OK“.
