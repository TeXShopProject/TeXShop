TeX-Formate erstellen und verwenden

Eine Formatdatei (Endung .fmt) ist eine Momentaufnahme von TeX, nachdem es eine Reihe von Makros gelesen hat. LaTeX selbst ist ein Format: TeX lädt es in einem Augenblick, statt jedes Mal die Quellen von LaTeX zu lesen. Sie können aus einer langen Präambel ein eigenes Format erstellen, damit das Setzen schneller beginnt, oder ein Format verwenden, das ein Projekt oder eine Organisation bereitstellt.

Ein Format funktioniert nur mit der Engine und der Version von TeX Live, mit der es erstellt wurde. Ein mit pdfLaTeX aus TeX Live 2026 erstelltes Format kann weder XeLaTeX noch ein anderer Jahrgang von TeX Live verwenden; erstellen Sie es nach der Installation eines neuen TeX Live erneut.

Ein Format erstellen

Schreiben Sie die Zeilen, die das Format enthalten soll, in eine Datei und beenden Sie sie mit \dump. Zum Beispiel uo.tex:

\documentclass[11pt]{article}
\usepackage{geometry}
\usepackage{graphicx}
\usepackage{amsmath,amssymb}
\dump

Wechseln Sie im Terminal in den Ordner dieser Datei und geben Sie ein:

pdflatex -ini -jobname=uo "&pdflatex" uo.tex

Das lädt das LaTeX-Format, liest uo.tex und schreibt uo.fmt. Ein Dokument, das mit diesem Format gesetzt wird, lässt die Zeilen weg, die im Format stehen, und beginnt mit \begin{document}.

Ein Format in TeXShop verwenden

  1. Bewegen Sie uo.fmt in den Ordner ~/Library/texmf/web2c und legen Sie die Ordner bei Bedarf an, damit TeX das Format aus jedem Ordner findet.
  2. Öffnen Sie im Finder ~/Library/TeXShop/Engines (TeXShop › Den Ordner „~/Library/TeXShop“ im Finder öffnen), duplizieren Sie eine Engine wie XeLaTeX.engine und benennen Sie die Kopie um, etwa in Oregon.engine. Der Name erscheint in TeXShop und muss nicht zum Format passen.
  3. Öffnen Sie die Kopie in TeXShop und ändern Sie ihre letzte Zeile, sodass die Engine so lautet: 
    #!/bin/tcsh

set path= ($path /Library/TeX/texbin /usr/texbin /usr/local/bin)
pdflatex -fmt=uo -file-line-error -synctex=1 "$1"

Danach geöffnete Dokumente führen Oregon im Einblendmenü neben der Taste „Setzen“ auf. Um das Format für ein Dokument zu verwenden, gleich was dort gewählt ist, schreiben Sie diese Zeile an den Anfang des Quelltexts:

% !TEX program = Oregon

Um es zur Vorgabe zu machen, wählen Sie unter Einstellungen › Satz › Engine › Neue Dokumente setzen mit „Engine-Datei“ und im Menü „Engine-Datei“ Oregon. Siehe Satz-Engines hinzufügen.

Für ein Format für plain TeX verwenden Sie in der Engine pdftex statt pdflatex. Bei einem Format, das „Über DVI“ verwendet wird, muss die Engine die DVI-Datei außerdem in PDF umwandeln, etwa mit dvipdfmx "${1:r}.dvi" in einem zsh-Skript, denn TeXShop zeigt die PDF-Datei mit dem Namen der Quelltextdatei an.
