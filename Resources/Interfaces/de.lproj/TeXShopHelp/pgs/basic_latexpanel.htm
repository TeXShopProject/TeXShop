LaTeX-Palette

Fenster › LaTeX-Palette … öffnet eine Palette mit LaTeX-Code: mathematische Symbole, griechische Buchstaben, Funktionen, Buchstaben mit Akzent und internationale Zeichen, Umgebungen und Befehle für Schriftarten. Klicken Sie im Quelltext an die Stelle, an die der Code soll, und klicken Sie dann auf eine Taste der Palette. Ihr Code wird an der Einfügemarke eingefügt. Die Palette bleibt beim Arbeiten vor den Quelltextfenstern.

Die Tasten sind auf Seiten angeordnet. Wählen Sie eine Seite mit den Tasten oben in jedem Teil der Palette: Mathematik, Griechisch, Symbole, Funktionen und International sowie Umgebungen, Typographie und Eigene.

Ist beim Klicken auf eine Schriftart- oder Umgebungstaste Text ausgewählt, kommt der ausgewählte Text in den eingefügten Code, wie in \textbf{ausgewählter Text}.

Einige Symbole brauchen das Paket amssymb. Fügen Sie diese Zeile in die Präambel eines Dokuments ein, das sie verwendet:

\usepackage{amssymb}

Die Palette anpassen

Der Code, den jede Taste einfügt, steht in ~/Library/TeXShop/LatexPanel/completion.plist. Öffnen Sie diese Datei in TeXShop, um ihn zu ändern; die Kommentare am Anfang erklären ihren Aufbau. Die Namen der Standardtasten lassen sich nicht ändern, wohl aber der Code, den sie einfügen. In diesem Code gilt:

  • #SEL# steht für den ausgewählten Text;
  • #INS# gibt an, wo die Einfügemarke nach dem Einfügen des Codes steht;
  • #PASTE# steht für den Text in der Zwischenablage.

Die Seite „Eigene“ bietet Platz für bis zu sechzehn eigene Tasten. Jede wird in der Liste Customized der Datei durch zwei Zeichenketten definiert, den Namen der Taste und den Code, den sie einfügt:

<string>Section</string>
<string>\section{#SEL##INS#}</string>

Sichern Sie die Datei in UTF-8, beenden Sie TeXShop und starten Sie es neu, um die Änderungen in der Palette zu sehen. Fehlt die Datei oder ist sie beschädigt, ersetzt TeXShop sie durch seine eigene Kopie. Siehe Die LaTeX-Palette anpassen und Dateien in ~/Library/TeXShop.
