BibTeX

BibTeX erstellt das Literaturverzeichnis eines LaTeX-Dokuments aus einer Datenbank von Literaturangaben, einer Datei mit der Endung .bib. Das Dokument zitiert Einträge über ihre Schlüssel, und BibTeX führt nur die zitierten Einträge auf.

Eine Datenbank mybibliography.bib enthält Einträge wie

@book{Knuth:TeXbook,
  author    = {Donald E. Knuth},
  title     = {The {\TeX}book},
  publisher = {Addison-Wesley},
  year      = {1986}
}

und das Dokument zitiert sie und nennt den Stil und die Datenbank:

As explained in~\cite{Knuth:TeXbook}, …

\bibliographystyle{plain}
\bibliography{mybibliography}

BibTeX ausführen

  1. Setzen Sie das Dokument. Die Zitate erscheinen als [?], und das Literaturverzeichnis fehlt.
  2. Wählen Sie Setzen › BibTeX (⇧⌘B), oder wählen Sie BibTeX im Einblendmenü neben der Taste „Setzen“ und klicken Sie auf „Setzen“.
  3. Setzen Sie noch zweimal: Der erste Lauf fügt das Literaturverzeichnis hinzu, der zweite ergänzt die Zitate.

Beim Setzen mit latexmk, etwa mit der Engine pdflatexmk oder einem Profil, das „Mit latexmk“ eingerichtet ist, werden BibTeX und die zusätzlichen Läufe von selbst ausgeführt.

Um in TeXShop eine neue Datenbank anzulegen, wählen Sie im Sichern-Dialog im Menü „Dateityp“ den Typ bib, damit die Datei die Endung .bib erhält. Eine Datenbank kann auch in Ihrem persönlichen TeX-Baum liegen, wo jedes Dokument sie findet; siehe Persönliche Dateien zu TeX Live hinzufügen.

Das Programm wählen

Setzen › BibTeX führt den Befehl unter Einstellungen › Satz › Zugehörige Programme › BibTeX-Programm aus, als Vorgabe bibtex. Tragen Sie dort ein anderes Programm mit den nötigen Optionen ein, etwa biber für Dokumente, die das Paket biblatex verwenden. Die Engine-Profile setzen dieses Feld: pbibtex für pLaTeX + dvipdfmx, upbibtex für upLaTeX + dvipdfmx und LuaLaTeX (Japanisch) und bibtex für die übrigen Profile.

Um das Programm für ein einzelnes Dokument zu wählen, schreiben Sie eine Zeile wie diese in eine seiner ersten zwanzig Zeilen:

% !BIB program = biber

Die Zeile hat Vorrang vor der Einstellung. Die Form % !BIB TS-program = wird genauso gelesen.
