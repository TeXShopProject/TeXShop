Alternativer Satzmodus

TeXShop setzt normalerweise mit der Methode „PDF direkt“: pdfLaTeX oder pdfTeX schreibt die PDF-Datei unmittelbar. Die alternative Methode „Über DVI“ lässt LaTeX oder TeX eine DVI-Datei erzeugen, wandelt sie mit dvips in PostScript um und das PostScript mit Ghostscript in PDF. Diese Schritte erledigt das Skript simpdftex von TeX Live.

„Über DVI“ ist für Dokumente nötig, die PostScript-Code in die Ausgabe schreiben, etwa mit dem Paket pstricks. EPS-Bilder brauchen es nicht: TeX Live wandelt sie beim Setzen mit „PDF direkt“ in PDF um.

Die Methode wählen

Setzen › Über DVI und Setzen › PDF direkt stellen die Methode des aktiven Dokuments um; andere geöffnete Dokumente behalten ihre. Einstellungen › Satz › Satzmethode legt die Methode fest, mit der Dokumente beginnen. Die dritte Wahl, „Persönliches Skript“, ruft stattdessen die Befehle der Gruppe „Persönliches Skript“ auf. Die Befehle für „Über DVI“, einer für plain TeX und einer für LaTeX, stehen in der Gruppe „Über DVI“ unter Einstellungen › Satz. Das Engine-Profil LaTeX + dvips + Ghostscript unter „Andere“ im Menü „Engine-Profil“ richtet den Satz über DVI ein.

Die Methode im Dokument festlegen

Eine Zeile in den ersten 20 Zeilen des Quelltexts legt das Programm und die Methode für dieses Dokument fest, unabhängig von den Einstellungen:

ZeileGesetzt mit
% !TEX program = pdflatexLaTeX, PDF direkt
% !TEX program = latexLaTeX, Über DVI
% !TEX program = pdftexplain TeX, PDF direkt
% !TEX program = texplain TeX, Über DVI
% !TEX program = personallatexLaTeX, Persönliches Skript
% !TEX program = personaltexplain TeX, Persönliches Skript

Optionen für „Über DVI“

Ghostscript ignoriert Transparenz in PostScript standardmäßig. Um sie zu erhalten, fügen Sie --distilleropts "-dALLOWPSTRANSPARENCY" am Ende des Befehls in der Gruppe „Über DVI“ hinzu. Um die PostScript-Zwischendatei zu behalten, fügen Sie --keep-psfile hinzu. Ghostscript wird aus dem Ordner unter Einstellungen › Satz › Pfade › Ghostscript aufgerufen.
