Schutz vor Shell Escape

Während des Setzens kann TeX andere Programme starten. Als Vorgabe erlaubt TeX Live nur eine kurze Liste vertrauenswürdiger Programme, etwa um EPS-Grafiken in PDF umzuwandeln. Pakete, die andere Programme starten müssen, verlangen die Option -shell-escape (auch --shell-escape geschrieben).

Mit dieser Option kann ein Dokument jeden beliebigen Befehl ausführen, zum Beispiel einen, der alle Dateien in Ihrem Benutzerordner löscht. Verwenden Sie sie nur für Dokumente, denen Sie vertrauen, und nicht für Dateien, die Sie von anderen erhalten.

Die Option hinzufügen

  • Im Befehl für LaTeX oder plain TeX unter Einstellungen › Satz › PDF direkt, für jedes Dokument, das „PDF direkt“ gesetzt wird.
  • In einer Engine-Datei, für jedes Dokument, das mit dieser Engine gesetzt wird; siehe Satz-Engines hinzufügen.
  • Für ein einzelnes Dokument, das mit einer der latexmk-Engines wie pdflatexmk gesetzt wird, mit der Zeile % !TEX parameter = -shell-escape am Anfang des Quelltexts.

Eine Engine hat die Option bereits: sepdflatexmk, das mit TeXShop kommt und von Anfang an im Ordner Engines liegt, setzt immer mit --shell-escape. Es genügt, sie in der Symbolleiste des Quelltextfensters oder mit einer Zeile % !TEX program = sepdflatexmk zu wählen; verwenden Sie sie daher nur für Dokumente, denen Sie vertrauen.

Bei Shell-Escape nachfragen

Einstellungen › Satz › PDF direkt › „Bei Shell-Escape nachfragen“, als Vorgabe ausgeschaltet, schützt die Befehle der Gruppe „PDF direkt“. Ist die Einstellung eingeschaltet und enthält der Befehl für plain TeX oder LaTeX dort -shell-escape oder --shell-escape, fragt TeXShop nach, bevor es ein Dokument nach dem Öffnen zum ersten Mal setzt:

  • „OK“ setzt mit der Option.
  • „Shell Escape nicht benutzen“ setzt ohne sie.
  • „Abbrechen“ setzt nicht.

Haben Sie „OK“ oder „Shell Escape nicht benutzen“ gewählt, gilt die Antwort für dieses Dokument, bis es geschlossen wird; so können Sie Ihre eigenen Dokumente mit der Option setzen und Dokumente von anderen ohne sie. Engine-Dateien werden nicht geprüft, auch wenn sie -shell-escape enthalten; sepdflatexmk setzt also ohne Nachfrage mit der Option.
