In TeX Live können pdftex, pdflatex und andere TeX-Programme seit 2011 während des Setzens eine kleine Liste vertrauenswürdiger Programme aufrufen. So dürfen diese Programme zum Beispiel Ghostscript aufrufen, um eps-Dateien in pdf-Dateien umzuwandeln.

pdftex, pdflatex und andere Programme lassen sich so einrichten, dass sie während des Setzens beliebige Shell-Befehle aufrufen können. Dazu muss dem Aufruf die Option „-shell-escape“ hinzugefügt werden, entweder in der Kategorie „Satz“ der Einstellungen von TeXShop oder in einzelnen Engine-Skripten. Diese Option ist jedoch ein ernstes Sicherheitsrisiko, da sie die Ausführung beliebiger Shell-Programme erlaubt, zum Beispiel auch eines kurzen Programms, das alle Dateien im Benutzerordner löscht. Ist die Option gesetzt, könnte eine böswillige Website eine TeX-Quelldatei anbieten, die diese Dateien beim Setzen löscht.

Wir raten davon ab, die Option zu setzen, doch einige ungewöhnliche Pakete benötigen sie möglicherweise. Für diesen Fall bietet TeXShop einen Schutz: In der Gruppe „PDF direkt“ der Kategorie „Satz“ gibt es die Einstellung „Bei Shell-Escape nachfragen“. Sie ist bei Auslieferung von TeXShop ausgeschaltet. Sie prüft nur die Befehle für plain TeX und LaTeX in dieser Gruppe, die verwendet werden, wenn eine Datei mit TeX oder LaTeX über „PDF direkt“ gesetzt wird. Engine-Skripte (.engine-Dateien) werden nicht geprüft, auch wenn sie „-shell-escape“ enthalten. Ist die Einstellung eingeschaltet und enthält der verwendete Befehl „-shell-escape“, erscheint beim ersten Setzen einer Datei während einer TeXShop-Sitzung ein Warndialog, in dem Sie Shell-Escape für diese Datei ausschalten können. Während der Sitzung erscheint der Dialog für diese Datei nicht noch einmal. So können Sie Ihre eigenen Dateien mit Shell-Escape setzen und per E-Mail erhaltene Dateien ohne Shell-Escape.
