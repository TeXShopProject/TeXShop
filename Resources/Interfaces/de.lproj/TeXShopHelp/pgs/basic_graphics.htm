Die Programme pdftex und pdflatex können Grafikdateien in den Formaten pdf, jpg, png oder mps verwenden. Das native Grafikformat von Mac OS X ist pdf (portable document format); solche Dateien lassen sich in jeder Größe gut drucken. Wahrscheinlich werden die meisten künftigen Grafikprogramme für den Mac pdf ausgeben.

Um Grafiken zu verwenden, fügen Sie die folgende Zeile in die Präambel Ihrer Quelldatei ein:

\usepackage{graphicx}

Wenn Sie eine Grafikdatei einfügen wollen, beispielsweise „f1.pdf“, benutzen Sie den Befehl

\includegraphics[width=2in]{f1}

Indem Sie die angegebene Breite in diesem Befehl ändern, können Sie die Größe der Grafik beim Setzen anpassen. Probieren Sie aus, welche Größe Ihnen zusagt.

Sollten Sie schon früher TeX benutzt haben, liegen Ihre Grafiken vielleicht im eps-Format vor. Diese Dateien müssen in das pdf-Format umgewandelt werden, bevor sie mit pdftex und pdflatex gesetzt werden. Ab TeX Live 2011 geschieht das automatisch, sofern die Quelldatei das Paket graphicx lädt.

Einzelne eps-Dateien können Sie in das pdf-Format umwandeln, indem Sie sie in TeXShop öffnen. Dabei wird die eps-Datei automatisch in pdf umgewandelt; die pdf-Datei wird auf die Festplatte geschrieben, und die eps-Datei bleibt erhalten. Anschließend wird die pdf-Datei geöffnet.

Die Autoren von pdflatex und die Autoren des Grafikpakets graphicx haben es einfach gemacht, Grafikdateien in ein LaTeX-Dokument einzufügen, das mit pdflatex gesetzt wird – selbst wenn das Dokument später mit Standard-LaTeX gesetzt und für die Weitergabe an andere in eine dvi-Datei umgewandelt wird. Das kann vorkommen, wenn Sie Quelldateien mit einem Kollegen austauschen, der gewöhnliches LaTeX benutzt und eps-Grafiken statt pdf-Grafiken braucht. Wenn Sie eine Grafik einfügen wollen, beispielsweise „f1.pdf“, benutzen Sie den folgenden Befehl und lassen dabei die Endung „.pdf“ bzw. „.eps“ weg:

\includegraphics[width=2in]{f1}

Dieser Befehl lässt TeX die Datei „f1.pdf“ einlesen, wenn der Text mit pdflatex gesetzt wird, aber die Datei „f1.eps“, wenn der Text mit latex gesetzt wird.

Sie können auch tif- und tiff-Grafiken verwenden. Dafür hat TeXShop den Menübefehl „TIFF umwandeln“, der die Dateien in png-Dateien umwandelt, die pdftex und pdflatex verstehen. Der Befehl ist verfügbar, wenn das Quelltextfenster aktiv ist. Wenn Sie ihn wählen, erscheint ein Öffnen-Dialog, der alle Dateien im Ordner der Quelldatei anzeigt. Nur tif- und tiff-Dateien sind auswählbar, alle anderen sind ausgegraut. Wählen Sie eine oder mehrere Dateien und klicken Sie auf „Konvertieren“. Alle gewählten Dateien werden in png-Dateien umgewandelt; die tiff-Dateien bleiben unverändert.

Wenn Sie einige ältere Dateien mit eps-Grafiken haben oder in TeX das PostScript-Paket pstricks benutzen, können Sie statt mit pdflatex „Über DVI“ setzen. Einzelheiten finden Sie im Abschnitt „Alternativer Schriftsatzmodus“ der TeXShop-Hilfe. In diesem Modus müssen eps-Dateien nicht in das pdf-Format umgewandelt werden. Für neue Projekte mit vielen eps-Dateien ist dieser Modus jedoch keine gute Wahl, weil die eps-Grafiken bei jedem Setzen implizit in pdf umgewandelt werden müssen; bei komplizierten Grafiken verlangsamt das das Setzen enorm. Im Modus „Über DVI“ findet die Umwandlung von PostScript in pdf nämlich ganz am Ende des Setzens statt, nachdem die Grafiken in das vollständige Dokument eingebettet wurden.
