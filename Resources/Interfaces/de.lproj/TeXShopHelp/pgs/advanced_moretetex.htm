Mehr über TeX Live

Wo TeX Live installiert ist

MacTeX installiert TeX Live in /usr/local/texlive/2026, BasicTeX in /usr/local/texlive/2026basic. TeX Live erscheint einmal im Jahr, und jeder Jahrgang wird in einem eigenen Ordner installiert, etwa 2027, sodass mehrere Jahrgänge nebeneinander auf dem Mac bleiben können. Um einen zu entfernen, bewegen Sie seinen Ordner in den Papierkorb.

Der Ordner /usr/local ist im Finder ausgeblendet. Um hineinzusehen, wählen Sie im Finder „Gehe zu“ › „Gehe zum Ordner …“ und geben den Pfad ein.

Wie TeXShop TeX findet

TeXShop startet TeX aus dem Ordner im Feld „TeX-Engines“ unter Einstellungen › Satz › Pfade. Vorgabe ist /Library/TeX/texbin, ein Link, den die Installationsprogramme von MacTeX und BasicTeX auf die Programme des gerade installierten TeX Live richten. Wird ein neuer Jahrgang von TeX Live installiert, folgt ihm der Link, und TeXShop verwendet das neue TeX ohne Änderung in den Einstellungen.

Um eine andere Installation zu verwenden, geben Sie unter „TeX-Engines“ den Ordner ihrer Programme ein, zum Beispiel /usr/local/texlive/2026/bin/universal-darwin, oder klicken Sie auf „Pfade erkennen …“ und wählen Sie unter den Installationen, die TeXShop findet; siehe Mehrere TeX-Distributionen nebeneinander.

TeX Live unverändert lassen

Die Ordner von TeX Live gehören dem System, und ein Update oder ein neuer Jahrgang von TeX Live ersetzt sie. Fügen Sie dort keine Dateien hinzu und ändern Sie keine. Legen Sie eigene Stildateien, Klassen und Literaturdatenbanken stattdessen in Ihren persönlichen Baum, wo TeX sie zuerst findet und Updates sie nicht berühren; siehe Persönliche Dateien zu TeX Live hinzufügen.

Dokumentation

TeX Live enthält Dokumentation zu fast jedem Paket. Hilfe › Hilfe für Paket einblenden … öffnet die Dokumentation eines Pakets anhand seines Namens, zum Beispiel hyperref oder tikz. Hilfe › TeX-Live-Dokumentation (Englisch) nennt, wo die Anleitung zu TeX Live und weitere Dokumentation online zu finden sind.
