TeX Live von der TUG wird im Verzeichnis /usr/local/texlive installiert, das im Finder nicht sichtbar ist. Der Installer erstellt jedoch in /Library/TeX/Root einen symbolischen Link auf das Verzeichnis der aktiven TeX-Distribution. Um die Dateien Ihrer Distribution anzusehen, gehen Sie deshalb nach /Library/TeX/Root.

Die Dokumentation der aktiven Distribution befindet sich in /Library/TeX/Documentation (eigentlich ein Link auf verschiedene Dokumentationsordner in der Distribution).

Es ist möglich, zusätzliche Style-Dateien, Schriften und so weiter in TeX Live selbst abzulegen. TeX Live gehört jedoch dem Benutzer „root“ und liegt in einem Ordner, in den Benutzer nicht schreiben dürfen. Außerdem ist es sinnvoll, dieses Verzeichnis unverändert zu lassen, damit es sich leicht aktualisieren lässt, wenn neuere Versionen erscheinen. Besser ist es, in Ihrem Library-Ordner ein Abbild der Verzeichnisstruktur von TeX Live anzulegen und Ihre persönlichen Dateien dort zu speichern.

Die Dateien müssen in den richtigen Verzeichnissen liegen. TeX Live benutzt eine Verzeichnisstruktur, die von der TeX-Arbeitsgruppe entwickelt wurde. Angenommen, Sie möchten den Style-Dateien von LaTeX eine weitere Datei namens new.sty hinzufügen. Ein Blick in TeX Live zeigt, dass der natürliche Platz für diese Datei folgender wäre:

/usr/local/texlive/2008/texmf/tex/latex/misc/

Legen Sie deshalb im Library-Ordner Ihres Benutzerordners die folgenden Unterordner an:

Library --> texmf --> tex --> latex --> misc

und speichern Sie „new.sty“ in diesem Ordner „misc“.

TeX Live sucht BibTeX-bib-Dateien in ~/Library/texmf/bibtex/bib und BibTeX-bst-Dateien in ~/Library/texmf/bibtex/bst.

MacTeX installiert außerdem das Programm TeX Live Utility in /Applications/TeX. Wenn mehrere TeX-Distributionen auf Ihrem Rechner installiert sind, wechseln Sie in TeX Live Utility mit dem Befehl „Reconfigure Distributions“ im Menü „Configure“ zwischen ihnen. Die aktive Distribution wird für Aufrufe von TeX auf der Befehlszeile, für die MAN-Seiten im Terminal und von allen GUI-Programmen verwendet, die TeX über /Library/TeX/texbin finden. Wenn Sie TeX Live ohne MacTeX installiert haben und TeX Live Utility es nicht anzeigt, stellen Sie stattdessen in den TeXShop-Einstellungen unter Satz > Pfade > TeX-Engines den Programmordner dieses TeX Live ein (zum Beispiel /usr/local/texlive/2026/bin/universal-darwin).
