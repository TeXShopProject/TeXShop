<h3>LaTeX Documentation</h3> 



<p> TeX is a typesetting program by Donald Knuth, used extensively in mathematics, computer science, physics, economics, and other fields.  For a history of the development of TeX,
see <a href="http://www.tug.org/whatis.html">Just What Is TeX</a>. Consult the <a href="http://www.tug.org/">TeX Users Group Web Site</a> for additional information.</p>


<p> To use TeXShop, you need to learn TeX or LaTeX. The following books are
recommended. The first, by the author of LaTeX, is short, and the other three are detailed and comprehensive.</p>

<ul>
<li> <i>LaTeX, A Document Preparation System (Second Edition)</i> by Leslie Lamport, Addison-Wesley </li>
<p><li> <i>More Math Into LaTeX (Fifth Edition)</i> by
George Gratzer, Springer</li>
<p><li> <i>Guide to LaTeX, Tools and Techniques for Computer Typesetting (Fourth Edition)</i> by
Helmut Kopka and Patrick W. Daly, Addison-Wesley</li>
<p><li> <i>The LaTeX Companion, Parts I & II (Third Edition)</i> by
Frank Mittelbach and Ulrike Fischer, Addison-Wesley</li>
</ul> 

<p> A number of free guides to LaTeX are available. Two of the most useful are</p>
<ul>
<li><a href="http://www.ctan.org/tex-archive/info/lshort/english/lshort.pdf">The Not So Short Introduction to LaTeX2e</a>, by Tobias Oetiker</li>

<p><li><a href="https://www.learnlatex.org/en/">
LaTeX Tutorials</a> from Learn LaTeX.org</li>
</ul>

<p> The previous links give English versions of the guides, but versions are available in many  languages using the alternate links below:
<ul>
<li><a href="https://ctan.org/pkg/lshort">The Not So Short Introduction to LaTeX2e</a>, by Tobias Oetiker</li>

<p><li><a href="https://www.learnlatex.org/">
LaTeX Tutorials</a> from Learn LaTeX.org</li>
</ul>
