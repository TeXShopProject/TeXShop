    Installing TeXShop

    To install TeXShop, double click the zip file if it did not unzip automatically, and then drag the TeXShop icon to /Applications or /Applications/TeX, creating that TeX subfolder if necessary.

    After installing, users upgrading from an earlier version should read "About This Release", the first item in the TeXShop Help menu, to learn how to make minor configuration changes which activate new features.

    TeXShop will automatically configure itself to look for TeX binaries in /Library/TeX/texbin. If you are using a different TeX distribution like MikTeX, MacPorts, or Homebrew, open TeXShop Preferences (called "Settings" in the most recent macOS), select the "Engine" tab, and fill in the top item with a path to your TeX binary directory.
